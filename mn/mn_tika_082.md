Sandhāretunti vināsanato pubbe yādisaṃ, tatheva sammadeva dhāretuṃ samattho. Saddhāti kammaphalasaddhāya sampannā. Sāmaṇeraṃ disvāti sikkhākāmatāya etadagge ṭhapiyamānaṃ disvā.

## 295

295. Piyāyitabbato piyoti āha ‘‘pītijanako’’ti. Manassa appāyanato manāpoti āha ‘‘manavaḍḍhanako’’ti. Sukhedhito taruṇadārakakāle. Tato parañca sappikhīrādisādurasamanuññabhojanādiāhārasampattiyā sukhaparibhato. Atha vā daḷhabhattikadhātijanādiparijanasampattiyā ceva paricchadasampattiyā ca uḷārapaṇītasukhapaccayūpahārehi ca sukhedhito, akiccheneva dukkhappaccayavinodanena sukhaparibhato. Ajjhattikaṅgasampattiyā vā sukhedhito, bāhiraṅgasampattiyā sukhaparibhato. Kassacīti upayogatthe sāmivacanaṃ, kiñcīti vuttaṃ hoti, ayameva vā pāṭho. →「"tesu"とは、悪を行っている衆生たちの中で(ということであり)、そしてこれは選び出しの意味での処格である。」

12. Paramparāyāti attabhāvaparamparāya.

* paramparāya = 「連続によって、相続によって」
  * paramparā = 「連続、次々と続くこと」
* ti = 「とは」

  * attabhāva = 「自己存在、個体、身体」

→「"paramparāya"とは、自己存在の連続によって(ということである)。」

13. Saṃsāraṃ āpajjitvāti bhavādīsu saṃsārassa āpajjanahetuṃ āpajjanto paralokaṃ upeti, paralokaṃ upentova bahuvidhadukkhasaṅkhātaṃ gabbhañca upeti.

* saṃsāraṃ āpajjitvā = 「輪廻に入って、輪廻に陥って」
  * āpajjitvā = 「陥って、入って」(āpajjati の連続体)
* ti = 「とは」
* bhava-ādīsu = 「有などにおいて」
  * bhava = 「有、生存」
* saṃsārassa = 「輪廻の」
* āpajjana-hetuṃ = 「陥る原因を」
  * āpajjana = 「陥ること、入ること」
  * hetu = 「原因」
* āpajjanto = 「陥りつつ、身に受けつつ」(現在分詞)
* para-lokaṃ = 「他の世界を、来世を」
* upeti = 「至る、赴く」
* para-lokaṃ upento eva = 「来世に至りつつ、まさに」

  * bahuvidha = 「多種の、様々な」
  * saṅkhāta = 「〜と呼ばれる、〜と称される」
* gabbhaṃ ca = 「母胎にも」
  * gabbha = 「母胎、胎」
* upeti = 「至る」

→「"saṃsāraṃ āpajjitvā"とは、有などにおいて輪廻に陥る原因を身に受けつつ来世に至り、来世に至りつつ、まさに多種の苦と呼ばれる母胎にも至る(ということである)。」

14. Tādisassāti tathārūpassa gabbhavāsadukkhādīnaṃ adhiṭṭhānabhūtassa appapaññassa añño appapañño ca abhisaddahanto hitasukhāvahanti pattiyāyanto.

* tādisassa = 「そのような者の」
* ti = 「とは」
* tathārūpassa = 「そのような性質の(者の)」
* gabbha-vāsa-dukkha-ādīnaṃ = 「母胎に住む苦などの」
  * gabbha-vāsa = 「母胎に住むこと、胎内の生活」
* adhiṭṭhāna-bhūtassa = 「依りどころとなっている(者の)」
  * adhiṭṭhāna = 「依りどころ、基盤」
  * bhūta = 「〜となった」
* appa-paññassa = 「智慧の少ない者の」
  * appa = 「少ない」
* añño appapañño ca = 「また別の智慧の少ない者も」
* abhisaddahanto = 「信じつつ」
  * abhisaddahati = 「信じる、信頼する」
* hita-sukha-āvahaṃ = 「利益と安楽をもたらす」
  * hita = 「利益」
  * sukha = 「安楽」
  * āvaha = 「もたらす」
* ti = 「と」
* pattiyāyanto = 「信じつつ、信頼しつつ」
  * abhisaddahanto の言い換え

→「"tādisassa"とは、そのような性質の、母胎に住む苦などの依りどころとなっている智慧の少ない者の(ということであり)、また別の智慧の少ない者も(その者を)信じつつ、すなわち利益と安楽をもたらすと信頼しつつ(ということである)。」

15. ‘‘Pāpadhammo’’ti vuttattā tādisassa paraloko nāma duggati evāti āha ‘‘paramhi apāyaloke’’ti.

* ''pāpa-dhammo'' = 「悪い性質の者」
  * pāpa = 「悪い」
  * dhamma = 「性質、法」
* ti vuttattā = 「と説かれているから」
  * vuttatta = 「説かれていること」(奪格)
* tādisassa = 「そのような者の」
* para-loko nāma = 「来世というものは」
* duggati eva = 「悪趣にほかならない」
  * duggati = 「悪趣、悪い境遇」
* ti = 「と(考えて)」
* āha = 「(アッタカターの作者は)言った」
* ''paramhi apāya-loke'' = 「他の世界において、(すなわち)苦界の世界において」
  * paramhi = 「他の、次の」(処格)
  * apāya = 「苦界、悪処」
* ti = 「と」

→「"悪い性質の者"と説かれているから、そのような者の来世というものは悪趣にほかならない、と(考えて)"他の世界、すなわち苦界の世界において"と言ったのである。」

16. Vividharūpenāti rūpasaddādivasena tatthapi paṇītatarādivasena bahuvidharūpena.

→「"vividharūpena"とは、色・声などによって、またそれらの中でもより優れたものなどによって、多種の姿によって(ということである)。」

17. Sāmaññamevāti samaṇabhāvo eva seyyo.

* sāmaññaṃ eva = 「沙門であることこそ」
  * sāmañña = 「沙門の生活、沙門であること」

18. Ettha ca ādito dvīhi gāthāhi catuttho dhammuddeso anugīto.

* ettha ca = 「そしてここで」
* ādito = 「最初から、初めの」

  * dhamma-uddesa = 「法の要説、法の要約的提示」

* anugīto = 「追って歌われた、再び述べられた」
  * anu-gīta = 「後に続けて歌われた」(anugāyati の過去分詞)

→「そしてここで、最初の二つの偈によって第四の法の要説が追って歌われた。」

19. Catutthagāthāya tatiyo.

* catuttha-gāthāya = 「第四の偈によって」
* tatiyo = 「第三の(法の要説が)」
  * 第三の要説は「世界は自分のものがなく、すべてを捨てて行かねばならない」

→「第四の偈によって第三の(法の要説が追って歌われた)。」

20. Pañcamagāthāya dutiyo.

22. Sattamagāthāya paṭhamo dhammuddeso anugīto, aṭṭhamādīhi pavattinivattīsu kāmesu nekkhamme ca yathārahaṃ ādīnavānisaṃsaṃ vibhāvetvā attano pabbajjakāraṇaṃ paramato dassento yathāvuttadhammuddesaṃ nigameti, tena vuttaṃ ‘‘tā pana gāthā dhammuddesānaṃ desanānupubbiṃ anādiyitvāpi yathārahaṃ saṅgaṇhanavasena anugītā’’ti.

* sattama-gāthāya = 「第七の偈によって」
* paṭhamo dhammuddeso = 「第一の法の要説が」
  * 第一の要説は「世界は運び去られ、常住ではない」
* anugīto = 「追って歌われた」
* aṭṭhama-ādīhi = 「第八(の偈)などによって」
* pavatti-nivattīsu = 「(輪廻の)続行と止滅とにおいて」
  * pavatti = 「続行、流転」
  * nivatti = 「止滅、退転」
* kāmesu nekkhamme ca = 「諸欲と出離とにおいて」
  * nekkhamma = 「出離」
* yathārahaṃ = 「それぞれにふさわしく」
* ādīnava-ānisaṃsaṃ = 「危険と利益とを」
  * ādīnava = 「危険、過患」
  * ānisaṃsa = 「利益、功徳」
* vibhāvetvā = 「明らかにして」(vibhāveti の連続体)
* attano pabbajjā-kāraṇaṃ = 「自分の出家の理由を」
  * pabbajjā = 「出家」
  * kāraṇa = 「理由、原因」
* paramato = 「最高のものとして、究極的に」
* dassento = 「示しつつ」(現在分詞)
* yathāvutta-dhammuddesaṃ = 「前述の法の要説を」
* nigameti = 「結論づける、締めくくる」
* tena vuttaṃ = 「それゆえに(アッタカターで)言われた」
* ''tā pana gāthā = 「しかしそれらの偈は」
* dhammuddesānaṃ desanā-anupubbiṃ = 「法の要説の説示の順序を」
  * desanā = 「説示、教説」
  * anupubbī = 「順序、次第」
* anādiyitvā pi = 「取り上げずにもまた、従わなくても」
  * an-ādiyitvā = 「取らずに」(ādiyati の連続体の否定)
* yathārahaṃ = 「それぞれにふさわしく」
* saṅgaṇhana-vasena = 「包摂によって、まとめることによって」
  * saṅgaṇhana = 「包摂、総括」
