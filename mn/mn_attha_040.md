1. 10. Cūḷaassapurasuttavaṇṇanā

* cūḷa-assapura-sutta-vaṇṇanā = 「小アッサプラ経の解説」
  * cūḷa = 「小さい」
  * assapura = 「アッサプラ（アンガ国の町の名）」
  * vaṇṇanā = 「解説、註釈」

→「小アッサプラ経の解説」

2. 435. Evaṃme sutanti cūḷaassapurasuttaṃ.

* evaṃ me sutaṃ = 「このように私は聞いた」
* ti = 「～という（経は）」
* cūḷaassapurasuttaṃ = 「小アッサプラ経（である）」

→「『このように私は聞いた』（で始まるの）は小アッサプラ経である。」

3. Tassa desanākāraṇaṃ purimasadisameva.

* tassa = 「その（経の）」
* desanā-kāraṇaṃ = 「説示の理由、説かれた因縁」
  * desanā = 「説示、教説」
  * kāraṇa = 「理由、原因」
* purima-sadisam eva = 「前の（経）と同じである」
  * purima = 「前の、先の（大アッサプラ経を指す）」
  * sadisa = 「同様の、同じ」
  * eva = 「まさに、～にほかならない」

→「その説示の理由は前の（大アッサプラ経の場合）とまったく同じである。」

4. Samaṇasāmīcippaṭipadāti samaṇānaṃ anucchavikā samaṇānaṃ anulomappaṭipadā.

* samaṇa-sāmīci-ppaṭipadā = 「沙門にふさわしい実践」
  * samaṇa = 「沙門」
  * sāmīci = 「正しいこと、ふさわしいこと、適切さ」
  * paṭipadā = 「実践、行道」
* ti = 「～とは」
* samaṇānaṃ = 「沙門たちにとって」
* anucchavikā = 「ふさわしい、適した」
* samaṇānaṃ anuloma-ppaṭipadā = 「沙門たちに順応した実践」
  * anuloma = 「順応した、随順する、適合する」

→「『沙門にふさわしい実践』とは、沙門たちにふさわしい、沙門たちに順応した実践のことである。」
