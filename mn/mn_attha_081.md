# 1. Ghaṭikārasuttavaṇṇanā

## 282 (1)

282. Evaṃme sutanti ghaṭikārasuttaṃ. Tattha sitaṃ pātvākāsīti mahāmaggena gacchanto aññataraṃ bhūmippadesaṃ oloketvā – ‘‘atthi nu kho mayā cariyaṃ caramānena imasmiṃ ṭhāne nivutthapubba’’nti āvajjanto addasa – ‘‘kassapabuddhakāle imasmiṃ ṭhāne vegaḷiṅgaṃ nāma gāmanigamo ahosi, ahaṃ tadā jotipālo nāma māṇavo ahosiṃ, mayhaṃ sahāyo ghaṭikāro nāma kumbhakāro ahosi, tena saddhiṃ mayā idha ekaṃ sukāraṇaṃ kataṃ, taṃ bhikkhusaṅghassa apākaṭaṃ paṭicchannaṃ, handa naṃ bhikkhusaṅghassa pākaṭaṃ karomī’’ti maggā okkamma aññatarasmiṃ padese ṭhitakova sitapātukammamakāsi, aggaggadante dassetvā mandahasitaṃ hasi. Yathā hi lokiyamanussā uraṃ paharantā – ‘‘kuhaṃ kuha’’nti hasanti, na evaṃ buddhā, buddhānaṃ pana hasitaṃ haṭṭhapahaṭṭhākāramattameva hoti.

Hasitañca nāmetaṃ terasahi somanassasahagatacittehi hoti. Tattha lokiyamahājano akusalato catūhi, kāmāvacarakusalato catūhīti aṭṭhahi cittehi hasati, sekkhā akusalato diṭṭhisampayuttāni dve apanetvā chahi cittehi hasanti, khīṇāsavā catūhi sahetukakiriyacittehi ekena ahetukakiriyacittenāti pañcahi cittehi hasanti. Tesupi balavārammaṇe āpāthagate dvīhi ñāṇasampayuttacittehi hasanti, dubbalārammaṇe duhetukacittadvayena ca ahetukacittena cāti tīhi cittehi hasanti. Imasmiṃ pana ṭhāne kiriyāhetukamanoviññāṇadhātusomanassasahagatacittaṃ bhagavato haṭṭhapahaṭṭhākāramattaṃ hasitaṃ uppādesi.

* taṇḍula-vāha-satāni = 「百ヴァーハの米」
  * taṇḍula = 「米、精米」
  * vāha = 「ヴァーハ(荷量の単位、荷車の積み荷)」
  * sata = 「百」
* iti ettha = 「とはここで」
* dve sakaṭāni = 「二台の荷車(分)が」
* eko vāho = 「一ヴァーハ」
* iti veditabbo = 「と知られるべきである」

→「『百ヴァーハの米』とは、ここでは二台の荷車分が一ヴァーハであると知られるべきである。」

2. Tadupiyañca sūpeyyanti sūpatthāya tadanurūpaṃ telaphāṇitādiṃ.

* tad-upiyaṃ = 「それにふさわしい」
  * upiya = 「適した、ふさわしい」
* ca = 「そして」
* sūpeyyaṃ = 「汁物の材料、副食の材料」
* iti = 「とは」
* sūpa-atthāya = 「汁物のために」
* tad-anurūpaṃ = 「それに相応した」
* tela-phāṇita-ādiṃ = 「油・糖蜜など」
  * tela = 「油」
  * phāṇita = 「糖蜜」
  * ādi = 「など」

→「『それにふさわしい副食の材料』とは、汁物のための、それに相応した油・糖蜜などである。」

3. Vīsatibhikkhusahassassa temāsatthāya bhattaṃ bhavissatīti kira saññāya rājā ettakaṃ pesesi.

* vīsati-bhikkhu-sahassassa = 「二万人の比丘のための」
  * vīsati = 「二十」
  * sahassa = 「千」
* te-māsa-atthāya = 「三か月のために」
* bhattaṃ = 「食事が」
* bhavissati = 「あるだろう」
* iti kira saññāya = 「という思いで、と伝えられる」
  * kira = 「〜と伝えられる、〜だそうである」
  * saññā = 「思い、想念」
* rājā = 「王は」
* ettakaṃ = 「これだけ(の量)を」
* pesesi = 「送った」

→「二万人の比丘の三か月分の食事になるだろうという思いで、王はこれだけ(の量)を送ったと伝えられる。」

4. Alaṃ me raññova hotūti kasmā paṭikkhipi?

* alaṃ me = 「私には十分である(不要である)」
* rañño eva hotu = 「王のものでありますように」
  * rañño = 「王の(属格)」
  * hotu = 「あれ、ありますように(命令法)」
* iti = 「と」
* kasmā = 「なぜ」
* paṭikkhipi = 「拒んだのか」

→「『私には不要です。王のものでありますように』と、なぜ拒んだのか。」

5. Adhigataappicchatāya.

* adhigata-appicchatāya = 「すでに得ている少欲性によって」
  * adhigata = 「得られた、達した(adhigacchati の過去分詞)」
  * appicchatā = 「少欲性、欲の少なさ」

→「すでに得ている少欲性のためである。」

6. Evaṃ kirassa ahosi – ‘‘nāhaṃ raññā diṭṭhapubbo, kathaṃ nu kho pesesī’’ti.

* evaṃ kira assa ahosi = 「彼にはこのような(思いが)あったと伝えられる」
  * assa = 「彼に(与格)」
* na ahaṃ = 「私は〜ない」
* raññā = 「王によって」
* diṭṭha-pubbo = 「以前に見られたことがある」
  * diṭṭha = 「見られた(passati の過去分詞)」
  * pubba = 「以前に」
* kathaṃ nu kho = 「いったいどうして」
* pesesi = 「送ったのか」
* iti = 「と」

→「彼にはこのような思いがあったと伝えられる。『私は王に会ったことがないのに、いったいどうして送ったのだろうか』と。」

7. Tato cintesi – ‘‘satthā bārāṇasiṃ gato, addhā so rañño vassāvāsaṃ yāciyamāno mayhaṃ paṭiññātabhāvaṃ ārocetvā mama guṇakathaṃ kathesi,

* tato = 「それから」
* cintesi = 「考えた」
* satthā = 「師は」
* bārāṇasiṃ gato = 「バーラーナシーに行かれた」
* addhā = 「きっと、確かに」
* so = 「その方(師)は」
* rañño = 「王によって(具格相当の属格)」
* vassāvāsaṃ yāciyamāno = 「雨安居の滞在を請われて」
  * vassa-āvāsa = 「雨安居の滞在」
  * yāciyamāna = 「請われている(yācati の受動現在分詞)」
* mayhaṃ paṭiññāta-bhāvaṃ = 「私に(すでに)約束済みであること」
  * paṭiññāta = 「承諾された、約束された(paṭijānāti の過去分詞)」
  * bhāva = 「〜であること」
* ārocetvā = 「告げて」
* mama guṇa-kathaṃ = 「私の徳についての話を」
* kathesi = 「語られた」

→「それから考えた。『師はバーラーナシーに行かれた。きっと師は王から雨安居の滞在を請われたとき、私にすでに約束していることを告げて、私の徳について語られたのだろう。」

8. guṇakathāya laddhalābho pana naṭena naccitvā laddhaṃ viya gāyakena gāyitvā laddhaṃ viya ca hoti.

* guṇa-kathāya = 「徳についての話によって」
* laddha-lābho = 「得られた利得」
  * laddha = 「得られた(labhati の過去分詞)」
  * lābha = 「利得」
* pana = 「しかし」
* naṭena naccitvā laddhaṃ viya = 「役者が踊って得たもののように」
  * naṭa = 「役者、踊り手」
  * naccitvā = 「踊って(連続体)」
* gāyakena gāyitvā laddhaṃ viya ca = 「また歌い手が歌って得たもののように」
  * gāyaka = 「歌い手」
  * gāyitvā = 「歌って(連続体)」
* hoti = 「である」

→「しかし、徳についての話によって得られた利得は、役者が踊って得たもの、また歌い手が歌って得たもののようなものである。」

9. Kiṃ mayhaṃ iminā, kammaṃ katvā uppannena mātāpitūnampi sammāsambuddhassapi upaṭṭhānaṃ sakkā kātu’’nti.

* kiṃ mayhaṃ iminā = 「これが私に何になろうか(私にはこれは不要だ)」
* kammaṃ katvā = 「仕事をして」
* uppannena = 「生じたもの(収入)によって」
  * uppanna = 「生じた(uppajjati の過去分詞)」
* mātā-pitūnam pi = 「父母にも」
* sammāsambuddhassa pi = 「正自覚者にも」
* upaṭṭhānaṃ = 「給仕、奉仕」
* sakkā kātuṃ = 「することができる」
  * sakkā = 「可能である」
  * kātuṃ = 「すること(不定体)」
* iti = 「と」

→「これが私に何になろうか。仕事をして生じたものによって、父母にも正自覚者にも給仕することができる』と。」

10. Sesaṃ sabbattha uttānamevāti.

* sesaṃ = 「残りは」
* sabbattha = 「すべての箇所で」
* uttānaṃ eva = 「明白そのものである」
  * uttāna = 「明白な、明らかな」
* iti = 「と(以上)」

→「残りはすべての箇所で明白そのものである。」

11. Papañcasūdaniyā majjhimanikāyaṭṭhakathāya

* papañcasūdaniyā = 「パパンチャスーダニーの(属格)」
* majjhima-nikāya-aṭṭhakathāya = 「マッジマニカーヤの註釈の(属格)」

→「パパンチャスーダニーというマッジマニカーヤ註釈における」

12. Ghaṭikārasuttavaṇṇanā niṭṭhitā.

* ghaṭikāra-sutta-vaṇṇanā = 「ガティカーラ経の解説は」
  * vaṇṇanā = 「解説、註解」
* niṭṭhitā = 「終わった」

→「ガティカーラ経の解説は終わった。」
