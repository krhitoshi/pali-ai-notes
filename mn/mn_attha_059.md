# 9. Bahuvedanīyasuttavaṇṇanā

## 88

88. Evaṃme sutanti bahuvedanīyasuttaṃ. Tattha pañcakaṅgo thapatīti pañcakaṅgoti tassa nāmaṃ. Vāsipharasunikhādanadaṇḍamuggarakāḷasuttanāḷisaṅkhātehi vā aṅgehi samannāgatattā so pañcaṅgoti paññāto. Thapatīti vaḍḍhakījeṭṭhako. Udāyīti paṇḍitaudāyitthero.

### 対訳

1. 9. Bahuvedanīyasuttavaṇṇanā

* bahuvedanīya-sutta-vaṇṇanā = 「バフヴェーダニーヤ経の解説」
  * bahu = 「多くの」
  * vedanīya = 「感受されるもの、感受に関するもの」
  * sutta = 「経」
  * vaṇṇanā = 「解説、語句の説明」

→「9. バフヴェーダニーヤ経(多くの感受についての経)の解説」

2. 88. Evaṃme sutanti bahuvedanīyasuttaṃ.

* evaṃ me sutaṃ = 「このように私は聞いた」
  * 経の冒頭の句を見出し語として引いたもの
* ti = 「〜と(始まるのは)」
* bahuvedanīyasuttaṃ = 「バフヴェーダニーヤ経(である)」

→「"このように私は聞いた"と始まるのが、バフヴェーダニーヤ経である。」

3. Tattha pañcakaṅgo thapatīti pañcakaṅgoti tassa nāmaṃ.

* tattha = 「そこにおいて、その(経の)中で」
* pañcakaṅgo thapati = 「大工の棟梁パンチャカンガ」
  * 経の語句を見出し語として引いたもの
* ti = 「〜とあるうち」
* pañcakaṅgo ti = 「"パンチャカンガ"というのは」
* tassa = 「彼の」
* nāmaṃ = 「名前(である)」

→「その中で、"パンチャカンガ・タパティ"とあるうち、"パンチャカンガ"というのは彼の名前である。」

4. Vāsipharasunikhādanadaṇḍamuggarakāḷasuttanāḷisaṅkhātehi vā aṅgehi samannāgatattā so pañcaṅgoti paññāto.

* vāsi-pharasu-nikhādana-daṇḍa-muggara-kāḷasutta-nāḷi-saṅkhātehi = 「手斧・斧・のみ・棒・槌・墨縄・筒と呼ばれる」
  * vāsi = 「手斧(ちょうな)」
  * pharasu = 「斧」
  * nikhādana = 「のみ」
  * daṇḍa = 「棒、物差しの棒」(要確認)
  * muggara = 「槌」
  * kāḷasutta = 「墨縄(黒い糸)」
  * nāḷi = 「筒、管」(要確認)
  * saṅkhāta = 「〜と呼ばれる、〜と数えられる」
  * 列挙された語をどう区切って五つと数えるのかは、この文だけからは確定できない(要確認)。vāsipharasu をひとまとめ、kāḷasuttanāḷi をひとまとめにして、手斧・のみ・棒・槌・墨縄の五つとする数え方が考えられる
* vā = 「あるいは」
  * 前文の「単に名前である」という説明に対する、もう一つの説明を導く
* aṅgehi = 「部分によって、道具によって」(具格・複数)
  * ここでは大工の持つ道具を aṅga(支分)と言っている
* samannāgatattā = 「備えていることから」(samannāgata + tta の奪格)
* so = 「彼は」
* pañcaṅgo ti = 「"パンチャンガ(五つの支分を持つ者)"と」
  * pañca = 「五つ」
  * aṅga = 「支分、部分」
* paññāto = 「知られた、通称された」

→「あるいは、手斧・斧・のみ・棒・槌・墨縄・筒と呼ばれる(五つの)道具を備えていることから、彼は"パンチャンガ(五つの道具を持つ者)"として知られたのである。」

5. Thapatīti vaḍḍhakījeṭṭhako.

* thapati ti = 「"タパティ"というのは」
* vaḍḍhakī-jeṭṭhako = 「大工の長、大工の棟梁」
  * vaḍḍhakī = 「大工」
  * jeṭṭhaka = 「最年長の者、長、頭」

→「"タパティ"というのは、大工の棟梁のことである。」

6. Udāyīti paṇḍitaudāyitthero.

* udāyī ti = 「"ウダーイー"というのは」
* paṇḍita-udāyi-tthero = 「賢者ウダーイ長老」
  * paṇḍita = 「賢者、賢い」
  * thera = 「長老」
  * paṇḍita を付けて、同名の他のウダーイーと区別している

→「"ウダーイー"というのは、賢者ウダーイ長老のことである。」

## 89

### 対訳

1. 89. Pariyāyanti kāraṇaṃ.

* pariyāyaṃ = 「理由、(説き方の)筋道を」(pariyāya の単数・対格)
  * 経の本文の語を見出しとして挙げている
* ti = 「〜とは」(見出し語を示す)
* kāraṇaṃ = 「理由、根拠」

→「"pariyāyaṃ" とは、理由のことである。」

2. Dvepānandāti dvepi, ānanda.

* dvepānanda = dve + pi + ānanda の連声形
* ti = 「〜とは」
* dve = 「二つ」
* pi = 「〜も」
* ānanda = 「アーナンダよ」(呼格)

→「"dvepānanda" とは、"二つも、アーナンダよ"(dve pi, ānanda)ということである。」

3. Pariyāyenāti kāraṇena.

* pariyāyena = 「理由によって、(ある)説き方によって」(単数・具格)
* ti = 「〜とは」
* kāraṇena = 「理由によって」(単数・具格)

→「"pariyāyena" とは、理由によって、ということである。」

4. Ettha ca kāyikacetasikavasena dve veditabbā.

* ettha = 「ここで、この点について」
* ca = 「そして」
* kāyika-cetasika-vasena = 「身体的なものと心的なものという区別によって」
  * kāyika = 「身体的な」
  * cetasika = 「心的な」
  * vasena = 「〜によって、〜の観点で」
* dve = 「二つ(の受)」
  * 女性名詞 vedanā(受)を補って読む
* veditabbā = 「知られるべきである」(女性・複数・主格、vedanā に一致)

→「そしてここで、身体的なものと心的なものという区別によって、二つ(の受)が知られるべきである。」

5. Sukhādivasena tisso,

* sukha-ādi-vasena = 「楽などの区別によって」
  * sukha = 「楽」
  * ādi = 「〜など」(楽・苦・不苦不楽を指す)
* tisso = 「三つ」(女性・主格、vedanā に一致)

→「楽などの区別によって三つ、」

6. indriyavasena sukhindriyādikā pañca,

* indriya-vasena = 「根の区別によって」
  * indriya = 「根」
* sukhindriya-ādikā = 「楽根などの」
  * sukhindriya = 「楽根」(sukha + indriya)
  * ādikā = 「〜をはじめとする」(女性・複数)
* pañca = 「五つ」

→「根の区別によって、楽根などの五つ、」

7. dvāravasena cakkhusamphassajādikā cha,

* dvāra-vasena = 「門の区別によって」
  * dvāra = 「門」(眼などの感覚の門)
* cakkhu-samphassa-jā-ādikā = 「眼の接触から生じた(受)などの」
  * cakkhu = 「眼」
  * samphassa = 「接触、触」
  * jā = 「〜から生じた」(女性形)
  * ādikā = 「〜をはじめとする」
* cha = 「六つ」

→「門の区別によって、眼の接触から生じた(受)などの六つ、」

8. upavicāravasena ‘‘cakkhunā rūpaṃ disvā somanassaṭṭhāniyaṃ rūpaṃ upavicaratī’’tiādikā aṭṭhārasa,

* upavicāra-vasena = 「思いめぐらすことの区別によって」
  * upavicāra = 「(対象に)近づいて思いめぐらすこと」
* cakkhunā = 「眼によって」(具格)
* rūpaṃ = 「色(見える対象)を」
* disvā = 「見て」(dassati の連続体)
* somanassa-ṭṭhāniyaṃ = 「喜のもととなる」
  * somanassa = 「喜(心の楽)」
  * ṭhāniya = 「〜のもととなる、〜の場となる」
* rūpaṃ = 「色を」
* upavicarati = 「思いめぐらす」(三人称・単数・現在)
* ti ādikā = 「〜という言葉をはじめとする」
* aṭṭhārasa = 「十八」
  * 六つの門それぞれに喜・憂・捨の三つがあるので十八という数え方と読める(要確認)

→「思いめぐらすことの区別によって、"眼によって色を見て、喜のもととなる色を思いめぐらす" などの十八、」

9. cha gehassitāni somanassāni, cha nekkhammasitāni somanassāni, cha gehassitāni domanassāni, cha nekkhammasitāni domanassāni, cha gehassitā upekkhā, cha nekkhammasitāti evaṃ chattiṃsa,

* cha = 「六つ」
* geha-ssitāni = 「家に依った」(中性・複数)
  * geha = 「家、在家の生活」
  * sita = 「依った」
* somanassāni = 「喜」(中性・複数)
* nekkhamma-sitāni = 「出離に依った」
  * nekkhamma = 「出離」
* domanassāni = 「憂」(中性・複数)
* gehassitā upekkhā = 「家に依った捨」(女性・複数)
  * upekkhā = 「捨」
* cha nekkhammasitā = 「六つの出離に依った(捨)」
  * upekkhā が省かれているので補って読む
* ti evaṃ = 「〜と、このようにして」
* chattiṃsa = 「三十六」

→「家に依った六つの喜、出離に依った六つの喜、家に依った六つの憂、出離に依った六つの憂、家に依った六つの捨、出離に依った六つ(の捨)と、このようにして三十六、」

10. tā atīte chattiṃsa, anāgate chattiṃsa, paccuppanne chattiṃsāti evaṃ aṭṭhavedanāsataṃ veditabbaṃ.

* tā = 「それらは」(女性・複数・主格、上の三十六の受を指す)
* atīte = 「過去において」(処格)
* chattiṃsa = 「三十六」
* anāgate = 「未来において」
* paccuppanne = 「現在において」
* ti evaṃ = 「〜と、このようにして」
* aṭṭha-vedanā-sataṃ = 「百八の受」
  * aṭṭha = 「八」
  * vedanā = 「受」
  * sata = 「百」
  * 三十六 × 三(過去・未来・現在)= 百八
* veditabbaṃ = 「知られるべきである」(中性・単数、sataṃ に一致)

→「それらが過去に三十六、未来に三十六、現在に三十六と、このようにして百八の受が知られるべきである。」

## 90

90. Pañca kho ime, ānanda, kāmaguṇāti ayaṃ pāṭiekko anusandhi. Na kevalampi dve ādiṃ katvā vedanā bhagavatā paññattā, pariyāyena ekāpi vedanā kathitā. Taṃ dassento pañcakaṅgassa thapatino vādaṃ upatthambhetuṃ imaṃ desanaṃ ārabhi.

Abhikkantataranti sundarataraṃ. Paṇītataranti atappakataraṃ. Ettha ca catutthajjhānato paṭṭhāya adukkhamasukhā vedanā, sāpi santaṭṭhena paṇītaṭṭhena ca sukhanti vuttā. Cha gehassitāni sukhanti vuttāni. Nirodho avedayitasukhavasena sukhaṃ nāma jāto. Pañcakāmaguṇavasena hi aṭṭhasamāpattivasena ca uppannaṃ vedayitasukhaṃ nāma. Nirodho avedayitasukhaṃ nāma. Iti vedayitasukhaṃ vā hotu avedayitasukhaṃ vā, taṃ niddukkhabhāvasaṅkhātena sukhaṭṭhena ekantasukhameva jātaṃ.

### 対訳

1. 90. Pañca kho ime, ānanda, kāmaguṇāti ayaṃ pāṭiekko anusandhi.

* pañca kho ime, ānanda, kāmaguṇā = 「アーナンダよ、これら五つの欲の対象がある」(経の本文の引用)
  * pañca = 「五つの」
  * kho = 強調の不変化詞
  * ime = 「これらの」
  * ānanda = 「アーナンダよ」(呼格)
  * kāmaguṇā = 「欲の対象、欲の構成要素」(kāma-guṇa、複数主格)
* ti = 引用の標識、「〜というのは」
* ayaṃ = 「これは」
* pāṭiekko = 「別個の、独立した」
* anusandhi = 「(説法の)つながり、連結」

→「"アーナンダよ、これら五つの欲の対象がある" というのは、これは別個の(独立した)つながりである。」

2. Na kevalampi dve ādiṃ katvā vedanā bhagavatā paññattā, pariyāyena ekāpi vedanā kathitā.

* na kevalam pi = 「〜だけではない」
* dve ādiṃ katvā = 「二つを初めとして」
  * §89 で数えられた二・三・五・六・十八・三十六・百八の受を指す
* vedanā = 「受」(複数主格)
* bhagavatā = 「世尊によって」(具格)
* paññattā = 「説き定められた、告げ知らされた」(paññāpeti の過去分詞)
* pariyāyena = 「ある根拠によって、ある観点から」
  * §89 で pariyāya は kāraṇa(根拠、理由)と言い換えられている
* ekā pi vedanā = 「一つの受も」
* kathitā = 「説かれた」(katheti の過去分詞)

→「世尊は二つを初めとする受だけを説き定めたのではなく、ある根拠によっては一つの受も説いたのである。」

3. Taṃ dassento pañcakaṅgassa thapatino vādaṃ upatthambhetuṃ imaṃ desanaṃ ārabhi.

* taṃ = 「それを」(一つの受も説かれたということ)
* dassento = 「示しながら」(dasseti の現在分詞、男性単数主格。主語は世尊)
* pañcakaṅgassa thapatino = 「棟梁パンチャカンガの」(属格)
  * thapati = 「棟梁、大工の頭」(§88 で vaḍḍhakījeṭṭhako と説明されている)
* vādaṃ = 「説、主張を」
* upatthambhetuṃ = 「支えるために、支持するために」(不定詞)
* imaṃ desanaṃ = 「この説法を」
* ārabhi = 「始めた」(ārabhati のアオリスト)

→「それを示しながら、棟梁パンチャカンガの説を支持するために、(世尊は)この説法を始めた。」

4. Abhikkantataranti sundarataraṃ.

* abhikkantataraṃ = 「よりすばらしい」(abhikkanta の比較級)
* ti = 引用の標識
* sundarataraṃ = 「より良い、より美しい」(sundara の比較級)

→「"abhikkantataraṃ(よりすばらしい)" とは、より良いということである。」

5. Paṇītataranti atappakataraṃ.

* paṇītataraṃ = 「よりすぐれた」(paṇīta の比較級)
* ti = 引用の標識
* atappakataraṃ = 「より飽きることのない」(atappaka の比較級)
  * atappaka = 「飽き足りさせない、いくら味わっても飽きない」(a + tappaka。tappati「満ち足りる」から)

→「"paṇītataraṃ(よりすぐれた)" とは、より飽きることのないということである。」

6. Ettha ca catutthajjhānato paṭṭhāya adukkhamasukhā vedanā, sāpi santaṭṭhena paṇītaṭṭhena ca sukhanti vuttā.

* ettha ca = 「そしてここで」
* catutthajjhānato paṭṭhāya = 「第四禅から以降は」
  * catuttha-jjhāna = 「第四禅」
  * paṭṭhāya = 「〜から始めて、〜以降」(奪格とともに)
* adukkhamasukhā vedanā = 「不苦不楽の受」
* sā pi = 「それもまた」
* santaṭṭhena = 「寂静であるという意味で」(santa-aṭṭha、具格)
* paṇītaṭṭhena ca = 「またすぐれているという意味で」(paṇīta-aṭṭha、具格)
* sukhan ti = 「"楽" と」
* vuttā = 「言われた」(vuccati / vadati の過去分詞、女性単数主格)

→「そしてここで、第四禅から以降は不苦不楽の受であるが、それもまた寂静であるという意味とすぐれているという意味で "楽" と言われた。」

7. Cha gehassitāni sukhanti vuttāni.

* cha = 「六つの」
* gehassitāni = 「家(在家の生活)に依るもの」(geha-sita、中性複数主格)
  * §89 の "cha gehassitāni somanassāni" を受けて、somanassāni(喜)が省かれていると見られる(要確認)
* sukhan ti = 「"楽" と」
* vuttāni = 「言われた」(中性複数主格)

→「六つの家に依る(喜)は "楽" と言われた。」

8. Nirodho avedayitasukhavasena sukhaṃ nāma jāto.

* nirodho = 「滅」
  * 経の文脈から想受滅を指す。§91 では nirodhasamāpatti(滅尽定)と言われている
* avedayitasukhavasena = 「感受されない楽という点で」
  * avedayita = 「感受されない」(a + vedayita。vedayita は vedeti の過去分詞)
  * sukha = 「楽」
  * vasena = 「〜によって、〜という点で」
* sukhaṃ nāma = 「"楽" という名のもの」
* jāto = 「〜となった」(jāyati の過去分詞、男性単数主格)

→「滅は、感受されない楽という点で "楽" と呼ばれるものとなった。」

9. Pañcakāmaguṇavasena hi aṭṭhasamāpattivasena ca uppannaṃ vedayitasukhaṃ nāma.

* pañcakāmaguṇavasena = 「五つの欲の対象によって」
* hi = 「というのは、実に」
* aṭṭhasamāpattivasena ca = 「また八つの等至によって」
  * aṭṭha-samāpatti = 「八つの等至」(四つの色界禅と四つの無色界定)
* uppannaṃ = 「生じた(もの)」(uppajjati の過去分詞)
* vedayitasukhaṃ nāma = 「"感受される楽" という名のもの」
  * vedayita = 「感受された、感受される」

→「というのは、五つの欲の対象によって、また八つの等至によって生じたものは "感受される楽" という。」

10. Nirodho avedayitasukhaṃ nāma.

* nirodho = 「滅」
* avedayitasukhaṃ nāma = 「"感受されない楽" という名のもの」

→「滅は "感受されない楽" という。」

11. Iti vedayitasukhaṃ vā hotu avedayitasukhaṃ vā, taṃ niddukkhabhāvasaṅkhātena sukhaṭṭhena ekantasukhameva jātaṃ.

* iti = 「このように」
* vedayitasukhaṃ vā hotu avedayitasukhaṃ vā = 「感受される楽であれ、感受されない楽であれ」
  * hotu = 「〜であれ」(hoti の命令法三人称単数)
  * vā ... vā = 「〜であれ〜であれ」
* taṃ = 「それは」
* niddukkhabhāvasaṅkhātena = 「苦がないことと呼ばれる」(具格、sukhaṭṭhena にかかる)
  * niddukkha = 「苦のない」(nis + dukkha)
  * bhāva = 「状態、〜であること」
  * saṅkhāta = 「〜と呼ばれる、〜と数えられる」
* sukhaṭṭhena = 「楽という意味で」(sukha-aṭṭha、具格)
* ekantasukham eva = 「まったくの楽にほかならないもの」
  * ekanta = 「ひたすらの、まったくの」
* jātaṃ = 「〜となった」(中性単数主格)

→「このように、感受される楽であれ、感受されない楽であれ、それは苦がないことと呼ばれる楽の意味によって、まったくの楽となったのである。」

### 対訳

1. 91. Yatthayatthāti yasmiṃ yasmiṃ ṭhāne.

* yattha yattha = 「どこであれ、どこにおいてであれ」(経の語句の引用)
* ti = 「〜とは」(引用の標識)
* yasmiṃ yasmiṃ ṭhāne = 「どの場合においてであれ」
  * yasmiṃ = 「〜であるところの(それ)において」(関係代名詞 ya の処格。繰り返して「どの〜でも」の意)
  * ṭhāne = 「場所において、場合において」(ṭhāna の処格)

→「"yattha yattha"(どこであれ)とは、どの場合においてであれ、ということである。」

2. Sukhaṃ upalabbhatīti vedayitasukhaṃ vā avedayitasukhaṃ vā upalabbhati.

* sukhaṃ = 「楽が」
* upalabbhati = 「得られる、見いだされる」(upa + labh の受動)
* ti = 「〜とは」
* vedayitasukhaṃ = 「感受される楽」(vedayita-sukha)
  * vedayita = 「感受された(もの)」
  * §90 では、五つの欲の対象と八つの等至によって生じる楽がこれにあたると説明されている
* avedayitasukhaṃ = 「感受されない楽」(a-vedayita-sukha)
  * §90 では、滅(nirodha)がこれにあたると説明されている
* vā ... vā = 「〜であれ、〜であれ」

→「"楽が見いだされる" とは、感受される楽であれ、感受されない楽であれ、それが見いだされる、ということである。」

3. Taṃ taṃ tathāgato sukhasmiṃ paññapetīti taṃ sabbaṃ tathāgato niddukkhabhāvaṃ sukhasmiṃyeva paññapetīti.

* taṃ taṃ = 「それぞれを」
* tathāgato = 「如来は」
* sukhasmiṃ = 「楽の中に、楽として」(sukha の処格)
* paññapeti = 「設定する、位置づける、説き示す」
* ti = 「〜とは」
* taṃ sabbaṃ = 「そのすべてを」
* niddukkhabhāvaṃ = 「苦のない状態を」(nis + dukkha + bhāva)
  * §90 の "niddukkhabhāvasaṅkhātena sukhaṭṭhena"(苦のない状態という楽の意味で)を受けた言い方
* sukhasmiṃyeva = 「楽の中にこそ」(sukhasmiṃ + eva)
* 末尾の ti = 語句の説明の結び

→「"如来はそれぞれを楽の中に位置づける" とは、そのすべての、苦のない状態を、如来は楽の中にこそ位置づける、ということである。」

4. Idha bhagavā nirodhasamāpattiṃ sīsaṃ katvā neyyapuggalavasena arahattanikūṭeneva desanaṃ niṭṭhāpesīti.

* idha = 「ここで(この経において)」
* bhagavā = 「世尊は」
* nirodhasamāpattiṃ = 「滅の等至(滅尽定)を」(nirodha-samāpatti)
* sīsaṃ katvā = 「頭にして、すなわち主として最上位に置いて」
  * sīsa = 「頭、頂」
  * katvā = 「して」(karoti の連続体)
* neyyapuggalavasena = 「導かれるべき人に応じて」(neyya-puggala-vasena)
  * neyya = 「導かれるべき」
  * puggala = 「人」
  * vasena = 「〜によって、〜に応じて」
* arahattanikūṭeneva = 「阿羅漢の位を頂点としてこそ」(arahatta-nikūṭena + eva)
  * arahatta = 「阿羅漢であること、阿羅漢の位」
  * nikūṭa = 「頂、頂点」
* desanaṃ = 「説法を」
* niṭṭhāpesi = 「終えた、完結させた」(niṭṭhāpeti のアオリスト)
* ti = 註釈本文の結び

→「ここで世尊は、滅の等至を頭に置き、導かれるべき人に応じて、阿羅漢の位を頂点として説法を終えたのである。」

5. Papañcasūdaniyā majjhimanikāyaṭṭhakathāya

* Papañcasūdaniyā = 「パパンチャスーダニーにおける」(Papañcasūdanī の処格または属格)
* majjhimanikāyaṭṭhakathāya = 「マッジマ・ニカーヤの註釈書における」(majjhimanikāya-aṭṭhakathā の処格または属格)

  * vaṇṇanā = 「解説、註釈」
