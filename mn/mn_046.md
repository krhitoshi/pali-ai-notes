1. 6. Mahādhammasamādānasuttaṃ

* mahā-dhamma-samādāna-suttaṃ = 「大法受持経」
  * mahā = 「大きい、大」
  * dhamma = 「法、行い方」
  * samādāna = 「受持、受け取って実行すること」（saṃ + ā + dā）
  * sutta = 「経」

→「大法受持経」

2. 473. Evaṃ me sutaṃ –

* evaṃ = 「このように」
* me = 「私によって」
* sutaṃ = 「聞かれた」（suṇāti の過去分詞）

→「このように私は聞いた。」

3. ekaṃ samayaṃ bhagavā sāvatthiyaṃ viharati jetavane anāthapiṇḍikassa ārāme.

* ekaṃ samayaṃ = 「あるとき」
* bhagavā = 「世尊は」
* sāvatthiyaṃ = 「サーヴァッティーに」（処格）
* viharati = 「住んでいる」
* jetavane = 「ジェータ林の」（処格）
* anāthapiṇḍikassa ārāme = 「アナータピンディカの園に」

→「あるとき世尊はサーヴァッティーのジェータ林、アナータピンディカの園に住んでいた。」

4. Tatra kho bhagavā bhikkhū āmantesi – ‘‘bhikkhavo’’ti.

* tatra kho = 「そこで」
* bhikkhū = 「比丘たちに」（対格複数）
* āmantesi = 「呼びかけた」（āmanteti のアオリスト）
* bhikkhavo ti = 「『比丘たちよ』と」

→「そこで世尊は比丘たちに『比丘たちよ』と呼びかけた。」

5. ‘‘Bhadante’’ti te bhikkhū bhagavato paccassosuṃ.

* bhadante ti = 「『尊師よ』と」
* te bhikkhū = 「それらの比丘たちは」
* bhagavato = 「世尊に」（与格）
* paccassosuṃ = 「応答した」（paṭissuṇāti のアオリスト複数）

→「それらの比丘たちは『尊師よ』と世尊に応答した。」

6. Bhagavā etadavoca –

* etad avoca = 「このことを言った」（etaṃ + avoca、vadati のアオリスト）

→「世尊はこう言った。」

7. ‘‘yebhuyyena, bhikkhave, sattā evaṃkāmā evaṃchandā evaṃadhippāyā –

* yebhuyyena = 「たいてい、大部分は」
* sattā = 「衆生たちは、生きものたちは」
* evaṃ-kāmā = 「このような欲求をもつ」
  * kāma = 「欲求、望み」
* evaṃ-chandā = 「このような意欲をもつ」
  * chanda = 「意欲、願い」
* evaṃ-adhippāyā = 「このような意向をもつ」
  * adhippāya = 「意向、意図」

→「比丘たちよ、たいていの衆生はこのような欲求、このような意欲、このような意向をもっている。」

8. ‘aho vata aniṭṭhā akantā amanāpā dhammā parihāyeyyuṃ, iṭṭhā kantā manāpā dhammā abhivaḍḍheyyu’nti.

* aho vata = 「ああ、どうか（願望の間投詞）」
* aniṭṭhā = 「望ましくない」（a + iṭṭha）
* akantā = 「好ましくない」（a + kanta）
* amanāpā = 「意に適わない」（a + manāpa）
* dhammā = 「法が、事柄が」
* parihāyeyyuṃ = 「減ってほしい、衰えてほしい」（parihāyati の願望法複数）
* iṭṭhā kantā manāpā dhammā = 「望ましく、好ましく、意に適う法が」
* abhivaḍḍheyyuṃ = 「増えてほしい、増大してほしい」（abhivaḍḍhati の願望法複数）

→「『ああ、望ましくない、好ましくない、意に適わない法は減り、望ましく、好ましく、意に適う法は増えてほしい』と。」

9. Tesaṃ, bhikkhave, sattānaṃ evaṃkāmānaṃ evaṃchandānaṃ evaṃadhippāyānaṃ aniṭṭhā akantā amanāpā dhammā abhivaḍḍhanti, iṭṭhā kantā manāpā dhammā parihāyanti.

* tesaṃ sattānaṃ = 「それらの衆生にとって」（属格複数）
* evaṃkāmānaṃ evaṃchandānaṃ evaṃadhippāyānaṃ = 「このような欲求、意欲、意向をもつ（者たちにとって）」
* abhivaḍḍhanti = 「増える」（現在複数）
* parihāyanti = 「減る」（現在複数）

→「比丘たちよ、このような欲求、このような意欲、このような意向をもつそれらの衆生にとって、望ましくない、好ましくない、意に適わない法は増え、望ましく、好ましく、意に適う法は減る。」

10. Tatra tumhe, bhikkhave, kaṃ hetuṃ paccethā’’ti?

* tatra = 「そこに、その点について」
* tumhe = 「あなたたちは」
* kaṃ hetuṃ = 「どんな原因を」
* paccetha = 「考えるか、認めるか」（pacceti の現在二人称複数）

→「比丘たちよ、あなたたちはその点についてどんな原因があると考えるか。」

11. ‘‘Bhagavaṃmūlakā no, bhante, dhammā, bhagavaṃnettikā, bhagavaṃpaṭisaraṇā.

* bhagavaṃ-mūlakā = 「世尊を根本とする」
  * mūlaka = 「根本とする」
* no = 「私たちの」（属格複数）
* dhammā = 「法は」
* bhagavaṃ-nettikā = 「世尊を導き手とする」
  * nettika = 「導く者、案内者」
* bhagavaṃ-paṭisaraṇā = 「世尊を依りどころとする」
  * paṭisaraṇa = 「依りどころ、帰依処」

→「尊師よ、私たちの法は世尊を根本とし、世尊を導き手とし、世尊を依りどころとしています。」

12. Sādhu vata, bhante, bhagavantaññeva paṭibhātu etassa bhāsitassa attho;

* sādhu vata = 「どうか、願わくは」
* bhagavantaṃ eva = 「まさに世尊に」（対格）
* paṭibhātu = 「明らかになりますように、思い浮かびますように」（paṭibhāti の命令法三人称単数）
* etassa bhāsitassa attho = 「この説かれたことの意味が」

→「尊師よ、どうかこの説かれたことの意味を世尊ご自身が明らかにしてください。」

13. bhagavato sutvā bhikkhū dhāressantī’’ti.

* bhagavato sutvā = 「世尊から聞いて」（sutvā は絶対分詞）
* dhāressanti = 「保持するでしょう、憶えるでしょう」（dhāreti の未来複数）

→「比丘たちは世尊から聞いて憶え保つでしょう。」

14. ‘‘Tena hi, bhikkhave, suṇātha, sādhukaṃ manasi karotha, bhāsissāmī’’ti.

* tena hi = 「それでは」
* suṇātha = 「聞きなさい」（命令法複数）
* sādhukaṃ manasi karotha = 「よく注意しなさい、よく心に留めなさい」
* bhāsissāmi = 「私は説くだろう」（未来一人称単数）

→「それでは、比丘たちよ、聞いて、よく心に留めなさい。私は説こう。」

15. ‘‘Evaṃ, bhante’’ti kho te bhikkhū bhagavato paccassosuṃ.

* evaṃ bhante ti = 「『はい、尊師よ』と」

→「『はい、尊師よ』とそれらの比丘たちは世尊に応答した。」

16. Bhagavā etadavoca –

→「世尊はこう言った。」

  * pacchime māse = 「最後の月に（処格）」
* saradasamaye = 「秋の時季に」
  * sarada = 「秋」
  * samaya = 「時、時季」
* viddhe vigatavalāhake deve = 「空が晴れわたり、雲が去ったときに（絶対処格）」
  * viddha = 「晴れわたった、澄んだ」
  * vigata-valāhaka = 「雲が去った」
  * deva = 「空、天」
* ādicco = 「太陽が」
* nabhaṃ abbhussakkamāno = 「空に昇りながら」
  * nabha = 「空」
  * abbhussakkamāna = 「昇っていく（abhi + ud + sakk の現在分詞）」
* sabbaṃ ākāsagataṃ tamagataṃ = 「虚空にあるすべての闇を」
  * ākāsa-gata = 「虚空にある」
  * tama-gata = 「闇、暗黒」
* abhivihacca = 「打ち払って（abhi + vi + han の連続体）」
* bhāsate ca tapate ca virocate ca = 「輝き、照らし、光り輝く」
  * bhāsati = 「輝く」
  * tapati = 「照らす、熱する」
  * virocati = 「光り輝く」

→「比丘たちよ、たとえば雨期の最後の月、秋の時季に、空が晴れわたり雲が去ったとき、太陽が空に昇りながら、虚空にあるすべての闇を打ち払って輝き、照らし、光り輝くように、」

2. evameva kho, bhikkhave, yamidaṃ dhammasamādānaṃ paccuppannasukhañceva āyatiñca sukhavipākaṃ tadaññe puthusamaṇabrāhmaṇaparappavāde abhivihacca bhāsate ca tapate ca virocate cā’’ti.

* evameva kho = 「まさにそのように」
* bhikkhave = 「比丘たちよ」
* yamidaṃ dhammasamādānaṃ = 「この法の受持は（yaṃ idaṃ）」
  * dhamma-samādāna = 「法の受持、法の実行」
* paccuppannasukhañceva = 「現在において楽であり（paccuppanna-sukhaṃ ca eva）」
* āyatiñca sukhavipākaṃ = 「未来において楽の果報をもたらす」
  * āyatiṃ = 「未来に」
  * sukha-vipāka = 「楽の果報をもつ」
* tadaññe = 「それは他の（taṃ aññe）」
* puthusamaṇabrāhmaṇaparappavāde = 「多くの沙門・婆羅門の他の教説を」
  * puthu = 「多くの、種々の」
  * samaṇa-brāhmaṇa = 「沙門・婆羅門」
  * para-ppavāda = 「他の教説、他派の論」
* abhivihacca = 「打ち払って」
* bhāsate ca tapate ca virocate ca = 「輝き、照らし、光り輝く」
* ti = 「と（引用の終わり）」

→「比丘たちよ、まさにそのように、現在において楽であり未来において楽の果報をもたらすこの法の受持は、他の多くの沙門・婆羅門の教説を打ち払って輝き、照らし、光り輝く。」

3. Idamavoca bhagavā.

* idaṃ avoca = 「このことを説いた」
  * avoca = 「説いた（vac のアオリスト）」
* bhagavā = 「世尊は」

→「世尊はこのことを説いた。」

4. Attamanā te bhikkhū bhagavato bhāsitaṃ abhinandunti.

* attamanā = 「心が満たされた、喜んだ」
* te bhikkhū = 「それらの比丘たちは」
* bhagavato bhāsitaṃ = 「世尊の説いたことを」
* abhinandunti = 「歓喜した、と（abhinanduṃ + iti）」
  * abhinanduṃ = 「歓喜した（abhi + nand のアオリスト三人称複数）」

→「それらの比丘たちは心が満たされ、世尊の説いたことを歓喜した。」

5. Mahādhammasamādānasuttaṃ niṭṭhitaṃ chaṭṭhaṃ.

* mahā-dhamma-samādāna-suttaṃ = 「大法受持経は」
* niṭṭhitaṃ = 「終わった」
* chaṭṭhaṃ = 「第六の」

→「第六、大法受持経、終わり。」
