# 10. Vekhanasasuttaṃ

## 278 (1)

278. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā sāvatthiyaṃ viharati jetavane anāthapiṇḍikassa ārāme. Atha kho vekhanaso [vekhanasso (sī. pī.)] paribbājako yena bhagavā tenupasaṅkami; upasaṅkamitvā bhagavatā saddhiṃ sammodi. Sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā ekamantaṃ aṭṭhāsi. Ekamantaṃ ṭhito kho vekhanaso paribbājako bhagavato santike udānaṃ udānesi – ‘‘ayaṃ paramo vaṇṇo, ayaṃ paramo vaṇṇo’’ti.

‘‘Kiṃ pana tvaṃ, kaccāna, evaṃ vadesi – ‘ayaṃ paramo vaṇṇo, ayaṃ paramo vaṇṇo’ti? Katamo, kaccāna, so paramo vaṇṇo’’ti?

‘‘Yasmā, bho gotama, vaṇṇā añño vaṇṇo uttaritaro vā paṇītataro vā natthi so paramo vaṇṇo’’ti.

‘‘Katamo pana so, kaccāna, vaṇṇo yasmā vaṇṇā añño vaṇṇo uttaritaro vā paṇītataro vā natthī’’ti?

‘‘Yasmā, bho gotama, vaṇṇā añño vaṇṇo uttaritaro vā paṇītataro vā natthi so paramo vaṇṇo’’ti.

### 対訳

1. 10. Vekhanasasuttaṃ

* Vekhanasa-suttaṃ = 「ヴェーカナサ経」
  * Vekhanasa = 「ヴェーカナサ（遍歴行者の名。異読 Vekhanassa）」
  * suttaṃ = 「経」

→「ヴェーカナサ経」

2. 278. Evaṃ me sutaṃ –

* evaṃ = 「このように」
* me = 「私によって（aham の具格・属格）」
* sutaṃ = 「聞かれた（suṇāti の過去分詞）」

→「このように私は聞いた。」

3. ekaṃ samayaṃ bhagavā sāvatthiyaṃ viharati jetavane anāthapiṇḍikassa ārāme.

* ekaṃ samayaṃ = 「ある時（対格で時を示す）」
* bhagavā = 「世尊は」
* sāvatthiyaṃ = 「サーヴァッティにおいて（処格）」
* viharati = 「住んでいる」
* jetavane = 「ジェータ林において（処格）」
* anāthapiṇḍikassa ārāme = 「アナータピンディカの園において」
  * anāthapiṇḍika = 「アナータピンディカ（給孤独長者）」
  * ārāma = 「園、僧園」

→「ある時、世尊はサーヴァッティのジェータ林、アナータピンディカの園に住んでいた。」

4. Atha kho vekhanaso [vekhanasso (sī. pī.)] paribbājako yena bhagavā tenupasaṅkami;

* vekhanaso paribbājako = 「遍歴行者ヴェーカナサは」
  * paribbājaka = 「遍歴行者、出家遊行者」
* yena bhagavā tena upasaṅkami = 「世尊のいる所へ近づいた」
  * yena ... tena = 「～のいる所へ（慣用表現）」
  * upasaṅkami = 「近づいた（upasaṅkamati のアオリスト）」

→「さて、遍歴行者ヴェーカナサは世尊のいる所へ近づいた。」

5. upasaṅkamitvā bhagavatā saddhiṃ sammodi.

* upasaṅkamitvā = 「近づいて（連続体）」
* bhagavatā saddhiṃ = 「世尊と共に（具格 + saddhiṃ）」
* sammodi = 「挨拶を交わした、喜び合った（sammodati のアオリスト）」

→「近づいて、世尊と挨拶を交わした。」

6. Sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā ekamantaṃ aṭṭhāsi.

* sammodanīyaṃ kathaṃ = 「喜ばしい話を」
  * sammodanīya = 「喜ばしい、友好的な」
* sāraṇīyaṃ = 「思い出すに値する、記憶に残る」
* vītisāretvā = 「交わし終えて（vītisāreti の連続体）」
* ekamantaṃ = 「一方に、かたわらに」
* aṭṭhāsi = 「立った（tiṭṭhati のアオリスト）」
  * 通常の定型句 nisīdi（坐った）ではなく立ったままである点が注意される

→「喜ばしく記憶に残る話を交わし終えて、一方に立った。」

7. Ekamantaṃ ṭhito kho vekhanaso paribbājako bhagavato santike udānaṃ udānesi – ‘‘ayaṃ paramo vaṇṇo, ayaṃ paramo vaṇṇo’’ti.

* ekamantaṃ ṭhito = 「一方に立った（ṭhita = tiṭṭhati の過去分詞）」
* kho = 「実に（強調の小辞）」
* bhagavato santike = 「世尊の面前で」
  * santike = 「近くで、面前で（処格）」
* udānaṃ udānesi = 「感興の言葉を発した」
  * udāna = 「感興語、自然に発せられる言葉」
  * udānesi = 「発した（udāneti のアオリスト）」
* ayaṃ paramo vaṇṇo = 「これが最上の色光である」
  * ayaṃ = 「これが」
  * parama = 「最上の、最高の」
  * vaṇṇa = 「色光、光輝、容色（ここでは自我・梵などの最上の光輝を指す）」
* ti = 「と（引用の終わり）」

→「一方に立った遍歴行者ヴェーカナサは、世尊の面前で感興の言葉を発した――『これが最上の色光である、これが最上の色光である』と。」

8. ‘‘Kiṃ pana tvaṃ, kaccāna, evaṃ vadesi – ‘ayaṃ paramo vaṇṇo, ayaṃ paramo vaṇṇo’ti?

* kiṃ pana = 「いったい何を（理由・根拠を問う）」
* tvaṃ = 「あなたは」
* kaccāna = 「カッチャーナよ（呼格。ヴェーカナサの姓）」
* evaṃ vadesi = 「このように言うのか」
  * vadesi = 「言う（vadati の二人称単数）」
* ayaṃ paramo vaṇṇo ... ti = 「『これが最上の色光である、これが最上の色光である』と」

→「『カッチャーナよ、あなたはいったい何を根拠に、このように言うのか――「これが最上の色光である、これが最上の色光である」と。』」

9. Katamo, kaccāna, so paramo vaṇṇo’’ti?

* katamo = 「どれが、どのような（疑問代名詞）」
* so paramo vaṇṇo = 「その最上の色光は」
* ti = 「と（世尊の言葉の終わり）」

→「『カッチャーナよ、その最上の色光とはどのようなものか。』」

10. ‘‘Yasmā, bho gotama, vaṇṇā añño vaṇṇo uttaritaro vā paṇītataro vā natthi so paramo vaṇṇo’’ti.

* yasmā vaṇṇā = 「その色光よりも（奪格。関係代名詞 ya の奪格）」
* bho gotama = 「ゴータマ殿よ（呼格）」
* añño vaṇṇo = 「他の色光が」
* uttaritaro vā paṇītataro vā = 「よりすぐれた、あるいはより精妙な」
  * uttaritara = 「よりすぐれた（uttara の比較級）」
  * paṇītatara = 「より精妙な、より優れた（paṇīta の比較級）」
* natthi = 「存在しない」
* so paramo vaṇṇo = 「それが最上の色光である」
* ti = 「と」

→「『ゴータマ殿、それよりすぐれ、あるいはそれより精妙な他の色光が存在しないところの色光、それが最上の色光です。』」

11. ‘‘Katamo pana so, kaccāna, vaṇṇo yasmā vaṇṇā añño vaṇṇo uttaritaro vā paṇītataro vā natthī’’ti?

* katamo pana so vaṇṇo = 「では、その色光とはどのようなものか」
* kaccāna = 「カッチャーナよ」
* yasmā vaṇṇā = 「その色光よりも」
* añño vaṇṇo uttaritaro vā paṇītataro vā natthi = 「よりすぐれた、あるいはより精妙な他の色光が存在しない」
* ti = 「と」

→「『では、カッチャーナよ、それよりすぐれ、あるいはそれより精妙な他の色光が存在しないところのその色光とは、どのようなものか。』」

12. ‘‘Yasmā, bho gotama, vaṇṇā añño vaṇṇo uttaritaro vā paṇītataro vā natthi so paramo vaṇṇo’’ti.

* 項目 10 と同文
* yasmā vaṇṇā = 「その色光よりも」
* añño vaṇṇo uttaritaro vā paṇītataro vā natthi = 「よりすぐれた、あるいはより精妙な他の色光が存在しない」
* so paramo vaṇṇo = 「それが最上の色光である」

→「『ゴータマ殿、それよりすぐれ、あるいはそれより精妙な他の色光が存在しないところの色光、それが最上の色光です。』」

## 278 (2)

‘‘Dīghāpi kho te esā, kaccāna, phareyya – ‘yasmā, bho gotama, vaṇṇā añño vaṇṇo uttaritaro vā paṇītataro vā natthi so paramo vaṇṇo’ti vadesi, tañca vaṇṇaṃ na paññapesi. Seyyathāpi, kaccāna, puriso evaṃ vadeyya – ‘ahaṃ yā imasmiṃ janapade janapadakalyāṇī, taṃ icchāmi taṃ kāmemī’ti. Tamenaṃ evaṃ vadeyyuṃ – ‘ambho purisa, yaṃ tvaṃ janapadakalyāṇiṃ icchasi kāmesi, jānāsi taṃ janapadakalyāṇiṃ – khattiyī vā brāhmaṇī vā vessī vā suddī vā’ti? Iti puṭṭho ‘no’ti vadeyya. Tamenaṃ evaṃ vadeyyuṃ – ‘ambho purisa, yaṃ tvaṃ janapadakalyāṇiṃ icchasi kāmesi, jānāsi taṃ janapadakalyāṇiṃ ‘evaṃnāmā evaṃgottāti vāti…pe… dīghā vā rassā vā majjhimā vā kāḷī vā sāmā vā maṅguracchavī vāti… amukasmiṃ gāme vā nigame vā nagare vā’ti? Iti puṭṭho ‘no’ti vadeyya. Tamenaṃ evaṃ vadeyyuṃ – ‘ambho purisa, yaṃ tvaṃ na jānāsi na passasi, taṃ tvaṃ icchasi kāmesī’’’ti? Iti puṭṭho ‘āmā’ti vadeyya.

‘‘Taṃ kiṃ maññasi, kaccāna, nanu evaṃ sante tassa purisassa appāṭihīrakataṃ bhāsitaṃ sampajjatī’’ti? ‘‘Addhā kho, bho gotama, evaṃ sante tassa purisassa appāṭihīrakataṃ bhāsitaṃ sampajjatī’’ti. ‘‘Evameva kho tvaṃ, kaccāna, ‘yasmā, bho gotama, vaṇṇā añño vaṇṇo uttaritaro vā paṇītataro vā natthi so paramo vaṇṇo’ti vadesi; tañca vaṇṇaṃ na paññapesī’’ti. ‘‘Seyyathāpi, bho gotama, maṇi veḷuriyo subho jātimā aṭṭhaṃso suparikammakato paṇḍukambale nikkhitto bhāsate ca tapate ca virocati ca, evaṃ vaṇṇo attā hoti arogo paraṃ maraṇā’’ti.

### 対訳

1. ‘‘Dīghāpi kho te esā, kaccāna, phareyya –

* dīghā pi kho = 「長くも、まことに」
  * dīghā = 「長い」(esā を修飾)
  * pi = 「〜さえも、〜もまた」
  * kho = 「まことに」(強調の小辞)
* te = 「あなたの」(tvaṃ の属格)
* esā = 「この(言葉は)」(女性・単数・主格。次の引用文を指す)
* kaccāna = 「カッチャーナよ」(呼格。遍歴行者ヴェーカナッサの姓)
* phareyya = 「広がるだろう、及ぶだろう」(pharati の願望法。「その言葉は長く引き延ばされることになる」の意。要確認)

→「カッチャーナよ、あなたのこの(言葉)は長々と及ぶことになるだろう。すなわち――」

2. ‘yasmā, bho gotama, vaṇṇā añño vaṇṇo uttaritaro vā paṇītataro vā natthi so paramo vaṇṇo’ti vadesi, tañca vaṇṇaṃ na paññapesi.

* yasmā vaṇṇā = 「その色(光輝)よりも」(関係代名詞 yasmā は vaṇṇā と同格の奪格)
* bho gotama = 「ゴータマ殿」(呼格)
* añño vaṇṇo = 「他の色(光輝)が」
* uttaritaro vā paṇītataro vā = 「よりすぐれたものも、よりすばらしいものも」
  * uttaritara = 「よりすぐれた」(uttara の比較級)
  * paṇītatara = 「よりすばらしい、より上等な」(paṇīta の比較級)
* natthi = 「存在しない」(na + atthi)
* so paramo vaṇṇo = 「それが最上の色(光輝)である」
* ti vadesi = 「〜と、あなたは言う」(vadati の2人称単数)
* tañ ca vaṇṇaṃ = 「そしてその色(光輝)を」
* na paññapesi = 「あなたは示さない、明らかにしない」(paññapeti の2人称単数)

→「『ゴータマ殿、その色よりもすぐれた、あるいはよりすばらしい他の色は存在しない、それが最上の色である』とあなたは言いながら、その色を示さない。」

3. Seyyathāpi, kaccāna, puriso evaṃ vadeyya –

* seyyathāpi = 「たとえば〜のように」
* kaccāna = 「カッチャーナよ」
* puriso = 「ある男が」
* evaṃ vadeyya = 「このように言うとしよう」(vadati の願望法)

→「カッチャーナよ、たとえばある男がこのように言うとしよう。」

4. ‘ahaṃ yā imasmiṃ janapade janapadakalyāṇī, taṃ icchāmi taṃ kāmemī’ti.

* ahaṃ = 「私は」
* yā imasmiṃ janapade janapadakalyāṇī = 「この地方にいる地方一の美女、その人を」
  * imasmiṃ janapade = 「この地方において」(処格)
  * janapada-kalyāṇī = 「地方一の美女、国中で最も美しい女性」
* taṃ icchāmi = 「彼女を欲する」(icchati の1人称単数)
* taṃ kāmemi = 「彼女を愛する、求める」(kāmeti の1人称単数)
* ti = 「〜と」

→「『私はこの地方の地方一の美女を欲し、彼女を求める』と。」

5. Tamenaṃ evaṃ vadeyyuṃ –

* tam enaṃ = 「その彼に」(taṃ + enaṃ、対格の重複による強調)
* evaṃ vadeyyuṃ = 「(人々は)このように言うだろう」(vadati の願望法・3人称複数)

→「その男に(人々は)このように言うだろう。」

6. ‘ambho purisa, yaṃ tvaṃ janapadakalyāṇiṃ icchasi kāmesi, jānāsi taṃ janapadakalyāṇiṃ – khattiyī vā brāhmaṇī vā vessī vā suddī vā’ti?

* ambho purisa = 「おい、男よ」(ambho は呼びかけの間投詞)
* yaṃ tvaṃ janapadakalyāṇiṃ icchasi kāmesi = 「あなたが欲し求めるその地方一の美女を」
* jānāsi = 「あなたは知っているのか」(jānāti の2人称単数)
* taṃ janapadakalyāṇiṃ = 「その地方一の美女を」
* khattiyī vā brāhmaṇī vā vessī vā suddī vā = 「刹帝利の女か、婆羅門の女か、庶民の女か、隷民の女か」
  * khattiyī = 「クシャトリヤ階級の女性」
  * brāhmaṇī = 「バラモン階級の女性」
  * vessī = 「ヴァイシャ階級の女性」
  * suddī = 「シュードラ階級の女性」
* ti = 「〜と」

→「『おい、男よ、あなたが欲し求めるその地方一の美女について、あなたはその美女が刹帝利の女か、婆羅門の女か、庶民の女か、隷民の女かを知っているのか』と。」

7. Iti puṭṭho ‘no’ti vadeyya.

* iti puṭṭho = 「このように問われて」
  * puṭṭha = 「問われた」(pucchati の過去分詞)
* no ti vadeyya = 「『いいえ』と言うだろう」

→「このように問われて、『いいえ』と言うだろう。」

8. Tamenaṃ evaṃ vadeyyuṃ –

* evaṃ vadeyyuṃ = 「このように言うだろう」

→「その男に(人々は)このように言うだろう。」

9. ‘ambho purisa, yaṃ tvaṃ janapadakalyāṇiṃ icchasi kāmesi, jānāsi taṃ janapadakalyāṇiṃ ‘evaṃnāmā evaṃgottāti vāti…pe… dīghā vā rassā vā majjhimā vā kāḷī vā sāmā vā maṅguracchavī vāti… amukasmiṃ gāme vā nigame vā nagare vā’ti?

* ambho purisa = 「おい、男よ」
* yaṃ tvaṃ janapadakalyāṇiṃ icchasi kāmesi = 「あなたが欲し求めるその地方一の美女を」
* jānāsi taṃ janapadakalyāṇiṃ = 「あなたはその美女を知っているのか」
* evaṃnāmā evaṃgottā ti vā = 「これこれの名、これこれの姓であると」
  * evaṃ-nāmā = 「このような名をもつ」
  * evaṃ-gottā = 「このような姓をもつ」
* …pe… = 「(中略)」
* dīghā vā rassā vā majjhimā vā = 「背が高いか、低いか、中くらいか」
* kāḷī vā sāmā vā maṅguracchavī vā = 「肌が黒いか、褐色か、黄金色か」
  * kāḷī = 「黒い(肌の)」
  * sāmā = 「褐色の、浅黒い(肌の)」
  * maṅgura-cchavī = 「黄金色の肌をもつ」(maṅgura = 金色の魚の名、chavi = 皮膚。要確認)
* amukasmiṃ gāme vā nigame vā nagare vā = 「どこそこの村か、町か、都市か(に住む)」
  * amuka = 「どこそこの、某」
  * gāma = 「村」、nigama = 「町」、nagara = 「都市」
* ti = 「〜と」

→「『おい、男よ、あなたが欲し求めるその地方一の美女について、あなたはその美女がこれこれの名、これこれの姓であると……(中略)……背が高いか、低いか、中くらいか、肌が黒いか、褐色か、黄金色か……どこそこの村か、町か、都市かに住むのかを知っているのか』と。」

10. Iti puṭṭho ‘no’ti vadeyya.

* iti puṭṭho = 「このように問われて」
* no ti vadeyya = 「『いいえ』と言うだろう」

→「このように問われて、『いいえ』と言うだろう。」

11. Tamenaṃ evaṃ vadeyyuṃ –

* tam enaṃ = 「その彼に」
* evaṃ vadeyyuṃ = 「このように言うだろう」

→「その男に(人々は)このように言うだろう。」

12. ‘ambho purisa, yaṃ tvaṃ na jānāsi na passasi, taṃ tvaṃ icchasi kāmesī’’’ti?

* ambho purisa = 「おい、男よ」
* yaṃ tvaṃ na jānāsi na passasi = 「あなたが知らず、見てもいない者を」
  * na passasi = 「見ていない」(passati の2人称単数)
* taṃ tvaṃ icchasi kāmesi = 「その者をあなたは欲し、求めるのか」
* ti = 「〜と」

→「『おい、男よ、あなたが知りもせず見てもいない者を、あなたは欲し求めるのか』と。」

13. Iti puṭṭho ‘āmā’ti vadeyya.

* iti puṭṭho = 「このように問われて」
* āmā ti vadeyya = 「『はい』と言うだろう」
  * āma = 「はい、そうです」

→「このように問われて、『はい』と言うだろう。」

14. ‘‘Taṃ kiṃ maññasi, kaccāna, nanu evaṃ sante tassa purisassa appāṭihīrakataṃ bhāsitaṃ sampajjatī’’ti?

* taṃ kiṃ maññasi = 「それをどう思うか」(定型句)
* kaccāna = 「カッチャーナよ」
* nanu = 「〜ではないか」(反語の疑問詞)
* evaṃ sante = 「そうであるならば」(処格絶対句)
* tassa purisassa = 「その男の」
* appāṭihīrakataṃ bhāsitaṃ = 「根拠のない話、実証されない言葉」
  * a-pāṭihīra-kata = 「証拠立てられていない、根拠のない」(pāṭihīra = 証明、確証)
  * bhāsita = 「話されたこと、言葉」
* sampajjati = 「〜となる、帰結する」

* ti = 「～と」(引用の終わり)

→「カッチャーナよ、阿羅漢であり、漏が尽き、(梵行を) 完成し、なすべきことをなし、重荷を下ろし、自らの目的に達し、有の結を滅尽し、正しい了知によって解脱した比丘たち、彼らこそがこれ ― 欲にせよ、欲の楽にせよ、欲の最上の楽にせよ ― を知るであろう。」

Tesamidaṃ bhāsitaṃ hassakaṃyeva sampajjati, nāmakaṃyeva sampajjati, rittakaṃyeva sampajjati, tucchakaṃyeva sampajjatī’’ti. ‘‘Ye kho te, kaccāna, samaṇabrāhmaṇā ajānantā pubbantaṃ , apassantā aparantaṃ, ‘khīṇā jāti, vusitaṃ brahmacariyaṃ, kataṃ karaṇīyaṃ, nāparaṃ itthattāyāti – pajānāmā’ti – paṭijānanti; tesaṃ soyeva [tesaṃ tesāyaṃ (sī.), tesaṃyeva so (?)] sahadhammiko niggaho hoti. Yathānusiṭṭhaṃ tathā paṭipajjamāno [yathānusiṭṭhaṃ paṭipajjamāno (?)] nacirasseva sāmaññeva ñassati sāmaṃ dakkhiti – evaṃ kira sammā [evaṃ kirāyasmā (syā. ka.)] bandhanā vippamokkho hoti, yadidaṃ avijjā bandhanā. Evameva kho, kaccāna, etu viññū puriso asaṭho amāyāvī ujujātiko, ahamanusāsāmi, ahaṃ dhammaṃ desemi; yathānusiṭṭhaṃ tathā paṭipajjamāno nacirasseva sāmaññe ñassati , sāmaṃ dakkhiti – ‘evaṃ kira sammā bandhanā vippamokkho hoti, yadidaṃ avijjā bandhanā’’’ti.

1. 281. Evaṃ vutte, vekhanaso paribbājako kupito anattamano bhagavantaṃyeva khuṃsento bhagavantaṃyeva vambhento bhagavantaṃyeva vadamāno ‘‘samaṇo [samaṇo ca (sī. pī.)] gotamo pāpito bhavissatī’’ti bhagavantaṃ etadavoca –

* evaṃ vutte = 「このように言われたとき」(絶対処格)
* vekhanaso paribbājako = 「遍歴行者ヴェーカナサは」
* kupito = 「怒って」(kuppati の過去分詞)
* anattamano = 「不機嫌になって、不満になって」(an-attamana)
* bhagavantaṃ yeva khuṃsento = 「まさに世尊を罵り」
  * khuṃsento = khuṃseti「罵る、非難する」の現在分詞
* bhagavantaṃ yeva vambhento = 「まさに世尊をけなし」
  * vambhento = vambheti「軽蔑する、けなす」の現在分詞
* bhagavantaṃ yeva vadamāno = 「まさに世尊を非難して」(vadati の現在分詞。ここでは「難じて」の意)
* samaṇo gotamo pāpito bhavissatī ti = 「"沙門ゴータマは悪い者にされる(論破されて面目を失う)だろう"と(思って)」
  * pāpito = pāpeti「悪に至らせる、害する」の過去分詞。異読 samaṇo ca
* bhagavantaṃ etad avoca = 「世尊にこう言った」

→「このように言われたとき、遍歴行者ヴェーカナサは怒り、不機嫌になり、まさに世尊を罵り、まさに世尊をけなし、まさに世尊を非難して、"沙門ゴータマは面目を失うことになるだろう"と(思い)、世尊にこう言った。」

2. ‘‘evameva panidhekacce [panidheke (sī. pī.), panimeke (uparisubhasutte)] samaṇabrāhmaṇā ajānantā pubbantaṃ, apassantā aparantaṃ atha ca pana ‘khīṇā jāti, vusitaṃ brahmacariyaṃ, kataṃ karaṇīyaṃ, nāparaṃ itthattāyāti – pajānāmā’ti – paṭijānanti [itthattāyāti paṭijānanti (pī.)].

* evam eva pana = 「まさにこのように、しかし」
* idha ekacce samaṇabrāhmaṇā = 「ここで、ある沙門・婆羅門たちは」
  * panidhekacce = pana + idha + ekacce
* ajānantā pubbantaṃ = 「過去の端(過去世)を知らず」
  * pubbanta = pubba-anta「前の端、過去の辺際」
* apassantā aparantaṃ = 「未来の端(未来世)を見ず」
  * aparanta = apara-anta「後の端、未来の辺際」
* atha ca pana = 「それでもなお」
* khīṇā jāti = 「生は尽きた」
* vusitaṃ brahmacariyaṃ = 「梵行は完成した」
* kataṃ karaṇīyaṃ = 「なすべきことはなされた」
* nāparaṃ itthattāya = 「この状態のほかにもうない(再びこの状態になることはない)」
* ti pajānāmā ti = 「～と私たちは知っている、と」
* paṭijānanti = 「公言する、自認する」

→「"まさにこのように、しかしここで、ある沙門・婆羅門たちは過去の端を知らず、未来の端を見ず、それでもなお、'生は尽きた、梵行は完成した、なすべきことはなされた、この状態のほかにもうない、と私たちは知っている'と公言する。」

3. Tesamidaṃ bhāsitaṃ hassakaṃyeva sampajjati, nāmakaṃyeva sampajjati, rittakaṃyeva sampajjati, tucchakaṃyeva sampajjatī’’ti.

* tesaṃ idaṃ bhāsitaṃ = 「彼らのこの言葉は」
* hassakaṃ yeva sampajjati = 「まさに笑うべきものとなる」
  * hassaka = hassa「笑い」+ ka
* nāmakaṃ yeva sampajjati = 「まさに名ばかりのものとなる」
* rittakaṃ yeva sampajjati = 「まさに空虚なものとなる」
* tucchakaṃ yeva sampajjati = 「まさに虚妄なものとなる」

→「彼らのこの言葉は、まさに笑うべきものとなり、まさに名ばかりのものとなり、まさに空虚なものとなり、まさに虚妄なものとなる"と。」

4. ‘‘Ye kho te, kaccāna, samaṇabrāhmaṇā ajānantā pubbantaṃ , apassantā aparantaṃ, ‘khīṇā jāti, vusitaṃ brahmacariyaṃ, kataṃ karaṇīyaṃ, nāparaṃ itthattāyāti – pajānāmā’ti – paṭijānanti; tesaṃ soyeva [tesaṃ tesāyaṃ (sī.), tesaṃyeva so (?)] sahadhammiko niggaho hoti.

* ye kho te, kaccāna, samaṇabrāhmaṇā = 「カッチャーナよ、およそその沙門・婆羅門たちが」
  * kaccāna = ヴェーカナサの姓による呼びかけ
* ajānantā pubbantaṃ, apassantā aparantaṃ = 「過去の端を知らず、未来の端を見ず」
* khīṇā jāti ... pajānāmā ti paṭijānanti = 「'生は尽きた……と私たちは知っている'と公言する(なら)」
* tesaṃ so yeva sahadhammiko niggaho hoti = 「彼らにとって、まさにそれ(あなたの批判)が正当な論破となる」
  * sahadhammika = 「法にかなった、正当な」
  * niggaha = 「論破、折伏、非難」
  * so yeva = 「まさにそれが」。異読 tesaṃ tesāyaṃ / tesaṃ yeva so

→「"カッチャーナよ、およそその沙門・婆羅門たちが、過去の端を知らず、未来の端を見ず、'生は尽きた、梵行は完成した、なすべきことはなされた、この状態のほかにもうない、と私たちは知っている'と公言するなら、彼らにとってはまさにそれが正当な論破となる。」

5. Api ca, kaccāna, tiṭṭhatu pubbanto, tiṭṭhatu aparanto.

* api ca = 「しかしまた、それはさておき」
* tiṭṭhatu pubbanto = 「過去の端はそのままにしておけ」
  * tiṭṭhatu = tiṭṭhati の命令法三人称単数。「置いておけ、問わないでおけ」
* tiṭṭhatu aparanto = 「未来の端はそのままにしておけ」

→「しかしまた、カッチャーナよ、過去の端はそのままにしておき、未来の端はそのままにしておけ。」

6. Etu viññū puriso asaṭho amāyāvī ujujātiko, ahamanusāsāmi ahaṃ dhammaṃ desemi.

* etu = 「来るがよい」(eti の命令法三人称単数)
* viññū puriso = 「賢明な人が」
* asaṭho = 「狡猾でない」
* amāyāvī = 「欺瞞のない」
* ujujātiko = 「正直な性質の」(uju-jātika)
* ahaṃ anusāsāmi = 「私は教え諭す」
* ahaṃ dhammaṃ desemi = 「私は法を説く」

→「狡猾でなく、欺瞞がなく、正直な性質の賢明な人が来るがよい。私は教え諭し、私は法を説く。」

7. Yathānusiṭṭhaṃ tathā paṭipajjamāno [yathānusiṭṭhaṃ paṭipajjamāno (?)] nacirasseva sāmaññeva ñassati sāmaṃ dakkhiti – evaṃ kira sammā [evaṃ kirāyasmā (syā. ka.)] bandhanā vippamokkho hoti, yadidaṃ avijjā bandhanā.

* yathānusiṭṭhaṃ tathā paṭipajjamāno = 「教え諭されたとおりにそのように実践するなら」
  * anusiṭṭha = anusāsati の過去分詞
* na cirass' eva = 「久しくないうちに、すぐに」
* sāmaṃ yeva ñassati = 「自ら知るだろう」
  * ñassati = jānāti の未来形
* sāmaṃ dakkhiti = 「自ら見るだろう」
  * dakkhiti = dakkhati (見る) の未来形
* evaṃ kira = 「このように確かに」
* sammā bandhanā vippamokkho hoti = 「束縛からの正しい解放がある」
  * vippamokkha = 「解放、脱出」
* yadidaṃ avijjā bandhanā = 「すなわち無明という束縛から」

→「教え諭されたとおりにそのように実践するなら、すぐに自ら知り、自ら見るだろう、"このように確かに束縛からの正しい解放がある、すなわち無明という束縛からの(解放が)"と。」

8. Seyyathāpi, kaccāna, daharo kumāro mando uttānaseyyako kaṇṭhapañcamehi bandhanehi baddho assa suttabandhanehi;

* seyyathāpi = 「たとえば」
* daharo kumāro = 「幼い子どもが」
* mando = 「無知な、幼くて弱い」
* uttānaseyyako = 「仰向けに寝ている(赤子)」(uttāna-seyyaka)
* kaṇṭhapañcamehi bandhanehi = 「首を第五とする束縛によって」(両手・両足・首の五か所)
* baddho assa = 「縛られているとしよう」(assa = atthi の願望法)
* suttabandhanehi = 「糸の束縛によって」

→「カッチャーナよ、たとえば幼く無知で仰向けに寝ている子どもが、首を第五とする糸の束縛によって縛られているとしよう。」

9. tassa vuddhimanvāya indriyānaṃ paripākamanvāya tāni bandhanāni mucceyyuṃ;

* tassa = 「その(子の)」
* vuddhiṃ anvāya = 「成長に伴って」
  * anvāya = 「～に従って、～によって」(anveti の絶対分詞)
* indriyānaṃ paripākaṃ anvāya = 「諸根の成熟に伴って」
* tāni bandhanāni mucceyyuṃ = 「それらの束縛が解けるだろう」
  * mucceyyuṃ = muccati の願望法三人称複数

→「その子の成長に伴い、諸根の成熟に伴い、それらの束縛が解けるだろう。」

10. so mokkhomhīti kho jāneyya no ca bandhanaṃ .

* so = 「彼は」
* mokkho 'mhī ti jāneyya = 「'私は解放された'と知るだろう」
  * mokkho = 「解放された者、自由な者」
* no ca bandhanaṃ = 「しかし束縛は(知らない)」(要確認)
  * 束縛が何であったかは知らない、という意。「もはや束縛はない」と読む解釈もある

→「彼は'私は解放された'と知るだろうが、束縛(が何であったか)は知らないだろう。」

11. Evameva kho, kaccāna, etu viññū puriso asaṭho amāyāvī ujujātiko, ahamanusāsāmi, ahaṃ dhammaṃ desemi;

* evam eva kho = 「まさにそのように」
* etu viññū puriso asaṭho amāyāvī ujujātiko = 「狡猾でなく、欺瞞がなく、正直な性質の賢明な人が来るがよい」
* ahaṃ anusāsāmi, ahaṃ dhammaṃ desemi = 「私は教え諭し、私は法を説く」

→「まさにそのように、カッチャーナよ、狡猾でなく、欺瞞がなく、正直な性質の賢明な人が来るがよい。私は教え諭し、私は法を説く。」

12. yathānusiṭṭhaṃ tathā paṭipajjamāno nacirasseva sāmaññe ñassati , sāmaṃ dakkhiti – ‘evaṃ kira sammā bandhanā vippamokkho hoti, yadidaṃ avijjā bandhanā’’’ti.

* yathānusiṭṭhaṃ tathā paṭipajjamāno = 「教え諭されたとおりにそのように実践するなら」
* na cirass' eva sāmaṃ yeva ñassati, sāmaṃ dakkhiti = 「すぐに自ら知り、自ら見るだろう」
* evaṃ kira sammā bandhanā vippamokkho hoti = 「このように確かに束縛からの正しい解放がある」
* yadidaṃ avijjā bandhanā ti = 「すなわち無明という束縛から、と」

→「教え諭されたとおりにそのように実践するなら、すぐに自ら知り、自ら見るだろう、'このように確かに束縛からの正しい解放がある、すなわち無明という束縛からの(解放が)'と。"」

13. Evaṃ vutte, vekhanaso paribbājako bhagavantaṃ etadavoca – ‘‘abhikkantaṃ, bho gotama…pe… upāsakaṃ maṃ bhavaṃ gotamo dhāretu ajjatagge pāṇupetaṃ saraṇaṃ gata’’nti.

* vekhanaso paribbājako bhagavantaṃ etad avoca = 「遍歴行者ヴェーカナサは世尊にこう言った」

* pe = 「(中略)」

  * dhāretu = dhāreti の命令法三人称単数
* ajjatagge = 「今日以後」(ajja-t-agge)
* pāṇupetaṃ saraṇaṃ gataṃ = 「命ある限り帰依した者として」
  * pāṇupeta = pāṇa-upeta「命を具えた(命の続く限りの)」

→「このように言われたとき、遍歴行者ヴェーカナサは世尊にこう言った。"すばらしい、ゴータマ殿……(中略)……ゴータマ殿は私を、今日以後、命ある限り帰依した優婆塞として憶えてください"と。」

14. Vekhanasasuttaṃ niṭṭhitaṃ dasamaṃ.

* niṭṭhitaṃ = 「終わった」
