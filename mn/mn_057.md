## 78

### 対訳

1. 7. Kukkuravatikasuttaṃ

* kukkura-vatika-sutta = 「犬の戒行者経」
  * kukkura = 「犬」
  * vatika = 「誓戒(vata)を実践する者」
  * sutta = 「経」

→「犬の戒行者経」

2. 78. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā koliyesu viharati haliddavasanaṃ nāma koliyānaṃ nigamo.

* evaṃ me sutaṃ = 「このように私は聞いた」
* ekaṃ samayaṃ = 「ある時」
* bhagavā = 「世尊は」
* koliyesu viharati = 「コーリヤ族の(国に)住んでいた」
* haliddavasanaṃ nāma = 「ハリッダヴァサナという名の」
* koliyānaṃ nigamo = 「コーリヤ族の町(があり、そこに住んでいた)」
  * nigama = 「町、市場町」

→「このように私は聞いた――ある時、世尊はコーリヤ族の国、ハリッダヴァサナという名のコーリヤ族の町に住んでいた。」

3. Atha kho puṇṇo ca koliyaputto govatiko acelo ca seniyo kukkuravatiko yena bhagavā tenupasaṅkamiṃsu;

* atha kho = 「さて」
* puṇṇo ca koliyaputto govatiko = 「牛の戒行者であるコーリヤ族の子プンナと」
  * govatika = 「牛の戒行(牛の真似をする誓戒)を実践する者」
* acelo ca seniyo kukkuravatiko = 「犬の戒行者である裸行者セーニヤ(の二人)は」
  * acela = 「裸行者(衣を着けない苦行者)」
* yena bhagavā tenupasaṅkamiṃsu = 「世尊のいる所へ近づいた」
  * upasaṅkamiṃsu = 「近づいた(upasaṅkamati のアオリスト複数)」

→「さて、牛の戒行者であるコーリヤ族の子プンナと、犬の戒行者である裸行者セーニヤは、世尊のいる所へ近づいた。」

4. upasaṅkamitvā puṇṇo koliyaputto govatiko bhagavantaṃ abhivādetvā ekamantaṃ nisīdi.

* upasaṅkamitvā = 「近づいてから」
* bhagavantaṃ abhivādetvā = 「世尊に敬礼して」
* ekamantaṃ nisīdi = 「一方に坐った」

→「近づいて、牛の戒行者であるコーリヤ族の子プンナは、世尊に敬礼して一方に坐った。」

5. Acelo pana seniyo kukkuravatiko bhagavatā saddhiṃ sammodi.

* pana = 「一方」
* bhagavatā saddhiṃ = 「世尊とともに」
* sammodi = 「挨拶を交わした(sammodati のアオリスト)」

→「一方、犬の戒行者である裸行者セーニヤは、世尊と挨拶を交わした。」

6. Sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā kukkurova palikujjitvā [palikuṇṭhitvā (syā. kaṃ.), paliguṇṭhitvā (ka.)] ekamantaṃ nisīdi.

* sammodanīyaṃ kathaṃ sāraṇīyaṃ = 「喜ばしく思い出に残る話を」
* vītisāretvā = 「交わし終えて」
* kukkuro va = 「犬のように」
* palikujjitvā = 「身を丸めて、うずくまって」
  * 異読: palikuṇṭhitvā (シャム版・カンボジア版), paliguṇṭhitvā (ある写本)
* ekamantaṃ nisīdi = 「一方に坐った」

→「喜ばしく思い出に残る話を交わし終えて、犬のように身を丸めて一方に坐った。」

7. Ekamantaṃ nisinno kho puṇṇo koliyaputto govatiko bhagavantaṃ etadavoca – ‘‘ayaṃ , bhante, acelo seniyo kukkuravatiko dukkarakārako chamānikkhittaṃ bhojanaṃ bhuñjati.

* ekamantaṃ nisinno = 「一方に坐った(プンナは)」
* bhagavantaṃ etadavoca = 「世尊にこう言った」
* ayaṃ, bhante = 「尊師よ、この」
* dukkarakārako = 「難行を行う者」
  * dukkara = 「行い難いこと」、kāraka = 「行う者」
* chamānikkhittaṃ bhojanaṃ = 「地面に置かれた食物を」
  * chamā = 「地面」、nikkhitta = 「置かれた」
* bhuñjati = 「食べる」

→「一方に坐った牛の戒行者であるコーリヤ族の子プンナは、世尊にこう言った――『尊師よ、この犬の戒行者である裸行者セーニヤは難行を行う者で、地面に置かれた食物を食べます。」

8. Tassa taṃ kukkuravataṃ dīgharattaṃ samattaṃ samādinnaṃ.

* tassa = 「彼にとって」
* taṃ kukkuravataṃ = 「その犬の戒行は」
* dīgharattaṃ = 「長い間」
* samattaṃ samādinnaṃ = 「完全に受持されています」
  * samatta = 「完全な、完成した」
  * samādinna = 「受持された(samādiyati の過去分詞)」

→「その犬の戒行は、彼によって長い間、完全に受持されています。」

9. Tassa kā gati, ko abhisamparāyo’’ti?

* tassa = 「彼の」
* kā gati = 「趣(死後の行き先)は何でしょうか」
* ko abhisamparāyo = 「来世の運命は何でしょうか」
* ti = 引用の終わり

→「彼の趣は何でしょうか、来世の運命は何でしょうか』と。」

10. ‘‘Alaṃ, puṇṇa, tiṭṭhatetaṃ; mā maṃ etaṃ pucchī’’ti.

* alaṃ, puṇṇa = 「プンナよ、やめなさい」
  * alaṃ = 「十分である、もうよい」
* tiṭṭhatetaṃ = tiṭṭhatu etaṃ = 「それはそのままにしておきなさい」
  * tiṭṭhatu = 「(そのまま)あれ(tiṭṭhati の命令法三人称単数)」
* mā maṃ etaṃ pucchi = 「私にそれを尋ねないでください」
  * mā + アオリスト = 禁止の表現

→「『プンナよ、やめなさい。それはそのままにしておきなさい。私にそれを尋ねないでください』と。」

11. Dutiyampi kho puṇṇo koliyaputto govatiko…pe… tatiyampi kho puṇṇo koliyaputto govatiko bhagavantaṃ etadavoca – ‘‘ayaṃ, bhante, acelo seniyo kukkuravatiko dukkarakārako chamānikkhittaṃ bhojanaṃ bhuñjati.

* dutiyampi = 「二度目にも」
* …pe… = 「(中略)」
* tatiyampi = 「三度目にも」
* bhagavantaṃ etadavoca = 「世尊にこう言った」
* 以下は項目 7 と同文

→「二度目にも牛の戒行者であるコーリヤ族の子プンナは(中略)三度目にも牛の戒行者であるコーリヤ族の子プンナは、世尊にこう言った――『尊師よ、この犬の戒行者である裸行者セーニヤは難行を行う者で、地面に置かれた食物を食べます。」

12. Tassa taṃ kukkuravataṃ dīgharattaṃ samattaṃ samādinnaṃ.

* 項目 8 と同文

→「その犬の戒行は、彼によって長い間、完全に受持されています。」

13. Tassa kā gati, ko abhisamparāyo’’ti?

* 項目 9 と同文

→「彼の趣は何でしょうか、来世の運命は何でしょうか』と。」

### 対訳

1. 79. ‘‘Addhā kho te ahaṃ, puṇṇa, na labhāmi.

* addhā = 「確かに、まことに」
* kho = 強意の小辞
* te = 「あなたから」(tvaṃ の属格. ここでは「あなたから(承諾を)得る」の意)
* ahaṃ = 「私は」
* puṇṇa = 「プンナよ」(呼格)
* na labhāmi = 「得られない」(labhati「得る」現在 1 人称単数)
  * 「質問をやめてほしいという私の求めを, あなたから得られない」の意

→「確かに, プンナよ, 私は(その求めを)あなたから得られない。」

2. Alaṃ, puṇṇa, tiṭṭhatetaṃ; mā maṃ etaṃ pucchīti; api ca tyāhaṃ byākarissāmi.

* alaṃ = 「もうよい、十分だ」
* tiṭṭhatetaṃ = tiṭṭhatu etaṃ 「それはそのままにしておきなさい(やめておきなさい)」
  * tiṭṭhatu = tiṭṭhati「立つ、とどまる」命令法 3 人称単数
* mā maṃ etaṃ pucchi = 「私にそれを尋ねるな」(mā + アオリストで禁止)
* ti = 引用の小辞(ここまでが先の制止の言葉)
* api ca = 「しかしながら、とはいえ」
* tyāhaṃ = te ahaṃ 「私はあなたに」
* byākarissāmi = 「解答しよう」(byākaroti「解答する、説明する」未来 1 人称単数)

→「『もうよい, プンナよ, それはやめておきなさい。私にそれを尋ねるな』(と言ったが), それでも私はあなたに解答しよう。」

3. Idha, puṇṇa, ekacco kukkuravataṃ bhāveti paripuṇṇaṃ abbokiṇṇaṃ, kukkurasīlaṃ bhāveti paripuṇṇaṃ abbokiṇṇaṃ, kukkuracittaṃ bhāveti paripuṇṇaṃ abbokiṇṇaṃ , kukkurākappaṃ bhāveti paripuṇṇaṃ abbokiṇṇaṃ.

* idha = 「ここに、この世において」
* ekacco = 「ある者は」
* kukkura-vataṃ = 「犬の誓戒を」
  * kukkura = 「犬」
  * vata = 「誓戒、務め」
* bhāveti = 「修習する、育てる」
* paripuṇṇaṃ = 「完全に、円満に」
* abbokiṇṇaṃ = 「間断なく、途切れなく」
* kukkura-sīlaṃ = 「犬の習慣(戒)を」
* kukkura-cittaṃ = 「犬の心を」
* kukkura-ākappaṃ = 「犬の振る舞いを」
  * ākappa = 「装い、立ち居振る舞い」

→「プンナよ, ここにある者が, 犬の誓戒を完全に間断なく修習し, 犬の習慣を完全に間断なく修習し, 犬の心を完全に間断なく修習し, 犬の振る舞いを完全に間断なく修習する。」

4. So kukkuravataṃ bhāvetvā paripuṇṇaṃ abbokiṇṇaṃ, kukkurasīlaṃ bhāvetvā paripuṇṇaṃ abbokiṇṇaṃ, kukkuracittaṃ bhāvetvā paripuṇṇaṃ abbokiṇṇaṃ, kukkurākappaṃ bhāvetvā paripuṇṇaṃ abbokiṇṇaṃ kāyassa bhedā paraṃ maraṇā kukkurānaṃ sahabyataṃ upapajjati.

* so = 「彼は」
* bhāvetvā = 「修習して」(連続体)
* kāyassa bhedā = 「身体が壊れてから」
* paraṃ maraṇā = 「死後に」
* kukkurānaṃ sahabyataṃ = 「犬たちの仲間として」
  * sahabyatā = 「共住、仲間であること」
* upapajjati = 「生まれ変わる」

→「彼は犬の誓戒を完全に間断なく修習し, 犬の習慣を完全に間断なく修習し, 犬の心を完全に間断なく修習し, 犬の振る舞いを完全に間断なく修習して, 身体が壊れて死んだ後, 犬たちの仲間として生まれ変わる。」

5. Sace kho panassa evaṃdiṭṭhi hoti – ‘imināhaṃ sīlena vā vatena vā tapena vā brahmacariyena vā devo vā bhavissāmi devaññataro vā’ti, sāssa [sāyaṃ (ka.)] hoti micchādiṭṭhi.

* sace kho pana = 「しかしもし」
* assa = 「彼に」
* evaṃdiṭṭhi hoti = 「このような見解がある」
* imināhaṃ = iminā ahaṃ 「これによって私は」
* sīlena vā vatena vā tapena vā brahmacariyena vā = 「戒によって, あるいは誓戒によって, あるいは苦行によって, あるいは梵行によって」
* devo vā bhavissāmi devaññataro vā = 「神になるだろう, あるいは神々のいずれかに(なるだろう)」
  * devaññatara = deva-aññatara 「神々のうちのある者」
* sāssa = sā assa 「それは彼の」
* hoti micchādiṭṭhi = 「邪見である」

→「しかしもし彼に『この戒や誓戒や苦行や梵行によって, 私は神に, あるいは神々のいずれかになるだろう』というこのような見解があるなら, それは彼の邪見である。」

6. Micchādiṭṭhissa [micchādiṭṭhikassa (sī.)] kho ahaṃ, puṇṇa, dvinnaṃ gatīnaṃ aññataraṃ gatiṃ vadāmi – nirayaṃ vā tiracchānayoniṃ vā.

* micchādiṭṭhissa = 「邪見の者には」
* dvinnaṃ gatīnaṃ aññataraṃ gatiṃ = 「二つの趣のいずれかの趣を」
  * gati = 「趣、死後の行き先」
* vadāmi = 「私は説く」
* nirayaṃ vā = 「地獄か」
* tiracchānayoniṃ vā = 「畜生の胎か」

→「プンナよ, 邪見の者には, 二つの趣のいずれかの趣を私は説く。すなわち地獄か畜生の胎かである。」

7. Iti kho, puṇṇa, sampajjamānaṃ kukkuravataṃ kukkurānaṃ sahabyataṃ upaneti, vipajjamānaṃ niraya’’nti.

* iti kho = 「このように」
* sampajjamānaṃ = 「成就しつつある(うまくいけば)」(sampajjati の現在分詞)
* kukkuravataṃ ... upaneti = 「犬の誓戒は～へ導く」
* kukkurānaṃ sahabyataṃ = 「犬たちの仲間へ」
* vipajjamānaṃ = 「失敗しつつある(うまくいかなければ)」(vipajjati の現在分詞)
* nirayaṃ = 「地獄へ」
* ti = 引用の小辞(世尊の言葉の終わり)

→「このように, プンナよ, 犬の誓戒は, 成就すれば犬たちの仲間へ導き, 失敗すれば地獄へ(導く)。」

8. Evaṃ vutte, acelo seniyo kukkuravatiko parodi, assūni pavattesi.

* evaṃ vutte = 「このように言われたとき」
* acelo = 「裸行者」
* seniyo = 「セーニヤは」
* kukkuravatiko = 「犬の誓戒者(犬の誓戒を実践する者)」
* parodi = 「泣き出した」(parodati のアオリスト)
* assūni pavattesi = 「涙を流した」
  * assu = 「涙」
  * pavattesi = 「流した」(pavatteti のアオリスト)

→「このように言われたとき, 犬の誓戒者である裸行者セーニヤは泣き出し, 涙を流した。」

9. Atha kho bhagavā puṇṇaṃ koliyaputtaṃ govatikaṃ etadavoca – ‘‘etaṃ kho te ahaṃ, puṇṇa, nālatthaṃ.

* atha kho = 「そこで」
* bhagavā = 「世尊は」
* puṇṇaṃ koliyaputtaṃ govatikaṃ = 「牛の誓戒者であるコーリヤの子プンナに」
  * govatika = 「牛の誓戒者(牛の誓戒を実践する者)」
* etadavoca = 「このように言った」
* etaṃ ... te ... nālatthaṃ = 「私はそれをあなたから得られなかった」
  * nālatthaṃ = na alatthaṃ (labhati のアオリスト 1 人称単数)
  * 「質問をやめてほしいという求めが受け入れられなかった」の意

→「そこで世尊は, 牛の誓戒者であるコーリヤの子プンナにこう言った ―『プンナよ, 私はそれ(その求め)をあなたから得られなかった。』」

10. Alaṃ, puṇṇa, tiṭṭhatetaṃ; mā maṃ etaṃ pucchī’’ti.

* alaṃ = 「もうよい」
* tiṭṭhatetaṃ = 「それはやめておきなさい」
* mā maṃ etaṃ pucchi = 「私にそれを尋ねるな」

→「『もうよい, プンナよ, それはやめておきなさい。私にそれを尋ねるな』と。」

11. ‘‘Nāhaṃ, bhante, etaṃ rodāmi yaṃ maṃ bhagavā evamāha; api ca me idaṃ, bhante, kukkuravataṃ dīgharattaṃ samattaṃ samādinnaṃ.

* nāhaṃ = na ahaṃ 「私は～ない」
* bhante = 「尊師よ」
* etaṃ rodāmi yaṃ = 「～ということを泣いているのではない」

→「このようにも私は、プンナよ、『衆生は業の相続者である』と説く。」

9. Idaṃ vuccati, puṇṇa, kammaṃ kaṇhasukkaṃ kaṇhasukkavipākaṃ.

* idaṃ vuccati = 「これが～と言われる」

→「プンナよ、これが黒白であり黒白の果報のある業と言われる。」

10. ‘‘Katamañca , puṇṇa, kammaṃ akaṇhaṃ asukkaṃ akaṇhaasukkavipākaṃ, kammakkhayāya saṃvattati?

* akaṇhaṃ asukkaṃ = 「黒でもなく白でもない」
* akaṇhaasukkavipākaṃ = 「黒でも白でもない果報のある」
* kammakkhayāya = 「業の滅尽のために」
  * kamma-kkhaya = 「業の滅尽」
* saṃvattati = 「導く、資する」

→「では、プンナよ、どれが黒でもなく白でもなく、黒でも白でもない果報があり、業の滅尽に導く業か。」

11. Tatra, puṇṇa, yamidaṃ kammaṃ kaṇhaṃ kaṇhavipākaṃ tassa pahānāya yā cetanā, yamidaṃ kammaṃ sukkaṃ sukkavipākaṃ tassa pahānāya yā cetanā, yamidaṃ kammaṃ kaṇhasukkaṃ kaṇhasukkavipākaṃ tassa pahānāya yā cetanā – idaṃ vuccati, puṇṇa, kammaṃ akaṇhaṃ asukkaṃ akaṇhaasukkavipākaṃ, kammakkhayāya saṃvattatīti.

* tatra = 「そのうち、そこで」
* yam idaṃ kammaṃ kaṇhaṃ kaṇhavipākaṃ = 「黒く黒い果報のあるこの業」
* tassa pahānāya = 「それを捨断するための」
  * pahāna = 「捨断、捨て去ること」
* yā cetanā = 「その思（意思）」
  * cetanā = 「思、意思」
* yamidaṃ = 「およそこの～」
  * 異読 yampidaṃ (sī. pī.)
* idaṃ vuccati = 「これが～と言われる」
* saṃvattatī ti = 「～に導く、と」

→「プンナよ、そのうち、黒く黒い果報のあるこの業、それを捨断するための思、白く白い果報のあるこの業、それを捨断するための思、黒白であり黒白の果報のあるこの業、それを捨断するための思、――これが、プンナよ、黒でもなく白でもなく、黒でも白でもない果報があり、業の滅尽に導く業と言われる。」

12. Imāni kho, puṇṇa, cattāri kammāni mayā sayaṃ abhiññā sacchikatvā paveditānī’’ti.

* imāni cattāri kammāni = 「これら四つの業は」
* mayā = 「私によって」
* sayaṃ = 「自ら」
* abhiññā = 「証知して」（連続体的用法。abhijānāti より）
* sacchikatvā = 「実証して」（sacchikaroti の連続体）
* paveditāni = 「説き示された」（pavedeti の過去分詞）
* ti = 「～と（引用の終わり）」

→「プンナよ、これら四つの業は、私が自ら証知し実証して説き示したものである。」

1. 82. Evaṃ vutte, puṇṇo koliyaputto govatiko bhagavantaṃ etadavoca –

  * go-vatika = 「牛の行（牛のまねをする苦行）を実践する者」
* bhagavantaṃ etadavoca = 「世尊にこう言った」

→「このように言われたとき、コーリヤの子で牛の行を実践するプンナは、世尊にこう言った。」
