# 5. Bodhirājakumārasuttavaṇṇanā

## 324

324. Evaṃme sutanti bodhirājakumārasuttaṃ. Tattha kokanadoti kokanadaṃ vuccati padumaṃ. So ca maṅgalapāsādo olokanakapadumaṃ dassetvā kato, tasmā kokanadoti saṅkhaṃ labhi.

### 対訳

1. 5. Bodhirājakumārasuttavaṇṇanā

* Bodhirājakumāra-sutta-vaṇṇanā = 「ボーディ王子経の註釈」
  * Bodhi = 「ボーディ(人名)」
  * rājakumāra = 「王子」
  * sutta = 「経」
  * vaṇṇanā = 「註釈、解説」

→「5. ボーディ王子経の註釈」

2. 324. Evaṃme sutanti bodhirājakumārasuttaṃ.

* Evaṃ me sutaṃ = 「このように私は聞いた」
  * 経の冒頭句を引いて、経全体を指している
* ti = 「〜と(で始まるのが)」
* bodhirājakumārasuttaṃ = 「ボーディ王子経(である)」

→「324. "このように私は聞いた" で始まるのがボーディ王子経である。」

3. Tattha kokanadoti kokanadaṃ vuccati padumaṃ.

* tattha = 「そこにおいて、その(経の)中で」
* kokanado ti = 「"kokanado(コーカナダ)" とは」
  * 経では高殿の名として出る語
* kokanadaṃ = 「kokanada(という語)は」
* vuccati = 「言われる、呼ばれる」
* padumaṃ = 「蓮華」

→「その中で "kokanado(コーカナダ)" について、kokanada とは蓮華のことをいう。」

4. So ca maṅgalapāsādo olokanakapadumaṃ dassetvā kato, tasmā kokanadoti saṅkhaṃ labhi.

* so ca = 「そしてその」
* maṅgala-pāsādo = 「めでたい高殿、吉祥の高殿」
  * maṅgala = 「吉祥、めでたいこと」
  * pāsāda = 「高殿、楼閣」
* olokanaka-padumaṃ = 「眺めるための蓮華」(要確認)
  * olokanaka = 「眺めることに関わる、見るための」
  * paduma = 「蓮華」
* dassetvā = 「示して、表して」
  * dasseti の連続体
  * ここでは蓮華の形を見せるように造ったことをいうと解される(要確認)
* kato = 「造られた」
  * karoti の過去分詞
* tasmā = 「それゆえ」
* kokanado ti = 「"コーカナダ" という」
* saṅkhaṃ = 「呼称、名称を」
* labhi = 「得た」
  * labhati のアオリスト

→「そしてそのめでたい高殿は、眺めるための蓮華を表して造られた。それゆえ "コーカナダ" という呼称を得たのである。」

## 325

325. Yāva pacchimasopānakaḷevarāti ettha pacchimasopānakaḷevaranti paṭhamaṃ sopānaphalakaṃ vuttaṃ. Addasākhoti olokanatthaṃyeva dvārakoṭṭhake ṭhito addasa. Bhagavā tuṇhī ahosīti ‘‘kissa nu kho atthāya rājakumārena ayaṃ mahāsakkāro kato’’ti āvajjanto puttapatthanāya katabhāvaṃ aññāsi. So hi rājakumāro aputtako, sutañcānena ahosi – ‘‘buddhānaṃ kira adhikāraṃ katvā manasā icchitaṃ labhantī’’ti. So – ‘‘sacāhaṃ puttaṃ labhissāmi, sammāsambuddho mama celappaṭikaṃ akkamissati. No ce labhissāmi, na akkamissatī’’ti patthanaṃ katvā santharāpesi. Atha bhagavā ‘‘nibbattissati nu kho etassa putto’’ti āvajjetvā ‘‘na nibbattissatī’’ti addasa.

Pubbe kira so ekasmiṃ dīpe vasamāno samacchandena sakuṇapotake khādi. Sacassa mātugāmo aññova bhaveyya, puttaṃ labheyya. Ubhohi pana samānacchandehi hutvā pāpakammaṃ kataṃ, tenassa putto na nibbattissatīti aññāsi. Dusse pana akkante – ‘‘buddhānaṃ adhikāraṃ katvā patthitapatthitaṃ labhantīti loke anussavo, mayā ca mahāabhinīhāro kato, na ca puttaṃ labhāmi, tucchaṃ idaṃ vacana’’nti micchāgahaṇaṃ gaṇheyya. Titthiyāpi – ‘‘natthi samaṇānaṃ akattabbaṃ nāma, celappaṭikaṃ maddantā āhiṇḍantī’’ti ujjhāyeyyuṃ . Etarahi ca akkamantesu bahū bhikkhū paracittaviduno, te bhabbaṃ jānitvā akkamissanti, abhabbaṃ jānitvā na akkamissanti. Anāgate pana upanissayo mando bhavissati, anāgataṃ na jānissanti. Tesu akkamantesu sace patthitaṃ ijjhissati, iccetaṃ kusalaṃ . No ce ijjhissati, – ‘‘pubbe bhikkhusaṅghassa abhinīhāraṃ katvā icchiticchitaṃ labhanti, taṃ idāni na labhanti . Teyeva maññe bhikkhū paṭipattipūrakā ahesuṃ, ime paṭipattiṃ pūretuṃ na sakkontī’’ti manussā vippaṭisārino bhavissantīti imehi kāraṇehi bhagavā akkamituṃ anicchanto tuṇhī ahosi. Sikkhāpadaṃ paññapesi ‘‘na, bhikkhave, celappaṭikā akkamitabbā’’ti (cūḷava. 268). Maṅgalatthāya paññattaṃ anakkamantesu pana akkamanatthāya anupaññattiṃ ṭhapesi – ‘‘gihī, bhikkhave, maṅgalikā, anujānāmi, bhikkhave, gihīnaṃ maṅgalatthāyā’’ti (cūḷava. 268).

### 対訳

1. 325. Yāva pacchimasopānakaḷevarāti ettha pacchimasopānakaḷevaranti paṭhamaṃ sopānaphalakaṃ vuttaṃ.

* yāva = 「〜まで」
* pacchima-sopāna-kaḷevarā = 「最後の階段の段(まで)」(奪格、yāva と結ぶ)
  * pacchima = 「最後の、最も後の」
  * sopāna = 「階段」
  * kaḷevara = 「(階段の)段、踏み段」(本来は「身体」の意の語)
* ti ettha = 「〜とあるここで」
* pacchimasopānakaḷevaraṃ ti = 「"最後の階段の段"とは」
* paṭhamaṃ = 「最初の」
* sopāna-phalakaṃ = 「階段の板、踏み板」
  * 上る側から数えて最初の板、つまり一番下の段を指すと解される(文脈からの判断)
* vuttaṃ = 「言われている」

→「"最後の階段の段まで"とあるここで、"最後の階段の段"とは、最初の階段の踏み板(一番下の段)のことを言っている。」

2. Addasākhoti olokanatthaṃyeva dvārakoṭṭhake ṭhito addasa.

* addasā kho ti = 「"見た"とは」
* olokana-atthaṃ yeva = 「まさに見るために、見張るためにこそ」
  * olokana = 「見ること、眺めること」
* dvārakoṭṭhake = 「門屋で」(処格)
* ṭhito = 「立っていて」(tiṭṭhati の過去分詞)
* addasa = 「見た」

→「"見た"とは、(世尊の到来を)見るためにこそ門屋に立っていて、見たのである。」

3. Bhagavā tuṇhī ahosīti ‘‘kissa nu kho atthāya rājakumārena ayaṃ mahāsakkāro kato’’ti āvajjanto puttapatthanāya katabhāvaṃ aññāsi.

* bhagavā tuṇhī ahosi ti = 「"世尊は沈黙していた"とは」
* kissa nu kho atthāya = 「いったい何のために」
* rājakumārena = 「王子によって」
* ayaṃ mahā-sakkāro = 「この大きなもてなし」
* kato = 「なされた」
* ti āvajjanto = 「〜と心を向けて(考察して)」(現在分詞)
* putta-patthanāya = 「子を願って、子への願いのために」
* kata-bhāvaṃ = 「なされたものであること」
* aññāsi = 「知った」

→「"世尊は沈黙していた"とは、"いったい何のために王子はこの大きなもてなしをしたのか"と心を向けて、それが子を願ってなされたものであることを知った(ということである)。」

4. So hi rājakumāro aputtako, sutañcānena ahosi – ‘‘buddhānaṃ kira adhikāraṃ katvā manasā icchitaṃ labhantī’’ti.

* so hi rājakumāro = 「というのは、その王子は」
* aputtako = 「子のない者」
* sutañcānena ahosi = 「そして彼によって聞かれていた」(sutaṃ ca anena ahosi)
* buddhānaṃ = 「仏たちに対して」
* kira = 「〜だそうだ」(伝聞)
* adhikāraṃ katvā = 「奉仕をして、供養の行いをして」
* manasā icchitaṃ = 「心で望んだもの」
* labhanti = 「(人々は)得る」

→「というのは、その王子には子がなく、彼は"仏たちに奉仕をすれば、心で望んだものを得るそうだ"と聞いていたからである。」

5. So – ‘‘sacāhaṃ puttaṃ labhissāmi, sammāsambuddho mama celappaṭikaṃ akkamissati. No ce labhissāmi, na akkamissatī’’ti patthanaṃ katvā santharāpesi.

* so = 「彼は」
* sacāhaṃ = 「もし私が」(sace ahaṃ)
* puttaṃ labhissāmi = 「子を得るのであれば」
* sammāsambuddho = 「正自覚者は」
* mama celappaṭikaṃ = 「私の布の敷物を」
  * cela = 「布」
* akkamissati = 「踏むだろう」
* no ce labhissāmi = 「もし得ないのであれば」
* na akkamissati = 「踏まないだろう」
* ti patthanaṃ katvā = 「〜と願をかけて」
* santharāpesi = 「敷かせた」(使役)

→「彼は"もし私が子を得るのであれば、正自覚者は私の布の敷物を踏むだろう。もし得ないのであれば、踏まないだろう"と願をかけて、(布を)敷かせた。」

6. Atha bhagavā ‘‘nibbattissati nu kho etassa putto’’ti āvajjetvā ‘‘na nibbattissatī’’ti addasa.

* atha = 「そこで」
* nibbattissati nu kho = 「いったい生まれるだろうか」
* etassa putto = 「この者に子が」
* ti āvajjetvā = 「〜と心を向けて」
* na nibbattissati ti = 「"生まれないだろう"と」
* addasa = 「見た、見てとった」

→「そこで世尊は"この者に子は生まれるだろうか"と心を向けて、"生まれないだろう"と見てとった。」

7. Pubbe kira so ekasmiṃ dīpe vasamāno samacchandena sakuṇapotake khādi.

* pubbe = 「以前に、過去(の生)に」
* kira = 「〜という」(伝聞)
* ekasmiṃ dīpe = 「ある島に」
* vasamāno = 「住んでいて」(現在分詞)
* sama-cchandena = 「同じ意向で」
  * 次々文の "ubhohi samānacchandehi" から、妻と意向を同じくしての意と解される
* sakuṇa-potake = 「鳥の雛たちを」
* khādi = 「食べた」

→「以前、彼はある島に住んでいたとき、(妻と)意向を同じくして鳥の雛たちを食べたという。」

8. Sacassa mātugāmo aññova bhaveyya, puttaṃ labheyya.

* sacassa = 「もし彼の」(sace assa)
* mātugāmo = 「女性、(ここでは)妻」
* añño va = 「別の者こそ」
* bhaveyya = 「であったなら」(願望法)
* puttaṃ labheyya = 「子を得るだろう」

→「もし彼の妻が別の女性であったなら、子を得られただろう。」

9. Ubhohi pana samānacchandehi hutvā pāpakammaṃ kataṃ, tenassa putto na nibbattissatīti aññāsi.

* ubhohi = 「二人によって」(具格)
* pana = 「しかし」
* samāna-cchandehi hutvā = 「意向を同じくして」
* pāpa-kammaṃ kataṃ = 「悪業がなされた」
* tenassa = 「それゆえ彼に」(tena assa)
* putto na nibbattissati ti = 「子は生まれないだろう、と」
* aññāsi = 「(世尊は)知った」

→「しかし二人が意向を同じくして悪業をなした。それゆえ彼に子は生まれないだろう、と(世尊は)知った。」

10. Dusse pana akkante – ‘‘buddhānaṃ adhikāraṃ katvā patthitapatthitaṃ labhantīti loke anussavo, mayā ca mahāabhinīhāro kato, na ca puttaṃ labhāmi, tucchaṃ idaṃ vacana’’nti micchāgahaṇaṃ gaṇheyya.

* dusse akkante = 「布が踏まれたなら」(処格絶対節)
  * dussa = 「布」
* pana = 「しかし、ところで」
* buddhānaṃ adhikāraṃ katvā = 「仏たちに奉仕をして」
* patthita-patthitaṃ = 「願ったものを何でも」(反復による配分の意)
* labhanti ti = 「得る、という」
* loke anussavo = 「世間での言い伝え」
* mayā ca mahā-abhinīhāro kato = 「そして私は大きな志願を立てた」
  * abhinīhāra = 「志願、発願」
* na ca puttaṃ labhāmi = 「それなのに子を得ない」
* tucchaṃ idaṃ vacanaṃ = 「この言葉は空しい(中身がない)」
* micchā-gahaṇaṃ gaṇheyya = 「誤った捉え方をするだろう」

→「しかし、もし布が踏まれたなら、(王子は)"仏たちに奉仕をすれば願ったものを何でも得る、というのが世間の言い伝えであり、私も大きな志願を立てたのに、子を得ない。この言葉は空しい"と誤った捉え方をするだろう。」

11. Titthiyāpi – ‘‘natthi samaṇānaṃ akattabbaṃ nāma, celappaṭikaṃ maddantā āhiṇḍantī’’ti ujjhāyeyyuṃ .

* titthiyā pi = 「外道たちも」
* natthi = 「ない」
* samaṇānaṃ = 「沙門たちには」
* akattabbaṃ nāma = 「してはならないことというもの」
* celappaṭikaṃ = 「布の敷物を」
* maddantā = 「踏みつけながら」(現在分詞)
* āhiṇḍanti = 「歩き回っている」
* ujjhāyeyyuṃ = 「非難するだろう」(願望法)

→「外道たちも"沙門たちにはしてはならないことというものがない。布の敷物を踏みつけながら歩き回っている"と非難するだろう。」

12. Etarahi ca akkamantesu bahū bhikkhū paracittaviduno, te bhabbaṃ jānitvā akkamissanti, abhabbaṃ jānitvā na akkamissanti.

* etarahi ca = 「また、今は」
* akkamantesu = 「踏む者たちの中に」(現在分詞、処格複数)
* bahū bhikkhū = 「多くの比丘たちが」
* para-citta-viduno = 「他人の心を知る者」
* te = 「彼らは」
* bhabbaṃ jānitvā = 「可能であると知って」
  * 願いがかなう見込みがあることを指すと解される(文脈からの判断)
* akkamissanti = 「踏むだろう」
* abhabbaṃ jānitvā = 「不可能であると知って」
* na akkamissanti = 「踏まないだろう」

→「また、今は踏む者たちの中に他人の心を知る比丘が多く、彼らは(願いがかなう)見込みがあると知れば踏み、見込みがないと知れば踏まないだろう。」

13. Anāgate pana upanissayo mando bhavissati, anāgataṃ na jānissanti.

* anāgate = 「未来には」
* pana = 「しかし」
* upanissayo = 「素質、(力のもととなる)強い条件」
* mando = 「弱い、鈍い」
* bhavissati = 「なるだろう」
* anāgataṃ = 「未来のことを」
* na jānissanti = 「知らないだろう」

→「しかし未来には(比丘たちの)素質が弱くなり、未来のことを知らないだろう。」

14. Tesu akkamantesu sace patthitaṃ ijjhissati, iccetaṃ kusalaṃ .

* tesu akkamantesu = 「彼らが踏んだとき」(処格絶対節)
* sace = 「もし」
* patthitaṃ = 「願ったこと」
* ijjhissati = 「成就するなら」
* iccetaṃ kusalaṃ = 「それはそれでよい」(iti etaṃ kusalaṃ)

→「彼らが踏んだとき、もし願ったことが成就するなら、それはそれでよい。」

15. No ce ijjhissati, – ‘‘pubbe bhikkhusaṅghassa abhinīhāraṃ katvā icchiticchitaṃ labhanti, taṃ idāni na labhanti .

* no ce ijjhissati = 「もし成就しないなら」
* pubbe = 「以前は」
* bhikkhu-saṅghassa = 「比丘サンガに対して」
* abhinīhāraṃ katvā = 「志願を立てて」
* icchita-icchitaṃ = 「望んだものを何でも」(反復による配分の意)
* labhanti = 「得る」(以前のことを現在形で述べる)
* taṃ idāni na labhanti = 「それを今は得ない」

→「もし成就しないなら、"以前は比丘サンガに志願を立てて、望んだものを何でも得ていた。それを今は得られない。」

16. Teyeva maññe bhikkhū paṭipattipūrakā ahesuṃ, ime paṭipattiṃ pūretuṃ na sakkontī’’ti manussā vippaṭisārino bhavissantīti imehi kāraṇehi bhagavā akkamituṃ anicchanto tuṇhī ahosi.

* te yeva = 「あの(以前の)者たちこそ」
* maññe = 「思うに」
* bhikkhū = 「比丘たちは」
* paṭipatti-pūrakā = 「実践を満たす者」
* ahesuṃ = 「であった」
* ime = 「この(今の)者たちは」
* paṭipattiṃ pūretuṃ na sakkonti = 「実践を満たすことができない」
* ti manussā = 「〜と人々は」
* vippaṭisārino bhavissanti = 「悔やむ者となるだろう」
* ti imehi kāraṇehi = 「〜という、これらの理由によって」
  * 王子の誤った捉え方、外道の非難、未来の人々の悔やみの三つを指す
* akkamituṃ anicchanto = 「踏むことを望まず」
* tuṇhī ahosi = 「沈黙していた」

→「思うに、あの比丘たちこそ実践を満たす者であった。今の比丘たちは実践を満たすことができないのだ"と人々は悔やむことになるだろう。これらの理由によって、世尊は踏むことを望まず、沈黙していた。」

17. Sikkhāpadaṃ paññapesi ‘‘na, bhikkhave, celappaṭikā akkamitabbā’’ti (cūḷava. 268).

* sikkhāpadaṃ = 「学処を」
* paññapesi = 「制定した」
* na ... akkamitabbā = 「踏んではならない」(未来受動分詞)
* bhikkhave = 「比丘たちよ」
* celappaṭikā = 「布の敷物は」
* (cūḷava. 268) = 出典表示(チューラヴァッガ 268)

→「(そして)"比丘たちよ、布の敷物を踏んではならない"と学処を制定した。」

18. Maṅgalatthāya paññattaṃ anakkamantesu pana akkamanatthāya anupaññattiṃ ṭhapesi – ‘‘gihī, bhikkhave, maṅgalikā, anujānāmi, bhikkhave, gihīnaṃ maṅgalatthāyā’’ti (cūḷava. 268).

* maṅgala-atthāya = 「吉祥のために」
* paññattaṃ = 「敷かれたもの(布の敷物)を」
* anakkamantesu = 「(比丘たちが)踏まずにいたとき」(処格絶対節)
* pana = 「しかし」
* akkamana-atthāya = 「踏むことのために、踏めるように」
* anupaññattiṃ = 「追加の制定を」
* ṭhapesi = 「設けた」
* gihī = 「在家者たちは」
* maṅgalikā = 「吉祥を重んじる者」
* anujānāmi = 「私は許可する」
* gihīnaṃ maṅgala-atthāya = 「在家者たちの吉祥のために」
  * 引用は途中で切られており、許可の内容(踏むこと)は直前の akkamanatthāya から補う
* (cūḷava. 268) = 出典表示(チューラヴァッガ 268)

→「しかし、吉祥のために敷かれたものを(比丘たちが)踏まずにいたので、踏めるようにするために追加の制定を設けた。"比丘たちよ、在家者たちは吉祥を重んじる。比丘たちよ、在家者たちの吉祥のために(踏むことを)許可する"と。」

  * ti = 経の語句を取り上げて示す引用の標識
* āpannasattā = 「胎児を宿した女、妊娠している女」(āpanna-sattā)
  * āpanna = 「入った、至った」(āpajjati の過去分詞)
  * satta = 「生き物、衆生」(ここでは胎児)

→「"kucchimatī (身ごもった女)" とは、胎児を宿した女のことである。」

2. Yo me ayaṃ, bhante, kucchigatoti kiṃ panevaṃ saraṇaṃ gahitaṃ hotīti.

* yo me ayaṃ, bhante, kucchigato ti = 「"尊者よ、私のこの胎内にいる者は" という句について」
  * yo = 「〜であるところの者」(関係代名詞)
  * me = 「私の」
  * ayaṃ = 「この」
  * bhante = 「尊者よ」(呼びかけ)
  * kucchigato = 「胎内にいる者」(kucchi = 胎 + gata = 行った、入っている)
* kiṃ pana = 「では〜なのか」(疑問を導く)
* evaṃ = 「このようにして」
  * 母親が胎内の子に代わって帰依を表明するやり方を指す
* saraṇaṃ = 「帰依(処)」
* gahitaṃ = 「受けられた、取られた」(gaṇhāti の過去分詞)
* hoti = 「〜である、〜となる」
* ti = 問いの終わりを示す

→「"尊者よ、私のこの胎内にいる者は" という句について。では、このようにして帰依は受けられたことになるのか。」

3. Na hoti.

* na = 「〜ない」
* hoti = 「〜である、〜となる」

→「ならない。」

4. Acittakasaraṇagamanaṃ nāma natthi, ārakkho panassa paccupaṭṭhitova hoti.

* acittaka-saraṇagamanaṃ = 「心を伴わない帰依」
  * acittaka = 「心(意思)のない」(a- + citta + -ka)
  * saraṇagamana = 「帰依すること」(saraṇa = 帰依処 + gamana = 行くこと)
* nāma = 「〜というもの」
* natthi = 「存在しない」(na + atthi)
* ārakkho = 「守護、保護」
* pana = 「しかし」
* assa = 「その者には」(胎内の子を指す)
* paccupaṭṭhito va = 「まさに現前している、そなわっている」
  * paccupaṭṭhita = 「現前した、そばに立った」(paccupaṭṭhāti の過去分詞)
  * va = eva 「まさに」
* hoti = 「〜である」

→「心を伴わない帰依というものはない。しかし、その者には守護がまさに現前している。」

5. Atha naṃ yadā mahallakakāle mātāpitaro, – ‘‘tāta, kucchigatameva taṃ saraṇaṃ gaṇhāpayimhā’’ti sārenti,

* atha = 「そして、その後」
* naṃ = 「彼を、その者に」
* yadā = 「〜するとき」(後の tadā と呼応)
* mahallaka-kāle = 「大きくなったときに」
  * mahallaka = 「年をとった、年長の」(ここでは文脈から、成長して物事が分かる年齢になったことを指すと判断)
  * kāla = 「時」
* mātāpitaro = 「母と父が、両親が」
* tāta = 「わが子よ」(親しい呼びかけ)
* kucchigatam eva = 「胎内にいるうちに、まさに胎内にいるお前を」
* taṃ = 「お前を」
* saraṇaṃ = 「帰依を」
* gaṇhāpayimhā = 「私たちは受けさせた」(gaṇhāpeti = gaṇhāti の使役、アオリスト 1 人称複数)
* ti = 引用の終わり
* sārenti = 「思い出させる」(sāreti = sarati の使役、3 人称複数)

→「その後、彼が大きくなったときに、両親が "わが子よ、お前がまだ胎内にいるうちに、私たちはお前に帰依を受けさせたのだ" と思い出させ、」

6. so ca sallakkhetvā ‘‘ahaṃ saraṇaṃ gato upāsako’’ti satiṃ uppādeti, tadā saraṇaṃ gahitaṃ nāma hoti.

* so ca = 「そして彼が」
* sallakkhetvā = 「よく考えて、そのことを認めて」(sallakkheti の連続体)
* ahaṃ = 「私は」
* saraṇaṃ gato = 「帰依した(者)」
  * gata = 「行った」(gacchati の過去分詞)
* upāsako = 「在家信者」
* ti = 引用の終わり
* satiṃ = 「念を、自覚を」
* uppādeti = 「起こす、生じさせる」(uppajjati の使役)
* tadā = 「そのとき」(yadā と呼応)
* saraṇaṃ gahitaṃ nāma hoti = 「帰依が受けられたということになる」
  * nāma = 「〜ということ、〜と呼ばれる」

→「そして彼がそのことをよく考えて "私は帰依した在家信者である" という念を起こすとき、そのときに帰依は受けられたことになる。」

7. Sesaṃ sabbattha uttānamevāti.

* sesaṃ = 「残りは」
* sabbattha = 「すべての箇所で」
* uttānam eva = 「まさに明白である」
  * uttāna = 「明らかな、平易な」
* ti = 註釈の結びを示す

→「残りはすべての箇所で明白である。」

8. Papañcasūdaniyā majjhimanikāyaṭṭhakathāya

* Papañcasūdaniyā = 「パパンチャスーダニーにおける」(Papañcasūdanī の単数、majjhimanikāyaṭṭhakathāya と同格)
* majjhimanikāya-aṭṭhakathāya = 「マッジマ・ニカーヤの註釈書における」
  * majjhimanikāya = 「マッジマ・ニカーヤ(中部)」
  * aṭṭhakathā = 「註釈書」

→「マッジマ・ニカーヤの註釈書であるパパンチャスーダニーにおける」

9. Bodhirājakumārasuttavaṇṇanā niṭṭhitā.

* Bodhirājakumāra-sutta-vaṇṇanā = 「ボーディラージャクマーラ経の解説」
  * Bodhirājakumāra = 「ボーディ王子」(rājakumāra = 王子)
  * sutta = 「経」
  * vaṇṇanā = 「解説、註釈」
* niṭṭhitā = 「終わった、完結した」(niṭṭhāti の過去分詞、女性形)

→「ボーディラージャクマーラ経の解説が終わった。」
