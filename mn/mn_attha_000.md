# Ganthārambhakathā

## 0 (1)

Karuṇāsītalahadayaṃ , paññāpajjotavihatamohatamaṃ;

Sanarāmaralokagaruṃ, vande sugataṃ gativimuttaṃ.

Buddhopi buddhabhāvaṃ, bhāvetvā ceva sacchikatvā ca;

Yaṃ upagato gatamalaṃ, vande tamanuttaraṃ dhammaṃ.

Sugatassa orasānaṃ, puttānaṃ mārasenamathanānaṃ;

Aṭṭhannampi samūhaṃ, sirasā vande ariyasaṅghaṃ.

### 対訳

1. Ganthārambhakathā

* gantha-ārambha-kathā = 「書物の書き始めの話」
  * gantha = 「書物、著作」
  * ārambha = 「開始、着手」
  * kathā = 「話、論述」

→「著述開始の話(序偈)」

2. Karuṇāsītalahadayaṃ , paññāpajjotavihatamohatamaṃ;

* karuṇā-sītala-hadayaṃ = 「悲によって涼やかな心をもつ方を」(sugataṃ にかかる所有複合語、対格)
  * karuṇā = 「悲、あわれみ」
  * sītala = 「涼しい、冷ややかな」
  * hadaya = 「心、心臓」
* paññā-pajjota-vihata-moha-tamaṃ = 「智慧の灯火によって痴の闇を打ち破った方を」(同じく sugataṃ にかかる)
  * paññā = 「智慧」
  * pajjota = 「灯火、光明」
  * vihata = 「打ち破られた、除かれた」(vihanati の過去分詞)
  * moha = 「痴、迷い」
  * tama = 「闇」

→「悲によって心が涼やかであり、智慧の灯火によって痴の闇を打ち破った方、」

3. Sanarāmaralokagaruṃ, vande sugataṃ gativimuttaṃ.

* sa-nara-amara-loka-garuṃ = 「人間と神々を含む世界の師を」
  * sa- = 「〜を伴う、〜を含む」
  * nara = 「人間」
  * amara = 「不死の者、すなわち神」
  * loka = 「世界、世間」
  * garu = 「重んじられる者、師」
* vande = 「私は礼拝する」(vandati の現在・一人称単数)
* sugataṃ = 「善逝を」(よく行った方、仏の称号)
* gati-vimuttaṃ = 「趣から解脱した方を」
  * gati = 「趣、生まれ変わる先の境遇」
  * vimutta = 「解脱した、離れた」(vimuccati の過去分詞)
  * sugata と gati で gata / gati の音を重ねている

→「人間と神々を含む世界の師であり、趣から解脱した善逝を、私は礼拝する。」

4. Buddhopi buddhabhāvaṃ, bhāvetvā ceva sacchikatvā ca;

* buddho pi = 「仏陀でさえも」
* buddha-bhāvaṃ = 「仏であることに、仏の境地に」(次行の upagato の目的語)
  * bhāva = 「〜であること、状態」
* bhāvetvā = 「修習して」(bhāveti の連続体)
  * 目的語は次行の yaṃ(法)
* ceva ... ca = 「〜もし、また〜もして」
* sacchikatvā = 「現証して、目の当たりにして」(sacchikaroti の連続体)
  * 目的語は同じく yaṃ(法)

→「仏陀でさえも、(それを)修習し、また現証して、仏であることに」

5. Yaṃ upagato gatamalaṃ, vande tamanuttaraṃ dhammaṃ.

* yaṃ = 「それを」(関係代名詞、対格。bhāvetvā と sacchikatvā の目的語で、後の taṃ ... dhammaṃ と呼応)
* upagato = 「到達した」(upagacchati の過去分詞、主語は buddho)
* gata-malaṃ = 「垢の去った、垢を離れた」(dhammaṃ にかかる)
  * gata = 「去った」
  * mala = 「垢、汚れ」
* vande = 「私は礼拝する」
* tam anuttaraṃ = 「その無上の」
  * anuttara = 「この上ない」(an-uttara)
* dhammaṃ = 「法を」

→「仏陀でさえも、それを修習し、また現証して仏であることに到達した、その垢を離れた無上の法を、私は礼拝する。」

6. Sugatassa orasānaṃ, puttānaṃ mārasenamathanānaṃ;

* sugatassa = 「善逝の」(属格)
* orasānaṃ = 「胸から生まれた、実の」(属格複数、puttānaṃ にかかる)
  * orasa = 「胸(ura)から生まれた、自分自身の(子)」
* puttānaṃ = 「子たちの」(属格複数)
* māra-sena-mathanānaṃ = 「魔の軍勢を打ち砕く者たちの」(属格複数、puttānaṃ と同格)
  * māra = 「魔、マーラ」
  * senā = 「軍勢」
  * mathana = 「打ち砕くこと、打ち砕く者」

→「善逝の実の子であり、魔の軍勢を打ち砕く者たちである、」

7. Aṭṭhannampi samūhaṃ, sirasā vande ariyasaṅghaṃ.

* aṭṭhannam pi = 「八つ(八種の者)すべての」(aṭṭha の属格複数 + pi)
  * 四つの道と四つの果に立つ八種の聖者を指すと文脈から判断
* samūhaṃ = 「集まりを」(対格、ariyasaṅghaṃ と同格)
* sirasā = 「頭で、頭を下げて」(sira の具格)
* vande = 「私は礼拝する」
* ariya-saṅghaṃ = 「聖なるサンガを」
  * ariya = 「聖なる、聖者の」
  * saṅgha = 「サンガ、僧団」

→「善逝の実の子であり、魔の軍勢を打ち砕く者たちである八種の者すべての集まり、その聖なるサンガを、私は頭を下げて礼拝する。」

## 0 (2)

Iti me pasannamatino, ratanattayavandanāmayaṃ puññaṃ;

Yaṃ suvihatantarāyo, hutvā tassānubhāvena.

Majjhimapamāṇasuttaṅkitassa idha majjhimāgamavarassa;

Buddhānubuddhasaṃvaṇṇitassa paravādamathanassa.

Atthappakāsanatthaṃ, aṭṭhakathā ādito vasisatehi;

Pañcahi yā saṅgītā, anusaṅgītā ca pacchāpi.

Sīhaḷadīpaṃ pana ābhatātha vasinā mahāmahindena;

Ṭhapitā sīhaḷabhāsāya, dīpavāsīnamatthāya.

Apanetvāna tatohaṃ, sīhaḷabhāsaṃ manoramaṃ bhāsaṃ;

Tantinayānucchavikaṃ, āropento vigatadosaṃ.

Samayaṃ avilomento, therānaṃ theravaṃsadīpānaṃ;

Sunipuṇavinicchayānaṃ, mahāvihāre nivāsīnaṃ.

Hitvā punappunāgatamatthaṃ, atthaṃ pakāsayissāmi;

Sujanassa ca tuṭṭhatthaṃ, ciraṭṭhitatthañca dhammassa.

### 対訳

1. Iti me pasannamatino, ratanattayavandanāmayaṃ puññaṃ;

* iti = 「このように」
  * 直前の三偈(仏・法・僧への礼拝)を受ける
* me = 「私の、私に」(属格)
* pasannamatino = 「清らかに信じる心をもつ(者の)」(pasanna-mati、単数属格で me にかかる)
  * pasanna = 「澄んだ、信じて清らかな」
  * mati = 「心、思い」
* ratanattaya-vandanā-mayaṃ = 「三宝への礼拝から成る」
  * ratanattaya = 「三つの宝(仏・法・僧)」
  * vandanā = 「礼拝」
  * -maya = 「〜から成る、〜でできた」
* puññaṃ = 「福徳」

→「このように清らかな信の心をもつ私に、三宝への礼拝から成る福徳が(生じた)。」

2. Yaṃ suvihatantarāyo, hutvā tassānubhāvena.

* yaṃ = 「それ(その福徳)であるところの」(関係代名詞、前行の puññaṃ を受ける)
* suvihatantarāyo = 「障害をよく打ち破られた者」(su-vihata-antarāyo)
  * su = 「よく」
  * vihata = 「打ち破られた」
  * antarāya = 「障害、妨げ」
* hutvā = 「〜となって」
* tassānubhāvena = 「その威力によって」(tassa + ānubhāvena)
  * tassa = 「その(福徳の)」
  * ānubhāva = 「威力、力」
  * 主語は "ahaṃ"(私)で、第 13 行の pakāsayissāmi まで文が続く

→「その(福徳の)威力によって、障害をよく打ち破られた者となって、」

3. Majjhimapamāṇasuttaṅkitassa idha majjhimāgamavarassa;

* majjhima-pamāṇa-sutta-aṅkitassa = 「中くらいの長さの経によって特徴づけられた」(属格)
  * majjhima = 「中くらいの」
  * pamāṇa = 「量、長さ」
  * sutta = 「経」
  * aṅkita = 「しるしを付けられた、特徴づけられた」
* idha = 「ここで」
* majjhimāgama-varassa = 「すぐれたマッジマ・アーガマ(中くらいの経を集めた聖典)の」(属格)
  * āgama = 「伝えられた聖典、アーガマ」
  * vara = 「すぐれた」
  * 属格は第 5 行の atthappakāsanatthaṃ("意味を明らかにするために")にかかる

→「ここで、中くらいの長さの経によって特徴づけられる、すぐれたマッジマ・アーガマの、」

4. Buddhānubuddhasaṃvaṇṇitassa paravādamathanassa.

* buddha-anubuddha-saṃvaṇṇitassa = 「ブッダと、ブッダにならって覚った者たちによって称賛された」(属格)
  * buddha = 「ブッダ」
  * anubuddha = 「(ブッダに)続いて覚った者、すなわち弟子たち」
  * saṃvaṇṇita = 「称賛された」または「解説された」(どちらの意味かは要確認)
* paravāda-mathanassa = 「他者の説を打ち砕く」(属格)
  * paravāda = 「他者の説、異論」
  * mathana = 「打ち砕くこと、打ち砕くもの」

→「ブッダとそれに続いて覚った者たちに称賛され、他者の説を打ち砕く(そのアーガマの)、」

5. Atthappakāsanatthaṃ, aṭṭhakathā ādito vasisatehi;

* attha-ppakāsana-atthaṃ = 「意味を明らかにするために」
  * attha = 「意味」
  * pakāsana = 「明らかにすること」
  * -atthaṃ = 「〜のために」
* aṭṭhakathā = 「註釈(アッタカター)」(女性・主格)
* ādito = 「最初に」
* vasi-satehi = 「自在を得た者たちの百(複数)によって」(具格)
  * vasī = 「自在を得た者、(心を)制御した者」
  * sata = 「百」
  * 次行の pañcahi と結んで「五百人の自在者によって」

→「意味を明らかにするために、註釈は最初に(五)百人の自在者たちによって」

6. Pañcahi yā saṅgītā, anusaṅgītā ca pacchāpi.

* pañcahi = 「五つの(百)によって」(前行の vasisatehi にかかる)
* yā = 「〜であるところの(註釈)」(関係代名詞、女性・主格)
* saṅgītā = 「合誦された」
* anusaṅgītā = 「重ねて合誦された」
  * anu = 「続いて、重ねて」
* ca = 「そして」
* pacchāpi = 「後にもまた」(pacchā + api)

→「合誦され、後にもまた重ねて合誦された、その(註釈は)、」

7. Sīhaḷadīpaṃ pana ābhatātha vasinā mahāmahindena;

* Sīhaḷadīpaṃ = 「シーハラ島へ」(対格)
* pana = 「さて、そして」
* ābhatātha = 「もたらされ、それから」(ābhatā + atha)
  * ābhatā = 「運ばれた、もたらされた」(女性・主格、aṭṭhakathā にかかる)
  * atha = 「それから」
* vasinā = 「自在を得た者である」(具格)
* mahāmahindena = 「マハーマヒンダによって」(具格)

→「さて、自在を得たマハーマヒンダによってシーハラ島へもたらされ、それから」

8. Ṭhapitā sīhaḷabhāsāya, dīpavāsīnamatthāya.

* ṭhapitā = 「置かれた、定め置かれた」(女性・主格)
* sīhaḷabhāsāya = 「シーハラ語で」
  * bhāsā = 「言葉、言語」
* dīpavāsīnamatthāya = 「島の住民たちのために」(dīpavāsīnaṃ + atthāya)
  * dīpa = 「島」
  * vāsī = 「住む者」
  * atthāya = 「〜のために、利益のために」

→「島の住民たちのために、シーハラ語で定め置かれた。」

9. Apanetvāna tatohaṃ, sīhaḷabhāsaṃ manoramaṃ bhāsaṃ;

* apanetvāna = 「取り除いて」(連続体)
* tatohaṃ = 「そこから私は」(tato + ahaṃ)
  * tato = 「そこから(その註釈から)」
  * ahaṃ = 「私は」
* sīhaḷabhāsaṃ = 「シーハラ語を」(apanetvāna の目的語)
* manoramaṃ = 「心地よい、心を喜ばせる」
* bhāsaṃ = 「言葉を」(次行の āropento の目的語)

→「私はそこからシーハラ語を取り除いて、心地よい言葉、」

10. Tantinayānucchavikaṃ, āropento vigatadosaṃ.

* tanti-naya-anucchavikaṃ = 「聖典の方式にふさわしい」(bhāsaṃ にかかる)
  * tanti = 「聖典、聖典の本文」
  * naya = 「方式、やり方」
  * anucchavika = 「ふさわしい、適した」
* āropento = 「載せながら、移しながら」(現在分詞、主格)
  * 註釈を別の言葉へ移すこと
* vigata-dosaṃ = 「欠点のない」(bhāsaṃ にかかる)
  * vigata = 「離れ去った」
  * dosa = 「欠点、過失」

→「聖典の方式にふさわしく欠点のない(言葉)へと移しながら、」

11. Samayaṃ avilomento, therānaṃ theravaṃsadīpānaṃ;

* samayaṃ = 「定説、教えの立場を」(対格)
* avilomento = 「逆らわず、背かずに」(現在分詞、主格)
  * a + vilomento(viloma = 「逆の、反する」)
* therānaṃ = 「長老たちの」(属格、samayaṃ にかかる)
* thera-vaṃsa-dīpānaṃ = 「長老の系譜の灯火である」(属格)
  * vaṃsa = 「系譜、伝統」
  * dīpa = 「灯火」(ここでは「島」ではなく「灯火」の意と判断)

→「長老の系譜の灯火である長老たち、」

12. Sunipuṇavinicchayānaṃ, mahāvihāre nivāsīnaṃ.

* su-nipuṇa-vinicchayānaṃ = 「きわめて精緻な判定をもつ」(属格、therānaṃ にかかる)
  * su = 「よく、きわめて」
  * nipuṇa = 「精緻な、巧みな」
  * vinicchaya = 「判定、決定」
* mahāvihāre = 「マハーヴィハーラに」(処格)
* nivāsīnaṃ = 「住む者たちの」(属格)

→「きわめて精緻な判定をもち、マハーヴィハーラに住む(長老たち)の定説に背かずに、」

13. Hitvā punappunāgatamatthaṃ, atthaṃ pakāsayissāmi;

* hitvā = 「捨てて、省いて」(連続体)
* punappunāgatamatthaṃ = 「繰り返し出てくる意味(内容)を」(punappuna + āgataṃ + atthaṃ)
  * punappuna = 「繰り返し」
  * āgata = 「来た、出てきた」
* atthaṃ = 「意味を」
* pakāsayissāmi = 「(私は)明らかにしよう」(未来・一人称単数)
  * 第 1 行から続く文の主動詞

→「繰り返し出てくる内容は省いて、(私は)意味を明らかにしよう。」

14. Sujanassa ca tuṭṭhatthaṃ, ciraṭṭhitatthañca dhammassa.

* sujanassa = 「善き人々の」(属格)
  * su + jana = 「善い人」
* ca ... ca = 「〜と〜と」
* tuṭṭhatthaṃ = 「満足のために」(tuṭṭhi + atthaṃ)
  * tuṭṭhi = 「満足、喜び」
* ciraṭṭhitatthañca = 「また長く存続するために」(ciraṭṭhiti + atthaṃ + ca)
  * cira = 「長い間」
  * ṭhiti = 「存続、とどまること」
* dhammassa = 「法の」(属格)

→「善き人々の満足のために、また法が長く存続するために。」

## 0 (3)

Sīlakathā dhutadhammā, kammaṭṭhānāni ceva sabbāni;

Cariyāvidhānasahito, jhānasamāpattivitthāro.

Sabbā ca abhiññāyo, paññāsaṅkalananicchayo ceva;

Khandhādhātāyatanindriyāni ariyāni ceva cattāri.

Saccāni paccayākāradesanā suparisuddhanipuṇanayā;

Avimuttatantimaggā, vipassanābhāvanā ceva.

Iti pana sabbaṃ yasmā, visuddhimagge mayā suparisuddhaṃ;

Vuttaṃ tasmā bhiyyo, na taṃ idha vicārayissāmi.

‘‘Majjhe visuddhimaggo, esa catunnampi āgamānañhi;

Ṭhatvā pakāsayissati, tattha yathābhāsitamatthaṃ’’.

Icceva kato tasmā, tampi gahetvāna saddhimetāya;

Aṭṭhakathāya vijānatha, majjhimasaṅgītiyā atthanti.

### 対訳

1. Sīlakathā dhutadhammā, kammaṭṭhānāni ceva sabbāni;

* sīla-kathā = 「戒についての論」
  * sīla = 「戒」
  * kathā = 「論、話」
* dhuta-dhammā = 「頭陀の諸法」(複数主格)
  * dhuta = 「払い落とした、(煩悩を)振り払う修行」
  * dhamma = 「法、事項」
* kammaṭṭhānāni = 「諸々の業処」(複数主格)
* ceva = ca + eva 「また、そして」
* sabbāni = 「すべての」(kammaṭṭhānāni にかかる)
* 以下 6 行目まで、主格の項目の列挙が続き、7 行目の "iti pana sabbaṃ"(これらすべて)で受けられる。

→「戒についての論、頭陀の諸法、そしてすべての業処、」

2. Cariyāvidhānasahito, jhānasamāpattivitthāro.

* cariyā-vidhāna-sahito = 「性行の規定を伴った」(jhānasamāpattivitthāro にかかる)
  * cariyā = 「性行、気質(行者の性格の型)」
  * vidhāna = 「規定、取り決め、整理」
  * sahita = 「伴った、ともにある」
* jhāna-samāpatti-vitthāro = 「禅と等至の詳しい説明」(単数主格)
  * jhāna = 「禅」
  * samāpatti = 「等至」
  * vitthāra = 「詳説、詳しい説明」

→「性行の規定を伴った、禅と等至の詳しい説明、」

3. Sabbā ca abhiññāyo, paññāsaṅkalananicchayo ceva;

* sabbā = 「すべての」(abhiññāyo にかかる)
* ca = 「また」
* abhiññāyo = 「諸々の神通(証智)」(abhiññā の複数主格)
* paññā-saṅkalana-nicchayo = 「慧をまとめて示す判定」(単数主格)
  * paññā = 「慧」
  * saṅkalana = 「まとめること、総括」
  * nicchaya = 「判定、決定」
* ceva = 「そしてまた」

→「またすべての神通、そして慧をまとめて示す判定、」

4. Khandhādhātāyatanindriyāni ariyāni ceva cattāri.

* khandhā-dhātāyatanindriyāni = 「蘊・界・処・根」(複数主格)
  * khandha = 「蘊」
  * dhātu = 「界」
  * āyatana = 「処」
  * indriya = 「根」
  * khandhā- の長音は韻律上のものとみられる(要確認)
