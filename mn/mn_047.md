1. 7. Vīmaṃsakasuttaṃ

* vīmaṃsaka-sutta = 「考察者経」
  * vīmaṃsaka = 「考察する者、吟味する者」（vīmaṃsati「考察する、吟味する」から）
  * sutta = 「経」

→「考察者経」

2. 487. Evaṃ me sutaṃ –

* evaṃ = 「このように」
* me = 「私によって」
* sutaṃ = 「聞かれた（suṇāti の過去分詞）」

→「このように私は聞いた。」

3. ekaṃ samayaṃ bhagavā sāvatthiyaṃ viharati jetavane anāthapiṇḍikassa ārāme.

* ekaṃ samayaṃ = 「ある時」
* bhagavā = 「世尊は」
* sāvatthiyaṃ = 「サーヴァッティーにおいて」
* viharati = 「住んでいる」
* jetavane = 「ジェータ林において」
* anāthapiṇḍikassa ārāme = 「アナータピンディカの園において」

→「ある時、世尊はサーヴァッティーのジェータ林、アナータピンディカの園に住んでいた。」

4. Tatra kho bhagavā bhikkhū āmantesi – ‘‘bhikkhavo’’ti.

* tatra kho = 「そこで」
* bhagavā = 「世尊は」
* bhikkhū = 「比丘たちに」
* āmantesi = 「呼びかけた（āmanteti のアオリスト）」
* bhikkhavo ti = 「『比丘たちよ』と」

→「そこで世尊は比丘たちに『比丘たちよ』と呼びかけた。」

5. ‘‘Bhadante’’ti te bhikkhū bhagavato paccassosuṃ.

* bhadante ti = 「『尊師よ』と」
* te bhikkhū = 「その比丘たちは」
* bhagavato = 「世尊に」
* paccassosuṃ = 「応答した（paṭi-suṇāti のアオリスト、三人称複数）」

→「その比丘たちは世尊に『尊師よ』と応答した。」

6. Bhagavā etadavoca –

* bhagavā = 「世尊は」
* etad avoca = 「このことを言った」
  * etad = 「これを」
  * avoca = 「言った（vatti のアオリスト）」

→「世尊はこう言った。」

7. ‘‘vīmaṃsakena, bhikkhave, bhikkhunā parassa cetopariyāyaṃ ajānantena [ājānantena (pī. ka.), ajānantena kinti (?)] tathāgate samannesanā kātabbā ‘sammāsambuddho vā no vā’ iti viññāṇāyā’’ti.

* vīmaṃsakena bhikkhunā = 「考察する比丘によって」
  * vīmaṃsaka = 「考察する者、吟味する者」
* bhikkhave = 「比丘たちよ」
* parassa = 「他人の」
* ceto-pariyāyaṃ = 「心の様相を、心の在り方を」
  * ceto = 「心」
  * pariyāya = 「様相、在り方、次第」
* ajānantena = 「知らない（者）によって」
  * a + jānanta（jānāti の現在分詞）
  * 異読 ājānantena = 「了知する（者）によって」（本文は ajānantena「知らない」を採る）
* tathāgate = 「如来について（処格）」
* samannesanā = 「調査、探究」
  * saṃ + anu + esanā（esati「探し求める」から）
* kātabbā = 「なされるべきである（karoti の未来受動分詞、女性形）」
* sammāsambuddho vā no vā iti = 「『正等覚者であるか、そうでないか』と」
* viññāṇāya = 「知るために（vijānāti の不定詞、与格的用法）」

→「比丘たちよ、他人の心の様相を知らない考察者である比丘は、『正等覚者であるか、そうでないか』と知るために、如来について調査をなすべきである。」

8. ‘‘Bhagavaṃmūlakā no, bhante, dhammā, bhagavaṃnettikā bhagavaṃpaṭisaraṇā;

* bhante = 「尊師よ」

→「尊師よ、私たちの諸々の教えは世尊を根本とし、世尊を導き手とし、世尊を依りどころとしています。」

9. sādhu vata, bhante, bhagavantaṃyeva paṭibhātu etassa bhāsitassa attho;

* sādhu vata = 「実によいことです、どうか」
* bhante = 「尊師よ」
* bhagavantaṃ yeva = 「世尊にこそ」
* paṭibhātu = 「明らかになりますように（paṭibhāti の命令法）」
  * paṭibhāti = 「（意味が）明らかになる、思い浮かぶ」
* etassa bhāsitassa = 「この言葉の」
* attho = 「意味が」

→「尊師よ、どうかこの言葉の意味は世尊にこそ明らかになりますように。」

10. bhagavato sutvā bhikkhū dhāressantī’’ti.

* bhagavato = 「世尊から」
* sutvā = 「聞いて（suṇāti の連続体）」
* bhikkhū = 「比丘たちは」
* dhāressanti = 「保持するでしょう（dhāreti の未来形、三人称複数）」

→「比丘たちは世尊から聞いて保持するでしょう。」

11. ‘‘Tena hi, bhikkhave, suṇātha, sādhukaṃ manasi karotha, bhāsissāmī’’ti.

* tena hi = 「それでは」
* bhikkhave = 「比丘たちよ」

* sādhukaṃ = 「よく」
* manasi karotha = 「注意しなさい、心にとどめなさい」
  * manasi karoti = 「作意する、注意を向ける」
* bhāsissāmi = 「私は語ろう（bhāsati の未来形、一人称単数）」

→「それでは比丘たちよ、聞きなさい。よく注意しなさい。私は語ろう。」

12. ‘‘Evaṃ, bhante’’ti kho te bhikkhū bhagavato paccassosuṃ.

* evaṃ bhante ti = 「『はい、尊師よ』と」

* paccassosuṃ = 「応答した」

→「その比丘たちは世尊に『はい、尊師よ』と応答した。」

* bhagavā = 「世尊は」

### 対訳

1. 488. ‘‘Vīmaṃsakena, bhikkhave, bhikkhunā parassa cetopariyāyaṃ ajānantena dvīsu dhammesu tathāgato samannesitabbo cakkhusotaviññeyyesu dhammesu –

* vīmaṃsakena = 「考察する、調べる（比丘）によって」（vīmaṃsaka の具格）
  * vīmaṃsaka = 「考察者、吟味する者」（vīmaṃsati「考察する」から）
* bhikkhave = 「比丘たちよ」（呼格）
* bhikkhunā = 「比丘によって」（具格。samannesitabbo の動作主）
* parassa = 「他者の」（属格）
* cetopariyāyaṃ = 「心の行相を、心の在り方を」（対格）
  * ceto-pariyāya = 「心（ceto）の行相・成り行き（pariyāya）」。他心通で知られる対象
* ajānantena = 「知らない（者）によって」（a + jānanta の具格。vīmaṃsakena bhikkhunā に一致）
* dvīsu dhammesu = 「二つの法において」（処格）
* tathāgato = 「如来は」（主格。samannesitabbo の主語）
* samannesitabbo = 「調べられるべきである、吟味されるべきである」（samannesati の未来受動分詞）
  * saṃ + anu + esati（√is「求める」）
* cakkhusotaviññeyyesu dhammesu = 「眼と耳によって識られる法において」（処格。dvīsu dhammesu の言い換え）
  * cakkhu-sota-viññeyya = 「眼（cakkhu）と耳（sota）によって識られるべき（viññeyya）」

→「比丘たちよ、考察する比丘は、他者の心の行相を知らないなら、二つの法において、すなわち眼と耳によって識られる法において、如来を調べるべきである――」

2. ‘ye saṃkiliṭṭhā cakkhusotaviññeyyā dhammā, saṃvijjanti vā te tathāgatassa no vā’ti?

* ye ... dhammā = 「～である諸法は」（関係代名詞 ye、主格複数）
* saṃkiliṭṭhā = 「汚れた、雑染の」（saṃkilissati の過去分詞）
* cakkhusotaviññeyyā = 「眼と耳によって識られる」
* saṃvijjanti = 「存在する、見いだされる」（saṃ + vindati の受動）
* vā ... no vā = 「～か、それとも～でないか」
* te = 「それらは」（ye を受ける）
* tathāgatassa = 「如来に」（属格。所有を表す）
* ti = 「と（考えて）」（引用の終わり）

→「『眼と耳によって識られる汚れた諸法は、如来に存在するのか、それとも存在しないのか』と。」

3. Tamenaṃ samannesamāno evaṃ jānāti – ‘ye saṃkiliṭṭhā cakkhusotaviññeyyā dhammā, na te tathāgatassa saṃvijjantī’ti.

* tamenaṃ = 「その彼を」（taṃ + enaṃ。如来を指す）
* samannesamāno = 「調べつつ」（samannesati の現在分詞、主格）
* evaṃ jānāti = 「このように知る」
* na te tathāgatassa saṃvijjanti = 「それらは如来に存在しない」
* ti = 「と」

→「その彼を調べつつ、このように知る――『眼と耳によって識られる汚れた諸法は、如来に存在しない』と。」

4. ‘‘Yato naṃ samannesamāno evaṃ jānāti – ‘ye saṃkiliṭṭhā cakkhusotaviññeyyā dhammā, na te tathāgatassa saṃvijjantī’ti, tato naṃ uttariṃ samannesati –

* yato = 「～するときに、～することによって」（関係副詞。tato と呼応）
* naṃ = 「彼を」（如来を指す）
* samannesamāno evaṃ jānāti = 「調べつつこのように知る」
* tato = 「そのとき、それによって」（yato と呼応）
* uttariṃ = 「さらに、より上に」（副詞）
* samannesati = 「調べる」

→「彼を調べつつ『眼と耳によって識られる汚れた諸法は、如来に存在しない』とこのように知るとき、それから彼をさらに調べる――」

5. ‘ye vītimissā cakkhusotaviññeyyā dhammā, saṃvijjanti vā te tathāgatassa no vā’ti?

* vītimissā = 「混じった、混合した」（vi + ati + missa）
  * 註では黒白の混じった法、すなわち汚れたものと清浄なものが混在する状態とされる（要確認）
* saṃvijjanti vā te tathāgatassa no vā = 「それらは如来に存在するのか、存在しないのか」

→「『眼と耳によって識られる混じった諸法は、如来に存在するのか、それとも存在しないのか』と。」

6. Tamenaṃ samannesamāno evaṃ jānāti – ‘ye vītimissā cakkhusotaviññeyyā dhammā, na te tathāgatassa saṃvijjantī’ti.

* tamenaṃ samannesamāno evaṃ jānāti = 「その彼を調べつつ、このように知る」
* na te tathāgatassa saṃvijjanti = 「それらは如来に存在しない」

→「その彼を調べつつ、このように知る――『眼と耳によって識られる混じった諸法は、如来に存在しない』と。」

7. ‘‘Yato naṃ samannesamāno evaṃ jānāti – ‘ye vītimissā cakkhusotaviññeyyā dhammā, na te tathāgatassa saṃvijjantī’ti, tato naṃ uttariṃ samannesati –

* yato ... tato = 「～するとき、それから」
* uttariṃ samannesati = 「さらに調べる」

→「彼を調べつつ『眼と耳によって識られる混じった諸法は、如来に存在しない』とこのように知るとき、それから彼をさらに調べる――」

8. ‘ye vodātā cakkhusotaviññeyyā dhammā, saṃvijjanti vā te tathāgatassa no vā’ti?

* vodātā = 「清浄な、白い、浄化された」（vi + avadāta）
* saṃvijjanti vā te tathāgatassa no vā = 「それらは如来に存在するのか、存在しないのか」

→「『眼と耳によって識られる清浄な諸法は、如来に存在するのか、それとも存在しないのか』と。」

9. Tamenaṃ samannesamāno evaṃ jānāti – ‘ye vodātā cakkhusotaviññeyyā dhammā, saṃvijjanti te tathāgatassā’ti.

* saṃvijjanti te tathāgatassa = 「それらは如来に存在する」（肯定）
  * tathāgatassā ti = tathāgatassa + iti（連声で母音が長くなる）

→「その彼を調べつつ、このように知る――『眼と耳によって識られる清浄な諸法は、如来に存在する』と。」

10. ‘‘Yato naṃ samannesamāno evaṃ jānāti – ‘ye vodātā cakkhusotaviññeyyā dhammā, saṃvijjanti te tathāgatassā’ti, tato naṃ uttariṃ samannesati –

* yato ... tato = 「～するとき、それから」
* uttariṃ samannesati = 「さらに調べる」

→「彼を調べつつ『眼と耳によって識られる清浄な諸法は、如来に存在する』とこのように知るとき、それから彼をさらに調べる――」

11. ‘dīgharattaṃ samāpanno ayamāyasmā imaṃ kusalaṃ dhammaṃ, udāhu ittarasamāpanno’ti?

* dīgharattaṃ = 「長い間、長夜に」（副詞的対格）
  * dīgha-ratta = 「長い（dīgha）夜（ratta）」から「長期間」
* samāpanno = 「具えた、達した、入った」（samāpajjati の過去分詞、主格）
* ayamāyasmā = 「この尊者は」（ayaṃ + āyasmā）
* imaṃ kusalaṃ dhammaṃ = 「この善なる法を」（対格。samāpanno の目的語）
* udāhu = 「それとも」
* ittarasamāpanno = 「短期間だけ具えた（者）」
  * ittara = 「短い、わずかな、一時的な」

→「『この尊者は、この善なる法を長い間具えているのか、それとも短期間だけ具えているのか』と。」

12. Tamenaṃ samannesamāno evaṃ jānāti – ‘dīgharattaṃ samāpanno ayamāyasmā imaṃ kusalaṃ dhammaṃ, nāyamāyasmā ittarasamāpanno’ti.

* tamenaṃ samannesamāno evaṃ jānāti = 「その彼を調べつつ、このように知る」
* dīgharattaṃ samāpanno ayamāyasmā imaṃ kusalaṃ dhammaṃ = 「この尊者はこの善なる法を長い間具えている」
* nāyamāyasmā = 「この尊者は～ではない」（na + ayaṃ + āyasmā）
* ittarasamāpanno = 「短期間だけ具えた者」

→「その彼を調べつつ、このように知る――『この尊者は、この善なる法を長い間具えている。この尊者は短期間だけ具えた者ではない』と。」

## 488 (2)

‘‘Yato naṃ samannesamāno evaṃ jānāti – ‘dīgharattaṃ samāpanno ayamāyasmā imaṃ kusalaṃ dhammaṃ, nāyamāyasmā ittarasamāpanno’ti, tato naṃ uttariṃ samannesati – ‘ñattajjhāpanno ayamāyasmā bhikkhu yasappatto, saṃvijjantassa idhekacce ādīnavā’ti? Na tāva, bhikkhave, bhikkhuno idhekacce ādīnavā saṃvijjanti yāva na ñattajjhāpanno hoti yasappatto. Yato ca kho, bhikkhave, bhikkhu ñattajjhāpanno hoti yasappatto , athassa idhekacce ādīnavā saṃvijjanti. Tamenaṃ samannesamāno evaṃ jānāti – ‘ñattajjhāpanno ayamāyasmā bhikkhu yasappatto, nāssa idhekacce ādīnavā saṃvijjantī’ti.

‘‘Yato naṃ samannesamāno evaṃ jānāti – ‘ñattajjhāpanno ayamāyasmā bhikkhu yasappatto, nāssa idhekacce ādīnavā saṃvijjantī’ti, tato naṃ uttariṃ samannesati – ‘abhayūparato ayamāyasmā, nāyamāyasmā bhayūparato; vītarāgattā kāme na sevati khayā rāgassā’ti? Tamenaṃ samannesamāno evaṃ jānāti – ‘abhayūparato ayamāyasmā, nāyamāyasmā bhayūparato; vītarāgattā kāme na sevati khayā rāgassā’ti. Tañce, bhikkhave, bhikkhuṃ pare evaṃ puccheyyuṃ – ‘ke panāyasmato ākārā, ke anvayā, yenāyasmā evaṃ vadesi – abhayūparato ayamāyasmā, nāyamāyasmā bhayūparato; vītarāgattā kāme na sevati khayā rāgassā’ti. * no ca tena tammayo = 「しかし、それによってそれと同化した者ではない」
  * tammaya = 「それに執着した、それと一体になった、それから成る」（taṃ + maya）
  * 註釈では taṇhā（渇愛）による同化・執着のないことを指す

→「比丘たちよ、答えるときには、如来はこのように答えるであろう。『眼と耳によって識られる清浄な諸法は、如来にある。私はこれを道とし、これを行境とする者であるが、それによってそれと同化した者ではない』と。」

7. ‘‘Evaṃvādiṃ kho, bhikkhave, satthāraṃ arahati sāvako upasaṅkamituṃ dhammassavanāya.

* evaṃvādiṃ = 「このように語る（師を）」（対格）
  * evaṃ-vādin = 「このように説く者」
* satthāraṃ = 「師を」（satthar の対格）
* arahati = 「ふさわしい、値する」
* sāvako = 「弟子は」
* upasaṅkamituṃ = 「近づくこと（不定詞）」
* dhammassavanāya = 「法を聞くために」
  * dhamma-savana = 「聞法」

→「比丘たちよ、このように語る師には、弟子が法を聞くために近づくのがふさわしい。」

8. Tassa satthā dhammaṃ deseti uttaruttariṃ paṇītapaṇītaṃ kaṇhasukkasappaṭibhāgaṃ.

* tassa = 「その者（弟子）に」
* satthā dhammaṃ deseti = 「師は法を説く」
* uttaruttariṃ = 「ますます高く、次第に高く」
* paṇītapaṇītaṃ = 「ますますすぐれた、次第にすぐれた」
* kaṇhasukkasappaṭibhāgaṃ = 「黒と白とを対照させた」
  * kaṇha = 「黒（不善）」、sukka = 「白（善）」
  * sappaṭibhāga = 「対をなす、対照をもつ」

→「その者に師は、ますます高く、ますますすぐれた、黒と白とを対照させた法を説く。」

9. Yathā yathā kho, bhikkhave, bhikkhuno satthā dhammaṃ deseti uttaruttariṃ paṇītapaṇītaṃ kaṇhasukkasappaṭibhāgaṃ tathā tathā so tasmiṃ dhamme abhiññāya idhekaccaṃ dhammaṃ dhammesu niṭṭhaṃ gacchati, satthari pasīdati – ‘sammāsambuddho bhagavā, svākkhāto bhagavatā dhammo, suppaṭipanno saṅgho’ti.

* yathā yathā ... tathā tathā = 「～するにつれて、それに応じて」
* bhikkhuno = 「比丘に」
* so = 「彼は」
* tasmiṃ dhamme = 「その法において」
* abhiññāya = 「証知して、よく知って」（abhijānāti の連続体）
* idhekaccaṃ dhammaṃ = 「ここにある一部の法を」（idha + ekaccaṃ）
* dhammesu niṭṭhaṃ gacchati = 「諸法において結論に至る、確信に達する」
  * niṭṭhā = 「結論、完成、確信」
* satthari pasīdati = 「師に対して浄信を起こす」
  * satthari = 「師において」（処格）
  * pasīdati = 「浄信する、清らかに信じる」
* sammāsambuddho bhagavā = 「世尊は正等覚者である」
* svākkhāto bhagavatā dhammo = 「法は世尊によってよく説かれた」
* suppaṭipanno saṅgho = 「僧団はよく実践している」

→「比丘たちよ、比丘に師が、ますます高く、ますますすぐれた、黒と白とを対照させた法を説くにつれて、それに応じて彼はその法において、ここにある一部の法を証知して、諸法において結論に至り、師に対して浄信を起こす。『世尊は正等覚者である、法は世尊によってよく説かれた、僧団はよく実践している』と。」

10. Tañce, bhikkhave, bhikkhuṃ pare evaṃ puccheyyuṃ – ‘ke panāyasmato ākārā, ke anvayā, yenāyasmā evaṃ vadesi – sammāsambuddho bhagavā , svākkhāto bhagavatā dhammo, suppaṭipanno saṅgho’ti?

* taṃ ce bhikkhuṃ = 「もしその比丘に」
* pare = 「他の者たちが」
* evaṃ puccheyyuṃ = 「このように問うならば」
* ke pana āyasmato ākārā = 「では、尊者にはどのような理由があるのか」
  * ākāra = 「理由、様相、根拠」
  * āyasmato = 「尊者の」（属格）
* ke anvayā = 「どのような推知があるのか」
  * anvaya = 「随行、推論、根拠づけ」
* yena āyasmā evaṃ vadesi = 「それによって尊者はこのように言うのか」
  * vadesi = 「言う（二人称単数）」

→「比丘たちよ、もし他の者たちがその比丘にこのように問うならば。『では、尊者にはどのような理由があり、どのような推知があって、それによって尊者は「世尊は正等覚者である、法は世尊によってよく説かれた、僧団はよく実践している」とこのように言うのか』と。」

11. Sammā byākaramāno, bhikkhave, bhikkhu evaṃ byākareyya – ‘idhāhaṃ, āvuso, yena bhagavā tenupasaṅkamiṃ dhammassavanāya.

* sammā byākaramāno = 「正しく答えるときには」
* bhikkhu evaṃ byākareyya = 「比丘はこのように答えるであろう」
* idha ahaṃ = 「ここで私は」
* āvuso = 「友よ」
* yena bhagavā tena upasaṅkamiṃ = 「世尊のもとへ近づいた」
  * upasaṅkamiṃ = 「近づいた（アオリスト一人称単数）」
* dhammassavanāya = 「法を聞くために」

→「比丘たちよ、正しく答えるときには、比丘はこのように答えるであろう。『友よ、ここで私は法を聞くために世尊のもとへ近づいた。」

12. Tassa me bhagavā dhammaṃ deseti uttaruttariṃ paṇītapaṇītaṃ kaṇhasukkasappaṭibhāgaṃ.

* tassa me = 「その私に」
* （他は 8 と同じ）

→「その私に世尊は、ますます高く、ますますすぐれた、黒と白とを対照させた法を説く。」

13. Yathā yathā me, āvuso , bhagavā dhammaṃ deseti uttaruttariṃ paṇītapaṇītaṃ kaṇhasukkasappaṭibhāgaṃ tathā tathāhaṃ tasmiṃ dhamme abhiññāya idhekaccaṃ dhammaṃ dhammesu niṭṭhamagamaṃ, satthari pasīdiṃ – sammāsambuddho bhagavā, svākkhāto bhagavatā, dhammo, suppaṭipanno saṅgho’ti.

* me = 「私に」
* tathā tathā ahaṃ = 「それに応じて私は」
* niṭṭhaṃ agamaṃ = 「結論に至った（アオリスト一人称単数）」
* satthari pasīdiṃ = 「師に対して浄信を起こした（アオリスト一人称単数）」
* （他は 9 と同じ）

→「友よ、世尊が私に、ますます高く、ますますすぐれた、黒と白とを対照させた法を説くにつれて、それに応じて私はその法において、ここにある一部の法を証知して、諸法において結論に至り、師に対して浄信を起こした。「世尊は正等覚者である、法は世尊によってよく説かれた、僧団はよく実践している」と』と。」

## 490

490. ‘‘Yassa kassaci, bhikkhave, imehi ākārehi imehi padehi imehi byañjanehi tathāgate saddhā niviṭṭhā hoti mūlajātā patiṭṭhitā, ayaṃ vuccati, bhikkhave, ākāravatī saddhā dassanamūlikā, daḷhā; asaṃhāriyā samaṇena vā brāhmaṇena vā devena vā mārena vā brahmunā vā kenaci vā lokasmiṃ. Idamavoca bhagavā. Attamanā te bhikkhū bhagavato bhāsitaṃ abhinandunti.

Vīmaṃsakasuttaṃ niṭṭhitaṃ sattamaṃ.

1. 490. ‘‘Yassa kassaci, bhikkhave, imehi ākārehi imehi padehi imehi byañjanehi tathāgate saddhā niviṭṭhā hoti mūlajātā patiṭṭhitā,

* imehi ākārehi = 「これらの様相によって」

* imehi padehi = 「これらの句によって」
  * pada = 「句、語句」
* imehi byañjanehi = 「これらの文によって」
  * byañjana = 「文字、表現、文言」

* saddhā = 「信」
* niviṭṭhā hoti = 「定着している」

* patiṭṭhitā = 「確立した」（patiṭṭhāti の過去分詞）

→「比丘たちよ、誰であれ、これらの様相によって、これらの句によって、これらの文によって、如来に対する信が定着し、根を生じ、確立している人がいれば、」

2. ayaṃ vuccati, bhikkhave, ākāravatī saddhā dassanamūlikā, daḷhā;

* ayaṃ = 「これは」

  * mūlika = 「～を根とする」

→「比丘たちよ、これは様相をそなえた信、見ることを根とする、堅固な（信）と言われる。」

* asaṃhāriyā = 「揺るがされ得ない、奪い去られ得ない」

* kenaci vā lokasmiṃ = 「世間の誰によっても」

→「沙門によっても、婆羅門によっても、天によっても、魔によっても、梵天によっても、世間の誰によっても揺るがされ得ない。」

4. Evaṃ kho, bhikkhave, tathāgate dhammasamannesanā hoti.

  * samannesanā = 「探究、吟味」（saṃ + anu + √is）

→「比丘たちよ、このように如来に対する法の探究がある。」

* avoca = 「語った」（vatti のアオリスト）
