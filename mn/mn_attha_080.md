# 10. Vekhanasasuttavaṇṇanā

## 278

278. Evaṃme sutanti vekhanasasuttaṃ. ### 対訳

1. 10. Vekhanasasuttavaṇṇanā

* Vekhanasa-sutta-vaṇṇanā = 「ヴェーカナサ経の註釈」
  * vaṇṇanā = 「註釈、解説」

→「ヴェーカナサ経の註釈」

2. 278. Evaṃme sutanti vekhanasasuttaṃ.

* evaṃ me sutaṃ = 「このように私は聞いた」
* ti = 「〜という (経の冒頭句を示す)」
* vekhanasa-suttaṃ = 「ヴェーカナサ経 (である)」

→「『このように私は聞いた』(と始まるもの) がヴェーカナサ経である。」

3. Tattha vekhanasoti ayaṃ kira sakuludāyissa ācariyo,

* tattha = 「そのうち、その (経の) なかで」
* vekhanaso ti = 「『ヴェーカナサ』とは」
* ayaṃ = 「この者は」
* kira = 「伝えるところでは、〜ということである」
* sakuludāyissa = 「サクルダーイの (属格)」
* ācariyo = 「師、阿闍梨」

→「そのうち『ヴェーカナサ』とは、伝えるところではこの者はサクルダーイの師であった。」

4. so ‘‘sakuludāyī paribbājako paramavaṇṇapañhe parājito’’ti sutvā

* so = 「彼は」
* sakuludāyī paribbājako = 「遍歴行者サクルダーイが」
* parama-vaṇṇa-pañhe = 「最上の光輝についての問いにおいて (処格)」

  * vaṇṇa = 「光輝、色、美しさ」(サクルダーイ経で問われた「最上の光輝 (paramavaṇṇa)」の論題)
  * pañha = 「問い、問題」
* parājito = 「負かされた、論破された (parājeti の過去分詞)」
* ti sutvā = 「〜と聞いて」

→「彼は『遍歴行者サクルダーイが最上の光輝についての問いで負かされた』と聞いて、」

5. ‘‘mayā so sādhukaṃ uggahāpito, tenāpi sādhukaṃ uggahitaṃ, kathaṃ nu kho parājito,

→「『彼は私がよく教え込んだし、彼もよく習得していた。いったいどうして負かされたのか。」

6. handāhaṃ sayaṃ gantvā samaṇaṃ gotamaṃ paramavaṇṇapañhaṃ pucchitvā jānissāmī’’ti

* pucchitvā = 「尋ねて」
* jānissāmi = 「私は知るだろう、確かめよう」

→「さあ、私が自ら行って沙門ゴータマに最上の光輝についての問いを尋ねて確かめよう』と (考えて)、」

7. rājagahato pañcacattālīsayojanaṃ sāvatthiṃ gantvā yena bhagavā, tenupasaṅkami,

→「そして近づいてから、立ったままで世尊の面前で感興の言葉を発した。」

→「そこにおいて前 (の経) と同様の部分は、すでに述べた方法によって理解されるべきである。」

Pabbajitopi ca ekacco kāmagaruko kāmādhimutto hoti, ekacco nekkhammagaruko nekkhammādhimutto hoti. Ayaṃ pana kāmagaruko kāmādhimutto hoti. ### 対訳

1. 280. Pañca kho imeti kasmā ārabhi?

* pañca kho ime ti = 「『pañca kho ime（実に、これら五つは）』と」
  * 経文（Mahādukkhakkhandhasutta 系の五種欲の説示）の冒頭句の引用
* kasmā = 「なぜ」
* ārabhi = 「（世尊は）始めたのか（ārabhati の過去形）」

→「『Pañca kho ime（実に、これら五つは）』と、なぜ（世尊は説き）始めたのか。」

2. Agāriyopi ekacco kāmagaruko kāmādhimutto hoti, ekacco nekkhammagaruko nekkhammādhimutto hoti.

* agāriyo pi = 「在家者もまた」
* ekacco = 「ある者は」
* kāma-garuko = 「欲を重んじる者」
  * garuka = 「重んじる、重きを置く」
* kāma-adhimutto = 「欲に傾倒した者」
  * adhimutta = 「傾倒した、志向した（adhimuccati の過去分詞）」
* hoti = 「である」
* nekkhamma-garuko = 「出離を重んじる者」
* nekkhamma-adhimutto = 「出離に傾倒した者」

→「在家者にも、ある者は欲を重んじ、欲に傾倒しており、ある者は出離を重んじ、出離に傾倒している。」

3. Pabbajitopi ca ekacco kāmagaruko kāmādhimutto hoti, ekacco nekkhammagaruko nekkhammādhimutto hoti.

* pabbajito pi ca = 「そして出家者もまた」
* ekacco ... ekacco = 「ある者は～、ある者は～」
* kāmagaruko kāmādhimutto = 「欲を重んじ、欲に傾倒した者」
* nekkhammagaruko nekkhammādhimutto = 「出離を重んじ、出離に傾倒した者」

→「そして出家者にも、ある者は欲を重んじ、欲に傾倒しており、ある者は出離を重んじ、出離に傾倒している。」

4. Ayaṃ pana kāmagaruko kāmādhimutto hoti.

* ayaṃ pana = 「しかしこの者（説法の相手）は」
  * 経の対告者を指す
* kāmagaruko kāmādhimutto hoti = 「欲を重んじ、欲に傾倒した者である」

→「しかしこの者は、欲を重んじ、欲に傾倒した者である。」

5. So imāya kathāya kathiyamānāya attano kāmādhimuttattaṃ sallakkhessati, evamassāyaṃ desanā sappāyā bhavissatīti imaṃ desanaṃ ārabhi.

* so = 「彼は」
* imāya kathāya kathiyamānāya = 「この話が語られるとき（絶対処格）」
  * kathiyamāna = 「語られている（katheti の受動現在分詞）」
* attano = 「自分の」
* kāmādhimuttattaṃ = 「欲に傾倒していること」
  * kāma-adhimutta-tta = 「欲に傾倒している状態（-tta は抽象名詞化の接尾辞）」
* sallakkhessati = 「認識するだろう、気づくだろう（sallakkheti の未来形）」
* evaṃ assa ayaṃ desanā = 「このようにして、彼にとってこの説示は」
* sappāyā bhavissati = 「適切なものとなるだろう」
  * sappāya = 「適切な、有益な」
* ti = 「と（考えて）」
* imaṃ desanaṃ ārabhi = 「この説示を始めた」

→「彼はこの話が語られるとき、自分が欲に傾倒していることに気づくだろう。このようにして、彼にとってこの説示は適切なものとなるだろう、と（考えて世尊は）この説示を始めた。」

6. Kāmaggasukhanti nibbānaṃ adhippetaṃ.

* kāmagga-sukhaṃ ti = 「『kāmaggasukhaṃ（欲の頂点の楽）』とは」
  * kāma-agga-sukha = 「欲の頂点の楽」
  * agga = 「頂点、最上」
* nibbānaṃ = 「涅槃が」
* adhippetaṃ = 「意図されている（adhippeta）」

→「『kāmaggasukhaṃ（欲の頂点の楽）』とは、涅槃が意図されている。」

### 対訳

1. 281. Pāpitobhavissatīti ajānanabhāvaṃ pāpito bhavissati.

* pāpito bhavissatī ti = 「『pāpito bhavissati (陥れられるだろう)』とは」
  * pāpita = 「至らせられた、陥れられた (pāpeti の過去分詞)」
* ajānana-bhāvaṃ = 「知らない状態に」
  * ajānana = 「知らないこと、無知」
  * bhāva = 「状態」
* pāpito bhavissati = 「陥れられるだろう」

→「『陥れられるだろう』とは、知らない状態に陥れられるだろう、ということである。」

2. Nāmakaṃyeva sampajjatīti niratthakavacanamattameva sampajjati.

* nāmakaṃ yeva sampajjatī ti = 「『nāmakaṃ yeva sampajjati (名前だけになる)』とは」
  * nāmaka = 「名前だけのもの、名ばかりのもの」
  * sampajjati = 「～となる、～に帰する」
* niratthaka-vacana-mattam eva = 「無意味な言葉にすぎないものに」
  * niratthaka = 「無意味な、役に立たない」
  * vacana = 「言葉」
  * matta = 「～だけ、～にすぎない」
* sampajjati = 「～となる」

→「『名前だけになる』とは、無意味な言葉にすぎないものとなる、ということである。」

3. Tiṭṭhatu pubbanto tiṭṭhatu aparantoti yasmā tuyhaṃ atītakathāya anucchavikaṃ pubbenivāsañāṇaṃ natthi, anāgatakathāya anucchavikaṃ dibbacakkhuñāṇaṃ natthi, tasmā ubhayampetaṃ tiṭṭhatūti āha.

* tiṭṭhatu pubbanto tiṭṭhatu aparanto ti = 「『過去の際はさておけ、未来の際はさておけ』とは」
  * tiṭṭhatu = 「そのままにしておけ、さておけ (tiṭṭhati の命令法三人称単数)」
  * pubbanta = 「過去の際、過去の極限」(pubba-anta)
  * aparanta = 「未来の際、未来の極限」(apara-anta)
* yasmā = 「なぜなら」
* tuyhaṃ = 「あなたには」
* atīta-kathāya anucchavikaṃ = 「過去についての話にふさわしい」
  * anucchavika = 「ふさわしい、適した」
* pubbenivāsa-ñāṇaṃ natthi = 「宿住智がない」
  * pubbenivāsa = 「宿住、過去の生存」
* anāgata-kathāya anucchavikaṃ = 「未来についての話にふさわしい」
* dibbacakkhu-ñāṇaṃ natthi = 「天眼智がない」
* tasmā = 「それゆえ」
* ubhayam pi etaṃ = 「この両方とも」
* tiṭṭhatū ti āha = 「さておけ、と言った」

→「『過去の際はさておけ、未来の際はさておけ』とは、あなたには過去についての話にふさわしい宿住智がなく、未来についての話にふさわしい天眼智がない、それゆえこの両方ともさておけ、と (世尊は) 言ったのである。」

4. Suttabandhanehīti suttamayabandhanehi.

  * bandhana = 「縛り、束縛、結び」

  * suttaka = 「糸、小さな糸 (sutta の指小形)」

→「実に、その (幼い子) を守るために、手足にも首にも糸を結ぶのである。」

→「そして、その (子) が大きくなった時に、それら (の糸) は自然に腐ってほどけるか、あるいは (人が) 切って取り去るのである。」

8. Evamevakhoti iminā idaṃ dasseti – daharassa kumārassa suttabandhanānaṃ ajānanakālo viya avijjāya purimāya koṭiyā ajānanaṃ, na hi sakkā avijjāya purimakoṭi ñātuṃ, mocanakāle jānanasadisaṃ pana arahattamaggena avijjābandhanassa pamokkho jātoti jānanaṃ.

* evam eva kho ti = 「『evameva kho (まさにそのように)』とは」
* iminā = 「これによって」
* idaṃ dasseti = 「このことを示す」
* daharassa kumārassa = 「幼い子どもの」
  * dahara = 「幼い、若い」
  * kumāra = 「子ども、少年」
* sutta-bandhanānaṃ ajānana-kālo viya = 「糸の縛りを知らない時のように」
  * ajānana-kāla = 「知らない時期」
* avijjāya purimāya koṭiyā ajānanaṃ = 「無明の最初の端を知らないこと (がある)」
  * purima koṭi = 「最初の端、始まりの極限」
  * ajānana = 「知らないこと」
* na hi sakkā = 「実に～することはできない」
* avijjāya purima-koṭi ñātuṃ = 「無明の最初の端を知る」
* mocana-kāle jānana-sadisaṃ pana = 「しかし、ほどく時に知るのと同様に」
  * mocana = 「ほどくこと、解放」
  * sadisa = 「同様の」
* arahatta-maggena = 「阿羅漢道によって」
* avijjā-bandhanassa pamokkho jāto ti jānanaṃ = 「無明の縛りからの解放が生じた、と知ること (がある)」
  * pamokkha = 「解放、脱すること」
  * jāta = 「生じた」

→「『まさにそのように』とは、これによってこのことを示す。幼い子どもが糸の縛りを知らない時のように、無明の最初の端を知らないこと (がある)。実に無明の最初の端を知ることはできない。しかし、(糸を) ほどく時に知るのと同様に、阿羅漢道によって無明の縛りからの解放が生じた、と知ること (がある)。」
