# 4. Cūḷavedallasuttaṃ

## 460 (1)

460. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā rājagahe viharati veḷuvane kalandakanivāpe. Atha kho visākho upāsako yena dhammadinnā bhikkhunī tenupasaṅkami; upasaṅkamitvā dhammadinnaṃ bhikkhuniṃ abhivādetvā ekamantaṃ nisīdi. Ekamantaṃ nisinno kho visākho upāsako dhammadinnaṃ bhikkhuniṃ etadavoca – ‘‘‘sakkāyo sakkāyo’ti, ayye, vuccati. Katamo nu kho, ayye, sakkāyo vutto bhagavatā’’ti? ‘‘Pañca kho ime, āvuso visākha, upādānakkhandhā sakkāyo vutto bhagavatā, seyyathidaṃ – rūpupādānakkhandho, vedanupādānakkhandho, saññupādānakkhandho, saṅkhārupādānakkhandho, viññāṇupādānakkhandho. Ime kho, āvuso visākha, pañcupādānakkhandhā sakkāyo vutto bhagavatā’’ti.

‘‘Sādhayye’’ti kho visākho upāsako dhammadinnāya bhikkhuniyā bhāsitaṃ abhinanditvā anumoditvā dhammadinnaṃ bhikkhuniṃ uttariṃ pañhaṃ apucchi – ‘‘‘sakkāyasamudayo sakkāyasamudayo’ti, ayye, vuccati. ### 対訳

1. 4. Cūḷavedallasuttaṃ

* cūḷa-vedalla-sutta = 「小さな問答の経」
  * cūḷa = 「小さい」(大なる Mahāvedallasutta との対比)
  * vedalla = 「問答体の教説、知識と歓喜を伴う問答」(九分教の一つ)
  * sutta = 「経」

→「小さな問答の経」

2. 460. Evaṃ me sutaṃ –

* evaṃ = 「このように」
* me = 「私によって」(ahaṃ の具格)
* sutaṃ = 「聞かれた」(suṇāti の過去分詞)

→「このように私は聞いた。」

3. ekaṃ samayaṃ bhagavā rājagahe viharati veḷuvane kalandakanivāpe.

* ekaṃ samayaṃ = 「ある時」(対格による時の表現)
* bhagavā = 「世尊は」
* rājagahe = 「王舎城に」(処格)
* viharati = 「住んでいる」
* veḷuvane = 「竹林に」(veḷu-vana の処格)
* kalandakanivāpe = 「栗鼠の餌場に」(kalandaka-nivāpa の処格)
  * kalandaka = 「栗鼠」
  * nivāpa = 「餌を撒く場所、餌場」

→「ある時、世尊は王舎城の竹林の栗鼠の餌場に住んでいた。」

4. Atha kho visākho upāsako yena dhammadinnā bhikkhunī tenupasaṅkami;

* atha kho = 「さて、そこで」
* visākho upāsako = 「優婆塞ヴィサーカは」
  * upāsaka = 「優婆塞、在家の男性信者」
* yena ... tena = 「〜のところへ」(具格の相関表現)
* dhammadinnā bhikkhunī = 「ダンマディンナー比丘尼(の)」
* upasaṅkami = 「近づいた」(upasaṅkamati のアオリスト)

→「さて、優婆塞ヴィサーカはダンマディンナー比丘尼のところへ近づいた。」

5. upasaṅkamitvā dhammadinnaṃ bhikkhuniṃ abhivādetvā ekamantaṃ nisīdi.

* upasaṅkamitvā = 「近づいて」(絶対分詞)
* dhammadinnaṃ bhikkhuniṃ = 「ダンマディンナー比丘尼に」(対格)
* abhivādetvā = 「礼拝して」(abhivādeti の絶対分詞)
* ekamantaṃ = 「一方に、傍らに」
* nisīdi = 「坐った」(nisīdati のアオリスト)

→「近づいてダンマディンナー比丘尼に礼拝し、一方に坐った。」

6. Ekamantaṃ nisinno kho visākho upāsako dhammadinnaṃ bhikkhuniṃ etadavoca –

* ekamantaṃ nisinno = 「一方に坐った(者は)」
  * nisinna = 「坐った」(nisīdati の過去分詞)
* kho = 「実に」(強調の小辞)
* visākho upāsako = 「優婆塞ヴィサーカは」
* dhammadinnaṃ bhikkhuniṃ = 「ダンマディンナー比丘尼に」
* etadavoca = 「このことを言った」(etad + avoca)
  * avoca = 「言った」(vatti のアオリスト)

→「一方に坐った優婆塞ヴィサーカはダンマディンナー比丘尼にこう言った。」

7. ‘‘‘sakkāyo sakkāyo’ti, ayye, vuccati.

* sakkāyo sakkāyo ti = 「『有身、有身』と」
  * sakkāya = 「有身、自身として存在するもの」(sat-kāya = 「存在する身体、存在の集まり」。五取蘊を指す)
* ayye = 「尊姉よ」(ayyā の呼格。比丘尼に対する敬称)
* vuccati = 「言われる」(vatti の受動態)

→「『尊姉よ、有身、有身と言われます。』」

8. Katamo nu kho, ayye, sakkāyo vutto bhagavatā’’ti?

* katamo = 「どれが、どのようなものが」(疑問代名詞)
* nu kho = 「一体」(疑問の小辞)
* ayye = 「尊姉よ」
* sakkāyo = 「有身が」
* vutto = 「説かれた」(vatti の過去分詞)
* bhagavatā = 「世尊によって」(具格)
* ti = 「と」(引用の終わり)

→「『尊姉よ、一体どのようなものが世尊によって有身と説かれたのですか。』」

9. ‘‘Pañca kho ime, āvuso visākha, upādānakkhandhā sakkāyo vutto bhagavatā,

  * upādāna = 「取、執着」
  * khandha = 「蘊、集まり」
* sakkāyo vutto bhagavatā = 「世尊によって有身と説かれた」

→「『友ヴィサーカよ、実にこれら五つの取蘊が世尊によって有身と説かれました。』」

10. seyyathidaṃ – rūpupādānakkhandho, vedanupādānakkhandho, saññupādānakkhandho, saṅkhārupādānakkhandho, viññāṇupādānakkhandho.

* seyyathidaṃ = 「すなわち」
* rūpupādānakkhandho = 「色取蘊」(rūpa-upādāna-khandha)
* vedanupādānakkhandho = 「受取蘊」(vedanā-upādāna-khandha)
* saññupādānakkhandho = 「想取蘊」(saññā-upādāna-khandha)
* saṅkhārupādānakkhandho = 「行取蘊」(saṅkhāra-upādāna-khandha)
* viññāṇupādānakkhandho = 「識取蘊」(viññāṇa-upādāna-khandha)

→「すなわち、色取蘊、受取蘊、想取蘊、行取蘊、識取蘊です。」

11. Ime kho, āvuso visākha, pañcupādānakkhandhā sakkāyo vutto bhagavatā’’ti.

* ime kho = 「実にこれら」
* āvuso visākha = 「友ヴィサーカよ」
* pañcupādānakkhandhā = 「五取蘊は」(pañca-upādāna-khandha の複数主格)
* sakkāyo vutto bhagavatā = 「世尊によって有身と説かれた」
* ti = 「と」

→「『友ヴィサーカよ、実にこれら五取蘊が世尊によって有身と説かれました。』」

12. ‘‘Sādhayye’’ti kho visākho upāsako dhammadinnāya bhikkhuniyā bhāsitaṃ abhinanditvā anumoditvā dhammadinnaṃ bhikkhuniṃ uttariṃ pañhaṃ apucchi –

* visākho upāsako = 「優婆塞ヴィサーカは」

* abhinanditvā = 「喜んで」(abhinandati の絶対分詞)
* anumoditvā = 「随喜して」(anumodati の絶対分詞)

* uttariṃ = 「さらに」
* pañhaṃ = 「問いを」
* apucchi = 「尋ねた」(pucchati のアオリスト)

→「優婆塞ヴィサーカは『尊姉よ、善いことです』とダンマディンナー比丘尼の語ったことを喜び随喜して、ダンマディンナー比丘尼にさらに問いを尋ねた。」

13. ‘‘‘sakkāyasamudayo sakkāyasamudayo’ti, ayye, vuccati.

* sakkāyasamudayo sakkāyasamudayo ti = 「『有身の生起、有身の生起』と」
  * samudaya = 「生起、集、起こり」
* ayye = 「尊姉よ」
* vuccati = 「言われる」

→「『尊姉よ、有身の生起、有身の生起と言われます。』」

* katamo nu kho = 「一体どのようなものが」
* ayye = 「尊姉よ」
* sakkāyasamudayo = 「有身の生起が」
* vutto bhagavatā = 「世尊によって説かれた」

→「『尊姉よ、一体どのようなものが世尊によって有身の生起と説かれたのですか。』」

15. ‘‘Yāyaṃ, āvuso visākha, taṇhā ponobbhavikā nandīrāgasahagatā tatratatrābhinandinī,

* taṇhā = 「渇愛は」
* ponobbhavikā = 「再び生存をもたらす」(puna-bhava からの派生形容詞)
* nandīrāgasahagatā = 「喜びと貪りを伴う」(nandī-rāga-sahagata)
  * nandī = 「喜び」
  * rāga = 「貪り」
  * sahagata = 「伴う、ともにある」
* tatratatrābhinandinī = 「あちこちで喜ぶ」(tatra-tatra-abhinandin の女性形)
  * tatra tatra = 「そこかしこに、あちこちで」
  * abhinandinī = 「喜ぶ(もの)、歓喜する(もの)」

→「『友ヴィサーカよ、およそこの渇愛は、再び生存をもたらし、喜びと貪りを伴い、あちこちで喜ぶものであり、』」

16. seyyathidaṃ – kāmataṇhā bhavataṇhā vibhavataṇhā;

* seyyathidaṃ = 「すなわち」
* kāmataṇhā = 「欲愛」(kāma-taṇhā = 感覚的欲望への渇愛)
* bhavataṇhā = 「有愛」(bhava-taṇhā = 存在への渇愛)
* vibhavataṇhā = 「無有愛」(vibhava-taṇhā = 非存在への渇愛)

→「すなわち、欲愛、有愛、無有愛です。」

17. ayaṃ kho, āvuso visākha, sakkāyasamudayo vutto bhagavatā’’ti.

* ayaṃ kho = 「実にこれが」
* āvuso visākha = 「友ヴィサーカよ」
* sakkāyasamudayo = 「有身の生起と」
* vutto bhagavatā = 「世尊によって説かれた」

1. ‘‘‘Sakkāyanirodho sakkāyanirodho’ti, ayye, vuccati. Katamo nu kho, ayye, sakkāyanirodho vutto bhagavatā’’ti?

* sakkāya-nirodho = 「有身の滅」

  * nirodha = 「滅、滅尽」
* ti ... vuccati = 「～と言われます」
* ayye = 「尊姉よ（比丘尼への呼びかけ、ayyā の呼格）」
* katamo nu kho = 「いったいどのようなものが」
* vutto bhagavatā = 「世尊によって説かれた」
  * vutta = 「説かれた（vacati の過去分詞）」
  * bhagavatā = 「世尊によって（具格）」

→「『有身の滅、有身の滅』と、尊姉よ、言われます。尊姉よ、いったいどのようなものが有身の滅として世尊によって説かれたのですか。」

* āvuso visākha = 「友ヴィサーカよ」

  * eva = 「まさに」

→「友ヴィサーカよ、まさにその取がかの五取蘊であるのではなく、また五取蘊とは別に取があるのでもありません。」

* yo kho = 「まさに～であるものが」
* pañcasu upādānakkhandhesu = 「五取蘊において（処格）」
* chanda-rāgo = 「欲貪」
  * chanda = 「欲、意欲」
  * rāga = 「貪り」
* taṃ = 「それが」
* tattha = 「そこにおいて、その場合」
* upādānaṃ = 「取である」

→「友ヴィサーカよ、五取蘊における欲貪、それがそこにおける取なのです。」

* dhammadinnāya bhikkhuniyā = 「ダンマディンナー比丘尼によって」（具格）

→「ヴィサーカよ、もしあなたが私にこの意味を尋ねたとしても、私もまた、ダンマディンナー比丘尼によって解答されたとおりに、まったく同じようにそれを解答するであろう。」

7. Eso cevetassa [esovetassa (syā. kaṃ.)] attho. Evañca naṃ [evametaṃ (sī. syā. kaṃ.)] dhārehī’’ti.

* eso ceva = 「まさにこれが」
  * eso = 「これが」
  * ceva = ca + eva「そしてまさに」
* etassa attho = 「この（問い）の意味である」
* evañca = 「そしてこのように」
* naṃ = 「それを」
* dhārehi = 「受持しなさい、記憶しなさい」（dhāreti の命令法 2 人称単数）
* ti = 「～と」（引用終わり）

→「まさにこれがこの（問い）の意味である。そしてこのように、それを受持しなさい。』と。」

8. Idamavoca bhagavā. Attamano visākho upāsako bhagavato bhāsitaṃ abhinandīti.

* idamavoca bhagavā = 「世尊はこのことを言った」（idaṃ + avoca）
* attamano = 「心が満たされた、喜んだ」（atta-mana）
* visākho upāsako = 「ヴィサーカ在家信者は」
* bhagavato bhāsitaṃ = 「世尊の説いたことを」
* abhinandīti = 「歓喜した、と」（abhinandi + iti）
  * abhinandi = 「歓喜した」（abhi-nandati のアオリスト）

→「世尊はこのことを言った。心が満たされたヴィサーカ在家信者は、世尊の説いたことを歓喜した、と。」

9. Cūḷavedallasuttaṃ niṭṭhitaṃ catutthaṃ.

* cūḷavedallasuttaṃ = 「小ヴェーダッラ経は」
  * cūḷa = 「小さい」
  * vedalla = 「ヴェーダッラ（問答形式の経の種別）」
* niṭṭhitaṃ = 「終わった、完結した」（niṭṭhāti の過去分詞）
* catutthaṃ = 「第四（の経）」

→「第四の小ヴェーダッラ経が終わった。」
