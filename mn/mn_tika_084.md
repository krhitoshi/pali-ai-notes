# 4. Madhurasuttavaṇṇanā

## 317

317. Madhurāyanti uttaramadhurāyaṃ. Gundāvaneti kāḷasippalivane. Atimuttakavaneti ca vadanti. Catūsu vaṇṇesu brāhmaṇova seṭṭho vaṇṇo. Paṇḍaroti parisuddho. Kāḷakoti aparisuddho. Jātigottādipaññāpanaṭṭhānesūti jātigottādivasena suddhacintāyaṃ brāhmaṇā eva suddhajātikā, na itareti adhippāyo. Saṃsārato vā suddhacintāyaṃ brāhmaṇāva sujjhanti vedavihitassa suddhavidhino aññesaṃ avisayattāti adhippāyo. Taṃ panetaṃ tesaṃ virujjhati khattiyavessānampi mantajjhenassa anuññātattā, mantajjhenavidhinā ca saṃsārasuddhiyābhāvato. Puttā nāma anorasāpi honti, na tathā imeti āha ‘‘orasā’’ti. Ure saṃvaḍḍhitaputtopi ‘‘orasa’’nti vuccati. Ime pana mukhato niggato hutvā ure saṃvaḍḍhāti dassetuṃ ‘‘orasā mukhato jātā’’ti vuttaṃ. Tato eva brahmato jātāti brahmajā, brahmasambhūtāpi ‘‘brahmajā’’ti vuccanti, na tathā ime. Ime pana paccakkhato brahmunā nimmitāti brahmanimmitā, tato eva brahmato laddhabbavijjādidāyajjadāyādāti brahmadāyādāti sabbametaṃ brāhmaṇānaṃ katthanāpalāpasadisaṃ viññūnaṃ appamāṇaṃ avimaddakkhamaṃ vācāvatthumattaṃ brahmakuttasseva abhāvato. Vohāramattamevetanti etaṃ ‘‘brāhmaṇova seṭṭho vaṇṇo’’tiādi vacanamattameva, na tassa attho tehi adhippetappakāro atthi.

1. 318. Samijjheyyāti diṭṭhidīpanavasena attano ajjhāsayo nipphajjeyya.

→「"samijjheyya"(成就するであろう)とは、見解を明らかにするという仕方で(要確認)、自分の意向が実現するであろう、ということである。」

## 322

322. Ahaṃ cīvarādīhi upaṭṭhāko, tumhākaṃ icchitacchitakkhaṇe vadeyyātha yenatthoti yojanā. Corādiupaddavanisedhanena rakkhāgutti, dānādinimittaupaddavanisedhanena āvaraṇagutti. Paccuppannānatthanisedhanena vā rakkhāgutti, āgāmianatthanisedhanena āvaraṇagutti. Ettha ca khattiyādīsu yo yo issaro, tassa itarena anuvattetabbabhāve, kusalākusalakaraṇena nesaṃ vasena laddhabbaabhisamparāye, pabbajitehi laddhabbasāmīcikiriyāya ca aṇumattopi viseso natthi, tasmā so visesābhāvo pāḷiyaṃ tattha tattha vāre ‘‘evaṃ sante’’tiādinā vibhāvito. Sesaṃ suviññeyyameva.

Madhurasuttavaṇṇanāya līnatthappakāsanā samattā.

### 対訳

1. 322. Ahaṃ cīvarādīhi upaṭṭhāko, tumhākaṃ icchitacchitakkhaṇe vadeyyātha yenatthoti yojanā.

* ahaṃ = 「私は」
* cīvarādīhi = 「衣などによって」
  * cīvara-ādi = 「衣をはじめとするもの」(具格・複数)
* upaṭṭhāko = 「奉仕する者、世話をする者」
* tumhākaṃ = 「あなた方の、あなた方にとって」
  * icchitacchitakkhaṇe にかかる(あなた方が望んだ時に)とも、yenattho にかかる(あなた方に必要なもの)とも取れる(要確認)
* icchitacchitakkhaṇe = 「望んだその時その時に」
  * icchita の反復 + khaṇa(時、瞬間)。反復は「〜するたびごとに」の意味
  * 綴りは icchiticchita- の形が想定される(要確認)
* vadeyyātha = 「言ってください」(vadati の願望法・二人称複数)
* yenattho = 「必要なもの」(yena attho)
  * 直訳は「それによって用があるもの」
* ti yojanā = 「というのが語のつなぎ方である」
  * yojanā = 「文の組み立て、語の結びつけ」

→「"私は衣などによって奉仕する者である。あなた方は望むたびごとに、必要なものを言ってください"というのが語のつなぎ方である。」

2. Corādiupaddavanisedhanena rakkhāgutti, dānādinimittaupaddavanisedhanena āvaraṇagutti.

* corādiupaddavanisedhanena = 「盗賊などによる災いを防ぐことによって」
  * cora-ādi = 「盗賊など」
  * upaddava = 「災い、危害」
  * nisedhana = 「防ぐこと、退けること」(具格)
* rakkhāgutti = 「守りによる保護」
  * rakkhā = 「守り」
  * gutti = 「保護、護衛」
* dānādinimittaupaddavanisedhanena = 「布施などを原因とする災いを防ぐことによって」(要確認)
  * dāna-ādi = 「布施など」
  * nimitta = 「原因、きっかけ」
  * 「布施などにかかわって生じる災い」の意味と見られる(要確認)
* āvaraṇagutti = 「遮りによる保護」
  * āvaraṇa = 「遮ること、防ぎ止めること」
  * rakkhāgutti と āvaraṇagutti を対にして、それぞれの内容を分けて説明している

→「盗賊などによる災いを防ぐことによるのが守りによる保護であり、布施などを原因とする災いを防ぐことによるのが遮りによる保護である。」

3. Paccuppannānatthanisedhanena vā rakkhāgutti, āgāmianatthanisedhanena āvaraṇagutti.

* paccuppannānatthanisedhanena = 「現在の不利益を防ぐことによって」
  * paccuppanna = 「現在の、今生じている」
  * anattha = 「不利益、害」
  * nisedhana = 「防ぐこと」(具格)
* vā = 「あるいは」
  * 別の説明を示す
* rakkhāgutti = 「守りによる保護」
* āgāmianatthanisedhanena = 「これから来る不利益を防ぐことによって」
  * āgāmi = 「未来の、これから来る」
* āvaraṇagutti = 「遮りによる保護」

→「あるいは、現在の不利益を防ぐことによるのが守りによる保護であり、これから来る不利益を防ぐことによるのが遮りによる保護である。」

4. Ettha ca khattiyādīsu yo yo issaro, tassa itarena anuvattetabbabhāve, kusalākusalakaraṇena nesaṃ vasena laddhabbaabhisamparāye, pabbajitehi laddhabbasāmīcikiriyāya ca aṇumattopi viseso natthi,

* ettha ca = 「そしてここでは」
* khattiyādīsu = 「クシャトリヤなどの中で」(処格・複数)
* yo yo issaro = 「誰であれ支配者である者」
  * issara = 「支配者、権勢のある者」
* tassa = 「その者に」
* itarena = 「他の者によって」
* anuvattetabbabhāve = 「従われるべきであるという点において」
  * anuvattetabba = 「従われるべき」(anuvattati の未来受動分詞)
  * bhāva = 「〜であること」(処格)
* kusalākusalakaraṇena = 「善・不善を行うことによって」
* nesaṃ vasena = 「それらの力によって、それらに応じて」
  * nesaṃ は善・不善を指すと見られる(要確認)
* laddhabbaabhisamparāye = 「得られるべき来世において」
  * laddhabba = 「得られるべき」(labhati の未来受動分詞)
  * abhisamparāya = 「来世、死後の行き先」
* pabbajitehi = 「出家した者たちによって」
* laddhabbasāmīcikiriyāya = 「受けるべき礼遇において」
  * sāmīci-kiriyā = 「ふさわしい敬意の行い、礼遇」
* ca = 「〜も」
* aṇumatto pi = 「わずかばかりも」
* viseso natthi = 「違いはない」

→「そしてここでは、クシャトリヤなどの中で誰であれ支配者である者に他の者が従うべきであるという点においても、善・不善を行うことでそれらに応じて得られる来世においても、出家した者たちが受けるべき礼遇においても、わずかばかりの違いもない。」

5. tasmā so visesābhāvo pāḷiyaṃ tattha tattha vāre ‘‘evaṃ sante’’tiādinā vibhāvito.

* tasmā = 「それゆえ」
* so visesābhāvo = 「その違いのないこと」
  * visesa-abhāva = 「違いが存在しないこと」
* pāḷiyaṃ = 「聖典の本文において」
* tattha tattha vāre = 「それぞれの段において」
  * vāra = 「回、段、区分」
* "evaṃ sante" tiādinā = 「"そうであるならば"などの言葉によって」
  * evaṃ sante = 「そうであるならば」(処格絶対節)
* vibhāvito = 「明らかにされた」(vibhāveti の過去分詞)

→「それゆえ、その違いのないことが、聖典の本文ではそれぞれの段で"そうであるならば"などの言葉によって明らかにされている。」

6. Sesaṃ suviññeyyameva.

* sesaṃ = 「残りは」
* suviññeyyaṃ eva = 「まったく理解しやすい」
  * su-viññeyya = 「容易に知られる」

→「残りは容易に理解できるものである。」

7. Madhurasuttavaṇṇanāya līnatthappakāsanā samattā.

* Madhurasuttavaṇṇanāya = 「マドゥラ経の註釈の」(属格)
  * vaṇṇanā = 「註釈、解説」
* līnatthappakāsanā = 「隠れた意味の解明」
  * līna-attha = 「隠れた意味」
  * pakāsanā = 「明らかにすること、解明」
* samattā = 「終わった、完結した」

→「マドゥラ経の註釈の、隠れた意味の解明が終わった。」
