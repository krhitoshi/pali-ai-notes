# 9. Cūḷasakuludāyisuttaṃ

## 269

269. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā rājagahe viharati veḷuvane kalandakanivāpe. Tena kho pana samayena sakuludāyī paribbājako moranivāpe paribbājakārāme paṭivasati mahatiyā paribbājakaparisāya saddhiṃ. Atha kho bhagavā pubbaṇhasamayaṃ nivāsetvā pattacīvaramādāya rājagahaṃ piṇḍāya pāvisi. Atha kho bhagavato etadahosi – ‘‘atippago kho tāva rājagahe piṇḍāya carituṃ. Yaṃnūnāhaṃ yena moranivāpo paribbājakārāmo yena sakuludāyī paribbājako tenupasaṅkameyya’’nti. Atha kho bhagavā yena moranivāpo paribbājakārāmo tenupasaṅkami.

Tena kho pana samayena sakuludāyī paribbājako mahatiyā paribbājakaparisāya saddhiṃ nisinno hoti unnādiniyā uccāsaddamahāsaddāya anekavihitaṃ tiracchānakathaṃ kathentiyā, seyyathidaṃ – rājakathaṃ corakathaṃ mahāmattakathaṃ senākathaṃ bhayakathaṃ yuddhakathaṃ annakathaṃ pānakathaṃ vatthakathaṃ sayanakathaṃ mālākathaṃ gandhakathaṃ ñātikathaṃ yānakathaṃ gāmakathaṃ nigamakathaṃ nagarakathaṃ janapadakathaṃ itthikathaṃ sūrakathaṃ visikhākathaṃ kumbhaṭṭhānakathaṃ pubbapetakathaṃ nānattakathaṃ lokakkhāyikaṃ samuddakkhāyikaṃ itibhavābhavakathaṃ iti vā. Addasā kho sakuludāyī paribbājako bhagavantaṃ dūratova āgacchantaṃ. Disvāna sakaṃ parisaṃ saṇṭhāpesi – ‘‘appasaddā bhonto hontu, mā bhonto saddamakattha. Ayaṃ samaṇo gotamo āgacchati; appasaddakāmo kho pana so āyasmā appasaddassa vaṇṇavādī. Appeva nāma appasaddaṃ parisaṃ viditvā upasaṅkamitabbaṃ maññeyyā’’ti. Atha kho te paribbājakā tuṇhī ahesuṃ .

  * dakkhanti = 「見る、見るであろう」

→「尊師よ、たとえば、倒れたものを起こすように、覆われたものを開くように、迷った者に道を教えるように、あるいは『眼のある者たちは諸々のかたちを見るように』と暗闇の中で油の灯火を掲げるように、」

4. evamevaṃ bhagavatā anekapariyāyena dhammo pakāsito.

* evamevaṃ = 「まさにそのように」
* bhagavatā = 「世尊によって」
* aneka-pariyāyena = 「多くの方法で、さまざまな仕方で」
* dhammo pakāsito = 「法が明らかにされた」
  * pakāsita = 「明らかにされた、説き示された」(pakāseti の過去分詞)

→「まさにそのように、世尊によって法がさまざまな仕方で明らかにされました。」

5. Esāhaṃ, bhante, bhagavantaṃ saraṇaṃ gacchāmi dhammañca bhikkhusaṅghañca.

* esāhaṃ = 「この私は」(eso + ahaṃ)
* bhagavantaṃ saraṇaṃ gacchāmi = 「世尊を帰依処として赴きます(世尊に帰依します)」
* dhammañca bhikkhusaṅghañca = 「法にも、比丘僧伽にも」

→「尊師よ、この私は世尊に帰依します。法にも、比丘僧伽にも(帰依します)。」

6. Labheyyāhaṃ, bhante, bhagavato santike pabbajjaṃ, labheyyaṃ upasampada’’nti.

* labheyyāhaṃ = 「私は得たいものです」(labheyyaṃ + ahaṃ、願望法)
* bhagavato santike = 「世尊のもとで」
* pabbajjaṃ = 「出家を」
* upasampadaṃ = 「具足戒を」

→「尊師よ、私は世尊のもとで出家を得たいものです。具足戒を得たいものです』と。」

7. Evaṃ vutte, sakuludāyissa paribbājakassa parisā sakuludāyiṃ paribbājakaṃ etadavocuṃ –

* evaṃ vutte = 「このように言われたとき」
* sakuludāyissa paribbājakassa parisā = 「遍歴行者サクルダーインの会衆は」
  * parisā = 「会衆、集まり、取り巻き」
* sakuludāyiṃ paribbājakaṃ = 「遍歴行者サクルダーインに」
* etadavocuṃ = 「このことを言った」(複数)

→「このように言われたとき、遍歴行者サクルダーインの会衆は、遍歴行者サクルダーインにこのことを言った。」

8. ‘‘mā bhavaṃ, udāyi, samaṇe gotame brahmacariyaṃ cari; mā bhavaṃ, udāyi, ācariyo hutvā antevāsīvāsaṃ vasi.

* mā ... cari = 「～を行じてはいけない」(mā + アオリスト、禁止)
* bhavaṃ = 「尊者は」(bhavant の主格)
* udāyi = 「ウダーインよ」(呼格)
* samaṇe gotame = 「沙門ゴータマのもとで」(処格)
* brahmacariyaṃ = 「梵行を」
* ācariyo hutvā = 「師でありながら」
* antevāsī-vāsaṃ vasi = 「弟子としての住まいに住んではいけない」
  * antevāsī = 「弟子、内弟子」
  * vāsa = 「住まい、住むこと」

→「『尊者ウダーインよ、沙門ゴータマのもとで梵行を行じてはいけません。尊者ウダーインよ、師でありながら弟子として住んではいけません。」

9. Seyyathāpi nāma udakamaṇiko [maṇiko (sī. pī. ka.)] hutvā udañcaniko [uddekaniko (sī. syā. kaṃ. pī.)] assa, evaṃ sampadamidaṃ [evaṃ sampadametaṃ (sī. pī.)] bhoto udāyissa bhavissati.

* seyyathāpi nāma = 「たとえば～のように」
* udaka-maṇiko hutvā = 「水がめでありながら」
  * udaka-maṇika = 「水がめ、大きな水壺」
* udañcaniko assa = 「汲み桶になるようなものである」
  * udañcanika = 「汲み桶、(井戸から水を)汲み上げる小さな器」(要確認)
  * assa = 「～であろう」(atthi の願望法)
* evaṃ sampadamidaṃ = 「これはそのような成り行きになる」
  * sampadā = 「成就、結果、成り行き」(ここでは「そのような事態」の意)
  * idaṃ = 「これは」
* bhoto udāyissa bhavissati = 「尊者ウダーインには～となるでしょう」

→「たとえば、水がめでありながら汲み桶になるようなものです。尊者ウダーインにはそのような成り行きになるでしょう。」

10. Mā bhavaṃ, udāyi, samaṇe gotame brahmacariyaṃ cari; mā bhavaṃ, udāyi, ācariyo hutvā antevāsīvāsaṃ vasī’’ti.

* (項目 8 と同じ)

→「尊者ウダーインよ、沙門ゴータマのもとで梵行を行じてはいけません。尊者ウダーインよ、師でありながら弟子として住んではいけません』と。」

11. Iti hidaṃ sakuludāyissa paribbājakassa parisā sakuludāyiṃ paribbājakaṃ antarāyamakāsi bhagavati brahmacariyeti.

* iti hidaṃ = 「このようにして、実にこの(ことが)」(iti + hi + idaṃ)
* sakuludāyissa paribbājakassa parisā = 「遍歴行者サクルダーインの会衆は」
* sakuludāyiṃ paribbājakaṃ = 「遍歴行者サクルダーインに対して」
* antarāyam akāsi = 「障害をなした、妨げた」
  * antarāya = 「障害、妨げ」
  * akāsi = 「なした」(karoti のアオリスト)
* bhagavati brahmacariye = 「世尊のもとでの梵行について」(処格)
* ti = 「と(以上)」

→「このようにして、遍歴行者サクルダーインの会衆は、遍歴行者サクルダーインが世尊のもとで梵行を行じることに障害をなしたのである。」

12. Cūḷasakuludāyisuttaṃ niṭṭhitaṃ navamaṃ.

* cūḷa-sakuludāyi-suttaṃ = 「小サクルダーイン経」
* niṭṭhitaṃ = 「終わった」
* navamaṃ = 「第九」

→「第九、小サクルダーイン経、終わり。」
