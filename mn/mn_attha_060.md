## 95

95. Nekkhamme ānisaṃsanti yo nesaṃ akusalato nikkhantabhāve ānisaṃso, yo ca vodānapakkho visuddhipakkho, taṃ na passantīti attho. Asaddhammasaññattīti abhūtadhammasaññāpanā . Attānukkaṃsetīti ṭhapetvā maṃ ko añño attano dassanaṃ pare gaṇhāpetuṃ sakkotīti attānaṃ ukkhipati. Paraṃ vambhetīti ettakesu janesu ekopi attano dassanaṃ pare gaṇhāpetuṃ na sakkotīti evaṃ paraṃ heṭṭhā khipati. Pubbeva kho panāti pubbe micchādassanaṃ gaṇhantasseva susīlyaṃ pahīnaṃ hoti, dussīlabhāvo paccupaṭṭhito. Evamassimeti evaṃ assa ime micchādiṭṭhiādayo satta. Aparāparaṃ uppajjanavasena pana teyeva micchādiṭṭhipaccayā aneke pāpakā akusalā dhammā uppajjanti nāma.

Tatrāti tāsu tesaṃ samaṇabrāhmaṇānaṃ laddhīsu. Kaliggahoti parājayaggāho. Dussamatto samādinnoti duggahito dupparāmaṭṭho. Ekaṃsaṃ pharitvā tiṭṭhatīti ekantaṃ ekakoṭṭhāsaṃ sakavādameva pharitvā adhimuccitvā tiṭṭhati, ‘‘sace kho natthi paro loko’’ti evaṃ santeyeva sotthibhāvāvaho hoti. Riñcatīti vajjeti.

### 対訳

1. 95. Nekkhamme ānisaṃsanti yo nesaṃ akusalato nikkhantabhāve ānisaṃso, yo ca vodānapakkho visuddhipakkho, taṃ na passantīti attho.

* nekkhamme ānisaṃsan ti = 「『出離における利益』とは」
  * nekkhamma = 「出離、離れ出ること」(処格 nekkhamme)
  * ānisaṃsa = 「利益、功徳」
* yo nesaṃ = 「それら(善法)の～であるところの」
  * nesaṃ = 「これらの」(経文の三つの善法 = 身・語・意の善行を指す)
* akusalato nikkhantabhāve ānisaṃso = 「不善から離れ出た状態にある利益」
  * akusalato = 「不善から」(奪格)
  * nikkhanta-bhāva = 「離れ出た状態」(nikkhanta は nikkhamati の過去分詞)
* yo ca vodānapakkho visuddhipakkho = 「また、浄化の側というのは清浄の側であり」
  * vodāna-pakkha = 「浄化の側、浄化に属するもの」
  * visuddhi-pakkha = 「清浄の側」
* taṃ na passanti = 「それを見ない」
* ti attho = 「という意味である」

→「『出離における利益』とは、それら(善法)が不善から離れ出た状態にある利益と、浄化の側すなわち清浄の側と、それを見ない、という意味である。」

2. Asaddhammasaññattīti abhūtadhammasaññāpanā.

* asaddhammasaññatti = 「非正法の説得」(a-saddhamma-saññatti)
  * saddhamma = 「正法」
  * saññatti = 「説得、納得させること、教示」
* abhūtadhammasaññāpanā = 「事実でない法を納得させること」
  * abhūta = 「事実でない、真実でない」
  * saññāpanā = 「納得させること、知らせること」(saññāpeti の名詞形)

→「『非正法の説得』とは、事実でない法を(他者に)納得させることである。」

3. Attānukkaṃsetīti ṭhapetvā maṃ ko añño attano dassanaṃ pare gaṇhāpetuṃ sakkotīti attānaṃ ukkhipati.

* attānukkaṃseti = 「自らを称揚する」(attānaṃ ukkaṃseti)
  * ukkaṃseti = 「持ち上げる、称揚する」
* ṭhapetvā maṃ = 「私を除いて」
* ko añño = 「他の誰が」
* attano dassanaṃ = 「自分の見解を」
* pare gaṇhāpetuṃ sakkoti = 「他の人々に受け入れさせることができるか」
  * gaṇhāpetuṃ = 「取らせること、受け入れさせること」(gaṇhāti の使役形の不定体)
  * pare = 「他の人々に」(対格複数)
* ti = 「と(考えて)」
* attānaṃ ukkhipati = 「自分を持ち上げる」

→「『自らを称揚する』とは、『私を除いて、他の誰が自分の見解を他の人々に受け入れさせることができるか』と、自分を持ち上げることである。」

  * nibbattissāmi = 「生じよう、生まれるだろう」(nibbattati の未来形)
* evaṃ paṭipajjati = 「このように実践する」

→「もしないならば、無色(界)に生まれよう』と、このように実践する。」

12. Takkī pana ekasamāpattiyāpi na lābhī, āruppe panassa kaṅkhā natthi, bhavanirodhe atthi.

* takkī pana = 「一方、思弁者は」
* eka-samāpattiyā pi = 「一つの等至さえも」
* na lābhī = 「得ていない」
* āruppe pana assa = 「しかし彼には無色(界)について」
* kaṅkhā natthi = 「疑いがない」
* bhava-nirodhe atthi = 「有の滅については(疑いが)ある」

→「一方、思弁者は一つの等至さえも得ていないが、彼には無色(界)について疑いはなく、有の滅については(疑いが)ある。」

13. So – ‘‘ahaṃ nirodho atthītipi natthītipi suṇāmi, sayaṃ na jānāmi, kasiṇaparikammaṃ katvā aṭṭhasamāpattiyo nibbattetvā samāpattipadaṭṭhānaṃ vipassanaṃ vaḍḍhessāmi.

* so = 「彼は」
* ahaṃ nirodho atthī ti pi natthī ti pi suṇāmi = 「私は "滅はある" とも "ない" とも聞いている」
* sayaṃ na jānāmi = 「自分では知らない」
* kasiṇa-parikammaṃ katvā = 「遍(カシナ)の準備修習を行って」
  * parikamma = 「準備、予備修習」
* aṭṭha-samāpattiyo nibbattetvā = 「八等至を生じさせて」
  * nibbattetvā = 「生じさせて」(nibbatteti の連続体)
* samāpatti-padaṭṭhānaṃ vipassanaṃ = 「等至を近因とする観を」
  * padaṭṭhāna = 「近因、足場」
* vaḍḍhessāmi = 「増大させよう」

→「彼は、『私は "滅はある" とも "ない" とも聞いているが、自分では知らない。遍の準備修習を行い、八等至を生じさせて、等至を近因とする観を増大させよう。」

14. Sace nirodho bhavissati, arahattaṃ patvā parinibbāyissāmi.

* sace nirodho bhavissati = 「もし滅があるならば」
* arahattaṃ patvā = 「阿羅漢果に達して」
* parinibbāyissāmi = 「般涅槃しよう」

→「もし滅があるならば、阿羅漢果に達して般涅槃しよう。」

15. No ce bhavissati, āruppe nibbattissāmī’’ti evaṃ paṭipajjati.

* no ce bhavissati = 「もしないならば」
* āruppe nibbattissāmī ti = 「無色(界)に生まれよう、と」
* evaṃ paṭipajjati = 「このように実践する」

→「もしないならば、無色(界)に生まれよう』と、このように実践する。」

16. Etthāha – ‘‘atthi dinnantiādīni tāva apaṇṇakāni bhavantu, natthi dinnantiādīni pana kathaṃ apaṇṇakānī’’ti.

* ettha āha = 「ここで(ある人が)言う」
* atthi dinnan ti ādīni = 「"布施(の果)はある" などは」
* tāva = 「まず、ひとまず」
* apaṇṇakāni bhavantu = 「無戯論(確実なもの)であるとしよう」
  * apaṇṇaka = 「誤りのない、確実な、無戯論の」
  * bhavantu = 「～であれ」(bhavati の命令形三人称複数)
* natthi dinnan ti ādīni pana = 「しかし "布施(の果)はない" などは」
* kathaṃ apaṇṇakānī ti = 「どうして無戯論(確実なもの)なのか、と」

→「ここで(ある人が)言う、『"布施(の果)はある" などはまず無戯論(確実なもの)であるとしよう。しかし "布施(の果)はない" などはどうして無戯論なのか』と。」

17. Gahaṇavasena.

* gahaṇa-vasena = 「把握(の仕方)によって、(そのように)取られることによって」
  * gahaṇa = 「把握、取ること」

→「(それは)把握(の仕方)によってである。」

18. Tāni hi apaṇṇakaṃ apaṇṇakanti evaṃ gahitattā apaṇṇakāni nāma jātāni.

* tāni hi = 「実にそれらは」
* apaṇṇakaṃ apaṇṇakan ti = 「"無戯論だ、無戯論だ" と」
* evaṃ gahitattā = 「このように取られているから」
  * gahitatta = 「取られていること」(gahita + -tta)
* apaṇṇakāni nāma jātāni = 「無戯論と呼ばれるものになった」
  * jātāni = 「生じた、～になった」

→「実にそれらは "無戯論だ、無戯論だ" とこのように取られているから、無戯論と呼ばれるものになったのである。」
