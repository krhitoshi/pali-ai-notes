# 1. Mūlapariyāyasuttaṃ

### 対訳

1. 1. Mūlapariyāyasuttaṃ

* mūla-pariyāya-suttaṃ = 「根本についての教えの経」
  * mūla = 「根、根本」
  * pariyāya = 「教えの筋道、法門、説き方」
  * sutta = 「経」

→「ムーラパリヤーヤ経(根本についての教えの経)」

2. 1. Evaṃ me sutaṃ –

* evaṃ = 「このように」
* me = 「私によって」(具格。属格とも取れる)
* sutaṃ = 「聞かれた」(suṇāti の過去分詞)

→「このように私は聞いた。」

3. ekaṃ samayaṃ bhagavā ukkaṭṭhāyaṃ viharati subhagavane sālarājamūle.

* ekaṃ samayaṃ = 「あるとき」(時間を表す対格)
* bhagavā = 「世尊は」
* ukkaṭṭhāyaṃ = 「ウッカッターに」(地名、処格)
* viharati = 「住んでいる、滞在している」(物語の現在形で、過去のこととして訳す)
* subhagavane = 「スバガヴァナ(スバガの林)に」(処格)
  * subhaga = 「幸運な、麗しい」
  * vana = 「林、森」
* sālarājamūle = 「サーラ樹の王の根元に」(処格)
  * sāla = 「サーラ樹」
  * rāja = 「王」
  * mūla = 「根元」
  * sāla-rāja は「サーラ樹の中の王」、つまりひときわ大きなサーラ樹を指すと解される

→「あるとき、世尊はウッカッターのスバガヴァナにある、サーラ樹の王の根元に滞在しておられた。」

4. Tatra kho bhagavā bhikkhū āmantesi – ‘‘bhikkhavo’’ti.

* tatra = 「そこで」
* kho = 強調の不変化詞(訳出しないことが多い)
* bhagavā = 「世尊は」
* bhikkhū = 「比丘たちに」(複数対格)
* āmantesi = 「呼びかけた」(āmanteti のアオリスト 3 人称単数)
* bhikkhavo = 「比丘たちよ」(複数呼格)
* ti = 引用の終わりを示す不変化詞

→「そこで世尊は比丘たちに「比丘たちよ」と呼びかけられた。」

5. ‘‘Bhadante’’ti te bhikkhū bhagavato paccassosuṃ.

* bhadante = 「尊い方よ」(師への呼びかけ)
* ti = 「と」
* te bhikkhū = 「その比丘たちは」
* bhagavato = 「世尊に」(与格)
* paccassosuṃ = 「応えた、返事をした」(paṭissuṇāti のアオリスト 3 人称複数)
  * paṭi + assosuṃ

→「「尊い方よ」と、その比丘たちは世尊に応えた。」

6. Bhagavā etadavoca –

* bhagavā = 「世尊は」
* etadavoca = 「このことを言った」(etaṃ + avoca)
  * etaṃ = 「これを」
  * avoca = 「言った」(vatti / vacati のアオリスト 3 人称単数)

→「世尊は次のように言われた。」

7. ‘‘sabbadhammamūlapariyāyaṃ vo, bhikkhave, desessāmi.

* sabbadhammamūlapariyāyaṃ = 「一切の法の根本についての教えを」(対格)
  * sabba = 「一切の、すべての」
  * dhamma = 「法」
  * mūla = 「根、根本」
  * pariyāya = 「教えの筋道、法門」
* vo = 「あなたたちに」(与格)
* bhikkhave = 「比丘たちよ」(複数呼格)
* desessāmi = 「私は説こう」(deseti の未来形 1 人称単数)

→「「比丘たちよ、一切の法の根本についての教えを、あなたたちに説こう。」

8. Taṃ suṇātha, sādhukaṃ manasi karotha, bhāsissāmī’’ti.

* taṃ = 「それを」
* suṇātha = 「聞きなさい」(suṇāti の命令形 2 人称複数)
* sādhukaṃ = 「よく、しっかりと」(副詞)
* manasi karotha = 「心に留めなさい、注意を向けなさい」(manasi karoti の命令形 2 人称複数)
  * manasi = 「心に」(mano の処格)
  * karotha = 「しなさい」
* bhāsissāmi = 「私は語ろう」(bhāsati の未来形 1 人称単数)
* ti = 引用の終わり

→「それを聞きなさい。よく心に留めなさい。私は語ろう」と。」

9. ‘‘Evaṃ, bhante’’ti kho te bhikkhū bhagavato paccassosuṃ.

* evaṃ = 「そのとおりです、はい」
* bhante = 「尊い方よ」(呼格)
* ti = 「と」
* kho = 強調の不変化詞
* te bhikkhū = 「その比丘たちは」
* bhagavato = 「世尊に」(与格)
* paccassosuṃ = 「応えた」(paṭissuṇāti のアオリスト 3 人称複数)

→「「はい、尊い方よ」と、その比丘たちは世尊に応えた。」

10. Bhagavā etadavoca –

* bhagavā = 「世尊は」
* etadavoca = 「このことを言った」(etaṃ + avoca)

→「世尊は次のように言われた。」

* pathaviṃ pathavito saññatvā = 「地を地として認識して」
  * saññatvā = 「認識して」(sañjānāti の連続体)
* pathaviṃ maññati = 「地を思いなす」
  * maññati = 「思いなす、(自分に引き寄せて)考える」(三人称・単数・現在)
* pathaviyā maññati = 「地において思いなす」

→「地を地として認識して、地を思いなし、地において思いなし、地から思いなし、"地は私のものだ" と思いなし、地を喜ぶ。」

1. 3. ‘‘Bhūte bhūtato sañjānāti;

* bhūte = 「生きものたちを」(bhūta の複数・対格)
  * bhūta = 「生じたもの、生きもの」(bhavati の過去分詞の名詞用法)

→「(教えを聞いていない凡夫は)生きものたちを生きものたちとして認識する。」

2. bhūte bhūtato saññatvā bhūte maññati, bhūtesu maññati, bhūtato maññati, bhūte meti maññati, bhūte abhinandati.

* bhūte bhūtato saññatvā = 「生きものたちを生きものたちとして認識してから」

* bhūte maññati = 「生きものたちを思いなす」

* bhūtesu maññati = 「生きものたちの中に思いなす」

→「水を…(中略)…火を…風を…生き物たちを…神々を…パジャーパティを…ブラフマーを…アーバッサラを…スバキンハを…ヴェーハッパラを…アビブーを…空無辺処を…識無辺処を…無所有処を…非想非非想処を…見られたものを…聞かれたものを…感じ取られたものを…識られたものを…単一であることを…多様であることを…一切を…」

6. nibbānaṃ nibbānato abhijānāti;

* nibbānaṃ = 「涅槃を」(対格)
* nibbānato = 「涅槃として」
* abhijānāti = 「直接に知る」

→「涅槃を涅槃として直接に知る。」

7. nibbānaṃ nibbānato abhiññāya nibbānaṃ na maññati, nibbānasmiṃ na maññati, nibbānato na maññati, nibbānaṃ meti na maññati, nibbānaṃ nābhinandati.

* nibbānaṃ nibbānato abhiññāya = 「涅槃を涅槃として直接に知って」
* nibbānaṃ na maññati = 「涅槃を思い描かない」
* nibbānasmiṃ na maññati = 「涅槃において思い描かない」
  * nibbānasmiṃ = 処格
* nibbānato na maññati = 「涅槃から思い描かない」
  * nibbānato = ここでは奪格
* nibbānaṃ me ti na maññati = 「『涅槃は私のものだ』と思い描かない」
* nibbānaṃ nābhinandati = 「涅槃を喜ばない」

→「涅槃を涅槃として直接に知って、涅槃を思い描かず、涅槃において思い描かず、涅槃から思い描かず、『涅槃は私のものだ』と思い描かず、涅槃を喜ばない。」

8. Taṃ kissa hetu?

* taṃ kissa hetu = 「それはなぜか」

→「それはなぜか。」

9. ‘Pariññātantaṃ tathāgatassā’ti vadāmi.

* pariññātantaṃ = 「それは終わりまで遍知されている」(要確認。項目 4 と同じ)
* tathāgatassa = 「如来によって」
* ti vadāmi = 「と私は言う」

→「『それは如来によって終わりまで遍知されているからである』と私は言う。」

10. Tathāgatavasena sattamanayabhūmiparicchedo niṭṭhito.

* tathāgata-vasena = 「如来に関して、如来という観点で」
  * vasena = 「〜によって、〜の観点で」(vasa の具格)
* sattama-naya-bhūmi-paricchedo = 「第七の方法の段階の区切り」
  * sattama = 「第七の」
  * naya = 「方法、説き方」
  * bhūmi = 「地、段階」
  * pariccheda = 「区切り、区分、章」
* niṭṭhito = 「終わった、完結した」

→「如来に関する、第七の方法の段階の区切りが終わった。」

1. 13. ‘‘Tathāgatopi , bhikkhave, arahaṃ sammāsambuddho pathaviṃ pathavito abhijānāti;

* tathāgato pi = 「如来もまた」
  * pi = 「〜もまた」(§8〜§11 の阿羅漢に続けて、如来についても述べる)
* bhikkhave = 「比丘たちよ」(呼格・複数)
* arahaṃ = 「阿羅漢である」(主格・単数)
* sammāsambuddho = 「正等覚者」(正しく自ら完全に目覚めた者)
* pathaviṃ = 「地を」(対格)
* pathavito = 「地として」(-to の奪格形。ここでは「〜として」の意)
* abhijānāti = 「証知する、直接に知る」(abhi + jānāti)
  * §2 の凡夫の sañjānāti(想によって認める)と対比される語

→「比丘たちよ、阿羅漢であり正等覚者である如来もまた、地を地として証知する。」

2. pathaviṃ pathavito abhiññāya pathaviṃ na maññati, pathaviyā na maññati, pathavito na maññati, pathaviṃ meti na maññati, pathaviṃ nābhinandati.

* pathaviṃ pathavito abhiññāya = 「地を地として証知して」
  * abhiññāya = 「証知して」(abhijānāti の連続体)
* pathaviṃ na maññati = 「地を思いなさない」
  * maññati = 「思いなす、思い込む」(対象を自己と関係づけて考えること)
* pathaviyā na maññati = 「地において思いなさない」
  * pathaviyā = 「地において」(処格)
* pathavito na maññati = 「地から思いなさない」
  * pathavito = 「地から」(奪格。ここでは起点の意)
* pathaviṃ me ti na maññati = 「"地は私のものだ" と思いなさない」
  * me = 「私の」(属格)
  * ti = 引用を示す不変化詞
* pathaviṃ nābhinandati = 「地を喜ばない」
  * nābhinandati = na + abhinandati(「喜ぶ、歓喜して受け入れる」の否定)

→「地を地として証知して、地を思いなさず、地において思いなさず、地から思いなさず、"地は私のものだ" と思いなさず、地を喜ばない。」

3. Taṃ kissa hetu?

* taṃ = 「それは」
* kissa hetu = 「何のゆえに、なぜか」
  * kissa = 「何の」(属格)
  * hetu = 「原因、理由」(副詞的用法)

→「それはなぜか。」

4. ‘Nandī [nandi (sī. syā.)] dukkhassa mūla’nti – iti viditvā ‘bhavā jāti bhūtassa jarāmaraṇa’nti.

* nandī = 「喜び、歓喜」(主格・単数)
  * [nandi (sī. syā.)] = スリランカ版・タイ版では短母音の nandi とする異読
* dukkhassa = 「苦の」(属格)
* mūlaṃ = 「根、根本」
  * mūla'nti = mūlaṃ + ti
* iti viditvā = 「このように知って」
  * viditvā = 「知って」(連続体)
* bhavā = 「有(生存)から」(奪格)
* jāti = 「生、生まれること」
* bhūtassa = 「生じた者には」(属格。bhūta = 「生じた、存在するに至った」)
* jarāmaraṇaṃ = 「老いと死」(jarā-maraṇa)
  * jarāmaraṇa'nti = jarāmaraṇaṃ + ti

→「"喜びは苦の根である" と、このように知り、"有(生存)から生があり、生じた者には老いと死がある" と知ったからである。」

5. Tasmātiha, bhikkhave, ‘tathāgato sabbaso taṇhānaṃ khayā virāgā nirodhā cāgā paṭinissaggā anuttaraṃ sammāsambodhiṃ abhisambuddho’ti vadāmi.

* tasmātiha = 「それゆえ、ここに」(tasmā 「それゆえ」を強めた定型句)
* bhikkhave = 「比丘たちよ」
* tathāgato = 「如来は」
* sabbaso = 「すべてにわたって、完全に」

* khayā = 「尽きることによって」(奪格)
* virāgā = 「離貪によって、色あせることによって」(奪格)
* nirodhā = 「滅によって」(奪格)
* cāgā = 「捨てることによって」(奪格)
