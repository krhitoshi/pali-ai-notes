# 4. Madhurasuttavaṇṇanā

## 317

317. Evaṃme sutanti madhurasuttaṃ. Tattha mahākaccānoti gihikāle ujjenikarañño purohitaputto abhirūpo dassanīyo pāsādiko suvaṇṇavaṇṇo ca. Madhurāyanti evaṃnāmake nagare. Gundāvaneti kaṇhakagundāvane . Avantiputtoti avantiraṭṭhe rañño dhītāya putto. Vuddho ceva arahā cāti daharaṃ arahantampi na tathā sambhāventi yathā mahallakaṃ, thero pana vuddho ceva ahosi arahā ca. Brāhmaṇā, bho kaccānāti so kira rājā brāhmaṇaladdhiko, tasmā evamāha. Brāhmaṇova seṭṭho vaṇṇotiādīsu jātigottādīnaṃ paññāpanaṭṭhāne brāhmaṇāva seṭṭhāti dasseti. Hīno añño vaṇṇoti itare tayo vaṇṇā hīnā lāmakāti vadati. Sukkoti paṇḍaro. Kaṇhoti kāḷako. Sujjhantīti jātigottādipaññāpanaṭṭhānesu sujjhanti. Brahmuno puttāti mahābrahmuno puttā. Ghosoyeva kho esoti vohāramattamevetaṃ.

### 対訳

1. 318. Ijjheyyāti samijjheyya,

* ijjheyya = 「成就するであろう、栄えるであろう」(ijjhati の願望法・三人称単数)
* ti = 「〜とは」(経の語句を挙げる引用標識)
* samijjheyya = 「成就するであろう、うまくいくであろう」(samijjhati の願望法・三人称単数)
  * 接頭辞 saṃ を付けた同義語で ijjheyya を言い換えている

→「"ijjheyya"(成就するであろう)とは、うまく成就するであろう、ということである。」

2. yattakāni dhanādīni pattheyya, tattakehissa manoratho pūreyyāti attho.

* yattakāni = 「どれだけの(ものを)」(関係詞、中性・複数・対格)
* dhanādīni = 「財産などを」(dhana-ādi)
  * dhana = 「財産、富」
  * ādi = 「〜など」
* pattheyya = 「望むであろう」(pattheti の願望法・三人称単数)
* tattakehissa = tattakehi + assa
  * tattakehi = 「それだけのものによって」(yattakāni と対応する相関詞、具格・複数)
  * assa = 「その人の」(属格・単数)
* manoratho = 「願い、望み」(主格・単数)
* pūreyya = 「満たされるであろう」(pūrati の願望法・三人称単数)
* ti attho = 「という意味である」

→「どれだけの財産などを望んだとしても、それだけのものによってその人の願いが満たされるであろう、という意味である。」

3. Khattiyopissāssāti khattiyopi assa issariyasampattassa pubbuṭṭhāyī assa.

* khattiyopissāssa = khattiyo + pi + assa + assa
  * khattiyo = 「カッティヤ(王族階級の者)」(主格・単数)
  * pi = 「〜もまた」
  * assa (一つ目) = 「その人の、その人に対して」(代名詞の属格・単数)
  * assa (二つ目) = 「であろう」(atthi の願望法・三人称単数)
* ti = 「〜とは」
* khattiyopi = 「カッティヤもまた」
* assa = 「その人の」(代名詞、issariyasampattassa と同格)
* issariyasampattassa = 「権勢を得た者の」(issariya-sampatta、属格・単数)
  * issariya = 「権勢、支配力」
  * sampatta = 「到達した、得た」(sampāpuṇāti の過去分詞)
* pubbuṭṭhāyī = 「先に起きる者」(pubba-uṭṭhāyī、主格・単数)
  * 主人よりも早く起きて仕える者のこと
* assa = 「であろう」(atthi の願望法・三人称単数)
  * 註釈は二つの assa を分け、一つ目に issariyasampattassa を補い、二つ目を pubbuṭṭhāyī の述語として示している

→「"khattiyopissāssa" とは、カッティヤもまた、権勢を得たその人に対して、先に起きて仕える者となるであろう、ということである。」

4. Nesaṃ ettha kiñcīti na etesaṃ ettha kiñci.

* nesaṃ = na + esaṃ
  * 註釈はこれを na etesaṃ と分けて示している
* ettha = 「ここにおいて、この点で」
* kiñci = 「何も、いかなるものも」
  * 否定の na と合わせて「何も〜ない」
* ti = 「〜とは」
* na = 「〜ない」
* etesaṃ = 「これらの者たちの、これらの者たちには」(属格・複数)
  * 文脈から、四つの階級の者たちを指すと判断される

→「"nesaṃ ettha kiñci" とは、これらの者たちには、この点で何も〜ない(na etesaṃ ettha kiñci)、ということである。」

## 322

322. Āsanena vā nimanteyyāmāti nisinnāsanaṃ papphoṭetvā idha nisīdāti vadeyyāma. Abhinimanteyyāmapi nanti abhiharitvā taṃ nimanteyyāma. Tattha duvidho abhihāro vācāya ceva kāyena ca. ‘‘Tumhākaṃ icchiticchitakkhaṇe mamaṃ cīvarādīhi vadeyyātha yenattho’’ti vadanto hi vācāya abhiharitvā nimanteti nāma. ### 対訳

1. 322. Āsanena vā nimanteyyāmāti nisinnāsanaṃ papphoṭetvā idha nisīdāti vadeyyāma.

* āsanena vā nimanteyyāma = 「あるいは座をもって招くだろう」(経の語句の引用)
  * āsanena = 「座によって」(具格)
  * nimanteyyāma = 「私たちは招くだろう」(nimanteti の願望法・一人称複数)
* ti = 「〜とは」
* nisinnāsanaṃ = 「坐っていた座を」(nisinna-āsana)
  * nisinna = 「坐った」(nisīdati の過去分詞)
* papphoṭetvā = 「払って、はたいて」(papphoṭeti の連続体)
* idha nisīdā ti = 「"ここにお坐りください" と」
  * nisīda = 「坐りなさい」(nisīdati の命令法・二人称単数)
* vadeyyāma = 「私たちは言うだろう」(vadati の願望法・一人称複数)

→「『あるいは座をもって招くだろう』とは、坐っていた座を払って『ここにお坐りください』と私たちは言うだろう、ということである。」

2. Abhinimanteyyāmapi nanti abhiharitvā taṃ nimanteyyāma.

* abhinimanteyyāma pi naṃ = 「また彼に申し出て招くだろう」(経の語句の引用)
  * abhinimanteyyāma = 「私たちは(物を差し出して)招くだろう」(abhinimanteti の願望法・一人称複数)
  * pi = 「〜も、また」
  * naṃ = 「彼を」
* ti = 「〜とは」
* abhiharitvā = 「差し出して、申し出て」(abhiharati の連続体)
* taṃ = 「彼を」
* nimanteyyāma = 「私たちは招くだろう」

→「『また彼に申し出て招くだろう』とは、差し出して彼を招くだろう、ということである。」

3. Tattha duvidho abhihāro vācāya ceva kāyena ca.

* tattha = 「そこにおいて、そのうち」
* duvidho = 「二種の」
* abhihāro = 「差し出すこと、申し出」
* vācāya ceva kāyena ca = 「言葉によるものと身体によるものと」
  * vācāya = 「言葉によって」(具格)
  * kāyena = 「身体によって」(具格)

→「そこで、差し出すことには二種がある。言葉によるものと身体によるものとである。」

4. ‘‘Tumhākaṃ icchiticchitakkhaṇe mamaṃ cīvarādīhi vadeyyātha yenattho’’ti vadanto hi vācāya abhiharitvā nimanteti nāma.

* tumhākaṃ = 「あなた方の、あなた方にとって」
* icchiticchitakkhaṇe = 「望むその時その時に」(icchita-icchita-kkhaṇa)
  * icchita = 「望まれた」(icchati の過去分詞)。反復で「望むたびごとの」
  * khaṇe = 「時に」(処格)
* mamaṃ = 「私に」(対格)
* cīvarādīhi = 「衣など(のうち)で」(cīvara-ādi、具格)
* vadeyyātha = 「あなた方は言ってください」(vadati の願望法・二人称複数)
* yenattho = 「必要なもの」(yena attho = 「それによって用があるところのもの」)
* ti vadanto = 「〜と言う者は」(vadati の現在分詞)
* hi = 「実に、というのは」
* vācāya abhiharitvā nimanteti nāma = 「言葉によって差し出して招くという」
  * nāma = 「〜と呼ばれる」

→「『あなた方が望むその時その時に、衣などのうち必要なものを私に言ってください』と言う者は、言葉によって差し出して招くという。」

5. Cīvarādivekallaṃ sallakkhetvā ‘‘idaṃ gaṇhathā’’ti tāni dento pana kāyena abhiharitvā nimanteti nāma.

* cīvarādivekallaṃ = 「衣などの不足を」(cīvara-ādi-vekalla)
  * vekalla = 「不足、欠けていること」
* sallakkhetvā = 「見てとって、気づいて」(sallakkheti の連続体)
* idaṃ gaṇhatha = 「これをお受け取りください」
  * gaṇhatha = 「取りなさい」(gaṇhāti の命令法・二人称複数)
* ti = 「〜と(言って)」
* tāni = 「それらを」
* dento = 「与える者は」(dadāti の現在分詞)
* pana = 「一方」
* kāyena abhiharitvā nimanteti nāma = 「身体によって差し出して招くという」

→「一方、衣などの不足を見てとって、『これをお受け取りください』とそれらを与える者は、身体によって差し出して招くという。」

6. Tadubhayampi sandhāya ‘‘abhinimanteyyāmapi na’’nti āha.

* tadubhayam pi = 「その両方ともを」(tad-ubhaya)
* sandhāya = 「指して、意図して」
* abhinimanteyyāma pi naṃ = 「また彼に申し出て招くだろう」
* ti āha = 「〜と言った」

→「その両方を指して『また彼に申し出て招くだろう』と言ったのである。」

7. Rakkhāvaraṇaguttinti rakkhāsaṅkhātañceva āvaraṇasaṅkhātañca guttiṃ.

* rakkhāvaraṇaguttiṃ = 「守りと防ぎによる保護を」(rakkhā-āvaraṇa-gutti、経の語句の引用)
* ti = 「〜とは」
* rakkhāsaṅkhātañ ceva = 「守りと呼ばれるものと」
  * rakkhā = 「守り、守護」
  * saṅkhāta = 「〜と呼ばれる」
* āvaraṇasaṅkhātañ ca = 「防ぎと呼ばれるものと」
  * āvaraṇa = 「防ぎ、遮ること」
* guttiṃ = 「保護を」(対格)

→「『守りと防ぎによる保護を』とは、守りと呼ばれ、また防ぎと呼ばれる保護を、ということである。」

8. Yā panesā āvudhahatthe purise ṭhapentena rakkhā, sā dhammikā nāma saṃvihitā na hoti.

* yā pana esā ... rakkhā = 「しかし、この〜という守りは」
* āvudhahatthe = 「武器を手にした」(āvudha-hattha、purise にかかる)
* purise = 「男たちを」(対格複数)
* ṭhapentena = 「配置する者によって」(ṭhapeti の現在分詞・具格)
* sā = 「それは」
* dhammikā nāma = 「法にかなったものとして」
* saṃvihitā na hoti = 「手配されたことにならない」
  * saṃvihita = 「手配された、整えられた」(saṃvidahati の過去分詞)

→「しかし、武器を手にした男たちを配置する者による守り、それは法にかなったものとして手配されたことにはならない。」

9. Yathā pana avelāya kaṭṭhahārikāpaṇṇahārikādayo vihāraṃ na pavisanti, migaluddakādayo vihārasīmāya mige vā macche vā na gaṇhanti, evaṃ saṃvidahantena dhammikā nāma saṃvihitā hoti.

* yathā pana ... evaṃ = 「一方、〜であるように、そのように」
* avelāya = 「ふさわしくない時刻に」(a-velā、処格)
* kaṭṭhahārikāpaṇṇahārikādayo = 「薪を取る女や葉を取る女など」(kaṭṭha-hārikā-paṇṇa-hārikā-ādi)
  * kaṭṭha = 「薪」
  * paṇṇa = 「葉」
  * hārikā = 「運ぶ女、取ってくる女」
* vihāraṃ na pavisanti = 「精舎に入らない」
* migaluddakādayo = 「猟師など」(miga-luddaka-ādi)
* vihārasīmāya = 「精舎の境界内で」(処格)
* mige vā macche vā = 「獣や魚を」
* na gaṇhanti = 「捕らえない」
* saṃvidahantena = 「手配する者によって」(saṃvidahati の現在分詞・具格)
* dhammikā nāma saṃvihitā hoti = 「法にかなったものとして手配されたことになる」
  * 主語は項目 8 の rakkhā(守り)

→「一方、薪を取る女や葉を取る女などがふさわしくない時刻に精舎に入らず、猟師などが精舎の境界内で獣や魚を捕らえないように、そのように手配する者によって、(守りは)法にかなったものとして手配されたことになる。」

10. Taṃ sandhāyāha ‘‘dhammika’’nti.

* taṃ = 「それを」
* sandhāya = 「指して」
* āha = 「言った」
* dhammikaṃ = 「法にかなった」(経の語句の引用)
* ti = 「〜と」

→「それを指して『法にかなった』と言ったのである。」

11. Evaṃsanteti evaṃ catunnampi vaṇṇānaṃ pabbajitānaṃ pabbajitasakkārena same samāne.

* evaṃ sante = 「このようであるならば」(経の語句の引用、処格絶対節)
* ti = 「〜とは」
* evaṃ = 「このように」
* catunnam pi vaṇṇānaṃ = 「四つの階級すべての」(属格複数)
* pabbajitānaṃ = 「出家者たちの」(属格複数)
* pabbajitasakkārena = 「出家者への敬いによって」(pabbajita-sakkāra、具格)
  * sakkāra = 「敬い、もてなし」
* same samāne = 「等しいのであるとき」(処格絶対節)
  * sama = 「等しい」
  * samāna = 「〜である」(atthi の現在分詞)
  * 属格の語句と処格絶対節のつながりは文脈からの判断(要確認)

→「『このようであるならば』とは、このように四つの階級すべての出家者が、出家者への敬いという点で等しいのであるならば、ということである。」

12. Sesaṃ sabbattha uttānamevāti.

* sesaṃ = 「残りは」
* sabbattha = 「すべての箇所で」
* uttānam eva = 「まったく明らかである」
  * uttāna = 「明らかな、平明な」
* ti = (註釈の結びを示す)

→「残りはすべての箇所で明らかである。」

13. Papañcasūdaniyā majjhimanikāyaṭṭhakathāya

* Papañcasūdaniyā = 「パパンチャスーダニーにおける」(処格。属格とも読める)
* majjhimanikāyaṭṭhakathāya = 「マッジマ・ニカーヤの註釈書における」(majjhima-nikāya-aṭṭhakathā、Papañcasūdaniyā と同格)

→「マッジマ・ニカーヤの註釈書であるパパンチャスーダニーにおける」

14. Madhurasuttavaṇṇanā niṭṭhitā.

* Madhurasuttavaṇṇanā = 「マドゥラ経の解説」(Madhura-sutta-vaṇṇanā)
  * vaṇṇanā = 「解説、説明」
* niṭṭhitā = 「終わった、完結した」(niṭṭhāti の過去分詞)

→「マドゥラ経の解説は終わった。」
