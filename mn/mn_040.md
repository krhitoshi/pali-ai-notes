# 10. Cūḷaassapurasuttaṃ

## 435

435. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā aṅgesu viharati assapuraṃ nāma aṅgānaṃ nigamo. Tatra kho bhagavā bhikkhū āmantesi – ‘‘bhikkhavo’’ti. ‘‘Bhadante’’ti te bhikkhū bhagavato paccassosuṃ. Bhagavā etadavoca – ‘‘samaṇā samaṇāti vo, bhikkhave, jano sañjānāti. Tumhe ca pana ‘ke tumhe’ti puṭṭhā samānā ‘samaṇāmhā’ti paṭijānātha. Tesaṃ vo, bhikkhave, evaṃsamaññānaṃ sataṃ evaṃpaṭiññānaṃ sataṃ – ‘yā samaṇasāmīcippaṭipadā taṃ paṭipajjissāma; evaṃ no ayaṃ amhākaṃ samaññā ca saccā bhavissati paṭiññā ca bhūtā; yesañca mayaṃ cīvarapiṇḍapātasenāsanagilānappaccayabhesajjaparikkhāraṃ paribhuñjāma, tesaṃ te kārā amhesu mahapphalā bhavissanti mahānisaṃsā, amhākañcevāyaṃ pabbajjā avañjhā bhavissati saphalā saudrayā’ti. Evañhi vo, bhikkhave, sikkhitabbaṃ.

### 対訳

1. 10. Cūḷaassapurasuttaṃ

* cūḷa-assapura-sutta = 「小アッサプラ経」
  * cūḷa = 「小さい」(同名の Mahāassapurasutta と区別するため)
  * assapura = 「アッサプラ」(アンガ国の町の名)
  * sutta = 「経」

→「小アッサプラ経」

2. 435. Evaṃ me sutaṃ –

* evaṃ = 「このように」
* me = 「私によって」(ahaṃ の具格・属格)
* sutaṃ = 「聞かれた」(suṇāti の過去分詞, 中性単数)

→「私はこのように聞いた。」

3. ekaṃ samayaṃ bhagavā aṅgesu viharati assapuraṃ nāma aṅgānaṃ nigamo.

* ekaṃ samayaṃ = 「ある時」(対格による時の表現)
* bhagavā = 「世尊は」
* aṅgesu = 「アンガ国に」(aṅga の処格複数. 国名は民族名の複数で表す)
* viharati = 「住んでいた」(現在形を歴史的現在として用いる)
* assapuraṃ nāma = 「アッサプラという名の」
* aṅgānaṃ nigamo = 「アンガ人たちの町」
  * nigama = 「町、市場町」

→「ある時、世尊はアンガ国の、アッサプラという名のアンガ人たちの町に住んでいた。」

4. Tatra kho bhagavā bhikkhū āmantesi – ‘‘bhikkhavo’’ti.

* tatra = 「そこで」
* kho = 「実に」(強調の不変化詞)
* bhikkhū = 「比丘たちに」(対格複数)
* āmantesi = 「呼びかけた」(āmanteti のアオリスト)
* bhikkhavo ti = 「『比丘たちよ』と」(呼格複数)

→「そこで世尊は比丘たちに『比丘たちよ』と呼びかけた。」

5. ‘‘Bhadante’’ti te bhikkhū bhagavato paccassosuṃ.

* bhadante ti = 「『尊師よ』と」
* te bhikkhū = 「それらの比丘たちは」
* bhagavato = 「世尊に」(与格)
* paccassosuṃ = 「応答した」(paṭi-ssuṇāti のアオリスト三人称複数)

→「それらの比丘たちは『尊師よ』と世尊に応答した。」

6. Bhagavā etadavoca –

* etad avoca = 「このことを言った」
  * etad = 「このことを」
  * avoca = 「言った」(vacati のアオリスト)

→「世尊はこのように言った。」

7. ‘‘samaṇā samaṇāti vo, bhikkhave, jano sañjānāti.

* samaṇā samaṇā ti = 「『沙門だ、沙門だ』と」(繰り返しは人々が口々に言う様子を表す)
* vo = 「あなたたちを」(tumhe の対格の短形)
* bhikkhave = 「比丘たちよ」
* jano = 「人々は」
* sañjānāti = 「認識している、見なしている」(saṃ-jānāti)

→「比丘たちよ、人々はあなたたちを『沙門だ、沙門だ』と見なしている。」

8. Tumhe ca pana ‘ke tumhe’ti puṭṭhā samānā ‘samaṇāmhā’ti paṭijānātha.

* tumhe ca pana = 「そしてまた、あなたたちも」
* ke tumhe ti = 「『あなたたちは誰か』と」
* puṭṭhā samānā = 「問われたとき」
  * puṭṭhā = 「問われた」(pucchati の過去分詞, 複数)
  * samānā = 「〜である (時に)」(atthi の現在分詞. 過去分詞と組んで状況を示す)
* samaṇā amhā ti = 「『私たちは沙門である』と」
  * amhā = 「私たちは〜である」(atthi の一人称複数現在 amha の長音形)
* paṭijānātha = 「自認する、公言する」(paṭi-jānāti の二人称複数)

→「そしてまたあなたたちも、『あなたたちは誰か』と問われたとき、『私たちは沙門である』と自認している。」

9. Tesaṃ vo, bhikkhave, evaṃsamaññānaṃ sataṃ evaṃpaṭiññānaṃ sataṃ –

* tesaṃ vo = 「そのようなあなたたちには」(tesaṃ は vo と同格の属格複数. 後の sikkhitabbaṃ の行為者を示す)
* evaṃ-samaññānaṃ sataṃ = 「このような呼称を持つ者として」
  * samaññā = 「呼称、通称」(人々からそう呼ばれること)
  * sataṃ = 「〜である (者たち) の」(atthi の現在分詞 santa の属格複数)
* evaṃ-paṭiññānaṃ sataṃ = 「このような自認を持つ者として」
  * paṭiññā = 「自認、公言」

→「比丘たちよ、このような呼称を持ち、このような自認を持つあなたたちは、」

10. ‘yā samaṇasāmīcippaṭipadā taṃ paṭipajjissāma;

* yā ... taṃ = 「〜であるところのもの、それを」(関係文)
* samaṇa-sāmīci-ppaṭipadā = 「沙門にふさわしい実践の道」
  * sāmīci = 「正しいこと、ふさわしいこと」
  * paṭipadā = 「実践の道、行道」
* paṭipajjissāma = 「私たちは実践しよう」(paṭipajjati の未来一人称複数)

→「『沙門にふさわしい実践の道であるもの、それを私たちは実践しよう。」

11. evaṃ no ayaṃ amhākaṃ samaññā ca saccā bhavissati paṭiññā ca bhūtā;

* evaṃ = 「このようにすれば」
* no = 「私たちの」(amhākaṃ の短形. amhākaṃ と重ねて強調)
* ayaṃ samaññā saccā bhavissati = 「この呼称は真実のものとなるだろう」
  * saccā = 「真実の」(女性形)
* paṭiññā ca bhūtā = 「自認も事実のものとなる」
  * bhūtā = 「事実の、本当の」(bhavati の過去分詞)

→「このようにすれば、私たちのこの呼称は真実のものとなり、自認も事実のものとなるだろう。」

12. yesañca mayaṃ cīvarapiṇḍapātasenāsanagilānappaccayabhesajjaparikkhāraṃ paribhuñjāma, tesaṃ te kārā amhesu mahapphalā bhavissanti mahānisaṃsā,

* yesaṃ ca ... tesaṃ = 「〜である人々の、その人々の」(関係文)
* mayaṃ = 「私たちが」
* cīvara-piṇḍapāta-senāsana-gilānappaccaya-bhesajja-parikkhāraṃ = 「衣・食・住居・病者の助けとなる薬の資具」
  * cīvara = 「衣」
  * piṇḍapāta = 「食 (托鉢の食)」
  * senāsana = 「住居、床座」
  * gilāna-paccaya-bhesajja = 「病者の助けとなる薬」
  * parikkhāra = 「資具、必需品」
* paribhuñjāma = 「受用する、使用する」(pari-bhuñjati の一人称複数)
* te kārā = 「それらの行為 (施し) は」
  * kāra = 「なすこと、奉仕、施し」
* amhesu = 「私たちにおいて」(処格複数. 施しの対象を示す)
* mahapphalā ... mahānisaṃsā = 「大きな果報・大きな利益のあるもの」
  * phala = 「果報」
  * ānisaṃsa = 「利益、功徳」

→「私たちが衣・食・住居・病者の助けとなる薬の資具を受け取って用いる人々の、それらの施しは、私たちにおいて大きな果報・大きな利益のあるものとなるだろう。」

13. amhākañcevāyaṃ pabbajjā avañjhā bhavissati saphalā saudrayā’ti.

* amhākaṃ ca eva ayaṃ pabbajjā = 「そして私たちのこの出家は」
  * pabbajjā = 「出家」
* avañjhā = 「むなしくないもの」(a-vañjha. vañjha = 「不毛の、むなしい」)
* saphalā = 「果のあるもの」
* saudrayā = 「実りのあるもの」
  * sa-udraya = 「結果・収益を伴う」(udraya = 「結果、収益」)
* ti = 「と」(sikkhitabbaṃ の内容を示す引用の終わり)

→「そして私たちのこの出家はむなしいものとならず、果があり、実りのあるものとなるだろう』と。」

14. Evañhi vo, bhikkhave, sikkhitabbaṃ.

* evaṃ hi = 「実にこのように」
* vo = 「あなたたちによって」(行為者を示す)
* sikkhitabbaṃ = 「学ばれるべきである」(sikkhati の未来受動分詞)

→「比丘たちよ、あなたたちは実にこのように学ぶべきである。」

### 対訳

1. 436. ‘‘Kathañca, bhikkhave, bhikkhu na samaṇasāmīcippaṭipadaṃ paṭipanno hoti?

* samaṇa-sāmīci-ppaṭipadaṃ = 「沙門にふさわしい実践の道を」（samaṇa-sāmīci-paṭipadā）
  * samaṇa = 「沙門、出家修行者」
  * sāmīci = 「ふさわしいこと、正しいあり方」

  * dosa = 「欠点、過失」

  * āpāyika = 「悪趣（apāya）に関する、悪趣に導く」
  * ṭhāna = 「要因、根拠、場合」
* duggati-vedaniyānaṃ = 「悪い境遇において感受されるべき（結果をもたらす）」
  * duggati = 「悪い境遇、悪趣」
  * vedaniya = 「感受されるべき」
* appahānā = 「捨てていないことから」（奪格、理由）
* ‘na samaṇasāmīcippaṭipadaṃ paṭipanno’ ti = 「『沙門にふさわしい実践の道を歩んでいる者ではない』と」

→「比丘たちよ、私は、これら沙門の汚れ・沙門の欠点・沙門のかすであり、悪趣に至らせる要因であり、悪い境遇で感受されるべき（結果をもたらす）ものを捨てていないことから、『沙門にふさわしい実践の道を歩んでいる者ではない』と言う。」

15. Seyyathāpi, bhikkhave, matajaṃ nāma āvudhajātaṃ ubhatodhāraṃ pītanisitaṃ.

* seyyathāpi = 「たとえば、ちょうど～のように」

  * mataja = 「武器の一種の名（鋭利な両刃の刃物）」（要確認）
* āvudha-jātaṃ = 「武器の類」
  * āvudha = 「武器」
  * jāta = 「種類、類」

  * ubhato = 「両側に」
  * dhārā = 「刃」
* pīta-nisitaṃ = 「研ぎ上げられ鋭利にされた」
  * pīta = 「研がれた、磨かれた」（要確認）
  * nisita = 「鋭利な、研がれた」

→「比丘たちよ、たとえば、マタジャという名の武器の類があり、両刃で、研ぎ上げられて鋭利であるとしよう。」

* tad assa = 「それが～であるとしよう」
  * taṃ = 「それ（その武器）が」
  * assa = 「～であろう」（atthi の願望法三人称単数）

  * saṅghāṭī = 「比丘の三衣のひとつである大衣」

  * saṃ-pāruta = 「覆われた、着せられた（pārupati の過去分詞）」
* sampaliveṭhitaṃ = 「すっかり巻きつけられた、包まれた」
  * saṃ-pali-veṭhita = 「巻き包まれた（veṭheti の過去分詞）」

→「それが大衣ですっかり覆われ、包まれているとしよう。」

* tathūpamaṃ = 「それと同様の、そのような譬えにあたるもの」
  * tathā = 「そのように」
  * upamā = 「譬え」
* ahaṃ ... vadāmi = 「私は～と言う」
* imassa bhikkhuno = 「この比丘の」
* pabbajjaṃ = 「出家を」

→「比丘たちよ、私はこの比丘の出家を、それと同様のものであると言う。」

## 437 (1)

5. yasmā kasmā cepi kulā agārasmā anagāriyaṃ pabbajito hoti, so ca āsavānaṃ khayā anāsavaṃ cetovimuttiṃ paññāvimuttiṃ diṭṭheva dhamme sayaṃ abhiññā sacchikatvā upasampajja viharati.

* yasmā kasmā cepi kulā = 「どのような家からであっても」
  * yasmā kasmā = 「いかなる～からでも（関係詞と疑問詞の併用による総称表現）」
* agārasmā anagāriyaṃ pabbajito hoti = 「家を出て家なき出家の生活に入った者である」
* so ca ... viharati = 項目 2 と同じ

→「どのような家からであれ、家を出て家なき出家の生活に入った者で、しかも彼が、諸漏の滅尽によって、漏のない心解脱・慧解脱を、まさにこの現世において自ら証知し、作証し、達して住するならば、」

6. Āsavānaṃ khayā samaṇo hotī’’ti.

* āsavānaṃ khayā = 「諸漏の滅尽によって」
* samaṇo hoti = 「沙門である」
* ti = 「と（引用の終わり）」

→「諸漏の滅尽によって、沙門である」と。

7. Idamavoca bhagavā.

* idaṃ = 「このことを」
* avoca = 「語った（vadati のアオリスト）」
* bhagavā = 「世尊は」

→「世尊はこのことを語った。」

8. Attamanā te bhikkhū bhagavato bhāsitaṃ abhinandunti.

* attamanā = 「心が満ち足りた、歓喜した」
  * atta-mana = 「満ち足りた心をもつ（atta は ā-dā「取る」の過去分詞）」
* te bhikkhū = 「それらの比丘たちは」
* bhagavato bhāsitaṃ = 「世尊の説かれたことを」
* abhinanduṃ = 「歓喜した、喜んで受け入れた（abhinandati のアオリスト・三人称複数）」
* ti = 「と（経の終わりを示す）」

→「心が満ち足りたそれらの比丘たちは、世尊の説かれたことを歓喜して受け入れた。」

9. Cūḷaassapurasuttaṃ niṭṭhitaṃ dasamaṃ.

* cūḷa-assapura-suttaṃ = 「小アッサプラ経」
  * cūḷa = 「小さい」
  * assapura = 「アッサプラ（アンガ国の町の名）」
* niṭṭhitaṃ = 「終わった、完結した」
* dasamaṃ = 「第十の」

→「第十、小アッサプラ経、終わり。」
