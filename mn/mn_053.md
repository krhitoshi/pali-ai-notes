# 3. Sekhasuttaṃ

## 22

22. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā sakkesu viharati kapilavatthusmiṃ nigrodhārāme. Tena kho pana samayena kāpilavatthavānaṃ [kapilavatthuvāsīnaṃ (ka.)] sakyānaṃ navaṃ santhāgāraṃ acirakāritaṃ hoti anajjhāvuṭṭhaṃ [anajjhāvutthaṃ (sī. syā. kaṃ. pī.)] samaṇena vā brāhmaṇena vā kenaci vā manussabhūtena. Atha kho kāpilavatthavā sakyā yena bhagavā tenupasaṅkamiṃsu; upasaṅkamitvā bhagavantaṃ abhivādetvā ekamantaṃ nisīdiṃsu. Ekamantaṃ nisinnā kho kāpilavatthavā sakyā bhagavantaṃ etadavocuṃ – ‘‘idha, bhante, kāpilavatthavānaṃ sakyānaṃ navaṃ santhāgāraṃ acirakāritaṃ [acirakāritaṃ hoti (syā. kaṃ. ka.)] anajjhāvuṭṭhaṃ samaṇena vā brāhmaṇena vā kenaci vā manussabhūtena. Taṃ, bhante, bhagavā paṭhamaṃ paribhuñjatu. Bhagavatā paṭhamaṃ paribhuttaṃ pacchā kāpilavatthavā sakyā paribhuñjissanti. Tadassa kāpilavatthavānaṃ sakyānaṃ dīgharattaṃ hitāya sukhāyā’’ti . Adhivāsesi bhagavā tuṇhībhāvena. Atha kho kāpilavatthavā sakyā bhagavato adhivāsanaṃ viditvā uṭṭhāyāsanā bhagavantaṃ abhivādetvā padakkhiṇaṃ katvā yena navaṃ santhāgāraṃ tenupasaṅkamiṃsu; upasaṅkamitvā sabbasanthariṃ santhāgāraṃ [sabbasanthariṃ santhataṃ (ka.)] santharitvā āsanāni paññapetvā udakamaṇikaṃ upaṭṭhapetvā telappadīpaṃ āropetvā yena bhagavā tenupasaṅkamiṃsu; upasaṅkamitvā bhagavantaṃ abhivādetvā ekamantaṃ aṭṭhaṃsu. Ekamantaṃ ṭhitā kho kāpilavatthavā sakyā bhagavantaṃ etadavocuṃ – ‘‘sabbasanthariṃ santhataṃ, bhante, santhāgāraṃ, āsanāni paññattāni, udakamaṇiko upaṭṭhāpito, telappadīpo āropito. Yassadāni, bhante , bhagavā kālaṃ maññatī’’ti. Atha kho bhagavā nivāsetvā pattacīvaramādāya saddhiṃ bhikkhusaṅghena yena santhāgāraṃ tenupasaṅkami; upasaṅkamitvā pāde pakkhāletvā santhāgāraṃ pavisitvā majjhimaṃ thambhaṃ nissāya puratthābhimukho nisīdi. Bhikkhusaṅghopi kho pāde pakkhāletvā santhāgāraṃ pavisitvā pacchimaṃ bhittiṃ nissāya puratthābhimukho nisīdi, bhagavantaṃyeva purakkhatvā. Kāpilavatthavāpi kho sakyā pāde pakkhāletvā santhāgāraṃ pavisitvā puratthimaṃ bhittiṃ nissāya pacchimābhimukhā nisīdiṃsu, bhagavantaṃyeva purakkhatvā. Atha kho bhagavā kāpilavatthave sakye bahudeva rattiṃ dhammiyā kathāya sandassetvā samādapetvā samuttejetvā sampahaṃsetvā āyasmantaṃ ānandaṃ āmantesi – ‘‘paṭibhātu taṃ, ānanda, kāpilavatthavānaṃ sakyānaṃ sekho pāṭipado [paṭipado (syā. kaṃ. ka.)]. Piṭṭhi me āgilāyati; tamahaṃ āyamissāmī’’ti. ‘‘Evaṃ, bhante’’ti kho āyasmā ānando bhagavato paccassosi. Atha kho bhagavā catugguṇaṃ saṅghāṭiṃ paññāpetvā dakkhiṇena passena sīhaseyyaṃ kappesi, pāde pādaṃ accādhāya, sato sampajāno, uṭṭhānasaññaṃ manasi karitvā.

1. 3. Sekhasuttaṃ

* sekha-sutta = 「有学経」
  * sekha = 「有学(まだ学ぶべきことのある者、阿羅漢に至っていない聖者)」
  * sutta = 「経」

→「有学経」

2. 22. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā sakkesu viharati kapilavatthusmiṃ nigrodhārāme.

* evaṃ me sutaṃ = 「このように私は聞いた」
  * me = 「私によって(具格的用法)」
  * sutaṃ = 「聞かれた(suṇāti の過去分詞)」
* ekaṃ samayaṃ = 「あるとき」
* bhagavā = 「世尊は」
* sakkesu = 「釈迦族の(国)において」
* viharati = 「住んでいた」
* kapilavatthusmiṃ = 「カピラヴァットゥ(迦毘羅衛城)において」
* nigrodhārāme = 「ニグローダ園において」
  * nigrodha = 「バニヤン樹」、ārāma = 「園」

→「このように私は聞いた。あるとき世尊は釈迦族の国、カピラヴァットゥのニグローダ園に住んでいた。」

3. Tena kho pana samayena kāpilavatthavānaṃ [kapilavatthuvāsīnaṃ (ka.)] sakyānaṃ navaṃ santhāgāraṃ acirakāritaṃ hoti anajjhāvuṭṭhaṃ [anajjhāvutthaṃ (sī. syā. kaṃ. pī.)] samaṇena vā brāhmaṇena vā kenaci vā manussabhūtena.

* tena kho pana samayena = 「さてそのとき」
* kāpilavatthavānaṃ sakyānaṃ = 「カピラヴァットゥの釈迦族たちの」
  * kāpilavatthava = 「カピラヴァットゥに住む」(異読 kapilavatthuvāsīnaṃ = 「カピラヴァットゥの住人たちの」)
* navaṃ santhāgāraṃ = 「新しい集会所が」
  * santhāgāra = 「集会所、公会堂」
* acirakāritaṃ hoti = 「造られて間もなかった」
  * a-cira = 「久しくない」、kārita = 「造られた」
* anajjhāvuṭṭhaṃ = 「まだ住まわれて(使用されて)いない」
  * an + adhi + ā + vas の過去分詞
* samaṇena vā brāhmaṇena vā = 「沙門によっても、婆羅門によっても」
* kenaci vā manussabhūtena = 「あるいはいかなる人間によっても」

→「さてそのとき、カピラヴァットゥの釈迦族たちの新しい集会所が造られて間もなく、沙門によっても婆羅門によってもいかなる人間によっても、まだ使用されていなかった。」

4. Atha kho kāpilavatthavā sakyā yena bhagavā tenupasaṅkamiṃsu; upasaṅkamitvā bhagavantaṃ abhivādetvā ekamantaṃ nisīdiṃsu.

* atha kho = 「そこで」
* kāpilavatthavā sakyā = 「カピラヴァットゥの釈迦族たちは」
* yena bhagavā tena upasaṅkamiṃsu = 「世尊のいるところへ近づいた」
* upasaṅkamitvā = 「近づいて」
* bhagavantaṃ abhivādetvā = 「世尊に礼拝して」
* ekamantaṃ nisīdiṃsu = 「一方に坐った」

→「そこでカピラヴァットゥの釈迦族たちは世尊のいるところへ近づいた。近づいて世尊に礼拝して一方に坐った。」

5. Ekamantaṃ nisinnā kho kāpilavatthavā sakyā bhagavantaṃ etadavocuṃ – ‘‘idha, bhante, kāpilavatthavānaṃ sakyānaṃ navaṃ santhāgāraṃ acirakāritaṃ [acirakāritaṃ hoti (syā. kaṃ. ka.)] anajjhāvuṭṭhaṃ samaṇena vā brāhmaṇena vā kenaci vā manussabhūtena.

* ekamantaṃ nisinnā = 「一方に坐って」
* etadavocuṃ = 「このように言った」(etad + avocuṃ)
* idha, bhante = 「尊師よ、ここに」
* (以下は 3. と同文)

→「一方に坐ったカピラヴァットゥの釈迦族たちは世尊にこのように言った――『尊師よ、ここにカピラヴァットゥの釈迦族たちの新しい集会所が造られて間もなく、沙門によっても婆羅門によってもいかなる人間によっても、まだ使用されていません。」

6. Taṃ, bhante, bhagavā paṭhamaṃ paribhuñjatu.

* taṃ = 「それを」
* bhante = 「尊師よ」
* bhagavā = 「世尊が」
* paṭhamaṃ = 「最初に」
* paribhuñjatu = 「使用してください(paribhuñjati の命令法三人称単数)」

→「尊師よ、世尊が最初にそれを使用してください。」

7. Bhagavatā paṭhamaṃ paribhuttaṃ pacchā kāpilavatthavā sakyā paribhuñjissanti.

* bhagavatā = 「世尊によって(具格)」
* paṭhamaṃ paribhuttaṃ = 「最初に使用されたものを」
  * paribhutta = 「使用された(paribhuñjati の過去分詞)」
* pacchā = 「後で」
* paribhuñjissanti = 「使用するでしょう(未来形)」

→「世尊によって最初に使用されたものを、後でカピラヴァットゥの釈迦族たちが使用するでしょう。」

8. Tadassa kāpilavatthavānaṃ sakyānaṃ dīgharattaṃ hitāya sukhāyā’’ti .

* tad assa = 「それは～となるでしょう」(taṃ + assa、assa は atthi の願望法)
* kāpilavatthavānaṃ sakyānaṃ = 「カピラヴァットゥの釈迦族たちにとって」
* dīgharattaṃ = 「長い間、長夜に」
* hitāya sukhāya = 「利益のため、安楽のために(与格)」
* ti = 「と(引用の終わり)」

→「それはカピラヴァットゥの釈迦族たちにとって長い間、利益と安楽のためになるでしょう』と。」

9. Adhivāsesi bhagavā tuṇhībhāvena.

* adhivāsesi = 「承諾した(adhivāseti のアオリスト)」
* bhagavā = 「世尊は」
* tuṇhībhāvena = 「沈黙によって」
  * tuṇhī = 「沈黙して」、bhāva = 「状態」

→「世尊は沈黙によって承諾した。」

10. Atha kho kāpilavatthavā sakyā bhagavato adhivāsanaṃ viditvā uṭṭhāyāsanā bhagavantaṃ abhivādetvā padakkhiṇaṃ katvā yena navaṃ santhāgāraṃ tenupasaṅkamiṃsu; upasaṅkamitvā sabbasanthariṃ santhāgāraṃ [sabbasanthariṃ santhataṃ (ka.)] santharitvā āsanāni paññapetvā udakamaṇikaṃ upaṭṭhapetvā telappadīpaṃ āropetvā yena bhagavā tenupasaṅkamiṃsu; upasaṅkamitvā bhagavantaṃ abhivādetvā ekamantaṃ aṭṭhaṃsu.

* bhagavato adhivāsanaṃ viditvā = 「世尊の承諾を知って」
* uṭṭhāyāsanā = 「座から立ち上がって」(uṭṭhāya + āsanā)
* padakkhiṇaṃ katvā = 「右繞して(右回りに回って敬意を表して)」
* yena navaṃ santhāgāraṃ tenupasaṅkamiṃsu = 「新しい集会所のあるところへ近づいた」
* sabbasanthariṃ santhāgāraṃ santharitvā = 「集会所の全面に敷物を敷いて」
  * sabbasanthariṃ = 「全面に敷かれるように(副詞的)」
* āsanāni paññapetvā = 「座を設けて」
* udakamaṇikaṃ upaṭṭhapetvā = 「水がめを備えて」
  * udaka-maṇika = 「水がめ」
* telappadīpaṃ āropetvā = 「油灯を灯して」
  * tela = 「油」、padīpa = 「灯明」、āropetvā = 「掲げて、灯して」
* ekamantaṃ aṭṭhaṃsu = 「一方に立った」

→「そこでカピラヴァットゥの釈迦族たちは世尊の承諾を知って、座から立ち上がり、世尊に礼拝し右繞して、新しい集会所のあるところへ近づいた。近づいて集会所の全面に敷物を敷き、座を設け、水がめを備え、油灯を灯して、世尊のいるところへ近づいた。近づいて世尊に礼拝して一方に立った。」

11. Ekamantaṃ ṭhitā kho kāpilavatthavā sakyā bhagavantaṃ etadavocuṃ – ‘‘sabbasanthariṃ santhataṃ, bhante, santhāgāraṃ, āsanāni paññattāni, udakamaṇiko upaṭṭhāpito, telappadīpo āropito.

* ekamantaṃ ṭhitā = 「一方に立って」
* sabbasanthariṃ santhataṃ santhāgāraṃ = 「集会所は全面に敷物が敷かれ」
  * santhata = 「敷かれた(santharati の過去分詞)」
* āsanāni paññattāni = 「座が設けられ」
* udakamaṇiko upaṭṭhāpito = 「水がめが備えられ」
* telappadīpo āropito = 「油灯が灯されました」

→「一方に立ったカピラヴァットゥの釈迦族たちは世尊にこのように言った――『尊師よ、集会所は全面に敷物が敷かれ、座が設けられ、水がめが備えられ、油灯が灯されました。」

12. Yassadāni, bhante , bhagavā kālaṃ maññatī’’ti.

* yassa dāni = 「今や、そのための」(yassa + idāni)
* kālaṃ maññati = 「時と考える、時が来たと思う」
  * 定型句で「今が(お出ましの)時であるとお考えならば、どうぞ」の意

→「尊師よ、今や世尊が(その)時であるとお考えのままに(お出ましください)』と。」

13. Atha kho bhagavā nivāsetvā pattacīvaramādāya saddhiṃ bhikkhusaṅghena yena santhāgāraṃ tenupasaṅkami; upasaṅkamitvā pāde pakkhāletvā santhāgāraṃ pavisitvā majjhimaṃ thambhaṃ nissāya puratthābhimukho nisīdi.

* nivāsetvā = 「(下衣を)着けて」
* pattacīvaraṃ ādāya = 「鉢と衣を取って」
* saddhiṃ bhikkhusaṅghena = 「比丘僧団とともに」
* pāde pakkhāletvā = 「両足を洗って」
* santhāgāraṃ pavisitvā = 「集会所に入って」
* majjhimaṃ thambhaṃ nissāya = 「中央の柱に寄って」
  * nissāya = 「依って、もたれて」
* puratthābhimukho = 「東に向かって」
* nisīdi = 「坐った」

→「そこで世尊は衣を着け、鉢と衣を取り、比丘僧団とともに集会所のあるところへ近づいた。近づいて両足を洗い、集会所に入って、中央の柱に寄って東に向かって坐った。」

14. Bhikkhusaṅghopi kho pāde pakkhāletvā santhāgāraṃ pavisitvā pacchimaṃ bhittiṃ nissāya puratthābhimukho nisīdi, bhagavantaṃyeva purakkhatvā.

* bhikkhusaṅgho pi = 「比丘僧団もまた」
* pacchimaṃ bhittiṃ nissāya = 「西の壁に寄って」
  * bhitti = 「壁」
* puratthābhimukho nisīdi = 「東に向かって坐った」
* bhagavantaṃ yeva purakkhatvā = 「まさに世尊を前にして」
  * purakkhatvā = 「前に置いて、上首として」

→「比丘僧団もまた両足を洗い、集会所に入って、まさに世尊を前にして、西の壁に寄って東に向かって坐った。」

15. Kāpilavatthavāpi kho sakyā pāde pakkhāletvā santhāgāraṃ pavisitvā puratthimaṃ bhittiṃ nissāya pacchimābhimukhā nisīdiṃsu, bhagavantaṃyeva purakkhatvā.

* kāpilavatthavā pi kho sakyā = 「カピラヴァットゥの釈迦族たちもまた」
* puratthimaṃ bhittiṃ nissāya = 「東の壁に寄って」
* pacchimābhimukhā nisīdiṃsu = 「西に向かって坐った」

→「カピラヴァットゥの釈迦族たちもまた両足を洗い、集会所に入って、まさに世尊を前にして、東の壁に寄って西に向かって坐った。」

16. Atha kho bhagavā kāpilavatthave sakye bahudeva rattiṃ dhammiyā kathāya sandassetvā samādapetvā samuttejetvā sampahaṃsetvā āyasmantaṃ ānandaṃ āmantesi – ‘‘paṭibhātu taṃ, ānanda, kāpilavatthavānaṃ sakyānaṃ sekho pāṭipado [paṭipado (syā. kaṃ. ka.)].

* kāpilavatthave sakye = 「カピラヴァットゥの釈迦族たちを(対格)」
* bahudeva rattiṃ = 「夜の多く(の時間)を通して」
* dhammiyā kathāya = 「法話によって」
* sandassetvā = 「示して」
* samādapetvā = 「受け入れさせて、奨励して」
* samuttejetvā = 「奮い立たせて」
* sampahaṃsetvā = 「喜ばせて」
* āyasmantaṃ ānandaṃ āmantesi = 「尊者アーナンダに呼びかけた」
* paṭibhātu taṃ = 「あなたに(語るべきことが)思い浮かぶように → あなたが説きなさい」
  * paṭibhātu = 「明らかになれ、思い浮かべ(paṭibhāti の命令法)」
  * taṃ = 「あなたに(tvaṃ の対格)」
* sekho pāṭipado = 「道を実践する有学(についての法話)」
  * sekha = 「有学」
  * pāṭipada = 「実践者、道を歩む者」

→「そこで世尊は夜の多くの時間を通してカピラヴァットゥの釈迦族たちに法話によって示し、奨励し、奮い立たせ、喜ばせてから、尊者アーナンダに呼びかけた――『アーナンダよ、カピラヴァットゥの釈迦族たちに、道を実践する有学(についての法話)をあなたが説きなさい。」

17. Piṭṭhi me āgilāyati; tamahaṃ āyamissāmī’’ti.

* piṭṭhi me āgilāyati = 「私の背中が痛む」
  * piṭṭhi = 「背中」
  * āgilāyati = 「痛む、疲れる」
* taṃ ahaṃ āyamissāmi = 「私はそれを伸ばそう」
  * āyamissāmi = 「伸ばすだろう(āyamati の未来形)」

→「私の背中が痛む。私はそれを伸ばそう』と。」

18. ‘‘Evaṃ, bhante’’ti kho āyasmā ānando bhagavato paccassosi.

* evaṃ, bhante = 「はい、尊師よ」
* paccassosi = 「応答した(paṭissuṇāti のアオリスト)」
* bhagavato = 「世尊に(与格)」

→「『はい、尊師よ』と尊者アーナンダは世尊に応答した。」

19. Atha kho bhagavā catugguṇaṃ saṅghāṭiṃ paññāpetvā dakkhiṇena passena sīhaseyyaṃ kappesi, pāde pādaṃ accādhāya, sato sampajāno, uṭṭhānasaññaṃ manasi karitvā.

* catugguṇaṃ saṅghāṭiṃ paññāpetvā = 「大衣を四つ折りにして敷いて」
  * catu-guṇa = 「四重の」
  * saṅghāṭi = 「大衣、重衣」
* dakkhiṇena passena = 「右脇によって」
* sīhaseyyaṃ kappesi = 「獅子の臥法をとった」
  * sīha-seyyā = 「獅子のように横たわること」
  * kappesi = 「行った、整えた(kappeti のアオリスト)」
* pāde pādaṃ accādhāya = 「足の上に足を重ねて」
  * accādhāya = 「上に置いて(ati + ā + dhā)」
* sato sampajāno = 「念があり、正知して」
* uṭṭhānasaññaṃ manasi karitvā = 「起きる想いを心に留めて」
  * uṭṭhāna-saññā = 「起き上がることの想い」
  * manasi karitvā = 「作意して、心に留めて」

→「そこで世尊は大衣を四つ折りにして敷き、足の上に足を重ね、念があり正知して、起きる想いを心に留めて、右脇によって獅子の臥法をとった。」

## 23

23. Atha kho āyasmā ānando mahānāmaṃ sakkaṃ āmantesi – ‘‘idha , mahānāma, ariyasāvako sīlasampanno hoti, indriyesu guttadvāro hoti, bhojane mattaññū hoti, jāgariyaṃ anuyutto hoti, sattahi saddhammehi samannāgato hoti, catunnaṃ jhānānaṃ ābhicetasikānaṃ diṭṭhadhammasukhavihārānaṃ nikāmalābhī hoti akicchalābhī akasiralābhī.
