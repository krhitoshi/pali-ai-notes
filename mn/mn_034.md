# 4. Cūḷagopālakasuttaṃ

## 350

350. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā vajjīsu viharati ukkacelāyaṃ gaṅgāya nadiyā tīre. Tatra kho bhagavā bhikkhū āmantesi – ‘‘bhikkhavo’’ti. ‘‘Bhadante’’ti te bhikkhū bhagavato paccassosuṃ. Bhagavā etadavoca –

‘‘Bhūtapubbaṃ , bhikkhave, māgadhako gopālako duppaññajātiko, vassānaṃ pacchime māse saradasamaye, asamavekkhitvā gaṅgāya nadiyā orimaṃ tīraṃ, asamavekkhitvā pārimaṃ tīraṃ, atittheneva gāvo patāresi uttaraṃ tīraṃ suvidehānaṃ. Atha kho, bhikkhave, gāvo majjhegaṅgāya nadiyā sote āmaṇḍaliyaṃ karitvā tattheva anayabyasanaṃ āpajjiṃsu. Taṃ kissa hetu? Tathā hi so, bhikkhave, māgadhako gopālako duppaññajātiko, vassānaṃ pacchime māse saradasamaye, asamavekkhitvā gaṅgāya nadiyā orimaṃ tīraṃ, asamavekkhitvā pārimaṃ tīraṃ, atittheneva gāvo patāresi uttaraṃ tīraṃ suvidehānaṃ. Evameva kho, bhikkhave, ye hi keci [ye keci (syā. kaṃ.)] samaṇā vā brāhmaṇā vā akusalā imassa lokassa akusalā parassa lokassa, akusalā māradheyyassa akusalā amāradheyyassa, akusalā maccudheyyassa akusalā amaccudheyyassa, tesaṃ ye sotabbaṃ saddahātabbaṃ maññissanti, tesaṃ taṃ bhavissati dīgharattaṃ ahitāya dukkhāya.

### 対訳

1. 4. Cūḷagopālakasuttaṃ

* cūḷa-gopālaka-suttaṃ = 「チューラゴーパーラカ経」
  * cūḷa = 「小さい、短い」
  * gopālaka = 「牛飼い」(go = 牛、pālaka = 守る者)
  * sutta = 「経」

→「チューラゴーパーラカ経(牛飼いの小さな経)」

2. 350. Evaṃ me sutaṃ –

* evaṃ = 「このように」
* me = 「私によって」(具格)
* sutaṃ = 「聞かれた」(suṇāti の過去分詞)

→「このように私は聞いた。」

3. ekaṃ samayaṃ bhagavā vajjīsu viharati ukkacelāyaṃ gaṅgāya nadiyā tīre.

* ekaṃ samayaṃ = 「あるとき」
* bhagavā = 「世尊は」
* vajjīsu = 「ヴァッジ族の人々のあいだに、ヴァッジ国に」(処格・複数)
* viharati = 「住んでいる、滞在している」
  * 現在形だが、過去の出来事を語る文なので「滞在していた」と訳す
* ukkacelāyaṃ = 「ウッカチェーラーに」(処格)
* gaṅgāya nadiyā = 「ガンガー川の」(属格)
* tīre = 「岸に」(処格)

→「あるとき世尊は、ヴァッジ国のウッカチェーラーで、ガンガー川の岸に滞在していた。」

4. Tatra kho bhagavā bhikkhū āmantesi – ‘‘bhikkhavo’’ti.

* tatra kho = 「そこで」
* bhagavā = 「世尊は」
* bhikkhū = 「比丘たちに」(対格・複数)
* āmantesi = 「呼びかけた」(āmanteti のアオリスト・3 人称単数)
* bhikkhavo = 「比丘たちよ」(呼格・複数)
* ti = 「〜と」(引用)

→「そこで世尊は比丘たちに「比丘たちよ」と呼びかけた。」

5. ‘‘Bhadante’’ti te bhikkhū bhagavato paccassosuṃ.

* bhadante = 「尊い方よ」(呼格)
* ti = 「〜と」
* te bhikkhū = 「その比丘たちは」
* bhagavato = 「世尊に」(与格)
* paccassosuṃ = 「応答した」(paṭissuṇāti のアオリスト・3 人称複数)

→「「尊い方よ」と、その比丘たちは世尊に応答した。」

6. Bhagavā etadavoca –

* bhagavā = 「世尊は」
* etad = 「このことを」
* avoca = 「言った」(vatti のアオリスト・3 人称単数)

→「世尊は次のように言った。」

7. ‘‘Bhūtapubbaṃ , bhikkhave, māgadhako gopālako duppaññajātiko, vassānaṃ pacchime māse saradasamaye,

* bhūtapubbaṃ = 「昔、かつて」
* bhikkhave = 「比丘たちよ」(呼格・複数)
* māgadhako = 「マガダの、マガダ国の」
* gopālako = 「牛飼いが」
* duppaññajātiko = 「生まれつき智慧の劣った、愚かな性質の」
  * du-paññā = 「劣った智慧」
  * jātika = 「〜の生まれの、〜の性質をもつ」
* vassānaṃ = 「雨季の」(属格・複数)
* pacchime māse = 「最後の月に」(処格)
* saradasamaye = 「秋の時期に」(処格)
  * sarada = 「秋」
  * samaya = 「時、時期」

→「「比丘たちよ、昔、マガダ国の生まれつき智慧の劣った牛飼いが、雨季の最後の月、秋の時期に、」

8. asamavekkhitvā gaṅgāya nadiyā orimaṃ tīraṃ, asamavekkhitvā pārimaṃ tīraṃ,

* asamavekkhitvā = 「よく観察せずに、よく調べずに」
  * a + samavekkhati(よく見る、検討する)の連続体
* gaṅgāya nadiyā = 「ガンガー川の」(属格)
* orimaṃ tīraṃ = 「こちらの岸を」(対格)
  * orima = 「こちら側の」
* pārimaṃ tīraṃ = 「向こうの岸を」(対格)
  * pārima = 「向こう側の」

→「ガンガー川のこちらの岸をよく調べず、向こうの岸もよく調べずに、」

9. atittheneva gāvo patāresi uttaraṃ tīraṃ suvidehānaṃ.

* atitthena eva = 「渡し場でないところから」(具格)
  * a-tittha = 「渡し場でないところ」(tittha = 渡し場、浅瀬)
  * eva = 「まさに」(強調)
* gāvo = 「牛たちを」(対格・複数)
* patāresi = 「渡らせた」(patāreti のアオリスト・3 人称単数、tarati「渡る」の使役)
* uttaraṃ tīraṃ = 「北の岸へ」(対格)
  * uttara は「北の」のほか「渡った先の」とも取れる(要確認)
* suvidehānaṃ = 「スヴィデーハの人々の」(属格・複数)
  * ヴィデーハ地方の人々を指すと読む(要確認)

→「渡し場でないところから、スヴィデーハの人々の側の北の岸へ牛たちを渡らせた。」

10. Atha kho, bhikkhave, gāvo majjhegaṅgāya nadiyā sote āmaṇḍaliyaṃ karitvā tattheva anayabyasanaṃ āpajjiṃsu.

* atha kho = 「すると」
* bhikkhave = 「比丘たちよ」
* gāvo = 「牛たちは」(主格・複数)
* majjhe = 「真ん中で」(処格)
* gaṅgāya nadiyā = 「ガンガー川の」(属格)
* sote = 「流れにおいて」(処格)
* āmaṇḍaliyaṃ karitvā = 「輪をなして固まり」(要確認)
  * āmaṇḍaliya = 「輪、円くかたまること」(要確認)
  * karitvā = 「なして」(karoti の連続体)
* tattha eva = 「まさにその場で」
* anayabyasanaṃ = 「災いと破滅に」(対格)
  * anaya = 「不幸、災い」
  * byasana = 「破滅、災難」
* āpajjiṃsu = 「陥った」(āpajjati のアオリスト・3 人称複数)

→「すると比丘たちよ、牛たちはガンガー川の流れの真ん中で輪をなして固まり、まさにその場で災いと破滅に陥った。」

11. Taṃ kissa hetu?

* taṃ = 「それは」
* kissa hetu = 「何のゆえに、なぜ」

→「それはなぜか。」

12. Tathā hi so, bhikkhave, māgadhako gopālako duppaññajātiko, vassānaṃ pacchime māse saradasamaye, asamavekkhitvā gaṅgāya nadiyā orimaṃ tīraṃ, asamavekkhitvā pārimaṃ tīraṃ, atittheneva gāvo patāresi uttaraṃ tīraṃ suvidehānaṃ.

* tathā hi = 「というのは、実にそのように」
* so = 「その」
* bhikkhave = 「比丘たちよ」
* māgadhako gopālako duppaññajātiko = 「マガダ国の生まれつき智慧の劣った牛飼いは」
* vassānaṃ pacchime māse saradasamaye = 「雨季の最後の月、秋の時期に」
* asamavekkhitvā = 「よく調べずに」
* gaṅgāya nadiyā orimaṃ tīraṃ = 「ガンガー川のこちらの岸を」
* pārimaṃ tīraṃ = 「向こうの岸を」
* atitthena eva = 「渡し場でないところから」
* gāvo patāresi = 「牛たちを渡らせた」
* uttaraṃ tīraṃ suvidehānaṃ = 「スヴィデーハの人々の側の北の岸へ」

→「というのは比丘たちよ、そのマガダ国の生まれつき智慧の劣った牛飼いは、雨季の最後の月、秋の時期に、ガンガー川のこちらの岸をよく調べず、向こうの岸もよく調べずに、渡し場でないところから、スヴィデーハの人々の側の北の岸へ牛たちを渡らせたからである。」

13. Evameva kho, bhikkhave, ye hi keci [ye keci (syā. kaṃ.)] samaṇā vā brāhmaṇā vā akusalā imassa lokassa akusalā parassa lokassa,

* evameva kho = 「まさにそのように」
* bhikkhave = 「比丘たちよ」
* ye hi keci = 「誰であれ〜である者たちは」
  * [ye keci (syā. kaṃ.)] = シャム版・カンボジア版では hi のない "ye keci" と読むという異読の注記
* samaṇā vā brāhmaṇā vā = 「沙門であれバラモンであれ」
* akusalā = 「巧みでない、通じていない」(主格・複数)
  * 属格の語をとって「〜について巧みでない」
* imassa lokassa = 「この世について」(属格)
* parassa lokassa = 「あの世について」(属格)

→「まさにそのように比丘たちよ、沙門であれバラモンであれ、この世について巧みでなく、あの世について巧みでなく、」

14. akusalā māradheyyassa akusalā amāradheyyassa, akusalā maccudheyyassa akusalā amaccudheyyassa,

* akusalā = 「巧みでない」
* māradheyyassa = 「マーラの領域について」(属格)
  * māra = 「マーラ」
  * dheyya = 「領域、支配の及ぶところ」
* amāradheyyassa = 「マーラの領域でないものについて」(属格)
* maccudheyyassa = 「死の領域について」(属格)
  * maccu = 「死」
* amaccudheyyassa = 「死の領域でないものについて」(属格)

→「マーラの領域について巧みでなく、マーラの領域でないものについて巧みでなく、死の領域について巧みでなく、死の領域でないものについて巧みでない者たちがいるが、」

15. tesaṃ ye sotabbaṃ saddahātabbaṃ maññissanti, tesaṃ taṃ bhavissati dīgharattaṃ ahitāya dukkhāya.

* tesaṃ = 「その者たちの(言葉を)」(属格・複数)
  * 前の沙門・バラモンたちを指す
* ye = 「〜する人々は」(関係代名詞・主格・複数)
* sotabbaṃ = 「聞くべきである」(suṇāti の未来受動分詞)
* saddahātabbaṃ = 「信じるべきである」(saddahati の未来受動分詞)
* maññissanti = 「考えるだろう」(maññati の未来・3 人称複数)
* tesaṃ = 「その人々にとって」(与格・複数)
  * こちらは ye を受け、聞いて信じる側の人々を指す
* taṃ = 「それは」
* bhavissati = 「〜となるだろう」(bhavati の未来・3 人称単数)
* dīgharattaṃ = 「長い間」
* ahitāya = 「不利益のために」(与格)
* dukkhāya = 「苦しみのために」(与格)

→「その者たちの言葉を聞くべきだ、信じるべきだと考える人々にとって、それは長い間、不利益と苦しみをもたらすだろう。」

  * rava = 「鳴き声」
* vuyhamāno = 「運ばれながら、引かれながら」(vahati の受動・現在分詞)
* tiriyaṃ gaṅgāya sotaṃ chetvā = 「ガンガーの流れを横に断ち切って」
* sotthinā = 「無事に」
* pāraṃ agamāsi = 「向こう岸へ行った」(gacchati のアオリスト・三人称単数)

→「比丘たちよ、たとえば、ちょうどその時に生まれたばかりのあの幼い子牛が、母牛の鳴き声に引かれながら、ガンガーの流れを横に断ち切って無事に向こう岸へ行ったように、」

14. evameva kho, bhikkhave, ye te bhikkhū dhammānusārino saddhānusārino,

* evameva kho = 「まさにそのように」
* ye te bhikkhū = 「〜であるそれらの比丘たち」
* dhammānusārino = 「法に従って進む者、随法行者」(dhamma-anusārin の主格・複数)
* saddhānusārino = 「信に従って進む者、随信行者」(saddhā-anusārin の主格・複数)
  * anusārin = 「従って行く者」

→「比丘たちよ、まさにそのように、法に従って進む者、信に従って進む者である比丘たち、」

15. tepi tiriyaṃ mārassa sotaṃ chetvā sotthinā pāraṃ gamissanti.

* tepi = 「彼らもまた」
* tiriyaṃ mārassa sotaṃ chetvā = 「マーラの流れを横に断ち切って」
* sotthinā = 「無事に」
* pāraṃ gamissanti = 「向こう岸へ行くだろう」

→「彼らもまた、マーラの流れを横に断ち切って、無事に向こう岸へ行くだろう。」

### 対訳

1. ‘‘Ahaṃ kho pana, bhikkhave, kusalo imassa lokassa kusalo parassa lokassa, kusalo māradheyyassa kusalo amāradheyyassa, kusalo maccudheyyassa kusalo amaccudheyyassa.

* ahaṃ = 「私は」
* kho pana = 「さて、ところで(話題を自分に転じる不変化詞)」
* bhikkhave = 「比丘たちよ(呼格・複数)」
* kusalo = 「よく知っている、熟達している(主格・単数)」
  * 属格の語をとって「〜について熟達している」の意味になる
* imassa lokassa = 「この世について(属格)」
* parassa lokassa = 「あの世について(属格)」
  * para = 「他の、向こうの」
* māradheyyassa = 「マーラの領域について(属格)」(māra-dheyya)
  * dheyya = 「領域、支配の及ぶ範囲」
* amāradheyyassa = 「マーラの領域でないものについて(属格)」
  * a- = 否定の接頭辞
* maccudheyyassa = 「死の領域について(属格)」(maccu-dheyya)
  * maccu = 「死、死神」
* amaccudheyyassa = 「死の領域でないものについて(属格)」

→「比丘たちよ、私はこの世をよく知り、あの世をよく知り、マーラの領域をよく知り、マーラの領域でないものをよく知り、死の領域をよく知り、死の領域でないものをよく知っている。」

2. Tassa mayhaṃ, bhikkhave, ye sotabbaṃ saddahātabbaṃ maññissanti, tesaṃ taṃ bhavissati dīgharattaṃ hitāya sukhāyā’’ti.

* tassa mayhaṃ = 「そのような私の(言葉を)」
  * tassa = 「その(属格)」。前文の「よく知っている者」である私を受ける
  * mayhaṃ = 「私の(属格)」
* bhikkhave = 「比丘たちよ」
* ye = 「〜する者たちは(関係代名詞、主格・複数)」
* sotabbaṃ = 「聞くべきである」(suṇāti の未来受動分詞)
* saddahātabbaṃ = 「信じるべきである」(saddahati の未来受動分詞)
* maññissanti = 「考えるだろう」(maññati の未来・三人称複数)
* tesaṃ = 「その者たちにとって(与格・複数)」。ye と対応する
* taṃ = 「それは」
* bhavissati = 「〜となるだろう」(bhavati の未来・三人称単数)
* dīgharattaṃ = 「長い間、長期にわたって」(dīgha-ratta、副詞的対格)
* hitāya = 「利益のために(与格)」
* sukhāya = 「安楽のために(与格)」
* ti = 引用の終わりを示す

→「比丘たちよ、そのような私の言葉を、聞くべきであり信じるべきであると考える者たちにとって、それは長い間の利益と安楽になるだろう」と。

3. Idamavoca bhagavā.

* idaṃ = 「これを」
* avoca = 「言った」(vatti のアオリスト・三人称単数)
* bhagavā = 「世尊は(主格・単数)」

→「世尊はこれを言った。」

4. Idaṃ vatvā sugato athāparaṃ etadavoca satthā –

* idaṃ vatvā = 「これを言って」
  * vatvā = 「言って」(vatti の連続体)
* sugato = 「善逝(よく行った方)は」。ブッダの呼び名
* athāparaṃ = 「そしてさらに」(atha + aparaṃ)
* etad avoca = 「次のことを言った」
* satthā = 「師は(主格・単数)」

→「これを言ってから、善逝である師は、さらに次のことを言った。」

5. ‘‘Ayaṃ loko paro loko, jānatā suppakāsito;

* ayaṃ loko = 「この世は」
* paro loko = 「あの世は」
* jānatā = 「知る者によって(具格・単数)」(jānāti の現在分詞)
* suppakāsito = 「よく明らかにされた、よく説き示された」(su-pakāsita)
  * pakāsita = pakāseti「明らかにする」の過去分詞

→「この世もあの世も、知る者によってよく明らかにされた。」

6. Yañca mārena sampattaṃ, appattaṃ yañca maccunā.

* yañ ca = 「また〜であるところのものも」(yaṃ + ca)
* mārena = 「マーラによって(具格)」
* sampattaṃ = 「到達された、手の届いた」(sampāpuṇāti の過去分詞)
* appattaṃ = 「到達されていない、手の届かない」(a-patta)
* maccunā = 「死によって(具格)」

→「マーラの手が届くところも、死の手が届かないところも(よく明らかにされた)。」

7. ‘‘Sabbaṃ lokaṃ abhiññāya, sambuddhena pajānatā;

* sabbaṃ lokaṃ = 「すべての世界を(対格)」
* abhiññāya = 「直接に知って、証知して」(abhijānāti の連続体)
* sambuddhena = 「正しく目覚めた者によって(具格)」
* pajānatā = 「よく知る者によって(具格・単数)」(pajānāti の現在分詞)
  * sambuddhena にかかる

→「すべての世界を直接に知って、よく知る正覚者によって、」

8. Vivaṭaṃ amatadvāraṃ, khemaṃ nibbānapattiyā.

* vivaṭaṃ = 「開かれた」(vivarati の過去分詞)
* amatadvāraṃ = 「不死の門」(amata-dvāra)
  * amata = 「不死」
  * dvāra = 「門、扉」
* khemaṃ = 「安穏な」
  * amatadvāraṃ にかかる形容詞として読む(要確認)
* nibbānapattiyā = 「涅槃に到達するために(与格)」(nibbāna-patti)
  * patti = 「到達、獲得」

→「涅槃に到達するための、安穏な不死の門が開かれた。」

9. ‘‘Chinnaṃ pāpimato sotaṃ, viddhastaṃ vinaḷīkataṃ;

* chinnaṃ = 「断ち切られた」(chindati の過去分詞)
* pāpimato = 「悪しき者の(属格・単数)」(pāpimant)。マーラの呼び名
* sotaṃ = 「流れ」
* viddhastaṃ = 「打ち壊された、粉砕された」(viddhaṃsati の過去分詞)
* vinaḷīkataṃ = 「葦を取り払ったようにされた、すなわち無力にされた」(要確認)
  * vi + naḷa(葦)+ kata(された)の構成と見る

→「悪しき者(マーラ)の流れは断ち切られ、打ち壊され、無力にされた。」

10. Pāmojjabahulā hotha, khemaṃ pattattha [patthetha (syā. kaṃ. ka. aṭṭhakathāyaṃ saṃvaṇṇetabbapāṭho)] bhikkhavo’’ti.

* pāmojjabahulā = 「喜びに満ちた者たち(主格・複数)」(pāmojja-bahula)
  * pāmojja = 「喜び」
  * bahula = 「多い、豊かな」
* hotha = 「〜であれ」(hoti の命令・二人称複数)
* khemaṃ = 「安穏を(対格)」
* pattattha = 「あなたたちは到達した」
  * pāpuṇāti のアオリスト二人称複数、または pattā + attha(到達した者である)の連声と見る(要確認)
* [patthetha (syā. kaṃ. ka. aṭṭhakathāyaṃ saṃvaṇṇetabbapāṭho)] = 異読についての校訂注
  * patthetha = 「願い求めよ」(pattheti の二人称複数)
  * syā. = シャム(タイ)版、kaṃ. = カンボジア版、ka. = ある本(要確認)
  * aṭṭhakathāyaṃ = 「註釈書において(処格)」
  * saṃvaṇṇetabbapāṭho = 「註釈の対象となる読み」(saṃvaṇṇetabba-pāṭha)
  * 注全体で「シャム版・カンボジア版・ある本では patthetha。註釈書で註釈の対象となっている読み」の意味
* bhikkhavo = 「比丘たちよ(呼格・複数)」
* ti = 引用の終わりを示す

→「比丘たちよ、喜びに満ちた者であれ。あなたたちは安穏に到達したのだ」と。
  * 異読 patthetha に従えば「比丘たちよ、喜びに満ちた者であれ。安穏を願い求めよ」となる

11. Cūḷagopālakasuttaṃ niṭṭhitaṃ catutthaṃ.

* Cūḷagopālakasuttaṃ = 「チューラゴーパーラカ経」(cūḷa-gopālaka-sutta)
  * cūḷa = 「小さい」
  * gopālaka = 「牛飼い」
* niṭṭhitaṃ = 「終わった、完結した」(niṭṭhāti の過去分詞)
* catutthaṃ = 「第四の」

→「第四のチューラゴーパーラカ経が終わった。」
