## 294 (2)

Kuṭumbikesu eko sakkabhavanaṃ patthanaṃ katvā sakko hutvā nibbatto, eko nāgabhavane pālitanāgarājā nāma. Taṃ sakko attano upaṭṭhānaṃ āgataṃ disvā nāgayoniyaṃ abhiramasīti pucchi. So nābhiramāmīti āha. Tena hi padumuttarassa bhagavato dānaṃ datvā imasmiṃ ṭhāne patthanaṃ karohi, ubho sukhaṃ vasissāmāti. Nāgarājā satthāraṃ nimantetvā bhikkhusatasahassaparivārassa bhagavato sattāhaṃ mahādānaṃ dadamāno padumuttarassa dasabalassa puttaṃ uparevataṃ nāma sāmaṇeraṃ disvā sattame divase buddhappamukhassa saṅghassa dibbavatthāni datvā sāmaṇerassa ṭhānantaraṃ patthesi. Bhagavā anāgataṃ oloketvā – ‘‘anāgate gotamassa nāma buddhassa putto rāhulakumāro bhavissatī’’ti disvā ‘‘samijjhissati te patthanā’’ti kathesi. Nāgarājā tamatthaṃ sakkassa kathesi. Sakko tassa vacanaṃ sutvā tatheva sattāhaṃ dānaṃ datvā bhinnaṃ raṭṭhaṃ sandhāretuṃ pāletuṃ samatthakule nibbattitvā saddhāpabbajitaṃ raṭṭhapālaṃ nāma kulaputtaṃ disvā – ‘‘ahampi anāgate lokasmiṃ tumhādise buddhe uppanne bhinnaṃ raṭṭhaṃ sandhāretuṃ pāletuṃ samatthakule nibbattitvā ayaṃ kulaputto viya saddhāpabbajito raṭṭhapālo nāma bhaveyya’’nti patthanamakāsi. Satthā samijjhanakabhāvaṃ ñatvā imaṃ gāthamāha –

‘‘Sarājikaṃ cātuvaṇṇaṃ, posetuṃ yaṃ pahossati;

Raṭṭhapālakulaṃ nāma, tattha jāyissate aya’’nti. –

Evaṃ padumuttarasammāsambuddhakāle tassetaṃ nāmaṃ uppannanti veditabbaṃ.

Kīdisānāma tā ayyaputta accharāyoti kasmā evamāhaṃsu? Tadā kira sambahule khattiyakumārepi brāhmaṇakumārepi seṭṭhiputtepi mahāsampattiyo pahāya pabbajante disvā pabbajjāguṇaṃ ajānantā kathaṃ samuṭṭhāpenti ‘‘kasmā ete pabbajantī’’ti.   * virūpa = 「異なった、多様な」
  * rūpa = 「姿、形」
* vividha-rūpena = 「種々の姿によって」
* nānā-sabhāvena = 「種々の性質によって」
  * sabhāva = 「性質、本性」
* ti attho = 「という意味である」

→「『さまざまな姿によって』とは、種々の姿によって、種々の性質によって、という意味である。」

9. Kāmaguṇesūti diṭṭhadhammikasamparāyikesu sabbakāmaguṇesu ādīnavaṃ disvā.

* kāmaguṇesū ti = 「『諸々の欲の対象において』とは」
  * kāma-guṇa = 「欲の対象(五欲)」
* diṭṭhadhammika-samparāyikesu = 「現世のものと来世のものとにおける」
  * diṭṭhadhammika = 「現世の、現法の」
  * samparāyika = 「来世の」
* sabba-kāmaguṇesu = 「すべての欲の対象において」
* ādīnavaṃ disvā = 「過患を見て」
  * ādīnava = 「過患、災い」
  * disvā = 「見て(絶対分詞)」

→「『諸々の欲の対象において』とは、現世と来世のすべての欲の対象において過患を見て(ということである)。」

10. Daharāti antamaso kalalamattabhāvaṃ upādāya taruṇā.

* daharā ti = 「『若い者たち』とは」
  * dahara = 「若い、幼い」
* antamaso = 「最少でも、はては〜に至るまで」
* kalala-matta-bhāvaṃ upādāya = 「カララ(受胎直後の状態)にすぎない状態をも含めて」
  * kalala = 「カララ(胎内の最初期の状態)」
  * matta = 「〜にすぎない、〜だけの」
  * upādāya = 「〜を含めて、〜に関して(絶対分詞)」
* taruṇā = 「若い者たち」

→「『若い者たち』とは、はてはカララにすぎない状態をも含めて、若い者たち(ということである)。」

11. Vuḍḍhāti vassasatātikkantā.

* vuḍḍhā ti = 「『老いた者たち』とは」
  * vuḍḍha = 「老いた、年長の」
* vassa-sata-atikkantā = 「百歳を超えた者たち」
  * vassa = 「年、歳」
  * sata = 「百」
  * atikkanta = 「超えた、過ぎた(atikkamati の過去分詞)」

→「『老いた者たち』とは、百歳を超えた者たち(ということである)。」

12. Apaṇṇakaṃ sāmaññameva seyyoti aviruddhaṃ advajjhagāmiṃ ekantaniyyānikaṃ sāmaññameva ‘‘seyyo, uttaritarañca paṇītatarañcā’’ti upadhāretvā pabbajitosmi mahārājāti.

* apaṇṇakaṃ sāmaññam eva seyyo ti = 「『確実な沙門の道こそがすぐれている』とは」
  * apaṇṇaka = 「確実な、誤りのない」
  * sāmañña = 「沙門の道、沙門であること」
  * seyyo = 「よりすぐれている」
* aviruddhaṃ = 「矛盾のない、違背のない」
* advajjha-gāmiṃ = 「二つに分かれず(一路に)進む」(要確認)
  * a-dvajjha = 「二分されない、二途でない」
  * gāmin = 「進む、至る」
* ekanta-niyyānikaṃ = 「ひたすら出離に導く」
  * ekanta = 「ひたすら、一向に」
  * niyyānika = 「出離に導く、解脱へ導く」
* sāmaññam eva = 「沙門の道こそが」
* ‘‘seyyo, uttaritarañ ca paṇītatarañ cā’’ ti = 「『よりすぐれており、より上であり、より勝れている』と」
  * uttaritara = 「より上の」
  * paṇītatara = 「よりすぐれた、より高い」
* upadhāretvā = 「よく考えて、判断して(絶対分詞)」
* pabbajito 'smi = 「私は出家した」
* mahārājā ti = 「『大王よ』と」

→「『確実な沙門の道こそがすぐれている』とは、矛盾がなく、二途に分かれず、ひたすら出離に導く沙門の道こそが『よりすぐれており、より上であり、より勝れている』とよく考えて、大王よ、私は出家したのである(ということである)。」

13. Tasmā yaṃ tvaṃ vadasi – ‘‘kiṃ disvā vā sutvā vā’’ti, idaṃ disvā ca sutvā ca pabbajitosmīti maṃ dhārehīti desanaṃ niṭṭhāpesīti.

* tasmā = 「それゆえ」
* yaṃ tvaṃ vadasi = 「あなたが言うところの」
* ‘‘kiṃ disvā vā sutvā vā’’ ti = 「『何を見て、あるいは聞いて』と」
  * kiṃ = 「何を」
  * disvā = 「見て」
  * sutvā = 「聞いて」
* idaṃ disvā ca sutvā ca = 「このことを見て、そして聞いて」
* pabbajito 'smī ti = 「私は出家したと」
* maṃ dhārehī ti = 「私を(そのように)理解しなさい、と」
  * dhārehi = 「保て、理解せよ(命令形)」
* desanaṃ niṭṭhāpesī ti = 「(と)教説を終えた(ということである)」
  * desanā = 「教説、説示」
  * niṭṭhāpesi = 「終えた、完結させた(niṭṭhāpeti のアオリスト)」

→「それゆえ、あなたが『何を見て、あるいは聞いて』と言うところのことについては、『このことを見て、聞いて私は出家したのだ、と私を理解しなさい』と、(ラッタパーラは)教説を終えたのである。」

14. Papañcasūdaniyā majjhimanikāyaṭṭhakathāya

* Papañcasūdaniyā = 「パパンチャスーダニーの(属格)」
  * Papañcasūdanī = 中部註釈書の名称
* majjhimanikāya-aṭṭhakathāya = 「中部の註釈書の(属格)」
  * aṭṭhakathā = 「註釈書」

→「パパンチャスーダニーという中部の註釈書における」

15. Raṭṭhapālasuttavaṇṇanā niṭṭhitā.

* Raṭṭhapāla-sutta-vaṇṇanā = 「ラッタパーラ経の解説」
  * vaṇṇanā = 「解説、註釈」
* niṭṭhitā = 「終わった、完結した」

→「ラッタパーラ経の解説が終わった。」
