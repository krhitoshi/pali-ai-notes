# 10. Vekhanasasuttavaṇṇanā

## 280

280. Saha vatthukāmena kilesakāmo garu garukātabbo etassāti kāmagaru. Tesveva kāmesu ninnapoṇapabbhārajjhāsayoti kāmādhimutto. Pabbajjāpaṭhamajjhānādikaṃ nekkhammaṃ garu garukātabbaṃ etassāti nekkhammagaru. Tattha ninnapoṇapabbhārajjhāsayo nekkhammādhimutto svāyamattho yathā ekacce gahaṭṭhe labbhati, evaṃ ekacce anagārepīti āha ‘‘pabbajitopī’’tiādi. Ayaṃ pana vekhanaso paribbājako. So hi vekhanasatāpasapabbajjaṃ upagantvā vekhanasena iminā diṭṭhimādāya samādiyitvā ṭhitattā ‘‘vekhanaso’’ti vuccati. Yathā loko sayaṃ ekādasahi aggīhi ādittopi samāno paccakkhato anubhaviyamānaṃ sālākikaṃ aggisantāpaṃ viya anādikālānugatasammākavacarasantāpaṃ ādittatāya na sallakkheti, sammāsambuddhena pana mahākaruṇāsamussāhitamānasena ‘‘sabbaṃ, bhikkhave, āditta’’nti ādittapariyāye (saṃ. ni. 4.28; mahāva. 54) desiyamāne sallakkheti, evaṃ ayampi anādikālaparibhāvitaṃ attaajjhāsaye avaṭṭhitaṃ kāmādhimuttaṃ sarasena anupadhārento satthārā – ‘‘pañca kho ime, kaccāna, kāmaguṇā’’tiādinā kāmaguṇesu kāmasukhe bhāsiyamāne ‘‘kāmādhimuttaṃ vata pabbajitassa citta’’nti upadhāressatīti āha – ‘‘imāya kathāya kathiyamānāya attano kāmādhimuttataṃ sallakkhessatī’’ti. Kāmaggasukhanti kāmetabbavatthūhi aggabhūtaṃ sukhaṃ. Sabbe hi tebhūmakadhammā kāmanīyaṭṭhena kāmā, te paṭicca uppajjanasukhato nibbānasukhameva aggabhūtaṃ sukhaṃ. Yathāha – ‘‘yāvatā, bhikkhave, dhammā saṅkhatā vā asaṅkhatā vā, virāgo tesaṃ aggamakkhāyatī’’ti (itivu. 90; a. ni. 4.34) – ‘‘nibbānaṃ paramaṃ sukha’’nti (ma. ni. 2.215, 217; dha. pa. 203) ca. Tena vuttaṃ ‘‘nibbānaṃ adhippeta’’nti.

2. 280. Saha vatthukāmena kilesakāmo garu garukātabbo etassāti kāmagaru.

* kilesakāmo = 「煩悩としての欲」
* garu = 「重いもの」

* kāmagaru = 「欲を重んじる者」(kāma-garu)

→「事物の欲とともに煩悩の欲が、この者にとって重いもの、重んじられるべきものである、ということで『kāmagaru (欲を重んじる者)』である。」

3. Tesveva kāmesu ninnapoṇapabbhārajjhāsayoti kāmādhimutto.

→「まさにそれらの欲に傾き、向かい、傾斜した意向を持つ者である、ということで『kāmādhimutto (欲に心を向けた者)』である。」

5. Tattha ninnapoṇapabbhārajjhāsayo nekkhammādhimutto svāyamattho yathā ekacce gahaṭṭhe labbhati, evaṃ ekacce anagārepīti āha ‘‘pabbajitopī’’tiādi.

* tattha = 「そこ (出離) において」

* nekkhammādhimutto = 「出離に心を向けた者」(nekkhamma-adhimutta)
* so ayaṃ attho = 「この意味は」(svāyam = so + ayaṃ)

→「そこに傾き、向かい、傾斜した意向を持つ者が『nekkhammādhimutto (出離に心を向けた者)』である。この意味は、ある在家者において得られるように、そのようにある出家者においても (得られる)、ということで (註釈は)『pabbajitopi (出家者もまた)』などと言った。」

9. sammāsambuddhena pana mahākaruṇāsamussāhitamānasena ‘‘sabbaṃ, bhikkhave, āditta’’nti ādittapariyāye (saṃ. ni. 4.28; mahāva. 54) desiyamāne sallakkheti,

10. evaṃ ayampi anādikālaparibhāvitaṃ attaajjhāsaye avaṭṭhitaṃ kāmādhimuttaṃ sarasena anupadhārento satthārā – ‘‘pañca kho ime, kaccāna, kāmaguṇā’’tiādinā kāmaguṇesu kāmasukhe bhāsiyamāne ‘‘kāmādhimuttaṃ vata pabbajitassa citta’’nti upadhāressatīti āha – ‘‘imāya kathāya kathiyamānāya attano kāmādhimuttataṃ sallakkhessatī’’ti.

→「そのようにこの者も、無始の時より薫習され、自らの意向の中に定着している欲への傾倒を、自然には考察しないでいるが、師によって『カッチャーナよ、これら五つの欲の対象がある』などと、欲の対象について欲の楽が語られるとき、『ああ、出家者の心が欲に心を向けている』と考察するであろう、ということで (註釈は)『この話が語られるとき、自らが欲に心を向けていることを認識するだろう』と言った。」

11. Kāmaggasukhanti kāmetabbavatthūhi aggabhūtaṃ sukhaṃ.

* kāmaggasukhaṃ = 「欲の最上の楽」(kāma-agga-sukha)

→「『kāmaggasukhaṃ (欲の最上の楽)』とは、欲されるべき事物の中で最上である楽である。」

12. Sabbe hi tebhūmakadhammā kāmanīyaṭṭhena kāmā, te paṭicca uppajjanasukhato nibbānasukhameva aggabhūtaṃ sukhaṃ.

* sabbe hi = 「というのは、すべての」
* tebhūmaka-dhammā = 「三界の諸法は」
* kāmanīya-aṭṭhena = 「欲されるべきという意味で」
* kāmā = 「欲 (である)」
* te paṭicca = 「それらに依って」
* uppajjana-sukhato = 「生じる楽に比べて」
* nibbānasukhaṃ eva = 「涅槃の楽こそが」
* aggabhūtaṃ sukhaṃ = 「最上である楽 (である)」

→「というのは、すべての三界の諸法は欲されるべきという意味で欲であり、それらに依って生じる楽に比べて、涅槃の楽こそが最上である楽である。」

13. Yathāha – ‘‘yāvatā, bhikkhave, dhammā saṅkhatā vā asaṅkhatā vā, virāgo tesaṃ aggamakkhāyatī’’ti (itivu. 90; a. ni. 4.34) – ‘‘nibbānaṃ paramaṃ sukha’’nti (ma. ni. 2.215, 217; dha. pa. 203) ca.

* yathā āha = 「次のように説かれた通りである」
* yāvatā = 「〜である限り」
* bhikkhave = 「比丘たちよ」
* dhammā saṅkhatā vā asaṅkhatā vā = 「有為あるいは無為の諸法が」
* virāgo = 「離貪が」
* tesaṃ aggaṃ akkhāyati = 「それらの中で最上と説かれる」
* ‘‘nibbānaṃ paramaṃ sukha’’nti ca = 「また『涅槃は最上の楽である』と」

→「次のように説かれた通りである。『比丘たちよ、有為あるいは無為の諸法がある限り、離貪がそれらの中で最上と説かれる』と、また『涅槃は最上の楽である』と。」

14. Tena vuttaṃ ‘‘nibbānaṃ adhippeta’’nti.

* tena = 「それゆえ」
* vuttaṃ = 「言われた」
* ‘‘nibbānaṃ adhippeta’’nti = 「『涅槃が意図されている』と」

→「それゆえ (註釈に)『涅槃が意図されている』と言われた。」

1. 281. Pubbenivāsañāṇalābhino pubbantaṃ ārabbha vuccamānakathā anucchavikā tadatthassa paccakkhabhāvato, tadabhāvato vekhanasassa ananucchavikāti āha ‘‘yasmā…pe… natthī’’ti.

* pubbenivāsañāṇalābhino = 「宿住智を得た者にとって」(pubbenivāsa-ñāṇa-lābhin の属格)
  * pubbenivāsa = 「宿住、過去の生存」
  * lābhin = 「得た者」
* pubbantaṃ ārabbha = 「過去際(過去の極限)に関して」
  * pubbanta = 「過去際」(pubba-anta)
  * ārabbha = 「~に関して、~について」
* vuccamānakathā = 「語られる話」(vuccamāna = vuccati の現在分詞受動)
* anucchavikā = 「ふさわしい」
* tadatthassa paccakkhabhāvato = 「その内容が(彼にとって)直接に知られるものだから」
  * tad-attha = 「その意味、その内容」
  * paccakkha-bhāva = 「直接知られること、現証であること」
* tadabhāvato = 「それ(宿住智)がないので」
* vekhanasassa = 「ヴェーカナサにとって」
* ananucchavikā = 「ふさわしくない」
* ti āha ‘‘yasmā…pe… natthī’’ti = 「と(考えて)"yasmā…pe… natthi"と言った」

→「宿住智を得た者にとっては、過去際に関して語られる話はその内容が直接に知られるものだからふさわしいが、それ(宿住智)がないのでヴェーカナサにはふさわしくない、と(考えて註釈者は)"yasmā(なぜなら)…中略…natthi(ない)"と言った。」

→「"ārakkhatthāya(守護のため)"とは、マントラの句とともに置かれた(糸の結びが)、そこにおいて諸天による守護のため、(という意味である)。」(要確認)

4. Avijjāyāti idaṃ lakkhaṇavacanaṃ, taṃmūlakattā vā sabbakilesadhammānaṃ avijjāva gahitā.
