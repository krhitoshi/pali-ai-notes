1. 318. ‘‘Taṃ kiṃ maññasi, mahārāja, khattiyassa cepi ijjheyya dhanena vā dhaññena vā rajatena vā jātarūpena vā

* taṃ kiṃ maññasi = 「それをどう思いますか」
  * taṃ = 「それを」
  * kiṃ = 「どう、何と」
  * maññasi = 「あなたは思う」(maññati の現在 2 人称単数)
* mahārāja = 「大王よ」(呼格)
* khattiyassa = 「カッティヤ(王族階級の者)にとって」(与格/属格)
* cepi = 「もし〜でも」(ce + pi)
* ijjheyya = 「栄えるならば、成功するならば」(ijjhati の願望法 3 人称単数)
  * khattiyassa ... ijjheyya dhanena で「カッティヤが財産によって栄えるならば」という非人称的な言い方
* dhanena vā = 「財産によってであれ」(具格)
* dhaññena vā = 「穀物によってであれ」

* ti = 引用の終わりを示す

→「この点について私はこのように思います。そしてまた、私はこれを阿羅漢たちからこのように聞いています」と。

12. ‘‘Sādhu sādhu, mahārāja!

* sādhu sādhu = 「よい、よい」
* mahārāja = 「大王よ」

→「よいことです、よいことです、大王よ。」

13. Sādhu kho te etaṃ, mahārāja, evaṃ hoti, sādhu ca pana te etaṃ arahataṃ sutaṃ.

* sādhu kho te etaṃ evaṃ hoti = 「あなたにこれがこのように思われるのは実によい」
* sādhu ca pana te etaṃ arahataṃ sutaṃ = 「そしてまた、あなたがこれを阿羅漢たちから聞いているのもよい」

→「大王よ、あなたがこれについてそのように思うのはよいことです。そしてまた、あなたがこれを阿羅漢たちから聞いているのもよいことです。」

14. Taṃ kiṃ maññasi, mahārāja, yadi evaṃ sante, ime cattāro vaṇṇā samasamā honti no vā?

* taṃ kiṃ maññasi = 「それをどう思うか」
* yadi = 「もし」
* evaṃ sante = 「そのようであるとき」(処格絶対句)
  * sante = 「あるとき」(atthi の現在分詞 santa の処格)
* ime = 「これらの」
* cattāro vaṇṇā = 「四つの階級は」
  * vaṇṇa = 「階級、種姓」(原義は「色」)
* samasamā = 「まったく等しい」
* honti = 「～である」(三人称複数)
* no vā = 「それともそうではないか」

→「大王よ、それをどう思いますか。もしそうであるならば、これら四つの階級はまったく等しいのでしょうか、それともそうではないのでしょうか。」

15. Kathaṃ vā te ettha hotī’’ti?

* kathaṃ vā = 「あるいはどのように」
* te ettha hoti = 「あなたにこの点について(思いが)ある」
* ti = 引用の終わりを示す

→「あるいは、この点についてあなたはどう思いますか」と。

16. ‘‘Addhā kho, bho kaccāna, evaṃ sante, ime cattāro vaṇṇā samasamā honti.

* addhā kho = 「確かに、間違いなく」
* bho kaccāna = 「カッチャーナ殿よ」
* evaṃ sante = 「そのようであるならば」
* ime cattāro vaṇṇā = 「これら四つの階級は」
* samasamā honti = 「まったく等しい」

→「カッチャーナ殿、確かに、そうであるならば、これら四つの階級はまったく等しいのです。」

17. Nesaṃ ettha kiñci nānākaraṇaṃ samanupassāmī’’ti.

* nesaṃ = na + esaṃ 「これらの者たちに～ない」
  * na = 否定
  * esaṃ = 「これらの者たちの」(属格・複数)
* ettha = 「この点において」
* kiñci = 「何らかの」
* nānākaraṇaṃ = 「違い、区別」
* samanupassāmi = 「(私は)見てとる」(samanupassati の現在・一人称単数)
* ti = 引用の終わりを示す

→「この点において、私は彼らの間に何の違いも見いだしません」と。

18. ‘‘Imināpi kho etaṃ, mahārāja, pariyāyena veditabbaṃ yathā ghoso yeveso lokasmiṃ –

* iminā pi = 「これによっても」(具格)
* kho = 強調の不変化詞
* etaṃ = 「このことが」
* mahārāja = 「大王よ」
* pariyāyena = 「道理によって、筋道によって」(具格)
  * iminā pi pariyāyena = 「この道理によっても」
* veditabbaṃ = 「知られるべきである」(vidati の未来受動分詞)
* yathā = 「～ということが、～であるように」
* ghoso = 「声、言い立て」
* yeveso = yeva + eso 「これはただ～にすぎない」
  * yeva = 「ただ～だけ」
  * eso = 「これは」
* lokasmiṃ = 「世間において」(処格)

→「大王よ、この道理によっても、このことが知られるべきです。すなわち、次のことは世間におけるただの言い立てにすぎないということが。」

19. ‘brāhmaṇova seṭṭho vaṇṇo, hīno añño vaṇṇo…pe… brahmadāyādā’’’ti.

* brāhmaṇo va = brāhmaṇo + eva 「バラモンだけが」
* seṭṭho vaṇṇo = 「最上の階級」
* hīno = 「劣った」
* añño vaṇṇo = 「他の階級は」
* …pe… = 省略記号(定型句の中間部分を略す)
* brahmadāyādā = 「ブラフマーの相続者たち」
  * brahma = 「ブラフマー(梵天)」、dāyāda = 「相続者」
* ti = 引用の終わりを示す

→「『バラモンだけが最上の階級であり、他の階級は劣っている…(略)…ブラフマーの相続者である』と。」
