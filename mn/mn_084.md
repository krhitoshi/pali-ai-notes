1. 318. ‘‘Taṃ kiṃ maññasi, mahārāja, khattiyassa cepi ijjheyya dhanena vā dhaññena vā rajatena vā jātarūpena vā

* taṃ kiṃ maññasi = 「それをどう思いますか」
  * taṃ = 「それを」
  * kiṃ = 「どう、何と」
  * maññasi = 「あなたは思う」(maññati の現在 2 人称単数)
* mahārāja = 「大王よ」(呼格)
* khattiyassa = 「カッティヤ(王族階級の者)にとって」(与格/属格)
* cepi = 「もし〜でも」(ce + pi)
* ijjheyya = 「栄えるならば、成功するならば」(ijjhati の願望法 3 人称単数)
  * khattiyassa ... ijjheyya dhanena で「カッティヤが財産によって栄えるならば」という非人称的な言い方
* dhanena vā = 「財産によってであれ」(具格)
* dhaññena vā = 「穀物によってであれ」

Tameva tvaṃ [tametaṃ tvaṃ (syā. kaṃ.), tametaṃ (ka.)] bhagavantaṃ saraṇaṃ gaccha yamahaṃ saraṇaṃ gato’’ti. ‘‘Kahaṃ pana, bho kaccāna, etarahi so bhagavā viharati arahaṃ sammāsambuddho’’ti? ‘‘Parinibbuto kho, mahārāja, etarahi so bhagavā arahaṃ sammāsambuddho’’ti. ‘‘Sacepi mayaṃ, bho kaccāna, suṇeyyāma taṃ bhagavantaṃ dasasu yojanesu, dasapi mayaṃ yojanāni gaccheyyāma taṃ bhagavantaṃ dassanāya arahantaṃ sammāsambuddhaṃ. Sacepi mayaṃ, bho kaccāna, suṇeyyāma taṃ bhagavantaṃ vīsatiyā yojanesu, tiṃsāya yojanesu, cattārīsāya yojanesu, paññāsāya yojanesu, paññāsampi mayaṃ yojanāni gaccheyyāma taṃ bhagavantaṃ dassanāya arahantaṃ sammāsambuddhaṃ. Yojanasate cepi mayaṃ bho kaccāna, suṇeyyāma taṃ bhagavantaṃ, yojanasatampi mayaṃ gaccheyyāma taṃ bhagavantaṃ dassanāya arahantaṃ sammāsambuddhaṃ. Yato ca, bho kaccāna, parinibbuto so bhagavā, parinibbutampi mayaṃ bhagavantaṃ saraṇaṃ gacchāma dhammañca bhikkhusaṅghañca. Upāsakaṃ maṃ bhavaṃ kaccāno dhāretu ajjatagge pāṇupetaṃ saraṇaṃ gata’’nti.

### 対訳

1. 323. Evaṃ vutte, rājā mādhuro avantiputto āyasmantaṃ mahākaccānaṃ etadavoca –

* evaṃ vutte = 「このように言われたとき」
  * vutte = 「言われたとき」(vutta の処格、絶対処格)
* rājā mādhuro = 「マドゥラーの王」
  * mādhura = 「マドゥラーの、マドゥラーに属する」
* avantiputto = 「アヴァンティプッタ」(人名。avanti-putta「アヴァンティの女性の子」の意)
* āyasmantaṃ mahākaccānaṃ = 「尊者マハーカッチャーナに」(対格)
* etad avoca = 「このことを言った」
  * avoca = 「言った」(vatti のアオリスト、三人称単数)

→「このように言われたとき、マドゥラーの王アヴァンティプッタは尊者マハーカッチャーナにこう言った。」

2. ‘‘abhikkantaṃ, bho kaccāna, abhikkantaṃ, bho kaccāna!

* abhikkantaṃ = 「すばらしい、すぐれている」(感嘆の表現)
* bho kaccāna = 「カッチャーナさんよ」(呼格)
  * bho = 敬意をこめた呼びかけの語

→「すばらしい、カッチャーナさんよ。すばらしい、カッチャーナさんよ。」

3. Seyyathāpi, bho kaccāna, nikkujjitaṃ vā ukkujjeyya, paṭicchannaṃ vā vivareyya, mūḷhassa vā maggaṃ ācikkheyya, andhakāre vā telapajjotaṃ dhāreyya – ‘cakkhumanto rūpāni dakkhantī’ti;

* seyyathāpi = 「たとえば〜のように」
* nikkujjitaṃ = 「うつ伏せにされたもの、倒されたものを」
* ukkujjeyya = 「起こすだろう、上向きにするだろう」(願望法、三人称単数)
* paṭicchannaṃ = 「覆われたものを」
* vivareyya = 「開くだろう、覆いを取るだろう」(願望法)
* mūḷhassa = 「道に迷った者に」(与格)
* maggaṃ = 「道を」
* ācikkheyya = 「告げるだろう、教えるだろう」(願望法)
* andhakāre = 「暗闇の中で」(処格)
* telapajjotaṃ = 「油の灯火を」(tela-pajjota)
* dhāreyya = 「掲げるだろう、持つだろう」(願望法)
* vā ... vā ... = 「あるいは〜、あるいは〜」
* cakkhumanto = 「眼のある者たちは」(複数主格)
* rūpāni = 「もろもろの色(形あるもの)を」
* dakkhanti = 「見るだろう」(passati の未来、三人称複数)
* iti = 「〜と(考えて)」

→「たとえば、カッチャーナさんよ、倒されたものを起こすように、あるいは覆われたものを開くように、あるいは道に迷った者に道を教えるように、あるいは『眼のある者たちは色を見るだろう』と考えて暗闇の中で油の灯火を掲げるように、」

4. evamevaṃ bhotā kaccānena anekapariyāyena dhammo pakāsito.

* evamevaṃ = 「まさにそのように」
* bhotā kaccānena = 「カッチャーナさんによって」(具格)
* anekapariyāyena = 「多くの仕方で」(aneka-pariyāya、具格)
  * aneka = 「一つでない、多くの」
  * pariyāya = 「仕方、方法、説き方」
* dhammo = 「法は」
* pakāsito = 「明らかにされた」(pakāseti の過去分詞)

→「まさにそのように、カッチャーナさんによって多くの仕方で法が明らかにされました。」

5. Esāhaṃ bhavantaṃ kaccānaṃ saraṇaṃ gacchāmi dhammañca bhikkhusaṅghañca .

* esāhaṃ = 「この私は」(eso + ahaṃ)
* bhavantaṃ kaccānaṃ = 「カッチャーナさんに」(対格)
* saraṇaṃ gacchāmi = 「帰依します」
  * saraṇa = 「依りどころ、帰依処」
  * gacchāmi = 「行く」(現在、一人称単数)
* dhammañ ca = 「法にも」
* bhikkhusaṅghañ ca = 「比丘サンガにも」

→「この私は、カッチャーナさんに帰依します。法にも比丘サンガにも(帰依します)。」

6. Upāsakaṃ maṃ bhavaṃ kaccāno dhāretu ajjatagge pāṇupetaṃ saraṇaṃ gata’’nti.

* upāsakaṃ = 「在家信者として」(対格)
* maṃ = 「私を」
* bhavaṃ kaccāno = 「カッチャーナさんは」(主格)
* dhāretu = 「覚えておいてください、認めてください」(dhāreti の命令法、三人称単数)
* ajjatagge = 「今日から以後」
* pāṇupetaṃ = 「命のある限り」(pāṇa-upeta「命をそなえた(間)」)
* saraṇaṃ gataṃ = 「帰依した者(として)」(maṃ にかかる)
* iti = 引用の終わり

→「カッチャーナさんは、私を、今日から命のある限り帰依した在家信者として認めてください」と。

7. ‘‘Mā kho maṃ tvaṃ, mahārāja, saraṇaṃ agamāsi.

* mā = 「〜するな」(禁止)
* kho = 強調の不変化詞
* maṃ = 「私に」(対格)
* tvaṃ = 「あなたは」
* mahārāja = 「大王よ」(呼格)
* saraṇaṃ agamāsi = 「帰依した」(gacchati のアオリスト、二人称単数)
  * mā + アオリストで禁止を表す

→「大王よ、あなたは私に帰依してはいけません。」

8. Tameva tvaṃ [tametaṃ tvaṃ (syā. kaṃ.), tametaṃ (ka.)] bhagavantaṃ saraṇaṃ gaccha yamahaṃ saraṇaṃ gato’’ti.

* tam eva = 「まさにその方に」
* tvaṃ = 「あなたは」
* [tametaṃ tvaṃ (syā. kaṃ.), tametaṃ (ka.)] = 異読の注記
  * シャム版・カンボジア版は tametaṃ tvaṃ、ある写本は tametaṃ と読む
* bhagavantaṃ = 「世尊に」(対格)
* saraṇaṃ gaccha = 「帰依しなさい」(命令法、二人称単数)
* yam ahaṃ = 「私が〜したその方に」(yaṃ + ahaṃ)
* saraṇaṃ gato = 「帰依した」(過去分詞)

→「私が帰依したまさにその世尊に、あなたは帰依しなさい」と。

9. ‘‘Kahaṃ pana, bho kaccāna, etarahi so bhagavā viharati arahaṃ sammāsambuddho’’ti?

* kahaṃ = 「どこに」
* pana = 「では、ところで」
* etarahi = 「今」
* so bhagavā = 「その世尊は」
* viharati = 「住んでいる、滞在している」
* arahaṃ = 「阿羅漢」(主格)
* sammāsambuddho = 「正等覚者」

→「では、カッチャーナさんよ、阿羅漢であり正等覚者であるその世尊は、今どこに住んでおられるのですか」と。

10. ‘‘Parinibbuto kho, mahārāja, etarahi so bhagavā arahaṃ sammāsambuddho’’ti.

* parinibbuto = 「般涅槃した」(過去分詞)
* kho = 強調の不変化詞
* etarahi = 「今では」
* so bhagavā arahaṃ sammāsambuddho = 「阿羅漢であり正等覚者であるその世尊は」

→「大王よ、阿羅漢であり正等覚者であるその世尊は、今ではすでに般涅槃されました」と。

11. ‘‘Sacepi mayaṃ, bho kaccāna, suṇeyyāma taṃ bhagavantaṃ dasasu yojanesu, dasapi mayaṃ yojanāni gaccheyyāma taṃ bhagavantaṃ dassanāya arahantaṃ sammāsambuddhaṃ.

* sace pi = 「もし〜ならば」
* mayaṃ = 「私たちは」(王の自称の複数)
* suṇeyyāma = 「聞くならば」(suṇāti の願望法、一人称複数)
* taṃ bhagavantaṃ = 「その世尊を(その世尊が〜におられると)」(対格)
* dasasu yojanesu = 「十ヨージャナのところに」(処格)
  * yojana = 距離の単位
* dasa pi yojanāni = 「十ヨージャナでも」(対格、距離を表す)
* gaccheyyāma = 「行くだろう」(願望法、一人称複数)
* dassanāya = 「見るために、お会いするために」(与格)
* arahantaṃ sammāsambuddhaṃ = 「阿羅漢であり正等覚者である方に」(対格)

→「カッチャーナさんよ、もし私たちが、その世尊が十ヨージャナのところにおられると聞いたならば、阿羅漢であり正等覚者であるその世尊にお会いするために、私たちは十ヨージャナでも行くでしょう。」

12. Sacepi mayaṃ, bho kaccāna, suṇeyyāma taṃ bhagavantaṃ vīsatiyā yojanesu, tiṃsāya yojanesu, cattārīsāya yojanesu, paññāsāya yojanesu, paññāsampi mayaṃ yojanāni gaccheyyāma taṃ bhagavantaṃ dassanāya arahantaṃ sammāsambuddhaṃ.

* vīsatiyā yojanesu = 「二十ヨージャナのところに」
* tiṃsāya yojanesu = 「三十ヨージャナのところに」
* cattārīsāya yojanesu = 「四十ヨージャナのところに」
* paññāsāya yojanesu = 「五十ヨージャナのところに」
* paññāsam pi yojanāni = 「五十ヨージャナでも」
* gaccheyyāma = 「行くだろう」(願望法、一人称複数)

→「カッチャーナさんよ、もし私たちが、その世尊が二十ヨージャナのところに、三十ヨージャナのところに、四十ヨージャナのところに、五十ヨージャナのところにおられると聞いたならば、阿羅漢であり正等覚者であるその世尊にお会いするために、私たちは五十ヨージャナでも行くでしょう。」

13. Yojanasate cepi mayaṃ bho kaccāna, suṇeyyāma taṃ bhagavantaṃ, yojanasatampi mayaṃ gaccheyyāma taṃ bhagavantaṃ dassanāya arahantaṃ sammāsambuddhaṃ.

* yojanasate = 「百ヨージャナのところに」(yojana-sata、処格)

* suṇeyyāma = 「聞くならば」(願望法、一人称複数)

14. Yato ca, bho kaccāna, parinibbuto so bhagavā, parinibbutampi mayaṃ bhagavantaṃ saraṇaṃ gacchāma dhammañca bhikkhusaṅghañca.

* yato ca = 「しかし〜であるからには」
  * yato = 「〜であるから、〜である以上」
* parinibbuto so bhagavā = 「その世尊は般涅槃された」
* parinibbutam pi = 「般涅槃された方であっても」(対格、bhagavantaṃ にかかる)
* mayaṃ = 「私たちは」
* bhagavantaṃ = 「世尊に」
* saraṇaṃ gacchāma = 「帰依します」(現在、一人称複数)
* dhammañ ca bhikkhusaṅghañ ca = 「法にも比丘サンガにも」

→「しかし、カッチャーナさんよ、その世尊は般涅槃されたのですから、私たちは般涅槃された世尊にも帰依します。法にも比丘サンガにも(帰依します)。」

15. Upāsakaṃ maṃ bhavaṃ kaccāno dhāretu ajjatagge pāṇupetaṃ saraṇaṃ gata’’nti.

* upāsakaṃ = 「在家信者として」
* maṃ = 「私を」
* bhavaṃ kaccāno = 「カッチャーナさんは」
* dhāretu = 「認めてください、覚えておいてください」(命令法、三人称単数)
