# 5. Cūḷasaccakasuttaṃ

## 353

353. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā vesāliyaṃ viharati mahāvane kūṭāgārasālāyaṃ. Tena kho pana samayena saccako nigaṇṭhaputto vesāliyaṃ paṭivasati bhassappavādako paṇḍitavādo sādhusammato bahujanassa. So vesāliyaṃ parisati evaṃ vācaṃ bhāsati – ‘‘nāhaṃ taṃ passāmi samaṇaṃ vā brāhmaṇaṃ vā, saṅghiṃ gaṇiṃ gaṇācariyaṃ, api arahantaṃ sammāsambuddhaṃ paṭijānamānaṃ, yo mayā vādena vādaṃ samāraddho na saṅkampeyya na sampakampeyya na sampavedheyya, yassa na kacchehi sedā mucceyyuṃ. Thūṇaṃ cepāhaṃ acetanaṃ vādena vādaṃ samārabheyyaṃ, sāpi mayā vādena vādaṃ samāraddhā saṅkampeyya sampakampeyya sampavedheyya. Ko pana vādo manussabhūtassā’’ti?

Atha kho āyasmā assaji pubbaṇhasamayaṃ nivāsetvā pattacīvaramādāya vesāliṃ piṇḍāya pāvisi. Addasā kho saccako nigaṇṭhaputto vesāliyaṃ jaṅghāvihāraṃ anucaṅkamamāno anuvicaramāno āyasmantaṃ assajiṃ dūratova āgacchantaṃ. Disvāna yenāyasmā assaji tenupasaṅkami; upasaṅkamitvā āyasmatā assajinā saddhiṃ sammodi. Sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā ekamantaṃ aṭṭhāsi. Ekamantaṃ ṭhito kho saccako nigaṇṭhaputto āyasmantaṃ assajiṃ etadavoca – ‘‘kathaṃ pana, bho assaji, samaṇo gotamo sāvake vineti, kathaṃbhāgā ca pana samaṇassa gotamassa sāvakesu anusāsanī bahulā pavattatī’’ti? ‘‘Evaṃ kho, aggivessana, bhagavā sāvake vineti, evaṃbhāgā ca pana bhagavato sāvakesu anusāsanī bahulā pavattati – ‘rūpaṃ, bhikkhave, aniccaṃ, vedanā aniccā, saññā aniccā, saṅkhārā aniccā, viññāṇaṃ aniccaṃ. Rūpaṃ, bhikkhave, anattā, vedanā anattā, saññā anattā, saṅkhārā anattā, viññāṇaṃ anattā. Sabbe saṅkhārā aniccā, sabbe dhammā anattā’ti. Evaṃ kho, aggivessana, bhagavā sāvake vineti, evaṃbhāgā ca pana bhagavato sāvakesu anusāsanī bahulā pavattatī’’ti. ‘‘Dussutaṃ vata, bho assaji, assumha ye mayaṃ evaṃvādiṃ samaṇaṃ gotamaṃ assumha. Appeva nāma mayaṃ kadāci karahaci tena bhotā gotamena saddhiṃ samāgaccheyyāma , appeva nāma siyā kocideva kathāsallāpo, appeva nāma tasmā pāpakā diṭṭhigatā viveceyyāmā’’ti.

7. yo mayā vādena vādaṃ samāraddho na saṅkampeyya na sampakampeyya na sampavedheyya, yassa na kacchehi sedā mucceyyuṃ.

* vādena vādaṃ = 「論をもって論を」
* samāraddho = 「挑まれた、仕掛けられた(samārabhati の過去分詞)」
  * mayā vādena vādaṃ samāraddho = 「私に論で論戦を挑まれて」
* na saṅkampeyya = 「震えない(願望法)」
* na sampakampeyya = 「大きく震えない」
* na sampavedheyya = 「激しくおののかない」
* yassa = 「その者の」

→「私に論で論戦を挑まれて、震えず、大きく震えず、激しくおののかず、脇の下から汗を流さないような者を(私は見ない)。」

8. Thūṇaṃ cepāhaṃ acetanaṃ vādena vādaṃ samārabheyyaṃ, sāpi mayā vādena vādaṃ samāraddhā saṅkampeyya sampakampeyya sampavedheyya.

* thūṇaṃ = 「柱を(thūṇā の対格)」
* cepāhaṃ = ce + pi + ahaṃ = 「もし私が〜さえも」
* acetanaṃ = 「心をもたない」
  * a + cetana = 「意識のない」
* vādena vādaṃ = 「論をもって論を」
* samārabheyyaṃ = 「挑むなら(samārabhati の願望法・一人称単数)」
* sāpi = sā + api = 「それ(柱)でさえ」
* mayā = 「私によって」
* samāraddhā = 「挑まれた(女性形、thūṇā にかかる)」
* saṅkampeyya = 「震えるだろう」
* sampakampeyya = 「大きく震えるだろう」
* sampavedheyya = 「激しくおののくだろう」

→「もし私が心をもたない柱に論で論戦を挑んだとしても、その柱でさえ、私に論戦を挑まれて、震え、大きく震え、激しくおののくだろう。」

11. Addasā kho saccako nigaṇṭhaputto vesāliyaṃ jaṅghāvihāraṃ anucaṅkamamāno anuvicaramāno āyasmantaṃ assajiṃ dūratova āgacchantaṃ.

12. Disvāna yenāyasmā assaji tenupasaṅkami; upasaṅkamitvā āyasmatā assajinā saddhiṃ sammodi.

→「見て、尊者アッサジのところへ近づいた。近づいて、尊者アッサジと挨拶を交わした。」

15. ‘‘kathaṃ pana, bho assaji, samaṇo gotamo sāvake vineti, kathaṃbhāgā ca pana samaṇassa gotamassa sāvakesu anusāsanī bahulā pavattatī’’ti?

16. ‘‘Evaṃ kho, aggivessana, bhagavā sāvake vineti, evaṃbhāgā ca pana bhagavato sāvakesu anusāsanī bahulā pavattati –

17. ‘rūpaṃ, bhikkhave, aniccaṃ, vedanā aniccā, saññā aniccā, saṅkhārā aniccā, viññāṇaṃ aniccaṃ.

→「『比丘たちよ、色は無常である。受は無常である。想は無常である。行は無常である。識は無常である。」

18. Rūpaṃ, bhikkhave, anattā, vedanā anattā, saññā anattā, saṅkhārā anattā, viññāṇaṃ anattā.

* rūpaṃ = 「色は」
* bhikkhave = 「比丘たちよ」
* anattā = 「無我である、自己ではない」
  * an + attā = 「自己でない」
  * 名詞の述語なので主語の性・数にかかわらず anattā の形
* vedanā / saññā / saṅkhārā / viññāṇaṃ = 「受・想・行・識は」

→「比丘たちよ、色は無我である。受は無我である。想は無我である。行は無我である。識は無我である。」

19. Sabbe saṅkhārā aniccā, sabbe dhammā anattā’ti.

20. Evaṃ kho, aggivessana, bhagavā sāvake vineti, evaṃbhāgā ca pana bhagavato sāvakesu anusāsanī bahulā pavattatī’’ti.

21. ‘‘Dussutaṃ vata, bho assaji, assumha ye mayaṃ evaṃvādiṃ samaṇaṃ gotamaṃ assumha.

* dussutaṃ = 「聞いてよくないこと、聞きたくないことを」
  * du + suta = 「悪く聞かれたこと」
* vata = 「ああ、実に(詠嘆)」
* bho assaji = 「アッサジ殿よ」

* evaṃvādiṃ = 「このように説く者である(対格)」

→「『ああ、アッサジ殿、私たちは聞きたくないことを聞いてしまった。沙門ゴータマがこのように説く者だと聞いたのだから。」

22. Appeva nāma mayaṃ kadāci karahaci tena bhotā gotamena saddhiṃ samāgaccheyyāma , appeva nāma siyā kocideva kathāsallāpo, appeva nāma tasmā pāpakā diṭṭhigatā viveceyyāmā’’ti.

* appeva nāma = 「できれば〜だとよいのだが、おそらく〜だろう」

* kadāci karahaci = 「いつか、何かの折に」
* tena bhotā gotamena saddhiṃ = 「あのゴータマ殿と共に」
  * bhotā = 「殿(bhavant の具格)」
* samāgaccheyyāma = 「出会うだろう(samāgacchati の願望法・一人称複数)」
* siyā = 「あるだろう(atthi の願望法)」
* kocideva = koci + eva = 「何らかの」
* kathāsallāpo = 「対話、語り合い」
  * kathā = 「話」

→「アッギヴェッサナよ、私のような、貪りを離れ、怒りを離れ、迷いを離れた、施しを受けるにふさわしい者に依って生じるもの、それはあなたのものとなるだろう」と。

15. Cūḷasaccakasuttaṃ niṭṭhitaṃ pañcamaṃ.

* Cūḷasaccakasuttaṃ = 「チューラサッチャカ経は」
  * cūḷa = 「小さい」
  * saccaka = 「サッチャカ(人名)」
  * sutta = 「経」
* niṭṭhitaṃ = 「終わった」(niṭṭhāti の過去分詞)
* pañcamaṃ = 「第五の」

→「第五のチューラサッチャカ経、終わり。」
