# 3. Maghadevasuttavaṇṇanā

## 308

308. Evaṃme sutanti maghadevasuttaṃ. Tattha maghadevaambavaneti pubbe maghadevo nāma rājā taṃ ambavanaṃ ropesi. Tesu rukkhesu palujjamānesu aparabhāge aññepi rājāno ropesuṃyeva. Taṃ pana paṭhamavohāravasena maghadevambavananteva saṅkhaṃ gataṃ. Sitaṃ pātvākāsīti sāyanhasamaye vihāracārikaṃ caramāno ramaṇīyaṃ bhūmibhāgaṃ disvā – ‘‘vasitapubbaṃ nu kho me imasmiṃ okāse’’ti āvajjanto – ‘‘pubbe ahaṃ maghadevo nāma rājā hutvā imaṃ ambavanaṃ ropesiṃ, ettheva pabbajitvā cattāro brahmavihāre bhāvetvā brahmaloke nibbattiṃ. Taṃ kho panetaṃ kāraṇaṃ bhikkhusaṅghassa apākaṭaṃ, pākaṭaṃ karissāmī’’ti aggaggadante dassento sitaṃ pātu akāsi.

Dhammo assa atthīti dhammiko. Dhammena rājā jātoti dhammarājā. Dhamme ṭhitoti dasakusalakammapathadhamme ṭhito. Dhammaṃ caratīti samaṃ carati . Tatra brāhmaṇagahapatikesūti yopi so pubbarājūhi brāhmaṇānaṃ dinnaparihāro, taṃ ahāpetvā pakatiniyāmeneva adāsi, tathā gahapatikānaṃ. Taṃ sandhāyetaṃ vuttaṃ. Pakkhassāti iminā pāṭihārikapakkhopi saṅgahito. Aṭṭhamīuposathassa hi paccuggamanānuggamanavasena sattamiyañca navamiyañca, cātuddasapannarasānaṃ paccuggamanānuggamanavasena terasiyañca pāṭipade cāti ime divasā pāṭihārikapakkhāti veditabbā. Tesupi uposathaṃ upavasi.

1. 309. Devadūtāti devoti maccu, tassa dūtāti devadūtā.

  * maccu = 「死、死神」
* tassa dūtā ti = 「その(死の)使者たちというので」
  * tassa = 「その(maccu を指す)」
  * dūta = 「使者」
* devadūtā = 「神の使者たち」(deva-dūta、ここでは「死という神の使者」)

→「"神の使者たち" とは、"神" とは死のことであり、その使者たちであるから "神の使者たち" という。」

1. Tattha katamenāti, mahārāja, imesu maggesu eko nirayaṃ gacchati, eko devalokaṃ, tesu taṃ katamena nemi.

* katamenā ti = 「"katamena" とは」

* mahārāja = 「大王よ」(呼格)
* imesu maggesu = 「これらの道のうち」(処格複数)
  * §313 でマータリが虚空に示した二つの道を指す
* eko nirayaṃ gacchati = 「一つは地獄へ行く」
* eko devalokaṃ = 「一つは天界へ(行く)」

2. Yenāti yena maggena gantvā yattha pāpakammantā pāpakānaṃ kammānaṃ vipākaṃ paṭisaṃvediyanti, taṃ ṭhānaṃ sakkā hoti passitunti attho.

→「(ニミ王を)連れ戻して、ほかならぬもとの寝室に落ち着かせた、ということである。」

## 315

315. Kaḷārajanakoti tassa nāmaṃ. Kaḷāradantatāya pana kaḷārajanakoti vutto. Na so agārasmā anagāriyaṃ pabbajīti ettakamattameva na akāsi, sesaṃ sabbaṃ pākatikameva ahosi.

### Meta

### 対訳

1. 315. Kaḷārajanakoti tassa nāmaṃ.

* Kaḷārajanako ti = 「"カラーラジャナカ"とは」
  * 経の本文の語を引用して説明する形
* tassa = 「彼の」
  * ニミ王の子である王子を指す
* nāmaṃ = 「名前」

→「"カラーラジャナカ"とは、彼の名前である。」

2. Kaḷāradantatāya pana kaḷārajanakoti vutto.

* kaḷāra-dantatāya = 「カラーラな歯をもっていたことによって」
  * kaḷāra = 「(歯が)突き出た、不揃いの」(要確認。「黄褐色の」の意の可能性もある)
  * danta = 「歯」
  * -tāya = 抽象名詞 -tā の具格・奪格で、「〜であることによって」と理由を表す
* pana = 「そして、ただし」
* kaḷārajanako ti = 「"カラーラジャナカ"と」
* vutto = 「呼ばれた」(vacati の過去分詞)

→「そして、歯が突き出ていた(要確認)ことから"カラーラジャナカ"と呼ばれたのである。」

3. Na so agārasmā anagāriyaṃ pabbajīti ettakamattameva na akāsi, sesaṃ sabbaṃ pākatikameva ahosi.

* Na so agārasmā anagāriyaṃ pabbajī ti = 「"彼は家から家なき状態へと出家しなかった"とは」
  * na = 「〜ない」
  * so = 「彼は」
  * agārasmā = 「家から」(agāra の奪格)
  * anagāriyaṃ = 「家なき状態へ」
  * pabbajī = 「出家した」(pabbajati のアオリスト)
* ettaka-mattam eva = 「ただこれだけのことを」
  * ettaka = 「これだけの」
  * matta = 「〜のみ、〜ほど」
  * eva = 強調「まさに、だけ」
  * 出家することを指す
* na akāsi = 「行わなかった」(karoti のアオリスト)
* sesaṃ = 「残りは」
* sabbaṃ = 「すべて」
* pākatikam eva = 「まさに通常どおり、もとのまま」
  * 出家以外の点は、歴代の王たちの慣行と変わらなかったという意味
* ahosi = 「であった」(hoti のアオリスト)

→「"彼は家から家なき状態へと出家しなかった"とは、ただこれだけのことを行わなかったのであり、残りはすべて通常どおりであった。」

### 対訳

1. 316. Samucchedo hotīti ettha kalyāṇavattaṃ ko samucchindati, kena samucchinnaṃ, ko pavatteti, kena pavattitaṃ nāma hotīti ayaṃ vibhāgo veditabbo.

* samucchedo hoti = 「断絶がある、断ち切られる」
  * samuccheda = 「断絶、断ち切ること」(男性・単数・主格)
  * マガデーヴァ経本文の語句を見出しとして引いたもの
* iti ettha = 「〜というここでは、〜という箇所では」
* kalyāṇavattaṃ = 「善い慣行を」(kalyāṇa-vatta、中性・単数・対格)
  * kalyāṇa = 「善い、すぐれた」
  * vatta = 「慣行、ならわし、守るべき行い」
  * 以下の四つの問いすべてに共通する対象
* ko samucchindati = 「誰が断ち切るのか」
  * ko = 「誰が」(疑問代名詞・男性・単数・主格)
  * samucchindati = 「断ち切る」(現在・三人称単数)
* kena samucchinnaṃ = 「誰によって断ち切られたのか」
  * kena = 「誰によって」(具格)
  * samucchinna = 「断ち切られた」(samucchindati の過去分詞)
* ko pavatteti = 「誰が続けさせるのか」
  * pavatteti = 「続けさせる、存続させる」(pavattati の使役)
* kena pavattitaṃ nāma hoti = 「誰によって続けさせられたことになるのか」
  * pavattita = 「続けさせられた」(pavatteti の過去分詞)
  * nāma hoti = 「〜と呼ばれる、〜ということになる」
* iti ayaṃ vibhāgo = 「というこの区別が」
  * vibhāga = 「区別、分類」
* veditabbo = 「知られるべきである」(vidati の未来受動分詞、vibhāgo に一致)

→「"断絶がある" というここでは、善い慣行を誰が断ち切るのか、誰によって断ち切られたことになるのか、誰が続けさせるのか、誰によって続けさせられたことになるのか、というこの区別を知るべきである。」

2. Tattha sīlavā bhikkhu ‘‘na sakkā mayā arahattaṃ laddhu’’nti vīriyaṃ akaronto samucchindati.

* tattha = 「そのうち、そこでは」
* sīlavā bhikkhu = 「戒を備えた比丘が」
  * sīlavant = 「戒を持つ、戒を備えた」(男性・単数・主格)
* na sakkā = 「〜できない」
  * sakkā = 「可能である」(不変化詞、不定詞をともなう)
* mayā = 「私によって、私には」(具格)
* arahattaṃ = 「阿羅漢の境地を」(対格)
* laddhuṃ = 「得ることが」(labhati の不定詞)
* iti = 「〜と(考えて)」
* vīriyaṃ = 「精進を、努力を」(対格)
* akaronto = 「行わないで、しないまま」(karoti の現在分詞に否定の a- が付いた形、男性・単数・主格)
* samucchindati = 「断ち切る」
  * 現在形であり、戒はあるが努力しない者が「いま断ち切りつつある者」であることを示す

→「そのうち、戒を備えた比丘が "私には阿羅漢の境地を得ることはできない" と考えて精進をしないなら、(その者が善い慣行を)断ち切る。」

3. Dussīlena samucchinnaṃ nāma hoti.

* dussīlena = 「戒を破った者によって、戒のない者によって」(dussīla、具格)
* samucchinnaṃ = 「断ち切られた」(過去分詞、中性・単数・主格、kalyāṇavattaṃ に一致)
* nāma hoti = 「〜ということになる、〜と呼ばれる」

→「戒を破った者によっては、(善い慣行は)断ち切られたことになる。」

4. Satta sekhā pavattenti.

* satta = 「七、七種の」
* sekhā = 「有学たちが」(sekha、男性・複数・主格)
  * 学ぶべきことがまだ残っている聖者。預流道の者から阿羅漢道の者までの七種を指す
* pavattenti = 「続けさせる、存続させる」(現在・三人称複数)
