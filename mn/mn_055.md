1. 52. ‘‘Ye te, jīvaka, evamāhaṃsu – ‘samaṇaṃ gotamaṃ uddissa pāṇaṃ ārabhanti, taṃ samaṇo gotamo jānaṃ uddissakataṃ maṃsaṃ paribhuñjati paṭiccakamma’nti

* ye te = 「およそ～という者たち」（次項の na me te vuttavādino に続く）
* jīvaka = 「ジーヴァカよ」（呼格。医師ジーヴァカ・コーマーラバッチャ）
* evamāhaṃsu = 「このように言った」（evaṃ + āhaṃsu、āha の三人称複数）
* samaṇaṃ gotamaṃ uddissa = 「沙門ゴータマのために（名指して）」
  * uddissa = 「～を指定して、～のために」（uddisati の連続体）
* pāṇaṃ ārabhanti = 「生き物を殺す」
  * pāṇa = 「生き物、生類」
  * ārabhati = ここでは「（生き物を）殺す」（要確認: 通常の「着手する」ではなく殺生の意の術語）
* taṃ = 「それを」（uddissakataṃ maṃsaṃ を指す）
* samaṇo gotamo = 「沙門ゴータマは」
* jānaṃ = 「知りながら」（jānanta の主格単数）
* uddissakataṃ maṃsaṃ = 「（自分のために）指定して作られた肉を」
  * uddissa-kata = 「名指して（そのために）作られた」
* paribhuñjati = 「食べる、受用する」
* paṭiccakammaṃ = 「（自分に）縁ってなされたもの（である肉）を」
  * 註釈では attānaṃ paṭicca kataṃ（自分を縁として作られたもの）と釈される。maṃsaṃ と同格
* ti = 「～と」（引用の終わり）

→「ジーヴァカよ、『人々は沙門ゴータマのために生き物を殺し、沙門ゴータマはそれと知りながら、自分のために作られた肉、自分に縁ってなされたものを食べる』とこのように言った者たちは、」

2. na me te vuttavādino, abbhācikkhanti ca maṃ te asatā abhūtena.

* na me te vuttavādino = 「彼らは私の言ったとおりを語る者ではない」
  * vuttavādin = 「言われたことを（そのまま）語る者」（vutta-vādin）
* abbhācikkhanti = 「誹謗する、事実に反して非難する」（abhi + ā + √khyā）
* ca = 「そして」
* maṃ = 「私を」
* te = 「彼らは」
* asatā abhūtena = 「事実でないこと、真実でないことによって」
  * asant = 「存在しないこと、事実でないこと」（具格 asatā）
  * abhūta = 「真実でないこと」（具格 abhūtena）

→「彼らは私の言ったとおりを語る者ではなく、事実でない、真実でないことによって私を誹謗しているのである。」

3. Tīhi kho ahaṃ, jīvaka, ṭhānehi maṃsaṃ aparibhoganti vadāmi.

* tīhi ṭhānehi = 「三つの理由によって」
  * ṭhāna = 「理由、根拠、場合」
* kho = 「実に」（強調の不変化詞）
* ahaṃ ... vadāmi = 「私は～と説く」
* maṃsaṃ aparibhogaṃ = 「肉は受用すべきでないもの（である）」
  * aparibhoga = 「受用すべきでない、食べてはならないもの」
* ti = 「～と」

→「ジーヴァカよ、私は三つの理由によって、肉は食べてはならないと説く。」

4. Diṭṭhaṃ, sutaṃ, parisaṅkitaṃ – imehi kho ahaṃ, jīvaka , tīhi ṭhānehi maṃsaṃ aparibhoganti vadāmi.

* diṭṭhaṃ = 「見られたもの」（自分のために殺されるのを見た場合）
* sutaṃ = 「聞かれたもの」（自分のために殺されたと聞いた場合）
* parisaṅkitaṃ = 「疑われたもの」（自分のために殺されたのではと疑われる場合）
  * pari + saṅkita（saṅkati「疑う」の過去分詞）
* imehi tīhi ṭhānehi = 「これら三つの理由によって」

→「（自分のために殺されたと）見られたもの、聞かれたもの、疑われたもの――ジーヴァカよ、私はこれら三つの理由によって、肉は食べてはならないと説く。」

5. Tīhi kho ahaṃ, jīvaka, ṭhānehi maṃsaṃ paribhoganti vadāmi.

* maṃsaṃ paribhogaṃ = 「肉は受用してよいもの（である）」

→「ジーヴァカよ、私は三つの理由によって、肉は食べてよいと説く。」

6. Adiṭṭhaṃ, asutaṃ, aparisaṅkitaṃ – imehi kho ahaṃ, jīvaka, tīhi ṭhānehi maṃsaṃ paribhoganti vadāmi.

→「（自分のために殺されたと）見られていないもの、聞かれていないもの、疑われていないもの――ジーヴァカよ、私はこれら三つの理由によって、肉は食べてよいと説く。」

1. 53. ‘‘Idha, jīvaka, bhikkhu aññataraṃ gāmaṃ vā nigamaṃ vā upanissāya viharati.

* idha = 「ここに(この教えにおいて)」
* jīvaka = 「ジーヴァカよ」(呼格)
* bhikkhu = 「比丘は」
* aññataraṃ = 「ある、どこかの」
* gāmaṃ vā nigamaṃ vā = 「村または町を」
* upanissāya = 「依りどころにして、近くに頼って」(upa-nissayati の連続体)
* viharati = 「住む」

→「ジーヴァカよ、ここに比丘が、ある村または町を依りどころにして住んでいる。」

2. So mettāsahagatena cetasā ekaṃ disaṃ pharitvā viharati, tathā dutiyaṃ, tathā tatiyaṃ, tathā catutthaṃ.

* so = 「彼は」
* mettā-sahagatena cetasā = 「慈をともなう心で」
  * sahagata = 「ともなう、俱行の」
* ekaṃ disaṃ = 「一つの方角を」
* pharitvā = 「満たして、遍満して」(pharati の連続体)
* viharati = 「住む」
* tathā dutiyaṃ = 「同様に第二の(方角を)」
* tathā tatiyaṃ = 「同様に第三の(方角を)」
* tathā catutthaṃ = 「同様に第四の(方角を)」

→「彼は慈をともなう心で一つの方角を満たして住む。同様に第二の方角を、同様に第三の方角を、同様に第四の方角を(満たして住む)。」

3. Iti uddhamadho tiriyaṃ sabbadhi sabbattatāya sabbāvantaṃ lokaṃ mettāsahagatena cetasā vipulena mahaggatena appamāṇena averena abyābajjhena pharitvā viharati.

* iti = 「このように」
* uddham adho = 「上に、下に」
* tiriyaṃ = 「横に」
* sabbadhi = 「あらゆるところに」
* sabbattatāya = 「すべての者を自分と同じように」(伝統釈: 一切の者に対して自己に対するのと等しく)
* sabbāvantaṃ lokaṃ = 「一切を含む世界を」
* mettāsahagatena cetasā = 「慈をともなう心で」
* vipulena = 「広大な」
* mahaggatena = 「大いなる(高められた)」
* appamāṇena = 「無量の」
* averena = 「怨みのない」
* abyābajjhena = 「悩害のない」
* pharitvā viharati = 「満たして住む」

→「このように上に、下に、横に、あらゆるところに、すべての者を自分と同じように、一切を含む世界を、広大で、大いなる、無量の、怨みのない、悩害のない、慈をともなう心で満たして住む。」

4. Tamenaṃ gahapati vā gahapatiputto vā upasaṅkamitvā svātanāya bhattena nimanteti.

* tam enaṃ = 「その彼のもとに」
* gahapati vā gahapatiputto vā = 「居士または居士の息子が」
* upasaṅkamitvā = 「近づいて」
* svātanāya = 「明日のために」

→「ジーヴァカよ、これをどう思うか。いったいその比丘はその時に、自分を害するために意図し、他者を害するために意図し、両者を害するために意図するだろうか。」

11. ‘‘No hetaṃ, bhante’’.

* no hi etaṃ = 「いいえ、それは（ありません）」
* bhante = 「尊師よ」

→「いいえ、尊師よ、それはありません。」

12. ‘‘Nanu so, jīvaka, bhikkhu tasmiṃ samaye anavajjaṃyeva āhāraṃ āhāretī’’ti?

* nanu = 「～ではないか（肯定の答えを促す疑問詞）」
* tasmiṃ samaye = 「その時に」
* anavajjaṃ yeva = 「非難されないものだけを、罪過のないものこそを」
  * anavajja = 「罪過のない、非難の余地のない」
* āhāraṃ āhāreti = 「食物を摂る」

→「ジーヴァカよ、その比丘はその時、罪過のない食物こそを摂るのではないか。」

13. ‘‘Evaṃ, bhante. Sutaṃ metaṃ, bhante – ‘brahmā upekkhāvihārī’ti.

* evaṃ, bhante = 「その通りです、尊師よ」
* sutaṃ me etaṃ = 「私はこれを聞いています」
* brahmā = 「梵天は」
* upekkhā-vihārī = 「捨に住する者」

→「その通りです、尊師よ。尊師よ、私はこう聞いています――『梵天は捨に住する者である』と。」

14. Taṃ me idaṃ, bhante, bhagavā sakkhidiṭṭho; bhagavā hi, bhante, upekkhāvihārī’’ti.

* taṃ me idaṃ = 「その（伝聞の）ことを、私はこの（今）」
* bhagavā = 「世尊が」
* sakkhi-diṭṭho = 「目の当たりに見られた（証人として直接見た）」
  * sakkhi = 「目撃して、直接に」
* bhagavā hi = 「なぜなら世尊こそ」
* upekkhā-vihārī = 「捨に住する者（だから）」

→「尊師よ、そのことを私は今、世尊を目の当たりにして確かめました。なぜなら尊師よ、世尊こそ捨に住する者だからです。」

15. ‘‘Yena kho, jīvaka, rāgena yena dosena yena mohena vihesavā assa arativā assa paṭighavā assa so rāgo so doso so moho tathāgatassa pahīno ucchinnamūlo tālāvatthukato anabhāvaṃkato āyatiṃ anuppādadhammo.

* yena rāgena yena dosena yena mohena = 「その貪によって、その瞋によって、その痴によって」
* vihesavā assa = 「悩害ある者となるであろう（assa = atthi の願望法三人称単数）」
  * vihesavant = 「悩害を持つ」
* arativā assa = 「不満ある者となるであろう」
  * arati = 「不快、不満」
* paṭighavā assa = 「敵意ある者となるであろう」
  * paṭigha = 「敵意、怒り」
* so rāgo so doso so moho = 「その貪、その瞋、その痴は」
* tathāgatassa pahīno = 「如来にとって捨てられた」
* ucchinna-mūlo = 「根が断たれた」
* tālāvatthukato = 「ターラ樹の切り株のようにされた」
  * tāla = 「ターラ樹（palmyra 椰子）」
  * avatthu-kata = 「基盤のないものにされた」
* anabhāvaṃkato = 「存在しないものにされた」
* āyatiṃ anuppāda-dhammo = 「将来に生じない性質のもの」

→「ジーヴァカよ、それによって悩害ある者となり、不満ある者となり、敵意ある者となるであろうその貪、その瞋、その痴は、如来にとって捨てられ、根が断たれ、ターラ樹の切り株のようにされ、存在しないものにされ、将来に生じない性質のものである。」

16. Sace kho te, jīvaka, idaṃ sandhāya bhāsitaṃ, anujānāmi te eta’’nti.

* sace = 「もし」
* te … bhāsitaṃ = 「あなたによって語られたのが」
* idaṃ sandhāya = 「このことを指して」
  * sandhāya = 「～に関して、～を指して（sandahati の連続体）」
* anujānāmi te etaṃ = 「私はあなたにそれを認める」

→「ジーヴァカよ、もしあなたがこのことを指して語ったのなら、私はあなたにそれを認めよう。」

17. ‘‘Etadeva kho pana me, bhante, sandhāya bhāsitaṃ’’.

* etad eva = 「まさにこのことを」
* me … bhāsitaṃ = 「私によって語られました」
* sandhāya = 「指して」

→「尊師よ、私はまさにこのことを指して語ったのです。」
