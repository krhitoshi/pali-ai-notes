# 1. Kandarakasuttaṃ

## 1

1. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā campāyaṃ viharati gaggarāya pokkharaṇiyā tīre mahatā bhikkhusaṅghena saddhiṃ. Atha kho pesso [peyo (ka.)] ca hatthārohaputto kandarako ca paribbājako yena bhagavā tenupasaṅkamiṃsu; upasaṅkamitvā pesso hatthārohaputto bhagavantaṃ abhivādetvā ekamantaṃ nisīdi. Kandarako pana paribbājako bhagavatā saddhiṃ sammodi. Sammodanīyaṃ kathaṃ sāraṇīyaṃ [sārāṇīyaṃ (sī. syā. kaṃ pī.)] vītisāretvā ekamantaṃ aṭṭhāsi. Ekamantaṃ ṭhito kho kandarako paribbājako tuṇhībhūtaṃ tuṇhībhūtaṃ bhikkhusaṅghaṃ anuviloketvā bhagavantaṃ etadavoca – ‘‘acchariyaṃ , bho gotama, abbhutaṃ, bho gotama, yāvañcidaṃ bhotā gotamena sammā bhikkhusaṅgho paṭipādito! * kataṃ karaṇīyaṃ = 「なすべきことはなされた」
* nāparaṃ itthattāya = 「もはやこのような状態(輪廻の生存)には至らない」
  * na aparaṃ = 「これ以上ない」
  * itthattāya = 「このような状態のために」(与格)
* ti pajānāti = 「と知る」

→「『生は尽きた。梵行は完成した。なすべきことはなされた。もはやこのような状態には至らない』と知る。」

13. Ayaṃ vuccati, bhikkhave, puggalo nevattantapo nāttaparitāpanānuyogamanuyutto, na parantapo na paraparitāpanānuyogamanuyutto .

* ayaṃ vuccati = 「この者が〜と言われる」
* bhikkhave = 「比丘たちよ」
* puggalo = 「人」
* n'eva attantapo = 「自らを苦しめる者でもなく」
  * atta-n-tapa = 「自己を苦しめる者」
* na atta-paritāpana-anuyogam anuyutto = 「自らを苦しめる実践に励む者でもなく」
  * paritāpana = 「苦しめること、責め苛むこと」
  * anuyoga = 「実践、専念」
  * anuyutta = 「励む、従事する」
* na parantapo = 「他を苦しめる者でもなく」
  * para-n-tapa = 「他者を苦しめる者」
* na para-paritāpana-anuyogam anuyutto = 「他を苦しめる実践に励む者でもない」

→「比丘たちよ、この者が、自らを苦しめる者でもなく、自らを苦しめる実践に励む者でもなく、他を苦しめる者でもなく、他を苦しめる実践に励む者でもない人と言われる。」

14. So attantapo aparantapo diṭṭheva dhamme nicchāto nibbuto sītībhūto sukhappaṭisaṃvedī brahmabhūtena attanā viharatī’’ti.

* so = 「彼は」
* attantapo = 「自らを苦しめる者」(要確認)
  * 底本の通例では anattantapo「自らを苦しめない者」と読む。ここでは入力の表記のまま再掲するが、文脈上は anattantapo の意で訳す
* aparantapo = 「他を苦しめない者」
  * a-para-n-tapa = 「他者を苦しめない」
* diṭṭh'eva dhamme = 「まさに現世において」
  * diṭṭha-dhamma = 「見られた法、現世」
* nicchāto = 「渇望のない」
  * nis-chāta = 「飢えのない、渇望の消えた」
* nibbuto = 「寂滅した、静まった」
* sītībhūto = 「清涼となった」
* sukha-paṭisaṃvedī = 「楽を感受する者」
* brahmabhūtena attanā = 「梵となった自己によって」
  * brahma-bhūta = 「梵となった、最上のものとなった」
* viharati = 「住む」
* ti = 「と」(引用の終わり)

→「彼は、自らを苦しめず、他を苦しめず、まさに現世において渇望なく、寂滅し、清涼となり、楽を感受しながら、梵となった自己によって住む」と。」

15. Idamavoca bhagavā.

* idam avoca = 「これを語った」
  * avoca = 「語った」(vacati のアオリスト)
* bhagavā = 「世尊は」

→「世尊はこのように語った。」

16. Attamanā te bhikkhū bhagavato bhāsitaṃ abhinandunti.

* attamanā = 「心満たされた、喜んだ」
* te bhikkhū = 「それらの比丘たちは」
* bhagavato bhāsitaṃ = 「世尊の説かれたことを」
* abhinanduṃ = 「歓喜した」(アオリスト、三人称複数)
* ti = 「と」(経の締めくくり)

→「それらの比丘たちは心満たされ、世尊の説かれたことを歓喜した。」

17. Kandarakasuttaṃ niṭṭhitaṃ paṭhamaṃ.

* Kandaraka-suttaṃ = 「カンダラカ経」
* niṭṭhitaṃ = 「終わった」
* paṭhamaṃ = 「第一(の経)」

→「第一のカンダラカ経、終わり。」
