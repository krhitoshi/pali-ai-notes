# 5. Cūḷadhammasamādānasuttaṃ

### 対訳

1. 5. Cūḷadhammasamādānasuttaṃ

* cūḷa-dhamma-samādāna-sutta = 「小法受持経」
  * cūḷa = 「小さい」(対になる Mahādhammasamādānasutta との区別)
  * dhamma-samādāna = 「法の受持、法を受け取って実践すること」
  * samādāna = 「受持、受け取り、取ること」(saṃ + ā + √dā)
  * sutta = 「経」

→「小法受持経」

2. 468. Evaṃ me sutaṃ –

* evaṃ = 「このように」
* me = 「私によって」(ahaṃ の具格)
* sutaṃ = 「聞かれた」(suṇāti の過去分詞)

→「このように私は聞いた。」

3. ekaṃ samayaṃ bhagavā sāvatthiyaṃ viharati jetavane anāthapiṇḍikassa ārāme.

* ekaṃ samayaṃ = 「ある時」(対格による時の表現)
* bhagavā = 「世尊は」
* sāvatthiyaṃ = 「サーヴァッティーにおいて」(処格)
* viharati = 「住んでいる」(現在形、歴史的現在)
* jetavane = 「ジェータ林において」(処格)
* anāthapiṇḍikassa = 「アナータピンディカの」(属格)
* ārāme = 「園において」(処格)

→「ある時、世尊はサーヴァッティーのジェータ林、アナータピンディカの園に住んでおられた。」

4. Tatra kho bhagavā bhikkhū āmantesi – ‘‘bhikkhavo’’ti.

* tatra = 「そこで」
* kho = 「実に」(強調の不変化詞)
* bhagavā = 「世尊は」
* bhikkhū = 「比丘たちに」(対格複数)
* āmantesi = 「呼びかけた」(āmanteti のアオリスト)
* bhikkhavo = 「比丘たちよ」(呼格複数)
* ti = 「と」(引用の終わり)

→「そこで世尊は比丘たちに『比丘たちよ』と呼びかけられた。」

5. ‘‘Bhadante’’ti te bhikkhū bhagavato paccassosuṃ.

* bhadante = 「尊師よ」(呼格)
* ti = 「と」
* te bhikkhū = 「その比丘たちは」
* bhagavato = 「世尊に」(与格)
* paccassosuṃ = 「応答した」(paṭissuṇāti のアオリスト三人称複数)

→「『尊師よ』とその比丘たちは世尊に応答した。」

6. Bhagavā etadavoca –

* bhagavā = 「世尊は」
* etad = 「これを」(etaṃ、連声で etad)
* avoca = 「言った」(vatti のアオリスト)

→「世尊はこう言われた。」

7. ‘‘cattārimāni, bhikkhave, dhammasamādānāni.

* cattāri imāni = 「これら四つの」(連声で cattārimāni)
  * cattāri = 「四つの」(中性)
  * imāni = 「これらの」(中性複数)
* bhikkhave = 「比丘たちよ」
* dhammasamādānāni = 「法の受持が(ある)」(中性複数主格)
  * dhamma = 「法、行い、実践」
  * samādāna = 「受持、受け取って実践すること」

→「比丘たちよ、これら四つの法の受持がある。」

8. Katamāni cattāri?

* katamāni = 「どの、どのような」(疑問形容詞、中性複数)
* cattāri = 「四つ(とは)」

→「どの四つか。」

9. Atthi, bhikkhave, dhammasamādānaṃ paccuppannasukhaṃ āyatiṃ dukkhavipākaṃ;

* atthi = 「ある」(存在を表す動詞)
* bhikkhave = 「比丘たちよ」
* dhammasamādānaṃ = 「法の受持が」(中性単数主格)
* paccuppanna-sukhaṃ = 「現在は楽である」
  * paccuppanna = 「現在の、現に生じている」(paṭi + ud + √pad の過去分詞)
  * sukha = 「楽、安楽」
* āyatiṃ = 「未来に、将来において」(副詞的対格)
* dukkha-vipākaṃ = 「苦の果報をもつ」(所有複合語)
  * vipāka = 「果報、異熟」

→「比丘たちよ、現在は楽であるが未来に苦の果報をもつ法の受持がある。」

10. atthi, bhikkhave , dhammasamādānaṃ paccuppannadukkhañceva āyatiñca dukkhavipākaṃ;

* atthi = 「ある」
* dhammasamādānaṃ = 「法の受持が」
* paccuppanna-dukkhaṃ ca eva = 「現在も苦であり」(連声で paccuppannadukkhañceva)
  * ca eva = 「〜も、まさに」
* āyatiṃ ca = 「未来にも」(連声で āyatiñca)
* dukkha-vipākaṃ = 「苦の果報をもつ」

→「比丘たちよ、現在も苦であり、未来にも苦の果報をもつ法の受持がある。」

11. atthi, bhikkhave, dhammasamādānaṃ paccuppannadukkhaṃ āyatiṃ sukhavipākaṃ;

* atthi = 「ある」
* dhammasamādānaṃ = 「法の受持が」
* paccuppanna-dukkhaṃ = 「現在は苦である」
* āyatiṃ = 「未来に」
* sukha-vipākaṃ = 「楽の果報をもつ」

→「比丘たちよ、現在は苦であるが未来に楽の果報をもつ法の受持がある。」

12. atthi, bhikkhave, dhammasamādānaṃ paccuppannasukhañceva āyatiñca sukhavipākaṃ’’.

* atthi = 「ある」
* dhammasamādānaṃ = 「法の受持が」
* paccuppanna-sukhaṃ ca eva = 「現在も楽であり」(連声で paccuppannasukhañceva)
* āyatiṃ ca = 「未来にも」
* sukha-vipākaṃ = 「楽の果報をもつ」

→「比丘たちよ、現在も楽であり、未来にも楽の果報をもつ法の受持がある。」

### 対訳

1. 469. ‘‘Katamañca, bhikkhave, dhammasamādānaṃ paccuppannasukhaṃ āyatiṃ dukkhavipākaṃ?

* katamañ ca = 「では、どれが～か」(katamaṃ + ca)
* bhikkhave = 「比丘たちよ」
* dhamma-samādānaṃ = 「法の受持(物事の取り組み方、行いのあり方)」
  * samādāna = 「受け取ること、引き受けること、実践」(saṃ + ā + dā)
* paccuppanna-sukhaṃ = 「現在は楽であり」
* āyatiṃ = 「未来に」
* dukkha-vipākaṃ = 「苦の果報をもつ」

→「比丘たちよ、では現在は楽で未来に苦の果報をもつ法の受持とはどれか。」

2. Santi, bhikkhave, eke samaṇabrāhmaṇā evaṃvādino evaṃdiṭṭhino – ‘natthi kāmesu doso’ti.

* santi = 「～がいる」
* eke samaṇa-brāhmaṇā = 「ある沙門・婆羅門たち」
* evaṃ-vādino = 「このように説く者たち」
* evaṃ-diṭṭhino = 「このような見解をもつ者たち」
* natthi kāmesu doso = 「諸欲には過失がない」
  * kāmesu = 「諸欲において」(処格)
  * doso = 「過失、害」
* ti = 「～と」

→「比丘たちよ、ある沙門・婆羅門たちがいて、このように説き、このような見解をもつ。『諸欲には過失がない』と。」

3. Te kāmesu pātabyataṃ āpajjanti.

* te = 「彼らは」
* kāmesu = 「諸欲において」
* pātabyataṃ = 「飲み耽る状態、耽溺」(pātabba「飲まれるべき」+ -tā)
* āpajjanti = 「陥る」

→「彼らは諸欲に耽溺する。」

4. Te kho moḷibaddhāhi [moḷibandhāhi (syā. kaṃ. ka.)] paribbājikāhi paricārenti.

* te kho = 「実に彼らは」
* moḷi-baddhāhi = 「髪を髻(もとどり)に結い上げた」(具格・複数・女性)
  * moḷi = 「髻、結い上げた髪」
  * baddha = 「結ばれた」(bandh の過去分詞)
* paribbājikāhi = 「女性遍歴行者たちと」
* paricārenti = 「楽しむ、戯れる」(paricāreti「侍らせる、快楽を享受する」)

→「実に彼らは、髪を結い上げた女性遍歴行者たちと戯れる。」

5. Te evamāhaṃsu – ‘kiṃsu nāma te bhonto samaṇabrāhmaṇā kāmesu anāgatabhayaṃ sampassamānā kāmānaṃ pahānamāhaṃsu, kāmānaṃ pariññaṃ paññapenti?

* evam āhaṃsu = 「このように言った」
* kiṃsu nāma = 「いったい何を」
* te bhonto samaṇa-brāhmaṇā = 「あの尊者である沙門・婆羅門たちは」
* kāmesu anāgata-bhayaṃ sampassamānā = 「諸欲において未来の怖れを見て」
  * anāgata-bhaya = 「未来の怖れ、来たるべき危険」
  * sampassamānā = 「見つつ」(現在分詞)
* kāmānaṃ pahānam āhaṃsu = 「諸欲の捨断を説いた」
* kāmānaṃ pariññaṃ paññapenti = 「諸欲の遍知を説く(施設する)」

→「彼らはこのように言った。『あの尊者である沙門・婆羅門たちは、いったい諸欲にどんな未来の怖れを見て、諸欲の捨断を説き、諸欲の遍知を説くのか。」

6. Sukho imissā paribbājikāya taruṇāya mudukāya lomasāya bāhāya samphasso’ti te kāmesu pātabyataṃ āpajjanti.

* sukho = 「楽である、心地よい」
* imissā paribbājikāya = 「この女性遍歴行者の」
* taruṇāya = 「若い」
* mudukāya = 「柔らかい」
* lomasāya = 「産毛の生えた」
* bāhāya = 「腕の」
* samphasso = 「触れること、接触」
* ti = 「～と(言って)」
* te kāmesu pātabyataṃ āpajjanti = 「彼らは諸欲に耽溺する」

→「この女性遍歴行者の若く柔らかく産毛の生えた腕に触れるのは心地よい』と(言って)、彼らは諸欲に耽溺する。」

7. Te kāmesu pātabyataṃ āpajjitvā kāyassa bhedā paraṃ maraṇā apāyaṃ duggatiṃ vinipātaṃ nirayaṃ upapajjanti.

* āpajjitvā = 「陥って」(連続体)
* kāyassa bhedā paraṃ maraṇā = 「身体が壊れて、死後に」
* apāyaṃ = 「悪処に」
* duggatiṃ = 「悪趣に」
* vinipātaṃ = 「堕処に」
* nirayaṃ = 「地獄に」
* upapajjanti = 「生まれる」

→「彼らは諸欲に耽溺して、身体が壊れて死後、悪処・悪趣・堕処・地獄に生まれる。」

8. Te tattha dukkhā tibbā kharā kaṭukā vedanā vedayanti.

* tattha = 「そこで」
* dukkhā = 「苦しい」
* tibbā = 「激しい」
* kharā = 「粗い、荒い」
* kaṭukā = 「辛辣な」
* vedanā = 「受(感受)を」(対格・複数)
* vedayanti = 「感受する」

→「彼らはそこで苦しく、激しく、荒く、辛辣な受を感受する。」

9. Te evamāhaṃsu – ‘idaṃ kho te bhonto samaṇabrāhmaṇā kāmesu anāgatabhayaṃ sampassamānā kāmānaṃ pahānamāhaṃsu, kāmānaṃ pariññaṃ paññapenti, ime hi mayaṃ kāmahetu kāmanidānaṃ dukkhā tibbā kharā kaṭukā vedanā vedayāmā’ti.

* idaṃ kho = 「実にこれを」
* te bhonto samaṇa-brāhmaṇā ... paññapenti = 「あの尊者である沙門・婆羅門たちは諸欲において未来の怖れを見て、諸欲の捨断を説き、諸欲の遍知を説く」
* ime hi mayaṃ = 「実にこの私たちは」
* kāma-hetu = 「諸欲を因として」
* kāma-nidānaṃ = 「諸欲を起源として」
* dukkhā tibbā kharā kaṭukā vedanā vedayāma = 「苦しく、激しく、荒く、辛辣な受を感受している」

→「彼らはこのように言った。『実にこれを、あの尊者である沙門・婆羅門たちは諸欲における未来の怖れとして見て、諸欲の捨断を説き、諸欲の遍知を説いたのだ。実にこの私たちは諸欲を因とし、諸欲を起源として、苦しく、激しく、荒く、辛辣な受を感受している』と。」

10. Seyyathāpi, bhikkhave, gimhānaṃ pacchime māse māluvāsipāṭikā phaleyya.

* seyyathāpi = 「たとえば」
* gimhānaṃ pacchime māse = 「夏の最後の月に」
* māluvā-sipāṭikā = 「マールヴァー蔓草の莢(さや)」
  * māluvā = 「マールヴァー(樹木に巻きついて枯らす蔓草)」
  * sipāṭikā = 「莢、種子の鞘」
* phaleyya = 「裂ける、はじける」(願望法)

→「比丘たちよ、たとえば夏の最後の月にマールヴァー蔓草の莢がはじけるとしよう。」

11. Atha kho taṃ, bhikkhave, māluvābījaṃ aññatarasmiṃ sālamūle nipateyya.

* atha kho = 「そして」
* taṃ māluvā-bījaṃ = 「そのマールヴァーの種子が」
* aññatarasmiṃ sāla-mūle = 「あるサーラ樹の根元に」
* nipateyya = 「落ちるとしよう」

→「比丘たちよ、そしてそのマールヴァーの種子があるサーラ樹の根元に落ちるとしよう。」

12. Atha kho, bhikkhave, yā tasmiṃ sāle adhivatthā devatā sā bhītā saṃviggā santāsaṃ āpajjeyya.

* yā tasmiṃ sāle adhivatthā devatā = 「そのサーラ樹に住んでいる神は」
  * adhivattha = 「住んでいる」(adhi + vas の過去分詞)
* sā = 「その(神)は」
* bhītā = 「怖れ」
* saṃviggā = 「動揺し」
* santāsaṃ āpajjeyya = 「恐怖に陥るであろう」

→「比丘たちよ、そしてそのサーラ樹に住んでいる神は、怖れ、動揺し、恐怖に陥るであろう。」

13. Atha kho, bhikkhave, tasmiṃ sāle adhivatthāya devatāya mittāmaccā ñātisālohitā ārāmadevatā vanadevatā rukkhadevatā osadhitiṇavanappatīsu adhivatthā devatā saṅgamma samāgamma evaṃ samassāseyyuṃ –

* tasmiṃ sāle adhivatthāya devatāya = 「そのサーラ樹に住んでいる神の」(属格)
* mittāmaccā = 「友人や同僚たち」(mitta + amacca)
* ñāti-sālohitā = 「親族や血縁者たち」
* ārāma-devatā = 「園の神々」
* vana-devatā = 「林の神々」
* rukkha-devatā = 「樹の神々」
* osadhi-tiṇa-vanappatīsu adhivatthā devatā = 「薬草・草・大樹に住む神々」
  * vanappati = 「森の主、大樹」
* saṅgamma samāgamma = 「集まり、寄り合って」
* evaṃ samassāseyyuṃ = 「このように安心させる(慰める)であろう」(saṃ + ā + sas)

→「比丘たちよ、そしてそのサーラ樹に住んでいる神の友人・同僚、親族・血縁者、園の神々、林の神々、樹の神々、薬草・草・大樹に住む神々が集まり寄り合って、このように安心させるであろう。」

14. ‘mā bhavaṃ bhāyi, mā bhavaṃ bhāyi; appeva nāmetaṃ māluvābījaṃ moro vā gileyya [moro vā gileyya, godhā vā khādeyya (ka.)], mago vā khādeyya, davaḍāho [vanadāho (ka.)] vā ḍaheyya, vanakammikā vā uddhareyyuṃ, upacikā vā uṭṭhaheyyuṃ [udrabheyyuṃ (sī. pī. ka.)], abījaṃ vā panassā’ti.

* mā bhavaṃ bhāyi = 「尊者よ、怖れないでください」
* appeva nāma = 「おそらく、きっと」
* etaṃ māluvā-bījaṃ = 「このマールヴァーの種子を」
* moro vā gileyya = 「孔雀が飲み込むか」
* mago vā khādeyya = 「鹿が食べるか」
* dava-ḍāho vā ḍaheyya = 「野火が焼くか」
* vana-kammikā vā uddhareyyuṃ = 「森の作業者たちが取り除くか」
* upacikā vā uṭṭhaheyyuṃ = 「白蟻たちが掘り起こす(食い荒らす)か」(要確認)
  * upacikā = 「白蟻」
* abījaṃ vā pana assa = 「あるいは(発芽しない)不良の種子であるかもしれない」
  * assa = 「～であろう」(atthi の願望法)

→「『尊者よ、怖れないでください。尊者よ、怖れないでください。きっとこのマールヴァーの種子は、孔雀が飲み込むか、鹿が食べるか、野火が焼くか、森の作業者たちが取り除くか、白蟻たちが掘り起こすか、あるいは不良の種子であるかもしれません』と。」

15. Atha kho taṃ, bhikkhave, māluvābījaṃ neva moro gileyya, na mago khādeyya, na davaḍāho ḍaheyya, na vanakammikā uddhareyyuṃ, na upacikā uṭṭhaheyyuṃ, bījañca panassa taṃ pāvussakena meghena abhippavuṭṭhaṃ sammadeva viruheyya.

* neva moro gileyya = 「孔雀は飲み込まず」
* na mago khādeyya = 「鹿は食べず」
* na dava-ḍāho ḍaheyya = 「野火は焼かず」
* na vana-kammikā uddhareyyuṃ = 「森の作業者たちは取り除かず」
* na upacikā uṭṭhaheyyuṃ = 「白蟻たちは掘り起こさず」
* bījañ ca pana assa taṃ = 「そしてその種子は」
* pāvussakena meghena abhippavuṭṭhaṃ = 「雨期の雲によって大いに降り注がれて」
  * pāvussaka = 「雨期の」
  * abhippavuṭṭha = 「大いに雨を降らされた」
* sammad eva viruheyya = 「よく発芽するであろう」

→「比丘たちよ、しかしそのマールヴァーの種子は、孔雀が飲み込むことも、鹿が食べることも、野火が焼くことも、森の作業者たちが取り除くことも、白蟻たちが掘り起こすこともなく、その種子は雨期の雲によって大いに雨を降らされて、よく発芽するであろう。」

16. Sāssa māluvālatā taruṇā mudukā lomasā vilambinī, sā taṃ sālaṃ upaniseveyya.

* sā assa māluvā-latā = 「その(種子から生えた)マールヴァーの蔓草は」
  * latā = 「蔓草」
* taruṇā = 「若く」
* mudukā = 「柔らかく」
* lomasā = 「産毛のある」
* vilambinī = 「垂れ下がる」
* sā taṃ sālaṃ upaniseveyya = 「それはそのサーラ樹に寄り添う(巻きつく)であろう」

→「そのマールヴァーの蔓草は若く、柔らかく、産毛があり、垂れ下がり、それはそのサーラ樹に寄り添うであろう。」

17. Atha kho, bhikkhave, tasmiṃ sāle adhivatthāya devatāya evamassa – ‘kiṃsu nāma te bhonto mittāmaccā ñātisālohitā ārāmadevatā vanadevatā rukkhadevatā osadhitiṇavanappatīsu adhivatthā devatā māluvābīje anāgatabhayaṃ sampassamānā saṅgamma samāgamma evaṃ samassāsesuṃ [samassāseyyuṃ (ka.)] – ‘‘mā bhavaṃ bhāyi mā bhavaṃ bhāyi, appeva nāmetaṃ māluvābījaṃ moro vā gileyya, mago vā khādeyya, davaḍāho vā ḍaheyya, vanakammikā vā uddhareyyuṃ, upacikā vā uṭṭhaheyyuṃ, abījaṃ vā panassā’’ti;

* tasmiṃ sāle adhivatthāya devatāya evam assa = 「そのサーラ樹に住んでいる神にこのように思われるであろう」
  * evam assa = 「このように～であろう」(思いが生じる)
* kiṃsu nāma = 「いったい何を」
* te bhonto mittāmaccā ... devatā = 「あの尊者である友人・同僚、親族・血縁者、園の神々、林の神々、樹の神々、薬草・草・大樹に住む神々は」
* māluvā-bīje anāgata-bhayaṃ sampassamānā = 「マールヴァーの種子に未来の怖れを見て」
* saṅgamma samāgamma evaṃ samassāsesuṃ = 「集まり寄り合って、このように安心させたのか」(アオリスト)
* mā bhavaṃ bhāyi ... abījaṃ vā panassā ti = 「『尊者よ、怖れないでください……不良の種子であるかもしれません』と」

→「比丘たちよ、そしてそのサーラ樹に住んでいる神にこのように思われるであろう。『あの尊者である友人・同僚、親族・血縁者、園の神々、林の神々、樹の神々、薬草・草・大樹に住む神々は、いったいマールヴァーの種子にどんな未来の怖れを見て、集まり寄り合って、このように安心させたのか。"尊者よ、怖れないでください。尊者よ、怖れないでください。きっとこのマールヴァーの種子は、孔雀が飲み込むか、鹿が食べるか、野火が焼くか、森の作業者たちが取り除くか、白蟻たちが掘り起こすか、あるいは不良の種子であるかもしれません"と。」

18. sukho imissā māluvālatāya taruṇāya mudukāya lomasāya vilambiniyā samphasso’ti.

* sukho = 「心地よい」
* imissā māluvā-latāya = 「このマールヴァーの蔓草の」
* taruṇāya mudukāya lomasāya vilambiniyā = 「若く、柔らかく、産毛があり、垂れ下がる」
* samphasso = 「接触は」

→「この若く、柔らかく、産毛があり、垂れ下がるマールヴァーの蔓草の接触は心地よい』と。」

19. Sā taṃ sālaṃ anuparihareyya.

* sā = 「それ(蔓草)は」
* taṃ sālaṃ = 「そのサーラ樹を」
* anuparihareyya = 「取り巻くであろう、まといつくであろう」(anu + pari + har)

→「それはそのサーラ樹にまといつくであろう。」

20. Sā taṃ sālaṃ anupariharitvā upari viṭabhiṃ [viṭapaṃ (syā. ṭṭha.)] kareyya.

* anupariharitvā = 「まといついて」
* upari = 「上に」
* viṭabhiṃ kareyya = 「枝葉の茂み(樹冠)を作るであろう」
  * viṭabhi = 「枝の茂み、樹冠」

→「それはそのサーラ樹にまといついて、上に枝葉の茂みを作るであろう。」

21. Upari viṭabhiṃ karitvā oghanaṃ janeyya.

* upari viṭabhiṃ karitvā = 「上に枝葉の茂みを作って」
* oghanaṃ janeyya = 「垂れ下がる密生した覆いを生じるであろう」(要確認)
  * oghana = 「垂れ下がる茂み、密な覆い」

→「上に枝葉の茂みを作って、垂れ下がる密生した覆いを生じるであろう。」

22. Oghanaṃ janetvā ye tassa sālassa mahantā mahantā khandhā te padāleyya.

* oghanaṃ janetvā = 「垂れ下がる覆いを生じて」
* ye tassa sālassa mahantā mahantā khandhā = 「そのサーラ樹の大きな大きな幹(主枝)を」
* te padāleyya = 「それらを裂くであろう」

→「垂れ下がる覆いを生じて、そのサーラ樹の大きな大きな幹を裂くであろう。」

23. Atha kho, bhikkhave, tasmiṃ sāle adhivatthāya devatāya evamassa – ‘idaṃ kho te bhonto mittāmaccā ñātisālohitā ārāmadevatā vanadevatā rukkhadevatā osadhitiṇavanappatīsu adhivatthā devatā māluvābīje anāgatabhayaṃ sampassamānā saṅgamma samāgamma evaṃ samassāsesuṃ [samassāseyyuṃ (ka.)] – ‘‘mā bhavaṃ bhāyi mā bhavaṃ bhāyi, appeva nāmetaṃ māluvābījaṃ moro vā gileyya, mago vā khādeyya, davaḍāho vā ḍaheyya, vanakammikā vā uddhareyyuṃ, upacikā vā uṭṭhaheyyuṃ abījaṃ vā panassā’’ti.

* evam assa = 「このように思われるであろう」
* idaṃ kho = 「実にこれを」
* te bhonto ... devatā = 「あの尊者である友人・同僚……薬草・草・大樹に住む神々は」
* māluvā-bīje anāgata-bhayaṃ sampassamānā = 「マールヴァーの種子に未来の怖れを見て」
* saṅgamma samāgamma evaṃ samassāsesuṃ = 「集まり寄り合って、このように安心させたのだ」

→「比丘たちよ、そしてそのサーラ樹に住んでいる神にこのように思われるであろう。『実にこれを、あの尊者である友人・同僚、親族・血縁者、園の神々、林の神々、樹の神々、薬草・草・大樹に住む神々は、マールヴァーの種子における未来の怖れとして見て、集まり寄り合って、このように安心させたのだ。"尊者よ、怖れないでください。尊者よ、怖れないでください。きっとこのマールヴァーの種子は、孔雀が飲み込むか、鹿が食べるか、野火が焼くか、森の作業者たちが取り除くか、白蟻たちが掘り起こすか、あるいは不良の種子であるかもしれません"と。」

24. Yañcāhaṃ [yaṃ vāhaṃ (ka.), svāhaṃ (syā. kaṃ.)] māluvābījahetu dukkhā tibbā kharā kaṭukā vedanā vedayāmī’ti.

* yañ ca ahaṃ = 「そして私は(そのために)」
* māluvā-bīja-hetu = 「マールヴァーの種子を因として」
* dukkhā tibbā kharā kaṭukā vedanā vedayāmi = 「苦しく、激しく、荒く、辛辣な受を感受している」

→「そして私はマールヴァーの種子を因として、苦しく、激しく、荒く、辛辣な受を感受している』と。」

25. Evameva kho, bhikkhave, santi eke samaṇabrāhmaṇā evaṃvādino evaṃdiṭṭhino ‘natthi kāmesu doso’ti .

* evam eva kho = 「まさにそのように」
* santi eke samaṇa-brāhmaṇā = 「ある沙門・婆羅門たちがいる」
* evaṃ-vādino evaṃ-diṭṭhino = 「このように説き、このような見解をもつ」
* natthi kāmesu doso ti = 「『諸欲には過失がない』と」

→「比丘たちよ、まさにそのように、ある沙門・婆羅門たちがいて、このように説き、このような見解をもつ。『諸欲には過失がない』と。」

26. Te kāmesu pātabyataṃ āpajjanti.

* te = 「彼らは」
* kāmesu pātabyataṃ āpajjanti = 「諸欲に耽溺する」

→「彼らは諸欲に耽溺する。」

27. Te moḷibaddhāhi paribbājikāhi paricārenti.

* moḷi-baddhāhi paribbājikāhi = 「髪を結い上げた女性遍歴行者たちと」
* paricārenti = 「戯れる」

→「彼らは髪を結い上げた女性遍歴行者たちと戯れる。」

28. Te evamāhaṃsu – ‘kiṃsu nāma te bhonto samaṇabrāhmaṇā kāmesu anāgatabhayaṃ sampassamānā kāmānaṃ pahānamāhaṃsu, kāmānaṃ pariññaṃ paññapenti?

* evam āhaṃsu = 「このように言った」
* kiṃsu nāma ... sampassamānā = 「いったい諸欲にどんな未来の怖れを見て」
* kāmānaṃ pahānam āhaṃsu = 「諸欲の捨断を説いた」
* kāmānaṃ pariññaṃ paññapenti = 「諸欲の遍知を説く」

→「彼らはこのように言った。『あの尊者である沙門・婆羅門たちは、いったい諸欲にどんな未来の怖れを見て、諸欲の捨断を説き、諸欲の遍知を説くのか。」

29. Sukho imissā paribbājikāya taruṇāya mudukāya lomasāya bāhāya samphasso’ti.

* sukho ... samphasso = 「この女性遍歴行者の若く柔らかく産毛の生えた腕に触れるのは心地よい」

→「この女性遍歴行者の若く柔らかく産毛の生えた腕に触れるのは心地よい』と。」

30. Te kāmesu pātabyataṃ āpajjanti.

* te kāmesu pātabyataṃ āpajjanti = 「彼らは諸欲に耽溺する」

→「彼らは諸欲に耽溺する。」

31. Te kāmesu pātabyataṃ āpajjitvā kāyassa bhedā paraṃ maraṇā apāyaṃ duggatiṃ vinipātaṃ nirayaṃ upapajjanti.

* āpajjitvā = 「陥って」
* kāyassa bhedā paraṃ maraṇā = 「身体が壊れて死後」
* apāyaṃ duggatiṃ vinipātaṃ nirayaṃ upapajjanti = 「悪処・悪趣・堕処・地獄に生まれる」

→「彼らは諸欲に耽溺して、身体が壊れて死後、悪処・悪趣・堕処・地獄に生まれる。」

32. Te tattha dukkhā tibbā kharā kaṭukā vedanā vedayanti.

* tattha = 「そこで」
* dukkhā tibbā kharā kaṭukā vedanā vedayanti = 「苦しく、激しく、荒く、辛辣な受を感受する」

→「彼らはそこで苦しく、激しく、荒く、辛辣な受を感受する。」

33. Te evamāhaṃsu – ‘idaṃ kho te bhonto samaṇabrāhmaṇā kāmesu anāgatabhayaṃ sampassamānā kāmānaṃ pahānamāhaṃsu, kāmānaṃ pariññaṃ paññapenti.

* idaṃ kho = 「実にこれを」
* te bhonto samaṇa-brāhmaṇā ... paññapenti = 「あの尊者である沙門・婆羅門たちは諸欲における未来の怖れとして見て、諸欲の捨断を説き、諸欲の遍知を説いた」

→「彼らはこのように言った。『実にこれを、あの尊者である沙門・婆羅門たちは諸欲における未来の怖れとして見て、諸欲の捨断を説き、諸欲の遍知を説いたのだ。」

34. Ime hi mayaṃ kāmahetu kāmanidānaṃ dukkhā tibbā kharā kaṭukā vedanā vedayāmā’ti.

* ime hi mayaṃ = 「実にこの私たちは」
* kāma-hetu kāma-nidānaṃ = 「諸欲を因とし、諸欲を起源として」
* dukkhā tibbā kharā kaṭukā vedanā vedayāma = 「苦しく、激しく、荒く、辛辣な受を感受している」

→「実にこの私たちは諸欲を因とし、諸欲を起源として、苦しく、激しく、荒く、辛辣な受を感受している』と。」

35. Idaṃ vuccati, bhikkhave, dhammasamādānaṃ paccuppannasukhaṃ āyatiṃ dukkhavipākaṃ.

* idaṃ vuccati = 「これが～と言われる」
* dhamma-samādānaṃ paccuppanna-sukhaṃ āyatiṃ dukkha-vipākaṃ = 「現在は楽で未来に苦の果報をもつ法の受持」

→「比丘たちよ、これが現在は楽で未来に苦の果報をもつ法の受持と言われる。」

470. ‘‘Katamañca, bhikkhave, dhammasamādānaṃ paccuppannadukkhañceva āyatiñca dukkhavipākaṃ? Idha, bhikkhave, ekacco acelako hoti muttācāro hatthāpalekhano, naehibhaddantiko, natiṭṭhabhaddantiko, nābhihaṭaṃ, na uddissakataṃ, na nimantanaṃ sādiyati, so na kumbhimukhā paṭiggaṇhāti, na kaḷopimukhā paṭiggaṇhāti, na eḷakamantaraṃ, na daṇḍamantaraṃ, na musalamantaraṃ, na dvinnaṃ bhuñjamānānaṃ, na gabbhiniyā, na pāyamānāya, na purisantaragatāya, na saṅkittīsu, na yattha sā upaṭṭhito hoti, na yattha makkhikā saṇḍasaṇḍacārinī, na macchaṃ, na maṃsaṃ, na suraṃ, na merayaṃ, na thusodakaṃ pivati. So ekāgāriko vā hoti ekālopiko, dvāgāriko vā hoti dvālopiko…pe… sattāgāriko vā hoti sattālopiko. Ekissāpi dattiyā yāpeti, dvīhipi dattīhi yāpeti… sattahipi dattīhi yāpeti. * vuccati = 「と言われる」

→「比丘たちよ、これが、現在に苦であって未来に楽の果報をもつ法の受持と言われる。」
