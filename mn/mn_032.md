# 2. Mahāgosiṅgasuttaṃ

## 332

332. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā gosiṅgasālavanadāye viharati sambahulehi abhiññātehi abhiññātehi therehi sāvakehi saddhiṃ – āyasmatā ca sāriputtena āyasmatā ca mahāmoggallānena āyasmatā ca mahākassapena āyasmatā ca anuruddhena āyasmatā ca revatena āyasmatā ca ānandena, aññehi ca abhiññātehi abhiññātehi therehi sāvakehi saddhiṃ. Atha kho āyasmā mahāmoggallāno sāyanhasamayaṃ paṭisallānā vuṭṭhito yenāyasmā mahākassapo tenupasaṅkami; upasaṅkamitvā āyasmantaṃ mahākassapaṃ etadavoca – ‘‘āyāmāvuso, kassapa, yenāyasmā sāriputto tenupasaṅkamissāma dhammassavanāyā’’ti. ‘‘Evamāvuso’’ti kho āyasmā mahākassapo āyasmato mahāmoggallānassa paccassosi. Atha kho āyasmā ca mahāmoggallāno āyasmā ca mahākassapo āyasmā ca anuruddho yenāyasmā sāriputto tenupasaṅkamiṃsu dhammassavanāya. Addasā kho āyasmā ānando āyasmantañca mahāmoggallānaṃ āyasmantañca mahākassapaṃ āyasmantañca anuruddhaṃ yenāyasmā sāriputto tenupasaṅkamante dhammassavanāya. Disvāna yenāyasmā revato tenupasaṅkami; upasaṅkamitvā āyasmantaṃ revataṃ etadavoca – ‘‘upasaṅkamantā kho amū, āvuso [āyasmantāvuso (ka.)] revata, sappurisā yenāyasmā sāriputto tena dhammassavanāya. Āyāmāvuso revata, yenāyasmā sāriputto tenupasaṅkamissāma dhammassavanāyā’’ti. ‘‘Evamāvuso’’ti kho āyasmā revato āyasmato ānandassa paccassosi. Atha kho āyasmā ca revato āyasmā ca ānando yenāyasmā sāriputto tenupasaṅkamiṃsu dhammassavanāya.

### 対訳

1. 333. Addasā kho āyasmā sāriputto āyasmantañca revataṃ āyasmantañca ānandaṃ dūratova āgacchante.

* addasā = 「見た」(dassati / passati のアオリスト 3 人称単数)
* kho = 「さて、実に」(強調の不変化詞)
* āyasmā sāriputto = 「尊者サーリプッタは」(主格)
* āyasmantañ ca revataṃ = 「尊者レーヴァタを」(対格)
* āyasmantañ ca ānandaṃ = 「尊者アーナンダを」(対格)
  * ca ... ca = 「～と～とを」
* dūrato va = 「遠くから(すでに)」
  * dūrato = 「遠くから」(奪格)
  * va = eva 「まさに」
* āgacchante = 「やって来るのを」(āgacchati の現在分詞、対格複数)

→「さて、尊者サーリプッタは、尊者レーヴァタと尊者アーナンダが遠くからやって来るのを見た。」

2. Disvāna āyasmantaṃ ānandaṃ etadavoca –

* disvāna = 「見て」(連続体)
* āyasmantaṃ ānandaṃ = 「尊者アーナンダに」(対格)
* etad avoca = 「このように言った」
  * etad = 「これを」
  * avoca = 「言った」(vatti のアオリスト 3 人称単数)

→「見て、尊者アーナンダにこのように言った。」

3. ‘‘etu kho āyasmā ānando!

* kho = 強調の不変化詞
* āyasmā ānando = 「尊者アーナンダは」(主格)

→「尊者アーナンダよ、どうぞおいでください。」

4. Svāgataṃ āyasmato ānandassa bhagavato upaṭṭhākassa bhagavato santikāvacarassa!

* svāgataṃ = 「ようこそ、よく来られた」(su + āgata)
* āyasmato ānandassa = 「尊者アーナンダに」(与格)
* bhagavato upaṭṭhākassa = 「世尊の侍者である(アーナンダに)」
  * bhagavato = 「世尊の」(属格)
  * upaṭṭhāka = 「侍者、そばで仕える者」
* bhagavato santikāvacarassa = 「世尊のそば近くにいる(アーナンダに)」
  * santika = 「近く、そば」
  * avacara = 「～を行動範囲とする者」

→「世尊の侍者であり、世尊のそば近くにいる尊者アーナンダよ、ようこそ。」

5. Ramaṇīyaṃ, āvuso ānanda, gosiṅgasālavanaṃ, dosinā ratti, sabbaphāliphullā [sabbapāliphullā (sī.)] sālā, dibbā, maññe, gandhā sampavanti;

* ramaṇīyaṃ = 「楽しい、心地よい、美しい」
* āvuso ānanda = 「友アーナンダよ」(呼格)
* gosiṅgasālavanaṃ = 「ゴーシンガ・サーラ林は」(主格)
  * gosiṅga = 固有名ゴーシンガ(語としては「牛の角」)
  * sāla-vana = 「サーラ樹の林」
* dosinā ratti = 「月の明るい夜(である)」
  * dosinā = 「月明かりのある、晴れわたった」
  * ratti = 「夜」
* sabbaphāliphullā sālā = 「サーラ樹はすべて満開である」
  * sabba = 「すべて」
  * phāliphulla = 「花が咲きほこった、満開の」

* dibbā gandhā = 「天の香りが」(主格複数)
* maññe = 「思うに、まるで～のようだ」(挿入句)
* sampavanti = 「漂っている、吹きわたっている」(現在 3 人称複数)

→「友アーナンダよ、ゴーシンガ・サーラ林は心地よく、夜は月が明るく、サーラ樹はすべて満開で、まるで天の香りが漂っているかのようだ。」

6. kathaṃrūpena, āvuso ānanda, bhikkhunā gosiṅgasālavanaṃ sobheyyā’’ti?

* kathaṃrūpena = 「どのような(あり方の)」(具格、bhikkhunā にかかる)

* sobheyya = 「輝くだろう、美しく映えるだろう」(sobhati の願望法 3 人称単数)
* ti = 引用の終わりを示す

→「友アーナンダよ、どのような比丘によってゴーシンガ・サーラ林は輝くのだろうか」と。

7. ‘‘Idhāvuso sāriputta , bhikkhu bahussuto hoti sutadharo sutasannicayo.

* idha = 「ここに、この(教えの)中で」
* āvuso sāriputta = 「友サーリプッタよ」(呼格)
* bhikkhu = 「比丘は」(主格)
* bahussuto hoti = 「多く聞いた者である」
  * bahu = 「多く」
  * suta = 「聞かれたもの、聞いて学んだこと」
* sutadharo = 「聞いたことを保持する者」
  * dhara = 「保つ者」
* sutasannicayo = 「聞いたことを蓄積した者」
  * sannicaya = 「蓄積、たくわえ」

→「友サーリプッタよ、ここに比丘が、多く聞いた者であり、聞いたことを保持し、聞いたことを蓄積している。」

8. Ye te dhammā ādikalyāṇā majjhekalyāṇā pariyosānakalyāṇā sātthā sabyañjanā;

* ye te dhammā = 「それらの教えで～であるもの」(関係代名詞 ye + 指示代名詞 te、主格複数)
  * dhammā = 「教え、法」
* ādikalyāṇā = 「初めが善い」
  * ādi = 「初め」
  * kalyāṇa = 「善い、美しい」
* majjhekalyāṇā = 「中ほどが善い」
* pariyosānakalyāṇā = 「終わりが善い」
* sātthā = 「意味をそなえた」(sa + attha)
* sabyañjanā = 「文言(字句)をそなえた」(sa + byañjana)

* bhante = 「尊師よ」

  * bhāsita = 「語られた(bhāsati の過去分詞)」
* ti = 「と」

→「"尊師よ、いったい誰の言葉がよく語られたものでしょうか" と。」

3. ‘‘Sabbesaṃ vo, sāriputta, subhāsitaṃ pariyāyena.

* sabbesaṃ = 「すべての者の」
* vo = 「あなたたちの」
* sāriputta = 「サーリプッタよ」
* subhāsitaṃ = 「よく語られたこと」
* pariyāyena = 「それぞれの観点から、ある仕方で」
  * pariyāya = 「観点、仕方、道筋」の具格

→「"サーリプッタよ、あなたたち全員の言葉が、それぞれの観点からよく語られたものである。」

4. Api ca mamapi suṇātha yathārūpena bhikkhunā gosiṅgasālavanaṃ sobheyya.

* api ca = 「しかしまた、さらに」
* mama pi = 「私の(言葉)も」
* suṇātha = 「聞きなさい(suṇāti の命令法 2 人称複数)」
* yathārūpena = 「どのような(yathā-rūpa の具格)」
* bhikkhunā = 「比丘によって」
* gosiṅga-sāla-vanaṃ = 「ゴーシンガのサーラ樹の林が」
  * gosiṅga = 「ゴーシンガ(地名)」
  * sāla = 「サーラ樹」
  * vana = 「林」
* sobheyya = 「輝くだろう(sobhati の願望法 3 人称単数)」

→「しかし、どのような比丘によってゴーシンガのサーラ樹の林が輝くのか、私の言葉も聞きなさい。」

5. Idha, sāriputta, bhikkhu pacchābhattaṃ piṇḍapātapaṭikkanto nisīdati pallaṅkaṃ ābhujitvā ujuṃ kāyaṃ paṇidhāya parimukhaṃ satiṃ upaṭṭhapetvā –

* idha = 「ここに、この教えにおいて」
* sāriputta = 「サーリプッタよ」
* bhikkhu = 「比丘は」
* pacchābhattaṃ = 「食後に」(pacchā-bhatta)
* piṇḍapāta-paṭikkanto = 「托鉢から戻った者として」
  * piṇḍapāta = 「托鉢、托鉢で得た食」
  * paṭikkanta = 「戻った(paṭikkamati の過去分詞)」
* nisīdati = 「坐る」
* pallaṅkaṃ ābhujitvā = 「結跏趺坐を組んで」
  * pallaṅka = 「結跏趺坐」
  * ābhujitvā = 「組んで、曲げて(ābhujati の連続体)」
* ujuṃ kāyaṃ paṇidhāya = 「身体をまっすぐに保って」
  * uju = 「まっすぐな」
  * paṇidhāya = 「据えて、保って(paṇidahati の連続体)」
* parimukhaṃ = 「面前に」
* satiṃ upaṭṭhapetvā = 「念を確立して」
  * upaṭṭhapetvā = 「確立して(upaṭṭhapeti の連続体)」

→「サーリプッタよ、ここに比丘が、食後に托鉢から戻り、結跏趺坐を組み、身体をまっすぐに保ち、面前に念を確立して坐る。」

6. ‘na tāvāhaṃ imaṃ pallaṅkaṃ bhindissāmi yāva me nānupādāya āsavehi cittaṃ vimuccissatī’ti.

* na tāva ... yāva na ... = 「～しない間は、それまで～しない」
  * tāva = 「それまで」
  * yāva = 「～する間は、～まで」
* ahaṃ = 「私は」
* imaṃ pallaṅkaṃ = 「この結跏趺坐を」
* bhindissāmi = 「解くだろう、崩すだろう(bhindati の未来 1 人称単数)」
* me = 「私の」
* na anupādāya = 「執着することなく～しない(間は)」
  * anupādāya = 「執着しないで(an-upādāya、upādiyati の連続体に否定の接頭辞)」
  * na は vimuccissati にかかる
* āsavehi = 「諸々の漏から」
* cittaṃ = 「心が」
* vimuccissati = 「解脱するだろう(vimuccati の未来 3 人称単数)」
* ti = 「と(決意の内容を示す)」

→「"私の心が執着することなく諸々の漏から解脱しない間は、私はこの結跏趺坐を解かない" と(決意して)。」

7. Evarūpena kho, sāriputta, bhikkhunā gosiṅgasālavanaṃ sobheyyā’’ti.

* evarūpena = 「このような(eva-rūpa の具格)」
* kho = 「実に(強調の不変化詞)」
* sāriputta = 「サーリプッタよ」
* bhikkhunā = 「比丘によって」
* gosiṅga-sāla-vanaṃ = 「ゴーシンガのサーラ樹の林が」
* sobheyya = 「輝くだろう(sobhati の願望法 3 人称単数)」
* ti = 「と」

→「サーリプッタよ、このような比丘によってこそ、ゴーシンガのサーラ樹の林は輝くだろう" と。」

8. Idamavoca bhagavā.

* idaṃ = 「このことを」
* avoca = 「言った(vatti のアオリスト 3 人称単数)」
* bhagavā = 「世尊は」

→「世尊はこのことを言った。」

9. Attamanā te āyasmanto [te bhikkhū (ka.)] bhagavato bhāsitaṃ abhinandunti.

* attamanā = 「心に満足した、喜んだ」(atta-mana)
* te āyasmanto = 「その尊者たちは」
  * āyasmanto = 「尊者たち(āyasmant の主格複数)」
* [te bhikkhū (ka.)] = 「異読: "その比丘たちは"」
  * (ka.) は異読の出所を示す版の略号
* bhagavato = 「世尊の」
* bhāsitaṃ = 「語られたことを、言葉を」
* abhinanduṃ = 「歓喜した、喜んで受け入れた(abhinandati のアオリスト 3 人称複数)」
* ti = 「と(経の結びを示す)」

→「その尊者たち(異読: その比丘たち)は心に満足して、世尊の言葉を喜んで受け入れた。」

10. Mahāgosiṅgasuttaṃ niṭṭhitaṃ dutiyaṃ.

* mahā-gosiṅga-suttaṃ = 「マハーゴーシンガ経」
  * mahā = 「大きな」
  * gosiṅga = 「ゴーシンガ(地名)」
  * sutta = 「経」
* niṭṭhitaṃ = 「終わった(niṭṭhāti の過去分詞)」
* dutiyaṃ = 「第二の」

→「第二のマハーゴーシンガ経が終わった。」
