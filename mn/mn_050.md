# 10. Māratajjanīyasuttaṃ

## 506

Atha kho mārassa pāpimato etadahosi – ‘‘ajānameva kho maṃ ayaṃ samaṇo apassaṃ evamāha – ‘nikkhama, pāpima; nikkhama, pāpima! Mā tathāgataṃ vihesesi, mā tathāgatasāvakaṃ. Mā te ahosi dīgharattaṃ ahitāya dukkhāyāti. Yopissa so satthā sopi maṃ neva khippaṃ jāneyya, kuto pana maṃ ayaṃ sāvako jānissatī’’’ti?

## 507 (1)

507. Addasā kho āyasmā mahāmoggallāno māraṃ pāpimantaṃ paccaggaḷe ṭhitaṃ; disvāna māraṃ pāpimantaṃ etadavoca – ‘etthāpi kho tāhaṃ, pāpima, passāmi; mā tvaṃ maññittho ‘‘na maṃ passatī’’ti. Eso tvaṃ, pāpima, paccaggaḷe ṭhito. Bhūtapubbāhaṃ, pāpima, dūsī nāma māro ahosiṃ, tassa me kāḷī nāma bhaginī. Tassā tvaṃ putto. So me tvaṃ bhāgineyyo ahosi. Tena kho pana, pāpima, samayena kakusandho bhagavā arahaṃ sammāsambuddho loke uppanno hoti. Kakusandhassa kho pana, pāpima, bhagavato arahato sammāsambuddhassa vidhurasañjīvaṃ nāma sāvakayugaṃ ahosi aggaṃ bhaddayugaṃ. Yāvatā kho pana, pāpima, kakusandhassa bhagavato arahato sammāsambuddhassa sāvakā. Tesu na ca koci āyasmatā vidhurena samasamo hoti yadidaṃ dhammadesanāya. Iminā kho evaṃ [etaṃ (sī. syā. pī.)], pāpima, pariyāyena āyasmato vidhurassa vidhuroteva [vidhurassa vidhuro vidhurotveva (sī. syā. kaṃ. pī.)] samaññā udapādi.

1. 507. Addasā kho āyasmā mahāmoggallāno māraṃ pāpimantaṃ paccaggaḷe ṭhitaṃ;

* addasā = 「見た」(dassati / passati のアオリスト)
* kho = 「実に」(強調の小辞)
* āyasmā mahāmoggallāno = 「尊者マハーモッガッラーナは」
* māraṃ pāpimantaṃ = 「悪魔マーラを」
  * pāpimant = 「悪しき者」(pāpa + 所有接尾辞 -mant)
* paccaggaḷe = 「門の閂のそば(閂の内側)に」(処格)
  * paccaggaḷa = 「門の閂の背後、閂のところ」(paṭi + aggaḷa)。註釈は「閂の背後、扉の後ろ」と説明する (要確認)
* ṭhitaṃ = 「立っている(のを)」(tiṭṭhati の過去分詞、対格)

→「尊者マハーモッガッラーナは、悪魔マーラが門の閂のそばに立っているのを見た。」

2. disvāna māraṃ pāpimantaṃ etadavoca –

* disvāna = 「見て」(passati の絶対分詞)
* māraṃ pāpimantaṃ = 「悪魔マーラに」
* etadavoca = 「このことを言った」(etad + avoca)
  * avoca = 「言った」(vatti のアオリスト)

→「悪魔マーラを見て、このように言った。」

3. ‘etthāpi kho tāhaṃ, pāpima, passāmi; mā tvaṃ maññittho ‘‘na maṃ passatī’’ti.

* etthāpi = 「ここにおいても」(ettha + api)
* kho = 「実に」
* tāhaṃ = 「私はあなたを」(taṃ + ahaṃ)
* pāpima = 「悪しき者よ」(呼格)
* passāmi = 「私は見る」
* mā tvaṃ maññittho = 「あなたは思ってはならない」
  * mā = 「〜するな」(禁止の小辞)
  * maññittho = 「思った、考えた」(maññati のアオリスト、mā と結んで禁止)
* na maṃ passatī ti = 「『(彼は)私を見ていない』と」
  * passati = 「見る」

→「『悪しき者よ、私はここでもあなたを見ている。あなたは「(彼は)私を見ていない」と思ってはならない。』」

4. Eso tvaṃ, pāpima, paccaggaḷe ṭhito.

* eso tvaṃ = 「そこにいるあなたは」
* pāpima = 「悪しき者よ」
* paccaggaḷe ṭhito = 「門の閂のそばに立っている」

→「悪しき者よ、そこにいるあなたは、門の閂のそばに立っている。」

5. Bhūtapubbāhaṃ, pāpima, dūsī nāma māro ahosiṃ, tassa me kāḷī nāma bhaginī.

* bhūtapubbāhaṃ = 「かつて私は」(bhūtapubbaṃ + ahaṃ)
  * bhūtapubbaṃ = 「以前に、昔」(副詞的対格)
* pāpima = 「悪しき者よ」
* dūsī nāma māro = 「ドゥーシーという名のマーラ」
  * dūsī = 「ドゥーシー(『汚す者』の意)」(dūseti「汚す、害する」から)
* ahosiṃ = 「私は〜であった」(hoti のアオリスト、一人称単数)
* tassa me = 「そのような私には」
* kāḷī nāma bhaginī = 「カーリーという名の妹(姉妹)」

* pubbavidehānaṃ = 「プッバヴィデーハ(東勝身洲)の人々の」
* ye ca = 「また～である(人々を)」
* bhūmisayā = 「地上に住む、地に臥す」(bhūmi-saya)
* narā = 「人々」

→「プッバヴィデーハの人々の森と、地上に住む人々とに(触れた者)。」

12. ‘‘Yo etamabhijānāti, bhikkhu buddhassa sāvako;

* yo etaṃ abhijānāti = 「これを証知する者は」
* bhikkhu buddhassa sāvako = 「比丘、仏の弟子」

→「これを証知する比丘、仏の弟子、」

13. Tādisaṃ bhikkhumāsajja, kaṇha dukkhaṃ nigacchasi.

* tādisaṃ bhikkhuṃ āsajja = 「そのような比丘を害して」
* kaṇha = 「黒い者よ」
* dukkhaṃ nigacchasi = 「あなたは苦に陥る」

→「黒い者よ、そのような比丘を害して、あなたは苦に陥る。」

14. ‘‘Na ve aggi cetayati [veṭhayati (sī.)], ‘ahaṃ bālaṃ ḍahāmī’ti;

* na ve = 「決して～ない」
* aggi = 「火は」
* cetayati = 「意図する、思う」
  * 異読 veṭhayati (シンハラ本) (要確認)
* ahaṃ = 「私は」
* bālaṃ = 「愚者を」
* ḍahāmi = 「焼く」
* ti = 「～と」

→「火は『私は愚者を焼こう』と決して意図しない。」

15. Bālo ca jalitaṃ aggiṃ, āsajja naṃ sa ḍayhati.

* bālo ca = 「しかし愚者は」
* jalitaṃ aggiṃ = 「燃えている火を」
* āsajja naṃ = 「それに手を出して、それを襲って」
* sa = 「彼は」(so)
* ḍayhati = 「焼かれる」(ḍahati の受動)

→「しかし愚者は、燃えている火に手を出して、自ら焼かれる。」

16. ‘‘Evameva tuvaṃ māra, āsajja naṃ tathāgataṃ;

* evam eva = 「まさにそのように」
* tuvaṃ = 「あなたは」
* māra = 「魔よ」
* āsajja = 「襲って」
* naṃ tathāgataṃ = 「その如来を」

→「まさにそのように魔よ、あなたはその如来を襲って、」

17. Sayaṃ ḍahissasi attānaṃ, bālo aggiṃva saṃphusaṃ.

* sayaṃ = 「自ら」
* ḍahissasi = 「焼くだろう」(ḍahati の未来)
* attānaṃ = 「自分を」
* bālo = 「愚者が」
* aggiṃ va = 「火に～ように」(va = iva)
* saṃphusaṃ = 「触れる(者)」(saṃphusati の現在分詞)

→「愚者が火に触れるように、自ら自分を焼くだろう。」

18. ‘‘Apuññaṃ pasavī māro, āsajja naṃ tathāgataṃ;

* apuññaṃ = 「非福、悪業を」
* pasavī = 「生み出した」(pasavati のアオリスト)
* māro = 「魔は」
* āsajja naṃ tathāgataṃ = 「その如来を襲って」

→「魔はその如来を襲って、非福を生み出した。」

19. Kinnu maññasi pāpima, na me pāpaṃ vipaccati.

* kiṃ nu = 「いったい～か」
* maññasi = 「あなたは思う」
* pāpima = 「悪しき者よ」(魔への呼びかけ)
* na me pāpaṃ vipaccati = 「私の悪は熟さない」
  * vipaccati = 「熟する、報いをもたらす」

→「悪しき者よ、『私の悪は熟さない(報いをもたらさない)』とあなたは思うのか。」

20. ‘‘Karoto cīyati pāpaṃ, cirarattāya antaka;

* karoto = 「行う者にとって」(karoti の現在分詞、属格)
* cīyati = 「積まれる」(cināti の受動)
* pāpaṃ = 「悪は」
* cirarattāya = 「長い間、長夜にわたって」
* antaka = 「終わらせる者よ」(魔への呼びかけ)

→「終わらせる者よ、行う者には悪が長い間積み重なる。」

21. Māra nibbinda buddhamhā, āsaṃ mākāsi bhikkhusu.

* māra = 「魔よ」
* nibbinda = 「離れよ、うんざりして去れ」(nibbindati の命令法)
* buddhamhā = 「仏から」(奪格)
* āsaṃ = 「望みを」
* mā akāsi = 「かけてはならない」(mā + アオリストによる禁止)
* bhikkhusu = 「比丘たちに対して」

→「魔よ、仏から離れよ。比丘たちに望みをかけてはならない。」

22. ‘‘Iti māraṃ atajjesi, bhikkhu bhesakaḷāvane;

* iti = 「このように」
* māraṃ = 「魔を」
* atajjesi = 「叱責した、脅した」(tajjeti のアオリスト)
* bhikkhu = 「比丘(モッガッラーナ)は」
* bhesakaḷāvane = 「ベーサカラー林において」

→「このように比丘はベーサカラー林で魔を叱責した。」

23. Tato so dummano yakkho, natatthevantaradhāyathā’’ti.

* tato = 「それから」
* so = 「その」
* dummano = 「意気消沈した、落胆した」(du-mano)
* yakkho = 「夜叉は」(魔のこと)
* tattha eva = 「まさにそこで」
* antaradhāyatha = 「消え去った」(antaradhāyati のアオリスト)
  * 冒頭の na は韻律上余分で、魔相応の定型句 "tatthevantaradhāyatha" と同じく否定を含まないものとして扱う (要確認)
* ti = 「～と」

→「それからその落胆した夜叉は、まさにそこで消え去った』と。」

24. Māratajjanīyasuttaṃ niṭṭhitaṃ dasamaṃ.

* māra-tajjanīya-suttaṃ = 「魔叱責経」
  * tajjanīya = 「叱責されるべき、叱責の」
* niṭṭhitaṃ = 「終わった」
* dasamaṃ = 「第十(経)」

→「第十、魔叱責経、終わり。」
