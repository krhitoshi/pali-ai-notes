# 6. Sandakasuttaṃ

## 223

223. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā kosambiyaṃ viharati ghositārāme. Tena kho pana samayena sandako paribbājako pilakkhaguhāyaṃ paṭivasati mahatiyā paribbājakaparisāya saddhiṃ pañcamattehi paribbājakasatehi. Atha kho āyasmā ānando sāyanhasamayaṃ paṭisallānā vuṭṭhito bhikkhū āmantesi – ‘‘āyāmāvuso, yena devakatasobbho tenupasaṅkamissāma guhādassanāyā’’ti. ‘‘Evamāvuso’’ti kho te bhikkhū āyasmato ānandassa paccassosuṃ. Atha kho āyasmā ānando sambahulehi bhikkhūhi saddhiṃ yena devakatasobbho tenupasaṅkami. Tena kho pana samayena sandako paribbājako mahatiyā paribbājakaparisāya saddhiṃ nisinno hoti unnādiniyā uccāsaddamahāsaddāya anekavihitaṃ tiracchānakathaṃ kathentiyā, seyyathidaṃ – rājakathaṃ corakathaṃ mahāmattakathaṃ senākathaṃ bhayakathaṃ yuddhakathaṃ annakathaṃ pānakathaṃ vatthakathaṃ sayanakathaṃ mālākathaṃ gandhakathaṃ ñātikathaṃ yānakathaṃ gāmakathaṃ nigamakathaṃ nagarakathaṃ janapadakathaṃ itthikathaṃ sūrakathaṃ visikhākathaṃ kumbhaṭṭhānakathaṃ pubbapetakathaṃ nānattakathaṃ lokakkhāyikaṃ samuddakkhāyikaṃ itibhavābhavakathaṃ iti vā. Addasā kho sandako paribbājako āyasmantaṃ ānandaṃ dūratova āgacchantaṃ. Disvāna sakaṃ parisaṃ saṇṭhāpesi – ‘‘appasaddā bhonto hontu, mā bhonto saddamakattha; ayaṃ samaṇassa gotamassa sāvako āgacchati samaṇo ānando. Appasaddakāmā kho pana te āyasmanto appasaddavinītā appasaddassa vaṇṇavādino; appeva nāma appasaddaṃ parisaṃ viditvā upasaṅkamitabbaṃ maññeyyā’’ti. Atha kho te paribbājakā tuṇhī ahesuṃ.

* [(chinnāva hatthapādā,) (sī. syā. kaṃ. pī.)] = 異読の注記
  * シンハラ本・シャム本・カンボジア本・PTS 本では chinnāva hatthapādā(「手足は切断されたのだ」、va = eva 強調)と読む

→「アーナンダ殿よ、その人は常に絶えず『私の手足は切断された』と知っているのではありません。」

6. Api ca kho pana naṃ paccavekkhamāno jānāti – ‘chinnā me hatthapādā’’’ti.

* api ca kho pana = 「しかしながら」
* naṃ = 「それを(手足が切断されたという事実を)」
* paccavekkhamāno jānāti = 「省察して知るのです」
* ‘chinnā me hatthapādā’ti = 「『私の手足は切断された』と」

→「しかしながら、それを省察して『私の手足は切断された』と知るのです。」

7. ‘‘Evameva kho, sandaka, yo so bhikkhu arahaṃ khīṇāsavo vusitavā katakaraṇīyo ohitabhāro anuppattasadattho parikkhīṇabhavasaṃyojano sammadaññā vimutto tassa carato ceva tiṭṭhato ca suttassa ca jāgarassa ca satataṃ samitaṃ (ñāṇadassanaṃ na paccupaṭṭhitaṃ – ‘khīṇā me āsavā’ti;) [(khīṇāva āsavā,) (sī. syā. kaṃ. pī.)] api ca kho pana naṃ paccavekkhamāno jānāti – ‘khīṇā me āsavā’’’ti.

* evameva kho = 「まさにそのように」
* yo so bhikkhu arahaṃ ... sammadaññā vimutto = 「阿羅漢であり〜正しく了知して解脱したその比丘には」(項目 1 と同じ定型句)
* tassa carato ceva tiṭṭhato ca suttassa ca jāgarassa ca = 「彼が歩いているときも、立っているときも、眠っているときも、目覚めているときも」
* satataṃ samitaṃ ñāṇadassanaṃ na paccupaṭṭhitaṃ = 「常に絶えず智見が現前しているのではない」
* ‘khīṇā me āsavā’ti = 「『私の漏は尽きた』という」
* [(khīṇāva āsavā,) (sī. syā. kaṃ. pī.)] = 異読の注記
  * シンハラ本・シャム本・カンボジア本・PTS 本では khīṇāva āsavā(「漏は尽きたのだ」、va = eva 強調)と読む
* api ca kho pana naṃ paccavekkhamāno jānāti = 「しかしながら、それを省察して知る」
* ‘khīṇā me āsavā’ti = 「『私の漏は尽きた』と」

→「まさにそのように、サンダカよ、阿羅漢であり、漏が尽き、(梵行を)住み終え、なすべきことをなし終え、重荷を下ろし、自らの目的に到達し、有の結が完全に尽き、正しく了知して解脱したその比丘には、歩いているときも、立っているときも、眠っているときも、目覚めているときも、常に絶えず『私の漏は尽きた』という智見が現前しているのではありません。しかしながら、それを省察して『私の漏は尽きた』と知るのです。」

### 対訳

1. 236. ‘‘Kīvabahukā pana, bho ānanda, imasmiṃ dhammavinaye niyyātāro’’ti?

* kīvabahukā = 「どれほど多くの」（kīva = どれほど + bahuka = 多い）
* pana = 「では、しかし」
* bho ānanda = 「アーナンダ殿よ」（bho は敬称の呼びかけ）
* imasmiṃ dhammavinaye = 「この法と律において」
* niyyātāro = 「出離した者たち（輪廻から出て解脱に至った者たち）」
  * niyyātar = niyyāti（出て行く、出離する）の行為者名詞
* ti = 引用の終わり（疑問文）

→「『では、アーナンダ殿よ、この法と律において出離した者はどれほど多くいるのですか』と。」

2. ‘‘Na kho, sandaka, ekaṃyeva sataṃ na dve satāni na tīṇi satāni na cattāri satāni na pañca satāni, atha kho bhiyyova ye imasmiṃ dhammavinaye niyyātāro’’ti.

* na kho = 「決して～ではない」
* sandaka = 「サンダカよ」（呼格）
* ekaṃ yeva sataṃ = 「ただ百だけ」
* na dve satāni = 「二百でもなく」
* na tīṇi satāni = 「三百でもなく」
* na cattāri satāni = 「四百でもなく」
* na pañca satāni = 「五百でもなく」
* atha kho bhiyyova = 「むしろそれ以上である」
  * bhiyyo = 「より多く」 + eva（強調）
* ye imasmiṃ dhammavinaye niyyātāro = 「この法と律において出離した者たちは」

→「『サンダカよ、この法と律において出離した者たちは、ただ百だけではなく、二百でもなく、三百でもなく、四百でもなく、五百でもなく、むしろそれ以上です』と。」

3. ‘‘Acchariyaṃ, bho ānanda, abbhutaṃ, bho ānanda!

* acchariyaṃ = 「驚くべきことです」
* abbhutaṃ = 「未曾有のことです」
* bho ānanda = 「アーナンダ殿よ」

→「『驚くべきことです、アーナンダ殿よ。未曾有のことです、アーナンダ殿よ。」

4. Na ca nāma sadhammokkaṃsanā bhavissati, na paradhammavambhanā, āyatane ca dhammadesanā tāva bahukā ca niyyātāro paññāyissanti.

* na ca nāma ... bhavissati = 「実に～があるのでもなく」
* sadhammokkaṃsanā = 「自分の法を持ち上げること」（sa-dhamma-ukkaṃsanā）
  * ukkaṃsanā = 「賞賛、持ち上げること」
* na paradhammavambhanā = 「他人の法をけなすこともなく」（para-dhamma-vambhanā）
  * vambhanā = 「軽蔑、けなすこと」
* āyatane ca = 「根拠のあるところで」
  * āyatana = ここでは「根拠、理由（kāraṇa）」の意（註釈による）
* dhammadesanā = 「法の説示が（ある）」
* tāva bahukā ca niyyātāro = 「そしてこれほど多くの出離した者たちが」
* paññāyissanti = 「知られるでしょう、認められるでしょう」（paññāyati の未来形）

→「実に自分の法を持ち上げることもなく、他人の法をけなすこともなく、根拠のあるところで法の説示があり、しかもこれほど多くの出離した者たちが知られることになるとは。」

5. Ime panājīvakā puttamatāya puttā attānañceva ukkaṃsenti, pare ca vambhenti tayo ceva niyyātāro paññapenti, seyyathidaṃ – nandaṃ vacchaṃ, kisaṃ saṃkiccaṃ, makkhaliṃ gosāla’’nti.

* ime pana ājīvakā = 「しかしこれらアージーヴァカたちは」
* puttamatāya puttā = 「子を亡くした母の子ら」（軽蔑の慣用句）
  * putta-matā = 「子が死んだ（女）」。役に立たない者たちという侮蔑表現
* attānañceva ukkaṃsenti = 「自分たち自身を持ち上げ」
* pare ca vambhenti = 「他人たちをけなし」
* tayo ceva niyyātāro paññapenti = 「三人だけの出離した者を示します」
  * paññapenti = 「知らしめる、公に示す」（paññāpeti）
* seyyathidaṃ = 「すなわち」
* nandaṃ vacchaṃ = 「ナンダ・ヴァッチャを」
* kisaṃ saṃkiccaṃ = 「キサ・サンキッチャを」
* makkhaliṃ gosālaṃ = 「マッカリ・ゴーサーラを」
* ti = 引用の終わり

→「しかしこれらアージーヴァカたち、子を亡くした母の子らは、自分たち自身を持ち上げ、他人たちをけなし、しかも三人だけの出離した者を示します。すなわちナンダ・ヴァッチャ、キサ・サンキッチャ、マッカリ・ゴーサーラです』と。」

6. Atha kho sandako paribbājako sakaṃ parisaṃ āmantesi – ‘‘carantu bhonto samaṇe gotame brahmacariyavāso.

* atha kho = 「そこで」
* sandako paribbājako = 「遍歴行者サンダカは」
* sakaṃ parisaṃ = 「自分の会衆に」
* āmantesi = 「呼びかけた」（āmanteti のアオリスト）
* carantu bhonto = 「諸君は行じなさい」
  * carantu = carati の命令法三人称複数
* samaṇe gotame = 「沙門ゴータマのもとで」（処格）
* brahmacariyavāso = 「梵行の住（梵行を行じて住むこと）は」
  * 主格だが carantu と結びつく緩やかな構文。「梵行の住は沙門ゴータマのもとで行じられるべきである」の趣旨（要確認）

→「そこで遍歴行者サンダカは自分の会衆に呼びかけた ――『諸君、梵行の住を沙門ゴータマのもとで行じなさい。」

7. Na dāni sukaraṃ amhehi lābhasakkārasiloke pariccajitu’’nti.

* na dāni sukaraṃ = 「今となっては容易ではない」
* amhehi = 「私たちにとって」（具格）
* lābhasakkārasiloke = 「利得と恭敬と名声を」（lābha-sakkāra-siloka、対格複数）
  * siloka = 「名声、評判」
* pariccajituṃ = 「捨てること」（pariccajati の不定詞）
* ti = 引用の終わり

→「私たちにとって、利得と恭敬と名声を捨てることは今となっては容易ではない』と。」

8. Iti hidaṃ sandako paribbājako sakaṃ parisaṃ uyyojesi bhagavati brahmacariyeti.

* iti hidaṃ = 「このようにして実に」（iti hi idaṃ）
* sandako paribbājako = 「遍歴行者サンダカは」
* sakaṃ parisaṃ = 「自分の会衆を」
* uyyojesi = 「送り出した、向かわせた」（uyyojeti のアオリスト)
* bhagavati brahmacariye = 「世尊のもとでの梵行へと」（処格）
* ti = 経の締めくくりの引用終止

→「このようにして実に、遍歴行者サンダカは自分の会衆を世尊のもとでの梵行へと送り出したのである。」

9. Sandakasuttaṃ niṭṭhitaṃ chaṭṭhaṃ.

* sandakasuttaṃ = 「サンダカ経は」
* niṭṭhitaṃ = 「終わった」（niṭṭhāti の過去分詞）
* chaṭṭhaṃ = 「第六（の経）」

→「サンダカ経、第六が終わった。」
