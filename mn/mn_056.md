# 6. Upālisuttaṃ

## 56 (1)

56. Evaṃ me sutaṃ – ekaṃ samayaṃ bhagavā nāḷandāyaṃ viharati pāvārikambavane. Tena kho pana samayena nigaṇṭho nāṭaputto [nāthaputto (sī.), nātaputto (pī.)] nāḷandāyaṃ paṭivasati mahatiyā nigaṇṭhaparisāya saddhiṃ. Atha kho dīghatapassī nigaṇṭho nāḷandāyaṃ piṇḍāya caritvā pacchābhattaṃ piṇḍapātapaṭikkanto yena pāvārikambavanaṃ yena bhagavā tenupasaṅkami; upasaṅkamitvā bhagavatā saddhiṃ sammodi. Sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā ekamantaṃ aṭṭhāsi. Ekamantaṃ ṭhitaṃ kho dīghatapassiṃ nigaṇṭhaṃ bhagavā etadavoca – ‘‘saṃvijjanti kho, tapassi [dīghatapassi (syā. kaṃ. ka.)], āsanāni; sace ākaṅkhasi nisīdā’’ti. Evaṃ vutte, dīghatapassī nigaṇṭho aññataraṃ nīcaṃ āsanaṃ gahetvā ekamantaṃ nisīdi. Ekamantaṃ nisinnaṃ kho dīghatapassiṃ nigaṇṭhaṃ bhagavā etadavoca – ‘‘kati pana, tapassi, nigaṇṭho nāṭaputto kammāni paññapeti pāpassa kammassa kiriyāya pāpassa kammassa pavattiyā’’ti?

1. ‘‘Na kho, āvuso gotama, āciṇṇaṃ nigaṇṭhassa nāṭaputtassa ‘kammaṃ, kamma’nti paññapetuṃ; ‘daṇḍaṃ, daṇḍa’nti kho, āvuso gotama, āciṇṇaṃ nigaṇṭhassa nāṭaputtassa paññapetu’’nti.

* na kho = 「実に～ではない」
* āvuso gotama = 「友ゴータマよ」
  * āvuso = 「友よ」(呼びかけ)
* āciṇṇaṃ = 「習慣、慣例(となっていること)」(ā-car の過去分詞)
* nigaṇṭhassa nāṭaputtassa = 「ニガンタ・ナータプッタにとって」(属格)
* 'kammaṃ, kamma'nti paññapetuṃ = 「『業、業』と説くこと」
  * kammaṃ = 「業、行為」
  * paññapetuṃ = 「説くこと、施設すること」(paññapeti の不定詞)
* 'daṇḍaṃ, daṇḍa'nti = 「『罰(daṇḍa)、罰』と」
  * daṇḍa = 「罰、杖」

→「友ゴータマよ、ニガンタ・ナータプッタが『業、業』と説くのは慣例ではありません。友ゴータマよ、ニガンタ・ナータプッタが『罰、罰』と説くのが慣例です。」

2. ‘‘Kati pana, tapassi, nigaṇṭho nāṭaputto daṇḍāni paññapeti pāpassa kammassa kiriyāya pāpassa kammassa pavattiyā’’ti?

* kati pana = 「では、いくつの」
* tapassi = 「タパッシンよ」(呼格)
* daṇḍāni paññapeti = 「罰を説くのか」
* pāpassa kammassa kiriyāya = 「悪い業を行うために」
  * kiriyā = 「行うこと、遂行」
* pāpassa kammassa pavattiyā = 「悪い業が働くために」
  * pavatti = 「働き、生起」

→「では、タパッシンよ、ニガンタ・ナータプッタは、悪い業を行うため、悪い業が働くために、いくつの罰を説くのですか。」

3. ‘‘Tīṇi kho, āvuso gotama, nigaṇṭho nāṭaputto daṇḍāni paññapeti pāpassa kammassa kiriyāya pāpassa kammassa pavattiyāti, seyyathidaṃ – kāyadaṇḍaṃ, vacīdaṇḍaṃ, manodaṇḍa’’nti.

* tīṇi = 「三つの」
* seyyathidaṃ = 「すなわち」
* kāyadaṇḍaṃ = 「身の罰」
* vacīdaṇḍaṃ = 「口の罰」
* manodaṇḍaṃ = 「意の罰」

→「友ゴータマよ、ニガンタ・ナータプッタは、悪い業を行うため、悪い業が働くために、三つの罰を説きます。すなわち、身の罰、口の罰、意の罰です。」

4. ‘‘Kiṃ pana, tapassi, aññadeva kāyadaṇḍaṃ, aññaṃ vacīdaṇḍaṃ, aññaṃ manodaṇḍa’’nti?

* kiṃ pana = 「では、どうか(疑問)」
* aññadeva = 「別のものこそ」(aññaṃ eva)
  * añña = 「別の、他の」

→「では、タパッシンよ、身の罰は別のもの、口の罰は別のもの、意の罰は別のものなのですか。」

5. ‘‘Aññadeva , āvuso gotama, kāyadaṇḍaṃ, aññaṃ vacīdaṇḍaṃ, aññaṃ manodaṇḍa’’nti.

→「友ゴータマよ、身の罰は別のもの、口の罰は別のもの、意の罰は別のものです。」

→「では、タパッシンよ、このように区分され、このように区別されたこれら三つの罰のうち、ニガンタ・ナータプッタは、悪い業を行うため、悪い業が働くために、どの罰をより大きな罪過のあるものとして説くのですか。身の罰ですか、口の罰ですか、それとも意の罰ですか。」

7. ‘‘Imesaṃ kho, āvuso gotama, tiṇṇaṃ daṇḍānaṃ evaṃ paṭivibhattānaṃ evaṃ paṭivisiṭṭhānaṃ kāyadaṇḍaṃ nigaṇṭho nāṭaputto mahāsāvajjataraṃ paññapeti pāpassa kammassa kiriyāya pāpassa kammassa pavattiyā, no tathā vacīdaṇḍaṃ, no tathā manodaṇḍa’’nti.

→「友ゴータマよ、このように区分され、このように区別されたこれら三つの罰のうち、ニガンタ・ナータプッタは、悪い業を行うため、悪い業が働くために、身の罰をより大きな罪過のあるものとして説きます。口の罰はそれほどではなく、意の罰もそれほどではありません。」

* itiha = 「このようにして」

  * kathā-vatthu = 「話の主題、論点」

  * yāva-tatiyaka = 「第三回に至るまで」

→「このようにして世尊は、ニガンタのディーガタパッシンに、この論点について三度まで(その主張を)確定させた。」

## 57
