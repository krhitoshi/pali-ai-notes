# 外部ノートの変換

別のプロジェクト・別の環境で書いた markdown を, このプロジェクトの調査
ノートとして `notes/` 配下に作り直す.

引数: $ARGUMENTS

先頭が変換元ファイルのパスである. パスが与えられていない場合はどれを
変換するのかユーザに確認する. 残りは変換方針の指示として扱う
(「○○の節は落として」「△△の観点を足して」など).

ノートの体裁・構成・書き方・公開前提の扱いは `/save` と共通である.
本コマンドは変換に固有の点だけを定める. 検証を終えたあとの整理・命名・
書き出しは `/save` の手順 3 以降に従う.

## 変換ではないこと

**移植ではなく作り直しである.** 元ファイルは素材であって原稿ではない.
文面を整形して持ち込むだけの作業にしない.

- 元ファイルは読むだけで, 編集も削除もしない
- 元ファイルの節構成・見出し・表をそのまま流用しない. `/save` の
  「疑問 -> 答え -> 根拠」に組み直す
- 元ファイルのタイトルをそのまま使わない. 変換後の内容が覆う範囲で
  付け直す

## 手順 1: 主張の洗い出し

元ファイルを読み, 検証すべき主張を列挙する. 少なくとも次を拾う.

- 原文・註釈の引用 (文言, 語順, どの書の記述とされているか)
- 出典の参照 (経・章・段落番号, 辞書の見出しと語義区分)
- 件数・分布・版本の異同についての記述
- 「既存訳はこうなっている」「この語はこう訳されている」という記述

## 手順 2: 全主張の裏取り

`/save` の手順 2 をすべての主張に適用する. 元ファイルに書いてあることを
裏取り済みとして扱わない. 別のモデル・別の環境で書かれたものは, 出典表記
まで含めて未確認とみなす.

引用の照合では文言の一致だけでなく次を確かめる.

- **帰属先** — その文言が本当にその書のものか. 同趣旨の語釈が註・復註の
  複数書に散らばっていて, 語順や語が書ごとに違うことがある
- **文脈** — 同じ語を釈していても別の箇所を釈した語釈であることがある.
  定型句の語釈でないものを語釈として引いていないか
- **独立性** — 「別の文献が裏づける」という主張が, 実はその文献による
  引用にすぎないことがある. 出典注記を辿って確かめる

## 手順 3: 検証結果の反映

主張ごとに次のいずれかに振り分ける. 判断がつかないものを黙って残さない.

| 検証結果 | 扱い |
| --- | --- |
| 裏が取れた | そのまま書く |
| 一部が崩れた | 崩れた部分を訂正し, 訂正後の根拠で書き直す |
| 根拠が弱い | 類推・傍証であることを明記して残すか, 落とす |
| 裏が取れない | 落とす. 論点として要るなら「確認できていないこと」に回す |
| 誤り | 落とす. ただし誤読しやすい箇所なら, なぜそう読めてしまうかを一文添えて残す |

裏取りの過程で見つかった根拠が元ファイルにない場合は加える. 変換は
元ファイルの範囲に縛られない.

## 手順 4: このプロジェクトの前提に合わせる

元ファイルは別の前提で書かれている. 次を突き合わせる.

- **訳語方針** — CLAUDE.md, `docs/plain_terms.md`, `docs/translation_terms.md`
  と衝突する訳語を使っていないか. 衝突する場合は方針を採り, 資料側の
  記述も併記する
- **対象範囲** — 元ファイルが一般読者向けの平易さを基準にしている場合,
  このプロジェクトの基準に読み替える
- **既存の対訳** — 「既存訳」「従来の訳」といった記述があれば, それが
  リポジトリのどのファイルのどの箇所かを特定し, 実際に読んで指摘を
  具体化する. 特定できなければその記述は落とす

対訳を直すべき箇所が見つかった場合の扱いは `/save` と同じで, 指摘を
書くにとどめる.

## 手順 5: 持ち込まないもの

`/save` の公開前提に加えて, 変換元に由来する次のものを落とす.

- 作成に使ったモデル名への言及 (「Opus の出力」など). モデル情報は
  frontmatter の `models` にのみ書く
- 元ファイルが置かれていた場所やそのプロジェクトの構造への言及
- 元ファイルでの推敲の経緯, 別案との比較の記録

## 手順 6: 報告

`/save` の報告に加えて, 検証の結果を報告する. 変換の主眼は検証にあり,
何を確かめて何を直したかが報告の中心になる.

- 裏が取れた主要な主張
- 訂正した主張と, その訂正内容
- 落とした主張と, 落とした理由
- 追加した根拠
