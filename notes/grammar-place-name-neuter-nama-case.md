# MN 81 の Vegaḷiṅgaṃ はなぜ nom. の位置で -aṃ なのか — 中性の地名と nāma がとる格

MN 81 Ghaṭikārasutta で、町の名 Vegaḷiṅga は nom. と思われる位置でも vegaḷiṅgaṃ という -aṃ 形で現れる。これは Vegaḷiṅga が中性名詞だからで、-aṃ は中性 nom. sg. の正規の形である。同格に並ぶ gāmanigamo が男性 nom. であっても、固有名詞は自分の性を保ち、格だけを一致させる。

この型から派生する二つの疑問にも答える。

- 中性の地名は珍しいか: 珍しくない。町・村の名は中性か女性が大半で、男性名詞の gāmo や nigamo と同格で並ぶ中性 -aṃ の地名は三蔵に多数ある
- 「〜という名の」の nāma は何格をとるか: nāma は格を支配しない。名前は同格の名詞と格・数を一致させ、nāma 自身は不変化詞として添わるだけである

## Vegaḷiṅga は中性名詞である

MN 81 と註 (Papañcasūdanī) での出現を格ごとに並べると、中性 -a 語幹の変化として一貫している。

| 形 | 格 | 箇所 |
|---|---|---|
| vegaḷiṅgaṃ nāma gāmanigamo ahosi / atthi, mahārāja, vegaḷiṅgaṃ nāma gāmanigamo | nom. | 282、註 282 / 288 |
| vegaḷiṅgaṃ kho, ānanda, gāmanigamaṃ ... upanissāya vihāsi | acc. | 282 |
| vegaḷiṅge kho, ānanda, gāmanigame / vegaḷiṅge (単独) / vegaḷiṅge nāma gāmanigame | loc. | 283 / 287 / 289-291 |
| vegaḷiṅgato nikkhamanakāle | abl. | 註 288 |

nom. で vegaḷiṅgaṃ (中性) と gāmanigamo (男性) の性が合わないのは、固有名詞が普通名詞と同格に置かれるとき、格は一致させるが性は固有名詞自身のものを保つためである。DPD も vegaḷiṅga を nt として登録している (DOP、PTSD は固有名詞を立項しないため、ここは DPD を参考として挙げる)。

MN 81 対訳の語釈行は、282 の vegaḷiṅgaṃ nāma を「ヴェーガリンガという名の」、vegaḷiṅgaṃ gāmanigamaṃ を対格と説明しており、この読みと矛盾しない。

## 中性の地名は珍しくない

パーリの地名は、都市・町・村の名では中性か女性が大半で、男性は少数派である。CSCD で確認できた範囲の傾向は次のとおり。

### 中性 -aṃ の地名が男性の gāmo / nigamo と同格に並ぶ例

Vegaḷiṅga と同じ型で、名前が -aṃ、同格の普通名詞が -o のもの。

```
yena icchānaṅgalaṃ nāma kosalānaṃ brāhmaṇagāmo tadavasari   (DN 3 ほか)
yena khāṇumataṃ nāma magadhānaṃ brāhmaṇagāmo tadavasari     (DN 5)
yena manasākaṭaṃ nāma kosalānaṃ brāhmaṇagāmo tadavasari     (DN 13)
atthi, mahārāja, medāḷupaṃ nāma sakyānaṃ nigamo              (MN 89)
bhagavā sakkesu viharati devadahaṃ nāma sakyānaṃ nigamo      (MN 101、SN 22.2)
bhagavā sakkesu viharati nagarakaṃ nāma sakyānaṃ nigamo      (MN 122)
bhagavā mallesu viharati uruvelakappaṃ nāma mallānaṃ nigamo  (SN 42.11)
yena veḷudvāraṃ nāma kosalānaṃ brāhmaṇagāmo tadavasari       (SN 55.7)
yena venāgapuraṃ nāma kosalānaṃ brāhmaṇagāmo tadavasari      (AN 3.63)
yena daṇḍakappakaṃ nāma kosalānaṃ nigamo tadavasari          (AN 6.62)
```

MN 89 の medāḷupaṃ nāma sakyānaṃ nigamo は MN 81 の atthi, mahārāja, vegaḷiṅgaṃ nāma gāmanigamo と同じ構文であり、どちらも nom. である。

### 都市名にも中性がある

Rājagaha や Kapilavatthu は同格の nagaraṃ も中性なので性の違いが表に出ないが、形容詞や指示代名詞の一致から中性と分かる。

```
rājagahaṃ nāma ākiṇṇamanussaṃ avivittaṃ dasahi saddehi   (MN 140 註、形容詞が中性)
sakaṃ kho panetaṃ, ambaṭṭha, sakyānaṃ yadidaṃ kapilavatthuṃ   (DN 3、etaṃ と一致)
kapilavatthu nāma nagaraṃ rājadhānī ahosi                  (DN 14)
```

### 女性の地名

-ī、-ā で終わる都市名は女性で、中性の nagaraṃ と同格に並んでも -ī のままである。中性名詞が男性の gāmo と並ぶのと向きが逆なだけで、同じ現象である。

```
puratthimesu janapadesu sāvatthī nāma nagaraṃ        (AN 2)
kikissa rañño bārāṇasī nāma nagaraṃ rājadhānī ahosi   (DN 14)
bandhumassa rañño bandhumatī nāma nagaraṃ rājadhānī ahosi   (DN 14)
```

### 男性の地名

国名・部族名は男性複数で、kosalesu、sakkesu、mallesu のように loc. pl. で「〜国に (おいて)」を表す。MN 81 冒頭の bhagavā kosalesu cārikaṃ carati がこれにあたる。町・村の名で男性のものは、gāma など男性名詞で終わる複合語が中心になる。

### 読む上での注意

- 「X-aṃ nāma + 男性名詞 nom.」を見ても X を acc. と取らない。中性では nom. と acc. が同形なので、男性名詞と並ぶと acc. に見えてしまう
- 「X-e viharati」の -e からは男性か中性か決められない (どちらも loc. -e)。性の判定は nom. の形 (-o か -aṃ か) か、形容詞・代名詞の一致で行う

## 「〜という名の」の nāma は格を支配しない

nāma は不変化詞である。DOP は nāma を ind. として立項し、第 1 の意味に「by name; called」を挙げる。PTSD は nāma の項の格の用法のところで、acc. の nāma (nāmaṃ より古い形で Sk. nāma に相当) を「by name」の意味で挙げる。名前の語はこの nāma に支配されるのではなく、同格に置かれる名詞と格・数を一致させる。人名が nom. で現れるのは同格の名詞が nom. だからで、地名の -aṃ が acc. だからではない。

名前の格が頭の名詞に合わせて動く例。

| 格 | 例 | 出典 |
|---|---|---|
| nom. | ambaṭṭho nāma māṇavo / bandhumā nāma rājā / bandhumatī nāma devī | DN 3、DN 14 |
| nom. | jotipālo nāma māṇavo / ghaṭikāro nāma kumbhakāro | MN 81 283 |
| nom. | vegaḷiṅgaṃ nāma gāmanigamo (中性 nom.) | MN 81 282 |
| acc. | āmantayi cundakaṃ nāma bhikkhuṃ | DN 16 (偈) |
| gen. | asukassa nāma rañño kāle | Dhs-a |
| loc. | amukasmiṃ nāma gāme vā nigame vā | AN 3、AN 4、AN 5 |
| loc. | vegaḷiṅge nāma gāmanigame viharāmi | MN 81 289-291 |

MN 81 の中だけでも nom. の vegaḷiṅgaṃ nāma gāmanigamo と loc. の vegaḷiṅge nāma gāmanigame が並んでおり、名前が頭の名詞の格に従っていることが確認できる。

読む際は「nāma の直前の語は、直後の名詞と同じ格」と決めてかかってよい。性は一致しなくてよいので、-aṃ と -o、-ī と -aṃ の組み合わせに惑わされないこと。
