# 無礙解道の四句定型 — anativattana と ekarasa

無礙解道 (Paṭisambhidāmagga) の初禅の記述にある `Tattha jātānaṃ dhammānaṃ anativattanaṭṭhena sampahaṃsanā` 以下の四句を読んで出た、次の三つの疑問を扱う。

1. 「そこに生じた諸法 (tattha jātā dhammā)」とは何を指すのか
2. 「乗り越えない (anativattana)」とはどういう事態か
3. 第 2 句の `indriyānaṃ ekarasaṭṭhena` は何を言っているのか

答えは順に次のとおり。

1. 註釈は定と慧の二法 (止観) に絞る。ただし本文は数を限定しておらず、二法読みは註釈の解釈である
2. 定と慧が互いに追い越さないこと。止が勝てば懈怠、観が勝てば掉挙に落ちるので、両者が等しく転起して互いを守る状態を指す
3. 対抗する煩悩も働きも異なる五根が、解脱の味という一点で一つになること。註釈は一刹那の事態として押さえ、各根が自分の仕事をしたまま一味になるとする

以下、根拠を順に示す。

## 四句の分担

この 4 句は一組で繰り返し現れる。主語だけが `bhāvanā` (修習)、`sampahaṃsanā` (励まし)、`susamāraddhā` などに差し替わる定型である。

```
tattha jātānaṃ dhammānaṃ anativattanaṭṭhena sampahaṃsanā, indriyānaṃ
ekarasaṭṭhena sampahaṃsanā, tadupagavīriyavāhanaṭṭhena sampahaṃsanā,
āsevanaṭṭhena sampahaṃsanā
```

4 句は対象を分担している。

| 句 | 対象 | 内容 |
| --- | --- | --- |
| 1 `tattha jātānaṃ dhammānaṃ anativattanaṭṭhena` | 定と慧 | 互いに超え出ない |
| 2 `indriyānaṃ ekarasaṭṭhena` | 信等の五根 | 解脱の味において一味 |
| 3 `tadupagavīriyavāhanaṭṭhena` | 精進 | 1・2 に相応しい精進を運ぶ |
| 4 `āsevanaṭṭhena` | 習行 | その瞬間の熟達・強力化 |

以下、疑問の的である第 1 句と第 2 句を中心に整理する。

## 第 1 句 — tattha jātānaṃ dhammānaṃ anativattanaṭṭhena

### tattha jātā dhammā (そこに生じた諸法) とは

註釈は**定と慧の二法** (止観) とする。「そこ」は捨によって増強された安止 (appanā) を指す。

```
tattha jātā samādhipaññāsaṅkhātā yuganaddhadhammā aññamaññaṃ
anativattamānā hutvā pavattā
```

本文自体は数を限定しておらず、二法に絞るのは註釈の読みである (後述)。

### anativattana (超えない) とは

定と慧が**互いに追い越さない**こと。註釈の語釈は `aññamaññaṃ anatikkamanaṭṭhena` (互いに超え出ないという意味において)。崩れた場合の記述が具体的である。

```
Aññamaññaṃ nātivattantīti samatho ce vipassanaṃ ativatteyya,
līnapakkhikattā samathassa cittaṃ kosajjāya saṃvatteyya. Vipassanā ce
samathaṃ ativatteyya, uddhaccapakkhikattā vipassanāya cittaṃ uddhaccāya
saṃvatteyya.
```

止が観を超えれば懈怠 (kosajja) に、観が止を超えれば掉挙 (uddhacca) に落ちる。等しく転起することで、止は観を掉挙から、観は止を懈怠から守る。註釈はこの状態を `samadhurā samabalā` (同じ軛、同じ力) と表現する。

語構成は `na + ati + √vatt + ana`。辞書では、CPD が `an-ativattana` を `not overcoming, not escaping from` とし、用例に無礙解道の三箇所を挙げる。DOP は動詞 `ativattati` を `goes beyond, escapes from; exceeds; transgresses` とし、否定現在分詞 `anativattamāna` の用例として、上に引いた `yuganaddhadhammā aññamaññaṃ anativattamānā hutvā` の箇所を挙げる。

### 「等しい」ことの内実と成立時点

双運品 1 Yuganaddhakathā §5 の 16 相が定型で示す。止が捨てるのは掉挙、観が捨てるのは無明で担当は異なるが、所縁は同じ滅 (涅槃) であり、捨断・捨遣・出起・還転なども同じものを同時に行う。この定型が所縁から空までの 14 相で反復され、一味と不超越を加えて 16 相となる (註釈は、14 相それぞれの末尾に既に両者が述べられているため別立てしないと説明する)。

厳密な意味での双運性は、出起に向かう観の瞬間と道心の瞬間に成立する。

```
Tesaṃ maggakkhaṇe yuganaddhattaṃ vuṭṭhānagāminivipassanākkhaṇe
yuganaddhattāyeva hoti.
```

### 指示範囲は本文と註釈でずれる

**本文は数を限定していない。** Ñāṇakathā §27 の第 2 の修習四句には観が登場せず、定の証得だけで同じ表現が使われる。

```
Katamā paṭilābhābhāvanā? Sabbesaṃ samādhiṃ samāpannānaṃ tattha jātā
dhammā aññamaññaṃ nātivattantīti – ayaṃ paṭilābhābhāvanā.
```

§28 の `Kāmacchandaṃ pajahato nekkhammavasena jātā dhammā aññamaññaṃ nātivattanti` も、文字通りには「その局面で共に生じた諸法」という群読みが自然である。§27 への註も `samappavattiyā aññamaññaṃ nātikkamanti` と言うだけで、二法に限定していない。

**註釈は二法に絞る。** `saṅkhāta` (〜と呼ばれる) を挟んだ同格構文で、`dhammā` が複数なのは二つあるからである。

```
tattha nekkhammādīsu bhāvanāvisesesu jātānaṃ samādhipaññāsaṅkhātānaṃ
yuganaddhadhammānaṃ aññamaññaṃ anatikkamanabhāvena
```

復々註も同じ読みで、超える相手を単数 `añña` で受ける (`Te yathā aññaṃ anativattamānā hutvā pavattanti`)。註釈の並行箇所も一貫して主語は二法である。

| 箇所 | 語 |
| --- | --- |
| Paṭis-a Ñāṇakathā §11 | `Samathavipassanānaṃ aññamaññaṃ anativattanaṭṭho` |
| Paṭis-a Ñāṇakathā §12 | `Yuganaddhassa samathavipassanādvayassa` (`dvaya` = 二つ組) |
| Yuganaddhakathā 本文 | 主語が `samathavipassanā` |

**絞り込みの根拠 (本ノートの推論)。** 第 1 句を諸法一般と取ると第 2 句 (五根) と第 3 句 (精進) が重複する。註釈が第 3 句を第 1・2 句を受ける形で説き、精進を第 1 句の外に置いている点がこの分担を裏づける (`tesaṃ anativattanaekarasabhāvānaṃ anucchavikassa vīriyassa vāhanabhāvena`)。ただし註釈がこの理由を述べているわけではない。

## 第 2 句 — indriyānaṃ ekarasaṭṭhena

### ekarasa とは — 解脱の味における同一

信等の五根が、**それぞれ異なる煩悩から解脱していることによって、解脱の味という一点で一つになる**こと。註釈の語釈は二通りある。

| 箇所 | 語釈 |
| --- | --- |
| Paṭis-a Yuganaddhakathā §5 | `ekakiccaṭṭhena` (一つの作用という意味において) |
| Paṭis-a Ñāṇakathā §28 | `nānākilesehi vimuttattā vimuttirasena ekarasabhāvena` |

各根が対抗する煩悩も働きも異なることが前提になっている。

| 根 / 力 | 不動である相手 | 働き |
| --- | --- | --- |
| 信 (saddhā) | 不信 (assaddhiya) | 勝解 |
| 精進 (vīriya) | 懈怠 (kosajja) | 策励 |
| 念 (sati) | 放逸 (pamāda) | 現起 |
| 定 (samādhi) | 掉挙 (uddhacca) | 不散乱 |
| 慧 (paññā) | 無明 (avijjā) | 見 |

典拠として引かれるのは Indriyakathā §201 の `Vimuttattā te dhammā ekarasā honti` (解脱しているので、それらの法は一味となる)。

### 一味になる機構

一根を修習すると、その力によって残る四根が一味となる。Ñāṇakathā §27 が同じ定型を五根・五力・七覚支・八支聖道について反復する。

```
Adhimokkhaṭṭhena saddhindriyaṃ bhāvayato saddhindriyassa vasena cattāri
indriyāni ekarasā hontīti – indriyānaṃ ekarasaṭṭhena bhāvanā.
```

註釈はこれを一刹那の事態として押さえ、**各根が自分の仕事をしたまま一味になる**と明言する。

```
ekakkhaṇepi ekekassa indriyassa sakasakakiccakaraṇe taṃtaṃnissayavasena
sakasakakiccakārakāni sesānipi indriyāni vimuttirasena ekarasā hontīti
vimuttiraseneva ekarasaṭṭhena bhāvanā
```

### rasa の意味 — 作用または成就

註釈が定義を付けている。アビダンマの「相・味・現起 (lakkhaṇa-rasa-paccupaṭṭhāna)」の `rasa` と同じで、作用 (kicca) または成就 (sampatti) を指す。

```
Ekarasā hontīti vimuttirasena, kiccarasena vā ekarasā honti.
Vimuttirasoti sampattiraso. Kiccasampattiatthena raso nāma pavuccatīti.
```

### 第 1 句との関係の型の違い

| | 第 1 句 `anativattana` | 第 2 句 `ekarasa` |
| --- | --- | --- |
| 対象 | 定と慧 | 信等の五根 |
| 註の語釈 | `aññamaññaṃ anatikkamana` / `samadhurā samabalā` | `ekakiccaṭṭha` / `vimuttirasena ekarasa` |
| 関係の型 | 量的 (力が対等) | 質的 (別の働きが同じ味に帰する) |
| 崩れた場合の記述 | 懈怠または掉挙 | 記述なし |

## 第 3 句・第 4 句

第 3 句 `tadupagavīriyavāhana` は、第 1・2 句の状態に相応しい精進を運ぶこと。第 4 句 `āsevana` は、その瞬間に転起している習行 (熟達・強力になること)。

なお `susamāraddhā` 版では第 4 句のみ `tappaccanīkānaṃ kilesānaṃ susamūhatattā` (それに対抗する煩悩がよく根絶されているので) に置き換わる。

Ñāṇakathā §27 の別の四句 (`esanā` / `paṭilābha` / `ekarasa` / `āsevana`) との違いについて、註釈は、§27 は修習の種別を示すために、§28 は修習の原因を示すために説かれたものだとし、`āsevana` も §27 は異刹那、§28 は一刹那の話だと区別する。

## sampahaṃsanā 版の文脈 — 初禅の三善十相

大品 3 Ānāpānassatikathā §158 (Vodānañāṇaniddesa) では、この 4 句が初禅の「終わり」の 4 相にあたる。

| 段 | 名称 | 相の数 |
| --- | --- | --- |
| 初 (ādi) | `paṭipadāvisuddhi` 行道の清浄 | 3 |
| 中 (majjhe) | `upekkhānubrūhanā` 捨による増強 | 3 |
| 終 (pariyosāna) | `sampahaṃsanā` 励まし | 4 |

`sampahaṃsanā` は智の働きの完成を指す。智が雑染と浄白において過患と功徳を見て諸法を励ました結果として不超越などが成立するので、次のように説明される。

```
dhammānaṃ anativattanādibhāvasādhanena pariyodāpakassa ñāṇassa
kiccanipphattivasena sampahaṃsanā veditabbā
```

註釈は、三段を「近行・安止・観察 (paccavekkhaṇā)」とする説を `evameke vaṇṇayanti` として記録した上で、本文が「一性に至った心が行道の清浄に入っている」と述べていることを理由に、三段とも安止の内部の事態として読む立場を取る。

## 関連 — Visuddhimagga の根の平等性

Visuddhimagga §62 の `indriyasamattapaṭipādana` (根の平等性の遂行) は、安止の十善巧の第 2 項として、五根の力を等しくする実践を説く。定が強く精進が弱ければ懈怠に、精進が強く定が弱ければ掉挙に負けるとし、信が強く慧が弱ければ根拠のないものに信じ込み (`muddhappasanno hoti, avatthusmiṃ pasīdati`)、慧が強く信が弱ければ狡猾に傾く (`kerāṭikapakkhaṃ bhajati`) とする。念だけは常に強くてよい (`sati pana sabbattha balavatī vaṭṭati`)。

対象は五根だが、扱う関係は力の均等 (samabala) であり、型としては第 1 句の `anativattana` と同じである。第 2 句の `ekarasa` とは別の枠組みを扱っている。

## 確認できていないこと

- 本文が二法に限定していない以上、註釈の二法読みは解釈である。この読みがどの段階で成立したかは追っていない
- §27 の `paṭilābhābhāvanā` と §28 第 1 句が同じ表現を使いながら註釈の扱いが異なる点について、註釈は説明を与えていない
- 漢訳・北伝側の対応箇所は参照していない
