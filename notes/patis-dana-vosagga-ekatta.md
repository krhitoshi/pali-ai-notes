# 無礙解道の四 ekatta に施 (dāna, cāga) が現れる理由

Paṭisambhidāmagga 大品・出入息念論の浄化支の説示 (Vodānaṅganiddesa) §158 に、
心が一境に至る (ekattagata) あり方として四つの ekatta が挙げられ、その第一に
`dānavosaggupaṭṭhānekattaṃ cāgādhimuttānaṃ` が来る。出入息念を論じている文脈に
なぜ布施の語が出てくるのかを調べた。

結論は以下のとおり。

- この四 ekatta は出入息念に固有の分類ではなく、**心一境性を人の類型別に
  並べた一覧**である。第一項は在家の施主 (cāgādhimutta) の心一境性を指す
- 内容としては十随念の一つ cāgānussati による定を指す。註が
  `etena paduddhāravasena cāgānussatisamādhi vutto` と明言する
- 出入息念の文脈に合わないことは註自身が認めており、それでもここに挙げる
  理由として二説を示す。(1) 他の三つの ekatta の依り所となる縁 (upanissaya-
  paccaya) だから、(2) 四項が近行定・安止定・観・道果の階梯を成しており、
  第一項はその近行定の段の代表だから
- 施の随念が安止に達するという主張ではない。Visuddhimagga は cāgānussati が
  近行止まりであると明示する

## 該当箇所の原文

`s0517m.mul.xml` (Paṭisambhidāmaggapāḷi) §158 の直後の段落。

```
Katame te ekattā? Dānavosaggupaṭṭhānekattaṃ, samathanimittupaṭṭhānekattaṃ,
vayalakkhaṇupaṭṭhānekattaṃ, nirodhupaṭṭhānekattaṃ. Dānavosaggupaṭṭhānekattaṃ
cāgādhimuttānaṃ, samathanimittupaṭṭhānekattañca adhicittamanuyuttānaṃ,
vayalakkhaṇupaṭṭhānekattañca vipassakānaṃ, nirodhupaṭṭhānekattañca
ariyapuggalānaṃ – imehi catūhi ṭhānehi ekattagataṃ cittaṃ
paṭipadāvisuddhipakkhandañceva hoti, upekkhānubrūhitañca, ñāṇena ca
sampahaṃsitaṃ.
```

十八の随煩悩 (upakkilesa) と十三の浄化智 (vodāne ñāṇāni) を説き終え、
「これら六つの理由によって心は清浄となり、遍浄となり、一境に至る」と結んだ
直後に置かれる。末尾がそのまま paṭipadāvisuddhi の三分節に接続する。

## 四 ekatta は人の類型別の一覧

各項に属格 (`-ānaṃ`) が付き、「誰の心一境性か」を示す。

| ekatta の対象 | 誰の | 註の語釈 |
| --- | --- | --- |
| dāna-vosagga (施の放捨) | cāgādhimutta | `dāne adhimuttānaṃ` 施に傾倒した者たち |
| samatha-nimitta | adhicitta に従事する者 | `adhicittanti vipassanāpādakasamādhi` 観の足場となる定 |
| vaya-lakkhaṇa (壊滅相) | vipassaka | `bhaṅgānupassanato paṭṭhāya tīhi anupassanāhi saṅkhāre vipassantānaṃ` |
| nirodha | 聖者 | `ariyapuggalānanti aṭṭhannaṃ` 八輩 |

註は `nirodho nibbānaṃ` として第四項の対象を涅槃と定める。

## dānavosaggupaṭṭhāna の語構成

Paṭisambhidāmagga-aṭṭhakathā (Saddhammappakāsinī, `s0517a.att.xml`) の分解。
註の見出しは異読 `dānūpasagga-` を立てる。

```
Dānūpasaggupaṭṭhānekattanti dānavatthusaṅkhātassa dānassa upasaggo vosajjanaṃ
dānūpasaggo, dānavatthupariccāgacetanā. Tassa upaṭṭhānaṃ ārammaṇakaraṇavasena
upagantvā ṭhānaṃ dānūpasaggupaṭṭhānaṃ, tadeva ekattaṃ, tena vā ekattaṃ
ekaggabhāvo dānūpasaggupaṭṭhānekattaṃ. Dānavosaggupaṭṭhānekattanti pāṭho
sundarataro, so evattho.
```

- `dānassa upasaggo vosajjanaṃ` — 施物という意味での施を放つこと
- それを言い換えて `dānavatthupariccāgacetanā` — 施物を捨てる思 (cetanā)
- `upaṭṭhāna` = `ārammaṇakaraṇavasena upagantvā ṭhānaṃ` 所縁とされて現前する
  こと
- `ekatta` = それ自体が一境性、あるいはそれによる一境性 (`ekaggabhāva`)

そのうえで `dānavosagga-` の読みのほうが `sundarataro` (より良い) で、意味は
同じであるとする。註は異読を並記しつつ本文の読みを支持している。

vosagga (= vossagga) は vi + ava + √sṛj で「放捨・手放すこと」。PTSD は
`relinquishing, relaxation; handing over, donation, gift` を挙げ、覚支の定型句
`vossaggapariṇāmī` と同語であることを示す。

## 内容は cāgānussati による定

註は語の分解に続けて次のように述べる。

```
Etena paduddhāravasena cāgānussatisamādhi vutto.
```

「この語を抜き出す形で cāgānussati の定が説かれた」。したがってここでの施は
布施という善行そのものではなく、**自分の放捨を随念することが所縁となって
生じる心一境性**を指す。Visuddhimagga §160 が cāgānussati の章を
`Cāgānussatiṃ bhāvetukāmena pana pakatiyā cāgādhimuttena niccappavattadāna-
saṃvibhāgena bhavitabbaṃ` と始めるのと同じ用語法である。

## 出入息念の文脈に合わないことは註も認めている

問いの導入部と、第二項以下の説明の二箇所で明示される。

```
Katame te ekattāti idha yujjamānāyujjamānepi ekatte ekato katvā pucchati.
```

「ここに当てはまるものと当てはまらないものを一括りにして問うている」。

```
Dutiyādīni tīṇi ekattāni ānāpānassativasena sesakammaṭṭhānavasena ca yujjanti.
```

「第二以下の三つは出入息念としても他の業処としても成り立つ」。裏を返せば
第一項は出入息念としては成り立たない。

## なぜそれでもここに挙げるのか — 註の二説

以下の二説はいずれも Saddhammappakāsinī の同じ箇所にあり、註が並置している
ものである。原文にはない解釈を持ち込んだものではない。ただし註の中での扱いは
同格ではない。

| | 導入と結び | 註の中での扱い |
| --- | --- | --- |
| 説 1 | `…niddiṭṭhanti vadanti` | 他師の説として紹介 |
| 説 2 | `Atha vā … veditabbaṃ` | 帰属を示さず註自身が並べる第二案 |

### 説 1: 他の三つの依り所となる縁だから

```
Paduddhāravasena vuttopi cesa itaresaṃ tiṇṇampi ekattānaṃ upanissayapaccayo
hoti, tasmā idha niddiṭṭhanti vadanti.
```

施の随念による一境性は残り三つの ekatta の upanissayapaccaya (強い依り所と
なる縁) なので、ここに挙げられているという説。`vadanti` とあり、註は他師の
説として紹介している。

この説の根拠として律大品 `(mahāva. 351)` の Visākhā の言葉を長く引用する。
要点は末尾の連鎖にある。

```
Tassā me tadanussarantiyā pāmojjaṃ jāyissati, pamuditāya pīti jāyissati,
pītimanāya kāyo passambhissati, passaddhakāyā sukhaṃ vedayissāmi, sukhiniyā
cittaṃ samādhiyissati, sā me bhavissati indriyabhāvanā balabhāvanā
bojjhaṅgabhāvanā
```

引用中の比丘は特定の人物ではない。`itthannāmo, bhante, bhikkhu kālaṅkato`
の `itthannāma` は「某という名の」という仮の代名詞で、「どこそこで比丘が
亡くなり果を得たと世尊が記別された場合」という仮定の設定である。主語は
比丘ではなく Visākhā 自身の心の動きにある。自分の雨安居衣や病者食を
その比丘が受用したはずだと随念する、という筋で、施の随念が
喜 → 喜悦 → 軽安 → 楽 → 定 の定型連鎖をたどることを示す。

### 説 2: 四項を修行の階梯として読む

```
Atha vā ekattesu paṭhamaṃ upacārasamādhivasena vuttaṃ, dutiyaṃ
appanāsamādhivasena, tatiyaṃ vipassanāvasena, catutthaṃ maggaphalavasenāti
veditabbaṃ.
```

説 1 の直後に `atha vā` で導かれる。近行定 → 安止定 → 観 → 道果 の順に読む説
で、cāgānussati は安止に達しない業処なので、第一項は近行定の段の代表として
置かれていることになる。四項の並び方そのものを説明できる点で、説 1 より構成上
の説明力がある。

二説の違いは、説 1 が「他の三つを支える前提だから」という縁起的な位置づけ、
説 2 が「四項が階梯を成しており第一段の実例だから」という構成上の位置づけ、
という点にある。

## 安止に達するという主張ではない

説 1 が引く Visākhā の連鎖は `cittaṃ samādhiyissati` に至り、根・力・覚支の
修習になると結ばれる。ここだけ読むと施の随念が安止 (appanā) まで運ぶように
見えるが、そうではない。Visuddhimagga §161 (`e0101n.mul.xml`) が cāgānussati
の到達点を明示する。

```
Cāgaguṇānaṃ pana gambhīratāya nānappakāracāgaguṇānussaraṇādhimuttatāya vā
appanaṃ appatvā upacārappattameva jhānaṃ hoti.
```

施の徳が深遠であり、また種々の徳を随念することに傾注するため、安止に達せず
近行止まりとなる。六随念に共通する説明である。

Paṭisambhidāmagga 註も安止とは述べていない。

- 説 1 の主張は `upanissayapaccayo hoti` であって、それ自体が安止に至るとは
  言っていない
- 説 2 は `paṭhamaṃ upacārasamādhivasena vuttaṃ` と明言する
- Visākhā の引用にある `cittaṃ samādhiyissati` の samādhi も安止とは限らない。
  pāmojja → pīti → passaddhi → sukha → samādhi の連鎖は近行でも成立し、
  根・力・覚支の修習も安止を要件としない

註の構図としては、施の随念は近行までを担い、その先の安止は第二の ekatta
(samathanimittupaṭṭhāna) が引き継ぐ、という分業になる。これが「依り所と
なる縁」という言い方の内実と読める。

## Visākhā の一節が引かれる理由

説 1 の裏づけとして、註はわざわざ律大品から在家女性の長い発言を引く。施の
随念が定を生むという話であれば、業処としての cāgānussati を詳述する
Visuddhimagga を指させば足りそうに見える。実際 Saddhammappakāsinī は Vism を
参照できる立場にあり、同じ出入息念論の中で `visuddhimagge vuttanayena
sīlaparisodhanādīni sabbakiccāni katvā`、`visuddhimagge vuttānukkamena` と
明示的に参照している。それでも律大品を引くのは、証明すべき内容が二段階に
分かれているためと考えられる。

- **技術的な位置づけ** — 「これは cāgānussati の定である」。これは
  `etena paduddhāravasena cāgānussatisamādhi vutto` の一行で済ませており、
  詳細が必要なら Vism を参照させれば足りる
- **聖典上の根拠** — 「施の随念が実際に定に至り、他の三つの依り所となる」。
  これは註釈者側の解釈が正しいという主張なので、註釈書を引いても論拠に
  ならない。仏語 (buddhavacana) を引く必要がある。だから律大品を出典明示で
  引いている

加えて、引用の人選も説明の対象に合っている。Vism の cāgānussati の章は修行者
向けの業処解説だが、ここで裏づけが要るのは `cāgādhimuttānaṃ` = 施に傾倒する
者たちという在家の類型である。大優婆夷 Visākhā が自分の施を随念して定に至る
と自ら述べた言葉は、その類型にそのまま重なる。

なお、この読み (二段階の証明という整理) は註の明文ではなく、註の引用の
仕方から導いた推論である。
