# kiṃ pana と疑問文 — パーリ語の疑問はどう示されるか、kiṃ pana が疑問に見えない場合

MN 79 (Cūḷasakuludāyisutta) の `Kiṃ panudāyi, atthi ekantasukho loko, atthi ākāravatī paṭipadā …` を読んでいて生じた疑問について。

- 文頭の atthi は疑問の目印ではない。パーリ語は語順で疑問文を示さず、atthi を頭に置く存在文は肯定文でも疑問文でも同じ形になる。疑問であることは kiṃ、nu kho、api などの不変化詞か、ko、katama などの疑問詞が示す
- kiṃ pana の kiṃ は代名詞「何」ではなく諾否疑問 (yes/no) の標識で、日本語では文末の「～か」に当たる。pana は「では、さて」と話題を転じる小辞で、疑問の本体ではない。語釈行で「では、どうか」のように訳すと疑問詞らしさが消えるのは、kiṃ に内容語としての訳がないため
- kiṃ pana は常に問いの形を作るが、その問いが本当の疑問として使われるか、修辞として使われるかは文脈で変わる。修辞用法には「まして」「そうではなく」「何の役に立つのか (何にもならない)」があり、訳文ではこれらが疑問の形に見えない

## 疑問文は語順では示されない

`atthi X` が文頭に来ると英語の倒置 (Is there …?) のように見えるが、パーリ語ではこれは存在文の普通の語順で、疑問とは無関係である。

MN 79 の VRI 段落 274 で、問いと答えの atthi 以下はまったく同じ語順・語形になっている。

```
Kiṃ panudāyi, atthi ekantasukho loko, atthi ākāravatī paṭipadā
ekantasukhassa lokassa sacchikiriyāyā’’ti?

Amhākaṃ, bhante, sake ācariyake evaṃ hoti – ‘atthi ekantasukho loko,
atthi ākāravatī paṭipadā ekantasukhassa lokassa sacchikiriyāyā’’’ti.
```

違いは問いの冒頭にある kiṃ pana だけで、答えの側は同じ文を引用 (…ti) の形で述べている。atthi が文頭に立つ例は肯定文にも疑問文にもある。

| 種別 | 原文 | 出典 |
|---|---|---|
| 肯定文 | `Atthi, bhikkhave, ajātaṃ abhūtaṃ akataṃ asaṅkhataṃ` | Ud 8.3, Iti 43 |
| 疑問文 | `Atthi nu kho, bhante, jātassa aññatra jarāmaraṇā` | SN 3.3 |

SN 3.3 の答えは `Natthi kho, mahārāja, …` で、問いと答えで語順は変わらず、疑問であることは nu kho だけが示している。

疑問であることを示すものは次の二種類である。

- 疑問の不変化詞: kiṃ、kiṃ pana、kiṃ nu kho、nu kho、api、api nu、kacci、nanu、udāhu (「それとも」) など。文頭か文の早い位置に置かれる
- 疑問詞: ko、kiṃ (何)、katama、kattha、kathaṃ、kasmā など。MN 79 の `Katamā pana sā … paṭipadā` の katamā がこれ

これらがない文は、文脈でしか疑問かどうか判断できない。

## kiṃ pana の内訳

kiṃ pana は二つの小辞の組み合わせで、疑問の力は kiṃ にあり、pana は添え物である。

**kiṃ**: DoP は代名詞 ka の項の「副詞的に用いられる形 (forms used adverbially)」で kiṃ の第一義を「疑問の不変化詞 (interrogative particle)」とし、用例に `kiṃ pana bhante taṃ jīvaṃ taṃ sarīraṃ` (DN I 188) を挙げる。PTSD も kiṃ の第二義を「疑問を導く不変化詞、ラテン語 nonne に当たる」とし、`kim pana` をその例としている。この用法の kiṃ は「何」という内容を持たず、文全体を諾否疑問にする標識である。サンスクリットの kim、ラテン語の num と同じ働きで、日本語では文末の「か」に対応する。

**pana**: DoP は pana の第一義を「疑問文に軽い強調を加える前接の小辞」とし、`kiṃ pana tvaṃ etarahi bāhulliko … adhigamissasi` (Vin I 9)、`kiṃ pana eso … vyādhito nāmā ti` (DN II 24) などを挙げる。働きとしては「では、さて」と話題を転じる程度で、疑問の本体ではない。

`Kiṃ panudāyi` は kiṃ pana udāyi の連声。

### 語釈行の訳が疑問に見えない理由

対訳 mn/mn_079.md の段落 274 では語釈行が `kiṃ pana = 「では、どうか」（疑問の導入）` となっている。これは pana を「では」、kiṃ を「どうか」に割り当てたもので、疑問であることは訳文末尾の「あるのか」に逃がしている。kiṃ に内容語としての訳がないため、単語対応の訳にすると疑問詞らしさが消える。構造を示すなら「kiṃ = 疑問の不変化詞 (文末の「か」に相当)、pana = では」のように、kiṃ が文全体を疑問文にする標識であると書く方が分かりやすい。これは語釈行の書き方への指摘であり、改訂は別途判断する。

### 代名詞・副詞としての kiṃ との区別

同じ対訳の段落 273 `kiṃ pana = 「しかしなぜ」` や段落 274 後半 `kiṃ pana = 「ではどうして、それでは何を」` は、kiṃ が副詞「なぜ」や代名詞「何を」として内容を持つ用法である。見分け方は、kiṃ の後ろに何が続くかで決まる。

- 後ろに完全な文 (`atthi ekantasukho loko`) が続けば、kiṃ は疑問標識
- 後ろに「何を」「なぜ」の受け皿となる動詞や文脈があれば、kiṃ は内容語

## kiṃ pana が疑問に見えない場合

kiṃ pana は常に問いの形を作る。ただし、その問いが相手に答えを求める本当の疑問か、問いの形を借りて肯定や否定を述べる修辞かは文脈で変わる。日本語の「～だろうか」が本当の問いにも反語にもなるのと同じ構図である。訳文で疑問に見えないのは、修辞用法を訳者が働きの方で訳しているからで、原文の形は変わっていない。

### 1. 本当の諾否疑問

相手の答えが直後に続く。MN 79 段落 274 の `Kiṃ panudāyi, atthi …` がこれで、ウダーイの答え `Amhākaṃ, bhante, sake ācariyake evaṃ hoti …` が続く。

### 2. 「まして」(言うまでもなく)

直前に「A でさえ～」という事例があり、kiṃ pana の後に B が来て「まして B は言うまでもない」となる。形は疑問でも、実質は肯定である。

MN 70 (Kīṭāgirisutta) 段落 184 では、利得を重んじる師に対してさえ取引は当てはまらない、と述べたあとに次が続く。

```
kiṃ pana, bhikkhave, yaṃ tathāgato sabbaso āmisehi visaṃsaṭṭho viharati.
```

対訳 mn/mn_070.md ではこれを「如来は全面的に物質 (利得) から離れて住んでいるのだから、なおさらのことである」と訳し、語釈行は「ましてや～においておや」としている。答えは続かない。

同じ働きで aṅga を挟んだ kimaṅga pana (kimaṅgaṃ pana) がある。DoP は kim aṅga を「how much more? how much less?」とし、`kim aṅga pana mayaṃ` (DN II 42、DN 14 Mahāpadānasutta) などを挙げる。CSCD では DN 14 段落 78 の `kimaṅgaṃ pana maya’nti`、SN 55.24 の `Kimaṅgaṃ pana saraṇāniṃ sakkaṃ!`、AN 5.180 の `Kimaṅgaṃ pana maya’nti!` などが拾える。DoP はさらに `ko pana vādo` (…については言うまでもない) も同系の表現として挙げる。

註釈には `paramatthe kiṃ pana vattabbaṃ` (勝義については何を言う必要があろうか = 言うまでもない) という言い方もある (Papañcasūdanī、Mūlapaṇṇāsa 註)。ただし `kiṃ pana vattabbaṃ` の形は CSCD の註釈・復註ではこの箇所と Visuddhimagga 復註の 1 箇所にしか見つからず、定型と呼べるほど多くはない。

### 3. 「そうではなく」(否定のあとに正解を出す)

註釈でよく使われる `na X, kiṃ pana Y` の型。X を否定したあと、kiṃ pana で「では何かといえば Y」と正解を出す。直訳すれば自問だが、働きは「むしろ」という訂正の接続である。

Paṭisambhidāmagga 註 (patisambhidamagga/patis_attha_1_03.md 段落 162) の例。

```
Eko anuttaraṃ sammāsambodhiṃ abhisambuddhoti buddhoti na parehi buddhattā
buddho, kiṃ pana sayameva anuttaraṃ sammāsambodhiṃ abhisambuddhattā
buddhoti vuttaṃ hoti.
```

「他者によって覚らされたから buddha なのではなく、自ら無上の正覚を覚ったから buddha である、と言われている」。対訳の語釈行は「そうではなく (では何かといえば)」。

### 4. 反語 (kiṃ + 具格「～に何の意味があろうか」)

DoP は kiṃ の副詞的用法の第四義として「(+ 具格) what is the use of …, away with …」を挙げ、`kiṃ pana tena muṇḍakena samaṇakena diṭṭhenā ti` (MN II 47) を例にする。答えを求めない問いで、実質は否定である。

MN 69 (Goliyānisutta) 段落 173 の例。

```
Kiṃ panimassāyasmato āraññikassa ekassāraññe serivihārena, yo ayamāyasmā
sabrahmacārīsu agāravo hoti appatisso’ti
```

対訳 mn/mn_069.md の語釈行は「一体何の (役に立つのか)」。「この森林住の尊者が独りで森に気ままに住んでいることに何の意味があるのか (何にもならない)」という非難である。

### 見分け方

- 相手の答えが直後に続けば、本当の疑問 (1)
- 直前に「A でさえ～」という事例があり、答えが続かなければ「まして」(2)
- 直前に na … があり、kiṃ pana の後に肯定の内容が来れば「そうではなく」(3)
- kiṃ の後に具格があり、文脈が否定的なら反語 (4)
