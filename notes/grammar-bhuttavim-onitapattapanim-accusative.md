# MN 81 の kassapaṃ bhagavantaṃ … bhuttāviṃ onītapattapāṇiṃ はどの動詞の目的語か — 食後の定型句で浮いている acc.

MN 81 ガティカーラ経 §288 の次の文には、長い acc. のかたまりがある。

```
Atha kho, ānanda, kikī kāsirājā kassapaṃ bhagavantaṃ arahantaṃ sammāsambuddhaṃ bhuttāviṃ onītapattapāṇiṃ aññataraṃ nīcaṃ āsanaṃ gahetvā ekamantaṃ nisīdi.
```

この acc. は、文中のどの動詞にも支配されていない。nisīdi は自動詞で、gahetvā の目的語は āsanaṃ だけである。註釈書はここに連続体を一語補い (ñatvā「知って」または upagantvā「近づいて」)、acc. をその目的語として読む。意味の上では「カッサパ世尊が食べ終えて鉢から手を離したとき」という時の従属節にあたる。

読み方としては「キキー王は、カッサパ世尊が食べ終えて鉢から手を離したのを (見て取って)、ある低い座を取り、一方に坐った」で足りる。

## acc. のかたまりはどういう構造か

kassapaṃ bhagavantaṃ arahantaṃ sammāsambuddhaṃ が核で、bhuttāviṃ と onītapattapāṇiṃ はそれにかかる同格の修飾語である。全体で「食べ終えて鉢から手を離した、カッサパ世尊・阿羅漢・正自覚者を」という一つの名詞句になる。

- bhuttāviṃ: bhuttāvin「食べ終えた者」の acc. sg.
- onītapattapāṇiṃ: 「鉢から手を引いた者」の acc. sg. (所有複合語)

この二語が普通の修飾語であることは、食べ終えた本人が主語になる文で nom. になることから分かる。

```
Atha kho āyasmā raṭṭhapālo bhuttāvī onītapattapāṇī ṭhitakova imā gāthā abhāsi –   (MN 82 §302)
```

MN 81 で acc. になっているのは、食べ終えた人 (カッサパ世尊) と文の主語 (キキー王) が別人だからである。

## なぜ acc. が浮いて見えるのか

この文の動詞は gahetvā と nisīdi の二つしかなく、どちらもこの acc. を目的語にとれない。

- gahetvā の目的語は aññataraṃ nīcaṃ āsanaṃ「ある低い座」である
- nisīdi「坐った」は自動詞で、ekamantaṃ は副詞である

したがって文面のままでは「世尊を … 坐った」となり、acc. の行き場がない。これは MN 81 に固有の乱れではなく、食事の供養の後に置かれる定型句全体に共通する形である (後述の分布を参照)。

## 註釈書は連続体を補って読む

以下は註釈書の説明であり、原文に書かれていることではない。註釈書の補い方は二通りある。

### ñatvā を補う (DN 3、MN 35 の註釈書)

DN 3 §297 と MN 35 §363 の註釈書は、ekamantaṃ nisīdi を次のように言い換える。

```
Ekamantaṃ nisīdīti bhagavantaṃ evaṃbhūtaṃ ñatvā ekasmiṃ okāse nisīdīti attho.
```

「世尊がそういう状態になったのを知って、ある場所に坐った」という読みで、acc. は補われた ñatvā の目的語になる。律の復註 (サーラッタディーパニー、大品 §29 の箇所) も同じ説明を複数形 nisīdiṃsu で繰り返している。

### upagantvā を補う (スッタニパータの註釈書)

スッタニパータ 3.7 (セーラ経) の註釈書は、語を補わないと文が成り立たないと明言する。

```
Tattha ‘‘upagantvā’’ti pāṭhaseso daṭṭhabbo. Itarathā hi bhagavantaṃ ekamantaṃ nisīdīti na yujjati.
```

「ここでは upagantvā を本文の省略として見るべきである。そうでなければ『世尊を一方に坐った』となって筋が通らない」という趣旨で、acc. は「そういう状態の世尊に近づいて」の目的語になる。

### 動詞を補わない註釈書もある

ウダーナの註釈書と律 (パーラージカ) の註釈書は bhuttāviṃ と onītapattapāṇiṃ の語義だけを説明し、支配する動詞には触れていない。MN 81 の註釈書もこの箇所には註釈を置いていない。

## 補う語は実際に本文に書かれることがある

註釈書が補う動詞は、同じ言い回しの別の箇所では本文に書かれている。

律の大品 §6 (タプッサとバッリカの話) は三蔵本文で viditvā を明示する。

```
Atha kho tapussabhallikā vāṇijā bhagavantaṃ onītapattapāṇiṃ viditvā bhagavato pādesu sirasā nipatitvā … etadavocuṃ
```

三蔵の外では次の例がある。

```
Atha kho milindo rājā āyasmantaṃ nāgasenaṃ bhuttāviṃ onītapattapāṇiṃ viditvā aññataraṃ nīcaṃ āsanaṃ gahetvā ekamantaṃ nisīdi   (ミリンダパンハ)
bhagavantaṃ bhuttāviṃ onītapattapāṇiṃ upasaṅkamitvā ekamantaṃ nisīdi   (ヴィマーナヴァットゥの註釈書、ラッジュマーラーの話)
```

ミリンダパンハの文は MN 81 と同じ型に viditvā が入っただけの形であり、註釈書の ñatvā の補いと同じ読みを本文として示している。

## 定型句の分布

CSCD の三蔵本文で bhuttāviṃ onītapattapāṇiṃ という連続した文字列を含む段落 (XML の p 要素) を数えると 41 件あり、acc. の後に続く形で四つに分かれる。

| 型 | acc. の後 | 件数 | 出現 |
|---|---|---|---|
| 1 | aññataraṃ nīcaṃ āsanaṃ gahetvā ekamantaṃ nisīdi | 16 | DN 6、MN 6、SN 1、ウダーナ 2、スッタニパータ 1 |
| 2 | (直接) ekamantaṃ nisīdi | 20 | AN 4、律の大品 12、小品 4 |
| 3 | acc. を支配できる動詞 | 3 | 律のパーラージカ 2、パーチッティヤ 1 |
| 4 | 別の動作が続き、acc. が言い直される | 2 | SN 35 (ヴェーラハッチャーニの話) |

型 1 と型 2 の計 36 件で acc. が浮いている。MN 81 は型 1 である。

型 3 では acc. は普通の目的語であり、浮いていない。

```
bhagavantaṃ bhuttāviṃ onītapattapāṇiṃ ticīvarena acchādesi   (パーラージカ §23)
āyasmantaṃ sudinnaṃ bhuttāviṃ onītapattapāṇiṃ etadavoca   (パーラージカ、スディンナの話)
āyasmantaṃ anuruddhaṃ bhuttāviṃ onītapattapāṇiṃ abhivādetvā ekamantaṃ nisīdi   (パーチッティヤ)
```

型 4 では acc. がいったん浮いた後、etadavoca の前で同じ名詞が言い直される。

```
āyasmantaṃ udāyiṃ bhuttāviṃ onītapattapāṇiṃ pādukā ārohitvā ucce āsane nisīditvā sīsaṃ oguṇṭhitvā āyasmantaṃ udāyiṃ etadavoca
```

以下は推論である。型 3 のように abhivādetvā や etadavoca が続く形では acc. は正規の目的語であり、型 1 と型 2 はその動詞が現れないまま「食べ終えたのを受けて」という場面設定の句として固定したものと見ることができる。註釈書が補う ñatvā や upagantvā は、この固定した句を文法的に落ち着かせるための説明である。

## 現代の文法書は絶対対格として扱うことがある

Wijesekera の Syntax of the Cases in the Pali Nikayas は、acc. の章の絶対対格の節 (§56 b) でこの定型句を取り上げている。同書の扱いは次のとおり。

- santaṃ を伴う絶対対格 (§56 a) とは別に、他の分詞を伴う例としてこの定型句を挙げる
- 厳密に絶対用法と言えるかは確かでないと留保する
- ブッダゴーサが ñatvā を補う省略構文として扱っていることに触れたうえで、それでも絶対的に使われた acc. とみなしうるとする

註釈書の説明 (連続体の省略) と文法書の説明 (絶対対格) は、acc. の文法上の位置づけが違うだけで、「世尊が食べ終えて鉢から手を離したとき」という意味の取り方は同じである。

## MN 81 対訳との関係

`mn/mn_081.md` §288 の訳文は「カッサパが食べ終えて鉢から手を離すと、ある低い座を取って一方に坐った」と時の従属節で訳しており、上の読みと合っている。

語釈行は acc. を「対格、以下の分詞の主体」とし、onītapattapāṇiṃ の下で「食べ終えて鉢から手を離した世尊に対して (王は)」と説明している。「世尊に対して」は、註釈書の補い (ñatvā、upagantvā) とも訳文の時の従属節とも別の言い方になっている。

## 確認できていない範囲

- 件数は bhuttāviṃ onītapattapāṇiṃ という連続した文字列を含む段落を数えたもので、語順や語形が違う変形 (bhuttāviṃ を欠く大品 §6 の形など) は含まない。1 段落に 2 回出る場合も 1 件と数えている
- 型 1 の MN 6 件、DN 6 件などの内訳は CSCD のファイル単位で数えたもので、経ごとの対応は一部しか確かめていない
- Wijesekera の記述は公開されている電子版の該当節の要旨で確認した。逐語的な引用はしていない。同書が挙げるという仏教梵語の対応箇所 (nom. の形) は、その文献自体を確認していない
- DN と MN の復註がこの acc. をどう説明しているかは調べていない
