# 「…なら」「…とき」はどこから来るか — ya-/ta- 相関構文と処格の訳し方

Paṭisambhidāmagga の Ānāpānassatikathā で `vatthukatā` を説明する一段は、
`yasmiṃ yasmiṃ … tasmiṃ tasmiṃ …` という相関構文でできている。これを日本語
に訳すと「…なら」「…とき」という条件や時の表現になりやすいが、パーリ文の
側にそれに対応する語はない。相関構文を日本語に組み替えるときに生じる表現
であり、同じ箇所を英語に訳す場合は条件や時の語を使わずに済む。

この段の処格 `yasmiṃ yasmiṃ vatthusmiṃ` も、時を指してはいない。指している
のは安般念の 16 の項目の一つ一つであり、場所でもない。

## 当該箇所

Paṭisambhidāmagga の Ānāpānassatikathā、VRI 段落番号 160。`bhāvitā
bahulīkatā yānīkatā vatthukatā anuṭṭhitā paricitā susamāraddhā` の各語を
順に説明していく段のうち、`vatthukatā` の語釈にあたる。

```
Vatthukatāti yasmiṃ yasmiṃ vatthusmiṃ cittaṃ svādhiṭṭhitaṃ hoti, tasmiṃ
tasmiṃ vatthusmiṃ sati supaṭṭhitā hoti. Yasmiṃ yasmiṃ vā pana vatthusmiṃ
sati sūpaṭṭhitā hoti, tasmiṃ tasmiṃ vatthusmiṃ cittaṃ svādhiṭṭhitaṃ hoti.
Tena vuccati vatthukatāti.
```

日本語訳の例:

> 「『基盤とされた』とは、どの基盤においてであれ心がよく確立されている
> なら、そのそれぞれの基盤において念がよく現前している。また、どの基盤に
> おいてであれ念がよく現前しているなら、そのそれぞれの基盤において心が
> よく確立されている。それゆえ『基盤とされた』と言われる。」

## 条件・時の表現の出どころ

訳文に条件の「なら」や時の「とき」が現れるため、原文にそうした語があると
読みたくなるが、対応する語はない。出どころは `yasmiṃ yasmiṃ …
tasmiṃ tasmiṃ …` という相関構文の側にある。

パーリ語では前半の `ya-` 節が後半の `ta-` 節を修飾する。日本語にはこの
形式で受け合う構文がないため、前半を従属節に組み替えるほかない。組み替え
先の選択肢が「…なら」「…とき」と連体修飾であり、どれを選んでも意味は
変わらない。連体修飾にすれば条件の語は消える。

> 「心がよく確立されているそれぞれの基盤において、念がよく現前している」

指示語が重ねられている (`yasmiṃ yasmiṃ`) のは、「どれであれ、その一つ一つに
ついて」という配分の表現である。註釈がこれを `ekekasmiṃ` (一つ一つにおいて)
と言い換えており、配分の読みは註釈が明示している。全称の関係節は論理的に
条件文と等価になるため、日本語では条件形にすると通りがよい。

なお、第二文が第一文の逆向きの命題になっている点も、時間や前後関係の読みを
退ける材料になる。心が立つ基盤には念が立ち、念が立つ基盤には心が立つ、と
両方向を述べているので、この二つは範囲が一致していると言っているにすぎない。

## 処格が指すもの

訳文の「とき」に引かれて時の処格と読みたくなるが、そうではない。パーリ語の
処格に時の用法があるのは `tasmiṃ samaye` のように時を表す語が入る場合で、
`vatthu` は時の語ではない。

註釈はこの句を次のように説明する。

```
Yasmiṃ yasmiṃ vatthusminti soḷasasu vatthūsu ekekasmiṃ.
Svādhiṭṭhitanti suppatiṭṭhitaṃ. Sūpaṭṭhitāti suṭṭhu upaṭṭhitā.
```

「『どの vatthu においてであれ』とは、16 の vatthu の一つ一つにおいて」。
処格が指しているのは修習の項目であり、時ではない。

`svādhiṭṭhita` を `suppatiṭṭhita`、`sūpaṭṭhita` を `suṭṭhu upaṭṭhita` と
言い換えているので、どちらも √ṭhā の「よく立っている」で読む。

## vatthu が指すもの

`vatthu` は「基盤」「所依」と訳されることが多く、場所を表す語と受け取られ
やすいが、ここでは場所ではない。註釈の言う `soḷasa vatthu` は安般念の 16 の
項目である。

Visuddhimagga は安般念の業処を `soḷasavatthukaṃ ānāpānassatikammaṭṭhānaṃ`
と呼び、Visuddhimagga-mahāṭīkā がこれを次のように説明する。

```
Soḷasavatthukanti catūsu anupassanāsu catunnaṃ catukkānaṃ vasena soḷasaṭṭhānaṃ.
```

四随観における四つ一組が 4 組で 16 の項目、という数え方である。したがって
処格は「16 の項目のそれぞれについて」を指す。項目を場に見立てて「その上に
心が立つ」と言っているので、立つという像は比喩として働いている。

## 英語に訳す場合

英語には `whatever X …, that X …` という相関構文があるため、ya-/ta- を
そのまま写せる。条件や時の語を補う必要がない。

ニャーナモリは `vatthukatā` を "Made the ground" と訳す。語釈の第一文は次の
とおり。

```
Yasmiṃ yasmiṃ vatthusmiṃ cittaṃ svādhiṭṭhitaṃ hoti,
tasmiṃ tasmiṃ vatthusmiṃ sati supaṭṭhitā hoti.
```

> his mindfulness is well-established (founded) on whatever basis his
> cognizance is well steadied on.
>
> — Ñāṇamoli, The Path of Discrimination

語の対応は `cittaṃ svādhiṭṭhitaṃ hoti` が "his cognizance is well steadied"、
`sati supaṭṭhitā hoti` が "his mindfulness is well-established (founded)"、
`yasmiṃ yasmiṃ vatthusmiṃ` が "on whatever basis" である。when も if も使わ
れておらず、処格は "on … basis" のまま受けられている。日本語で「なら」
「とき」が現れるのは日本語側の事情であって、原文の含みではないことが、
これで確かめられる。

節の順序にも差が出る。英語は主節を先に置いて関係節を後ろに回せるが、
日本語は修飾節が先に来るしかない。`yasmiṃ` 節が文頭に固定されるため、
そこで従属節を作る必要が生じ、その形として条件形が選ばれる。
