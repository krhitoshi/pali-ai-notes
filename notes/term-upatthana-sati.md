# upaṭṭhānaṃ sati の upaṭṭhāna は何を指すか

無礙解道 (Paṭisambhidāmagga) の出入息念の記述にあり、清浄道論 (Visuddhimagga)
と律註にも引かれる次の定型句について、三つの疑問を扱う。

```
Imehi navahākārehi dīghaṃ assāsapassāsā kāyo. Upaṭṭhānaṃ sati. Anupassanā
ñāṇaṃ. Kāyo upaṭṭhānaṃ, no sati; sati upaṭṭhānañceva sati ca.
```

1. 第 2 句 `upaṭṭhānaṃ sati` の upaṭṭhāna は何を言っているのか
2. なぜ「身は upaṭṭhāna である」とも「念は upaṭṭhāna である」とも言えるのか。
   観察される対象 (身) と観察する心のはたらき (念) の双方が、同じ一語で
   受けられている

答えは順に次のとおり。

1. 註釈伝統は upaṭṭhāna を「所縁に近づいて立つこと」(ārammaṇaṃ upagantvā
   ṭhānaṃ) と説明し、そう呼ぶ根拠を不忘失 (asammussanatā) に置く。第 2 句は
   念の側の働きを言っている
2. 復註が upaṭṭhāna を二つの ṭha に分けて解消する。身は「念がそこに近づいて
   立つ場所」という意味でのみ upaṭṭhāna であり、念は「近づき立つ」意味で
   upaṭṭhāna、「憶念する」意味で sati だから両方にあたる

以下、根拠を示す。なお本ノートでは assāsa を「出息」、passāsa を「入息」と
訳すプロジェクト方針に従う。無礙解道とその註はこれとは逆の向きだが、
ここでの論点には関わらない。

## 定型句の区切り

三つの独立した等置が並び、そのあとに身と念の対比が続く。

```
[dīghaṃ assāsapassāsā kāyo]  長い出入息 = 身
[upaṭṭhānaṃ sati]            近づき立つこと = 念
[anupassanā ñāṇaṃ]           随観 = 智
[kāyo upaṭṭhānaṃ, no sati]   身は upaṭṭhāna だが念ではない
[sati upaṭṭhānañceva sati ca] 念は upaṭṭhāna でありかつ念でもある
```

`kāyo` を後ろに送って `kāyo upaṭṭhānaṃ sati` (身は現前する念である) と読む
余地が字面上はある。CSCD では第 1 句末の `kāyo` のあとに句点が打たれていない
箇所が多く、切れ目が版面から読み取れないためである (ここでいう句点は
インド系文献の句切り記号 daṇḍa で、ローマ字版ではピリオドとして印刷される)。

しかし区切りは註釈の側から決まる。

- 註が `Upaṭṭhānaṃ satīti` を独立の見出し (lemma) として取り出している
  (Paṭis-a §166、§160)
- 第 4 句については復註が `No satīti so kāyo sati nāma na hoti` (「念ではない」
  とは、その身は念というものではない、ということ) と説明し、`kāyo` を第 4 句の
  主語として読んでいる (Vism-mahāṭīkā、Sāratthadīpanī-ṭīkā)

句読点そのものは根拠にならない。CSCD で第 1 句末の `kāyo` のあとに句点が
入るのは無礙解道 §166 と清浄道論の一箇所だけで、§169 以下の並行箇所や律註の
引用は `kāyo upaṭṭhānaṃ sati anupassanā ñāṇaṃ` と続けて印刷されている。
同じ Be の中でも一定していない。

DOP は用例欄に `Paṭis I 177,32 (kāyo ~aṃ sati)` と引くが、これは見出し語の
前後を示す文脈引用であり、`kāyo upaṭṭhānaṃ sati` を一つの統語単位として
読ませるものではない (本ノートの判断)。同じ箇所について DOP は Ee が
`uppaṭṭhānaṃ` と誤るとし、Be・Ce・Se は `upaṭṭhānaṃ` とする。

## upaṭṭhāna の語義

DOP は `upaṭṭhāna` を `upa-√sthā` (S. upasthāna) の名詞とし、第 1 義を
`going near, keeping close to; presence, appearance; serving, waiting on,
attendance; worshipping` とする。無礙解道の用例もここに分類される。第 2 義は
「集会所・謁見の間」で、本件には関わらない。

第 1 義が「近づく」「現れている」「仕える」を一括している点が重要で、
註釈の語釈はこの幅の中で動いている。

文法家は接頭辞 upa- を「接近」として取り出す。Padarūpasiddhi は
`upatiṭṭheyya sakyaputtānaṃ vaḍḍhakī` (大工が釈子たちに仕えるであろう) という
用例を挙げた箇所で次のように言う。

```
ettha ca upaṭṭhānaṃ nāma upagamanaṃ
```

DOP は同じ文言を Sadd 694,25 (Saddanīti) から引く。ただしこれは動詞
`upatiṭṭhati` の格支配を論じる文脈での語釈であって、upaṭṭhāna 一般の定義
として立てられているわけではない。

## 第 2 句 — 念の側の働き

無礙解道註は第 2 句を次のように説明する (§166)。

```
Upaṭṭhānaṃ satīti taṃ ārammaṇaṃ upecca tiṭṭhatīti sati upaṭṭhānaṃ nāma.
```

「その所縁に近づいて立つから、念は upaṭṭhāna と呼ばれる」。`upecca tiṭṭhati`
の主語は念であり、能動の働きとして読まれている。

同じ註は、出入息そのものを対象とする段 (§160) で、そう呼ぶ根拠を書き添える。

```
Upaṭṭhānaṃ satīti asammussanatāya tameva assāsaṃ upagantvā ṭhānaṃ sati
nāmāti attho.
```

「不忘失であることによって、まさにその息に近づいて立つことが念と呼ばれる、
という意味である」。「立つこと」が念と呼ばれる根拠は不忘失
(asammussanatā) である。Sāratthadīpanī-ṭīkā はこれをそのまま受け継ぎ、
Vimativinodanī-ṭīkā は語尾を変えて `tathā tiṭṭhanakadhammo sati nāmā`
(そのように立つ性質の法が念と呼ばれる) とし、念が「立つ側」であることを
いっそう明示する。

この語釈は出入息念の文脈に限らない。念根・念力・念覚支の `upaṭṭhānaṭṭha`
(現前の義) に対する復註の標準的な語釈は、諸註書を通じて次の形をとる。

```
Ārammaṇaṃ upagantvā ṭhānaṃ, anissajjanaṃ vā upaṭṭhānaṃ.
```

「所縁に近づいて立つこと、あるいは (所縁を) 手放さないことが upaṭṭhāna で
ある」。第二案の `anissajjana` (放さない) は、近づき立つという空間的な像を
保持の側から言い換えたもので、不忘失の規定と重なる。

無礙解道註は `Upaṭṭhānaṭṭhoti ārammaṇaṃ upecca patiṭṭhānaṭṭho` とも言い、
同じ読みを取る。

## 第 4 句 — 身の側

第 4 句 `kāyo upaṭṭhānaṃ, no sati` について、律の復註 Vimativinodanī-ṭīkā が
身の側の読み方を明示する。

```
Kāyo upaṭṭhānanti assāsapassāsasaṅkhāto kāyo upagantvā tiṭṭhati ettha satīti
upaṭṭhānaṃ, no sati.
```

「出入息と呼ばれる身は、念がそこに (ettha) 近づいて立つ、それゆえに
upaṭṭhāna である。念ではない」。ここでの upaṭṭhāna は「立つ働き」ではなく
「立つ場所」であり、動作主ではなく場所を表す派生語として読まれている。
第 2 句と第 4 句で語の指すものが入れ替わるのはこのためである。

清浄道論の `Upaṭṭhānaṃ nāma kammaṭṭhānassa upaṭṭhānaṃ` (現前とは業処が
現れ立つことである、§222) は DOP が第 1 義の用例に挙げる箇所で、
`presence, appearance` の面にあたる。ただしこれは業処習得の五段階
(uggaha, paripucchā, upaṭṭhāna, appanā, lakkhaṇa) を説く別の文脈であり、
本定型句を説明したものではない。第 4 句の傍証としては類推にとどまる。

## 第 5 句での解消 — 二つの ṭha

第 5 句 `sati upaṭṭhānañceva sati ca` について、復註は二つの ṭha を立てて
念だけが両方を満たすことを示す。表現は書ごとに少しずつ違う。

| 復註 | 文言 |
| --- | --- |
| Vimativinodanī-ṭīkā | `sati pana sarasato upatiṭṭhanaṭṭhena saraṇaṭṭhena ca upaṭṭhānañceva sati ca` |
| Visuddhimagga-mahāṭīkā | `Sati upaṭṭhānañceva sati ca saraṇaṭṭhena, upatiṭṭhanaṭṭhena ca` |
| Sāratthadīpanī-ṭīkā | `Sati upaṭṭhānañceva sati ca saraṇaṭṭhena upaṭṭhānaṭṭhena ca` |

念は「近づき立つ義」(upatiṭṭhana / upaṭṭhāna) によって upaṭṭhāna であり、
「憶念する義」(saraṇa) によって sati である。身は前者しか持たない。しかも
身が持つ前者は「立つ場所」としての意味であって、念が持つ「立つ働き」とは
向きが違う。

まとめると次のようになる。この「働きの側 / 場所の側」という整理自体は
本ノートの枠組みだが、構成する各語釈はいずれも註釈・復註に明記されている。

| | 第 2 句・第 5 句 | 第 4 句 |
| --- | --- | --- |
| upaṭṭhāna が指すもの | 念が所縁に近づいて立つ働き | 念がそこに立つ場所 (身・所縁) |
| 典拠の語 | `ārammaṇaṃ upecca tiṭṭhati` | `upagantvā tiṭṭhati ettha` |
| そう呼ぶ根拠 | `asammussanatā` (不忘失) | なし (念ではないと否定される) |

## 属格をどう読むか — kammatthe sāmivacanaṃ

同じ品の別の箇所に `Samanti ārammaṇassa upaṭṭhānaṃ samaṃ` (等しいとは、
所縁の upaṭṭhāna が等しいこと) という表現があり、註がこの属格の扱いを
明示している (Paṭis-a §168)。

```
Ārammaṇassa upaṭṭhānanti vipassanākkhaṇe saṅkhārārammaṇassa,
maggaphalakkhaṇe nibbānārammaṇassa upaṭṭhānaṃ sati. Ettha ca kammatthe
sāmivacanaṃ yathā rañño upaṭṭhānanti.
```

「ここでの属格は目的語の意味 (kammattha) である。『王への随侍
(rañño upaṭṭhānaṃ)』と同じように」。つまり所縁は upaṭṭhāna される側であり、
念が仕える側である。DOP 第 1 義の `serving, waiting on, attendance` の面を、
註自身が使っていることになる。

「近づいて立つ」を「仕える・随侍する」という具体像でとらえると、第 2 句と
第 4 句の役割分担がそのまま出る。念が随侍する者、身が随侍される対象である。

## 註釈は一様ではない

同じ無礙解道註でも、`satīti upaṭṭhānaṭṭho` (Paṭis §164、`parimukhaṃ sati` の
語釈) に対しては語源的な解析をせず、`Upaṭṭhānaṭṭhoti sabhāvaṭṭhoyeva`
(現前の義とは、まさにその自性の義である) とだけ言う。一方
Sīlakkhandhavagga-abhinavaṭīkā は同じ箇所に `Asammosanabhāvo upaṭṭhānaṭṭho`
(不忘失であることが現前の義) を当てる。upaṭṭhāna を常に `upagantvā ṭhāna` に
分解して読むわけではない。

なお、Udāna-aṭṭhakathā などに見える `satīti upaṭṭhānaṭṭho` は無礙解道 §164 の
引用であり (諸註が `paṭi. ma. 1.164` と出典を示す)、無礙解道から独立した
証拠にはならない。

## 確認できていないこと

- Ee (PTS 版) の `uppaṭṭhānaṃ` という読みは DOP の記述によるもので、
  PTS 版の本文を直接確認してはいない
- Ce・Se の句読点は確認していない。本ノートで数えた句点の有無は CSCD
  (Be) の範囲にとどまる
- 無礙解道註が第 4 句 `Kāyo upaṭṭhānaṃ, no sati` そのものを取り上げて説明して
  いる箇所は見つからなかった。第 4 句の語釈は律の復註に依存している
- 漢訳・北伝側の対応箇所は参照していない
