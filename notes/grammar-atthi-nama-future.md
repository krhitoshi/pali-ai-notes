# MN 82 の `atthi nāma … paribhuñjissasi` の atthi nāma はどういう意味か

MN 82 (Raṭṭhapālasutta) で父がラッタパーラにかける言葉 `atthi nāma, tāta raṭṭhapāla, ābhidosikaṃ kummāsaṃ paribhuñjissasi?` の `atthi nāma` は、未来形の動詞と組になって「〜するなどということがあるのか」という驚きと非難を表す言い回しである。何かが存在するかどうかを尋ねているのではなく、目の前の事実を信じられない、受け入れられないという気持ちを言っている。文全体は「わが子ラッタパーラよ、お前が一晩たった粥を食べるなどということがあるのか」となる。

- `atthi` は「ある」(as の現在 3 人称単数) だが、主語を取らず、文頭に立って「〜ということがある」と後ろの文全体を導いている
- `nāma` は前の語を強める不変化詞である
- `paribhuñjissasi` は形は未来形だが、これから先のことを言っているのではない。ラッタパーラはこのときすでに食べている
- 驚きと非難の意味だと明言しているのは註釈書が引く文法家の規則であり、辞書は `atthi` のこの用法を「〜ということがある」と記述するにとどまる

## 当該箇所

VRI 段落番号 300 にある。ラッタパーラは出家後に故郷へ戻り、実家で施しを得られず、召使いの女が捨てようとしていた一晩たった粥をもらって、壁の根もとで食べている。そこへ父が来て声をかける。

```
Tena kho pana samayena āyasmā raṭṭhapālo taṃ ābhidosikaṃ kummāsaṃ aññataraṃ kuṭṭamūlaṃ nissāya paribhuñjati. Atha kho āyasmato raṭṭhapālassa pitā yenāyasmā raṭṭhapālo tenupasaṅkami; upasaṅkamitvā āyasmantaṃ raṭṭhapālaṃ etadavoca – ‘‘atthi nāma, tāta raṭṭhapāla, ābhidosikaṃ kummāsaṃ paribhuñjissasi? Nanu, tāta raṭṭhapāla, sakaṃ gehaṃ gantabba’’nti?
```

地の文は `paribhuñjati` (現在形) で、父の言葉は `paribhuñjissasi` (未来形 2 人称単数) である。

## `atthi nāma` + 未来形は驚きと非難を表す

以下、原文から分かること、辞書の記述、註釈書の説明を分けて書く。

### 原文から分かること

原文から直接分かるのは、未来形が時間としての未来を表していないことである。父が来た時点でラッタパーラは食べている最中であり (`paribhuñjati`)、「これから食べるのか」と尋ねる場面ではない。続く `nanu … sakaṃ gehaṃ gantabbaṃ` (自分の家に行くべきではないか) も、目の前の行いをとがめる言葉である。

`atthi nāma` と未来形の組み合わせが驚きや非難の言い回しであるということ自体は、原文には書かれていない。これは下の辞書と註釈書の記述による。

### 辞書の記述

DOP と CPD はどちらも、`atthi` が文頭に立ち、別の動詞を持つ文を導く用法を挙げている。

- DOP `atthi` の 4 は、`atthi` が (多くは節の初めで) 単数・複数の主語と使われて「there is, there are」の意味になる用法を挙げ、続けて、後ろに動詞を伴って「there is [exists] … who …; it is the case that …」の意味になる用法を挙げる。後者の用例に AN の `atthi nāma Ānanda theraṃ bhikkhuṃ vihesiyamānaṃ ajjhupekkhissatha` (A III 194,22) がある
- CPD `¹atthi` は「sometimes used as an introductory verb in a clause with another verb of more special signification」と述べ、「in one clause with another verb」の用例として MN 82 のこの文 (MN II 62,24) と、上と同じ AN の文を並べている。AN の文には「it may be that, without yam; cf. Kāçikā III 3,146」と注記がある

`nāma` については、DOP `nāma` の 2 が「as a marker of emphasis」とし、その (ii) に「to emphasise a preceding word」を挙げる。同じ (ii) の中で、疑問詞やほかの不変化詞と一緒に使われると「often expressing astonishment or reproach」とも述べ、`kathaṃ hi nāma`、`yatra hi nāma` などを挙げている。ただし DOP はこの項に `atthi nāma` を挙げていない。PTSD `Nāma` の 4 も、副詞としての `nāma` を強調の不変化詞とする。

辞書が引く AN の文 (AN 5.166, VRI 段落番号 166) は次のとおりである。

```
atthi nāma, ānanda, theraṃ bhikkhuṃ vihesiyamānaṃ ajjhupekkhissatha. Na hi nāma, ānanda, kāruññampi bhavissati theramhi bhikkhumhi vihesiyamānamhī
```

ウダーイーがサーリプッタの言葉に三度反対し、ほかの比丘がだれもサーリプッタに賛同しなかったあとで、世尊がアーナンダに言う言葉である。ここでも動詞は未来形 (`ajjhupekkhissatha`) だが、見過ごしたのはすでに起きたことで、言葉の調子は叱責である。MN 82 と同じ組み合わせが同じ働きをしている。

辞書の記述をまとめると、`atthi` が「〜ということがある」と文を導く用法は DOP と CPD が明記している。驚きや非難という含みは、どちらの辞書も `atthi` の項では語義として書いていない。CPD が参照させる Kāśikā III 3,146 がそれに関わると見られるが、その本文は確認していない。

### 註釈書の説明

註釈書 (Papañcasūdanī) はこの句に二つの説明をつけている。一つめは註釈書自身の説明、二つめは文法家の説として引かれているもので、註釈書はどちらかを退けてはいない。

一つめは、`atthi` と `nāma` をそれぞれ語として説明し、父の言葉を言い残しのある文として補うものである。

```
Atthi nāma tātāti ettha atthīti vijjamānatthe, nāmāti pucchanatthe maññanatthe vā nipāto.
```

「`atthi` は存在するという意味、`nāma` は問いの意味または思うという意味の不変化詞である」。そのうえで `idañhi vuttaṃ hoti` (こういうことが言われている) として、補った形を三つ挙げる。

```
atthi nu kho, tāta raṭṭhapāla, amhākaṃ dhanaṃ, nanu mayaṃ niddhanāti vattabbā, yesaṃ no tvaṃ īdise ṭhāne nisīditvā ābhidosikaṃ kummāsaṃ paribhuñjissasi.
Tathā atthi nu kho, tāta raṭṭhapāla, amhākaṃ jīvitaṃ, nanu mayaṃ matāti vattabbā, yesaṃ no tvaṃ īdise ṭhāne nisīditvā ābhidosikaṃ kummāsaṃ paribhuñjissasi.
Tathā atthi maññe, tāta raṭṭhapāla, tava abbhantare sāsanaṃ nissāya paṭiladdho samaṇaguṇo, yaṃ tvaṃ subhojanarasasaṃvaḍḍhitopi imaṃ jigucchaneyyaṃ ābhidosikaṃ kummāsaṃ amatamiva nibbikāro paribhuñjissasīti.
```

1. 私たちに財産はあるのか。私たちは財産のない者と言われるべきではないか。その私たちの子であるお前が、このような所に座って一晩たった粥を食べるとは
2. 私たちに命はあるのか。私たちは死んだ者と言われるべきではないか。その私たちの子であるお前が (以下同じ)
3. お前の内には、教えによって得た沙門の徳があるのだろう。お前はおいしい食べ物の味で育ったのに、この嫌な一晩たった粥を、甘露のように平然と食べるとは

1 と 2 は `nāma` を問い (`nu kho`) に、3 は思うという意味 (`maññe`) に置き換えた形になっている。註釈書は続けて、父は苦しみに打たれてこの意味を全部は言えず、`atthi nāma … paribhuñjissasi` とだけ言ったのだと説明する。

```
So pana gahapati dukkhābhitunnatāya etamatthaṃ paripuṇṇaṃ katvā vattumasakkonto – ‘‘atthi nāma, tāta raṭṭhapāla, ābhidosikaṃ kummāsaṃ paribhuñjissasī’’ti ettakameva avaca.
```

この説明では、`atthi` は「財産がある」「命がある」「沙門の徳がある」という存在の意味のまま読まれ、あるとされるものが省かれていることになる。

二つめは、文法家 (`akkharacintakā`) の規則として引かれる (`vadanti`)。

```
Akkharacintakā panettha idaṃ lakkhaṇaṃ vadanti – anokappanāmarisanatthavasenetaṃ atthisadde upapade ‘‘paribhuñjissasī’’ti anāgatavacanaṃ kataṃ. Tassāyamattho – ‘‘atthi nāma…pe… paribhuñjissasi, idaṃ paccakkhampi ahaṃ na saddahāmi na marisayāmī’’ti.
```

「文法家たちはここで次の規則を言う。信じられないこと (`anokappana`) と耐えられないこと (`amarisana`) の意味で、`atthi` という語が添えられているときに、`paribhuñjissasi` という未来形が使われている。その意味は『`atthi nāma` … `paribhuñjissasi`、これを目の前に見ても私は信じないし、耐えられない』である」。

この規則が、未来形なのに未来の意味でない理由と、文全体が驚きと非難になる理由を直接説明している。冒頭の答えはこの二つめの説明に拠っている。

### 留保

- 「〜するなどということがあるのか」という訳は、文法家の規則が言う「信じない、耐えられない」を日本語の言い回しに移した筆者の訳であり、註釈書の言葉そのものではない
- 註釈書の一つめの説明に従えば、`atthi` は省かれた主語 (財産、命、沙門の徳) についての「あるのか」「あるのだろう」であり、文の組み立ての見方が二つめとは違う。註釈書は両方を並べており、どちらが正しいとは言っていない
- `nāma` の働きについて、註釈書は「問いまたは思うという意味」とし、DOP と PTSD は強調とする。註釈書の言い方は、一つめの説明で補った形 (`atthi nu kho`、`atthi maññe`) に対応している
