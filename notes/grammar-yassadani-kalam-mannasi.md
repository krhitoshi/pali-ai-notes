# `yassadāni tvaṃ, raṭṭhapāla, kālaṃ maññasi` の `yassa` は何のためにあるのか

MN 82 Raṭṭhapālasutta で世尊がラッタパーラに言う `yassadāni tvaṃ, raṭṭhapāla, kālaṃ maññasi` の `yassa` は、関係代名詞 `ya` の属格単数 (与格と同形) で、`kālaṃ` にかかって「何の時か」を言う語である。`yassa … kālaṃ` で「それの時、それをするのにふさわしい時」となり、全体は「今あなたがその時だと思うこと」という関係節になる。

この関係節を受ける主節 (「それをしなさい」「その時はあなたが知っている」) は本文には書かれていない。註釈書はこの定型句を説明するたびに、`yassa` に `gamanassa` (行くことの) などの名詞を補い、`tassa …` / `taṃ …` / `tadeva …` で始まる主節を補っている。`yassa` があることで、何をする時かの判断が相手にゆだねられた言い方になる。

## 当該箇所

MN 82 Raṭṭhapālasutta、VRI 段落番号 299。出家したラッタパーラが、両親に会いに行く許しを世尊に求める場面である。引用では VRI 版の異読注記を省いた。

```
Ekamantaṃ nisinno kho āyasmā raṭṭhapālo bhagavantaṃ etadavoca –
‘‘icchāmahaṃ, bhante, mātāpitaro uddassetuṃ, sace maṃ bhagavā
anujānātī’’ti. Atha kho bhagavā āyasmato raṭṭhapālassa cetasā ceto
paricca manasākāsi. Yathā bhagavā aññāsi – ‘‘abhabbo kho raṭṭhapālo
kulaputto sikkhaṃ paccakkhāya hīnāyāvattitu’’nti, atha kho bhagavā
āyasmantaṃ raṭṭhapālaṃ etadavoca – ‘‘yassadāni tvaṃ, raṭṭhapāla, kālaṃ
maññasī’’ti. Atha kho āyasmā raṭṭhapālo uṭṭhāyāsanā bhagavantaṃ
abhivādetvā padakkhiṇaṃ katvā senāsanaṃ saṃsāmetvā pattacīvaramādāya
yena thullakoṭṭhikaṃ tena cārikaṃ pakkāmi.
```

`yassadāni` は `yassa` + `dāni` (`idāni`、今) である。この言い回しは定型句で、CSCD の中部の本文を `yassadāni` の綴りで検索すると 17 の XML `p` 要素に現れる (`yassa dāni` と分けて書かれたものや `…pe…` で省かれた箇所は数えていない)。暇を告げる相手への返答 (`handa ca dāni mayaṃ … gacchāma` に対する `yassadāni tvaṃ, …, kālaṃ maññasi`) と、用意が整ったことを知らせる報告の結び (`yassadāni, bhante, bhagavā kālaṃ maññati`) が多い。呼びかけの語や `tvaṃ` の有無、動詞の人称は場面によって変わるが、`yassa (i)dāni … kālaṃ maññ-` の骨組みは変わらない。

## `yassa` は `kālaṃ` にかかる

辞書の記述による。DOP は `kāla` の第 2 義を "the proper time for (gen., dat., inf., or yaṃ + opt.); the right time; a suitable time" とし、`kāla` が「〜にふさわしい時」の意味で属格・与格・不定詞をとることを示している。その用例の先頭にこの定型句が挙がっている。

- `yassa dāni bhante bhagavā kālaṃ maññati` (Vin I 227,9)
- `na dāni te tuṇhībhāvassa kālo` (D I 95,4)。「今は君が黙っている時ではない」。`tuṇhībhāvassa` (黙っていることの) が `kālo` にかかる
- `kālo ito pakkamanāya` (Th 528)。「ここから立ち去る時である」

2 番目の例の `tuṇhībhāvassa kālo` で名詞が占めている位置に、関係代名詞を置いたものが `yassa kālaṃ` である。つまり `yassa` は `maññasi` の目的語でも呼びかけの相手を指す語でもなく、`kālaṃ` の内容 (何をする時か) を言う語である。

PTSD も `Kāla` の項の「ふさわしい時」の義にこの句を挙げ、"yassa kālaŋ maññasi for what you think it is time (to go), i. e. goodbye" と訳している。

`yassa` の語形は属格と与格が同形で、DOP は両方の構文を挙げたうえでこの句をどちらとも特定していない。本ノートでは、註釈書が `yassa gamanassa` と名詞を並べて `tassa kālaṃ` で受けていること (次節) に合わせて属格と呼んでおく。どちらに取っても「〜の時 / 〜のための時」で意味は変わらない。

## 註釈書は名詞と主節を補って読む

以下は註釈書と復註の説明である。本文にあるのは `yassa … kālaṃ maññasi` の関係節だけで、補われた名詞と主節は註釈書の読みである。

### 長部の註釈書 (Sumaṅgalavilāsinī)

DN 2 Sāmaññaphalasutta には、この句が 2 回現れる。1 回目 (VRI 段落番号 158) は、ジーヴァカがアジャータサットゥ王に象の用意ができたと知らせる場面である。

```
Tattha yassa dāni kālaṃ maññasīti upacāravacanametaṃ. Idaṃ vuttaṃ hoti –
‘‘yaṃ tayā āṇattaṃ, taṃ mayā kataṃ, idāni tvaṃ yassa gamanassa vā
agamanassa vā kālaṃ maññasi, tadeva attano ruciyā karohī’’ti.
```

「『yassa dāni kālaṃ maññasi』は礼儀としての言い方 (`upacāravacana`) である。こう言われたことになる。『あなたが命じたことは私がなしました。今あなたが、行くことであれ行かないことであれ、その時だと思うこと、それをこそ自分の好むとおりになさい』」。`yassa` に `gamanassa vā agamanassa vā` を補い、主節を `tadeva … karohi` (それをこそなさい) で補っている。

2 回目 (VRI 段落番号 252) は、暇を告げる王に世尊が答える場面である。

```
Yassadāni tvanti yassa idāni tvaṃ mahārāja gamanassa kālaṃ maññasi
jānāsi, tassa kālaṃ tvameva jānāsīti vuttaṃ hoti.
```

「大王よ、今あなたがその行くことの時だと思う (知る)、その時はあなた自身が知っている、と言われたことになる」。`dāni` を `idāni` に、`maññasi` を `jānāsi` に言い換え、`yassa` に `gamanassa` を補い、主節を `tassa kālaṃ tvameva jānāsi` で補っている。

### 相応部の註釈書と律の註釈書

SN 54.9 Vesālīsutta (VRI 段落番号 985) で、アーナンダが比丘たちを集め終えて世尊に報告する `yassa dāni, bhante, bhagavā kālaṃ maññati` について、相応部の Mahāvagga-aṭṭhakathā は次のように説明する。

```
Yassadāni, bhante, bhagavā kālaṃ maññatīti ettha ayamadhippāyo –
bhagavā bhikkhusaṅgho sannipatito, esa kālo bhikkhūnaṃ dhammakathaṃ
kātuṃ, anusāsaniṃ dātuṃ, idāni yassa tumhe kālaṃ jānātha, taṃ
kātabbanti.
```

「ここでの趣旨はこうである。世尊よ、比丘サンガは集まりました。これは比丘たちに法話をし、教誡を与える時です。今あなたがたがその時だと知ることを、なすべきです」。主節は `taṃ kātabbaṃ` (それをなすべきである) で補われている。律の Pārājikakaṇḍa-aṭṭhakathā も同じ場面にほぼ同文の説明を置く (`taṃ kattabbanti`)。

### 「行きなさい」と言い換える説明

夜が更けて世尊が在家の人々を帰す場面の `yassadāni tumhe kālaṃ maññatha` について、律の復註 Sāratthadīpanī は次のように説明する。相応部の Saḷāyatanavagga-aṭṭhakathā と Udāna-aṭṭhakathā にも同じ説明がある。

```
Yassadāni tumhe kālaṃ maññathāti yassa gamanassa tumhe kālaṃ maññatha,
gamanakālo tumhākaṃ, gacchathāti vuttaṃ hoti.
```

「あなたがたがその行くことの時だと思う、(その) 行く時はあなたがたのものである、行きなさい、と言われたことになる」。

### 補われる名詞は場面で変わる

上の説明で `yassa` に補われるのは「行くこと」が多いが、場面によって別の語になる。

| 場面 | `yassa` に補われる語 | 補われる主節 |
| --- | --- | --- |
| DN 2、ジーヴァカから王へ | `gamanassa vā agamanassa vā` (行くこと、または行かないこと) | `tadeva attano ruciyā karohi` |
| DN 2、世尊から王へ | `gamanassa` (行くこと) | `tassa kālaṃ tvameva jānāsi` |
| SN 54.9 と律、アーナンダから世尊へ | 名詞は補わず、直前に「法話をし教誡を与える時」と述べる | `taṃ kātabbaṃ` |
| 夜更けに世尊から在家へ | `gamanassa` (行くこと) | `gamanakālo tumhākaṃ, gacchatha` |
| 律の Mahāvagga-aṭṭhakathā、世尊への報告 | `tesaṃ hitakiriyatthassa` (かれらに利益をなすという事柄) | なし |
| DN 19、ブラフマー・サナンクマーラからゴーヴィンダへ | `yassā pabbajjāya` (出家) | `ayameva hotu` |

どの説明でも `yassa` は「相手がこれからしようとしていること」を指す位置にあり、その中身は場面から補われている。`yassa` 自体は中身を言わないので、同じ句が見送りにも、用意ができた知らせにも、許可にも使える。

## MN 82 のこの箇所での読み

中部の註釈書 (Papañcasūdanī) は、この箇所で世尊がラッタパーラの心を調べたことを説明し、本文を `yathā bhagavā aññāsi…pe… kālaṃ maññasīti` と引いて結ぶだけで、`yassadāni` の句そのものは説明していない。以下は、前節の註釈書の説明をこの箇所に当てはめた推論である。

- ラッタパーラの申し出は `icchāmahaṃ, bhante, mātāpitaro uddassetuṃ` (両親に会いに行きたい) なので、`yassa` が指すのは両親に会いに行くことである
- 長部の註釈書にならって補えば、「ラッタパーラよ、今あなたがその (行くことの) 時だと思うことを、(なしなさい)」となる。直後にラッタパーラが礼をして旅立っていることからも、この句は許可として受け取られている
- `yassa` がなく `dāni tvaṃ kālaṃ maññasi` だけなら、「今あなたは時だと思う」という叙述になり、何の時かを相手の判断にゆだねる形にならない

## 確認できていない範囲

- CPD は `kāreti` までの刊行で、字母順でその後に来る `kāla` は収録範囲の外である。辞書の根拠は DOP と PTSD である
- 関係代名詞 `ya` の項は、DOP と CPD が頭字 y の範囲を収録していないため引いていない
- DOP が用例として挙げる D I 95,4 と Th 528 は、DOP の引用のまま示した。それぞれの本文には当たっていない
- 註釈書・復註の説明は、CSCD を `yassadāni` と `yassa (i)dāni … kālaṃ maññ- / jān-` で検索して見つかったものに限る。別の言い回しで説明している箇所は拾えていない
- `upacāravacana` を「礼儀としての言い方」としたのは、DOP の `upacāra` 第 2 義 "act of civility, respects" による。DOP は第 3 義に文法用語としての「転用、比喩的な用法」も挙げており、こちらの意味である可能性は検討していない
- 現代語訳は確認していない
