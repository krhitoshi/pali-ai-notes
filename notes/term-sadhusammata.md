# sādhusammata は「尊敬された」か「善いと見なされた」か (MN 81)

MN 81 Ghaṭikārasutta で陶工 ghaṭikāra が繰り返す次の句の sādhusammataṃ は、辞書の訳語にある「尊敬された、名声ある」ではなく、文字通り「善いことと見なされている」の意味で読む。

```
Sādhusammatañhi me tassa bhagavato dassanaṃ arahato sammāsambuddhassā’ti.
```

「かの世尊・阿羅漢・正自覚者にお目にかかることは、私にとって善いことと見なされている」、つまり「私はあの世尊にお目にかかることを善いことだと思っている」である。sādhusammata の語義は常に「善い (sādhu) と見なされた (sammata)」であり、人を主語にしたときに結果として「尊敬された」と訳されるだけで、ここでは主語が「見ること (dassanaṃ)」なので「尊敬」の訳は入り込まない。

## なぜ「尊敬された」と読めてしまうか

PTSD は sādhu の項で sādhusammata を "highly honoured" (D i.48; S iv.398; Sn p. 90 sq.; Miln 4, 21) と訳し、sammata の項では "2. honoured, revered … sādhusammata considered, revered, as good D i.47; S iv.398" としている。DPD も "well regarded; respected (by)" を第一義に挙げ、"considered good" を直訳として添える。これらの訳語だけを見ると、MN 81 でも「よく尊敬された」と取りたくなる。

しかしこの訳語は、三蔵での用例の大半が「人 + sādhusammato bahujanassa」(多くの人に善人と見なされた = 名声ある) という定型句であることを反映したものであり、複合語そのものの意味が「尊敬」なのではない。

## 語義の中核は「善いと見なされた」

註釈 (自分の推論ではなく註の記述) は sādhusammata を次のように説明する。DN 2 Sāmaññaphalasutta 註 (s0101a.att.xml) の pūraṇa kassapa らの紹介句に対する語釈:

```
Sādhusammatoti ayaṃ sādhu, sundaro, sappurisoti evaṃ sammato.
Bahujanassāti assutavato andhabālaputhujjanassa.
```

「sādhusammato とは『この人は善い、立派だ、善人だ』とこのように見なされた、の意。bahujanassa とは、無聞の愚かな凡夫 (の多く) にとって、の意」。MN 30 註 (s0201a.att.xml)、SN 註、Sn 註も同趣旨で、Sn 註は `‘‘sādhavo ete santo sappurisā’’ti evaṃ bahujanassa sammatā` と、bahujanassa が「見なす側」であることを明示している。

復註も同じ読みを取る。DN 2 の復註 (s0101t.tik.xml) は、sādhu を「見なす側」(具格) ではなく評価の内容と取ることを明言している。

```
Sādhusammatoti ‘‘sādhū’’ti sammato, na sādhūhi sammatoti āha ‘‘ayaṃ sādhū’’tiādi.
```

「sādhusammato とは『善い』と見なされた、の意であって、善い人々によって見なされた、の意ではない。だから (註は)『この人は善い』云々と言った」。SN 3.1 の復註 (s0301t.tik.xml) も同趣旨で説明する。

つまり sammata の内容は「善いという評価」であり、「尊敬」はその評価を受けた人の社会的な立場を言い換えたものにすぎない。

## MN 81 の構文

- sādhusammataṃ は dassanaṃ (nt. nom. sg.) にかかる述語形容詞 (nt. nom. sg.)
- me は「誰がそう見なしているか」を表す属格 (行為者の属格)。定型句の bahujanassa と同じ位置を占める
- tassa bhagavato … arahato sammāsambuddhassa は dassanaṃ の目的語を示す属格 (目的語の属格)

定型句と並べると、構造が同じで主語だけが人から事柄に変わっていることが分かる。Ñāṇamoli / Bodhi 訳 (The Middle Length Discourses of the Buddha, p. 668) もこの句を "I hold that it is good to see that Blessed One" と、me を判断の主体として訳している。

| | 見なされるもの | 見なす者 (gen.) | 訳 |
|---|---|---|---|
| DN 2 など | pūraṇo kassapo (人) | bahujanassa | 多くの人に善人と見なされた (名声ある) |
| MN 81 | dassanaṃ (見ること) | me | 私に善いことと見なされた (私は善いと思う) |

MN 81 註 (mn/mn_attha_081.md) にも復註 (mn/mn_tika_081.md) にもこの句への語釈がない。

## 三蔵での用例の分布

CSCD の本文 (mula) で sādhusammat を検索した結果は 31 箇所。内訳は次のとおり (何を数えたか: 検索でヒットした段落・偈の行数)。

- 人 + bahujanassa の定型句: DN 2, DN 16 (Mahāparinibbāna の Subhadda の問い), MN 30, MN 35 (saccaka), MN 77, SN 3.1, SN 44.9, Sn (Sabhiya) の 22 箇所。六師外道の紹介句と、saccaka の紹介句 (bhassappavādako paṇḍitavādo sādhusammato bahujanassa) が大半を占める
- 人 + 他の属格 (isīnaṃ, kaññānaṃ) または属格なし: Ja (Saṃkicca), Ap (brāhmaṇo sādhusammato, sāvakaṃ sādhusammataṃ) の 7 箇所
- 事柄 (dassanaṃ) + me: MN 81 の 2 段落 (定型句は 283 に 2 回、284 に 4 回現れ、いずれも dutiyampi の箇所は …pe… で略されている。284 末尾の Tathā hi pana me sādhusammataṃ … を含めると語の出現は計 7 回)

主語が人でないのは MN 81 だけである。したがって辞書の「尊敬された」は MN 81 以外の用例から立てられた訳語であり、MN 81 には当てはまらない。PTSD が挙げる Milindapañha (Miln 4, 21) の用例も 2 箇所とも人 + bahujanassa の定型句 (六師の紹介句と nāgasena の紹介句) であり、上の 31 箇所には含めていない。

## 現行の対訳の扱い

mn/mn_081.md の語釈行は、283 で「善いこととみなされている、善いものと認められている」、284 で「実に、善いことと認められている」、284 末尾の Tathā hi pana me sādhusammataṃ で「私にとって善いことと思われる」としており、本ノートの読みと一致している。改訂の必要はない。
