# yena … tadavasari の構文 — yena … tenupasaṅkami との違い、動詞の格支配、関係詞と相関詞の格

MN 82 (ラッタパーラ経) 冒頭の `yena thullakoṭṭhikaṃ nāma kurūnaṃ nigamo tadavasari` は、「トゥッラコッティカという名のクル人の町がある方、そこに着いた」と読む。`yena` は「〜のある方に」を表す具格の関係詞、`tad` は `avasari` の行き先を表す対格の相関詞 (`taṃ`) である。

同じ経の `yena bhagavā tenupasaṅkamiṃsu` との違いは二点ある。相関詞が `tena` (具格) でなく `taṃ` (対格) であること、動詞が接近 (`upasaṅkamati`) でなく到着 (`avasarati`) を言うことである。

関連して確かめたことは次のとおり。

- 方向の `yena` を `taṃ` / `tad` で受ける形は、CSCD の本文 (mūla) で確認できた範囲では `avasarati` に限られる
- `yena … tena` は `upasaṅkamati` に限らず、出発する、進む、体を向けるなど方向をとる動詞に広く使われる
- `upasaṅkamati` も `avasarati` も、単体では行き先を対格でとる。行き先を具格で表す例は `yena` と組まない形では見つからなかった
- 関係詞 (`ya-`) と相関詞 (`ta-`) の格は、そろうのが通常というわけではない。格はそれぞれの節の中での働きで決まる

## yena … tadavasari の構造

当該箇所は MN 82、VRI 段落番号 293 (CSCD `s0202m.mul.xml`)。

```
ekaṃ samayaṃ bhagavā kurūsu cārikaṃ caramāno mahatā bhikkhusaṅghena
saddhiṃ yena thullakoṭṭhikaṃ nāma kurūnaṃ nigamo tadavasari.
```

語ごとの働きは次のとおり。

| 語 | 形 | 働き |
| --- | --- | --- |
| `yena` | 関係代名詞 `ya` の具格 | 「〜のある方に」という副詞の働き |
| `thullakoṭṭhikaṃ nāma kurūnaṃ nigamo` | 主格 | `yena` 節の主語 (動詞 `atthi` を補う名詞文) |
| `tad` | 相関詞 `taṃ` (対格) が母音の前でとる形 | `avasari` の行き先 |
| `avasari` | `avasarati` のアオリスト 3 人称単数 | 「着いた」 |

`nigamo` は主格であって `avasari` の目的語ではない。`avasari` の行き先は `tad` が表す。

`avasarati` は `ava` + `sarati`。DOP は "goes down (to); moves away (to)" とし、アオリストの用例として `yena Vesālī tad avasari` (Vin III 11)、`yena Uruvelā senānigamo tad avasariṃ` (M I 166)、`yena Vāsabhagāmo tad avasaruṃ` (Vin I 312) を挙げる。

### 註釈書の説明

以下は註釈書と復註の説明であり、本文が述べていることではない。MN 82 の註釈は `thullakoṭṭhika` という名の由来だけを説明し、`tadavasari` には触れない。同じ定型句への説明は他の箇所にある。

長部の註釈書 (Sīlakkhandhavaggaṭṭhakathā、DN 3 の VRI 段落番号 254 への註釈):

```
Yena icchānaṅgalanti yena disābhāgena icchānaṅgalaṃ avasaritabbaṃ.
Yasmiṃ vā padese icchānaṅgalaṃ. Ijjhānaṅgalantipi pāṭho. Tadavasarīti
tena avasari, taṃ vā avasari. Tena disābhāgena gato, taṃ vā padesaṃ
gatoti attho.
```

「『yena icchānaṅgalaṃ』とは、どの方角によってイッチャーナンガラに着くべきであるか、その方角によって。あるいは、イッチャーナンガラがある場所に。(中略) 『tadavasari』とは、それによって着いた、あるいは、それに着いた。その方角によって行った、あるいは、その場所に行った、という意味である。」

中部の註釈書 (Mūlapaṇṇāsa-aṭṭhakathā、MN 41 への註釈):

```
Tadavasarīti taṃ avasari, sampattoti attho.
```

ウダーナの註釈書 (Udāna-aṭṭhakathā):

```
Tadavasarīti tena avasari, taṃ vā avasari, tattha avasari, pāvisīti
attho.
```

律の註釈書 (Pārājikakaṇḍa-aṭṭhakathā、`yena bārāṇasī tadavasari` への註釈) は `Tena avasari tadavasari` とだけ言う。これを受けて律の復註 Sāratthadīpanī は次のように説明する。

```
Tadavasarīti ettha tanti karaṇatthe upayogavacananti āha ‘‘tena
avasari tadavasarī’’ti.
```

「『tadavasari』について、ここでの『taṃ』は具格の意味で用いられた対格である、ということを『tena avasari tadavasari』と述べている。」

註釈書が示す `tad` の読み方は二通りにまとまる。

1. 対格のまま行き先と読む (`taṃ avasari`、その場所に着いた)
2. 対格の形で具格の意味と読む (`tena avasari`、その方角によって行った)

長部の註釈書とウダーナの註釈書は両方を `vā` で並べる。中部の註釈書は 1 だけを挙げ、律の註釈書は 2 だけを挙げる。`avasari` の言い換えには `sampatto`、`pāvisi`、`gato`、`anupāpuṇi` が使われている。`anupāpuṇi` は上の引用の外にあり、ウダーナの註釈書の別の箇所 (VRI 段落番号 76 への註釈、`Tadavasarīti taṃ pāṭaligāmaṃ avasari anupāpuṇi`) と Suttanipāta の註釈書 (`tena avasari tadavasari agamāsi, taṃ nigamaṃ anupāpuṇīti vuttaṃ hoti`) に出る。

## yena bhagavā tenupasaṅkamiṃsu との違い

同じ MN 82 の VRI 段落番号 293 に次の文がある。

```
Atha kho thullakoṭṭhikā brāhmaṇagahapatikā yena bhagavā
tenupasaṅkamiṃsu;
```

| | `yena bhagavā tenupasaṅkamiṃsu` | `yena … nigamo tadavasari` |
| --- | --- | --- |
| 関係詞 | `yena` (具格) | `yena` (具格) |
| `yena` 節の名詞 | `bhagavā` (主格) | `nigamo` (主格) |
| 相関詞 | `tena` (具格) | `tad` = `taṃ` (対格) |
| 動詞 | `upasaṅkamati` (近づく) | `avasarati` (着く、入る) |

共通するのは、`yena` 節が主格の名詞文で「〜のいる (ある) 方」を表すことである。

違いの一つは相関詞の格である。`tenupasaṅkamiṃsu` では `yena` を `tena` で受け、両方の節で同じ「〜の方に」という副詞の働きをする。`tadavasari` では主節の側が副詞でなく `avasari` の行き先 (対格) になっている。関係詞と相関詞の格が違うこと自体は通常の範囲である (後の節「関係詞と相関詞は格がそろうのが通常か」)。目につくのは、方向の `yena` が他の動詞では `tena` と組むのに、`avasarati` の定型だけが `taṃ` で受ける点である。

`tenupasaṅkami` の `yena` について、中部の註釈書 (Mūlapaṇṇāsa-aṭṭhakathā) は次のように説明する。これは註釈書の説明であり、`tadavasari` の `yena` を `yena disābhāgena` または `yasmiṃ padese` と言い換える長部の註釈書の説明と並行する。

```
Yena bhagavā tenupasaṅkamīti yenāti bhummatthe karaṇavacanaṃ, tasmā
yattha bhagavā, tattha upasaṅkamīti evamettha attho daṭṭhabbo.
```

「『yena』とは処格の意味で用いられた具格である。それゆえ、世尊のおられる所、そこに近づいた、とここでの意味を見るべきである。」

もう一つは動詞の意味である。`upasaṅkamati` は「そちらへ近づく」という接近を言い、多くの場合 `upasaṅkamitvā …` と続いて、着いた後の動作が別に述べられる。`avasarati` は到着を言い、`cārikaṃ caramāno` (遊行しながら) に続いて、旅の末にその土地に着いたことを一語で述べる。

同じ経の VRI 段落番号 299 (番号のない 2 つめの p 要素) に、出発と到着が並ぶ箇所がある。

```
yena thullakoṭṭhikaṃ tena cārikaṃ pakkāmi. Anupubbena cārikaṃ caramāno
yena thullakoṭṭhiko tadavasari.
```

同じ行き先について、出発 (`pakkāmi`) は `tena`、到着 (`avasari`) は `tad` で受けている。

## avasarati 以外で yena を taṃ / tad で受ける例はあるか

CSCD の本文 (mūla) を検索した範囲では、見つからなかった。方向の `yena` を `taṃ` / `tad` で受ける形は `avasarati` の定型に限られるようである。

集計の対象と結果は次のとおり。

- `tadavasar-` を含む本文の段落 (XML の p 要素) は 115。活用形は `avasari` のほか `avasariṃ` (1 人称単数)、`avasaruṃ` (3 人称複数) がある
- その 115 のすべてで、同じ文の中に `yena` が先行する
- `yena` の後 5 語程度までに `taṃ` / `tad` が来て `upasaṅkamati`、`gacchati`、`āgacchati`、`pavisati`、`pakkamati`、`pāyāti`、`pāpuṇāti`、`osarati` などが続く形は該当がなかった
- `yena` を `tena` で受ける `avasarati` (`yena … tena avasari` の形) も、本文、註釈書、復註で該当がなかった。註釈書の `tena avasari` は `tadavasari` の言い換えとして出るだけである

`tadavasari` の行き先は、確認した用例ではすべて町、村、都市、地方などの場所である (ヴェーサーリー、ウルヴェーラー、パータリガーマ、スナーパランタ地方など)。

なお、`yena` の後に `taṃ` が来る文は他にもあるが、`yena` が方向を表さないものは別の構文である。

```
yena me āyasmanto attamanā honti taṃ karomi
```

増支部 4 集 (CSCD `s0402m3.mul.xml`)。「尊者たちが満足するようなこと、それを私はする」。`yena` は「それによって」という手段の具格、`taṃ` は `karomi` の目的語である。

## yena … tena は upasaṅkamati 以外でも使うか

使う。`yena … tena` は「〜のいる (ある) 方へ」という方向を表す枠で、動詞は `upasaṅkamati` に限らない。本文で確認できた動詞は、移動を表すものと、体や物を向けることを表すものに分かれる。

移動の動詞:

| 動詞 | 例 | 所在 |
| --- | --- | --- |
| `pakkamati` (出発する) | `yena sāvatthi tena cārikaṃ pakkāmi` / `yena vesālī tena pakkāmi` | 経と律に多数 |
| `pāyāti` (進む) | `yena jīvakassa komārabhaccassa ambavanaṃ tena pāyāsi` | DN 2、VRI 段落番号 159 ほか多数 |
| `paccāyāti` (帰る) | `yena sakaṃ gharaṃ tena paccāyāsi` | ウダーナ (`s0503m.mul.xml`) |
| `pavisati` (入る) | `Yena ārāmo tena pāvisi` | MN 86 (`s0202m.mul.xml`) |
| `saṅkamati` (移る) | `manussā yena subhikkhaṃ tena saṅkamanti` | 増支部 5 集 (`s0403m1.mul.xml`) |
| `gacchati` (行く) | `yena gāmo tena gantuṃ` | 律の大品、VRI 段落番号 201 |
| `abhidhāvati` (突進する) | `yena bhagavā tena abhidhāvi` | 律の小品、VRI 段落番号 342 |
| `peseti` (向かわせる) | `yena so kālaṅkato tena rathaṃ pesehi` | DN 14、VRI 段落番号 50 |

同じ仲間として、相関詞を重ねる形と、`vā` で並べる不定の形がある。

```
So yena yena icchati tena tena gacchati
```

相応部因縁篇、VRI 段落番号 233 (`s0302m.mul.xml`)。「行きたい方へどこへでも行く」。

```
yena vā tena vā palāyanti
```

相応部蘊篇、VRI 段落番号 78 (`s0303m.mul.xml`) ほか。「どこへでも逃げる」。

体や物を向ける動詞:

- 合掌を向ける: `yena bhagavā tenañjaliṃ paṇāmetvā`。用例の多い定型で (`tenañjali-` または `tena añjali-` を含む本文の XML の p 要素は 74)、MN 82 の VRI 段落番号 293 にも `appekacce yena bhagavā tenañjaliṃ paṇāmetvā ekamantaṃ nisīdiṃsu` とある
- 頭や足を向ける: `yena bhagavā tena sīsaṃ katvā nipātesuṃ`、`yena bhagavā tena pāde karitvā seyyaṃ kappesi` (律の波逸提、長老サーガタの話、`vin02m1.mul.xml`)。`yena rājā tena pāde abhippasāreyyāsi` (律の大品、VRI 段落番号 242)
- 向きを変える: `yena vuḍḍho tena parivattitabbaṃ` (律の小品、`vin02m3.mul.xml`)
- 心が向く: `yena buddho tena teneva nato` (Cūḷaniddesa、`s0516m.mul.xml`)

形は同じでも `yena` が方向を表さない文は、普通の具格の関係文である。

```
yena vāhanena jīvako icchati tena vāhanena gacchatu
```

律の大品、VRI 段落番号 334。「ジーヴァカが望む乗り物で行かせよ」。

## upasaṅkamati と avasarati は単体で具格・対格をとるか

どちらも単体では行き先を対格でとる。行き先を具格で表す例は、`yena` と組まない形では見つからなかった。

### upasaṅkamati

対格は単体で普通にとる。DOP の `upasaṅkamati` の項が挙げる用例のうち、CSCD の本文で確かめたものを示す。

- `candūpamā, bhikkhave, kulāni upasaṅkamatha` (月のように家々を訪ねなさい。相応部因縁篇、VRI 段落番号 146。S II 198)
- `Yaṃnūnāhaṃ taṃ bhagavantaṃ dassanāya upasaṅkameyyaṃ` (増支部 8 集、`s0404m1.mul.xml`。A IV 180)
- `akālo kho ajja bhagavantaṃ dassanāya upasaṅkamituṃ` (相応部有偈篇、VRI 段落番号 242。S I 211)
- `imaṃ parisaṃ upasaṅkanto homi` (MN 79、VRI 段落番号 270。M II 30)

受動の形でも `kulāni upasaṅkamitabbāni` (律の小品、`vin02m3.mul.xml`。Vin II 32) と、訪ねる相手が主格に立つ。能動で対格の目的語をとる動詞であることを示す。

具格については、`tenupasaṅkam-` / `tena upasaṅkam-` が同じ文に `yena` を伴わずに出る例を本文で探したが、該当がなかった。単体で具格と使われる場合、その具格は行き先ではなく手段を表す。

```
Manomayena kāyena, iddhiyā upasaṅkami.
```

増支部 8 集 (`s0404m1.mul.xml`。A IV 235)。「意から成る身体で、神通によって近づいた」。

### avasarati

対格を単体でとる。ただし `tadavasari` の定型の外では用例がごく少なく、本文で確認できたのは次の 2 例である。

```
So māsakhettaṃ turito avāsariṃ
```

Vimānavatthu (`s0506m.mul.xml`。Vv 80:8)。「私は急いで豆畑に入った」。対格の行き先 `māsakhettaṃ` を直接とる。

```
Taṃ saddaṃ sutvā turitamavasarī so, suddhodanassa tada bhavanaṃ upāvisi
```

Suttanipāta 685 (`s0505m.mul.xml`)。こちらは `avasarī` に行き先の語がない。

DOP は `avasarati` と `osarati` を相互に参照させている。`osarati` の項は第一の語義を "goes down (to); approaches; enters; flows into" とし、"+ acc. or loc." と明記する。

- `samaṇo khalu, bho, gotamo amukaṃ nāma gāmaṃ vā nigamaṃ vā osarissati` (MN 27、VRI 段落番号 289)
- `yo gāmantaṃ osareyya, vajjaṃ naṃ phuseyya` (律の経分別、VRI 段落番号 409、`vin01m.mul.xml`)
- `te anvaddhamāsaṃ saṅghamajjhe osaranti pātimokkhuddesāya` (処格。MN 77、`s0202m.mul.xml`)

註釈書の言い換えも対格の支配を前提にしている。長部の註釈書の `icchānaṅgalaṃ avasaritabbaṃ` と、Suttanipāta の註釈書の `so … nigamo osaritabbo` は、行き先が主格に立つ受動の形である。

行き先を具格で表す `avasarati` の例は見つからなかった。

### yena 構文との関係

以下は上の用例からの推論である。

- `yena … tena` の具格は動詞が要求する格ではなく、「〜の方へ」という方向の枠が持つ格と見られる。この枠は `pakkamati` や `añjaliṃ paṇāmeti` など、動詞を選ばずに付く
- `upasaṅkamati` は対格をとれる動詞だが、`yena … tena` の文ではその対格の位置が空いたままになっている
- `tadavasari` では、動詞本来の対格の位置を `tad` が埋めている。註釈書の二つの読み方のうち `taṃ avasari` は動詞の格支配にそのまま合う。`tena avasari` は `yena` に合わせた読み方で、動詞単体の用法からは裏づけが取れなかった

## 関係詞と相関詞は格がそろうのが通常か

そろうのが通常というわけではない。関係詞 (`ya-`) と相関詞 (`ta-`) の間でそろうのは性と数で、格はそれぞれの節の中での働きによって別々に決まる。

働きが同じならそろう。

```
Yo kho, vakkali, dhammaṃ passati so maṃ passati
```

相応部蘊篇 (`s0303m.mul.xml`)。`yo` も `so` も各節の主語なので、どちらも主格である。

働きが違えばそろわない。これも普通の形である。

```
Ye dhammā hetuppabhavā, tesaṃ hetuṃ tathāgato āha
```

律の大品 (`vin02m2.mul.xml`)。`ye` は主格 (関係節の主語)、`tesaṃ` は属格 (「それらの」原因) である。

```
Yassa pāraṃ apāraṃ vā, pārāpāraṃ na vijjati;
Vītaddaraṃ visaṃyuttaṃ, tamahaṃ brūmi brāhmaṇaṃ.
```

ダンマパダ 385。`yassa` は属格 (「その人には」ない)、`taṃ` は対格 (`brūmi` の目的語) である。

`yena … tena` で格がそろうのは、両方の節で同じ「〜の方に」という副詞の働きをするからである。これは副詞的な相関の組に共通する。

- `yattha … tattha` (〜の所に、そこに)
- `yadā … tadā` (〜の時に、その時に)
- `yathā … tathā` (〜のように、そのように)
- `yato … tato` (〜から、そこから)

この原則から見ると、`yena … tad` は不規則な形ではない。`yena` は関係節の中で「〜の方に」(具格)、`tad` は主節の中で `avasari` の行き先 (対格) と、それぞれの節の働きに従っている。註釈書の `taṃ avasari` という読み方は、この普通の関係構文としての理解に当たる。

## 確認できていない範囲

- 用例の検索は CSCD の本文 (mūla) を正規表現で引いたもので、`yena` と相関詞の間が 5 語程度までの散文を対象にした。語が長く離れた文や、偈のように語順が崩れた文は拾えていない可能性がある
- `yena` を伴わない `tenupasaṅkam-` の検索は、文頭から `tenupasaṅkam-` までに `yen-` で始まる語がないことを条件にした複雑な正規表現によった。取りこぼしがある可能性が残る
- `tadavasar-` の件数 115 は段落 (XML の p 要素) の数であり、語の出現回数ではない
- `yena … tena` と組む動詞の表は、検索結果から拾ったもので、網羅を確かめていない
- `avasarati` と `osarati` を同じ動詞の別形として扱ってよいかは、DOP の相互参照によるもので、独自には検討していない
- サンスクリットや仏教混淆梵語の並行表現 (DOP が `avasarati` の項で挙げる BHS `avasāri` など) は照合していない
