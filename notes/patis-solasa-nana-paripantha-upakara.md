# 無礙解道 Soḷasañāṇaniddesa の「十六」と八障害・八助けの対

無礙解道 (Paṭisambhidāmagga) 出入息念論の第二節 Soḷasañāṇaniddesa (§153) は次の一文で始まる。

```
153. Imehi soḷasahi ākārehi uducittaṃ cittaṃ samuducitaṃ cittaṃ ekatte
santiṭṭhati, nīvaraṇehi visujjhati.
```

この「十六 (soḷasa)」が何を指すのか、直前の Gaṇanavāra (§152) との関係、八障害と八助けの対応、そしてこの組み合わせが仏典一般でどの程度使われるものかを扱う。

答えは次のとおり。

1. 「十六の行相」は §152 で数えられた「八つの障害についての智と八つの助けについての智」の合計十六を指す。同じ段落の末尾に出る soḷasavatthuka (十六事の出入息念定) とは別物である
2. Gaṇanavāra に「十六智」という語がないのは、そこでは八と八の二組として数えるだけで合算していないためである。二組を合わせて「十六」と呼ぶのは §153 と節の結尾が最初である
3. 八障害と八助けは五蓋に無明・不楽・不善法一般を足した八項と、それぞれの反対の法との対である。この「五蓋 + 無明 + 不楽」の八項とその対治七項は無礙解道が全体で繰り返す固有の定型で、四部ニカーヤの本文には出てこない。註釈文献は無礙解道を典拠としてこの定型を広く引用している
4. 五蓋の対治のうち出離・無瞋・光明想の三つは経典の語と同じで、不散乱と法決定の二つは経典の内容を論蔵風の術語に言い換えたものである

## 「Imehi soḷasahi ākārehi」の十六は何か

原文の文脈と註釈の説明が一致して、八障害智と八助智の合計十六を指す。

原文側では、直前の §152 (Gaṇanavāra) が「Katamāni aṭṭha paripanthe ñāṇāni, aṭṭha ca upakāre ñāṇāni?」と問い、十六項を列挙したのち、次の一文で締めている。

```
Imāni aṭṭha paripanthe ñāṇāni, aṭṭha ca upakāre ñāṇāni.
Gaṇanavāro paṭhamo.
```

§153 冒頭の imehi (これらの) はこの直前の十六を受けている。節の名前 Soḷasañāṇaniddesa (十六智の解説) と結尾の「Soḷasañāṇaniddeso dutiyo」も同じ十六を指す。出入息念論の論母 (mātikā、§152 冒頭) では「aṭṭha paripanthe ñāṇāni, aṭṭha ca upakāre ñāṇāni」が二百余りの智の最初の二項として挙がり、この節はその詳説にあたる。

註 (Saddhammappakāsinī) は次のように言い換える。

```
Soḷasahi ākārehīti ubhayapakkhavasena vuttehi soḷasahi ñāṇakoṭṭhāsehi.
```

「両方の側面 (ubhayapakkha) によって説かれた十六の智の区分 (ñāṇakoṭṭhāsa) によって」の意で、両側面とは障害 (paripantha) と助け (upakāra) の二側面である。註は事 (vatthu) ではなく智の数として読んでおり、soḷasavatthuka には触れていない。

### soḷasavatthuka との区別

同じ §153 の末尾には別の「十六」が出る。

```
Imehi ca pana nīvaraṇehi visuddhacittassa soḷasavatthukaṃ
ānāpānassatisamādhiṃ bhāvayato khaṇikasamodhānā.
```

こちらの soḷasavatthuka は出入息念定の対象となる十六事 (四念処各四の十六段階) で、註は Gaṇanavāravaṇṇanā で「imesaṃ catunnaṃ catukkānaṃ vasena soḷasa vatthūni patiṭṭhā ārammaṇāni assāti soḷasavatthuko」と説明する。同じ段落に「十六」が二度出るため、冒頭の soḷasahi ākārehi を十六事と読みたくなるが、註の言い換えと imehi の指示対象から見て智の数である。

なお ākāra を「行相」と訳すと十六勝行 (soḷasa ākārā) を連想しやすいが、ここでは「十六の項目・観点によって」程度の意味で、註の言い換えどおり「十六の智の区分によって」と取るのが安全である。

## Gaṇanavāra に「十六智」の語がない理由

Gaṇanavāra は十六を八と八の二組として数えるだけで、合算した数を言わないためである。

§152 で soḷasa が出るのは soḷasavatthuka の一語だけで、智の数としては「aṭṭha paripanthe ñāṇāni, aṭṭha ca upakāre ñāṇāni」としか言わない。二組を合わせて「十六」と呼ぶのは §153 冒頭の soḷasahi ākārehi と結尾の Soḷasañāṇaniddeso dutiyo が最初で、註がそれを ubhayapakkhavasena (両側面によって) と説明するのも、障害側の八と助け側の八を合算した数だからである。

内容の面でも、§152 にはすでに十六の中身が列挙されており、§153 はその同じ十六を ekatta (一性)、nīvaraṇa (蓋)、niyyāna (出離) の三つの観点から展開したものである。註の冒頭が本文の構成を ñāṇagaṇanuddesa、ñāṇagaṇananiddesa、vitthāraniddesa、nigamana と区分する際にも soḷasañāṇa という語は使っていない。「十六智」は節の呼び名として二組をまとめて言う便宜的な数と見てよい。

## 八障害と八助けの対応

§152 は障害と助けを一文ずつ対にして並べる。各行は「その障害を除く反対の法」が助けになる構成である。

| # | paripantha (障害) | upakāra (助け) | 対応関係 |
|---|---|---|---|
| 1 | kāmacchanda (欲貪) | nekkhamma (出離) | 欲を離れること |
| 2 | byāpāda (瞋恚) | abyāpāda (無瞋恚) | a- による直接の否定 |
| 3 | thinamiddha (惛沈睡眠) | ālokasaññā (光明想) | 沈滞・眠気を光明の想で払う |
| 4 | uddhacca (掉挙) | avikkhepa (不散乱) | 散乱の否定 |
| 5 | vicikicchā (疑) | dhammavavatthāna (法の確定) | 疑いを法の区別・確定で除く |
| 6 | avijjā (無明) | ñāṇa (智) | 無知に対する知 |
| 7 | arati (不楽) | pāmojja (喜悦) | 修行を楽しめない状態に対する喜び |
| 8 | sabbepi akusalā dhammā (すべての不善法) | sabbepi kusalā dhammā (すべての善法) | 総括の対 |

構成についての補足。

- 1 から 5 は五蓋の順序である。4 は本文では uddhacca のみで kukkucca を含まない。§153 の nīvaraṇa の列挙では uddhaccakukkucca と合わせた形になる
- 6 と 7 は五蓋の外で、無明と不楽を加えて七項、8 で不善法全体に広げて締めている。註は §153 で「aratipi sabbepi akusalā āvaraṇaṭṭhena nīvaraṇāti vuttā」と断っており、五蓋に arati と不善法一般を含めるのが通常の用法からの拡張であることを註自身が意識している
- 対応の型は二種類ある。2 と 4 は a- による直接の否定 (byāpāda / abyāpāda、vikkhepa / avikkhepa) で、それ以外は反対の性質をもつ別の法である
- 助け側の八項は §153 でそのまま ekatta として再掲され (nekkhammaṃ ekattaṃ ... sabbepi kusalā dhammā ekattā)、障害側の八項は nīvaraṇa として再掲される。さらに niyyāna の段では「Nekkhammaṃ ariyānaṃ niyyānaṃ. ... Kāmacchando niyyānāvaraṇaṃ」の形で、表の各行がそのまま「出離と、それを覆うもの」の対として繰り返される

## この組み合わせは仏典で一般的か

五蓋そのものは経蔵全体で頻出だが、「五蓋 + 無明 + 不楽 (+ 不善法一般)」の八項とその対治「出離・無瞋・光明想・不散乱・法決定・智・喜」の組み合わせは無礙解道に固有の定型で、CSCD の全文検索では四部ニカーヤの本文に見つからない。

### 無礙解道内での出現

この七対は無礙解道の全体を貫く定型で、次のような箇所で繰り返し使われる (dhammavavatthānaṃ と ālokasaññā を手がかりに CSCD を検索した結果)。

- Ñāṇakathā の abhiññeyya (§18)、pariññeyya (§22)、bhāvanā (§28)、sīla (§41「abyāpādena byāpādaṃ saṃvaraṭṭhena sīlaṃ」)、ānantarikasamādhi (§80)、pahāna (§86-87「nekkhammena kāmacchandaṃ sammā samucchindati」)
- ekatta / nānatta (「kāmacchando nānattaṃ, nekkhammaṃ ekattaṃ」)、sallekha / asallekha、samathabala、bhāvanābala、khantibala、bojjhaṅga、iddhi、jhāna (「kāmacchandaṃ jhāpetīti jhānaṃ」)
- 出入息念論の paripantha / upakāra、ekatta、nīvaraṇa、niyyāna (本ノートの対象)

多くの箇所で、この七項の後に「paṭhamena jhānena nīvaraṇe ... dutiyena jhānena vitakkavicāre」(§41、§87 など) と四禅・四無色・観・四道が続き、修行の段階を出離から阿羅漢道まで一列に並べるリストの冒頭部を成している。

註 (§18 の Ñāṇakathā の説明) はこの七項を近行禅の段階のものとし、一つずつ対治として説明する。

```
Nekkhammādīni satta vissajjanāni upacārajjhānavasena niddiṭṭhāni.
Nekkhammanti kāmacchandassa paṭipakkho alobho. Ālokasaññāti thinamiddhassa
paṭipakkhe ālokanimitte saññā. Avikkhepoti uddhaccassa paṭipakkho samādhi.
Dhammavavatthānanti vicikicchāya paṭipakkhaṃ ñāṇaṃ. Ñāṇanti avijjāya
paṭipakkhaṃ ñāṇaṃ. Pāmojjanti aratipaṭipakkhā pīti.
```

五蓋を近行段階の障害、禅支を安止段階の獲得と分けるための枠組みなので、無明と不楽 (修行を楽しめない気持ち) が近行段階の障害として追加されていると読める。これは註の解釈であり、無礙解道本文は七項を近行段階とは明言していない。

### 無礙解道の外での出現

本文 (mūla) としては無礙解道以外に見つからなかった。論蔵の Dhammasaṅgaṇī に avikkhepa は多数出るが、定の同義語としてであり、この対のリストではない。

一方で註釈文献はこの定型を無礙解道から引いて広く使っている。

- 長部・中部・増支部・Udāna の註: Tathāgata の語義説明「nekkhammena kāmacchandaṃ pahāya gato, abyāpādena byāpādaṃ, ālokasaññāya thinamiddhaṃ, avikkhepena uddhaccakukkuccaṃ, dhammavavatthānena vicikicchaṃ pahāya ...」
- 相応部大品・増支部五集の註: 五蓋の nissaraṇa の説明で「vicikicchāya dhammavavatthānaṃ vikkhambhananissaraṇaṃ」など、各蓋の鎮伏出離としてこの七項を当てる
- 清浄道論: 戒の説明 (pahānasīla) の「nekkhammena kāmacchandassa, abyāpādena byāpādassa, ālokasaññāya thinamiddhassa, avikkhepena uddhaccassa, dhammavavatthānena vicikicchāya, ñāṇena avijjāya, pāmojjena aratiyā」と、samathabala の引用。前者は「vuttaṃ hetaṃ paṭisambhidāyaṃ」(PTS 版の読み) と断って無礙解道の五種戒の文 (§41 末尾) を引いたもので、清浄道論自身の記述ではない
- Vibhaṅga 註: 無礙解道 §113 (根上下智の kāmagaruka / nekkhammagaruka の箇所) を「paṭi. ma. 1.113」と出典を明示して引用
- 長部 Pāthikavagga 註と増支部 Dukanipāta 註: 「kāmacchandaṃ pajahanto ramati, abyāpādaṃ byāpādaṃ ...」の形での引用

まとめると、「五蓋 + 無明 + 不楽 + 不善法一般」の八項は無礙解道が作った近行段階の障害リストで、後代の註釈家が五蓋の対治を語るときに無礙解道を典拠として定型化したもの、という位置づけになる。

## 五蓋の対治は経典と同じか

五蓋の側は経典と同じだが、対治の側は経典の定型と一致するものと無礙解道独自の語がある。

経典で五蓋の対治を語る定型は主に二つある。沙門果経などの捨断定型 (DN 2 §217、Vibhaṅga §508 にも同文) と、相応部覚支相応 Āhārasutta (SN 46.51) の「非食 (anāhāra)」の列挙である。無礙解道の八助けと並べると次のようになる。

| 蓋 | 沙門果経の捨断定型 | SN 46.51 の非食 | 無礙解道の助け |
|---|---|---|---|
| kāmacchanda (定型では abhijjhā) | vigatābhijjhena cetasā | asubhanimitta (不浄相) | nekkhamma |
| byāpāda | abyāpannacitto, sabbapāṇabhūtahitānukampī | mettācetovimutti (慈心解脱) | abyāpāda |
| thinamiddha | vigatathinamiddho ālokasaññī sato sampajāno | ārambhadhātu, nikkamadhātu, parakkamadhātu | ālokasaññā |
| uddhaccakukkucca | anuddhato ajjhattaṃ vūpasantacitto | cetaso vūpasama (心の寂止) | avikkhepa (uddhacca のみ) |
| vicikicchā | tiṇṇavicikiccho akathaṃkathī kusalesu dhammesu | kusalākusalā dhammā sāvajjānavajjā ... への yoniso manasikāra | dhammavavatthāna |

項目ごとの評価。

- **abyāpāda と ālokasaññā は経典と同語**である。沙門果経定型の abyāpannacitta と ālokasaññī がそのまま名詞化されている。復註が abyāpāda を mettā と説明するのは SN 46.51 の mettācetovimutti と重なる
- **nekkhamma は語としては経典に対応がある**。沙門果経定型では「貪欲を離れる」としか言わず、SN 46.51 は不浄相を挙げるが、「kāmānametaṃ nissaraṇaṃ yadidaṃ nekkhammaṃ」(DN 33 の三出離界、無礙解道 §24 にも引用) や、DN 33 と AN 5.200 の出離界で kāma に nekkhamma、byāpāda に abyāpāda を当てる箇所、「tayo kusalavitakkā – nekkhammavitakko, abyāpādavitakko, avihiṃsāvitakko」(DN 33) のように、欲と出離を対にする用法は経典に根拠がある
- **avikkhepa は無礙解道と論蔵の語**である。経典は vūpasantacitta、cetaso vūpasama と言い、avikkhepa は Dhammasaṅgaṇī で samādhi の同義語群 (cittassa ṭhiti saṇṭhiti avaṭṭhiti avisāhāro avikkhepo ...) の一つとして使われる。復註も「Avikkhepenāti samādhinā」と言い換える。内容は同じで語が論蔵系に置き換わったと見られる。無礙解道は kukkucca を外して uddhacca のみを対にする
- **dhammavavatthāna は無礙解道の語**で、経典本文には出ない。内容的には沙門果経の「akathaṃkathī kusalesu dhammesu (善法について疑いがない)」と SN 46.51 の「善不善・有罪無罪の法への如理作意」に対応し、法を善不善などに区別して確定することを一語にしたものである。復註は「Dhammavavatthānenāti kusalādidhammānaṃ yāthāvanicchayena」(善などの法をありのままに決定することによって) と説明し、別説として「sappaccayanāmarūpavavatthānenātipi vadanti」(縁とともに名色を確定することによって、とも言う) を他師の説として添える。この文言は Tathāgata の語義説明に対する中部・増支部の復註 (Mūlapaṇṇāsa-ṭīkā、Ekakanipāta-ṭīkā) と長部 Sīlakkhandhavagga 新復註の形で、清浄道論大復註は sapaccaya-、長部 Sīlakkhandhavagga 復註は yāthāvavinicchayena と読む

まとめると、五つのうち三つ (nekkhamma、abyāpāda、ālokasaññā) は経典の語をそのまま使い、二つ (avikkhepa、dhammavavatthāna) は経典の内容を論蔵風の術語に言い換えたものである。経典の対治が「不浄相・慈・精進・寂止・如理作意」のように修習法を挙げるのに対し、無礙解道は蓋の反対の心の状態を名詞で並べるという性格の違いもある。

## 未確認の範囲

- 「無礙解道以外の本文に出ない」は CSCD の全文検索で dhammavavatthānaṃ、ālokasaññā (経蔵本文)、kāmacchandaṃ pajahanto nekkhammaṃ を検索した範囲での結果である。nekkhamma と abyāpāda が近接する本文を検索しても、無礙解道と清浄道論以外に出るのは nekkhamma・abyāpāda・avihiṃsā の三尋・三想・三界の形だけで、Vibhaṅga や Niddesa に七項の対は見つからなかった。ただし別の語形で現れる可能性までは網羅していない
- 註釈文献での出現は検索で見つかった範囲を挙げたもので、全件を数え上げてはいない
