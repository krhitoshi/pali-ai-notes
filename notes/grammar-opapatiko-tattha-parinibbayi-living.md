# opapātiko tattha parinibbāyī anāvattidhammo — 生きている人になぜ opapātiko と言うのか

MN 81 Ghaṭikārasutta で、カッサパ世尊はキキー王に陶工ガティカーラの徳を並べ、最後にこう言う (VRI 段落 288)。

```
Ghaṭikāro kho, mahārāja, kumbhakāro pañcannaṃ orambhāgiyānaṃ saṃyojanānaṃ parikkhayā opapātiko tattha parinibbāyī anāvattidhammo tasmā lokā.
```

このときガティカーラはヴェーガリンガで生きて暮らしている。それなのに opapātiko (化生の者) と言うのは、いま化生であるという意味なのか、不還果だというだけのことなのか、将来は化生となるということなのか。これがこのノートの疑問である。

答えは次のとおり。

- この句は不還の人を言い表す定型句で、生きている人にも亡くなった人にも同じ形で使われる。ガティカーラがいま化生の者だという意味ではない
- 句の中身は「(この生を終えたあと) 化生し、そこで完全に涅槃し、その世界から戻らない」という先の行き先である。つまり「不還果だということ」と「将来は化生となるということ」は別々の読みではなく、後者の内容によって前者を言い表している
- そう読めるのは、三つの述語がどれも時を示さない名詞・形容詞で、「そうなる定まりの者」を表すからである。これは原文の文法と註釈書の言い換えにもとづく

訳は次のようになる。

> 大王よ、陶工ガティカーラは、五つの下位の束縛が尽きたことによって、化生する者であり、そこで完全に涅槃する者であり、その世界から戻ってこない性質の者です。

## opapātiko、tattha parinibbāyī、anāvattidhammo は時を示さない

この節は原文の文法の分析で、語義は辞書、-in の規則は文法書 Kaccāyana による。接尾辞の働きについての説明は推論を含む。

この文には定動詞がない。文を切り分けると次のようになる。

```
Ghaṭikāro kho, mahārāja, kumbhakāro                  主語
pañcannaṃ orambhāgiyānaṃ saṃyojanānaṃ parikkhayā     理由 (奪格)
opapātiko                                            述語 1
tattha parinibbāyī                                   述語 2
anāvattidhammo tasmā lokā                            述語 3
```

主語「陶工ガティカーラは」に対して、述語 1 から 3 が「…である」の位置に並ぶ。

MN 81 のこの箇所は `Ghaṭikāro kho, mahārāja, kumbhakāro …` で始まる文が続くところで、`saraṇaṃ gato`、`paṭivirato`、`samannāgato`、`nikkaṅkho`、`mātāpitaro poseti` などガティカーラのいまの徳を述べる文の最後にこの文が置かれている。したがって文全体としては、いまのガティカーラがどういう人であるかを述べている。ただし述語 1 から 3 の中身は、いまの状態ではなく先の行き先である。

1. opapātiko は upapāta に -ika の付いた派生語で、DoP は "arising spontaneously; (one) being reborn without parents" とする。生まれ方の種類を言う語である
2. tattha parinibbāyī の parinibbāyī は -in で終わる語で、DoP は tatthaparinibbāyi(n) をひとまとまりの語として立て、"who realises nibbāna there, in that state" とする。tattha (そこで) は、opapātiko が含む生まれ先を指す
3. anāvattidhammo は anāvatti (戻らないこと) と dhamma の複合語で、DoP は "not subject to return (to this world, see anāgāmi[n])" とする。`tasmā lokā` (その世界から) が続くので、戻らないというのは生まれ先の世界から戻らないことである

1 の opapātiko が言う生まれ方について、MN 12 Mahāsīhanādasutta (VRI 段落 152) は四つの生まれ方 (yoni) を数え、その一つをこう説明する。

```
Katamā ca, sāriputta, opapātikā yoni? Devā, nerayikā, ekacce ca manussā, ekacce ca vinipātikā – ayaṃ vuccati, sāriputta, opapātikā yoni.
```

述語 2 と 3 は、述語 1 の opapātiko が言う生まれ先を tattha と tasmā lokā で受けている。三語はひと続きで「化生する、そこで涅槃する、そこから戻らない」という経過を述べており、opapātiko だけを切り離して「いま化生である」と読むことはできない。

-in や -dhamma の形が「いま…している者」ではなく「…することになる者」「…する性質の者」を表すという点は、次の節の註釈書の言い換えから推したものである。

-in の形については、文法書 Kaccāyana に、先のことを言うときに語根に ṇī (-in で終わる語を作る接尾辞) を付けるという規則がある (651 `Bhavissati gamādīhi ṇī ghiṇa`)。Kaccāyana はこの規則を次のように説明する。

```
Bhavissatikālatthe gamu bhaja su ṭhāiccevamādīhi dhātūhi ṇī ghiṇa paccayā honti.

Āyatiṃ gamituṃ sīlaṃ yassa, so hotīti gāmī, āyatiṃ bhajituṃ sīlaṃ yassa, so hotīti bhājī, āyatiṃ passāpituṃ sīlaṃ yassa, so hotīti passāvi, āyatiṃ paṭṭhāyituṃ sīlaṃ yassa, so hotīti paṭṭhāyi.
```

「将来行くことを習いとする者、それが gāmī である」という説明で、-in の形が先のことを表しうることは文法書でも確かめられる。ただし挙げられている語は gāmī、bhājī、passāvi、paṭṭhāyi で、parinibbāyī はない。parinibbāyī がこの規則による語かどうかは Kaccāyana には書かれておらず、この規則を当てるのは推論である。-dhamma の形については、文法書の規定では確かめていない。

## 註釈書の言い換え

この節は註釈書の説明である。MN 81 の註釈書と復註はこの句を説明していないので、同じ定型句が出る他の経への註釈を当てる。

MN 6 Ākaṅkheyyasutta への Papañcasūdanī は次のように説明する。

```
Opapātikoti sesayonipaṭikkhepavacanametaṃ. Tatthaparinibbāyīti tattheva brahmaloke parinibbāyī. Anāvattidhammo tasmā lokāti tato brahmalokā paṭisandhivasena puna anāvattisabhāvo.
```

opapātiko は「残りの生まれ方を退ける語」である。つまり胎生などではなく化生で生まれるという、生まれ方の限定を言う。tattha は「まさにその梵天界で」、anāvattidhammo は「その梵天界から結生によって再び戻らない性質の者」である。

DN 6 Mahālisutta への Sumaṅgalavilāsinī (VRI 段落 373 への註) は、同じ説明を少し違う言葉でしている。

```
Opapātikoti sesayonipaṭikkhepavacanametaṃ. Tattha parinibbāyīti tasmiṃ uparibhaveyeva parinibbānadhammo. Anāvattidhammoti tato brahmalokā puna paṭisandhivasena anāvattanadhammo.
```

ここでは parinibbāyī が `parinibbānadhammo` (涅槃する性質の者) と言い換えられている。-in の形を -dhamma で言い換えているので、註釈書は parinibbāyī を「いま涅槃している者」ではなく「涅槃することが定まっている者」と読んでいることになる。

AN Tikanipāta の Paṭhamasikkhāsutta (VRI 段落 87) への Manorathapūraṇī は、opapātiko の説明だけが違う。

```
Opapātiko hotīti uppannako hoti. Tattha parinibbāyīti heṭṭhā anotaritvā upariyeva parinibbānadhammo. Anāvattidhammoti yonigativasena anāgamanadhammo.
```

`uppannako hoti` は「生じた者となる」と読め、句を生まれたあとの経過として言い直しているように見える (この読みは推論である)。この箇所への復註は opapātiko を次のように説明し、他の註釈書と同じ「残りの生まれ方を退ける語」に戻したうえで、その意図を胎に宿る苦がないことだとする。

```
Opapātikoti upapātikayoniko upapatane sādhukārī. Sesayonipaṭikkhepavacanametaṃ. Tena gabbhavāsadukkhābhāvamāha.
```

どの註釈も、句を梵天界に生まれてからのこととして説明しており、いまの身体のあり方として説明するものはない。

## 生きている人への用例

この節は原文の用例である。

同じ定型句は、生きている人について繰り返し使われる。

MN 118 Ānāpānassatisutta (VRI 段落 147) は、いま目の前にいる比丘サンガの中にこういう比丘がいると言う。

```
Santi, bhikkhave, bhikkhū imasmiṃ bhikkhusaṅghe pañcannaṃ orambhāgiyānaṃ saṃyojanānaṃ parikkhayā opapātikā tattha parinibbāyino anāvattidhammā tasmā lokā
```

MN 73 Mahāvacchasutta では、ヴァッチャゴッタが在家で梵行を守る優婆塞について尋ねる。

```
Atthi pana bhoto gotamassa ekupāsakopi sāvako gihī odātavasano brahmacārī yo pañcannaṃ orambhāgiyānaṃ saṃyojanānaṃ parikkhayā opapātiko tattha parinibbāyī anāvattidhammo tasmā lokā
```

白衣を着た在家の梵行者という言い方は、MN 81 が述べるガティカーラ (`ekabhattiko brahmacārī`) と重なる。

MN 34 Cūḷagopālakasutta (VRI 段落 352) は、阿羅漢については過去の形で「渡り終えた」と言い、この定型句で呼ばれる比丘たちについては未来形で「渡るだろう」と言う。

```
ye te bhikkhū arahanto khīṇāsavā … te tiriyaṃ mārassa sotaṃ chetvā sotthinā pāraṃ gatā.

ye te bhikkhū pañcannaṃ orambhāgiyānaṃ saṃyojanānaṃ parikkhayā opapātikā tattha parinibbāyino anāvattidhammā tasmā lokā, tepi tiriyaṃ mārassa sotaṃ chetvā sotthinā pāraṃ gamissanti.
```

定型句で呼ばれる人たちがまだ道の途中にあり、句の中身がこれから先のことであることが、動詞の時制の対比に表れている。

MN 6 Ākaṅkheyyasutta では、比丘が自分について願う形で使われる。

```
Ākaṅkheyya ce, bhikkhave, bhikkhu – ‘pañcannaṃ orambhāgiyānaṃ saṃyojanānaṃ parikkhayā opapātiko assaṃ tattha parinibbāyī anāvattidhammo tasmā lokā’ti
```

`opapātiko assaṃ` は「私が化生の者であればよい」で、生きている比丘が自分を主語にして言う。願っているのはいま化生の身になることではなく、不還の者になることである。

## 亡くなった人への用例と hoti を伴う形

この節も原文の用例である。

同じ句は、亡くなった人の行き先の説明にも使われる。DN 16 Mahāparinibbānasutta (VRI 段落 157) のナンダー比丘尼、MN 68 Naḷakapānasutta (VRI 段落 171 など) の `itthannāmo … kālaṅkato; so bhagavatā byākato` に続く形、MN 140 Dhātuvibhaṅgasutta のプックサーティがその例である。プックサーティについて、Papañcasūdanī は牛に突かれて亡くなったあと `avihābrahmaloke nibbatti, nibbattamattova arahattaṃ pāpuṇi` (アヴィハー梵天界に生まれ、生まれてすぐ阿羅漢果に達した) と語る。

生きている人にも亡くなった人にも同じ形が使えるのは、句が時を示さず、その人の定まりを述べているからである。亡くなった人について言えば、その定まりのとおりになったことを言うことになる。

定動詞 hoti を伴う形もある。MN 52 Aṭṭhakanāgarasutta (VRI 段落 19) は次のように言う。

```
No ce āsavānaṃ khayaṃ pāpuṇāti, teneva dhammarāgena tāya dhammanandiyā pañcannaṃ orambhāgiyānaṃ saṃyojanānaṃ parikkhayā opapātiko hoti tattha parinibbāyī anāvattidhammo tasmā lokā.
```

Puggalapaññatti も `Idhekacco puggalo … opapātiko hoti tattha parinibbāyī anāvattidhammo tasmā lokā` という形で人の類型を定義する。hoti があっても、述べているのは「そういう者になる」という一般的な帰結で、いつ化生するかを示すものではない。

## ガティカーラのその後

この節は原文と註釈書の記述である。

SN 2.24 Ghaṭīkārasutta (VRI 段落 105) では、ガティカーラは天子 (`ghaṭīkāro devaputto`) としてゴータマ世尊の前に現れる。同じ偈は SN 1.50 Ghaṭīkārasutta (VRI 段落 50) にもある。偈の中で、彼は自分の前世をこう語る。

```
Kumbhakāro pure āsiṃ, vekaḷiṅge ghaṭīkaro;
Mātāpettibharo āsiṃ, kassapassa upāsako.

Virato methunā dhammā, brahmacārī nirāmiso;
```

SN 1.50 への Sāratthappakāsinī は `brahmacārī nirāmiso` を `nirāmisabrahmacārī nāma anāgāmī, anāgāmī ahosinti attho` (私は不還者であった、という意味である) と説明する。

天は MN 12 が言う化生の生まれ方に入るので、天子として現れるガティカーラは、カッサパ世尊が述べた opapātiko のとおりになっている。

この偈が「アヴィハーに生まれた」(`Avihaṃ upapannāse`) と言っているのは、ウパカ、プックサーティなど 7 人の比丘のことである。ガティカーラ自身がどの世界に生まれたかは、偈にも、ここで読んだ Sāratthappakāsinī の説明にも書かれていない。

他の註釈書はガティカーラを大梵天と呼ぶ。Jātaka-aṭṭhakathā の Nidānakathā は、出家した菩薩に沙門の持ち物を届ける者を次のように言う。

```
Athassa kassapabuddhakāle purāṇasahāyako ghaṭīkāramahābrahmā
```

「カッサパ仏の時代の昔の友である大梵天ガティカーラ」である。註釈書が定型句の tattha を梵天界と説明していたことと合う。

## 確認できていない範囲

- MN 81 のこの句を直接説明する註釈は、Papañcasūdanī と復註の VRI 段落 288 への註にはない。このノートの註釈書の説明は、MN 6、DN 6、AN Tikanipāta の同じ定型句への註釈を当てたものである
- -in や -dhamma の形が「…することになる者」「…する性質の者」を表すという点は、註釈書の言い換えからの推論である。-in の形が先のことを表しうることは Kaccāyana 651 で確かめたが、parinibbāyī がその規則による語かどうかは書かれていない。-dhamma の形については文法書の規定では確かめていない
- Manorathapūraṇī の `uppannako hoti` を「生じた者となる」と読んだのは推論である。uppannaka は DoP、CPD、PTSD のどれにも見出し語として見つからず、語義を辞書で確かめていない
- ガティカーラが梵天界のうちのどの世界に生まれたかは確かめていない。SN の偈と Sāratthappakāsinī の該当箇所には書かれていない。CSCD の全文で ghaṭīkāra (ghaṭikāra) の前後 300 字以内に suddhāvāsa、avihā、akaniṭṭha のいずれかが出る箇所を検索したが、見つからなかった
- 生きている人への用例と亡くなった人への用例は、定型句を MN、DN、論蔵の本文で検索して目についたものを挙げたもので、全用例を数えたものではない
