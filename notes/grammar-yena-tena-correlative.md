# yena … tena をどう読むか — `yena bhagavā tenupasaṅkami` との異同と「処格の意味の具格」という説明

Paṭisambhidāmagga の Ānāpānassatikathā で `anuṭṭhitā` を説明する一文
`yena yena cittaṃ abhinīharati tena tena sati anuparivattati` は、
`yena bhagavā tenupasaṅkami` (世尊のおられるところへ近づいた) と同じ型と
見てよい。註釈書自身が両者を並べて説明している。

一方、この型を「処格の意味で用いられた具格」(`bhummatthe karaṇavacanaṃ`)
と説明する点には留保が要る。これは註釈家の分析であって、格の交替が起きて
いることの証明ではない。註釈書もこれを唯一の解とはしておらず、具格のまま
方向を表すものとして読む解を先に置く註もある。

意味は「心をどこへ向けても、そのそれぞれについて」という配分の表現になる。

## 当該箇所

Paṭisambhidāmagga、Ānāpānassatikathā、VRI 段落番号 160。PTS 版では
Paṭis I 172-173。`bhāvitā bahulīkatā yānīkatā vatthukatā anuṭṭhitā
paricitā susamāraddhā` の各語を順に説明していく段のうち、`anuṭṭhitā` の
語釈にあたる。

```
Anuṭṭhitāti vatthusmiṃ yena yena cittaṃ abhinīharati tena tena sati
anuparivattati. Yena yena vā pana sati anuparivattati tena tena cittaṃ
abhinīharati. Tena vuccati – ‘‘anuṭṭhitā’’ti.
```

日本語訳の例:

> 「『付き従い立った』とは、対象について、どこへ心を向けるのであれ、その
> それぞれに念が付き従って回る。また、どこへ念が付き従って回るのであれ、
> そのそれぞれに心を向ける。それゆえ『付き従い立った』と言われる。」

直前の `vatthukatā` の語釈は同じ内容を処格の相関 `yasmiṃ yasmiṃ
vatthusmiṃ … tasmiṃ tasmiṃ vatthusmiṃ` で書いている。同一段落の中で処格の
相関と具格の相関が並んでいることになる。処格の側の検討は
[grammar-ya-ta-correlative-locative.md](grammar-ya-ta-correlative-locative.md)
にある。

## 註釈書は両者を同じ構文として扱っている

Paṭisambhidāmagga-aṭṭhakathā (Saddhammappakāsinī) はこの箇所を次のように
説明する。

```
Yena yena cittaṃ abhinīharatīti pubbappavattito apanetvā yattha yattha
bhāvanāvisese cittaṃ upaneti. Tena tena sati anuparivattatīti tasmiṃ
tasmiṃyeva bhāvanāvisese sati anukūlā hutvā pubbappavattito nivattitvā
pavattati. ‘‘Yena, tenā’’ti cettha ‘‘yena bhagavā tenupasaṅkamī’’tiādīsu
(khu. pā. 5.1; su. ni. maṅgalasutta) viya bhummattho veditabbo.
```

「ここでの『yena, tena』は、『yena bhagavā tenupasaṅkami』等における
のと同様に、処格の意味と理解すべきである」。註釈書がこの二つを明示的に
結びつけている。

同時に、註は `yena yena` を `yattha yattha bhāvanāvisese` (どの修習の
局面においてであれ)、`tena tena` を `tasmiṃ tasmiṃyeva bhāvanāvisese` と
処格で受け直している。指しているのは方角ではなく修習の局面である。

段末では `anuṭṭhitā` の語形を次のように押さえる。

```
Tena vuccati anuṭṭhitāti evaṃ karaṇatoyeva taṃ taṃ bhāvanaṃ anugantvā
ṭhitā hontīti vuttaṃ hoti.
```

`anu` + `ṭhitā` を「その都度の修習に付き従って立っている」と読んでいる。

さらに註は、この段の `vatthukatā` と `anuṭṭhitā` の二語について
`satiyā saha yojanā katā` (念と結びつけて構文が組まれている) と注意して
いる。安般念では念が主となる修習だからである。

## 「処格の意味」という説明の位置づけ

`yena bhagavā tenupasaṅkami` の型に対する註釈の定型句は、各部にほぼ同文
で現れる。Mūlapaṇṇāsa-aṭṭhakathā では次のとおり。

```
Yena bhagavā tenupasaṅkamīti yenāti bhummatthe karaṇavacanaṃ, tasmā
yattha bhagavā, tattha upasaṅkamīti evamettha attho daṭṭhabbo.
```

ここで注意が要るのは、註釈書がこれを唯一の解としていない点である。

Sīlakkhandhavaggaṭṭhakathā (Sumaṅgalavilāsinī) では、この説明は `vā` で
導かれる第二解であり、第一解は具格のまま読んでいる。

```
Yenāti yena disābhāgena, so upasaṅkamitabbo. Bhummatthe vā etaṃ
karaṇavacanaṃ, yasmiṃ padese so maṇḍalamāḷo, tattha gatoti ayamettha
attho.
```

Cūḷaniddesa-aṭṭhakathā も同じ順序で、方向の具格を先に置き `atha vā` で
処格の意味を挙げる。

```
Yena buddhoti yena disābhāgena buddho upasaṅkamitabbo, tena disābhāgena
na paleti. Atha vā bhummatthe karaṇavacanaṃ.
```

Mūlapaṇṇāsa-aṭṭhakathā などは、さらに原因の具格という第三の解を並べる。

```
Yena vā kāraṇena bhagavā devamanussehi upasaṅkamitabbo, tena kāraṇena
upasaṅkamīti evamettha attho daṭṭhabbo.
```

復註では分析がさらに割れる。Sīlakkhandhavaggaabhinavaṭīkā は `yena` と
`tena` に別々の格の意味を与える説を伝える。

```
Yenāti vā bhummatthe karaṇavacanaṃ. Tenāti pana upayogatthe.
```

`yena` は処格の意味だが `tena` は対格の意味だ、という非対称な分析であり、
`Tasmā tatthāti taṃ maṇḍalamāḷantipi vadanti` と `vadanti` で受けている
ので、註自身の断案ではなく他師の説として挙げられている。

つまり `bhummatthe karaṇavacanaṃ` は、伝統内で一致した唯一の分析では
ない。

## 「処格の意味」の根拠として出されているもの

註が根拠として示すのは言い換えの一致だけである。

- `yattha bhagavā, tattha upasaṅkami` という置き換え
- Theragāthā-aṭṭhakathā の `Tattha yena yenāti yattha yattha. Bhummatthe
  hi etaṃ karaṇavacanaṃ, yasmiṃ yasmiṃ disābhāgeti attho.`
- Paṭisambhidāmagga 内部で、同じ型の内容が `yasmiṃ yasmiṃ … tasmiṃ
  tasmiṃ` (処格) と `yena yena … tena tena` (具格) の両方で書かれている
  こと
- PTSD が `yena` を `yattha`、`yahiṃ` と同じ場所の副詞として扱うこと

これらは「意味が場所的である」ことの材料にはなるが、「本来処格であるべき
ところに具格が代用されている」ことの材料にはならない。意味が場所的で
あることと、格が入れ替わっていることは別の主張である。

## 具格のままでも説明はつく

方向や経路を表す副詞的な具格であれば、格の代用を持ち出さずに済む。註の
第一解 `yena disābhāgena` はまさにその読み方である。

二重形についても、Suttanipāta-aṭṭhakathā は具格のまま処理している。

```
Yenicchakaṃ gacchati gocarāyati yena yena disābhāgena gantumicchati,
tena tena disābhāgena gocarāya gacchati.
```

これは今回の Paṭisambhidāmagga の `yena yena … tena tena` と同型であり、
処格に読み替えずに説明できている例になる。

PTSD の `ya˚` の項も、`yena` を「副詞的に用いられる格」の下に置き、
`yena yena` を wherever、`yena … tena` を where (he was) — there (he went)
と説明する。あわせて `yattha yena yahiṃ` を whence, where, whither と訳し、
方向と場所が常には区別されないと注意している。格の代用としては記述して
いない。

註釈家が `bhummattha` を持ち出す動機も推測できる。`yena bhagavā tena` では
`bhagavā` が主格で置かれ、具格を受ける名詞が表面に出ていない。そこで
`disābhāgena` を補うか、さもなければ「処格の意味だ」と言い換えるかしか
ない。この説明は語の欠落を処理するための註釈上の手立てという面がある。

これは伝統の分析を退けるものではない。註がどこまでを述べ、どこからが
説明の便宜かを区別しておく、ということである。

## 二重形が表すもの

`yena yena` / `tena tena` のように相関詞を重ねるのは配分の表現で、「どれ
であれ、その一つ一つについて」を表す。PTSD は `ya˚` の項でこれを
generalizing (distributive) use として立て、`ya˚` を繰り返す形として次の
例を挙げる (niggahita は PTSD の表記のまま)。

```
yaŋ yaŋ passati taŋ taŋ pucchati
yassaŋ yassaŋ disāyaŋ viharati, sakasmiŋ yeva vijite viharati
```

Paṭisambhidāmagga の当該箇所を註が `yattha yattha bhāvanāvisese` /
`tasmiṃ tasmiṃyeva bhāvanāvisese` と受けているのも、この配分の読みに
沿っている。

## `yena bhagavā tena` と同じではない点

構文の型としては同じでよいが、次の点は違う。

| | `yena bhagavā ten' upasaṅkami` | `yena yena cittaṃ abhinīharati` |
| --- | --- | --- |
| `yena` が受ける語 | `bhagavā` (主格) | なし |
| 動詞の目的語 | なし (自動詞) | `cittaṃ` (対格) |
| 「場所」の中身 | 方角 (`disābhāga`) | 修習の局面 (`bhāvanāvisesa`) |
| 相関詞の重複 | なし | あり (配分) |

DPD は場所を表す `yena` を独立の副詞として立て、主格を伴う語
(`plus_case: +nom`) と記述する。`yena bhagavā tena` はこれに合うが、
`yena yena cittaṃ abhinīharati` には主格の名詞がなく、`cittaṃ` は動詞の
目的語である。したがって「同じ構文」と言えるのは、方向や場所を表す副詞的
具格の相関という型のレベルであって、`yena` + 主格 + `tena` + 移動動詞と
いう定型句そのものと同一ということではない。

## 確認できていない範囲

- サンスクリットや仏教混淆梵語における並行表現 (`yena bhagavāṃs
  tenopasaṃkrāntaḥ` の類) は今回照合していない。上の議論はパーリ語内部の
  資料だけに基づく
- DOP は m, y, r, l, ḷ, v, s, h の巻が未刊行、CPD は収録範囲が a-kh まで
  のため、`ya` / `yena` はどちらでも引けない。辞書の記述は PTSD と DPD に
  よる
- 相関詞を重ねない `yena … tena` が Paṭisambhidāmagga の他の箇所で
  どう使われているかは数え上げていない
