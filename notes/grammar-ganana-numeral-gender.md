# 数を数える言葉に出る数詞の性 (gaṇanā)

Visuddhimagga の安般念で息を数える箇所に、次の数詞の列がある。

```
… dvārappattaṃ dvārappattaṃyeva gahetvā ‘‘eko dve tīṇi cattāri pañca cha …’’ti
```

`eko` は男性形、`tīṇi` `cattāri` は中性形で、数えている息 (assāsapassāsa、
男性) と性が揃っていないように見える。

この列は、行者が数えながら口に出す言葉を引用符と `ti` (「…と」) で囲んだ
部分である。地の文の骨格は
`dvārappattaṃ dvārappattaṃyeva gahetvā … sīghaṃ sīghaṃ gaṇetabbameva`
(門 (鼻孔) に達したものを、達したものを取って … 速く速く数えるべきである)
で、`gahetvā` の目的語は `dvārappattaṃ dvārappattaṃyeva`。数詞は地の文の
どの名詞とも格・数で結びついていない。ただし、引用された発話の中で数えている物の名詞が省略
されている (`eko [assāsapassāso]`) と読むことはできる。Saddanīti は
牛飼いの喩えに `eko gāvī, dve gāvī` (一頭の牛、二頭の牛) と名詞を補って
おり、これは省略として処理する読み方である。

その上で列の中身は一様ではなく、

- `eko` — 数えている物に結びつけて読める形 (男性)
- `tīṇi` `cattāri` — 数を数として挙げるときの形 (中性)
- `dve`、`pañca` 以下 — 性による形の区別がなく、判定材料にならない

という混在になっている。パーリ語では、数を数として挙げるときは 1 も中性
`ekaṃ` で出る例があり (Pañcapakaraṇa-aṭṭhakathā。後述)、この列の `eko` は
それとは違う形である。

説明としては次の二つが立てられるが、どちらも列の一部にしか届かない。

- 名詞の省略と見る読み — `eko` が男性形であることは説明できる。ただし同じ
  名詞を補うなら 3・4 も男性形 `tayo cattāro` になる位置で、実際には
  `tīṇi cattāri` である点が残る
- 数を数として挙げる形と見る読み — `tīṇi` `cattāri` は説明できる。ただし
  それなら 1 も `ekaṃ` になる位置で、実際には `eko` である点が残る

`eko` についても、数えている物の性に合わせて選ばれた形なのか、数え始めの
言葉として `eko` の形で固まっていたのかは決めていない。雌牛を数える牛飼いの
喩えでも、伝承の多くは `eko` と伝えるためである (「伝承の異同」の節)。

## 当該箇所

同文が Visuddhimagga、Samantapāsādikā (Pārājikakaṇḍa-aṭṭhakathā)、
Paṭisambhidāmagga-aṭṭhakathā の三つに伝わる。安般念の gaṇanā の段で、遅い
数え方 (穀量りの喩え) と速い数え方 (牛飼いの喩え) が並んでいる。

速い数え方の適用 (Visuddhimagga):

```
Evamimassāpi purimanayena gaṇayato assāsapassāsā pākaṭā hutvā sīghaṃ sīghaṃ
punappunaṃ sañcaranti. Tato nena ‘‘punappunaṃ sañcarantī’’ti ñatvā anto ca
bahi ca agahetvā dvārappattaṃ dvārappattaṃyeva gahetvā ‘‘eko dve tīṇi
cattāri pañca cha. Eko dve tīṇi cattāri pañca cha satta…pe… aṭṭha, nava,
dasā’’ti …
```

Samantapāsādikā と Paṭisambhidāmagga-aṭṭhakathā は一巡目から
`‘‘eko dve tīṇi cattāri pañca, eko dve tīṇi cattāri pañca cha, …’’` と
繰り返す形で伝える。復註 (Visuddhimagga-mahāṭīkā、Sāratthadīpanī-ṭīkā) は
この列を `gaṇanāvidhidassanaṃ` (数え方の手順を示したもの) と注し、続けて
`Tasmā aṭṭhātiādīsupi ekato paṭṭhāyeva paccekaṃ aṭṭhādīni pāpetabbāni`
(八以降も毎回一から数え上げる) と補っている。

その喩えの側 (牛飼いが牛を数える):

```
… palighatthambhamatthake nisinno dvārappattaṃ dvārappattaṃyeva gāviṃ
ekā dveti sakkharaṃ khipitvā gaṇeti.   (Visuddhimagga)
```

遅い数え方 (穀量りの喩えとその適用、Visuddhimagga):

```
Dhaññamāpako hi nāḷiṃ pūretvā ‘‘eka’’nti vatvā okirati. Puna pūrento kiñci
kacavaraṃ disvā taṃ chaḍḍento ‘‘ekaṃ eka’’nti vadati. Esa nayo dve
dvetiādīsu. Evameva imināpi assāsapassāsesu yo upaṭṭhāti, taṃ gahetvā
‘‘ekaṃ eka’’nti ādiṃ katvā yāva ‘‘dasa dasā’’ti …
```

ここの `ekaṃ` は中性主格・対格とも男性対格とも同形で、どちらとも決められない。
直前が `taṃ gahetvā` (男性対格) であることから男性対格として読むこともできる。

## 性が読み取れるのは 1・3・4 だけ

- 1 … eko / ekā / ekaṃ と三性で形が分かれる
- 2 … dve は全性共通で、どの性を想定しているか判定できない
- 3 … tayo (男) / tisso (女) / tīṇi (中)
- 4 … cattāro (男) / catasso (女) / cattāri (中)
- 5 以上 (pañca, cha, satta, aṭṭha, nava, dasa) … 性による形の違いがない

つまり `eko dve tīṇi cattāri pañca cha satta aṭṭha nava dasa` の十語のうち、
性が読み取れるのは `eko` `tīṇi` `cattāri` の三語に限られる。そのうち一つが
男性、二つが中性という状態である。

## 修飾用法では性の区別が保たれている

数詞の性の区別そのものが崩れているわけではない。CSCD 全文を対象に文字列
検索を行うと、

- `dve tayo` … 230 件
- `dve tīṇi` … 134 件
- `cattāri dhammā` … 0 件

で、それぞれ先頭 20 件を目視した範囲では、`dve tayo` は男性名詞 (hetū,
āsavā, kilesā, javanavārā, nikāyā, janā, pahāre, pallaṅke ほか) とのみ、
`dve tīṇi` は中性名詞 (saṃyojanāni, nīvaraṇāni, phalacittāni, sikkhāpadāni,
ṭhānāni, buddhantarāni ほか) とのみ共起していた。全件を確認したわけでは
ないが、係り先がある場面では区別が働いていることは読み取れる。

数え上げの列でも、名詞に係る場合は男性形が並ぶ。Pañcapakaraṇa-aṭṭhakathā:

```
Samāsato panettha eko dve tayo cattāro pañca sattāti chaḷeva
paccayaparicchedā honti.
```

`paccayaparicchedā` (男性) に係るので `tayo cattāro` になっている。

## 数を数として挙げるときの形

数を数として引用する言い方では中性形が使われる。Pañcapakaraṇa-aṭṭhakathā:

```
Iminā nayena ‘‘ekaṃ dve tīṇi pañca satta navā’’ti āgataṭṭhānesu gaṇanā
veditabbā. ‘‘Cattāri cha aṭṭhā’’ti imā pana tisso gaṇanā …
```

「一・二・三・五・七・九と出てくる箇所では」という、数の名を挙げる用法で、
`ekaṃ` を含めて中性形になっている。安般念の段の復註が数そのものを
`aṭṭhādīni` と中性で受けるのも同じ扱いである。

Visuddhimagga の列の `tīṇi` `cattāri` は、この「数の名」の形と一致する。

## eko が結びつく語

速い数え方の適用文では、`gahetvā` の目的語が `dvārappattaṃ dvārappattaṃyeva`
(門に達したものを、達したものを) で、名詞そのものは省かれている。補われる
語は直前の文の主語 `assāsapassāsā` で、一つずつ取るので男性単数になる。同じ
段の遅い数え方が `assāsapassāsesu yo upaṭṭhāti, taṃ gahetvā` と男性単数の
関係代名詞で個々を受けているのも同じ構えである。

assāsapassāsa は男性で、複数形 `assāsapassāsā` で出ることが多いが、単数の
用例も canon にある (`catutthassa jhānassa assāsapassāso kaṇṭako`,
`Nāhu assāsapassāso, ṭhitacittassa tādino`、Mahāniddesa-aṭṭhakathā の
`Assāsapassāsoti tadubhayaṃ`)。

喩えの側については、パーリ語の文法書 Saddanīti (12 世紀のビルマで Aggavaṃsa
が著したもの。padamālā は語形変化を扱う部) が、gosadda (go 語) の項でこの
一文を引いて構文を明示している。

```
… ‘‘dvāraṃ pattaṃ pattaṃ gāviṃ ‘eko dve’ti sakkharaṃ khipitvā gaṇetī’’ti
vacanapariyosānāya saddaracanāyaṃ ‘‘eko gāvī, dve gāvī’’ti atthayojanānayo
vattabbo hoti, ‘‘gāvi’’nti upayogavacanañca dissati.
```

`eko` は gāvī (門に達した牛) に結びつくものとして構文が示され、`gāviṃ` が
対格形として現れている点も別に指摘されている。性については同じ箇所で、
go 語は雌雄どちらの牛も指す語であり、ここでの用法は性を明示しない言い方
(`avisadākāravohāratā`) だと述べている。

```
… ‘‘gāvo’’ti vatvā ‘‘gāvi’’nti vacanena itthipumavācakassa
okārantitthiliṅgassa gosaddassa avisadākāravohāratā vihitā. ‘‘Gāvo’’ti hi
iminā sāmaññato itthipumabhūtā goṇā gahitā, tathā ‘‘gāvi’’nti imināpi
itthibhūto pumabhūto ca goṇo.
```

## 伝承の異同

牛飼いの喩えの読みは一定していない。

| 出典 | 牛を指す語 | 口に出す言葉 |
| --- | --- | --- |
| Visuddhimagga (CSCD) | `gāviṃ` | `ekā dve` |
| Samantapāsādikā (CSCD) | `gāvaṃ` | `eko dve` |
| Paṭisambhidāmagga-aṭṭhakathā (CSCD) | `gāvaṃ` | `eko dve` |
| Saddanīti が引く註釈書本文 | `gāviṃ` | `eko dve` |

`gāvaṃ` `gāviṃ` はいずれも go 語の対格単数で、Saddanīti の示す女性の
padamālā (`Taṃ gāvaṃ, gāviṃ, gavaṃ passati`) にも男性の padamālā
(`Gāvuṃ, gāvaṃ, gavaṃ`) にも現れる形であり、これだけでは性を決められない。
口に出す言葉の側を `ekā` と読むのは Visuddhimagga の一伝のみで、他は
`eko` である。

なお同じ `eko dve tīṇi cattāri` の並びは Cūḷavaggapāḷi の uddāna 偈
(`Paṭikacceva ujjhanti, eko dve tīṇi cattāri`) にも現れる。

## 根拠が薄い点・確認できていない点

- 口に出す言葉の中で先頭の `eko` だけが数えている物の側に引かれ、3 と 4 が
  数を数として挙げる形になっている。この非対称の理由を述べた註釈は見つかって
  いない。上の整理は用例の分布からの読み取りであり、伝承がそう説明している
  わけではない
- 伝承がほぼ `eko` で一定していることから、「数え始めの言葉が `eko` の形で
  固まっていた」と読むこともできる。その場合 Saddanīti の `eko gāvī` という構文説明は
  後代の文法家による整理ということになる。どちらを取るかは Visuddhimagga の
  `ekā` が本来の読みかどうかにかかっており、確認できていない
- 女性の対象を数えたときに 3・4 が `tisso catasso` になるのか
  `tīṇi cattāri` のままなのかは、牛飼いの喩えが口に出す言葉を二までしか
  引かないため分からない
- 数の名を中性で挙げる例として Dhammapada-aṭṭhakathā の
  `Ekaṃ dve tīṇi cattāri pañca dasātiādinā nayena laddhānaṃ pana gaṇanā nāma
  natthi` があるが、そこで数えられている品物 (`sahassagghanakāni … dinnāni`)
  が中性なので、修飾語としての一致とも読める。純粋な引用用法の例としては
  弱い
- 数詞の共起の集計は CSCD の文字列検索による件数と、その先頭 20 件の目視に
  よる。全件は確認していない
- PTS 版の読みは参照できていない
