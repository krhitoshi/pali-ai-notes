# añño nūna tena samayena … ahosi — añño は誰に対して「別」か、siyā と assa はなぜ重なるか

MN 81 (Ghaṭikārasutta) の結びにある次の文を読んでいて生じた疑問について。

```
Siyā kho pana te, ānanda, evamassa –
‘añño nūna tena samayena jotipālo māṇavo ahosī’ti.
Na kho panetaṃ, ānanda, evaṃ daṭṭhabbaṃ.
Ahaṃ tena samayena jotipālo māṇavo ahosi’’nti.
```

- añño は「別の者」で、比べる相手は次の文の ahaṃ (語っている世尊自身) である
- ただし聞き手のアーナンダの側には比べる相手がまだない。聞き手にとってジョーティパーラは昔のある青年で、añño は「特定の誰でもない、よその誰か」と聞こえる。同じ añño が、語り手の世尊にとっては初めから「私ではない者」である
- この想定は Ahaṃ … ahosiṃ という結論があって初めて立つ。実際に浮かんだ疑問の報告ではなく、打ち消すために置かれた前置きである
- añño を主語と取るか述語と取るかは文法からは決まらない。どちらに取っても añño が文の中心で、ahaṃ と対になる
- siyā と assa はどちらも atthi の願望法三人称単数だが、働きが違う。siyā は文全体にかかる「〜かもしれない」、assa は「あなたにこういう考えがある」という節の動詞である

## añño は「別の者」で、基準は ahaṃ

añño は añña (別の、他の) の男性・単数・主格で、打ち消しの文 Na kho panetaṃ … evaṃ daṭṭhabbaṃ をはさんで、次の文の ahaṃ と対になっている。「そのときのジョーティパーラ青年は誰か別の者だったのだろう」に対して「そのときのジョーティパーラ青年は私だった」と続く。

辞書はこの定型そのものを añña の用例に挙げている。

- CPD は ¹añña の項で AN IV 394,8 (ヴェーラーマの話の同じ定型) を引き、different と訳したうえで、同じ箇所の ahaṃ と対になる語 (opp. ahaṃ) と注記している。また、これを jātaka-samodhāna (過去の人物を現在の人物に結びつける結び) の古い定型と呼んでいる
- DOP も añña² の項で同じ箇所 (~o nūna tena samayena Velāmo brāhmaṇo ahosi) を引いている。語義は other; different; another; somebody, something else などである

註釈書の言い換えも añño と ahaṃ を対にしている。ヴェーラーマの話のこの箇所について、Aṅguttaranikāya の註釈書 (`s0404a.att.xml`) は、世尊の趣旨を次のように言い換えたうえで siyā kho pana te 以下を導入している。

```
gahapati, etaṃ mahādānaṃ nāñño adāsi, ahaṃ adāsiṃ.
```

「長者よ、この大きな施しは他の者が与えたのではない。私が与えた」。añño という語の語義説明ではないが、añño を ahaṃ と対になる語として読んでいる。

### 聞き手には比べる相手がないのに、何に対して「別」なのか

「別の者」と言うには比べる相手が要る。しかし過去の物語を聞いているあいだ、アーナンダはジョーティパーラを世尊とも他の誰とも比べていない。それでも añño と言えるのは、この語が聞き手と語り手とで違って聞こえるためである (以下は辞書や註釈書の記述ではなく、文脈からの推論である)。

- 聞き手のアーナンダにとって、ジョーティパーラは昔のある青年で、ここにいる誰とも関係がない。この立場での añño は「よその誰か」、つまり特定の誰でもない者である。añño は、聞き手が意識せずに持っているこの受け取り方を言葉にしている
- 語り手の世尊は、これが自分の過去の話だと知っている。この立場での añño は初めから「私ではない者」である

añño という語の意味はどちらの場合も「別の」ひとつで、語義が二つあるわけではない。聞き手に「よその誰か」と聞こえていた añño が、次の Ahaṃ によって「私ではない者」の意味だったと分かる。

añña が特定しない「誰か」を指しうることは、辞書からも確かめられる。CPD と DOP は añña の語義に somebody else を挙げている。また「ある一人の」「誰か」を意味する aññatara は、añña の比較級として作られた語である (DOP)。

## この想定は結論から逆算して立てられている

añño nūna … という考えは、単独では出てこない。Ahaṃ … ahosiṃ と言うための前置きとして、打ち消される側を先に置いたものである。以下の用例の分布がこれを裏づける (逆算という言い方は用例からの推論である)。

añño nūna tena samayena … ahosi は、CSCD の本文では次の 5 箇所にある。どれも Na kho panetaṃ … evaṃ daṭṭhabbaṃ で打ち消され、Ahaṃ tena samayena … ahosiṃ と続く。

| 箇所 | 聞き手 | 「別の者だった」とされる人物 |
| --- | --- | --- |
| DN 17 (`s0102m.mul.xml` §270) | ānanda | rājā mahāsudassano |
| MN 81 (`s0202m.mul.xml` §292) | te, ānanda | jotipālo māṇavo |
| MN 83 (`s0202m.mul.xml` §316) | te, ānanda | rājā maghadevo |
| AN 三集 (`s0402m2.mul.xml`) | bhikkhave, tumhākaṃ | so rathakāro |
| AN 九集 (`s0404m2.mul.xml`、PTS AN IV 394) | te, gahapati | velāmo brāhmaṇo |

註釈書では Khuddakapāṭha-aṭṭhakathā と Suttanipāta-aṭṭhakathā が、saṅkho brāhmaṇo について同じ定型を使っている。

外枠の Siyā kho pana … evamassa は、同一人物であることを明かす場合に限らず、相手が抱きそうな見方を先に述べて退けるための枠である。律蔵・経蔵・論蔵の本文でこの枠を含む段落は 36 あり (ここでの段落は VRI の番号段落ではなく XML の p 要素。1 段落に複数回あっても 1 と数える)、うち 26 段落では同じ段落の中で Na kho panetaṃ … が続く。残る 10 段落 (DN 5 の §338 と MN 39 の §416–424) も、言い方は違うが同じく退けている。DN 5 は na kho panetassa dassukhīlassa evaṃ sammā samugghāto hoti と続き、MN 39 の §416–424 はどれも tāvatakeneva tuṭṭhiṃ āpajjeyyātha のあとに同じ戒め (Ārocayāmi vo, bhikkhave … mā vo sāmaññatthikānaṃ sataṃ sāmaññattho parihāyi, sati uttariṃ karaṇīye) が続く。

MN 12 (`s0201m.mul.xml` §158) には、añño の位置に形容詞が入った同じ形がある。

```
Siyā kho pana te, sāriputta, evamassa –
‘mahā nūna tena samayena kolo ahosī’ti.
Na kho panetaṃ, sāriputta, evaṃ daṭṭhabbaṃ.
Tadāpi etaparamoyeva kolo ahosi seyyathāpi etarahi.
```

「そのときのナツメの実はきっと大きかったのだろう」という想定を立て、「そのときも今と同じ大きさだった」と退ける。文頭に打ち消される述べ方を置き、nūna tena samayena … ahosi を続ける形が共通している。

## añño は主語か述語か

añño も jotipālo māṇavo も主格なので、どちらを主語と取ることもできる。

- 述語と取る読み: 「ジョーティパーラ青年は別の者だった」。上の MN 12 の文では、同じ位置の mahā が述語であること (kolo が主語) が明らかで、これと並行する
- 主語と取る読み: 「別の者がジョーティパーラ青年だった」。次の文 Ahaṃ … jotipālo māṇavo ahosiṃ と同じ形で、añño が ahaṃ と同じ位置に入っていることと並行する。Ñāṇamoli と Bodhi の英訳はこの読みで、"Certainly, someone else was the brahmin student Jotipāla on that occasion." としている

以下は推論である。Ahaṃ の文で動詞が一人称 (ahosiṃ) であることは、añño の文の主語を決める材料にはならない。一人称の代名詞と名詞を「である」でつなぐ文では、どちらが話題であっても動詞は一人称になるためである。したがって文法上の主語は決まらない。決まっているのは、jotipālo māṇavo が前の物語ですでに出ている人物で、añño (と次の文の ahaṃ) が新しく述べられる中心だということである。日本語では「そのときジョーティパーラ青年だったのは、きっと誰か別の者だろう」「そのときジョーティパーラ青年だったのは私だ」と言い表せる。

## nūna は確信寄りの推量

nūna はこの文では「きっと〜だろう」という推量を表す。nūna には問いを表す用法もあるが (DOP の 3 番目の語義 is it that …?)、この文はそれに当たらない。DOP は nūna の語義を 3 つに分け、2 番目の surely; probably, in all probability; it must be that … の用例に、上の MN 12 の文 (siyā kho pana te Sāriputta evaṃ assa mahā nūna tena samayena kolo ahosī ti) を挙げている。añño nūna も同じ枠の文なので、この語義に当たる。

英訳の Certainly は DOP の 1 番目の語義 (indeed; certainly) に当たる訳し方である。PTSD は nūna を affirmative-dubitative particle (肯定と疑いの両方を表す小辞) と説明しており、事実の断定というより、そうに違いないという見込みを述べる語と読める。

Siyā kho pana … evamassa の枠の中の想定には nūna がよく現れる。MN 4 の ajjāpi nūna samaṇo gotamo avītarāgo …、AN 二集の tattha nūna tāsaṃ devatānaṃ …、律蔵 Mahāvagga の kevalaṃ saddhāmattakaṃ nūna ayamāyasmā … などで、どれも文頭の語句の直後に置かれている。

## siyā と assa はなぜ重なるか

siyā と assa はどちらも atthi の願望法 (optative。希求法とも呼ぶ) の三人称単数で、同じ語が二度出ているように見える。しかし二つは別の層にある。

```
Siyā kho pana | te, ānanda, evam assa
```

- siyā は文頭に立ち、主語を持たずに「〜ということがあるかもしれない」と文全体の可能性を述べる
- assa は te evam assa (あなたにこのような考えがある) という節の動詞で、te (与格・属格) とともに「あなたに〜がある」という形を作る

直訳すると「あなたにこのような考えがある、ということがあるかもしれない」となる。

辞書はこの組み合わせを用法として立てている。DOP の atthi の項は、願望法 siyā について「別の願望法 (とくに assa) が続くとき perhaps; it might be (that) …」とし、MN 4 (M I 23,29) とヴェーラーマの話 (A IV 394,8) のこの枠を挙げる。assa についても「属格とともに (とくに siyā が前にあるとき) (perhaps) it might occur to …, one might think …」とし、DN 9 (D I 196,2) を挙げる。

註釈書も同じ切り方をしている。MN 4 の同じ枠について、Mūlapaṇṇāsa-aṭṭhakathā (`s0201a.att.xml` §55) は次のように言い換える。

```
Tattha siyā kho pana te, brāhmaṇa, evamassāti, brāhmaṇa, kadāci tuyhaṃ evaṃ bhaveyya.
```

siyā を kadāci (あるとき、場合によっては) という副詞に、te を tuyhaṃ に、assa を bhaveyya に置き換えている。siyā は副詞のように、assa は動詞として読まれている。assa が bhaveyya (願望法の普通の形 -eyya を持つ) で言い換えられていることから、assa が願望法の動詞であることも確かめられる。

復註はこの siyā を小辞 (nipāta) と明言している。同じ箇所について Mūlapaṇṇāsa-ṭīkā (`s0201t.tik.xml` §55) は次のように言う。

```
Siyā kho pana te brāhmaṇāti ettha siyāti ‘‘appevā’’ti iminā samānattho nipāto, tasmā ‘brāhmaṇa, appeva kho pana te evamassā’ti attho.
```

siyā は appeva と同じ意味の小辞で、文は appeva kho pana te evamassa の意味だとする。続けて、註釈書の kadāci もこの意味を指して言われたものだと述べている (Yaṃ pana aṭṭhakathāyaṃ ‘‘kadācī’’ti vuttaṃ, tampi imamevatthaṃ sandhāya vuttaṃ)。律の復註 Kaṅkhāvitaraṇīpurāṇa-ṭīkā (`vin09t.nrf.xml`) も、別の箇所の siyā を説明するのにこの文を例に引き、kadāci と同じ意味の小辞としている (‘‘siyā kho pana te brāhmaṇa evamassā’’tiādīsu viya ‘‘kadācī’’ti iminā samānattho nipāto)。

### 復註が挙げる別の読み

律蔵 Mahāvagga の Siyā kho pana, bhante, idhekaccassa āyasmato evamassa について、復註 Vajirabuddhi-ṭīkā (`vin06t.nrf.xml` §244) は二つの読みを並べている。

```
Siyā kho evamassāti kadāci evamassa, assa vā āyasmato evaṃ siyā.
```

一つ目は上の註釈書と同じで、siyā を kadāci と取る。二つ目は vā (あるいは) で導かれる別案で、assa を代名詞 (ayaṃ の属格「この」) として āyasmato にかけ、siyā を動詞と取る。「この尊者にこのような考えがあるかもしれない」となり、願望法は siyā ひとつになる。

この別案は、考えを抱く者が三人称 (idhekaccassa āyasmato) のときにだけ成り立つ。MN 81 のように te (二人称) がある文では、assa を te にかかる代名詞と読むことはできないので、assa は動詞である (この判断は推論である)。

### 願望法と他の願望法の重なり

siyā が可能性を立て、その中身を別の願望法が受ける形は、この枠以外にもある。AN 十集 (`s0404m3.mul.xml` §6) の問いがその例である。

```
siyā nu kho, bhante, bhikkhuno tathārūpo samādhipaṭilābho
yathā neva pathaviyaṃ pathavisaññī assa, na āpasmiṃ āposaññī assa, …
```

siyā が「〜ということがありうるか」と問い、yathā 以下の assa がその中身を述べる。内側の動詞が直説法でなく願望法なのは、siyā で導かれた仮定の話の中身だからだと考えられる (推論)。

### 語形と呼び名

PTSD の atthi の項は、三人称単数の願望法 (PTSD の用語では Pot.) として siyā と assa の二つを挙げ、siyā をサンスクリット syāt に対応させている。願望法は、事実として述べる直説法に対し、可能性・仮定・願望など、事実と決まっていないことを述べる法である。

## 確認できていない範囲

- assa という語形の成り立ち (siyā と並んで別の形がある理由) は確認していない
- 註釈書・復註が añño nūna の añño という語そのものを説明している箇所は見つけていない。CSCD 全体を `añño nūna` と、註釈の見出しの形 `añño nūnā…` で検索し、DN・MN・AN の註釈書と復註を見出しの形 `Aññoti` で検索した範囲での結果である
- 段落数 (36 と 26) は CSCD の XML の p 要素を単位とする集計で、`Siyā kho pan…` から 80 字以内に `evamassa` が続く段落を数えた。evaṃ assa と分けて書く形は、同じ条件で CSCD 全体を検索しても見つからなかった。語順の違う形は数えていない。Milindapañha (`s0518m.nrf.xml`) は DN 16 のこの枠を引用しているが、集計の対象に入れていない
- Ñāṇamoli と Bodhi の英訳は MN 81 の該当の一文だけを参照した
