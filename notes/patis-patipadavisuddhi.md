# 無礙解道の paṭipadāvisuddhi と paṭipadāvisuddhipakkhanda

Paṭisambhidāmagga 安般念論 (Ānāpānassatikathā) の段落 158 に出る
`paṭipadāvisuddhi` / `paṭipadāvisuddhipakkhanda` について、次の三つを調べた。

1. 何を指しているのか
2. なぜ paṭipadā という名前になっているのか
3. 「安止 (appanā) の直前まで」という理解でよいか

答えは次のとおり。

- 二語は別項目ではなく、同じ事柄の標挙形 (過去分詞) と解説形 (抽象名詞)
  である
- 本文が与える内容規定は三特相だけで、「障碍から心が清まり、中間の止の相
  へ進み行き、そこへ進み入る」局面を指す
- 名前の由来を「安止に至るまでの助走区間 (paṭipadā)」と説明するのは註釈層
  であり、無礙解道本文には近行・安止の語彙自体が無い
- したがって「安止の直前まで」という理解は、註釈の一方 (Abhayagiri 派) の
  読みと重なる。Buddhaghosa はこれを退けて、安止の一刹那の内に置く

以下、本文が言っていること、註釈が読み込んでいること、こちらの推論を
節ごとに分けて記す。

## 1. 出てくる場所

- 本文: Paṭisambhidāmaggapāḷi, 1. Mahāvaggo, 3. Ānāpānassatikathā,
  段落 158 (2)
- 註: Paṭisambhidāmagga-aṭṭhakathā (Saddhammappakāsinī) の該当箇所
- リポジトリの対訳: `patisambhidamagga/patis_1_03.md` の 158 (2)、
  註は `patisambhidamagga/patis_attha_1_03.md` の対応箇所

## 2. 本文が言っていること

### 2.1 二語は標挙と解説の関係

同じ三つ組が、語形を変えて二度現れる。

| | 語形 | 主語・機能 |
|---|---|---|
| 標挙 (uddesa) | `paṭipadāvisuddhipakkhandaṃ`, `upekkhānubrūhitaṃ`, `ñāṇena sampahaṃsitaṃ` | 「一つにまとまった心」を主語とする過去分詞 |
| 解説 (niddesa) | `paṭipadāvisuddhi`, `upekkhānubrūhanā`, `sampahaṃsanā` | 禅の始め・中間・終りに配当される抽象名詞 |

```
imehi catūhi ṭhānehi ekattagataṃ cittaṃ paṭipadāvisuddhipakkhandañceva
hoti, upekkhānubrūhitañca, ñāṇena ca sampahaṃsitaṃ.
```

```
Paṭhamassa jhānassa paṭipadāvisuddhi ādi, upekkhānubrūhanā majjhe,
sampahaṃsanā pariyosānaṃ.
```

`pakkhanda` は `pakkhandati` の過去分詞で、註が `paviṭṭha` と言い換える。
つまり `paṭipadāvisuddhipakkhanda` は「paṭipadāvisuddhi へ進み入った (心)」
であり、`paṭipadāvisuddhi` はその進み入る先にあたる。

### 2.2 内容規定は三特相のみ

```
Yo tassa paripantho tato cittaṃ visujjhati, visuddhattā cittaṃ majjhimaṃ
samathanimittaṃ paṭipajjati, paṭipannattā tattha cittaṃ pakkhandati.
```

1. 禅にとっての障碍 (paripantha) から心が清まる
2. 清まったがゆえに中間の止の相 (majjhima samathanimitta) へ進み行く
3. 進み行ったがゆえにそこへ進み入る (pakkhandati)

本文が paṭipadāvisuddhi について述べるのはこれだけである。到達点が何で
あるか (近行なのか安止なのか) は本文の語彙では規定されていない。

### 2.3 適用範囲

この三つ組は第一禅だけでなく第二禅以下にも、さらに各道 (arahattamagga
まで) にも同じ定型で繰り返される。段落全体の枠組みは、禅を
`ādikalyāṇa / majjhekalyāṇa / pariyosānakalyāṇa` (初善・中善・後善) に
当てはめて十相を数えることにある。

## 3. 註釈が読み込んでいること

### 3.1 複合語の解釈が二通りある

| 出典 | 解釈 | 読み |
|---|---|---|
| Paṭisambhidāmagga-aṭṭhakathā | `paṭipadā eva nīvaraṇamalavisodhanato visuddhi` | 同格 (行道こそが清浄) |
| Visuddhimagga-mahāṭīkā, Sāratthadīpanī-ṭīkā | `paripanthato visujjhanaṃ visuddhi, paṭipadāya visuddhi paṭipadāvisuddhi` | 属格 (行道の清浄) |

リポジトリの対訳は属格に沿って「行道の清浄」としている。

### 3.2 到達点を安止と同定するのは註

Paṭis-a は本文の `majjhima samathanimitta` を
`samappavatto appanāsamādhiyeva` (等しく起こった安止定そのもの) と
言い切る。本文には無い appanā という座標がここで入る。

### 3.3 位置づけをめぐる二説

| | paṭipadāvisuddhi | upekkhānubrūhanā | sampahaṃsanā |
|---|---|---|---|
| eke (Vism-mhṭ は Abhayagirivāsino と名指す) | `sasambhāriko upacāro` 資具を伴う近行 | `appanā` 安止 | `paccavekkhaṇā` 事後の観察 |
| Buddhaghosa | 安止の内、`āgamanavasena` (至り来た経路の面から) | 中捨の作用 (kicca) の面から | 澄み清める智の作用完成 (kiccanipphatti) の面から |

Buddhaghosa の論拠は本文の語形である。「一つにまとまった心が
paṭipadāvisuddhipakkhanda である」と心の述語として言う以上、三つとも
安止の一刹那の内 (`antoappanāyameva`) に見るべきだとする。

Vism-mhṭ が eke 説を退ける理由は二つ挙がる。

```
Te hi evaṃ paṭipadāvisuddhiādike vaṇṇayanti, tadayuttaṃ. Tathā hi sati
ajjhānadhammehi jhānassa guṇasaṃkittanaṃ nāma kataṃ hoti. Na hi
bhūmantaraṃ bhūmantarapariyāpannaṃ hoti. Pāḷiyā cetaṃ viruddhaṃ
```

禅でない諸法によって禅を讃嘆することになる点と、地 (bhūmi) の異なるものを
同じ地に含めることになる点、そして本文と食い違う点である。

なお Vism-mhṭ は、なぜ「始め」と言われるかも明示する。

```
Sā panāyaṃ yasmā jhānassa uppādakkhaṇe labbhati, tasmā vuttaṃ
"paṭipadāvisuddhi ādī"ti
```

得られるのは禅の生起の刹那である、という位置づけになっている。
Vimativinodanī-ṭīkā は別に、他の二つの先行原因 (purimakāraṇa) だから
「始め」と言われるとも補う。

### 3.4 paṭipadā の区間化は四行道の註釈から来ている

Visuddhimagga と Dhammasaṅgaṇī-aṭṭhakathā は、四行道 (dukkhapaṭipadā
dandhābhiññā など) を説くときに区間を二つに切る。

```
Tattha paṭhamasamannāhārato paṭṭhāya yāva tassa tassa jhānassa upacāraṃ
uppajjati, tāva pavattā samādhibhāvanā paṭipadāti vuccati. Upacārato pana
paṭṭhāya yāva appanā, tāva pavattā paññā abhiññāti vuccati.
```

最初の作意から近行までが paṭipadā、近行から安止までが abhiññā という
区切りである。これが「paṭipadā = 安止に至るまでの助走区間」という理解の
出どころにあたる。

ただしこの区間定義は Dhammasaṅgaṇī 本文には無い。Dhs は
`dukkhapaṭipadaṃ dandhābhiññaṃ pathavīkasiṇaṃ` のように禅の分類ラベルを
立てるだけで、区間の定義はしていない。定義は註釈層である。

### 3.5 名前の由来をどう説明しているか

Vism-mhṭ の語釈は道具格で解く。

```
paṭipajjati jhānaṃ etāyāti paṭipadā, gotrabhupariyosāno pubbabhāgiyo
bhāvanānayo
```

「これによって禅に入る」ので paṭipadā、種姓 (gotrabhū) で終わる前分の
修習の道筋のこと、とする。visuddhi の側は
`paripanthato visujjhanaṃ visuddhi` (障碍から清まることが清浄) である。

三語はそれぞれ別の観点から名を取っている。

| 語 | 何にちなむ名か |
|---|---|
| paṭipadāvisuddhi | 由来 (āgamana) — その清浄をどの局面から持ち込んだか |
| upekkhānubrūhanā | 作用 (kicca) — 何が支え育てているか |
| sampahaṃsanā | 作用の完成 (kiccanipphatti) — 何が仕上げるか |

## 4. 本文と註釈の語彙差 (集計)

CSCD の Paṭisambhidāmagga 本文 (`s0517m.mul.xml`、三品すべてを含む) 全体を
対象に、語形を文字列一致で数えた。

| 語 | 件数 | 備考 |
|---|---|---|
| `upacāra` | 0 | |
| `appanā` | 0 | 3 件ヒットするがすべて `lālappanā`, `saṅkappanānatta` の部分一致 |
| `dandhābhiññā` | 0 | |
| `khippābhiññā` | 0 | |
| `dukkhapaṭipada-` | 0 | |
| `gotrabhū` | 97 | 智論に gotrabhū 智の章がある |
| `paṭipadā` | 48 | 内訳は下記 |

`paṭipadā` 48 件の内訳。

| 用法 | 件数 |
|---|---|
| `nirodhagāminī/-iyā paṭipadā` (道諦、五蘊などの滅に至る道) | 36 |
| `majjhimā paṭipadā` (中道) | 3 |
| `catasso paṭipadā` (「四地」の項目列挙。定義は無い) | 1 |
| 本節の `paṭipadāvisuddhi` 系 (禅と道への適用) | 8 |

`abhiññā` も無礙解道では `abhiññeyya` (証知されるべき) の形が支配的で、
四行道の「証得の速い・遅い」を言う abhiññā とは用法が異なる。

つまり近行・安止という枠組みの語彙は本文に存在しない。一方 gotrabhū は
本文自身の語なので、Vism-mhṭ の「前分の修習は gotrabhū で終わる」という
線引きだけは本文の語彙と接続できる。後から入ったのは upacāra / appanā の
枠である。

## 5. こちらの推論

以下は資料に書かれている記述ではなく、上記からの推論である。

- 「安止の直前まで」という理解は、eke (Abhayagiri) 説の
  `sasambhāriko upacāro` とほぼ同じ内容になる。Buddhaghosa が明示的に
  退けた読みなので、どちらの立場を取るかは意識しておく必要がある
- 本文の第三特相は `tattha cittaṃ pakkhandati` (そこへ進み入る) であり、
  進み入る動作自体が記述に含まれている。標挙の語も `pakkhandaṃ` と
  「もう入っている」状態を言う。したがって「直前で切れる」という読みは、
  本文の記述より狭い
- そもそも「安止の直前まで」という問いの立て方が、本文に無い座標系を
  借りている。本文の言う到達点は「中間の止の相へ進み入る」ところまでで、
  それを安止と同定するのは Paṭis-a の解釈である
- 二説が争っているのは「その清浄をどの心刹那の属性として立てるか」で
  あって、修行の記述としての中身 (蓋から清まり、止の相に入る) は動かない
- Buddhaghosa が `āgamanavasena` という迂路を必要としたのは、本文が持たない
  近行/安止の枠を持ち込んだ側の事情にも見える。Abhayagiri 派の読みは、
  同じ枠を持ち込んだうえで語義どおり素直に当てはめた結果と理解できる

読解の実用的な線としては、「蓋から清まり、止の相に入るまで (入る瞬間を
含む) の局面」と押さえておけば無理がない。Buddhaghosa 説に寄せるなら
「安止の心が持っている、前分由来の清浄さ」という言い方になる。
