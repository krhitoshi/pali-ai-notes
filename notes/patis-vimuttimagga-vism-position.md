# 無礙解道・解脱道論・清浄道論の位置づけ — 三蔵の論との関係と註釈書の系統

三書はいずれも戒定慧の実践を体系的に扱うが、パーリ文献の中での扱われ方は
大きく違う。要点は次の三つになる。

1. 三蔵内にあるのは無礙解道 (Paṭisambhidāmagga) だけで、解脱道論
   (Vimuttimagga) と清浄道論 (Visuddhimagga) は蔵外である。
2. 論蔵 (Abhidhammapiṭaka) との距離で並べると、無礙解道は「論の方法を使うが
   分析の単位が法ではない書」、解脱道論は「論蔵をほとんど取り込まない実践
   書」、清浄道論は「論蔵を慧の地として統合した書」となる。
3. 註釈書まで含めると、清浄道論が註釈書階層のハブになる。論蔵の註が詳説を
   清浄道論に委ね、正典である無礙解道の註も清浄道論に依拠して書かれる。

以下、この三点を順に見ていく。


## 1. 三蔵のどこに位置するか

| | 無礙解道 | 解脱道論 | 清浄道論 |
|---|---|---|---|
| 位置 | 三蔵内 (経蔵・小部) | 蔵外 | 蔵外 |
| 伝統的著者 | サーリプッタ | ウパティッサ (Upatissa) | ブッダゴーサ (Buddhaghosa) |
| パーリ原典 | 現存 | 散逸 | 現存 |
| 主要な伝本 | パーリ | 漢訳『解脱道論』 | パーリ |
| 註 | Saddhammappakāsinī | パーリ註なし | Paramatthamañjūsā (大註) |

### 無礙解道

小部所収の正典で、三書のうち唯一三蔵に属する。大品・双結品・慧品の三品、
各 10 論で計 30 論からなる。冒頭の智論 (Ñāṇakathā) が 73 智を立てて順に
分別する構成をとり、観の智の階梯の原型を提示する。出入息念論
(Ānāpānassatikathā) は正典中で最も詳細な安般念の分析である。

内容は経典というより論書に近く、経蔵から論蔵への移行期の性格をもつ後期層と
見られている。

### 解脱道論

蔵外の実践綱要書で、清浄道論に先行する同型の書とされる。パーリ原典はほぼ
失われ、漢訳が主要な伝本となっている。戒・定・慧の三学構成をとり、清浄道論
と骨格がほぼ一致するが、説話や註釈史の引用がなくはるかに簡潔である。

パーリ文献の側からは、大註が批判的に言及する対象としてのみ姿を現す。大註
§44 は清浄道論の「或る者 (ekacce)」をウパティッサ長老と註し、その説が解脱
道論に出ていると述べる。

```
Ekacceti upatissattheraṃ sandhāyāha. Tena hi vimuttimagge tathā vuttaṃ.
```
(`e0103n.att.xml` §44、Visuddhimagga-mahāṭīkā)

### 清浄道論

蔵外ではあるが、上座部教理の事実上の標準テキストとなった。全 23 章を戒
(1-2 章)、定 (3-13 章)、慧 (14-23 章) に配する。冒頭の綱要偈は相応部の一偈
(CSCD の参照表記で saṃ. ni. 1.23) で、慧の部は中部 24 経の七清浄を枠組みと
する。


## 2. 論蔵との関係

論蔵七論に共通する方法は、(a) 論母 (mātikā) を立てて分別するという形式と、
(b) 分析の単位が法 (dhamma) であること、の二点に整理できる。三書の位置は
この二つを分けて見ると説明しやすい。

### 無礙解道 — 形式は論、単位が違う

無礙解道は形式面では完全に論書である。智論は冒頭に 73 智の一覧を掲げ、以下
それを一つずつ分別していく。これは分別論とまったく同じ手続きである。

分別論の複註は、この 73 智が無礙解道の「論母」に来ていると明示する。

```
sutamayañāṇādīni anāvaraṇañāṇapariyosānāni paṭisambhidāmagge
(paṭi. ma. mātikā 1.1 ādayo) āgatāni tesattati ñāṇāni
```
(`abh02t.tik.xml` §760、Vibhaṅga-mūlaṭīkā)

聞所成智に始まり無障智に終わる 73 智という記述で、CSCD 自身が無礙解道の
当該箇所を mātikā と呼んでいる点が確認できる。なお 73 智のうち最後の 6 は
仏に固有 (asādhāraṇa) の智とされる。

にもかかわらず七論に編入されなかった理由は、分析の単位にあると考えられる。

| | 論蔵七論 | 無礙解道 |
|---|---|---|
| 分析の単位 | 法 (心・心所・色) | 智・見・出入息念などの実践項目 |
| 到達点 | 二十四縁による法の相依関係 | 修行階梯としての智の序列 |
| 心の分類 | 法集論が網羅的に列挙 | 用いない |
| 論争 | 論事が部派説を破斥 | 論争層をもたない |

つまり無礙解道は法の分析学ではなく道の分析学であり、同じ論母-分別技法を
実践論に適用した並行的な流れと見られる。小部にはもう一つ義釈 (Niddesa) と
いう論書的テキストがあり、両者ともサーリプッタに帰される。論蔵自体もサーリ
プッタが伝持したと伝えられるため、「サーリプッタに帰される分析文献群のうち
七論に編入されたものとされなかったものがある」という構図になる。

漢訳『舎利弗阿毘曇論』(法蔵部系) との構成上の類似が指摘されることがあるが、
直接の対応関係は確定していない。二次情報として扱う。

### 解脱道論 — 論蔵の統合が薄い

清浄道論と骨格が一致するにもかかわらず、論蔵の教理体系をほとんど組み込んで
いない点が特徴である。五方便品 (蘊・入・界・因縁・諦) が慧の理論部にあたる
が、清浄道論の慧地に比べてはるかに簡略で、心路過程や有分の体系を前提にしな
い。

さらに、大註が挙げる清浄道論との相違点は論蔵解釈そのものの争点である。CSCD
所収の清浄道論序説 (`e0105n.nrf.xml`) は、大註が「或る者たち (ekaccānaṃ)」
を無畏山寺住者 (abhayagirivāsīnaṃ) と註していることを引き、生色 (jātirūpa)
と睡眠色 (middharūpa) を色法として立てる説が解脱道論に見えると指摘する。
睡眠を独立の色法と認めるか否かは、法の一覧をどう定めるかという論蔵レベルの
問題である。

同じ序説は、無礙解道の一節が解脱道論にも見えるとも述べている。解脱道論が
無礙解道を利用していた可能性を示す記述だが、漢訳を介した対応であり、序説
自体が後代の編纂物である点に注意が要る。

### 清浄道論 — 論蔵を慧の地とした統合点

清浄道論の慧の部は、まず慧地 (paññābhūmi) として蘊・処界・根諦・縁起を扱い
(14-17 章)、そのあとで七清浄の階梯に入る (18-23 章)。この慧地の四章が事実上
の論蔵ダイジェストである。17 章は縁起を発趣論の二十四縁で説明する。

構造として見ると、清浄道論は「論蔵 = 観の対象となる法の知識、七清浄 = その
知識を用いる手順」という役割分担を打ち出したことになる。実践書の中に論蔵を
制度的に組み込んだのはこの書である。

もう一点、上座部アビダンマの中核概念である心路過程 (vīthi) や有分
(bhavaṅga) は、論蔵本文には体系としては存在しない。有分は発趣論の無間縁の
記述に語として現れる。

```
Sukhāya vedanāya sampayuttaṃ bhavaṅgaṃ adukkhamasukhāya vedanāya
sampayuttassa bhavaṅgassa anantarapaccayena paccayo.
```
(`abh03m7.mul.xml`、Paṭṭhānapāḷi)

一方、有分が動く過程や速行の数を論じるのは法集論註以降である。これらが註釈
期の発展であり、その定着点の一つが清浄道論だという見方の根拠になる。


## 3. 論母 (mātikā) とは何か

論母は、本文の冒頭に置かれる見出し語の一覧である。定義も説明もつけず項目名
だけを並べ、本体でそれを一つずつ展開する。語としては mātā (母) 系で、
註釈は諸義が生まれる母胎の意に解する。日常語の mātikā は水路を意味し、教説
を導く導管というイメージも重なる。漢訳では論母・本母、音写で摩怛理迦。

論母が独立した伝持単位であったことは三蔵の中に痕跡がある。長部 16 経の四大
教法や中部・律蔵に、dhammadhara / vinayadhara / mātikādhara (法を持つ者・
律を持つ者・論母を持つ者) の三区分が現れる。

```
therā bhikkhū viharanti bahussutā āgatāgamā dhammadharā vinayadharā
mātikādharā
```
(`s0102m.mul.xml`、Mahāvaggapāḷi)

大註はこれを「その法と律の論母を持つゆえに論母持者」と註する
(`e0103n.att.xml` §53)。経と律と並んで論母を専門に暗誦する比丘がいたことに
なり、論蔵が最初から現在の七論の形で成立したのではなく、論母のリストが先に
あってその分別が後に七論になった、と見る根拠になる。

代表例が法集論冒頭の論蔵論母である。三法が 22 組、二法が 142 組で、二法の
うち 42 組は経の二法 (suttantikaduka) として区別される。

```
Tattha dvāvīsati tikā tikamātikā nāma. Dvecattālīsasatadukā dukamātikā
nāma
```
(`abh09t.nrf.xml`、Abhidhammamātikāpāḷi)

CSCD の論蔵に Abhidhammamātikāpāḷi という論母だけを抜き出したテキストが
独立して収められていること自体、論母がひとまとまりの単位として扱われてきた
ことを示している。

律にも同型がある。波羅提木叉 (戒条リスト) が論母にあたり、経分別
(Suttavibhaṅga) がその分別にあたる。


## 4. 論母-分別技法

手順は二段である。

1. 提示 (uddesa) — 論母を立てる
2. 分別 (niddesa / vibhaṅga) — 置かれた語の順に一つずつ解く

註釈書はこれを定型句で明示する。分別論註が第六力の説明で使うのがそのままの
例である。

```
mātikaṃ ṭhapetvā nikkhittapadānukkamena niddeso kato
```
(`abh02a.att.xml` §751、Vibhaṅga-aṭṭhakathā)

分別の中身は通常、問答形式をとる。「いかなる法が善か (katame dhammā
kusalā)」と問い、定義を述べ、該当する法を列挙する。論蔵ではこれが総当たり
展開に発展し、双論は項目を肯定形と否定形の対にして全組合せを問い、発趣論は
二十四縁を論母の全項目に掛け合わせる。あの反復は、論母を漏れなく尽くすと
いう方法上の要請から出ている。

この技法は論蔵専用ではない。法集論註は、仏が蜜丸経で要旨だけ述べて去った
場面を「論母を立てて座から立ち精舎に入った」と描写する。

```
…esevanto rāgānusayāna’’nti (ma. ni. 1.202) mātikaṃ ṭhapetvā uṭṭhāyāsanā
vihāraṃ pāvisi.
```
(`abh01a.att.xml`、Dhammasaṅgaṇī-aṭṭhakathā)

略説を仏が置き、弟子 (摩訶迦旃延) が分別するという構造を、註釈書自身が
論母-分別として捉えていることになる。この技法は上座部の註釈行為そのものの
基本形式だと言える。

三書への適用は次のとおり。

| 書 | 論母にあたるもの | 分別にあたるもの |
|---|---|---|
| 無礙解道 | 73 智の一覧 (智論冒頭) | 各智の逐次解説 |
| 解脱道論 | 戒・定・慧の三学 | 12 章の展開 |
| 清浄道論 | 冒頭偈 | 23 章全体。慧の部はさらに七清浄を第二の論母とする |

清浄道論が随所に「この偈によって戒定慧の面から説かれた清浄道のうち、ここ
までで戒が明かされた」という区切りを入れるのは、偈という論母の分別がどこ
まで進んだかを示す標識である。

```
Ettāvatā ca ‘‘sīle patiṭṭhāya naro sapañño’’ti imissā gāthāya
sīlasamādhipaññāmukhena desite visuddhimagge sīlaṃ tāva paridīpitaṃ
```
(`e0101n.mul.xml`、Visuddhimaggo)

経の一偈を論母に据えて論書の技法で展開した書、というのが清浄道論の形式面
での性格になる。


## 5. 註釈書を含めた関係

上座部の文献階層は 本文 (mūla) → 註 (aṭṭhakathā) → 複註 (ṭīkā) → 随複註
(anuṭīkā) である。三書をこの階層に置くと関係がはっきりする。

```
[三蔵]                  [註]                        [複註]
論蔵七論 ──────→ 法集論註 Atthasālinī ─┐
                  分別論註 Sammohavinodanī ├→ 根本複註 → 随複註
                  五論註 Pañcappakaraṇa ──┘
                        │
                        │ 「詳細は清浄道論に説かれた方法どおりに」
                        ↓
無礙解道 (小部) ─→ 【清浄道論】 ─────────→ 大註 Paramatthamañjūsā
   │  引用される        ↑ ハブ                        │
   │                    │                            │ 批判
   └→ 註 Saddhammappakāsinī                          ↓
        …清浄道論に依拠して解説                  解脱道論 (漢訳のみ)
                                                 パーリ註釈書をもたない
```

### 清浄道論は特定の本文の註ではなく、註釈書群の共通基盤である

論蔵の註が実際に清浄道論へ詳説を委ねている。分別論註は業処の説明で次のよう
に言う。

```
Tassa sodhanavidhānaṃ visuddhimagge vuttanayeneva veditabbaṃ.
```
(`abh02a.att.xml`、Vibhaṅga-aṭṭhakathā)

五論註は神通の項で「ここで説かれるべきことはすべて清浄道論に説かれている」
と済ませる。

```
…ettake ṭhāne yaṃ vattabbaṃ siyā, taṃ sabbaṃ visuddhimagge vuttameva.
```
(`abh03a.att.xml`、Pañcapakaraṇa-aṭṭhakathā)

註釈書群が共有する理論本体を外部に括り出したものが清浄道論だ、と理解できる。

### 依存の向きが逆転する

清浄道論は無礙解道を聖典として引く (正典 → 蔵外の方向)。一方、無礙解道の註
Saddhammappakāsinī は清浄道論より後代の成立で、無礙解道を清浄道論の枠組み
で解説する (蔵外 → 正典の方向)。

Cūḷagaṇṭhavaṃsa は同註の帰属を次のように記す。

```
Paṭisambhidāmaggassa aṭṭhakathā gantho mahānāmena upāsakena āyācitena
mahānāmācariyena kato.
```
(`e0701n.nrf.xml`、Cūḷaganthavaṃsapāḷi)

優婆塞マハーナーマの請いにより、マハーナーマ阿闍梨が作った、という伝である。
結果として、正典である無礙解道を読む場合も実際には清浄道論のフィルタを通る
ことになる。無礙解道の一節を追うと、参照は Saddhammappakāsinī → 清浄道論 →
大註 の順に伸びていく。

### 解脱道論は註釈網の外にある

解脱道論にはパーリの註も複註も存在しない。パーリ文献の側からは大註の批判
対象としてのみ現れる (§1 に引いた `e0103n.att.xml` §44 など)。註釈網に組み
込まれた書と、組み込まれず外から参照される書という非対称がある。

### 形式面での格付け

清浄道論の註が aṭṭhakathā ではなく ṭīkā (複註) と呼ばれる点は象徴的である。
複註がつくということは、伝統がこの書を註釈書の段 (本文に準ずる位置) に格付
けしたことを意味する。CSCD の構成もこれに従っていて、清浄道論は律蔵・経蔵・
論蔵のいずれにも属さない階層に本文 (`e0101n.mul.xml`) として置かれ、大註が
その註釈書 (`e0103n.att.xml`) として付く。


## 6. まとめ

論母-分別という一つの技法を軸に見たときの配置は次のようになる。

- 無礙解道 — 技法を実践論に適用した正典。論蔵と方法を共有するが分析の単位が
  違うため、七論とは別系統として経蔵に収まった
- 解脱道論 — 三学を論母とする簡潔な実践書。論蔵の展開も註釈網への接続も
  もたず、別系統の論蔵理解を示す史料として意味がある
- 清浄道論 — 経の一偈を論母に据えて論蔵の内容を分別しきった書。註釈書全体の
  共通基盤となり、正典の註までがこれに依拠する


## 確認できた範囲と留保

CSCD の全文検索で直接確認したのは次の事項である。

- 分別論註の定型句「論母を立てて置かれた語の順に分別がなされた」
  (`abh02a.att.xml` §751)
- 分別論複註が無礙解道の 73 智を mātikā として参照していること
  (`abh02t.tik.xml` §760)
- mātikādhara を含む三区分が長部・中部に現れること (`s0102m.mul.xml` ほか)
- 法集論の論母が三法 22 組・二法 142 組 (うち経二法 42 組) であること
  (`abh09t.nrf.xml`)
- 法集論註が蜜丸経の場面を「論母を立てて」と表現すること (`abh01a.att.xml`)
- 論蔵の註が清浄道論に詳説を委ねる記述 (`abh02a.att.xml`,
  `abh03a.att.xml`)
- 大註が清浄道論の「或る者」をウパティッサ長老と註し解脱道論に言及すること
  (`e0103n.att.xml` §44)
- 清浄道論序説が大註の無畏山寺住者への言及、生色・睡眠色の問題、無礙解道の
  一節が解脱道論にも見えることに触れること (`e0105n.nrf.xml`)
- Cūḷagaṇṭhavaṃsa による Saddhammappakāsinī の帰属 (`e0701n.nrf.xml`)
- 有分が発趣論本文に語として現れること (`abh03m7.mul.xml`,
  `abh03m8.mul.xml`)
- 清浄道論冒頭偈の出典表記が saṃ. ni. 1.23 であること (`abh03a.att.xml`)

確認できていない、または二次情報として扱うべき事項は次のとおり。

- 各書の成立年代 (無礙解道の正典内での層位、解脱道論の 1-2 世紀説、清浄道論
  の 5 世紀説)
- 解脱道論の学派帰属。大註が無畏山寺住者に言及することは確認できたが、
  解脱道論そのものを無畏山寺派の書と断定する根拠までは本調査で確認していない
- 漢訳『解脱道論』の訳出年代・訳者・巻数
- 註の著者帰属と年代 (マハーナーマの年代、根本複註・随複註の著者)
- 『舎利弗阿毘曇論』と無礙解道の関係
- 所造色の数え方 (23 と 24 の両様が文献に見える)。本調査では確定していない
  ため、本文では数を挙げていない

なお `e0105n.nrf.xml` (清浄道論序説) と `e0701n.nrf.xml`
(Cūḷaganthavaṃsapāḷi) は CSCD 収録の後代の編纂物であり、註釈書本体と同じ
重みでは扱えない。上記でこれらに依拠した箇所は伝承として読む必要がある。
