# 関係代名詞と相関詞・先行詞の間で、格・性・数・人称が一致しないことはあるか

関係代名詞 (`ya-`) と、それを受ける相関詞 (`ta-` など) や先行する名詞との間で、格が一致しないことは普通にある。性と数は一致するのが原則だが、一致しない文も本文 (mūla) に実在する。確認できた不一致は次の型にまとまる。

- 格: それぞれの節の中での働きで決まるので、そろわないことは通常の範囲である
- 性と数 (1): 相関詞の位置に立つ指示代名詞が、関係詞ではなく述語の名詞の性・数に合う型 (男性の `Yo … rāgakkhayo …` を中性の `idaṃ` で受けて涅槃の定義とする文など)
- 性と数 (2): 中性単数の `yaṃ` が特定の名詞を受けず、接続詞や副詞のように使われる型 (`so samayo yaṃ …`、`yadidaṃ`)
- 性と数 (3): 中性単数の `yaṃ` が男性や複数の語を指していて、註釈書が性や数の入れ替わり (`liṅgavipallāsa`、`vacanavipallāsa`) と説明する型
- 数: 単数の関係詞を並べて複数の相関詞でまとめる型、並列した二つの名詞を単数の関係詞で受ける型
- 人称: 関係代名詞に人称の形はないが、`yohaṃ`、`ye mayaṃ` のように人称代名詞を伴うと、関係節の動詞は 1 人称になる

以下、原則と、それぞれの型の用例を示す。用例はすべて CSCD の本文で確認したものである。

## 格は節ごとに決まる

関係詞と相関詞は同じものを指すが、格はそれぞれが属する節の中での働きで決まる。働きが同じならそろい、違えばそろわない。

```
Yo kho, vakkali, dhammaṃ passati so maṃ passati
```

相応部蘊篇、VRI 段落番号 87 (CSCD `s0303m.mul.xml`)。`yo` も `so` も各節の主語で、どちらも主格である。

```
Ye dhammā hetuppabhavā, tesaṃ hetuṃ tathāgato āha
```

律の大品、VRI 段落番号 60 (CSCD `vin02m2.mul.xml`)。`ye` は主格 (関係節の主語)、`tesaṃ` は属格 (「それらの」原因) である。

```
Yassa pāraṃ apāraṃ vā, pārāpāraṃ na vijjati;
Vītaddaraṃ visaṃyuttaṃ, tamahaṃ brūmi brāhmaṇaṃ.
```

ダンマパダ 385。`yassa` は属格 (「その人には」ない)、`taṃ` は対格 (`brūmi` の目的語) である。

`yena … tena`、`yattha … tattha`、`yadā … tadā`、`yathā … tathā` のような副詞的な相関の組では形がそろう。両方の節で同じ副詞の働きをするからである。

## 性と数は一致するのが原則

関係詞と相関詞・先行詞は同じものを指すので、性と数は一致するのが原則である。上の三例でも、`yo … so` (男性単数)、`ye … tesaṃ` (男性複数)、`yassa … taṃ` (男性単数) と、格は違っても性と数はそろっている。

Duroiselle の文法書は一致の規則を次のように述べる (§592)。

> The relative must agree with its antecedent in gender, number and person.

以下の節で挙げるのは、この原則どおりになっていない文である。

## 相関詞が述語の名詞に合う型

定義や言い換えの文では、関係節を受ける指示代名詞 (`idaṃ`、`ayaṃ`、`taṃ`) が、関係詞の性・数ではなく、後に来る述語の名詞の性・数に合うことがある。

```
Yo kho, āvuso, rāgakkhayo dosakkhayo mohakkhayo – idaṃ vuccati
nibbāna’’nti.
```

相応部六処篇、VRI 段落番号 314 (CSCD `s0304m.mul.xml`)。「友よ、貪りの尽きること、怒りの尽きること、愚かさの尽きること、これが涅槃と言われる」。`yo` は男性 (`rāgakkhayo` に合う)、`idaṃ` は中性 (`nibbānaṃ` に合う) である。

```
yo tattha chandarāgo, taṃ tattha saṃyojanaṃ
```

相応部蘊篇、VRI 段落番号 120 (CSCD `s0303m.mul.xml`)。`yo` は男性 (`chandarāgo`)、`taṃ` は中性 (`saṃyojanaṃ`) である。

```
Yaṃ kho, bhikkhave, ime pañca kāmaguṇe paṭicca uppajjati sukhaṃ
somanassaṃ – ayaṃ kāmānaṃ assādo.
```

MN 13、VRI 段落番号 166 (CSCD `s0201m.mul.xml`)。`yaṃ` は中性 (`sukhaṃ somanassaṃ`)、`ayaṃ` は男性 (`assādo`) である。

数についても同じことが起こる。複数の語を並べた関係節を、述語の名詞に合わせて単数で受ける例がある。

```
yaṃ etasmiṃ antare etthāvacarā ettha pariyāpannā khandhadhātuāyatanā
rūpā vedanā saññā saṅkhārā viññāṇaṃ – ayaṃ vuccati ‘‘kāmadhātu’’.
```

Vibhaṅga、VRI 段落番号 182 (CSCD `abh02m.mul.xml`)。`ayaṃ` は女性単数で `kāmadhātu` に合う。同じ関係節を Dhammasaṅgaṇī の VRI 段落番号 1287 は `ime dhammā kāmāvacarā` と複数で受けている。受ける側の形は述語の名詞によって変わる。

Duroiselle は主語と述語の一致について、述語が名詞のときは性と数の一致が要らないと述べる (§590 (4))。

> But if a substantive stands in the place of a verb, no such concord of gender or number needs take place

この型はその規則に沿ったものと見られる (これは筆者の推論)。指示代名詞を述語の名詞に合わせることは必須ではなく、関係詞と同じ性のままにする例もある。

```
Yadaniccaṃ taṃ dukkhaṃ; yaṃ dukkhaṃ tadanattā
```

相応部蘊篇、VRI 段落番号 15 (CSCD `s0303m.mul.xml`)。後半の `tad` は中性のままで、述語の `anattā` (男性名詞) の性には合わせていない。

## 中性単数の yaṃ が特定の名詞を受けない型

中性単数の `yaṃ` は、特定の名詞を受けずに「〜ということ」「〜する時」といった接続詞や副詞の働きをすることがある。この場合、前にある名詞と性が合わなくても不一致とは言えない。

```
Hoti kho so, āvuso, samayo yaṃ bāhirā āpodhātu pakuppati.
```

MN 28、VRI 段落番号 302、303 (CSCD `s0201m.mul.xml`)。「友よ、外の水界が乱れる時がある」。`samayo` は男性だが、それを説明する節は `yaṃ` で導かれている。

Duroiselle は関係代名詞の特別な用法としてこれを挙げる (§607 (iii))。

> The Neut. Sing. yaṃ is frequently used adverbially in the sense of "as; that, because, since, seeing that, If, when"

PTSD の `ya˚` の項も、中性の `yaṃ` を代名詞としての用法と別に立て、"so that"、時を表す "when, since, after"、条件や理由を表す "if, even if, because" の働きを挙げている。

`yadidaṃ` (すなわち) も、前後の語の性や数にかかわらずこの形のまま使われる。

```
sāmīcippaṭipanno bhagavato sāvakasaṅgho, yadidaṃ cattāri purisayugāni,
aṭṭha purisapuggalā.
```

MN 7、VRI 段落番号 74 (CSCD `s0201m.mul.xml`)。前の `sāvakasaṅgho` は男性単数、後の `cattāri purisayugāni` は中性複数、`aṭṭha purisapuggalā` は男性複数だが、`yadidaṃ` は中性単数の形のままである。PTSD は `yadidaṃ` を "viz."、"i. e." などと訳せると説明する。

具格の `yena` (〜の方に、それによって) や従格の `yasmā` (〜なので) も、副詞として使われる格の形であり、特定の名詞の性・数に合わせるものではない (Duroiselle §607 (iv)-(vi))。

## 註釈書が性や数の入れ替わりと説明する型

以下は註釈書と復註の説明である。中性単数の `yaṃ` が、文脈上は男性や複数の語を指している箇所について、註釈書は `liṅgavipallāsa` (性の入れ替わり)、`vacanavipallāsa` (数の入れ替わり) という言い方で説明する。ただし MN 2、Dhammasaṅgaṇī の VRI 段落番号 30、Vibhaṅga の VRI 段落番号 650、Jātaka 45 の偈については、不一致を立てない別の読み方が `vā` や `atha vā` で並べられている。これらは他師の説 (`vadanti`) としてではなく、註釈書自身の別案として示されている。`yaṃ etasmiṃ antare` の句と Paṭisambhidāmagga の偈については、別の読み方は示されていない。

### yaṃ が複数の語を指す例

```
yaṃ etasmiṃ antare etthāvacarā ettha pariyāpannā khandhadhātu āyatanā,
rūpaṃ vedanā saññā saṅkhārā viññāṇaṃ – ime dhammā kāmāvacarā.
```

Dhammasaṅgaṇī、VRI 段落番号 1287 (CSCD `abh01m.mul.xml`)。`yaṃ` は単数だが、受けているのは `khandhadhātu āyatanā` 以下の複数の語で、まとめる側も `ime dhammā` と複数である。

Dhammasaṅgaṇī の註釈書は `yaṃ` を複数の `ye` に言い換える。

```
Yaṃ etasmiṃ antareti ye etasmiṃ okāse.
```

同じ句について Paṭisambhidāmagga の註釈書は、入れ替わりであると明言する。

```
Yaṃ etasmiṃ antareti ye etasmiṃ okāse. Yanti ca liṅgavacanavipallāso
kato.
```

「『yaṃ』は性と数の入れ替えがなされたものである。」

MN 2 にも同じ型がある。

```
Yañhissa, bhikkhave, cakkhundriyasaṃvaraṃ asaṃvutassa viharato
uppajjeyyuṃ āsavā vighātapariḷāhā, cakkhundriyasaṃvaraṃ saṃvutassa
viharato evaṃsa te āsavā vighātapariḷāhā na honti.
```

MN 2、VRI 段落番号 22 (CSCD `s0201m.mul.xml`)。`yaṃ` は単数で、後に続く `uppajjeyyuṃ āsavā` と相関詞 `te āsavā` は複数である。`yaṃ` が `āsavā` を指すと読めば、性と数が合わない。

中部の註釈書はこの `Yañhissa` について二つの読み方を並べる。

```
Yañhissātiādimhi yaṃ cakkhundriyasaṃvaraṃ assa bhikkhuno asaṃvutassa
athaketvā apidahitvā viharantassāti evamattho veditabbo. Atha vā,
ye-kārassa yanti ādeso. Hikāro ca padapūraṇo, ye assāti attho.
```

第一の読み方は `yaṃ` を `cakkhundriyasaṃvaraṃ` にかけるもので、不一致は生じない。第二の読み方 (`atha vā`) は、`ye` の代わりに `yaṃ` が置かれたとするものである。中部の復註はこの第二の読み方を次のように説明する。

```
Yanti ādesoti iminā liṅgavipallāsena saddhiṃ vacanavipallāso katoti
dasseti, nipātapadaṃ vā etaṃ paccattaputhuvacanatthaṃ.
```

「『yaṃ は代置である』という言葉で、性の入れ替えとともに数の入れ替えがなされたことを示す。あるいは、これは主格複数の意味の不変化詞である。」

### yaṃ が男性の語を指す例

```
Katamaṃ tasmiṃ samaye hiribalaṃ hoti? Yaṃ tasmiṃ samaye hirīyati
hiriyitabbena hirīyati pāpakānaṃ akusalānaṃ dhammānaṃ samāpattiyā –
idaṃ tasmiṃ samaye hiribalaṃ hoti.
```

Dhammasaṅgaṇī、VRI 段落番号 30 (CSCD `abh01m.mul.xml`)。註釈書は `yaṃ` に二つの読み方を示す。

```
yaṃ tasmiṃ samayeti yena dhammena tasmiṃ samaye. Liṅgavipallāsaṃ vā
katvā yo dhammo tasmiṃ samayetipi attho veditabbo.
```

第一は `yaṃ` を具格の意味 (`yena dhammena`、その法によって) にとる読み方、第二は性を入れ替えて `yo dhammo` (その法が) にとる読み方である。

### 関係詞と相関詞の性が違う例

```
yaṃ vipulaṃ taṃ mahaggataṃ, yaṃ mahaggataṃ taṃ appamāṇaṃ, yaṃ appamāṇaṃ
so avero, yo avero so abyāpajjo.
```

Vibhaṅga、VRI 段落番号 650 (CSCD `abh02m.mul.xml`)。三つ目の対で `yaṃ` (中性) を `so` (男性) が受けている。註釈書は二つの説明を並べる。

```
Avero abyāpajjoti cettha liṅgavipariyāyena vuttaṃ. Manena vā saddhiṃ
yojanā kātabbā – yaṃ appamāṇaṃ cittaṃ, so avero mano; yo avero so
abyāpajjoti.
```

第一は性の入れ替わりとする説明、第二は `so avero` を男性名詞 `mano` にかけて読む説明である。第二の説明では、`yaṃ` は中性の `cittaṃ` に、`so` は男性の `mano` に合うことになり、それぞれの語は自分がかかる名詞と一致する。

### 偈の例

偈にも、註釈書が関係詞の性の入れ替わりと説明する箇所がある。

```
Seyyo amitto medhāvī, yañce bālānukampako;
```

Jātaka 45 (Rohiṇijātaka) の偈 (CSCD `s0513m.mul.xml`)。註釈書は `yaṃ` に二つの読み方を示す。

```
Yañce bālānukampakoti ettha yanti liṅgavipallāso kato, ceti nāmatthe
nipāto. Yo nāma bālo anukampako, tato sataguṇena sahassaguṇena paṇḍito
amitto hontopi seyyoyevāti attho. Atha vā yanti paṭisedhanatthe nipāto,
no ce bālānukampakoti attho.
```

第一は `yaṃ` を男性の `yo` の入れ替わりとし、`yo nāma bālo anukampako` (愚かで思いやりのある者) を指すとする読み方、第二 (`atha vā`) は `yaṃ` を否定の意味の不変化詞とする読み方である。

```
Pañcavīsati anattānupassanā, paññāsa aniccānupassanā;
Sataṃ pañcavīsati ceva, yāni dukkhe pavuccareti.
```

Paṭisambhidāmagga、Paññāvagga の Vipassanākathā、VRI 段落番号 39 (CSCD `s0517m.mul.xml`)。`yāni` は中性複数だが、指しているのは女性名詞の `anupassanā` である。註釈書は `yāni` を女性の `yā` に言い換え、性の入れ替わりとする。

```
Yāni dukkhe pavuccareti yā anupassanā dukkhe khandhapañcake gaṇanavasena
pavuccanti, tā sataṃ pañcavīsati cevāti sambandho veditabbo. ‘‘Yānī’’ti
cettha liṅgavipallāso daṭṭhabboti.
```

## 数が合わない型

単数の関係詞を二つ並べ、それを複数の指示代名詞でまとめる例がある。

```
Yo cāyaṃ kāmesu kāmasukhallikānuyogo hīno gammo pothujjaniko anariyo
anatthasaṃhito, yo cāyaṃ attakilamathānuyogo dukkho anariyo
anatthasaṃhito. Ete kho, bhikkhave, ubho ante anupagamma …
```

相応部大篇、VRI 段落番号 1081 (CSCD `s0305m.mul.xml`)。`yo … yo …` はそれぞれ単数、受ける `ete … ubho ante` は複数である。二つを足した数で受けているので、指すものの数と食い違ってはいない。

逆に、`ca` で並べた二つの名詞を単数の関係詞と相関詞で受ける例もある。

```
Yo vo, ānanda, mayā dhammo ca vinayo ca desito paññatto, so vo
mamaccayena satthā.
```

DN 16、VRI 段落番号 216 (CSCD `s0102m.mul.xml`)。`dhammo ca vinayo ca` は二つだが、`yo … so` も `desito paññatto` も `satthā` も単数である。

中性単数の `yaṃ` が複数の語を指す例は、前の節に挙げた。

## 人称

関係代名詞そのものには人称による形の区別がない。1 人称の代名詞を伴う `yohaṃ` (`yo ahaṃ`)、`ye mayaṃ` では、関係節の動詞が 1 人称になる。

```
yohaṃ pitaraṃ dhammikaṃ dhammarājānaṃ issariyakāraṇā jīvitā voropesiṃ
```

DN 2、VRI 段落番号 250 (CSCD `s0101m.mul.xml`)。「法にかなった法王である父の命を、王権のために奪った私」。動詞 `voropesiṃ` は 1 人称単数である。

```
lābhā no āvuso, suladdhaṃ no āvuso, ye mayaṃ āyasmantaṃ tādisaṃ
sabrahmacāriṃ passāma
```

DN 29、VRI 段落番号 181 (CSCD `s0103m.mul.xml`)。動詞 `passāma` は 1 人称複数である。

Duroiselle が一致の項目に person を含めている (§592) のは、このように関係節の動詞が先行詞の人称に従うことを指すと見られる (これは筆者の推論)。

## 確認できていない範囲

- 不一致の用例は、註釈書が `liṅgavipallāsa`、`liṅgavipariyāya`、`liṅgabyattaya`、`vacanavipallāsa`、`vacanabyattaya`、`vacanavipariyāya` と呼ぶ箇所の検索と、定義文の定型からたどったものである。本文全体を対象に不一致を数え上げたものではなく、上の型で尽きているかどうかは確かめていない
- 註釈書の検索結果 93 件 (上の六語のいずれかを含む段落の数。ここでの段落は XML の `p` 要素) はすべて見た。関係詞に関わらない箇所 (名詞や形容詞の性・数の入れ替わり) が大半で、関係詞とそれが指す語との不一致を言う箇所は、上に挙げた Dhammasaṅgaṇī-aṭṭhakathā、Vibhaṅga-aṭṭhakathā、Jātaka-aṭṭhakathā の各 1 件と Paṭisambhidāmagga-aṭṭhakathā の 2 件であった
- 偈では韻律のために性や数が入れ替わることがあるが、関係詞に限った偈の用例は、上の検索で見つかった二例のほかは調べていない
- 文法書は Duroiselle だけを確認した。Warder、Geiger、Oberlies などの記述は照合していない
- サンスクリットの文法で言う、代名詞が述語の名詞に引かれて性を変える現象との対応は検討していない
