# upanissāya viharati の「依って住む」は何を意味するか

MN 81 Ghaṭikārasutta §282 の次の文で、対訳は upanissāya vihāsi を
「依って住んでいた」と訳している。

```
Vegaḷiṅgaṃ kho, ānanda, gāmanigamaṃ kassapo bhagavā arahaṃ sammāsambuddho
upanissāya vihāsi.
```

この「依って」は「頼って、寄りかかって」の意味であり、文全体としては
「ヴェーガリンガの町を生活の拠点にして、その近くに住んでいた」ことを言う。
町の中に住んだのではなく、托鉢や四資具をその町に頼りながら、町の近くの
園林に住んだという意味である。律の語義分析と註釈はこの読みで一致しており、
直後の原文 (Idha sudaṃ ... ārāmo ahosi「ここにカッサパ世尊の園があった」) も
これを裏づける。

一方、同じ upanissāya viharati が人 (師) や法を目的語に取るときは
「師に身を寄せて、師の指導のもとで暮らす」「法を支えとして暮らす」の意味に
なる。場所を目的語とする MN 81 の用法とは区別して訳す必要がある。

## 1. upanissāya の語義

upanissāya は upa-ni-√śri (寄りかかる、頼る) に由来する動詞 upanissayati の
連続体 (absolutive) で、ほぼ前置詞のように対格 (まれに属格) を取る。

辞書の記述は次のとおり。

| 辞書 | 記述 |
|---|---|
| DOP (upanissayati の項) | 動詞は goes near to; clings to, depends upon。連続体 upanissāya は going near to; depending on; near (+ acc. or gen.) とし、用例に MN 81 §282 のこの文 (M II 45) を挙げる |
| PTSD (Upanissāya) | near, close by (with acc.); depending on, by means of (acc.) |
| CPD (upa-ni-ssāya) | 用法を二つに分ける。1. 動詞的な意味 clinging to, depending on, relying on。2. 対格の後に置かれ viharati などの動詞に続く後置詞で in, at, near, with (person)。2 の用例の筆頭に Vin III 70 = D II 119 = S V 321 の「bhikkhū Vesāliṃ upanissāya viharanti」を挙げ、MN 81 のこの文 (M II 45) もその用例に含める |

DOP と CPD がともに「近くに (near)」と「頼って (depending on)」の両方を
挙げ、しかも MN 81 のこの文を「場所 + viharati」の用例に選んでいることが、
以下の読みの出発点になる。CPD が「対格 + upanissāya + viharati」を独立した
後置詞用法として立てている点も、この句が定型句であることを示している。

## 2. 場所を目的語とするときの意味

CSCD の本文 (mūla) で upanissāya の直後に vihar- が続く段落を全文検索で
数えると 100 件 (律蔵 9、長部 5、中部 40、相応部 9、増支部 36、小部 1) で
あり、目的語を見るといずれも場所・物を取るもの (本節) か人・法を取るもの
(第 3 節) である。アオリスト vihāsi の形 (MN 81 §282 のほか SN 6.14、
AN 4.21、AN 5.180) はこの数に含めていない。

### 律の語義分析

原文 (律蔵) 自身が与えている定義が最も直接的である。Pārājikapāḷi の
僧残 13 (kuladūsaka 条) の語義分析 (padabhājanīya) は、学処本文の
「aññataraṃ gāmaṃ vā nigamaṃ vā upanissāya viharati (ある村または町に
依って住む)」を次のように定義する。

```
Upanissāya viharatīti tattha paṭibaddhā honti
cīvarapiṇḍapātasenāsanagilānappaccayabhesajjaparikkhārā.
```

「依って住むとは、そこに衣・托鉢食・住処・病の薬という資具が結びついて
いることである」。つまり「依って」の内容は、生活の四資具をその村や町から
得ていることである。これは原文 (律蔵本文) の記述であり、註釈の解釈ではない。

律註 (Samantapāsādikā) はこの語義分析の upanissāya viharati に語釈を置いて
いない。波羅提木叉の註釈 Kaṅkhāvitaraṇī は僧残 13 のこの句を次のように
言い換え、律の語義分析と同じ理解を示す。

```
Upanissāya viharatīti tattha paṭibaddhacīvarādipaccayatāya taṃ nissāya vasati.
```

「依って住むとは、衣などの資具がそこに結びついているために、そこを頼りに
して住むことである」。

### 註釈の読み

註釈は、場所を目的語とする upanissāya に対して二つの説明を与えている。
以下はいずれも註釈 (aṭṭhakathā) と復註 (ṭīkā) の記述である。

1. 距離としての説明。「yāvatikā bhikkhū vesāliṃ upanissāya viharanti
   (ヴェーサーリーに依って住む比丘たちすべて)」という文は律蔵 Pārājika 3 の
   因縁譚 (Vin III 70)、SN 54.9 Vesālīsutta (S V 321)、DN 16
   Mahāparinibbānasutta (D II 119) に共通して現れる。律註 (Samantapāsādikā)
   はこれを次のように言う。

   ```
   vesāliṃ upanissāyāti vesāliṃ upanissāya samantā gāvutepi addhayojanepi
   yāvatikā bhikkhū viharanti, te sabbe sannipātehīti attho
   ```

   相応部註 (Sāratthappakāsinī) も語形の細部 (vesāliyaṃ upanissāya、
   aḍḍhayojanepi、bhikkhū を欠く) を除いて同じ説明である。

   「ヴェーサーリーの周囲 1 gāvuta ないし半 yojana のうちに住む比丘たち」。
   町の中ではなく、町を中心とした一定の範囲内に住んでいることを指す。

2. 托鉢の村としての説明。同じ箇所の復註 (Sāratthadīpanī、Mahāvaggaṭīkā)
   は端的に次のように言う。

   ```
   Vesāliṃ upanissāyāti vesālīnagaraṃ gocaragāmaṃ katvā.
   ```

   「ヴェーサーリーの町を gocaragāma (托鉢に行く村) にして」。これは
   註釈が経の冒頭定型「X-yaṃ viharati Y-e (X の町に住む、Y 園に)」を
   説明するときに繰り返し使う言い方 (taṃ nagaraṃ gocaragāmaṃ katvā) と
   同じであり、upanissāya viharati と「X の町に住む」の定型が同じ事態を
   指すと註釈が見ていることが分かる。gocaragāmaṃ katvā の句は CSCD の註釈
   (aṭṭhakathā) 全体で 17 段落にあり、長部註 6、中部註 6、相応部註 2、
   増支部註 1、ウダーナ註 2 と各部に広がる。

   相応部註が Gayā の例で「gayāya avidūre niviṭṭhagāmaṃ upanissāyāti attho
   (ガヤーから遠くないところにある村に依って、の意)」と言うのも同じ趣旨で
   ある。

### 経の冒頭定型との関係

長部註 (Sumaṅgalavilāsinī) は、経の冒頭定型「X-yaṃ viharati Y-e (X に住む、
Y 園に)」を説明するときに、X を upanissāya で言い換える。

```
Sāvatthiyaṃ viharati jetavane anāthapiṇḍikassa ārāmeti sāvatthiṃ upanissāya
yo jetassa kumārassa vane anāthapiṇḍikena gahapatinā ārāmo kārito, tattha
viharati.
```

(DN 9 Poṭṭhapādasutta 註)「サーヴァッティーを upanissāya して、ジェータ
王子の林にアナータピンディカ長者が造った園、そこに住む」。DN 6 の註でも
「bhagavā taṃ vesāliṃ upanissāya tasmiṃ saṅghārāme viharati. Tena vuttaṃ
'vesāliyaṃ viharati mahāvane kūṭāgārasālāya'nti」と、同じ言い換えで
処格の町名を説明している。同じ言い換えは中部註 (MN 90 Kaṇṇakatthalasutta
註 §375「bhagavā uruññānagaraṃ upanissāya viharati」) と相応部註 (SN 4.1
註 §137「uruvelāyaṃ viharatīti ... uruvelagāmaṃ upanissāya viharati」) に
もある。

DN 2 Sāmaññaphalasutta 註はさらに踏み込んで、園の名が何を示すかを言う。

```
Jīvakassa komārabhaccassa ambavaneti idamassa yaṃ gocaragāmaṃ upanissāya
viharati, tassa samīpanivāsanaṭṭhānaparidīpanaṃ.
```

「『ジーヴァカ・コーマーラバッチャのマンゴー林に』とは、世尊が upanissāya
して住んでいる gocaragāma (王舎城) の近くの居住場所を示したものである」。
ここでは upanissāya の目的語が gocaragāma そのものであり、「依る」の内容が
托鉢の村であることが註の言葉で明示されている。

DN 21 Sakkapañhasutta 註 (§344) は「kahaṃ nu kho bhagavā etarahi viharati」
の説明で「kataraṃ nagaraṃ upanissāya kassa paccaye paribhuñjanto ... viharati
(どの町に依って、誰の資具を受けて住んでいるのか)」と言い、「依る」と
「資具を受ける」を並べている。律の語義分析 (四資具がそこに結びつく) と
同じ理解である。

### 森や自然物を目的語とする例

MN 17 Vanapatthasutta の「aññataraṃ vanapatthaṃ upanissāya viharati (ある
森林に依って住む)」を中部註は次のように言い換える。

```
manussūpacārātikkantaṃ vanasaṇḍasenāsanaṃ nissāya samaṇadhammaṃ karonto
viharati
```

「人の往来を離れた森の住処を nissāya して (頼りにして) 沙門の務めを
行いながら住む」。ここでは upanissāya を単純形の nissāya で置き換えている。

律蔵の譬喩では「dve bhātaro isayo gaṅgaṃ nadiṃ upanissāya vihariṃsu (二人の
兄弟の仙人がガンガー河に依って住んでいた)」「mahānigrodho ... taṃ tayo sahāyā
upanissāya vihariṃsu (大きなニグローダ樹に三匹の友が依って住んでいた)」
「mahāsarasī. Taṃ nāgā upanissāya vihariṃsu (大きな湖に象たちが依って住んで
いた)」のように、河・樹・湖を生活の拠点として「そのそばに住む」用法がある。
清浄道論の露地住 (abbhokāsika) 頭陀支でも、厳格な行者は「rukkhaṃ vā pabbataṃ
vā gehaṃ vā upanissāya vasituṃ na vaṭṭati (樹や山や家に依って住んではなら
ない)」と言い、ここでの upanissāya は雨風を避ける物理的な「そば」を指す。

これらを合わせると、場所や物を目的語とする upanissāya viharati は
「それを生活の支えにして、そのそばに住む」ことであり、「近くに」と
「頼って」は別々の意味ではなく一つの事態の二つの側面である。

## 3. 人や法を目的語とするときの意味

同じ句が人を目的語に取る用法は、場所の場合とは訳し分けが要る。

- 師を目的語とするもの。「satthāraṃ upanissāya viharati aññataraṃ vā
  garuṭṭhāniyaṃ sabrahmacāriṃ (師に、あるいは師に相当する同梵行者に依って
  住む)」(DN 34、AN 8.2 など)。「sakkatvā garuṃ katvā upanissāya viharati
  (敬い重んじて依って住む)」(MN 77、SN 6.2、AN 4.21 など) も同じ。
  これは「師に身を寄せ、その指導のもとで暮らす」ことで、律の
  nissaya (依止。新参比丘が師のもとで暮らす制度) と同系の意味である。
- 法や徳目を目的語とするもの。「appamādaṃ upanissāya (不放逸に依って)」
  (SN 3.17)、「pañca sekhabalāni upanissāya viharati (五つの有学の力に依って
  住む)」(AN 4.163)、「dhammaññeva sakkatvā garuṃ katvā upanissāya
  vihariṃsu (法のみを敬い重んじて依って住んだ)」(SN 6.2)。これは「それを
  支えとして」の意味である。

人や法の場合は「近くに」の含みは薄れ、「頼る、支えとする」が前面に出る。
長部註は DN 34 の「satthāraṃ upanissāya viharati」に関連して
「garubhāvanīyañhi upanissāya viharato kilesā nuppajjanti ovādānusāsaniṃ
labhati (尊敬すべき人に依って住む者には煩悩が起こらず、教誡と教示を得る)」
と言い、師に依ることの内容を「教えを受けること」としている。

## 4. MN 81 §282 への当てはめ

§282 の文は町 (gāmanigamaṃ) を目的語とするので、第 2 節の用法である。
原文の続きがそれを裏づける。

```
Idha sudaṃ, ānanda, kassapassa bhagavato arahato sammāsambuddhassa ārāmo
ahosi. Idha sudaṃ, ānanda, kassapo bhagavā arahaṃ sammāsambuddho nisinnako
bhikkhusaṅghaṃ ovadati.
```

世尊が微笑した「この場所 (imasmiṃ padese)」は街道から脇に入った地点で
あり、そこに Kassapa 仏の園 (ārāma) があった、と言っている。つまり
Kassapa 仏が住んだのは町の近くの園であり、町は托鉢の拠点である。
「ヴェーガリンガの町に依って住んでいた」は「ヴェーガリンガの町を拠点に
して (その近くに) 住んでいた」の意味で読む。同じ型の文は SN 6.14 (Sikhī 仏と
Aruṇavatī 王都) と AN 5.180 (Kassapa 仏と過去にあった町) にもある。

中部註 (Papañcasūdanī) は MN 81 のこの文に対して upanissāya の語釈を
置いていない (CSCD で確認)。

## 5. 訳語の検討

### 現状

本リポジトリの対訳では upanissāya viharati の訳が箇所ごとに揺れている
(いずれも対訳 md を読んで確認)。

| 箇所 | 目的語 | 訳 |
|---|---|---|
| MN 81 §282 | 町 | 〜の町に依って住んでいた |
| MN 55 §53 | 村または町 | 〜を依りどころにして住んでいる |
| MN 55 §54 | 村または町 | 〜の近くに依って住む |
| MN 77 §238-§242 | 師 (人) | 〜に依って住んでいる / 〜を依りどころとして暮らして / 〜に依って住して / 〜に依りついて住む |

### 「依って」の問題

`docs/translation_terms.md` には nissāya / nissita / āgamma の訳として
「頼りに / 依存 / 縁として」を使い「依って」は避ける、という既決の方針が
ある。理由は本ノートの冒頭の疑問そのものである。「〜に依って」は現代語では
「〜によって (手段・原因)」と読まれやすく、「〜に寄りかかって、〜を頼りに
して」の意味が伝わらない。upanissāya は nissāya の強調形であり、同じ方針が
及ぶと考えるのが自然である。

したがって MN 81 §282 の「依って住んでいた」は校閲上の指摘対象になる。
改訂するかどうか、またどの訳語にするかはユーザの判断に委ねる。

### 候補の比較

場所を目的語とする場合 (MN 81 §282、MN 55 §53-54):

| 候補 | 評価 |
|---|---|
| 〜を拠りどころにして住む | 「頼る」の意味が出る。MN 55 §53 の「依りどころにして」と同系で、translation_terms.md の方針 (所依・依止 → 依りどころ) にも沿う |
| 〜の近くに住む | 註の説明 (gāvuta 以内、gocaragāma) に合い平易だが、「頼る」の含みが落ちる。語釈行で補えば可 |
| 〜を拠点にして住む | 意味は正確だが、仏典の文脈でやや現代的な響きがある |
| 〜に依って住む | 現状の訳。「によって」との混同を招くため、方針上は避ける |
| 〜に依存して住む | 「依存」は否定的な含みが強く、仏が町に「依存」したという表現は不自然 |

人を目的語とする場合 (MN 77 など) は「〜を頼りにして暮らす」「〜に身を
寄せて暮らす」が候補になる。「身を寄せる」は translation_terms.md で bhajati
の訳としても使われており、師との関係を表すのに合う。
