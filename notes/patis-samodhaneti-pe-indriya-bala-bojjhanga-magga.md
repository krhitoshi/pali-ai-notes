# 無礙解道 §168 の `…pe…` と「根・力・覚支・道・法」の五項

無礙解道 (Paṭisambhidāmagga) 出入息念論 §168 の次の一文にある `…pe…` で何が省略されているのか、また `indriya – bala – bojjhaṅga – magga` という組み合わせが三十七菩提分法とどう関係するのかを扱う。

```
168. Dīghaṃ assāsapassāsavasena cittassa ekaggataṃ avikkhepaṃ pajānanto
indriyāni samodhāneti, gocarañca pajānāti, samatthañca paṭivijjhati…pe…
maggaṃ samodhāneti, dhamme samodhāneti, gocarañca pajānāti, samatthañca
paṭivijjhati.
```

答えは次のとおり。

1. `…pe…` の中身は `balāni samodhāneti, gocarañca pajānāti, samatthañca paṭivijjhati; bojjhaṅge samodhāneti, gocarañca pajānāti, samatthañca paṭivijjhati` の 2 項である。全体は「根・力・覚支・道・法」の 5 項をそれぞれ 3 句セットで繰り返す定型で、その中間 2 項が落とされている
2. 「根・力・覚支・道」は三十七菩提分法の後半 4 グループで、残りの念処・正勤・神足は 5 項目の `dhamme samodhāneti` の展開の中に含まれる。この 4 グループは同じ心所 (信・精進・念・定・慧など) を働きの面から数え直したものという共通構造を持ち、註釈書や論蔵系の文献では一かたまりとして先に置く並びが定着している

## `…pe…` の中身

省略部分の復元は、直後に続く逐語解釈と、同じ定型を省略なしで書いた別箇所の 2 つから確定できる。

### 直後の逐語解釈が 5 項を順に説明している

§168 の直後の釈文は `X samodhānetīti kathaṃ X samodhāneti?` の形で、次の順に 5 項を説明する。

| 順 | 句 | 展開される内容 |
|---|---|---|
| 1 | `Indriyāni samodhānetīti` | 五根 (adhimokkha 信、paggaha 精進、upaṭṭhāna 念、avikkhepa 定、dassana 慧) |
| 2 | `Balāni samodhānetīti` | 五力 (不信・懈怠・放逸・掉挙・無明に対する不動 akampiya) |
| 3 | `Bojjhaṅge samodhānetīti` | 七覚支 |
| 4 | `Maggaṃ samodhānetīti` | 八正道 |
| 5 | `Dhamme samodhānetīti` | 諸法 (根・力・覚支・道・念処・正勤・神足・諦・止・観・止観・双運・三清浄・解脱・明・尽智・無生智・欲〜涅槃) |

2〜4 の各項の末尾には `Gocarañca pajānātīti…pe… tena vuccati – "samatthañca paṭivijjhatī"ti.` が付いており、各項が「X samodhāneti, gocarañca pajānāti, samatthañca paṭivijjhati」の 3 句セットで繰り返される構造であることが分かる。1 と 5 では `gocarañca pajānāti` と `samatthañca paṭivijjhati` の釈が全文で書かれている。

### 同じ定型を pe なしで書いた箇所

出入息念論の終盤、paṭinissaggānupassī (定棄随観) の節では、同じ定型を VRI 版が次のように表記している。

```
paṭinissaggānupassī assāsapassāsavasena cittassa ekaggataṃ avikkhepaṃ
pajānanto indriyāni samodhāneti gocarañca pajānāti samatthañca
paṭivijjhati; balāni samodhāneti… bojjhaṅge samodhāneti… maggaṃ
samodhāneti… dhamme samodhāneti gocarañca pajānāti samatthañca
paṭivijjhati.
```

ここから §168 の `…pe… maggaṃ samodhāneti, dhamme samodhāneti` は「根・(力)・(覚支)・道・法」の 5 項列挙の中間 2 項を落としたものと確認できる。

### 留保

- `maggaṃ samodhāneti` と `dhamme samodhāneti` の間にも本来は `gocarañca pajānāti, samatthañca paṭivijjhati` が入る (3 句セット構造から) が、VRI 本文はこれも省いて最後の 1 回にまとめている
- §169 (短息) 以降では `indriyāni samodhāneti…pe… tena vuccati – "samatthañca paṭivijjhatī"ti` とさらに短縮されており、§168 の全文がその参照元になっている

## 「根・力・覚支・道」と三十七菩提分法

### 三十七菩提分法の後半 4 グループ + 残りは「法」に含まれる

三十七菩提分法は四念処・四正勤・四神足・五根・五力・七覚支・八正道の 7 グループである。無礙解道の `indriya – bala – bojjhaṅga – magga` はその後半 4 グループにあたる。前半 3 グループが抜けているように見えるが、5 項目の `dhamme samodhāneti` の展開は次のように始まる。

```
Ādhipateyyaṭṭhena indriyāni samodhāneti, akampiyaṭṭhena balāni
samodhāneti, niyyānaṭṭhena bojjhaṅge samodhāneti, hetuṭṭhena maggaṃ
samodhāneti, upaṭṭhānaṭṭhena satipaṭṭhānaṃ samodhāneti, padahanaṭṭhena
sammappadhānaṃ samodhāneti, ijjhanaṭṭhena iddhipādaṃ samodhāneti
tathaṭṭhena saccaṃ samodhāneti, avikkhepaṭṭhena samathaṃ samodhāneti,
anupassanaṭṭhena vipassanaṃ samodhāneti, …
```

念処・正勤・神足はここに含まれる。つまり無礙解道の 5 項は「根・力・覚支・道 + (それらを含む) 諸法全体」という構成で、三十七菩提分法を別の順序で網羅した上に、諦・止観・清浄・解脱・涅槃まで足したものになっている。

「根・力・覚支・道・念処・正勤・神足・諦・止・観 …」というこの並びは、無礙解道冒頭の Ñāṇakathā にある abhiññeyya の列挙 (`indriyānaṃ ādhipateyyaṭṭho, balānaṃ akampiyaṭṭho, bojjhaṅgānaṃ niyyānaṭṭho, maggassa hetuṭṭho, satipaṭṭhānānaṃ upaṭṭhānaṭṭho …`) 以来、論全体で繰り返される無礙解道固有の定型である。経蔵本来の 37 の順序 (念処→正勤→神足→根→力→覚支→道) とは異なる。

### なぜこの 4 つが一組になるか (註釈の説明)

以下は註釈 (Paṭisambhidāmagga-aṭṭhakathā, Visuddhimagga) の説明であり、無礙解道本文自身がこの理由を述べているわけではない。

Paṭis-a と Vism は samādhi と paññā の分析で次のように述べる。

```
samādhi eko indriyabalabojjhaṅgamaggaṅgavasena catudhā ṭhito, paññā
tesaṃ catunnaṃ iddhipādakoṭṭhāsassa ca vasena pañcadhā
```

定は根・力・覚支・道支の 4 通りに立ち、慧はそれに神足の分を加えて 5 通りに立つ、という説明である。五根・五力・七覚支・八正道は、同じ心所 (信・精進・念・定・慧など) が別の働きの面 (ādhipateyya 主導 / akampiya 不動 / niyyāna 出離 / hetu 因) で数え直されたもので、4 グループが同一構造の変奏になっている。これに対して念処 (念のみ)・正勤 (精進のみ)・神足 (欲・心・精進・観の 4) は単一の法を数えるグループで、性格が異なる。

Paṭis-a はこの 4 つを `indriyādibodhipakkhiyadhammapaṭipāṭiyā indriyabalabojjhaṅgamaggaṅgānaṃ vasena` (根を初めとする菩提分法の順序で) と呼び、道の瞬間に現に存在するもの (`maggakkhaṇe vijjamānāni indriyabalabojjhaṅgamaggaṅgāni`) として扱っている。

### 他文献での出現

CSCD で `indriya-bala-bojjhaṅga-magga(ṅga)` の連続を検索して確認できた主な箇所。

| 文献 | 表現 | 備考 |
|---|---|---|
| Buddhavaṃsa (本文) | `Indriyabalabojjhaṅga-maggasaccappakāsanaṃ` | 註は「これらを挙げることで念処・正勤・神足も含まれる」と説明 |
| Milindapañha | `indriyabalabojjhaṅgamaggaṅgasatipaṭṭhānasammappadhānaiddhipādajhānavimokkha…` | 無礙解道と同じ「根・力・覚支・道 → 念処・正勤・神足」の順 |
| 諸註 (DN-a, MN-a, SN-a, AN-a, Vibh-a) | `khandhadhātuāyatanaindriyabalabojjhaṅgamaggaṅgajhānaṅgasamathavipassanānaṃ` | paripucchakatā (問いを重ねること) の説明での定型 |
| 諸註 (DN-a, MN-a, SN-a) | `iddhipādaindriyabalabojjhaṅgamaggaṅgasuttantahārako` | SN Mahāvagga の相応名の列挙 |
| Vism, Paṭis-a | `samādhi eko indriyabalabojjhaṅgamaggaṅgavasena catudhā ṭhito` | 上記の定・慧の分析 |

これらから、無礙解道やそれを継ぐ論蔵・註釈系の文献では `indriya-bala-bojjhaṅga-magga(ṅga)` を一かたまりとして先に置く並びが定着していると言える。

## 確認できていない範囲

- 経蔵の本文 (mūla) で「根・力・覚支・道」の 4 つだけを取り出して一組にする用例は今回の検索では確認していない。上記の出現例は Buddhavaṃsa と Milindapañha を除き註釈書のものである
- 無礙解道の他の論 (Ñāṇakathā 以外) でこの 5 項定型が何回現れるかは数えていない
