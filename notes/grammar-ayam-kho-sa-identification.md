# ayaṃ kho sā — 意味の重なる ayaṃ と sā を並べる理由、sā sā にならない理由、kho が入る理由

MN 79 (Cūḷasakuludāyisutta) の `ayaṃ kho sā, udāyi, ākāravatī paṭipadā` の
ように、どちらも「これ / それ」と訳せる ayaṃ と sā が並ぶ句について。

- ayaṃ と sā は指す先が違う。sā は「先に名前だけ挙げた、例の」ものを指す
  照応の語で、ayaṃ は「いま述べたばかりの中身」を指す直示の語。二つで
  「(いま述べた) これが、(先に挙げた) その～である」という同定文を作る。
  註釈はこの句を「その道を結んで (nigamento) 述べた」と説明する
- sā sā と並べないのは、同定文には指し方の違う 2 語が要るからで、同じ
  照応の語を二つ並べても新しいものを結びつけられない。加えて同じ代名詞の
  繰り返し (`yaṃ yaṃ … taṃ taṃ`) は「それぞれの」という配分の意味に
  固定されている
- kho は前の語に付く付帯の小辞で、文頭の語の直後に置かれる規則により
  ayaṃ と sā の間に入る。註釈は kho を「限定強調 (avadhāraṇa) か、単に
  語を整える (padapūraṇa) か」の小辞と釈し、どちらかに決めていない

## ayaṃ と sā はなぜ一緒に使われるか

原文の構造から見ると、sā は先行する問いの sā をそのまま引き取っている。
MN 79 の VRI 段落 275 では、ウダーイが

```
Katamā pana sā, bhante, ākāravatī paṭipadā ekantasukhassa lokassa
sacchikiriyāyā’’ti?
```

と問う。この sā は、それより前に話題として挙がった ākāravatī paṭipadā
を指す。世尊は初禅から第三禅までを述べたうえで

```
ayaṃ kho sā, udāyi, ākāravatī paṭipadā ekantasukhassa lokassa
sacchikiriyāyā’’ti.
```

と結ぶ。ayaṃ は直前に述べた中身 (三つの禅) を指し、sā は問いにあった
「その道」を指す。全体は「いま述べたこれが、君の問うたその道である」と
いう同定文で、名前だけ先に出ていた項目と、いま示した内容を結びつける。

この型は定型句で、CSCD 本文を `ayaṃ kho sā` で検索すると、同じ形が繰り
返し現れる。いずれも先に名前を挙げた項目を、内容を述べたあとで結ぶ位置に
ある。

| 箇所 | 句 | 先に挙がっていた項目 |
|---|---|---|
| MN 3 Dhammadāyāda、SN 56.11、Vin Mahāvagga など | `ayaṃ kho sā, bhikkhave, majjhimā paṭipadā` | 冒頭で名を挙げた中道 |
| DN 3 Ambaṭṭha | `Ayaṃ kho sā, ambaṭṭha, vijjā` | 問われていた vijjā |
| SN 35.246 (琵琶の喩え) | `ayaṃ kho sā, bhante, vīṇā yassā eso saddo` | 話に出ていた音を出す琵琶 |
| MN 79 (VRI 段落 274、275) | `ayaṃ kho sā … ākāravatī paṭipadā` | 問われていた ākāravatī paṭipadā |

註釈もこの読みを示す。MN 3 の `ayaṃ kho sā, āvuso, majjhimā paṭipadā`
について Papañcasūdanī (Mūlapaṇṇāsa-aṭṭhakathā) は

```
Idāni ayaṃ kho sā, āvusoti tameva paṭipadaṃ nigamento āha.
```

(いま「ayaṃ kho sā, āvuso」と、まさにその道を結んで述べた) と釈す。
`tameva paṭipadaṃ` (まさにその道) という言い方が、sā が既出の同じ道を
指すことを示している。

ayaṃ + ta の組み合わせが同定を表すことは、他の註釈にも見える。

- DN 9 Poṭṭhapāda (VRI 段落 432-437) の `ayaṃ vā so, āvuso, oḷāriko
  attapaṭilābho` について、Sumaṅgalavilāsinī は `Ayaṃ soti evaṃ
  vibhāvetvā pakāsetvā byākareyyāma` (「これがそれだ」と明らかにして
  答える) と釈す
- Jātaka-aṭṭhakathā に `Ayaṃ soti ayameva so tava sabhāvo` (「ayaṃ so」
  とは、これこそがその君の性質だ、の意) とある
- ta と idaṃ が融合した tayidaṃ という語形があり、Ekakanipāta-ṭīkā
  (Manorathapūraṇī の復註) は `Tayidanti nipāto, tassa so ayanti attho`
  と、tayidaṃ = so ayaṃ と解する。組み合わせが一語化するほど定着している

サンスクリットの `so 'yam` / `eṣa saḥ` (既知のあれが、ここにいるこれだ)
と同じ型である。

## なぜ sā sā にならないか

同定文は「いま示した中身」と「既出の話題」という別々の対象を結ぶので、
指し方の違う 2 語が必要になる。sā を二つ並べると両方が「既出のもの」を
指すことになり、新しい内容を結びつける文にならない。

加えて、同じ代名詞の繰り返しには別の意味が固定されている。関係代名詞と
組んだ `yaṃ yaṃ … taṃ taṃ` は「～するものはどれでも、そのそれぞれを」と
いう配分の表現で、Visuddhimagga に多数の例がある。

```
yaṃ yaṃ iriyāpathaṃ icchati, taṃ taṃ karoti.
```

したがって `sā sā` と書けば、同定ではなくこの配分の読みに引かれる。

なお、ayaṃ を使わず `sā kho … paṭipadā` と書くこと自体は文として成り
立つが、それは「その道は～である」という叙述で、いま述べた内容を問いの
項目と同定する働きは持たない。

## kho が入る理由

kho は意味の上で ayaṃ と sā の関係を示す語ではなく、位置の規則で両者の
間に入る。

DoP は kho を、前の語を強調する付帯 (enclitic) の小辞で「しばしば単なる
埋め草 (merely expletive)」とし、特に代名詞の後に置かれる用法を挙げる
(`idaṃ kho pana`, `ayaṃ ca kho`, `so ca kho` など)。付帯語なので文頭の
語の直後に付き、その結果 `ayaṃ kho sā` の形になる。

註釈は kho の働きを二通りに釈す。Sumaṅgalavilāsinī (DN 1 の `assosi kho`)
と Papañcasūdanī (MN 4 の `atha kho`) に

```
Khoti avadhāraṇatthe padapūraṇamatte vā nipāto.
```

(kho とは、限定強調の意味か、単に語を整えるためかの小辞である) とあり、
限定強調 (avadhāraṇa) なら eva と同じ「まさに」、語を整えるため
(padapūraṇa) なら訳出は要らない、としている。DoP が引く Petavatthu 註は
`ayaṃ ca kho dakkhiṇā` の kho を avadhāraṇa と釈す。

`ayaṃ kho sā` の kho がどちらかを決める根拠は個々の文にはなく、註釈自身
が両案を併記している。対訳 mn/mn_079.md の語釈行「ayaṃ kho sā =
これこそがその～である」は、kho を avadhāraṇa (こそ) として訳した形で
ある。

## 確認できていない範囲

- `ayaṃ kho sā` の kho を直接釈した註釈は CSCD の検索では見つからなかった。
  上の avadhāraṇa / padapūraṇa の二分は、他の箇所の kho に対する註釈の
  一般的な説明を当てたもの
- `yo yo … so so` (男性) の形は CSCD 本文の検索では確認できず、配分の例
  として挙げたのは中性の `yaṃ yaṃ … taṃ taṃ` のみ
