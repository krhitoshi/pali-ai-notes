# MN の alaṃ: 文字どおり「十分だ・ふさわしい」の箇所と「もうよい」の箇所

MN 1, 32〜53, 55〜85, 118 の 55 経を調べると、alaṃ が「もうたくさんだ、やめろ」ではなく、文字どおり「十分だ・ふさわしい・〜するに足る」の意味で使われている箇所が多くある。もっとも分かりやすいのは、成道前の菩薩がウルヴェーラーの土地を見て思う *Alaṃ vatidaṃ kulaputtassa padhānatthikassa padhānāya*「ここは、精勤を求める良家の子が精勤するのに、実に十分な [場所] だ」(MN 36 §373、MN 85 §329) である。[場所] は idaṃ が指す直前の土地・林・川の描写から補った。一方、「もうよい・結構だ」の alaṃ は、申し出や問いを断る場面で文頭に立ち、呼格を伴うことが多い (MN 57、81、82、83)。

- **与格を伴う alaṃ は、どれも「〜に十分だ・ふさわしい」の意味である。** MN 36 §373 と MN 85 §329 の精勤の場所のほか、MN 82 の偈 *Alaṃ bālassa mohāya, no ca pāragavesino*「愚者を惑わすには十分だが、彼岸を求める者には [十分では] ない」、MN 72 §190 *Alañhi te, vaccha, aññāṇāya*「ヴァッチャよ、あなたが無知に陥るのも無理はない」がこれに当たる。Ps はこれらの alaṃ を samattha (できる)、pariyatta (足りる)、yutta (ふさわしい) で説明する。
- **否定形 nālaṃ と analaṃ は「十分ではない・値しない」の意味になる。** MN 37 の *sabbe dhammā nālaṃ abhinivesāya*「すべての法は執着するに値しない」、MN 76 §228 の七身説の *nālaṃ aññamaññassa sukhāya vā dukkhāya vā*「互いの楽にも苦にも役立たない」、MN 66 §156 の禅定について言う ‘*anala*’*nti vadāmi*「これは不十分だと私は言う」がある。
- **複合語の前の要素になった alam- も「十分な・能力のある」の意味を保つ。** MN 82 §306 の *alamatto*「十分な力量をそなえた [戦士]」、MN 36・65・85 の *alamariyañāṇadassanavisesa*「聖者にふさわしい殊勝な智見」がある。
- **「もうよい」の alaṃ は、断る・制止する場面に限られる。** 単独で文頭に立って呼格が続く形 (*Alaṃ, puṇṇa, tiṭṭhatetaṃ* など) が大半で、ほかに具格を伴う「〜はもうよい」(MN 82 §303 の *alaṃ dānajja uyyānabhūmiyā*「今日はもう遊園はよい」) と、h を添えた halaṃ (MN 36 §379、MN 85 §334・§337) がある。Ps はこれらを paṭikkhipati、paṭibāhati、paṭisedheti (退ける、拒む) で説明する。
- **構文だけでは決まらず、最後は場面で決まる。** 与格を伴えば「十分だ」、呼格を伴って単独で立てば「もうよい」とほぼ分かれる。ところが不定詞を伴う形は両方に現れる。MN 118 §146 では「〜しに行くに値する」、MN 85 §337 の *halaṃ dāni pakāsituṃ* では「今説く必要はない」の意味になる。具格を伴う MN 39 の *alamettāvatā* も、「これだけで足りている」という自己満足の言葉で、断りの言葉ではない。

## 調べた範囲と数え方

対象は MN 1、32〜53、55〜85、118 の 55 経の本文 (VRI 版、各 VRI 番号段落の本文) である。alaṃ を含む語形 (alaṃ、alañhi、alamidaṃ、nālaṃ、analaṃ、halaṃ、alam- で始まる複合語、analaṅkaritvā) を拾い、出現数を数えた。alaṅkaroti「飾る」とその派生語 (alaṅkata、alaṅkāra、MN 82 §300・§302 に出る) は、語源上は alaṃ を含むが「十分だ」とも「もうよい」とも別の意味になっているので除いた。

複合語・派生語の行のうち、MN 39 の alamettāvatā (9 回) と analaṅkaritvā (4 回) は、「十分」と「もうよい」の境目にある。

## 1. 与格・不定詞を伴う「十分だ・ふさわしい」

与格の名詞 (〜のために) や不定詞 (〜するのに) と結んだ alaṃ は、「〜に十分だ・ふさわしい」の意味になる。DOP は alaṃ の第 1 義を「enough, sufficient; adequate, equal to; competent, able; suitable, fit for」とし、人の属格・与格、事物の与格、不定詞と結ぶとする。

### MN 36 §373、MN 85 §329: 精勤の場所

菩薩がウルヴェーラーのセーナー村に着き、その土地を見て思う場面である。MN 36 ではアッギヴェッサナ (サッチャカ) に、MN 85 ではボーディ王子に語られる。

```
Alaṃ vatidaṃ kulaputtassa padhānatthikassa padhānāyā’ti. So kho ahaṃ, aggivessana, tattheva nisīdiṃ ‘alamidaṃ padhānāyā’ti.
```

本ノートで選んだ訳は「『ここは、精勤を求める良家の子が精勤するのに、実に十分な [場所] だ』と。アッギヴェッサナよ、その私は『ここは精勤するのに十分だ』と、まさにそこに坐った」である。kulaputtassa padhānatthikassa は人の与格 (属格)、padhānāya は事物の与格で、DOP の第 1 義の構文どおりである。[場所] は idaṃ が指す直前の描写から補った。

Ps は MN 26 の同じ文について *Alamidaṃ padhānāyāti idaṃ ṭhānaṃ padhānatthāya samatthanti evaṃ cintetvā nisīdinti attho*「『ここは精勤に十分だ』とは、『この場所は精勤のために足る』とこのように考えて坐った、という意味である」と説明する。MN 36 の註はこの箇所を MN 26 で述べたとおりだとしている。

### MN 82 §302: ラッタパーラの偈

ラッタパーラが、着飾らせた元の妻たちを前にして唱える偈である。3 つの偈が同じ後半句で結ばれる。

```
Alaṃ bālassa mohāya, no ca pāragavesino.
```

本ノートで選んだ訳は「愚者を惑わすには十分だが、彼岸を求める者には [十分では] ない」である。[十分では] は no ca の後に前半の alaṃ を補った。bālassa は人の属格・与格、mohāya は事物の与格である。対比があるので「十分」の意味がはっきり出る。CPD はこの偈 (Th 771〜773 と同じ) を「with gen. pers. & dat. rei (enough, able)」の例に挙げ、Th-a が samatthaṃ と説明することを示す。

### MN 72 §190: ヴァッチャへの答え

ヴァッチャゴッタが「解脱した比丘はどこに生まれるか」という問いへの答えを聞いて、混乱したと言う。これに対する答えである。

```
Alañhi te, vaccha, aññāṇāya, alaṃ sammohāya. Gambhīro hāyaṃ, vaccha, dhammo duddaso duranubodho santo paṇīto atakkāvacaro nipuṇo paṇḍitavedanīyo.
```

本ノートで選んだ訳は「ヴァッチャよ、あなたが無知に陥るのも無理はない、混乱に陥るのも無理はない。ヴァッチャよ、この法は深く、見がたく、悟りがたく、……」である。字義は「あなたにとって、無知に [陥るのに] 十分 [な事情がある]」である。続く文がその事情 (法が深いこと) を述べているので、「無理はない」と訳した。これは本ノートの推論で、alaṃ と与格の構文と、続く文の内容から組み立てた。Ps は *Alanti samatthaṃ pariyattaṃ*「alaṃ とは、できる、足りる」と説明する。DOP も第 1 義の用例にこの文 (M I 487) を挙げる。

### MN 118 §146: 見に行くに値する集まり

満月の夜、ブッダが黙して坐る比丘僧団をほめる言葉の一節である。

```
Tathārūpo ayaṃ, bhikkhave, bhikkhusaṅgho; tathārūpā ayaṃ, bhikkhave, parisā yathārūpaṃ parisaṃ alaṃ yojanagaṇanāni dassanāya gantuṃ puṭosenāpi.
```

本ノートで選んだ訳は「比丘たちよ、この比丘僧団はそのようなものである。比丘たちよ、この集まりは、旅の食糧袋を携えてでも、幾ヨージャナも [の道のりを] 見るために行くに値する、そのような集まりである」である。alaṃ は不定詞 gantuṃ と結んで「〜しに行くに値する」の意味になる。Ps は *Alanti yuttaṃ*「alaṃ とは、ふさわしい」と説明する。

## 2. 否定形 nālaṃ と analaṃ

na や an- で否定した形も、「十分だ・ふさわしい」の否定であり、「十分ではない・値しない・役立たない」の意味になる。

### MN 37: すべての法は執着するに値しない

サッカが、比丘はどのようにして渇愛を滅して解脱するのかと問い、ブッダが答える言葉である (§390。§394・§395 でモッガッラーナとの問答の中で繰り返される)。

```
Idha, devānaminda, bhikkhuno sutaṃ hoti – ‘sabbe dhammā nālaṃ abhinivesāyā’ti.
```

本ノートで選んだ訳は「神々の王よ、ここに比丘は『すべての法は執着するに値しない』と聞いている」である。Ps は *Te sabbepi taṇhādiṭṭhivasena abhinivesāya nālaṃ na pariyattā na samatthā na yuttā, kasmā? Gahitākārena atiṭṭhanato*「それらすべては、渇愛と見による執着に値せず、足りず、できず、ふさわしくない。なぜか。執着されたとおりの姿でとどまらないからである」と説明する。

### MN 76 §228: 七身説の記述

サンダカ経で、ある師の説 (七つの身が作られず不動であるという説) を紹介する文の一部である。

```
te na iñjanti na vipariṇamanti na aññamaññaṃ byābādhenti nālaṃ aññamaññassa sukhāya vā dukkhāya vā sukhadukkhāya vā.
```

本ノートで選んだ訳は「それらは動かず、変化せず、互いに害し合わず、互いの楽にも、苦にも、楽苦にも役立たない」である。Ps は *Nālanti na samatthā*「nālaṃ とは、できない」と説明する。互いに楽や苦を及ぼす力がない、という意味である。

### MN 66 §156: 禅定は不十分だ

ブッダがウダーイに、初禅から非想非非想処までの各段階について繰り返す言葉である (8 回)。

```
idaṃ kho ahaṃ, udāyi, ‘anala’nti vadāmi, ‘pajahathā’ti vadāmi, ‘samatikkamathā’ti vadāmi.
```

本ノートで選んだ訳は「ウダーイよ、私はこれを『不十分だ』と言い、『捨てよ』と言い、『超えよ』と言う」である。DOP は analaṃ を「not enough; not sufficient」とし、この文 (M I 455) を用例に挙げる。

Ps は二つの読みを並べる。先に *Analanti vadāmīti akattabbaālayanti vadāmi, taṇhālayo ettha na uppādetabboti dasseti*「analaṃ と言うとは、執着してはならないものだと言う、つまりここに渇愛の執着を起こしてはならないと示す」と、anala を an-ālaya (執着してはならない) に寄せて読む。続けて註自身の別案 (*atha vā*) として *analaṃ apariyattaṃ, na ettāvatā alametanti sanniṭṭhānaṃ kātabbanti vadāmi*「あるいは、analaṃ とは不十分ということで、これだけでこれは十分だと結論してはならない、と言う」と、alaṃ の否定として読む。本ノートは DOP と同じく後者の読みを採った。

## 3. 複合語・派生語の中の alam-

alam- が複合語の前の要素になっても、「十分な・能力のある・ふさわしい」の意味を保つ。

### MN 82 §306: alamatto (十分な力量のある)

ラッタパーラが、若いころのコーラビヤ王の力について問う言葉である。

```
‘‘Taṃ kiṃ maññasi, mahārāja, tvaṃ vīsativassuddesikopi paṇṇavīsativassuddesikopi hatthismimpi katāvī assasmimpi katāvī rathasmimpi katāvī dhanusmimpi katāvī tharusmimpi katāvī ūrubalī bāhubalī alamatto saṅgāmāvacaro’’ti?
```

本ノートで選んだ訳は「大王よ、どう思うか。あなたは二十歳のころも二十五歳のころも、象にも馬にも車にも弓にも剣にも熟達し、腿の力も腕の力もあり、十分な力量をそなえて戦場を行き来する者であったか」である。Ps は *Alamattoti samatthaattabhāvo*「alamatto とは、能力のある身をもつ者」と説明する。DOP は alamatta を alamattha「able, competent」の異読 (または誤記) とし、この箇所を alamattha の項に挙げる。PTSD も alamattha と読むよう注記する。どちらに読んでも「能力のある」の意味は変わらない。

### MN 36 §381、MN 65 §137・§138、MN 85 §335・§342: alamariyañāṇadassanavisesa

*uttari manussadhammā alamariyañāṇadassanavisesaṃ* の形で、苦行や修行によって得ようとする目標として現れる。MN 36 §381 と MN 85 §335 は、苦行の果てに菩薩が「この苦行では得られない」と思う場面、MN 85 §342 は五比丘が「あの苦行でも得られなかったのに」と菩薩を迎える場面、MN 65 は戒を満たさない比丘と満たす比丘を対比する場面である。

```
Na kho panāhaṃ imāya kaṭukāya dukkarakārikāya adhigacchāmi uttari manussadhammā alamariyañāṇadassanavisesaṃ.
```

本ノートで選んだ訳は「私はこの激しい苦行によっても、人間の法を超えた、聖者にふさわしい殊勝な智見を得ていない」である (MN 36 §381)。DOP は alam-ariya を「suitable for or worthy of the noble ones; truly noble」とする。Ps は MN 31 の同じ語を *ariyabhāvakaraṇasamattho ñāṇaviseso*「聖者の状態を作るに足る殊勝な智」と説明する。「聖者にふさわしい」と「聖者にするに足る」のどちらで取っても、alaṃ は「十分な・ふさわしい」の意味である。

## 4. 「十分」と「もうよい」の境目にある箇所

次の二つは、構文や註釈の説明のうえでは「もうよい」の側とつながりがある。それでも、文の中では「足りている・足りていない」という判断を表している。

### MN 39 §416〜424: alamettāvatā katamettāvatā

アッサプラ経で、修行の各段階 (慚と愧、身・口・意の行いの清浄、生活の清浄、感官の守護、食の節度、目覚めの努め、念と正知) を挙げるたびに繰り返される、比丘が陥りがちな考えである。

```
‘hirottappenamha samannāgatā, alamettāvatā katamettāvatā, anuppatto no sāmaññattho, natthi no kiñci uttariṃ karaṇīya’nti tāvatakeneva tuṭṭhiṃ āpajjeyyātha.
```

本ノートで選んだ訳は「『我々は慚と愧をそなえている。これだけで十分だ、これだけでなすべきことはなされた。我々は沙門の目的に到達した。これ以上なすべきことは何もない』と、それだけで満足してしまうかもしれない」である。

ettāvatā「これだけで」は具格の副詞である。CPD はこの句 (MN I 271 など) を、具格だけを伴う alaṃ の例として、MN 82 §303 の *alaṃ dānajja uyyānabhūmiyā*「今日はもう遊園はよい」と同じ群に並べる。構文の上では「これだけでもうよい」とも読める。しかし文の中では、続く「目的に到達した、これ以上なすべきことはない」と一組になって「これで足りている」という判断を表し、何かを断る言葉ではない。だからブッダは、そこで満足してはならないと戒める。Ps も MN 78 で *alamettāvatā, natthi ito kiñci uttari karaṇīyanti*「これだけで十分だ、これ以上なすべきことは何もない」を、戒に満足しきった者の考えの例として使う。

### MN 36 §371・§372、MN 85 §327・§328: analaṅkaritvā

菩薩がアーラーラ・カーラーマとウッダカ・ラーマプッタのもとを去る場面である。

```
So kho ahaṃ, aggivessana, taṃ dhammaṃ analaṅkaritvā tasmā dhammā nibbijja apakkamiṃ.
```

本ノートで選んだ訳は「アッギヴェッサナよ、その私は、その法を十分なものとせずに、その法に厭いて立ち去った」である。DOP は alaṅkaroti の否定の連続体 analaṅkaritvā を「thinking insufficient; not finding satisfaction in」とし、MN 26 の同じ文 (M I 165) を挙げる。本ノートの訳はこの説明によった。

一方 Ps は、MN 26 の同じ文について、CSCD 本では *Analaṅkaritvāti alaṃ iminā, alaṃ imināti punappunaṃ alaṅkaritvā*「analaṅkaritvā とは、『これはもうよい、これはもうよい』と繰り返し alaṃ と言って」と説明する。alaṃ iminā は具格を伴う「これはもうよい」の形で、Ps はここを断りの alaṃ で説明していることになる。DOP は同じ註の文を *punappunaṃ analaṅkaritvā* の形で引いており、註の本文に異読がある。どちらの説明でも、菩薩がその法に満足せずに去ったという文意は変わらない。

## 5. 「もうよい・結構だ」の alaṃ

DOP は alaṃ の第 2 義を「enough of, no more of, away with; there is no need of」(事物の具格または不定詞と結ぶ)、第 3 義を「(absolutely): enough! stop! don't!」とする。MN の調べた範囲では、この意味の alaṃ はすべて、相手の問いや申し出を断るか、自分の予定を取りやめる場面に出る。

| MN 82 §303 | *Alaṃ, mahārāja, nisīda tvaṃ; nisinno ahaṃ sake āsane* | 大王よ、結構です。あなたがお座りなさい。私は自分の座に座っています | ラッタパーラが王の勧める敷物を断る |
| MN 83 §313 | *Alaṃ, mārisa, tattheva maṃ mithilaṃ paṭinetu* | 友よ、結構です。私をそのままミティラーへ連れ戻してください | ニミ王が天に留まるようにというサッカの勧めを断る |

Ps はこれらの alaṃ を、断りの動詞で説明する。MN 57 では *Alanti tassa appiyaṃ bhavissatīti yāvatatiyaṃ paṭibāhati*「alaṃ とは、[答えが] 彼に好ましくないだろうと、三度まで退ける」、MN 82 §300 では *Alanti thero ukkaṭṭhaekāsanikatāya paṭikkhipanto evamāha*「alaṃ とは、長老が厳格な一坐食者であったので、断ってこう言った」とする。

### 具格を伴う形: MN 82 §303

コーラビヤ王が、遊園を清めに行かせたミガヴァから、そこにラッタパーラがいると聞いて言う言葉である。

```
‘‘Tena hi, samma migava, alaṃ dānajja uyyānabhūmiyā. Tameva dāni mayaṃ bhavantaṃ raṭṭhapālaṃ payirupāsissāmā’’ti.
```

本ノートで選んだ訳は「それなら、友ミガヴァよ、今日はもう遊園はよい。我々は今、あのラッタパーラ尊者のもとに参じよう」である。uyyānabhūmiyā は具格で、DOP は DN 14 の同じ句 (D II 23) を第 2 義の用例に挙げる。「遊園で足りた」のではなく、「遊園 [に行くこと] はもうやめる」という意味である。

### halaṃ: MN 36 §379、MN 85 §334・§337

halaṃ は alaṃ に h を添えた形である。CPD は alaṃ の項で、強めの形として halaṃ を挙げる。Ps も MN 26 で *Halanti ettha ha-kāro nipātamatto, alanti attho*「halaṃ において、ha の字はただの小辞で、意味は alaṃ である」と説明する。

MN 36 §379 と MN 85 §334 は、食をすべて断とうとする菩薩に、神々が「それなら毛穴から天の滋養を注ぎ込もう」と申し出る場面である。

```
So kho ahaṃ, aggivessana, tā devatā paccācikkhāmi, ‘hala’nti vadāmi.
```

本ノートで選んだ訳は「アッギヴェッサナよ、その私はその神々 [の申し出] を退け、『もうよい』と言う」である。Ps は *Halanti vadāmīti alanti vadāmi, alaṃ iminā evaṃ mā karittha, yāpessāmahanti evaṃ paṭisedhemīti attho*「『halaṃ と言う』とは alaṃ と言うことで、『これはもうよい、そのようにしてくれるな、私は [自分で] やっていく』と、このように拒む、という意味である」と説明する。

MN 85 §337 は、成道後のブッダが法を説くことをためらう偈である。

```
Kicchena me adhigataṃ, halaṃ dāni pakāsituṃ;
```

本ノートで選んだ訳は「苦労して私が得たものを、今説く必要はない」である。halaṃ は不定詞 pakāsituṃ と結んでいる。それでも MN 118 §146 の「〜しに行くに値する」とは逆に、「〜する必要はない」の意味になる。Ps は MN 26 の同じ偈について *evaṃ kicchena adhigatassa dhammassa alaṃ desituṃ, pariyattaṃ desituṃ, ko attho desitenāti vuttaṃ hoti*「このように苦労して得た法を説くのはもうよい、説くのはもう足りている、説いて何になるか、と言われているのである」と説明する。註は alaṃ を pariyatta (足りる) で言い換えたうえで、「説いて何になるか」と結論している。「足りている」という基本の意味から「もう要らない」へ移る道筋が、この説明に表れている。CPD もこの偈を、不定詞を伴う用例のうち否定的なもの (「why should I proclaim it now」) に挙げる。

## 6. 見分け方

調べた範囲の用例と辞書の記述から、次のように見分けられる。これは本ノートの整理で、DOP の三つの語義と上の用例の分布から組み立てたものである。

| 形 | 調べた範囲での意味 | 例 |
| --- | --- | --- |
| 与格 (人・事物) を伴う | すべて「〜に十分だ・ふさわしい」 | MN 36 §373、MN 72 §190、MN 82 §302 |
| na / an- で否定 | すべて「十分ではない・値しない」 | MN 37、MN 66 §156、MN 76 §228 |
| 複合語の前の要素 | 「十分な・能力のある・ふさわしい」 | MN 82 §306、MN 36 §381 |
| 単独で文頭、呼格が続く | すべて「もうよい・結構だ」 | MN 57、MN 81、MN 82、MN 83 |
| 具格を伴う | 「〜はもうよい」と「これで足りている」の両方 | MN 82 §303、MN 39 §416〜424 |
| 不定詞を伴う | 「〜するに値する」と「〜する必要はない」の両方 | MN 118 §146、MN 85 §337 |

PTSD は、与格や不定詞を伴う alaṃ を「fit for, proper」と解するのはパーリ文法家以来の慣習で、註釈も yuttaṃ で説明する、と注記する。上の Ps の説明もこれに合っている。「十分」の側を samattha、pariyatta、yutta で説明し、「もうよい」の側を paṭikkhipati、paṭibāhati、paṭisedheti で説明している。註釈がどちらの語で説明しているかも、見分ける手がかりになる。
