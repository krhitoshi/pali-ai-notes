1. 14. Sāriputtamoggallānapabbajjākathā

* sāriputta-moggallāna-pabbajjā-kathā = 「サーリプッタとモッガッラーナの出家の話」
  * pabbajjā = 「出家」
  * kathā = 「話、物語」

→「サーリプッタとモッガッラーナの出家の話」

2. 60. Tena kho pana samayena sañcayo [sañjayo (sī. syā.)] paribbājako rājagahe paṭivasati mahatiyā paribbājakaparisāya saddhiṃ aḍḍhateyyehi paribbājakasatehi.

* tena kho pana samayena = 「さてそのとき」
* sañcayo paribbājako = 「遍歴行者サンチャヤが」
  * [sañjayo (sī. syā.)] = 異読「サンジャヤ」(シンハラ本・シャム本)
  * paribbājaka = 「遍歴行者(仏教外の出家修行者)」
* rājagahe paṭivasati = 「王舎城(ラージャガハ)に住んでいた」
  * paṭivasati = 「住む、滞在する」
* mahatiyā paribbājakaparisāya saddhiṃ = 「大きな遍歴行者の会衆とともに」
* aḍḍhateyyehi paribbājakasatehi = 「二百五十人の遍歴行者たちとともに」
  * aḍḍhateyya = 「二つ半(2.5)」、sata = 「百」→ 2.5 × 100 = 250

→「さてそのとき、遍歴行者サンチャヤが、大きな遍歴行者の会衆、二百五十人の遍歴行者たちとともに王舎城に住んでいた。」

3. Tena kho pana samayena sāriputtamoggallānā sañcaye paribbājake brahmacariyaṃ caranti.

* tena kho pana samayena = 「さてそのとき」
* sāriputtamoggallānā = 「サーリプッタとモッガッラーナは」(相違釈複合語・複数)
* sañcaye paribbājake = 「遍歴行者サンチャヤのもとで」(処格)
* brahmacariyaṃ caranti = 「梵行を行じていた」
  * brahmacariya = 「梵行、清浄行」

→「さてそのとき、サーリプッタとモッガッラーナは遍歴行者サンチャヤのもとで梵行を行じていた。」

4. Tehi katikā katā hoti – yo paṭhamaṃ amataṃ adhigacchati, so itarassa ārocetūti.

* tehi = 「彼ら(二人)によって」
* katikā katā hoti = 「約束がなされていた」
  * katikā = 「約束、取り決め」
  * katā = 「なされた(karoti の過去分詞・女性形)」
* yo paṭhamaṃ amataṃ adhigacchati = 「先に不死に到達する者は」
  * amata = 「不死(涅槃の呼び名)」
  * adhigacchati = 「到達する、証得する」
* so itarassa ārocetu = 「その者がもう一方に告げるように」
  * itara = 「もう一方の者」
  * ārocetu = 「告げよ(āroceti の命令法三人称単数)」
* ti = 引用の終わり

→「彼らによって約束がなされていた――『先に不死に到達した者が、もう一方に告げるように』と。」

5. Atha kho āyasmā assaji pubbaṇhasamayaṃ nivāsetvā pattacīvaramādāya rājagahaṃ piṇḍāya pāvisi pāsādikena abhikkantena paṭikkantena ālokitena vilokitena samiñjitena pasāritena, okkhittacakkhu iriyāpathasampanno.

* atha kho = 「そこで」
* āyasmā assaji = 「尊者アッサジは」(五比丘の一人)
* pubbaṇhasamayaṃ nivāsetvā = 「午前中に(下衣を)着て」
* pattacīvaram ādāya = 「鉢と衣を取って」
* rājagahaṃ piṇḍāya pāvisi = 「托鉢のために王舎城に入った」
  * piṇḍa = 「団食、托鉢の食」
* pāsādikena abhikkantena paṭikkantena = 「浄信を起こさせる進み方と退き方で」
  * pāsādika = 「浄信を起こさせる、好ましい」
* ālokitena vilokitena = 「(浄信を起こさせる)前方の見方と周囲の見方で」
* samiñjitena pasāritena = 「(浄信を起こさせる腕の)曲げ方と伸ばし方で」
* okkhittacakkhu = 「目を伏せた者として」
  * okkhitta = 「投げ下ろされた、伏せられた」
* iriyāpathasampanno = 「威儀を具えた者として」
  * iriyāpatha = 「威儀(行・住・坐・臥のふるまい)」

→「そこで尊者アッサジは、午前中に衣を着け、鉢と衣を取って、托鉢のために王舎城に入った。浄信を起こさせる進み方・退き方、前方や周囲の見方、腕の曲げ伸ばしをもって、目を伏せ、威儀を具えて。」

6. Addasā kho sāriputto paribbājako āyasmantaṃ assajiṃ rājagahe piṇḍāya carantaṃ pāsādikena abhikkantena paṭikkantena ālokitena vilokitena samiñjitena pasāritena okkhittacakkhuṃ iriyāpathasampannaṃ.

* addasā = 「見た(dassati/passati のアオリスト)」
* sāriputto paribbājako = 「遍歴行者サーリプッタは」
* āyasmantaṃ assajiṃ ... carantaṃ = 「王舎城で托鉢して歩いている尊者アッサジを」
* pāsādikena abhikkantena ... pasāritena = 「浄信を起こさせる進み方・退き方、前方や周囲の見方、腕の曲げ伸ばしをもって」(前項と同じ定型)
* okkhittacakkhuṃ iriyāpathasampannaṃ = 「目を伏せ、威儀を具えた(彼を)」(対格)

→「遍歴行者サーリプッタは、浄信を起こさせる進み方・退き方、前方や周囲の見方、腕の曲げ伸ばしをもって、目を伏せ、威儀を具えて王舎城で托鉢して歩いている尊者アッサジを見た。」

7. Disvānassa etadahosi – ‘‘ye vata loke arahanto vā arahattamaggaṃ vā samāpannā, ayaṃ tesaṃ bhikkhu aññataro.

* disvāna assa etad ahosi = 「見て、彼にこの(思いが)起こった」
  * disvāna = 「見て(絶対分詞)」
* ye vata loke = 「実に世間において～である者たち」
* arahanto vā = 「阿羅漢たちであれ」
* arahattamaggaṃ vā samāpannā = 「阿羅漢道に入った者たちであれ」
  * samāpanna = 「入った、達した(samāpajjati の過去分詞)」
* ayaṃ bhikkhu tesaṃ aññataro = 「この比丘はその中の一人である」
  * aññatara = 「いずれか一人、その中の一人」

→「見て、彼にこの思いが起こった――『実に世間で阿羅漢である者たち、あるいは阿羅漢道に入った者たちがいるなら、この比丘はその中の一人だ。」

8. Yaṃnūnāhaṃ imaṃ bhikkhuṃ upasaṅkamitvā puccheyyaṃ – ‘kaṃsi tvaṃ, āvuso, uddissa pabbajito, ko vā te satthā, kassa vā tvaṃ dhammaṃ rocesī’’’ti?

* yaṃnūna ahaṃ = 「さあ、私は～してはどうか」
* imaṃ bhikkhuṃ upasaṅkamitvā puccheyyaṃ = 「この比丘に近づいて尋ねよう」
  * puccheyyaṃ = 「尋ねよう(pucchati の願望法一人称単数)」
* kaṃ si tvaṃ, āvuso, uddissa pabbajito = 「友よ、あなたは誰を頼って出家したのか」
  * kaṃsi = kaṃ + asi(疑問代名詞対格 + be動詞二人称単数)
  * uddissa = 「～を目指して、～を頼って」
* ko vā te satthā = 「あるいは、あなたの師は誰か」
* kassa vā tvaṃ dhammaṃ rocesi = 「あるいは、あなたは誰の法を喜ぶのか」
  * rocesi = 「喜ぶ、好む(roceti の二人称単数)」
* ti = 引用の終わり

→「さあ、私はこの比丘に近づいて尋ねてはどうか――友よ、あなたは誰を頼って出家したのか、あなたの師は誰か、あなたは誰の法を喜ぶのか、と。』」

9. Atha kho sāriputtassa paribbājakassa etadahosi – ‘‘akālo kho imaṃ bhikkhuṃ pucchituṃ, antaragharaṃ paviṭṭho piṇḍāya carati.

* atha kho = 「そこで」
* sāriputtassa paribbājakassa etad ahosi = 「遍歴行者サーリプッタにこの(思いが)起こった」
* akālo kho imaṃ bhikkhuṃ pucchituṃ = 「この比丘に尋ねるには時ではない」
  * akāla = 「非時、適切な時でないこと」
* antaragharaṃ paviṭṭho = 「家々の間(市街)に入って」
  * antaraghara = 「家の間、村内・市内」
* piṇḍāya carati = 「托鉢して歩いている」

→「そこで遍歴行者サーリプッタにこの思いが起こった――『この比丘に尋ねるには時ではない。彼は市街に入って托鉢して歩いている。」

10. Yaṃnūnāhaṃ imaṃ bhikkhuṃ piṭṭhito piṭṭhito anubandheyyaṃ, atthikehi upaññātaṃ magga’’nti.

* yaṃnūna ahaṃ = 「さあ、私は～してはどうか」
* imaṃ bhikkhuṃ piṭṭhito piṭṭhito anubandheyyaṃ = 「この比丘のすぐ後ろについて行こう」
  * piṭṭhito piṭṭhito = 「後ろから後ろから、すぐ後について」(反復による強調)
  * anubandheyyaṃ = 「ついて行こう(anubandhati の願望法一人称単数)」
* atthikehi upaññātaṃ maggaṃ = 「求める者たちによって見出された道を(たどって)」
  * atthika = 「(利益・真理を)求める者」
  * upaññāta = 「見出された、知られた」(要確認: 慣用句で「求める者には道が見出される」の意)
* ti = 引用の終わり

→「さあ、私はこの比丘のすぐ後ろについて行こう。求める者たちによって見出された道があるのだから。』」

11. Atha kho āyasmā assaji rājagahe piṇḍāya caritvā piṇḍapātaṃ ādāya paṭikkami.

* atha kho = 「そこで」
* rājagahe piṇḍāya caritvā = 「王舎城で托鉢して歩いてから」
* piṇḍapātaṃ ādāya = 「托鉢の食を取って」
* paṭikkami = 「戻った(paṭikkamati のアオリスト)」

→「そこで尊者アッサジは、王舎城で托鉢して歩き、托鉢の食を取って戻った。」

12. Atha kho sāriputtopi paribbājako yenāyasmā assaji tenupasaṅkami, upasaṅkamitvā āyasmatā assajinā saddhiṃ sammodi, sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā ekamantaṃ aṭṭhāsi.

* sāriputto pi paribbājako = 「遍歴行者サーリプッタも」
* yena āyasmā assaji tena upasaṅkami = 「尊者アッサジのいる所へ近づいた」(yena ... tena の定型)
* āyasmatā assajinā saddhiṃ sammodi = 「尊者アッサジと挨拶を交わした」
  * sammodi = 「喜び合った、挨拶した(sammodati のアオリスト)」
* sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā = 「喜ばしく思い出となる言葉を交わし終えて」
  * sāraṇīya = 「思い出すに値する、記憶に残る」
  * vītisāretvā = 「交わし終えて」
* ekamantaṃ aṭṭhāsi = 「一方に立った」
  * aṭṭhāsi = 「立った(tiṭṭhati のアオリスト)」

→「そこで遍歴行者サーリプッタも、尊者アッサジのいる所へ近づいた。近づいて尊者アッサジと挨拶を交わし、喜ばしく思い出となる言葉を交わし終えて、一方に立った。」

13. Ekamantaṃ ṭhito kho sāriputto paribbājako āyasmantaṃ assajiṃ etadavoca – ‘‘vippasannāni kho te, āvuso, indriyāni, parisuddho chavivaṇṇo pariyodāto.

* ekamantaṃ ṭhito = 「一方に立った(まま)」
* etad avoca = 「このように言った」
* vippasannāni kho te, āvuso, indriyāni = 「友よ、あなたの諸根は澄んでいる」
  * vippasanna = 「よく澄んだ、明浄な」
  * indriya = 「根(感覚器官)」
* parisuddho chavivaṇṇo pariyodāto = 「皮膚の色は清浄で明るく輝いている」
  * chavivaṇṇa = 「皮膚の色、顔色」
  * pariyodāta = 「明るく輝く、清白な」

→「一方に立った遍歴行者サーリプッタは、尊者アッサジにこう言った――『友よ、あなたの諸根は澄んでおり、皮膚の色は清浄で明るく輝いています。」

14. Kaṃsi tvaṃ, āvuso, uddissa pabbajito, ko vā te satthā, kassa vā tvaṃ dhammaṃ rocesī’’ti?

* kaṃ si tvaṃ, āvuso, uddissa pabbajito = 「友よ、あなたは誰を頼って出家したのですか」
* ko vā te satthā = 「あるいは、あなたの師は誰ですか」
* kassa vā tvaṃ dhammaṃ rocesi = 「あるいは、あなたは誰の法を喜ぶのですか」
* ti = 引用の終わり

→「友よ、あなたは誰を頼って出家したのですか。あなたの師は誰ですか。あなたは誰の法を喜ぶのですか。』」

15. ‘‘Atthāvuso, mahāsamaṇo sakyaputto sakyakulā pabbajito, tāhaṃ bhagavantaṃ uddissa pabbajito, so ca me bhagavā satthā, tassa cāhaṃ bhagavato dhammaṃ rocemī’’ti.

* atthi āvuso = 「友よ、～がおられます」
* mahāsamaṇo sakyaputto sakyakulā pabbajito = 「釈迦族の子で、釈迦族の家から出家した大沙門が」
  * sakyakulā = 「釈迦族の家から」(奪格)
* taṃ ahaṃ bhagavantaṃ uddissa pabbajito = 「私はその世尊を頼って出家しました」
  * tāhaṃ = taṃ + ahaṃ
* so ca me bhagavā satthā = 「そしてその世尊が私の師です」
* tassa ca ahaṃ bhagavato dhammaṃ rocemi = 「そして私はその世尊の法を喜びます」
* ti = 引用の終わり

→「『友よ、釈迦族の子で、釈迦族の家から出家した大沙門がおられます。私はその世尊を頼って出家しました。その世尊が私の師であり、私はその世尊の法を喜びます。』」

16. ‘‘Kiṃvādī panāyasmato satthā, kimakkhāyī’’ti?

* kiṃvādī pana āyasmato satthā = 「では、尊者の師は何を説く方ですか」
  * kiṃvādin = 「何を説く者」
  * āyasmato = 「尊者の」(属格)
* kimakkhāyī = 「何を明らかにする方ですか」
  * kiṃ-akkhāyin = 「何を告げ示す者」
* ti = 引用の終わり

→「『では、尊者の師は何を説き、何を明らかにする方ですか。』」

17. ‘‘Ahaṃ kho, āvuso, navo acirapabbajito, adhunāgato imaṃ dhammavinayaṃ, na tāhaṃ sakkomi vitthārena dhammaṃ desetuṃ, api ca te saṃkhittena atthaṃ vakkhāmī’’ti.

* ahaṃ kho, āvuso = 「友よ、私は」
* navo acirapabbajito = 「新参で、出家して間もない者です」
  * acira = 「久しくない、間もない」
* adhunāgato imaṃ dhammavinayaṃ = 「この法と律に来たばかりの者です」
  * adhunā + āgata = 「今しがた来た」
* na taṃ ahaṃ sakkomi vitthārena dhammaṃ desetuṃ = 「私はあなたに詳しく法を説くことができません」
  * tāhaṃ = te(あなたに)+ ahaṃ (要確認: taṃ + ahaṃ とも解しうる)
  * vitthārena = 「詳しく、詳細に」
* api ca te saṃkhittena atthaṃ vakkhāmi = 「しかし、あなたに簡潔に意味を語りましょう」
  * saṃkhittena = 「簡潔に、要約して」
  * vakkhāmi = 「語ろう(vatti/vadati の未来一人称単数)」
* ti = 引用の終わり

→「『友よ、私は新参で出家して間もなく、この法と律に来たばかりです。あなたに詳しく法を説くことはできません。しかし、簡潔に意味を語りましょう。』」

18. Atha kho sāriputto paribbājako āyasmantaṃ assajiṃ etadavoca – ‘‘hotu, āvuso –

* atha kho = 「そこで」
* etad avoca = 「このように言った」
* hotu, āvuso = 「友よ、それで結構です」
  * hotu = 「あれ、そうであれ(hoti の命令法三人称単数)」ここでは「それでよい」の意

→「そこで遍歴行者サーリプッタは尊者アッサジにこう言った――『友よ、それで結構です――」

## 60 (2)

‘‘Appaṃ vā bahuṃ vā bhāsassu, atthaṃyeva me brūhi;

Attheneva me attho, kiṃ kāhasi byañjanaṃ bahu’’nti.

Atha kho āyasmā assaji sāriputtassa paribbājakassa imaṃ dhammapariyāyaṃ abhāsi –
