# 7. Pabbajjākathā

## 25

25. Tena kho pana samayena bārāṇasiyaṃ yaso nāma kulaputto seṭṭhiputto sukhumālo hoti. Tassa tayo pāsādā honti – eko hemantiko, eko gimhiko, eko vassiko. So vassike pāsāde cattāro māse [vassike pāsāde vassike cattāro māse (sī.)] nippurisehi tūriyehi paricārayamāno na heṭṭhāpāsādaṃ orohati. Atha kho yasassa kulaputtassa pañcahi kāmaguṇehi samappitassa samaṅgībhūtassa paricārayamānassa paṭikacceva [paṭigacceva (sī.)] niddā okkami, parijanassapi niddā okkami, sabbarattiyo ca telapadīpo jhāyati. Atha kho yaso kulaputto paṭikacceva pabujjhitvā addasa sakaṃ parijanaṃ supantaṃ – aññissā kacche vīṇaṃ, aññissā kaṇṭhe mudiṅgaṃ, aññissā kacche āḷambaraṃ, aññaṃ vikesikaṃ, aññaṃ vikkheḷikaṃ, aññā vippalapantiyo, hatthappattaṃ susānaṃ maññe. Disvānassa ādīnavo pāturahosi, nibbidāya cittaṃ saṇṭhāsi. Atha kho yaso kulaputto udānaṃ udānesi – ‘‘upaddutaṃ vata bho, upassaṭṭhaṃ vata bho’’ti.

Atha kho yaso kulaputto suvaṇṇapādukāyo ārohitvā yena nivesanadvāraṃ tenupasaṅkami. Amanussā dvāraṃ vivariṃsu – mā yasassa kulaputtassa koci antarāyamakāsi agārasmā anagāriyaṃ pabbajjāyāti . Atha kho yaso kulaputto yena nagaradvāraṃ tenupasaṅkami. Amanussā dvāraṃ vivariṃsu – mā yasassa kulaputtassa koci antarāyamakāsi agārasmā anagāriyaṃ pabbajjāyāti. Atha kho yaso kulaputto yena isipatanaṃ migadāyo tenupasaṅkami.

* ekamantaṃ nisīdi = 「一方に坐った」

→「そこで尊者ヤサは、その五十人ほどの在家の友人たちを連れて世尊のところへ近づいた。近づいて世尊を礼拝し、一方に坐った。」

5. Ekamantaṃ nisinno kho āyasmā yaso bhagavantaṃ etadavoca – ‘‘ime me, bhante, paññāsamattā gihisahāyakā jānapadā pubbānupubbakānaṃ kulānaṃ puttā. Ime bhagavā ovadatu anusāsatū’’ti.

* ekamantaṃ nisinno = 「一方に坐った（ヤサは）」
* etadavoca = 「このように言った」
* ime me, bhante = 「尊師よ、これらは私の〜です」
* ime bhagavā ovadatu anusāsatu = 「世尊はこの者たちを教誡し、教え導いてください」
  * ovadatu = 「教誡してください」（命令法・三人称単数）
  * anusāsatu = 「教え導いてください」（命令法・三人称単数）

→「一方に坐った尊者ヤサは、世尊にこのように言った――『尊師よ、この者たちは私の五十人ほどの在家の友人たちで、地方の由緒ある家々の息子たちです。世尊はこの者たちを教誡し、教え導いてください』と。」

6. Tesaṃ bhagavā anupubbiṃ kathaṃ kathesi, seyyathidaṃ – dānakathaṃ sīlakathaṃ saggakathaṃ kāmānaṃ ādīnavaṃ okāraṃ saṃkilesaṃ nekkhamme ānisaṃsaṃ pakāsesi.

* tesaṃ = 「彼らに」
* anupubbiṃ kathaṃ kathesi = 「次第説法を説いた」
  * anupubbī kathā = 「順を追った話、次第説法」
* seyyathidaṃ = 「すなわち」
* dānakathaṃ = 「布施の話」
* sīlakathaṃ = 「戒の話」
* saggakathaṃ = 「天界の話」
* kāmānaṃ ādīnavaṃ okāraṃ saṃkilesaṃ = 「諸欲の危険と卑しさと汚れ」
  * ādīnava = 「危険、過患」
  * okāra = 「卑しさ、低劣さ」
  * saṃkilesa = 「汚れ」
* nekkhamme ānisaṃsaṃ = 「離欲における利益」
* pakāsesi = 「明らかにした」

→「世尊は彼らに次第説法を説いた。すなわち、布施の話、戒の話、天界の話、諸欲の危険と卑しさと汚れ、離欲における利益を明らかにした。」

7. Yadā te bhagavā aññāsi kallacitte muducitte vinīvaraṇacitte udaggacitte pasannacitte, atha yā buddhānaṃ sāmukkaṃsikā dhammadesanā, taṃ pakāsesi dukkhaṃ samudayaṃ nirodhaṃ maggaṃ,

* yadā ... aññāsi = 「〜と知ったとき」
  * aññāsi = 「知った」（ājānāti のアオリスト）
* kallacitte = 「心が調った（者たちであると）」
  * kalla = 「適した、準備のできた」
* muducitte = 「心が柔軟な」
* vinīvaraṇacitte = 「心が（五）蓋を離れた」
  * nīvaraṇa = 「蓋、覆い」
* udaggacitte = 「心が高揚した」
* pasannacitte = 「心が浄信をもつ」
* yā buddhānaṃ sāmukkaṃsikā dhammadesanā = 「諸仏がみずから称揚する法話」
  * sāmukkaṃsika = 「みずから挙げ示す、（諸仏に）固有の」
* taṃ pakāsesi = 「それを明らかにした」
* dukkhaṃ samudayaṃ nirodhaṃ maggaṃ = 「苦・集・滅・道（の四聖諦）を」

→「世尊は、彼らが心が調い、心が柔軟になり、心が蓋を離れ、心が高揚し、心が浄信をもつに至ったと知ったとき、諸仏がみずから称揚する法話、すなわち苦・集・滅・道を明らかにした。」

8. seyyathāpi nāma suddhaṃ vatthaṃ apagatakāḷakaṃ sammadeva rajanaṃ paṭiggaṇheyya, evameva tesaṃ tasmiṃyeva āsane virajaṃ vītamalaṃ dhammacakkhuṃ udapādi yaṃ kiñci samudayadhammaṃ, sabbaṃ taṃ nirodhadhammanti.

* seyyathāpi nāma = 「ちょうど〜のように」
* suddhaṃ vatthaṃ apagatakāḷakaṃ = 「黒い汚れを離れた清浄な布が」
  * apagata-kāḷaka = 「黒い点（汚れ）が去った」
* sammadeva rajanaṃ paṭiggaṇheyya = 「正しく染料を受け取るであろう（ように）」
  * rajana = 「染料」
* evameva = 「まさにそのように」
* tesaṃ tasmiṃyeva āsane = 「彼らに、まさにその座において」
* virajaṃ vītamalaṃ dhammacakkhuṃ udapādi = 「塵を離れ、垢を離れた法眼が生じた」
  * dhammacakkhu = 「法眼」（ここでは預流道の智）
  * udapādi = 「生じた」（アオリスト）
* yaṃ kiñci samudayadhammaṃ, sabbaṃ taṃ nirodhadhammaṃ = 「およそ生じる性質のものは、すべて滅する性質のものである」
* ti = 「〜という（内容の法眼）」

→「ちょうど黒い汚れを離れた清浄な布が正しく染料を受け取るように、まさにそのように、彼らにまさにその座で、塵を離れ垢を離れた法眼が生じた――『およそ生じる性質のものは、すべて滅する性質のものである』と。」

9. Te diṭṭhadhammā pattadhammā viditadhammā pariyogāḷhadhammā tiṇṇavicikicchā vigatakathaṃkathā vesārajjappattā aparappaccayā satthusāsane bhagavantaṃ etadavocuṃ – ‘‘labheyyāma mayaṃ, bhante, bhagavato santike pabbajjaṃ, labheyyāma upasampada’’nti.

* diṭṭhadhammā = 「法を見た者たち」
* pattadhammā = 「法に達した者たち」
* viditadhammā = 「法を知った者たち」
* pariyogāḷhadhammā = 「法に深く入った者たち」
  * pariyogāḷha = 「深く潜入した」（pariyogāhati の過去分詞）
* tiṇṇavicikicchā = 「疑いを渡り越えた者たち」
* vigatakathaṃkathā = 「疑念を離れた者たち」
  * kathaṃkathā = 「あれこれの疑い、疑念」
* vesārajjappattā = 「無畏に達した者たち」
* aparappaccayā satthusāsane = 「師の教えにおいて他に依らない者たち」
  * apara-paccaya = 「他を縁としない、他人に頼らない」
* etadavocuṃ = 「このように言った」（複数）
* labheyyāma mayaṃ = 「私たちは得たいのです」（願望法・一人称複数）
* bhagavato santike = 「世尊のもとで」
* pabbajjaṃ ... upasampadaṃ = 「出家を〜具足戒を」

→「彼らは法を見、法に達し、法を知り、法に深く入り、疑いを渡り越え、疑念を離れ、無畏に達し、師の教えにおいて他に依らない者となって、世尊にこのように言った――『尊師よ、私たちは世尊のもとで出家を得たいのです。具足戒を得たいのです』と。」

10. ‘‘Etha bhikkhavo’’ti bhagavā avoca – ‘‘svākkhāto dhammo, caratha brahmacariyaṃ sammā dukkhassa antakiriyāyā’’ti.

* etha bhikkhavo = 「来なさい、比丘たちよ」
  * etha = 「来なさい」（命令法・二人称複数）
* bhagavā avoca = 「世尊は言った」
* svākkhāto dhammo = 「法はよく説かれている」
  * su + akkhāta = 「よく + 説かれた」
* caratha brahmacariyaṃ = 「梵行を行じなさい」
* sammā dukkhassa antakiriyāya = 「正しく苦を終わらせるために」
  * anta-kiriyā = 「終わりにすること、終息させること」

→「『来なさい、比丘たちよ』と世尊は言った――『法はよく説かれている。正しく苦を終わらせるために梵行を行じなさい』と。」

11. Sāva tesaṃ āyasmantānaṃ upasampadā ahosi.

* sāva = 「それこそが」（sā eva）
  * この「来なさい、比丘たちよ」という言葉そのもの（善来比丘具足戒）を指す
* tesaṃ āyasmantānaṃ = 「その尊者たちの」
* upasampadā ahosi = 「具足戒となった」

→「それこそが、その尊者たちの具足戒となった。」

12. Atha kho bhagavā te bhikkhū dhammiyā kathāya ovadi anusāsi.

* atha kho = 「そこで」
* te bhikkhū = 「その比丘たちを」
* dhammiyā kathāya = 「法にかなった話によって」
* ovadi anusāsi = 「教誡し、教え導いた」（ともにアオリスト）

→「そこで世尊は、その比丘たちを法にかなった話によって教誡し、教え導いた。」

13. Tesaṃ bhagavatā dhammiyā kathāya ovadiyamānānaṃ anusāsiyamānānaṃ anupādāya āsavehi cittāni vimucciṃsu.

* tesaṃ ... ovadiyamānānaṃ anusāsiyamānānaṃ = 「世尊によって法にかなった話で教誡され、教え導かれている彼らの」
  * ovadiyamāna / anusāsiyamāna = 受動現在分詞
* anupādāya = 「執着することなく」
  * an + upādāya = 「取ることなしに」
* āsavehi cittāni vimucciṃsu = 「諸々の漏から心が解脱した」
  * āsava = 「漏、煩悩の流れ」
  * vimucciṃsu = 「解脱した」（アオリスト・三人称複数）

→「世尊によって法にかなった話で教誡され、教え導かれている彼らの心は、執着することなく諸々の漏から解脱した。」

14. Tena kho pana samayena ekasaṭṭhi loke arahanto honti.

* tena kho pana samayena = 「さて、そのとき」
* ekasaṭṭhi = 「六十一人の」
* loke arahanto honti = 「世に阿羅漢たちがいる」
  * 仏陀と六十人の弟子（五比丘・ヤサ・四人の友・五十人の友）を合わせて六十一人

→「さて、そのとき、世には六十一人の阿羅漢がいた。」

15. Paññāsagihisahāyakapabbajjā niṭṭhitā.

* paññāsa-gihi-sahāyaka-pabbajjā = 「五十人の在家の友人たちの出家（の話）」
* niṭṭhitā = 「終わった」

→「五十人の在家の友人たちの出家（の話）が終わった。」

16. Niṭṭhitā ca pabbajjākathā.

* niṭṭhitā ca = 「そして〜が終わった」
* pabbajjākathā = 「出家の話（の章）」

→「そして出家の話（の章）が終わった。」
