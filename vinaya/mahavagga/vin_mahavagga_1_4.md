# 4. Rājāyatanakathā

## 6

6. Atha kho bhagavā sattāhassa accayena tamhā samādhimhā vuṭṭhahitvā mucalindamūlā yena rājāyatanaṃ tenupasaṅkami, upasaṅkamitvā rājāyatanamūle sattāhaṃ ekapallaṅkena nisīdi vimuttisukhapaṭisaṃvedī. Tena kho pana samayena tapussa [tapassu (sī.)] bhallikā vāṇijā ukkalā taṃ desaṃ addhānamaggappaṭipannā honti. Atha kho tapussabhallikānaṃ vāṇijānaṃ ñātisālohitā devatā tapussabhallike vāṇije etadavoca – ‘‘ayaṃ, mārisā, bhagavā rājāyatanamūle viharati paṭhamābhisambuddho; gacchatha taṃ bhagavantaṃ manthena ca madhupiṇḍikāya ca patimānetha; taṃ vo bhavissati dīgharattaṃ hitāya sukhāyā’’ti. Atha kho tapussabhallikā vāṇijā manthañca madhupiṇḍikañca ādāya yena bhagavā tenupasaṅkamiṃsu, upasaṅkamitvā bhagavantaṃ abhivādetvā ekamantaṃ aṭṭhaṃsu. Ekamantaṃ ṭhitā kho tapussabhallikā vāṇijā bhagavantaṃ etadavocuṃ – ‘‘paṭiggaṇhātu no, bhante, bhagavā manthañca madhupiṇḍikañca, yaṃ amhākaṃ assa dīgharattaṃ hitāya sukhāyā’’ti. Atha kho bhagavato etadahosi – ‘‘na kho tathāgatā hatthesu paṭiggaṇhanti. Kimhi nu kho ahaṃ paṭiggaṇheyyaṃ manthañca madhupiṇḍikañcā’’ti? Atha kho cattāro mahārājāno bhagavato cetasā cetoparivitakkamaññāya catuddisā cattāro selamaye patte bhagavato upanāmesuṃ – ‘‘idha, bhante, bhagavā paṭiggaṇhātu manthañca madhupiṇḍikañcā’’ti. Paṭiggahesi bhagavā paccagghe selamaye patte manthañca madhupiṇḍikañca, paṭiggahetvā paribhuñji. Atha kho tapussabhallikā vāṇijā bhagavantaṃ onītapattapāṇiṃ viditvā bhagavato pādesu sirasā nipatitvā bhagavantaṃ (onītapattapāṇiṃ viditvā bhagavato pādesu sirasā nipatitvā bhagavantaṃ) [( ) sī. syā. potthakesu natthi] etadavocuṃ – ‘‘ete mayaṃ, bhante, bhagavantaṃ saraṇaṃ gacchāma dhammañca, upāsake no bhagavā dhāretu ajjatagge pāṇupete saraṇaṃ gate’’ti. Te ca loke paṭhamaṃ upāsakā ahesuṃ dvevācikā.

Rājāyatanakathā niṭṭhitā.

1. 4. Rājāyatanakathā

* rājāyatana-kathā = 「ラージャーヤタナ樹の話」
  * rājāyatana = 「ラージャーヤタナ樹（樹木の名。漢訳では王処樹などとされる）」
  * kathā = 「話、物語」

→「ラージャーヤタナ樹の話」

2. 6. Atha kho bhagavā sattāhassa accayena tamhā samādhimhā vuṭṭhahitvā mucalindamūlā yena rājāyatanaṃ tenupasaṅkami, upasaṅkamitvā rājāyatanamūle sattāhaṃ ekapallaṅkena nisīdi vimuttisukhapaṭisaṃvedī.

* atha kho = 「さて」
* bhagavā = 「世尊は」
* sattāhassa accayena = 「七日が過ぎたとき」
  * sattāha = 「七日」
  * accayena = 「経過によって（accaya の具格）」
* tamhā samādhimhā vuṭṭhahitvā = 「その三昧から出て」
  * vuṭṭhahitvā = 「出て、出定して（vuṭṭhahati の連続体）」
* mucalindamūlā = 「ムチャリンダ樹の根もとから」
* yena rājāyatanaṃ tenupasaṅkami = 「ラージャーヤタナ樹のところへ近づいた」
* upasaṅkamitvā = 「近づいて」
* rājāyatanamūle = 「ラージャーヤタナ樹の根もとで」
* sattāhaṃ = 「七日間」
* ekapallaṅkena nisīdi = 「一つの結跏趺坐のままで坐った」
* vimuttisukhapaṭisaṃvedī = 「解脱の楽を感受しながら」
  * vimutti = 「解脱」
  * sukha = 「楽」
  * paṭisaṃvedī = 「感受する者」

→「さて世尊は、七日が過ぎたとき、その三昧から出て、ムチャリンダ樹の根もとからラージャーヤタナ樹のところへ近づいた。近づいて、ラージャーヤタナ樹の根もとで七日間、一つの結跏趺坐のままで、解脱の楽を感受しながら坐った。」

3. Tena kho pana samayena tapussa [tapassu (sī.)] bhallikā vāṇijā ukkalā taṃ desaṃ addhānamaggappaṭipannā honti.

* tena kho pana samayena = 「さてそのとき」
* tapussa bhallikā vāṇijā = 「タプッサとバッリカという商人たちが」
* ukkalā = 「ウッカラ国から」
* taṃ desaṃ = 「その地方を」
* addhānamaggappaṭipannā honti = 「旅の道を進んでいた」
  * addhāna-magga = 「長い道のり、旅路」
  * paṭipanna = 「進んでいる（paṭipajjati の過去分詞）」

→「さてそのとき、タプッサとバッリカという商人たちが、ウッカラ国からその地方への旅の道を進んでいた。」

4. Atha kho tapussabhallikānaṃ vāṇijānaṃ ñātisālohitā devatā tapussabhallike vāṇije etadavoca – ‘‘ayaṃ, mārisā, bhagavā rājāyatanamūle viharati paṭhamābhisambuddho; gacchatha taṃ bhagavantaṃ manthena ca madhupiṇḍikāya ca patimānetha; taṃ vo bhavissati dīgharattaṃ hitāya sukhāyā’’ti.

* ñātisālohitā devatā = 「（前世の）親族・血縁であった神が」
  * ñāti = 「親族」
  * sālohita = 「血縁の者」
* tapussabhallike vāṇije etadavoca = 「商人タプッサとバッリカにこう言った」
* ayaṃ, mārisā, bhagavā = 「友らよ、この世尊は」
  * mārisā = 「友らよ（神が用いる敬愛の呼びかけ）」
* rājāyatanamūle viharati = 「ラージャーヤタナ樹の根もとに住んでいる」
* paṭhamābhisambuddho = 「初めて正覚を得たばかりの者として」
* gacchatha = 「行きなさい」
* manthena ca madhupiṇḍikāya ca = 「麦こがしと蜜団子とで」
  * mantha = 「麦こがし（炒った穀物の菓子）」
  * madhupiṇḍikā = 「蜜団子」
* patimānetha = 「もてなしなさい、供養しなさい」
* taṃ vo bhavissati dīgharattaṃ hitāya sukhāyā ti = 「それはあなたたちにとって長い間、利益と安楽のためになるだろう、と」
  * vo = 「あなたたちにとって」
  * dīgharattaṃ = 「長い間」

→「さてそのとき、商人タプッサとバッリカの（前世の）親族・血縁であった神が、商人タプッサとバッリカにこう言った――『友らよ、この世尊は初めて正覚を得たばかりの方として、ラージャーヤタナ樹の根もとに住んでおられる。行って、その世尊を麦こがしと蜜団子とでもてなしなさい。それはあなたたちにとって長い間、利益と安楽のためになるだろう』と。」

5. Atha kho tapussabhallikā vāṇijā manthañca madhupiṇḍikañca ādāya yena bhagavā tenupasaṅkamiṃsu, upasaṅkamitvā bhagavantaṃ abhivādetvā ekamantaṃ aṭṭhaṃsu.

* manthañca madhupiṇḍikañca ādāya = 「麦こがしと蜜団子とを持って」
  * ādāya = 「取って、持って（ādāti の連続体）」
* yena bhagavā tenupasaṅkamiṃsu = 「世尊のところへ近づいた」
* bhagavantaṃ abhivādetvā = 「世尊に敬礼して」
* ekamantaṃ aṭṭhaṃsu = 「一方に立った」

→「そこで商人タプッサとバッリカは、麦こがしと蜜団子とを持って世尊のところへ近づいた。近づいて世尊に敬礼し、一方に立った。」

6. Ekamantaṃ ṭhitā kho tapussabhallikā vāṇijā bhagavantaṃ etadavocuṃ – ‘‘paṭiggaṇhātu no, bhante, bhagavā manthañca madhupiṇḍikañca, yaṃ amhākaṃ assa dīgharattaṃ hitāya sukhāyā’’ti.

* ekamantaṃ ṭhitā = 「一方に立った（商人たちは）」
* etadavocuṃ = 「こう言った」
* paṭiggaṇhātu no, bhante, bhagavā = 「尊者よ、世尊は私たちの（供物を）お受け取りください」
  * paṭiggaṇhātu = 「受け取ってください（paṭiggaṇhāti の命令法三人称単数）」
  * no = 「私たちの」
* yaṃ amhākaṃ assa dīgharattaṃ hitāya sukhāyā ti = 「それが私たちにとって長い間、利益と安楽のためになりますように、と」
  * assa = 「あるだろう（atthi の願望法）」

→「一方に立った商人タプッサとバッリカは、世尊にこう言った――『尊者よ、世尊は私たちの麦こがしと蜜団子とをお受け取りください。それが私たちにとって長い間、利益と安楽のためになりますように』と。」

7. Atha kho bhagavato etadahosi – ‘‘na kho tathāgatā hatthesu paṭiggaṇhanti. Kimhi nu kho ahaṃ paṭiggaṇheyyaṃ manthañca madhupiṇḍikañcā’’ti?

* bhagavato etadahosi = 「世尊にこの思いが起こった」
* na kho tathāgatā hatthesu paṭiggaṇhanti = 「如来たちは両手では受け取らない」
* kimhi nu kho = 「いったい何において（何で）」
* ahaṃ paṭiggaṇheyyaṃ = 「私は受け取ったらよいのか（願望法一人称単数）」
* manthañca madhupiṇḍikañcā ti = 「麦こがしと蜜団子とを、と」

→「そのとき世尊にこの思いが起こった――『如来たちは両手では（食物を）受け取らない。私はいったい何で麦こがしと蜜団子とを受け取ったらよいのか』と。」

8. Atha kho cattāro mahārājāno bhagavato cetasā cetoparivitakkamaññāya catuddisā cattāro selamaye patte bhagavato upanāmesuṃ – ‘‘idha, bhante, bhagavā paṭiggaṇhātu manthañca madhupiṇḍikañcā’’ti.

* cattāro mahārājāno = 「四大王たちは（四天王）」
* bhagavato cetasā cetoparivitakkamaññāya = 「世尊の心の思いを（自らの）心で知って」
  * ceto-parivitakka = 「心の思い、心中の考え」
  * aññāya = 「知って（ājānāti の連続体）」
* catuddisā = 「四方から」
* cattāro selamaye patte = 「四つの石でできた鉢を」
  * selamaya = 「石でできた」
  * patta = 「鉢」
* bhagavato upanāmesuṃ = 「世尊に差し出した」
  * upanāmesuṃ = 「差し出した（upanāmeti のアオリスト三人称複数）」
* idha, bhante, bhagavā paṭiggaṇhātu = 「尊者よ、世尊はこれで受け取ってください」

→「そのとき四大王たちは、世尊の心の思いを心で知って、四方から四つの石でできた鉢を世尊に差し出した――『尊者よ、世尊はこれで麦こがしと蜜団子とをお受け取りください』と。」

9. Paṭiggahesi bhagavā paccagghe selamaye patte manthañca madhupiṇḍikañca, paṭiggahetvā paribhuñji.

* paṭiggahesi = 「受け取った（アオリスト）」
* paccagghe selamaye patte = 「高価な石でできた鉢で」
  * paccaggha = 「高価な、貴重な」
* paṭiggahetvā paribhuñji = 「受け取って食べた」
  * paribhuñji = 「食べた（paribhuñjati のアオリスト）」

→「世尊は高価な石でできた鉢で麦こがしと蜜団子とを受け取り、受け取って食べた。」

10. Atha kho tapussabhallikā vāṇijā bhagavantaṃ onītapattapāṇiṃ viditvā bhagavato pādesu sirasā nipatitvā bhagavantaṃ (onītapattapāṇiṃ viditvā bhagavato pādesu sirasā nipatitvā bhagavantaṃ) [( ) sī. syā. potthakesu natthi] etadavocuṃ – ‘‘ete mayaṃ, bhante, bhagavantaṃ saraṇaṃ gacchāma dhammañca, upāsake no bhagavā dhāretu ajjatagge pāṇupete saraṇaṃ gate’’ti.

* bhagavantaṃ onītapattapāṇiṃ viditvā = 「世尊が鉢から手を離した（食事を終えた）のを知って」
  * onīta-patta-pāṇi = 「鉢から手を離した者」
  * viditvā = 「知って（vindati/vidati の連続体）」
* bhagavato pādesu sirasā nipatitvā = 「世尊の両足に頭をつけて礼拝して」
  * sirasā = 「頭で（siras の具格）」
  * nipatitvā = 「ひれ伏して（nipatati の連続体）」
* ete mayaṃ, bhante = 「尊者よ、この私たちは」
* bhagavantaṃ saraṇaṃ gacchāma dhammañca = 「世尊と法とに帰依します」
  * saraṇaṃ gacchāma = 「帰依所として行きます、帰依します」
* upāsake no bhagavā dhāretu = 「世尊は私たちを優婆塞として受け入れてください」
  * dhāretu = 「保持してください、認めてください（dhāreti の命令法）」
* ajjatagge = 「今日から」
* pāṇupete saraṇaṃ gate ti = 「命ある限り帰依した者たちとして、と」
  * pāṇupeta = 「命を伴った、命ある限りの（pāṇa-upeta）」

→「そのとき商人タプッサとバッリカは、世尊が鉢から手を離した（食事を終えた）のを知って、世尊の両足に頭をつけて礼拝し、世尊にこう言った――『尊者よ、この私たちは世尊と法とに帰依します。世尊は私たちを、今日から命ある限り帰依した優婆塞としてお認めください』と。」

11. Te ca loke paṭhamaṃ upāsakā ahesuṃ dvevācikā.

* te ca = 「そして彼らは」
* loke paṭhamaṃ = 「世間で最初の」
* upāsakā ahesuṃ = 「優婆塞となった」
  * ahesuṃ = 「あった、なった（hoti のアオリスト三人称複数）」
* dvevācikā = 「二語の（帰依による）者たちとして」
  * dve-vācika = 「二語による（仏と法の二つへの帰依。このとき僧団はまだなかった）」

→「そして彼らは、世間で最初の、二語（の帰依）による優婆塞となった。」

12. Rājāyatanakathā niṭṭhitā.

* niṭṭhitā = 「終わった（niṭṭhāti の過去分詞）」

→「ラージャーヤタナ樹の話、終わり。」
