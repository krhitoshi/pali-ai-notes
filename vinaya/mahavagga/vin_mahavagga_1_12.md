1. 38. Addasā kho so nāgo bhagavantaṃ paviṭṭhaṃ, disvāna dummano [dukkhī dummano (sī. syā.)] padhūpāyi [pakhūpāsi (ka.)].

* kho = 「実に(強調の小辞)」
* so nāgo = 「その龍は」
  * nāga = 「龍、蛇の霊(ここでは火神堂に住む毒蛇の王)」
* bhagavantaṃ paviṭṭhaṃ = 「世尊が入ったのを」
  * paviṭṭha = 「入った(pavisati の過去分詞)」
* disvāna = 「見て(dassati の連続体)」
* dummano = 「不機嫌になり、心が荒れて」
  * du(r) + mano = 「悪い意(こころ)の」
  * 異読: dukkhī dummano = 「苦しみ、不機嫌になり」(sī. syā. 本)

  * 異読: pakhūpāsi (ka. 本)

1. ‘‘Evaṃ passaṃ, bhikkhave, sutavā ariyasāvako cakkhusmimpi nibbindati, rūpesupi nibbindati, cakkhuviññāṇepi nibbindati, cakkhusamphassepi nibbindati, yamidaṃ cakkhusamphassapaccayā uppajjati vedayitaṃ sukhaṃ vā dukkhaṃ vā adukkhamasukhaṃ vā, tasmimpi nibbindati.

* evaṃ passaṃ = 「このように見る者は」
  * passaṃ = passati(見る)の現在分詞・単数主格
* bhikkhave = 「比丘たちよ」(呼格)
* sutavā = 「(教えを)聞いた、学識ある」
* ariya-sāvako = 「聖なる弟子は」
* cakkhusmim pi nibbindati = 「眼に対しても厭う(厭離する)」
  * nibbindati = 「厭う、嫌気がさす、うんざりする」
* rūpesu pi nibbindati = 「諸々の色(見えるもの)に対しても厭う」
* cakkhu-viññāṇe pi nibbindati = 「眼識に対しても厭う」
* cakkhu-samphasse pi nibbindati = 「眼触に対しても厭う」
  * samphassa = 「触、接触」
* yam idaṃ cakkhu-samphassa-paccayā uppajjati vedayitaṃ = 「眼触を縁として生じるこの感受されたもの」
  * paccayā = 「〜を縁として、〜を条件として」(奪格)
  * vedayitaṃ = 「感受されたもの、受」
* sukhaṃ vā dukkhaṃ vā adukkhamasukhaṃ vā = 「楽であれ、苦であれ、不苦不楽であれ」
* tasmim pi nibbindati = 「それに対しても厭う」

→「比丘たちよ、このように見て、聞いた聖なる弟子は、眼に対しても厭い、諸々の色に対しても厭い、眼識に対しても厭い、眼触に対しても厭い、眼触を縁として生じる楽・苦・不苦不楽の感受に対しても厭う。」

2. Sotasmimpi nibbindati, saddesupi nibbindati…pe… ghānasmimpi nibbindati , gandhesupi nibbindati…pe… jivhāyapi nibbindati, rasesupi nibbindati…pe… kāyasmimpi nibbindati, phoṭṭhabbesupi nibbindati…pe…

* sotasmim pi = 「耳に対しても」
* saddesu pi = 「諸々の声(音)に対しても」
* …pe… = 「(中略)」
  * 眼の場合と同様に、識・触・触を縁とする受までが省略されている
* ghānasmim pi = 「鼻に対しても」
* gandhesu pi = 「諸々の香りに対しても」
* jivhāya pi = 「舌に対しても」
* rasesu pi = 「諸々の味に対しても」
* kāyasmim pi = 「身に対しても」
* phoṭṭhabbesu pi = 「諸々の触れられるもの(所触)に対しても」

→「耳に対しても厭い、諸々の声に対しても厭う……(中略)……鼻に対しても厭い、諸々の香りに対しても厭う……(中略)……舌に対しても厭い、諸々の味に対しても厭う……(中略)……身に対しても厭い、諸々の触れられるものに対しても厭う……(中略)……」

3. manasmimpi nibbindati, dhammesupi nibbindati, manoviññāṇepi nibbindati, manosamphassepi nibbindati, yamidaṃ manosamphassapaccayā uppajjati vedayitaṃ sukhaṃ vā dukkhaṃ vā adukkhamasukhaṃ vā tasmimpi nibbindati,

* manasmim pi = 「意に対しても」
* dhammesu pi = 「諸々の法(意の対象)に対しても」
* mano-viññāṇe pi = 「意識に対しても」
* mano-samphasse pi = 「意触に対しても」
* yam idaṃ mano-samphassa-paccayā uppajjati vedayitaṃ = 「意触を縁として生じるこの感受されたもの」
* sukhaṃ vā dukkhaṃ vā adukkhamasukhaṃ vā = 「楽であれ、苦であれ、不苦不楽であれ」
* tasmim pi nibbindati = 「それに対しても厭う」

→「意に対しても厭い、諸々の法に対しても厭い、意識に対しても厭い、意触に対しても厭い、意触を縁として生じる楽・苦・不苦不楽の感受に対しても厭う。」

4. nibbindaṃ virajjati, virāgā vimuccati, vimuttasmiṃ vimuttamiti ñāṇaṃ hoti.

* nibbindaṃ = 「厭いつつ」
  * nibbindati の現在分詞・単数主格
* virajjati = 「貪りを離れる(離貪する)」
* virāgā = 「離貪によって」(奪格)
* vimuccati = 「解脱する」
* vimuttasmiṃ = 「解脱したときに」(処格)
* vimuttam iti ñāṇaṃ hoti = 「『解脱した』という智が生じる」
  * ñāṇa = 「智、知」

→「厭って貪りを離れ、離貪によって解脱する。解脱したときに『解脱した』という智が生じる。」

5. Khīṇā jāti, vusitaṃ brahmacariyaṃ, kataṃ karaṇīyaṃ, nāparaṃ itthattāyāti pajānātī’’ti.

* khīṇā jāti = 「生は尽きた」
  * khīṇā = 「尽きた」(khīyati の過去分詞)
* vusitaṃ brahmacariyaṃ = 「梵行は完成した(住み終えた)」
  * vusita = vasati(住む)の過去分詞
* kataṃ karaṇīyaṃ = 「なすべきことはなされた」
  * karaṇīya = 「なされるべきこと」(未来受動分詞)
* nāparaṃ itthattāya = 「もはやこの状態(輪廻の生存)に戻ることはない」
  * na aparaṃ = 「さらには〜ない」
  * itthattāya = 「このような状態のために、この(輪廻の)状態へ」
* iti pajānāti = 「〜と知る」
* ti = 経全体の引用の終わり

→「『生は尽きた。梵行は完成した。なすべきことはなされた。もはやこの状態に戻ることはない』と知る、と(世尊は説かれた)。」

6. Imasmiñca pana veyyākaraṇasmiṃ bhaññamāne tassa bhikkhusahassassa anupādāya āsavehi cittāni vimucciṃsu.

* imasmiñ ca pana veyyākaraṇasmiṃ bhaññamāne = 「そして、この解説が説かれているとき」
  * veyyākaraṇa = 「解説、詳説(問答体でない散文の説法)」
  * bhaññamāne = 「説かれているとき」(bhaññati の現在分詞・処格、絶対処格構文)
* tassa bhikkhu-sahassassa = 「その千人の比丘たちの」
  * sahassa = 「千」
* anupādāya = 「取著することなく」
  * an-upādāya = upādiyati(取著する)の連続体の否定形
* āsavehi = 「諸々の漏から」(奪格)
  * āsava = 「漏、煩悩」
* cittāni vimucciṃsu = 「心が解脱した」
  * vimucciṃsu = vimuccati のアオリスト・複数

→「そして、この解説が説かれているとき、その千人の比丘たちの心は、取著することなく諸々の漏から解脱した。」

7. Ādittapariyāyasuttaṃ niṭṭhitaṃ.

* āditta-pariyāya-suttaṃ = 「燃焼の教説の経(燃える教えの経)」
  * āditta = 「燃えている」(ādippati の過去分詞)
  * pariyāya = 「教説、説き方、法門」
* niṭṭhitaṃ = 「終わった、完結した」

→「燃焼の教説の経、終わり。」

8. Uruvelapāṭihāriyaṃ tatiyabhāṇavāro niṭṭhito.

* uruvela-pāṭihāriyaṃ = 「ウルヴェーラーでの神変(の章)」
  * pāṭihāriya = 「神変、奇跡」
* tatiya-bhāṇavāro = 「第三誦分」
  * tatiya = 「第三の」
  * bhāṇavāra = 「誦分(誦出の一区切り)」
* niṭṭhito = 「終わった」

→「ウルヴェーラーでの神変(を含む)第三誦分、終わり。」
