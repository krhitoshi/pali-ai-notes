# 5. Brahmayācanakathā

## 7

7. [ayaṃ brahmayācanakathā dī. ni. 2.64 ādayo; ma. ni. 1.281 ādayo; ma. ni. 2.336 ādayo; saṃ. ni. 1.172 ādayo] Atha kho bhagavā sattāhassa accayena tamhā samādhimhā vuṭṭhahitvā rājāyatanamūlā yena ajapālanigrodho tenupasaṅkami. Tatra sudaṃ bhagavā ajapālanigrodhamūle viharati. Atha kho bhagavato rahogatassa paṭisallīnassa evaṃ cetaso parivitakko udapādi – ‘‘adhigato kho myāyaṃ dhammo gambhīro duddaso duranubodho santo paṇīto atakkāvacaro nipuṇo paṇḍitavedanīyo. Ālayarāmā kho panāyaṃ pajā ālayaratā ālayasammuditā. Ālayarāmāya kho pana pajāya ālayaratāya ālayasammuditāya duddasaṃ idaṃ ṭhānaṃ yadidaṃ idappaccayatāpaaccasamuppādo; idampi kho ṭhānaṃ sududdasaṃ yadidaṃ sabbasaṅkhārasamatho sabbūpadhipaṭinissaggo taṇhākkhayo virāgo nirodho nibbānaṃ. Ahañceva kho pana dhammaṃ deseyyaṃ, pare ca me na ājāneyyuṃ, so mamassa kilamatho, sā mamassa vihesā’’ti. Apissu bhagavantaṃ imā anacchariyā gāthāyo paṭibhaṃsu pubbe assutapubbā –

‘‘Kicchena me adhigataṃ, halaṃ dāni pakāsituṃ;

Rāgadosaparetehi, nāyaṃ dhammo susambudho.

‘‘Paṭisotagāmiṃ nipuṇaṃ, gambhīraṃ duddasaṃ aṇuṃ;

Rāgarattā na dakkhanti, tamokhandhena āvuṭā [āvaṭā (sī.)]’’ti.

Itiha bhagavato paṭisañcikkhato appossukkatāya cittaṃ namati, no dhammadesanāya.

→「貪りに染まった者たちは、闇の塊に覆われて、（この法を）見ないだろう。」

15. Itiha bhagavato paṭisañcikkhato appossukkatāya cittaṃ namati, no dhammadesanāya.

* itiha = 「このように」

* appossukkatāya = 「かかわらないこと（説法への無関心）へと」（与格）
  * appossukkatā = 「努力しないこと、あえてかかわらないこと」（appa-ussuka-tā）
* cittaṃ namati = 「心が傾いた」（歴史的現在）
* no dhammadesanāya = 「法を説くことへは（傾か）なかった」

→「このように考察している世尊の心は、あえてかかわらないことへと傾き、法を説くことへは傾かなかった。」

1. 8. Atha kho brahmuno sahampatissa bhagavato cetasā cetoparivitakkamaññāya etadahosi – ‘‘nassati vata bho loko, vinassati vata bho loko, yatra hi nāma tathāgatassa arahato sammāsambuddhassa appossukkatāya cittaṃ namati [namissati (?)], no dhammadesanāyā’’ti.

* atha kho = 「そこで、さて」
* brahmuno sahampatissa = 「梵天サハンパティに」（属格。etadahosi の意味上の主体）
* bhagavato cetasā cetoparivitakkamaññāya = 「世尊の心の思考を（自分の）心で知って」
  * ceto-parivitakka = 「心の思考、心中の考え」
  * aññāya = 「知って」（ājānāti の連続体）
* etadahosi = 「このような思いが起こった」（etad ahosi）
* nassati vata bho loko = 「ああ、世界は滅びる」
  * vata = 「ああ」（感嘆の不変化詞）
  * bho = 「君よ、ああ」（呼びかけの不変化詞）
* vinassati vata bho loko = 「ああ、世界は消え失せる」
* yatra hi nāma = 「まさに～というのだから」
* tathāgatassa arahato sammāsambuddhassa = 「如来・阿羅漢・正等覚者の」
* appossukkatāya cittaṃ namati = 「心が無関心（何もしないこと）へと傾く」
  * appossukkatā = 「無関心であること、あえて行動しないこと」（appa-ussuka の抽象名詞）
  * namati = 「傾く」（異読 namissati = 「傾くだろう」）
* no dhammadesanāya = 「法を説くことへではなく」

→「そこで梵天サハンパティは、世尊の心の思考を心で知って、このような思いが起こった――『ああ、世界は滅びる。ああ、世界は消え失せる。如来・阿羅漢・正等覚者の心が、法を説くことへではなく、無関心へと傾くのだから』と。」

2. Atha kho brahmā sahampati – seyyathāpi nāma balavā puriso samiñjitaṃ vā bāhaṃ pasāreyya, pasāritaṃ vā bāhaṃ samiñjeyya evameva – brahmaloke antarahito bhagavato purato pāturahosi.

* seyyathāpi nāma = 「あたかも～のように」
* balavā puriso = 「力のある人が」
* samiñjitaṃ vā bāhaṃ pasāreyya = 「曲げた腕を伸ばし」
  * samiñjita = 「曲げられた」（samiñjati の過去分詞）
  * pasāreyya = 「伸ばすであろう」（願望法）
* pasāritaṃ vā bāhaṃ samiñjeyya = 「あるいは伸ばした腕を曲げるように」
* evameva = 「ちょうどそのように」
* brahmaloke antarahito = 「梵天界で姿を消して」
  * antarahita = 「消えた、隠没した」（antaradhāyati の過去分詞）
* bhagavato purato pāturahosi = 「世尊の前に現れた」
  * purato = 「前に」
  * pāturahosi = 「現れた」（pātu(r) + ahosi）

→「そこで梵天サハンパティは、あたかも力のある人が曲げた腕を伸ばし、伸ばした腕を曲げるように、ちょうどそのように、梵天界で姿を消して世尊の前に現れた。」

3. Atha kho brahmā sahampati ekaṃsaṃ uttarāsaṅgaṃ karitvā dakkhiṇajāṇumaṇḍalaṃ pathaviyaṃ nihantvā yena bhagavā tenañjaliṃ paṇāmetvā bhagavantaṃ etadavoca – ‘‘desetu, bhante, bhagavā dhammaṃ, desetu sugato dhammaṃ.

* ekaṃsaṃ uttarāsaṅgaṃ karitvā = 「上衣を片方の肩にかけて」（右肩をあらわす作法）
  * uttarāsaṅga = 「上衣」
* dakkhiṇajāṇumaṇḍalaṃ pathaviyaṃ nihantvā = 「右の膝を地につけて」
  * jāṇu-maṇḍala = 「膝がしら」
  * nihantvā = 「打ちつけて、（地に）つけて」（nihanati の連続体）
* yena bhagavā tenañjaliṃ paṇāmetvā = 「世尊のいる方へ合掌を差し向けて」
  * añjaliṃ paṇāmetvā = 「合掌をささげて」
* bhagavantaṃ etadavoca = 「世尊にこう言った」
* desetu, bhante, bhagavā dhammaṃ = 「尊師よ、世尊は法をお説きください」
  * desetu = 「説いてください」（deseti の命令法・三人称）
* desetu sugato dhammaṃ = 「善逝は法をお説きください」

→「そこで梵天サハンパティは、上衣を片方の肩にかけ、右の膝を地につけ、世尊のいる方へ合掌を差し向けて、世尊にこう言った――『尊師よ、世尊は法をお説きください。善逝は法をお説きください。』」

4. Santi sattā apparajakkhajātikā, assavanatā dhammassa parihāyanti , bhavissanti dhammassa aññātāro’’ti.

* santi sattā = 「衆生たちがいます」
* apparajakkhajātikā = 「生まれつき（眼の）塵が少ない者たち」
  * appa-rajakkha = 「塵（汚れ）の少ない」
  * jātika = 「～の性質を持つ、生まれつきの」
* assavanatā dhammassa parihāyanti = 「法を聞かないために衰えています」
  * assavanatā = 「聞かないこと（の故に）」（a-savana の抽象名詞、奪格的用法）
  * parihāyanti = 「衰える、退失する」
