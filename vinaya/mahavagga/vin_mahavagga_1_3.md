# 3. Mucalindakathā

## 5

5. [udā. 11] Atha kho bhagavā sattāhassa accayena tamhā samādhimhā vuṭṭhahitvā ajapālanigrodhamūlā yena mucalindo tenupasaṅkami, upasaṅkamitvā mucalindamūle sattāhaṃ ekapallaṅkena nisīdi vimuttisukhapaṭisaṃvedī. Tena kho pana samayena mahā akālamegho udapādi, sattāhavaddalikā sītavātaduddinī. Atha kho mucalindo nāgarājā sakabhavanā nikkhamitvā bhagavato kāyaṃ sattakkhattuṃ bhogehi parikkhipitvā uparimuddhani mahantaṃ phaṇaṃ karitvā aṭṭhāsi – ‘‘mā bhagavantaṃ sītaṃ, mā bhagavantaṃ uṇhaṃ, mā bhagavantaṃ ḍaṃsamakasavātātapasarīsapasamphasso’’ti […siriṃ sapa… (sī. syā. kaṃ.)]. Atha kho mucalindo nāgarājā sattāhassa accayena viddhaṃ vigatavalāhakaṃ devaṃ viditvā bhagavato kāyā bhoge viniveṭhetvā sakavaṇṇaṃ paṭisaṃharitvā māṇavakavaṇṇaṃ abhinimminitvā bhagavato purato aṭṭhāsi pañjaliko bhagavantaṃ namassamāno. Atha kho bhagavā etamatthaṃ viditvā tāyaṃ velāyaṃ imaṃ udānaṃ udānesi –

[kathā. 338 kathāvatthupāḷiyampi]‘‘Sukho viveko tuṭṭhassa, sutadhammassa passato;

Abyāpajjaṃ sukhaṃ loke, pāṇabhūtesu saṃyamo.

[kathā. 338 kathāvatthupāḷiyampi]‘‘Sukhā virāgatā loke, kāmānaṃ samatikkamo;

Asmimānassa yo vinayo, etaṃ ve paramaṃ sukha’’nti.

Mucalindakathā niṭṭhitā.

1. 3. Mucalindakathā

* mucalinda-kathā = 「ムチャリンダの話」
  * mucalinda = 「ムチャリンダ（龍王の名、また樹の名）」
  * kathā = 「話、物語」

→「ムチャリンダの話」

2. 5. [udā. 11] Atha kho bhagavā sattāhassa accayena tamhā samādhimhā vuṭṭhahitvā ajapālanigrodhamūlā yena mucalindo tenupasaṅkami, upasaṅkamitvā mucalindamūle sattāhaṃ ekapallaṅkena nisīdi vimuttisukhapaṭisaṃvedī.

* atha kho = 「さて、そこで」
* bhagavā = 「世尊は」
* sattāhassa accayena = 「七日の経過の後に」
  * sattāha = 「七日間」（satta-aha）
  * accayena = 「経過によって、～の後に」
* tamhā samādhimhā vuṭṭhahitvā = 「その三昧から出て」
  * vuṭṭhahitvā = 「出て、出定して（vuṭṭhāti の連続体）」
* ajapālanigrodhamūlā = 「アジャパーラ・ニグローダ樹の根元から」（奪格）
* yena mucalindo tenupasaṅkami = 「ムチャリンダ樹のあるところへ近づいた」
* upasaṅkamitvā = 「近づいて」
* mucalindamūle = 「ムチャリンダ樹の根元で」
* sattāhaṃ = 「七日間」
* ekapallaṅkena nisīdi = 「一つの結跏趺坐のままで坐った」
* vimuttisukhapaṭisaṃvedī = 「解脱の楽を感受する者として」
  * vimutti = 「解脱」
  * sukha = 「楽」
  * paṭisaṃvedī = 「感受する者」

→「さて世尊は、七日の経過の後にその三昧から出て、アジャパーラ・ニグローダ樹の根元からムチャリンダ樹のあるところへ近づいた。近づいて、ムチャリンダ樹の根元で七日間、一つの結跏趺坐のままで、解脱の楽を感受しながら坐った。」

3. Tena kho pana samayena mahā akālamegho udapādi, sattāhavaddalikā sītavātaduddinī.

  * akāla = 「時ならぬ、季節はずれの」
  * megha = 「雨雲」
* udapādi = 「生じた（uppajjati のアオリスト）」
* sattāhavaddalikā = 「七日間の雨曇りがあり」
  * vaddalikā = 「雨曇り、雨天の続くこと」
* sītavātaduddinī = 「冷たい風の吹く悪天候であった」
  * sīta = 「冷たい」
  * vāta = 「風」
  * duddinī = 「悪天候の日、荒れた天気」

→「さてその時、大きな季節はずれの雨雲が生じ、七日間の雨曇りとなり、冷たい風の吹く悪天候であった。」

4. Atha kho mucalindo nāgarājā sakabhavanā nikkhamitvā bhagavato kāyaṃ sattakkhattuṃ bhogehi parikkhipitvā uparimuddhani mahantaṃ phaṇaṃ karitvā aṭṭhāsi –

* sakabhavanā nikkhamitvā = 「自分の住居から出て」

  * bhavana = 「住居」
* bhagavato kāyaṃ = 「世尊の身体を」
* sattakkhattuṃ = 「七回」
* bhogehi parikkhipitvā = 「とぐろで取り巻いて」
  * bhoga = 「（蛇の）とぐろ」
  * parikkhipitvā = 「取り巻いて、囲んで」
* uparimuddhani = 「頭の上に」

→「さて龍王ムチャリンダは、自分の住居から出て、世尊の身体を七回とぐろで取り巻き、頭の上に大きな鎌首を作って立った。」

5. ‘‘mā bhagavantaṃ sītaṃ, mā bhagavantaṃ uṇhaṃ, mā bhagavantaṃ ḍaṃsamakasavātātapasarīsapasamphasso’’ti […siriṃ sapa… (sī. syā. kaṃ.)].

* mā bhagavantaṃ sītaṃ = 「世尊に寒さが（触れることが）ありませんように」
  * mā = 「～ないように」（禁止・願望の不変化詞）
  * sītaṃ = 「寒さ」
* mā bhagavantaṃ uṇhaṃ = 「世尊に暑さがありませんように」
  * uṇhaṃ = 「暑さ、熱」
* mā bhagavantaṃ ḍaṃsamakasavātātapasarīsapasamphasso = 「世尊に虻・蚊・風・炎熱・爬虫類との接触がありませんように」
  * ḍaṃsa = 「虻」
  * makasa = 「蚊」
  * vāta = 「風」
  * ātapa = 「炎熱、日射し」
  * sarīsapa = 「爬虫類、這うもの」
  * samphassa = 「接触」
* ti = 「～と（考えて）」
* […siriṃ sapa… (sī. syā. kaṃ.)] = 「（異読の注記：シンハラ本・シャム本・カンボジア本では siriṃsapa と綴る）」

→「『世尊に寒さがありませんように、世尊に暑さがありませんように、世尊に虻・蚊・風・炎熱・爬虫類との接触がありませんように』と。」

6. Atha kho mucalindo nāgarājā sattāhassa accayena viddhaṃ vigatavalāhakaṃ devaṃ viditvā bhagavato kāyā bhoge viniveṭhetvā sakavaṇṇaṃ paṭisaṃharitvā māṇavakavaṇṇaṃ abhinimminitvā bhagavato purato aṭṭhāsi pañjaliko bhagavantaṃ namassamāno.

* sattāhassa accayena = 「七日の経過の後に」
* viddhaṃ vigatavalāhakaṃ devaṃ viditvā = 「晴れて雲の去った空を知って」
  * viddha = 「晴れ渡った、澄んだ」
  * vigata-valāhaka = 「雲の去った」（valāhaka = 「雲」）
  * deva = 「空」（ここでは「天空、天候」の意）
* bhagavato kāyā = 「世尊の身体から」（奪格）
* bhoge viniveṭhetvā = 「とぐろを解いて」
  * viniveṭhetvā = 「ほどいて、解いて」
* sakavaṇṇaṃ paṭisaṃharitvā = 「自分の姿を引っ込めて」
  * saka-vaṇṇa = 「自分の姿・形」
  * paṭisaṃharitvā = 「引っ込めて、収めて」
* māṇavakavaṇṇaṃ abhinimminitvā = 「青年の姿を化作して」
  * māṇavaka = 「青年、若者」
  * abhinimminitvā = 「化作して、（神通で）作り出して」
* bhagavato purato aṭṭhāsi = 「世尊の前に立った」
* pañjaliko = 「合掌して」
* bhagavantaṃ namassamāno = 「世尊を礼拝しながら」
  * namassamāna = 「礼拝している（namassati の現在分詞）」

→「さて龍王ムチャリンダは、七日の経過の後に、晴れて雲の去った空を知って、世尊の身体からとぐろを解き、自分の姿を引っ込めて青年の姿を化作し、合掌して世尊を礼拝しながら世尊の前に立った。」

7. Atha kho bhagavā etamatthaṃ viditvā tāyaṃ velāyaṃ imaṃ udānaṃ udānesi –

8. [kathā. 338 kathāvatthupāḷiyampi]‘‘Sukho viveko tuṭṭhassa, sutadhammassa passato;

* [kathā. 338 kathāvatthupāḷiyampi] = 「（参照注記：Kathāvatthu 338 にもこの偈がある）」
* sukho viveko = 「遠離は楽である」
  * viveka = 「遠離、独処」
* tuṭṭhassa = 「満足した者にとって」
  * tuṭṭha = 「満足した（tussati の過去分詞）」
* sutadhammassa = 「法を聞いた者にとって」
  * suta = 「聞いた」

  * passant = 「見ている（passati の現在分詞）」の属格

→「満足し、法を聞き、（法を）見る者にとって、遠離は楽である。」

9. Abyāpajjaṃ sukhaṃ loke, pāṇabhūtesu saṃyamo.

* abyāpajjaṃ = 「悩害しないことは」
  * a-byāpajja = 「悩害のないこと、害意のないこと」
* sukhaṃ loke = 「世において楽である」
* pāṇabhūtesu saṃyamo = 「生き物たちに対する自制は」
  * pāṇa-bhūta = 「生き物、生類」
  * saṃyama = 「自制、抑制」

→「世において、悩害しないこと、生き物たちに対する自制は楽である。」

10. [kathā. 338 kathāvatthupāḷiyampi]‘‘Sukhā virāgatā loke, kāmānaṃ samatikkamo;

* sukhā virāgatā loke = 「世において離貪は楽である」
  * virāgatā = 「離貪であること、貪りを離れた状態」
* kāmānaṃ samatikkamo = 「諸欲の超越は」
  * kāma = 「欲、欲望の対象」
  * samatikkama = 「超越、乗り越えること」

→「世において離貪、すなわち諸欲の超越は楽である。」

11. Asmimānassa yo vinayo, etaṃ ve paramaṃ sukha’’nti.

* asmimānassa = 「『私はある』という慢の」
  * asmi-māna = 「『私はある』という慢、我慢」（asmi = 「私はある（atthi の一人称単数）」）
* yo vinayo = 「その除去」
  * vinaya = 「除去、調伏」
* etaṃ ve = 「これこそ実に」
  * ve = 「実に」（強調の不変化詞）
* paramaṃ sukhaṃ = 「最高の楽である」
* ti = 「～と」（引用の終わり）

→「『私はある』という慢の除去、これこそ実に最高の楽である、と。」

12. Mucalindakathā niṭṭhitā.

* mucalindakathā = 「ムチャリンダの話は」
* niṭṭhitā = 「終わった（niṭṭhāti の過去分詞）」

→「ムチャリンダの話、終わり。」
