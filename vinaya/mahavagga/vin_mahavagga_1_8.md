# 8. Mārakathā

## 32

32. Atha kho bhagavā te bhikkhū āmantesi [saṃ. ni. 1.141 mārasaṃyuttepi] – ‘‘muttāhaṃ, bhikkhave, sabbapāsehi, ye dibbā ye ca mānusā. Tumhepi, bhikkhave , muttā sabbapāsehi, ye dibbā ye ca mānusā. Caratha, bhikkhave, cārikaṃ bahujanahitāya bahujanasukhāya lokānukampāya atthāya hitāya sukhāya devamanussānaṃ. Mā ekena dve agamittha. Desetha, bhikkhave, dhammaṃ ādikalyāṇaṃ majjhekalyāṇaṃ pariyosānakalyāṇaṃ sātthaṃ sabyañjanaṃ kevalaparipuṇṇaṃ parisuddhaṃ brahmacariyaṃ pakāsetha. Santi sattā apparajakkhajātikā , assavanatā dhammassa parihāyanti, bhavissanti dhammassa aññātāro. Ahampi, bhikkhave, yena uruvelā senānigamo tenupasaṅkamissāmi dhammadesanāyā’’ti.

### 対訳

1. 8. Mārakathā

* māra-kathā = 「魔の話」
  * māra = 「魔、マーラ(悪魔)」
  * kathā = 「話、物語」

→「魔の話」

2. 32. Atha kho bhagavā te bhikkhū āmantesi [saṃ. ni. 1.141 mārasaṃyuttepi] –

* atha kho = 「そこで、さて」
* bhagavā = 「世尊は」
* te bhikkhū = 「それらの比丘たちに」
* āmantesi = 「呼びかけた(āmanteti のアオリスト)」
* [saṃ. ni. 1.141 mārasaṃyuttepi] = 「(参照指示: 相応部 1.141 魔相応にも)」

→「そこで世尊はそれらの比丘たちに呼びかけた――」

3. ‘‘muttāhaṃ, bhikkhave, sabbapāsehi, ye dibbā ye ca mānusā.

* muttā ahaṃ = 「私は解き放たれている」(muttāhaṃ = mutto + ahaṃ の連声)
  * mutta = 「解き放たれた(muñcati の過去分詞)」
* bhikkhave = 「比丘たちよ」
* sabba-pāsehi = 「すべての罠から」
  * pāsa = 「罠、わな縄」
* ye dibbā ye ca mānusā = 「天のものも、人のものも」
  * dibba = 「天の、神々に属する」
  * mānusa = 「人間の」

→「比丘たちよ、私は天のものであれ人のものであれ、すべての罠から解き放たれている。」

4. Tumhepi, bhikkhave , muttā sabbapāsehi, ye dibbā ye ca mānusā.

* tumhe pi = 「あなたたちもまた」
* muttā = 「解き放たれている(複数形)」
* sabbapāsehi, ye dibbā ye ca mānusā = 「天のものも人のものも、すべての罠から」

→「比丘たちよ、あなたたちもまた、天のものであれ人のものであれ、すべての罠から解き放たれている。」

5. Caratha, bhikkhave, cārikaṃ bahujanahitāya bahujanasukhāya lokānukampāya atthāya hitāya sukhāya devamanussānaṃ.

* caratha = 「歩みなさい(carati の命令法・二人称複数)」
* cārikaṃ = 「遊行を」
  * cārikā = 「遊行、旅」
* bahujana-hitāya = 「多くの人々の利益のために」
* bahujana-sukhāya = 「多くの人々の幸福のために」
* loka-anukampāya = 「世間への憐れみのために」
  * anukampā = 「憐れみ、慈しみ」
* atthāya hitāya sukhāya = 「利益のため、幸福のため、安楽のため」
* deva-manussānaṃ = 「神々と人間たちの」

→「比丘たちよ、多くの人々の利益のため、多くの人々の幸福のため、世間への憐れみのため、神々と人間たちの利益・幸福・安楽のために遊行しなさい。」

6. Mā ekena dve agamittha.

* mā ... agamittha = 「行ってはならない(mā + アオリスト二人称複数で禁止)」
* ekena = 「一つの(道)によって」
* dve = 「二人で」

→「一つの道を二人で行ってはならない。」

7. Desetha, bhikkhave, dhammaṃ ādikalyāṇaṃ majjhekalyāṇaṃ pariyosānakalyāṇaṃ sātthaṃ sabyañjanaṃ kevalaparipuṇṇaṃ parisuddhaṃ brahmacariyaṃ pakāsetha.

* desetha = 「説きなさい(deseti の命令法・二人称複数)」
* dhammaṃ = 「法を」
* ādi-kalyāṇaṃ = 「初めが善く」
  * kalyāṇa = 「善い、美しい」
* majjhe-kalyāṇaṃ = 「中間が善く」
* pariyosāna-kalyāṇaṃ = 「終わりが善い」
  * pariyosāna = 「終結、終わり」
* sātthaṃ = 「意味を備えた」(sa + attha)
* sabyañjanaṃ = 「文を備えた」(sa + byañjana)
  * byañjana = 「文字、語句、表現」
* kevala-paripuṇṇaṃ = 「完全に円満な」
  * kevala = 「全体の、まったく」
  * paripuṇṇa = 「満たされた、円満な」
* parisuddhaṃ = 「清浄な」
* brahmacariyaṃ = 「梵行を」
* pakāsetha = 「明らかにしなさい(pakāseti の命令法・二人称複数)」

→「比丘たちよ、初めが善く、中間が善く、終わりが善く、意味を備え文を備えた法を説き、完全に円満で清浄な梵行を明らかにしなさい。」

8. Santi sattā apparajakkhajātikā , assavanatā dhammassa parihāyanti, bhavissanti dhammassa aññātāro.

* santi = 「存在する(atthi の三人称複数)」
* sattā = 「衆生たちが」
* appa-rajakkha-jātikā = 「(智慧の)眼の塵が少ない性質の者たち」
  * appa = 「少ない」
  * rajakkha = 「眼の塵、汚れ」(raja = 塵 + akkha = 眼)(要確認)
  * jātika = 「〜の性質を持つ」
* assavanatā = 「聞かないことのために」
  * a-savana = 「聞かないこと」+ 抽象名詞語尾 -tā(奪格的用法)
* dhammassa = 「法を」
* parihāyanti = 「衰退する、(利益を)失う」
* bhavissanti = 「(彼らは)〜となるだろう」
* dhammassa aññātāro = 「法を了解する者たち」
  * aññātar = 「了解する者(ājānāti から)」

→「(智慧の)眼の塵が少ない性質の衆生たちがいる。彼らは法を聞かないために衰退するが、(聞けば)法を了解する者となるだろう。」

9. Ahampi, bhikkhave, yena uruvelā senānigamo tenupasaṅkamissāmi dhammadesanāyā’’ti.

* aham pi = 「私もまた」
* yena ... tena = 「〜の方へ(方向を示す慣用表現)」
* uruvelā = 「ウルヴェーラー(地名)」
* senānigamo = 「セーナー村(セーナーニガマ)」
* upasaṅkamissāmi = 「近づいて行くだろう(upasaṅkamati の未来形)」
* dhamma-desanāya = 「法を説くために」
  * desanā = 「説示、説法」
* ti = 「〜と(引用の終わり)」

→「比丘たちよ、私もまた法を説くために、ウルヴェーラーのセーナー村へ行くだろう。」

## 33

33. Atha kho māro pāpimā yena bhagavā tenupasaṅkami, upasaṅkamitvā bhagavantaṃ gāthāya ajjhabhāsi –

‘‘Baddhosi sabbapāsehi, ye dibbā ye ca mānusā;

Mahābandhanabaddhosi, na me samaṇa mokkhasī’’ti.

‘‘Muttāhaṃ [muttohaṃ (sī. syā.)] sabbapāsehi, ye dibbā ye ca mānusā;

Mahābandhanamuttomhi, nihato tvamasi antakāti.

[saṃ. ni. 1.151 mārasaṃyuttepi] ‘‘Antalikkhacaro pāso, yvāyaṃ carati mānaso;

Tena taṃ bādhayissāmi, na me samaṇa mokkhasīti.

[saṃ. ni. 1.1151 mārasaṃyuttepi] ‘‘Rūpā saddā rasā gandhā, phoṭṭhabbā ca manoramā;

### 対訳

1. 33. Atha kho māro pāpimā yena bhagavā tenupasaṅkami, upasaṅkamitvā bhagavantaṃ gāthāya ajjhabhāsi –

* atha kho = 「そのとき」
* māro pāpimā = 「悪魔マーラは」
  * pāpimant = 「悪しき者(マーラの常套の呼称)」
* yena bhagavā tenupasaṅkami = 「世尊のいるところへ近づいた」
  * yena ... tena = 「～のいるところへ」(方向を示す慣用句)
  * upasaṅkami = 「近づいた(upasaṅkamati のアオリスト)」
* upasaṅkamitvā = 「近づいて(連続体)」
* bhagavantaṃ = 「世尊に(対格)」
* gāthāya = 「偈によって(具格)」
* ajjhabhāsi = 「語りかけた(adhibhāsati のアオリスト)」

→「そのとき悪魔マーラは世尊のいるところへ近づいた。近づいて世尊に偈で語りかけた。」

2. ‘‘Baddhosi sabbapāsehi, ye dibbā ye ca mānusā;

* baddhosi = baddho asi = 「あなたは縛られている」
  * baddha = 「縛られた(bandhati の過去分詞)」
* sabbapāsehi = 「すべての罠によって(具格複数)」
  * pāsa = 「罠、わな縄」
* ye dibbā ye ca mānusā = 「天のものであれ人のものであれ」
  * dibba = 「天の」
  * mānusa = 「人間の」

→「あなたは、天のものであれ人のものであれ、すべての罠によって縛られている。」

3. Mahābandhanabaddhosi, na me samaṇa mokkhasī’’ti.

* mahābandhanabaddhosi = mahā-bandhana-baddho asi = 「あなたは大きな束縛に縛られている」
  * bandhana = 「束縛、縛るもの」
* na me ... mokkhasi = 「あなたは私から逃れられない」
  * me = 「私から(奪格的用法)」
  * mokkhasi = 「逃れるだろう(muccati の未来形)」
* samaṇa = 「沙門よ(呼格)」
* ti = 「～と(引用)」

→「あなたは大きな束縛に縛られている。沙門よ、あなたは私から逃れられない、と。」

4. ‘‘Muttāhaṃ [muttohaṃ (sī. syā.)] sabbapāsehi, ye dibbā ye ca mānusā;

* muttāhaṃ = mutto ahaṃ = 「私は解き放たれている」
  * mutta = 「解き放たれた(muccati の過去分詞)」
  * 異読 muttohaṃ (シンハラ本・シャム本)も同義
* sabbapāsehi = 「すべての罠から(具格・分離の意)」
* ye dibbā ye ca mānusā = 「天のものであれ人のものであれ」

→「私は、天のものであれ人のものであれ、すべての罠から解き放たれている。」

5. Mahābandhanamuttomhi, nihato tvamasi antakāti.

* mahābandhanamuttomhi = mahā-bandhana-mutto amhi = 「私は大きな束縛から解き放たれている」
* nihato tvamasi = nihato tvaṃ asi = 「あなたは打ち破られた」
  * nihata = 「打ち倒された(nihanti の過去分詞)」
* antakā = antaka = 「終わらせる者よ(呼格。死魔=マーラの呼称)」
* ti = 「～と(引用)」

→「私は大きな束縛から解き放たれている。終わらせる者よ、あなたは打ち破られた、と。」

6. [saṃ. ni. 1.151 mārasaṃyuttepi] ‘‘Antalikkhacaro pāso, yvāyaṃ carati mānaso;

* antalikkhacaro = 「空中を行く」
  * antalikkha = 「空中、虚空」
  * cara = 「行くもの」
* pāso = 「罠は」
* yvāyaṃ = yo ayaṃ = 「このものが」
* carati = 「動き回る」
* mānaso = 「意から成る(罠)」
  * mānasa = 「意の、心の」
* [saṃ. ni. 1.151 mārasaṃyuttepi] = 「相応部マーラ相応にも並行箇所がある旨の校訂者注記」

→「意から成るこの罠は、空中を行き、動き回る。」

7. Tena taṃ bādhayissāmi, na me samaṇa mokkhasīti.

* tena = 「それによって(具格)」
* taṃ = 「あなたを(対格)」
* bādhayissāmi = 「捕らえよう(bādheti の未来形)」
  * bādheti = 「縛る、捕らえる、悩ます」
* na me samaṇa mokkhasi = 「沙門よ、あなたは私から逃れられない」
* ti = 「～と(引用)」

→「それによってあなたを捕らえよう。沙門よ、あなたは私から逃れられない、と。」

8. [saṃ. ni. 1.1151 mārasaṃyuttepi] ‘‘Rūpā saddā rasā gandhā, phoṭṭhabbā ca manoramā;

* rūpā = 「色(見えるもの)」
* saddā = 「声(聞こえるもの)」
* rasā = 「味」
* gandhā = 「香」
* phoṭṭhabbā = 「触(触れられるもの)」
* manoramā = 「意を楽しませる(もの)」
  * mano-rama = 「心を喜ばせる」

→「意を楽しませる色・声・味・香・触、」

9. Ettha me vigato chando, nihato tvamasi antakā’’ti.

* ettha = 「ここにおいて(これらに対して)」
* me = 「私の」
* vigato = 「離れ去った(vigacchati の過去分詞)」
* chando = 「欲は」
  * chanda = 「欲、欲求」
* nihato tvamasi = 「あなたは打ち破られた」
* antakā = 「終わらせる者よ(呼格)」
* ti = 「～と(引用)」

→「これらに対する私の欲は離れ去った。終わらせる者よ、あなたは打ち破られた、と。」

10. Atha kho māro pāpimā – jānāti maṃ bhagavā, jānāti maṃ sugatoti dukkhī dummano

* atha kho = 「そのとき」
* māro pāpimā = 「悪魔マーラは」
* jānāti maṃ bhagavā = 「世尊は私を知っている」
* jānāti maṃ sugato = 「善逝は私を知っている」
  * sugata = 「善逝(よく行かれた方。仏陀の称号)」
* ti = 「～と(思って)」
* dukkhī = 「苦しみ」
* dummano = 「意気消沈して」
  * du(r)-mano = 「心が沈んだ、落胆した」

→「そのとき悪魔マーラは『世尊は私を知っている、善逝は私を知っている』と苦しみ、意気消沈して、」

11. Tatthevantaradhāyīti.

* tattheva = tattha eva = 「まさにその場で」
* antaradhāyi = 「消え去った(antaradhāyati のアオリスト)」
* ti = 「～と(章の結び)」

→「まさにその場で消え去った。」

12. Mārakathā niṭṭhitā.

* māra-kathā = 「マーラの話」
* niṭṭhitā = 「終わった(niṭṭhāti の過去分詞)」

→「マーラの話、終わり。」
