# 2. Ajapālakathā

## 4

4. [udā. 4] Atha kho bhagavā sattāhassa accayena tamhā samādhimhā vuṭṭhahitvā bodhirukkhamūlā yena ajapālanigrodho tenupasaṅkami, upasaṅkamitvā ajapālanigrodhamūle sattāhaṃ ekapallaṅkena nisīdi vimuttisukhapaṭisaṃvedī. Atha kho aññataro huṃhuṅkajātiko brāhmaṇo yena bhagavā tenupasaṅkami. Upasaṅkamitvā bhagavatā saddhiṃ sammodi. Sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā ekamantaṃ aṭṭhāsi. Ekamantaṃ ṭhito kho so brāhmaṇo bhagavantaṃ etadavoca – ‘‘kittāvatā nu kho, bho gotama, brāhmaṇo hoti, katame ca pana brāhmaṇakaraṇā [brāhmaṇakārakā (ka.) brāhmaṇakarāṇā (?)] dhammā’’ti? Atha kho bhagavā etamatthaṃ viditvā tāyaṃ velāyaṃ imaṃ udānaṃ udānesi –

[netti. 103] Yo brāhmaṇo bāhitapāpadhammo;

Nihuṃhuṅko nikkasāvo yatatto;

Vedantagū vusitabrahmacariyo;

Dhammena so brahmavādaṃ vadeyya;

Yassussadā natthi kuhiñci loke’’ti.

Ajapālakathā niṭṭhitā.

### 対訳

1. 2. Ajapālakathā

* ajapāla-kathā = 「アジャパーラ(樹)の話」
  * ajapāla = 「山羊飼い(aja-pāla)」。ここでは「アジャパーラ・ニグローダ樹(山羊飼いのバニヤン樹)」の名
  * kathā = 「話、物語」

→「アジャパーラ樹の話」

2. 4. [udā. 4] Atha kho bhagavā sattāhassa accayena tamhā samādhimhā vuṭṭhahitvā bodhirukkhamūlā yena ajapālanigrodho tenupasaṅkami, upasaṅkamitvā ajapālanigrodhamūle sattāhaṃ ekapallaṅkena nisīdi vimuttisukhapaṭisaṃvedī.

* atha kho = 「そこで、さて」
* bhagavā = 「世尊は」
* sattāhassa accayena = 「七日が過ぎた後に」
  * sattāha = 「七日(satta-aha)」
  * accayena = 「経過によって(accaya の具格)」
* tamhā samādhimhā vuṭṭhahitvā = 「その三昧から出て」
  * vuṭṭhahitvā = 「出て、出定して(vuṭṭhāti の連続体)」
* bodhirukkhamūlā = 「菩提樹の根元から(奪格)」
* yena ajapālanigrodho tenupasaṅkami = 「アジャパーラ・ニグローダ樹のあるところへ近づいた」
* upasaṅkamitvā = 「近づいてから」
* ajapālanigrodhamūle = 「アジャパーラ・ニグローダ樹の根元で」
* sattāhaṃ = 「七日間(対格)」
* ekapallaṅkena = 「一つの結跏趺坐のままで」
* nisīdi = 「坐った(nisīdati のアオリスト)」
* vimuttisukhapaṭisaṃvedī = 「解脱の楽を感受する者として」
  * vimutti-sukha = 「解脱の楽」
  * paṭisaṃvedī = 「感受する者」

→「さて世尊は、七日が過ぎた後にその三昧から出て、菩提樹の根元からアジャパーラ・ニグローダ樹のところへ近づいた。近づいてから、アジャパーラ・ニグローダ樹の根元で、七日間、一つの結跏趺坐のまま、解脱の楽を感受しながら坐った。」

3. Atha kho aññataro huṃhuṅkajātiko brāhmaṇo yena bhagavā tenupasaṅkami.

* aññataro = 「ある一人の」
* huṃhuṅkajātiko = 「『フン、フン』と言う性質の者」
  * huṃhuṅka = 「(慢心から発する)『フン』という声」
  * jātika = 「〜の性質・生まれの」
* brāhmaṇo = 「バラモンが」
* yena bhagavā tenupasaṅkami = 「世尊のいるところへ近づいた」

→「そのとき、『フン、フン』と(慢心の声を)発する性質のあるバラモンが、世尊のところへ近づいた。」

4. Upasaṅkamitvā bhagavatā saddhiṃ sammodi.

* upasaṅkamitvā = 「近づいてから」
* bhagavatā saddhiṃ = 「世尊とともに」
* sammodi = 「挨拶を交わした(sammodati のアオリスト)」

→「近づいて、世尊と挨拶を交わした。」

5. Sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā ekamantaṃ aṭṭhāsi.

* sammodanīyaṃ kathaṃ = 「喜ばしい言葉を」
* sāraṇīyaṃ = 「思い出に残る、記憶されるべき」
* vītisāretvā = 「交わし終えて(vītisāreti の連続体)」
* ekamantaṃ = 「一方に、傍らに」
* aṭṭhāsi = 「立った(tiṭṭhati のアオリスト)」

→「喜ばしく思い出に残る言葉を交わし終えて、一方に立った。」

6. Ekamantaṃ ṭhito kho so brāhmaṇo bhagavantaṃ etadavoca – ‘‘kittāvatā nu kho, bho gotama, brāhmaṇo hoti, katame ca pana brāhmaṇakaraṇā [brāhmaṇakārakā (ka.) brāhmaṇakarāṇā (?)] dhammā’’ti?

* ekamantaṃ ṭhito = 「一方に立った(まま)」
* so brāhmaṇo = 「そのバラモンは」
* bhagavantaṃ etadavoca = 「世尊にこう言った」
  * etad avoca = 「このことを言った」
* kittāvatā nu kho = 「いったいどれだけによって」
* bho gotama = 「ゴータマどの(bho は対等・親しみの呼びかけ)」
* brāhmaṇo hoti = 「バラモンとなるのか」
* katame ca pana = 「また、どのようなものが」
* brāhmaṇakaraṇā dhammā = 「バラモンとする諸法(バラモンたらしむる法、の意。人をバラモンにする性質)」
  * karaṇa = 「作るもの、〜とするもの」
* ti = 引用の終わり

→「一方に立ったそのバラモンは、世尊にこう言った――『ゴータマどの、いったいどれだけによってバラモンとなるのですか。また、人をバラモンとする諸法とはどのようなものですか』と。」

7. Atha kho bhagavā etamatthaṃ viditvā tāyaṃ velāyaṃ imaṃ udānaṃ udānesi –

* etamatthaṃ viditvā = 「この意味を知って」
  * etam atthaṃ = 「この意味・事柄を」
* tāyaṃ velāyaṃ = 「そのときに」
* imaṃ udānaṃ udānesi = 「この感興の言葉(ウダーナ)を発した」

→「そこで世尊は、この意味を知って、そのとき、この感興の言葉を発した――」

8. [netti. 103] Yo brāhmaṇo bāhitapāpadhammo;

* yo brāhmaṇo = 「〜であるバラモンは」
* bāhitapāpadhammo = 「悪法を除き去った者」
  * bāhita = 「除去された(bāheti の過去分詞)」。bāhita と brāhmaṇa の語呂による語源解釈
  * pāpa-dhamma = 「悪法、悪しき性質」

→「悪法を除き去ったバラモンは、」

9. Nihuṃhuṅko nikkasāvo yatatto;

* nihuṃhuṅko = 「『フン』という(慢心の)声のない者」
  * ni + huṃhuṅka = 「フンという声を離れた」
* nikkasāvo = 「汚濁のない者」
  * kasāva = 「濁り、汚れ(貪などの煩悩の濁り)」
* yatatto = 「自己を制御した者」
  * yata-atta = 「制御された(yata)自己(atta)を持つ」

→「慢心の声なく、汚濁なく、自己を制御し、」

10. Vedantagū vusitabrahmacariyo;

* vedantagū = 「ヴェーダの究極に達した者」
  * veda-anta-gū = 「智(ヴェーダ)の終極(anta)に行った(gū)者」。仏教的には「(道の)智の完成に達した者」の意
* vusitabrahmacariyo = 「梵行を完成した者」
  * vusita = 「住み終えた、完成した(vasati の過去分詞)」
  * brahmacariya = 「梵行」

→「智の究極に達し、梵行を完成した者、」

11. Dhammena so brahmavādaṃ vadeyya;

* dhammena = 「法によって、正当に」
* so = 「その者は」
* brahmavādaṃ vadeyya = 「『(私は)バラモンである』という言葉を語ってよい」
  * brahma-vāda = 「バラモンの言葉、バラモンであるという主張」
  * vadeyya = 「語ってよい(vadati の願望法)」

→「その者こそ、正当に『バラモンである』と語ってよい。」

12. Yassussadā natthi kuhiñci loke’’ti.

* yassa = 「その者には(関係代名詞・属格)」
* ussadā = 「増盛、(煩悩の)高まり(複数)」
  * ussada = 「隆起、増大」。貪・瞋・痴・慢・見などの煩悩の高まりをいう
* natthi = 「存在しない」
* kuhiñci loke = 「世のどこにも」
* ti = 引用の終わり

→「その者には、世のどこにも(煩悩の)高まりが存在しない、と。」

13. Ajapālakathā niṭṭhitā.

* niṭṭhitā = 「終わった、完結した(niṭṭhāti の過去分詞)」

→「アジャパーラ樹の話は終わった。」
