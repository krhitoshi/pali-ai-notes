# 1. Bodhikathā

## 1

Atha kho bhagavā bodhirukkhamūle sattāhaṃ ekapallaṅkena nisīdi vimuttisukhapaṭisaṃvedī [vimuttisukhaṃ paṭisaṃvedī (ka.)]. 2. 1. [udā. 1 ādayo] Tena samayena buddho bhagavā uruvelāyaṃ viharati najjā nerañjarāya tīre bodhirukkhamūle paṭhamābhisambuddho.

6. ‘‘Avijjāyatveva asesavirāganirodhā saṅkhāranirodho, saṅkhāranirodhā viññāṇanirodho, viññāṇanirodhā nāmarūpanirodho, nāmarūpanirodhā saḷāyatananirodho, saḷāyatananirodhā phassanirodho, phassanirodhā vedanānirodho, vedanānirodhā taṇhānirodho, taṇhānirodhā upādānanirodho , upādānanirodhā bhavanirodho, bhavanirodhā jātinirodho, jātinirodhā jarāmaraṇaṃ sokaparidevadukkhadomanassupāyāsā nirujjhanti – evametassa kevalassa dukkhakkhandhassa nirodho hotī’’ti.

→「しかしまさに、無明が残りなく離貪して滅することから行の滅が、行の滅から識の滅が、識の滅から名色の滅が、名色の滅から六処の滅が、六処の滅から触の滅が、触の滅から受の滅が、受の滅から渇愛の滅が、渇愛の滅から取の滅が、取の滅から有の滅が、有の滅から生の滅が(あり)、生の滅から老死と愁・悲・苦・憂・悩が滅する。このように、この苦蘊全体の滅がある』と。」

→「そこで世尊は、この意味を知って、その時にこの感興の言葉を発した ――」

8. ‘‘Yadā have pātubhavanti dhammā; Ātāpino jhāyato brāhmaṇassa; Athassa kaṅkhā vapayanti sabbā; Yato pajānāti sahetudhamma’’nti.

  * pātubhavanti = 「現れる、顕現する」
* ātāpino jhāyato brāhmaṇassa = 「熱心に禅定している婆羅門に」
  * ātāpino = 「熱心な」(属格)
  * jhāyato = 「禅定している」(jhāyati の現在分詞属格)
* atha assa kaṅkhā vapayanti sabbā = 「そのとき彼のすべての疑いは消え去る」
  * athassa = atha + assa = 「そのとき彼の」
  * kaṅkhā = 「疑い」(複数)
  * vapayanti = 「消え去る」

  * yato = 「〜であるから、〜するがゆえに」

→「実に、熱心に禅定している婆羅門に諸法が現れるとき、そのとき彼のすべての疑いは消え去る。因を伴う法を了知するからである、と。」

* bhagavā = 「世尊は」
* etam atthaṃ = 「この意味を」
* viditvā = 「知って（vindati / √vid の連続体）」
* tāyaṃ velāyaṃ = 「その時に」
  * velā = 「時、時刻」
* imaṃ udānaṃ = 「この感興の言葉（ウダーナ）を」
* udānesi = 「発した（udāneti のアオリスト）」

→「さて世尊は、この意味を知って、その時にこの感興の言葉を発した。」

4. ‘‘Yadā have pātubhavanti dhammā;

* yadā = 「～するとき」
* have = 「実に（強意の不変化詞）」
* pātubhavanti = 「現れる、明らかになる」
  * pātu(r) = 「明らかに」+ bhavanti = 「なる」
* dhammā = 「諸法が」
  * ここでは四聖諦などの覚りの諸法とされる

→「実に、諸法が現れるとき、」

5. Ātāpino jhāyato brāhmaṇassa;

* ātāpino = 「熱心な（ātāpin の属格）」
  * ātāpa = 「熱意、精勤」から
* jhāyato = 「禅定している（jhāyant の属格）」
* brāhmaṇassa = 「婆羅門に（属格。ここでは煩悩を除いた者の意）」

→「熱心に禅定している婆羅門に（諸法が現れるとき）、」

6. Vidhūpayaṃ tiṭṭhati mārasenaṃ;

* vidhūpayaṃ = 「打ち払いながら、追い散らしながら（vidhūpeti の現在分詞）」
  * vi + √dhūp = 「いぶす、払う」
* tiṭṭhati = 「立つ、とどまる」
* mārasenaṃ = 「魔の軍勢を」
  * māra = 「魔、マーラ」
  * senā = 「軍勢」

→「彼は魔の軍勢を打ち払って立つ。」

7. Sūriyova [suriyova (sī. syā. kaṃ.)] obhāsayamantalikkha’’nti.

* sūriyo va = 「太陽が～ように」
  * va = 「～のように（iva の短縮形）」
  * [suriyova (sī. syā. kaṃ.)] = 「異読: シンハラ本・シャム本・カンボジア本では suriyo」
* obhāsayaṃ = 「照らしながら（obhāseti の現在分詞）」
* antalikkhaṃ = 「虚空を、空を」
* ti = 「～と（引用の終わり）」

→「太陽が虚空を照らすように、と。」

8. Bodhikathā niṭṭhitā.

* bodhi-kathā = 「菩提の話」
  * bodhi = 「菩提、覚り（ここでは菩提樹下での出来事の意も含む）」
  * kathā = 「話、章」
* niṭṭhitā = 「終わった（niṭṭhāti の過去分詞）」

→「菩提の話、終わり。」
