# 13. Bimbisārasamāgamakathā

## 55 (1)

55. Atha kho bhagavā gayāsīse yathābhirantaṃ viharitvā yena rājagahaṃ tena cārikaṃ pakkāmi, mahatā bhikkhusaṅghena saddhiṃ bhikkhusahassena sabbeheva purāṇajaṭilehi. Atha kho bhagavā anupubbena cārikaṃ caramāno yena rājagahaṃ tadavasari. Tatra sudaṃ bhagavā rājagahe viharati laṭṭhivane [laṭṭhivanuyyāne (syā.)] suppatiṭṭhe cetiye. Assosi kho rājā māgadho seniyo bimbisāro – samaṇo khalu bho gotamo sakyaputto sakyakulā pabbajito rājagahaṃ anuppatto rājagahe viharati laṭṭhivane suppatiṭṭhe cetiye. Taṃ kho pana bhagavantaṃ [bhavantaṃ (ka.)] gotamaṃ evaṃ kalyāṇo kittisaddo abbhuggato – itipi so bhagavā arahaṃ sammāsambuddho vijjācaraṇasampanno sugato lokavidū anuttaro purisadammasārathi satthā devamanussānaṃ buddho bhagavā [bhagavāti (ka.)]. So imaṃ lokaṃ sadevakaṃ samārakaṃ sabrahmakaṃ sassamaṇabrāhmaṇiṃ pajaṃ sadevamanussaṃ sayaṃ abhiññā sacchikatvā pavedeti. So dhammaṃ deseti ādikalyāṇaṃ majjhekalyāṇaṃ pariyosānakalyāṇaṃ sātthaṃ sabyañjanaṃ kevalaparipuṇṇaṃ parisuddhaṃ brahmacariyaṃ pakāseti. Sādhu kho pana tathārūpānaṃ arahataṃ dassanaṃ hotīti.

* dvādasanahutehi = 「十二ナフタ（12万）の」

→「さてそのとき、マガダ王セーニヤ・ビンビサーラは、12万のマガダ国のバラモンと資産家たちに囲まれて世尊のもとへ近づき、近づいて世尊に礼拝して一方に坐った。」

2. Tepi kho dvādasanahutā māgadhikā brāhmaṇagahapatikā appekacce bhagavantaṃ abhivādetvā ekamantaṃ nisīdiṃsu, appekacce bhagavatā saddhiṃ sammodiṃsu, sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā ekamantaṃ nisīdiṃsu, appekacce yena bhagavā tenañjaliṃ paṇāmetvā ekamantaṃ nisīdiṃsu, appekacce bhagavato santike nāmagottaṃ sāvetvā ekamantaṃ nisīdiṃsu, appekacce tuṇhībhūtā ekamantaṃ nisīdiṃsu.

* tepi kho = 「その彼らも」
* dvādasanahutā māgadhikā brāhmaṇagahapatikā = 「12万のマガダ国のバラモンと資産家たちは」
* appekacce = 「ある者たちは（api + ekacce）」
* bhagavantaṃ abhivādetvā ekamantaṃ nisīdiṃsu = 「世尊に礼拝して一方に坐った」
* bhagavatā saddhiṃ sammodiṃsu = 「世尊と挨拶を交わした」
* sammodanīyaṃ kathaṃ sāraṇīyaṃ vītisāretvā = 「喜ばしく思い出に残る言葉を交わし終えて」
  * sammodanīya = 「喜ばしい、和やかな」
  * sāraṇīya = 「思い出に残る、記憶に値する」
  * vītisāretvā = 「交わし終えて」

→「その12万のマガダ国のバラモンと資産家たちも、ある者たちは世尊に礼拝して一方に坐り、ある者たちは世尊と挨拶を交わし、喜ばしく思い出に残る言葉を交わし終えて一方に坐り、ある者たちは世尊の方へ合掌を差し向けて一方に坐り、ある者たちは世尊の面前で名前と姓を名乗って一方に坐り、ある者たちは沈黙したまま一方に坐った。」

3. Atha kho tesaṃ dvādasanahutānaṃ [dvādasaniyutānaṃ (yojanā)] māgadhikānaṃ brāhmaṇagahapatikānaṃ etadahosi – ‘‘kiṃ nu kho mahāsamaṇo uruvelakassape brahmacariyaṃ carati, udāhu uruvelakassapo mahāsamaṇe brahmacariyaṃ caratī’’ti?

* atha kho = 「さてそのとき」

* etadahosi = 「この（考え）が起こった」
* kiṃ nu kho = 「いったい～だろうか」

  * uruvelakassape = 「ウルヴェーラカッサパのもとで（処格：師事の対象を示す）」

→「さてそのとき、その12万のマガダ国のバラモンと資産家たちに、この考えが起こった――『いったい大沙門がウルヴェーラカッサパのもとで梵行を行じているのか、それともウルヴェーラカッサパが大沙門のもとで梵行を行じているのか』と。」

* cetasā cetoparivitakkamaññāya = 「心によって（彼らの）心の思考を知って」
  * cetasā = 「（自らの）心によって」
  * ceto-parivitakka = 「心の思考、心に巡らした考え」
  * aññāya = 「知って（ājānāti の連続体）」

  * ajjhabhāsi = 「語りかけた（adhibhāsati のアオリスト）」

→「さてそのとき、世尊はその12万のマガダ国のバラモンと資産家たちの心の思考を心によって知って、尊者ウルヴェーラカッサパに偈をもって語りかけた――」

5. ‘‘Kimeva disvā uruvelavāsi, pahāsi aggiṃ kisakovadāno;

* aggiṃ = 「火（祭火）を」

→「『ウルヴェーラに住む者よ、痩せた苦行者たちの教誡者よ、いったい何を見て、あなたは火（の祭祀）を捨てたのか。」

6. Pucchāmi taṃ kassapa, etamatthaṃ kathaṃ pahīnaṃ tava aggihuttanti.

→「カッサパよ、私はあなたにこの事柄を問う。どうしてあなたの火の供犠は捨てられたのか』と。」
