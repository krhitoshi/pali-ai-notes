# 11. Bhaddavaggiyavatthu

## 36

36. Atha kho bhagavā bārāṇasiyaṃ yathābhirantaṃ viharitvā yena uruvelā tena cārikaṃ pakkāmi. Atha kho bhagavā maggā okkamma yena aññataro vanasaṇḍo tenupasaṅkami, upasaṅkamitvā taṃ vanasaṇḍaṃ ajjhogāhetvā aññatarasmiṃ rukkhamūle nisīdi. Tena kho pana samayena tiṃsamattā bhaddavaggiyā sahāyakā sapajāpatikā tasmiṃ vanasaṇḍe paricārenti. Ekassa pajāpati nāhosi; tassa atthāya vesī ānītā ahosi. Atha kho sā vesī tesu pamattesu paricārentesu bhaṇḍaṃ ādāya palāyittha. Atha kho te sahāyakā sahāyakassa veyyāvaccaṃ karontā, taṃ itthiṃ gavesantā, taṃ vanasaṇḍaṃ āhiṇḍantā addasaṃsu bhagavantaṃ aññatarasmiṃ rukkhamūle nisinnaṃ. Disvāna yena bhagavā tenupasaṅkamiṃsu, upasaṅkamitvā bhagavantaṃ etadavocuṃ – ‘‘api, bhante, bhagavā ekaṃ itthiṃ passeyyā’’ti? ‘‘Kiṃ pana vo, kumārā, itthiyā’’ti? ‘‘Idha mayaṃ, bhante, tiṃsamattā bhaddavaggiyā sahāyakā sapajāpatikā imasmiṃ vanasaṇḍe paricārimhā. Ekassa pajāpati nāhosi; tassa atthāya vesī ānītā ahosi. Atha kho sā, bhante , vesī amhesu pamattesu paricārentesu bhaṇḍaṃ ādāya palāyittha. Te mayaṃ, bhante, sahāyakā sahāyakassa veyyāvaccaṃ karontā, taṃ itthiṃ gavesantā, imaṃ vanasaṇḍaṃ āhiṇḍāmā’’ti. ‘‘Taṃ kiṃ maññatha vo, kumārā, katamaṃ nu kho tumhākaṃ varaṃ – yaṃ vā tumhe itthiṃ gaveseyyātha, yaṃ vā attānaṃ gaveseyyāthā’’ti? ‘‘Etadeva, bhante, amhākaṃ varaṃ yaṃ mayaṃ attānaṃ gaveseyyāmā’’ti. ‘‘Tena hi vo, kumārā, nisīdatha, dhammaṃ vo desessāmī’’ti. ‘‘Evaṃ, bhante’’ti kho te bhaddavaggiyā sahāyakā bhagavantaṃ abhivādetvā ekamantaṃ nisīdiṃsu. Tesaṃ bhagavā anupubbiṃ kathaṃ kathesi, seyyathidaṃ – dānakathaṃ sīlakathaṃ saggakathaṃ kāmānaṃ ādīnavaṃ okāraṃ saṃkilesaṃ nekkhamme ānisaṃsaṃ pakāsesi, yadā te bhagavā aññāsi kallacitte muducitte vinīvaraṇacitte udaggacitte pasannacitte, atha yā buddhānaṃ sāmukkaṃsikā dhammadesanā, taṃ pakāsesi dukkhaṃ samudayaṃ nirodhaṃ maggaṃ, seyyathāpi nāma suddhaṃ vatthaṃ apagatakāḷakaṃ sammadeva rajanaṃ paṭiggaṇheyya, evameva tesaṃ tasmiṃyeva āsane virajaṃ vītamalaṃ dhammacakkhuṃ udapādi ‘‘yaṃ kiñci samudayadhammaṃ, sabbaṃ taṃ nirodhadhamma’’nti. Te diṭṭhadhammā pattadhammā viditadhammā pariyogāḷhadhammā tiṇṇavicikicchā vigatakathaṃkathā vesārajjappattā aparappaccayā satthusāsane bhagavantaṃ etadavocuṃ – ‘‘labheyyāma mayaṃ, bhante, bhagavato santike pabbajjaṃ, labheyyāma upasampada’’nti. ‘‘Etha bhikkhavo’’ti bhagavā avoca – ‘‘svākkhāto dhammo, caratha brahmacariyaṃ sammā dukkhassa antakiriyāyā’’ti. Sāva tesaṃ āyasmantānaṃ upasampadā ahosi.

Bhaddavaggiyasahāyakānaṃ vatthu niṭṭhitaṃ.

Dutiyabhāṇavāro.

2. 36. Atha kho bhagavā bārāṇasiyaṃ yathābhirantaṃ viharitvā yena uruvelā tena cārikaṃ pakkāmi.

* atha kho = 「さて」
* bhagavā = 「世尊は」
* bārāṇasiyaṃ = 「バーラーナシー(ベナレス)に」(処格)
* yathābhirantaṃ = 「心ゆくまで、好きなだけ」
* viharitvā = 「住んで」(viharati の連続体)

  * pakkāmi = 「出発した」(pakkamati のアオリスト)

→「さて世尊は、バーラーナシーに心ゆくまで住んだ後、ウルヴェーラーへ向けて遊行に出発した。」

3. Atha kho bhagavā maggā okkamma yena aññataro vanasaṇḍo tenupasaṅkami, upasaṅkamitvā taṃ vanasaṇḍaṃ ajjhogāhetvā aññatarasmiṃ rukkhamūle nisīdi.

* maggā okkamma = 「道からそれて」
  * okkamma = 「降りて、外れて」(okkamati の連続体)
* aññataro vanasaṇḍo = 「ある密林」
  * vanasaṇḍa = 「林叢、茂った林」
* tenupasaṅkami = 「そこへ近づいた」(tena upasaṅkami)
* ajjhogāhetvā = 「深く分け入って」(ajjhogāhati の連続体)
* aññatarasmiṃ rukkhamūle = 「ある木の根もとに」

→「さて世尊は、道からそれてある密林へ近づき、近づいてその密林に分け入り、ある木の根もとに坐った。」

4. Tena kho pana samayena tiṃsamattā bhaddavaggiyā sahāyakā sapajāpatikā tasmiṃ vanasaṇḍe paricārenti.

* tiṃsamattā = 「三十人ほどの」

* bhaddavaggiyā sahāyakā = 「バッダヴァッギヤの仲間たちが」

  * sa-pajāpatikā = 「妻(pajāpati)を伴った」
* paricārenti = 「遊び興じていた」(歴史的現在)

→「さてその時、三十人ほどのバッダヴァッギヤの仲間たちが、妻を連れてその密林で遊び興じていた。」

5. Ekassa pajāpati nāhosi; tassa atthāya vesī ānītā ahosi.

* ekassa = 「一人には」

→「一人には妻がいなかったので、彼のために遊女が連れて来られていた。」

6. Atha kho sā vesī tesu pamattesu paricārentesu bhaṇḍaṃ ādāya palāyittha.

  * ādāya = 「取って」(ādāti の連続体)
* palāyittha = 「逃げ去った」(palāyati のアオリスト)

→「さてその遊女は、彼らが油断して遊び興じている間に、財物を取って逃げ去った。」

7. Atha kho te sahāyakā sahāyakassa veyyāvaccaṃ karontā, taṃ itthiṃ gavesantā, taṃ vanasaṇḍaṃ āhiṇḍantā addasaṃsu bhagavantaṃ aññatarasmiṃ rukkhamūle nisinnaṃ.

* te sahāyakā = 「その仲間たちは」
* sahāyakassa veyyāvaccaṃ karontā = 「仲間のために手助けをして」
  * veyyāvacca = 「世話、手助け、用事」
* taṃ itthiṃ gavesantā = 「その女を探し求めて」
  * gavesati = 「探し求める」
* taṃ vanasaṇḍaṃ āhiṇḍantā = 「その密林を歩き回りながら」
  * āhiṇḍati = 「歩き回る、さまよう」
* addasaṃsu = 「見た」(dassati/passati のアオリスト複数)
* bhagavantaṃ ... nisinnaṃ = 「ある木の根もとに坐っている世尊を」

→「さてその仲間たちは、仲間のために手助けをしてその女を探し求め、その密林を歩き回っていて、ある木の根もとに坐っている世尊を見た。」

8. Disvāna yena bhagavā tenupasaṅkamiṃsu, upasaṅkamitvā bhagavantaṃ etadavocuṃ – ‘‘api, bhante, bhagavā ekaṃ itthiṃ passeyyā’’ti?

* disvāna = 「見て」(連続体)
* tenupasaṅkamiṃsu = 「世尊のもとへ近づいた」
* etadavocuṃ = 「このように言った」(etad avocuṃ)
* api ... passeyyā ti = 「ひょっとして〜を見なかったでしょうか」
  * api = 疑問・可能性を示す小辞
  * passeyya = 「見るであろう」(願望法。「見ませんでしたか」の丁寧な問い)
* bhante = 「尊師よ」
* ekaṃ itthiṃ = 「一人の女を」

→「見て、世尊のもとへ近づき、近づいて世尊にこう言った――「尊師よ、世尊は一人の女を見ませんでしたか」と。」

9. ‘‘Kiṃ pana vo, kumārā, itthiyā’’ti?

* kiṃ pana = 「いったい何(の用)があるのか」

* kumārā = 「若者たちよ」(呼格)
* itthiyā = 「女に、女で」(具格または与格)

→「「若者たちよ、あなたたちは女に何の用があるのか」と。」

10. ‘‘Idha mayaṃ, bhante, tiṃsamattā bhaddavaggiyā sahāyakā sapajāpatikā imasmiṃ vanasaṇḍe paricārimhā.

* idha = 「ここで」

→「「尊師よ、私たち三十人ほどのバッダヴァッギヤの仲間は、妻を連れてこの密林で遊び興じていました。」

11. Ekassa pajāpati nāhosi; tassa atthāya vesī ānītā ahosi.

12. Atha kho sā, bhante , vesī amhesu pamattesu paricārentesu bhaṇḍaṃ ādāya palāyittha.

13. Te mayaṃ, bhante, sahāyakā sahāyakassa veyyāvaccaṃ karontā, taṃ itthiṃ gavesantā, imaṃ vanasaṇḍaṃ āhiṇḍāmā’’ti.

14. ‘‘Taṃ kiṃ maññatha vo, kumārā, katamaṃ nu kho tumhākaṃ varaṃ – yaṃ vā tumhe itthiṃ gaveseyyātha, yaṃ vā attānaṃ gaveseyyāthā’’ti?

* taṃ kiṃ maññatha = 「これをどう思うか」
* katamaṃ nu kho = 「いったいどちらが」
* tumhākaṃ varaṃ = 「あなたたちにとってすぐれているか」
  * vara = 「よりよい、すぐれた」
* yaṃ vā ... yaṃ vā = 「〜することか、それとも〜することか」
* itthiṃ gaveseyyātha = 「女を探し求める」(願望法二人称複数)
* attānaṃ gaveseyyātha = 「自己を探し求める」
  * attānaṃ = 「自己を」(attan の対格)

→「「若者たちよ、これをどう思うか。あなたたちにとって、女を探し求めることと、自己を探し求めることの、いったいどちらがすぐれているか」と。」

15. ‘‘Etadeva, bhante, amhākaṃ varaṃ yaṃ mayaṃ attānaṃ gaveseyyāmā’’ti.

* etadeva = 「まさにこちらこそ」(etad eva)
* amhākaṃ varaṃ = 「私たちにとってすぐれています」
* yaṃ mayaṃ attānaṃ gaveseyyāmā = 「私たちが自己を探し求めること」

→「「尊師よ、私たちが自己を探し求めることこそ、私たちにとってすぐれています」と。」

16. ‘‘Tena hi vo, kumārā, nisīdatha, dhammaṃ vo desessāmī’’ti.

* tena hi = 「それでは」
* nisīdatha = 「坐りなさい」(命令法二人称複数)
* dhammaṃ vo desessāmī = 「あなたたちに法を説こう」
  * desessāmi = 「説くであろう」(deseti の未来形)
  * vo = 「あなたたちに」

→「「それでは若者たちよ、坐りなさい。あなたたちに法を説こう」と。」

17. ‘‘Evaṃ, bhante’’ti kho te bhaddavaggiyā sahāyakā bhagavantaṃ abhivādetvā ekamantaṃ nisīdiṃsu.

* evaṃ bhante ti = 「「はい、尊師よ」と」
* abhivādetvā = 「敬礼して」(abhivādeti の連続体)
* ekamantaṃ nisīdiṃsu = 「一方に坐った」

→「「はい、尊師よ」と、そのバッダヴァッギヤの仲間たちは世尊に敬礼して一方に坐った。」

18. Tesaṃ bhagavā anupubbiṃ kathaṃ kathesi, seyyathidaṃ – dānakathaṃ sīlakathaṃ saggakathaṃ kāmānaṃ ādīnavaṃ okāraṃ saṃkilesaṃ nekkhamme ānisaṃsaṃ pakāsesi,

* tesaṃ = 「彼らに」
* anupubbiṃ kathaṃ = 「次第説法(順を追った話)を」
* kathesi = 「語った」(katheti のアオリスト)
* seyyathidaṃ = 「すなわち」
* dānakathaṃ = 「布施の話を」
* sīlakathaṃ = 「戒の話を」
* saggakathaṃ = 「天界の話を」
* kāmānaṃ ādīnavaṃ = 「諸欲の危険を」
  * ādīnava = 「危険、災い」
* okāraṃ = 「卑しさを」
* saṃkilesaṃ = 「汚れを」
* nekkhamme ānisaṃsaṃ = 「出離における功徳を」
  * nekkhamma = 「出離」
  * ānisaṃsa = 「功徳、利益」
* pakāsesi = 「明らかにした」(pakāseti のアオリスト)

→「世尊は彼らに次第説法を語った。すなわち、布施の話、戒の話、天界の話、諸欲の危険・卑しさ・汚れ、出離における功徳を明らかにした。」

19. yadā te bhagavā aññāsi kallacitte muducitte vinīvaraṇacitte udaggacitte pasannacitte, atha yā buddhānaṃ sāmukkaṃsikā dhammadesanā, taṃ pakāsesi dukkhaṃ samudayaṃ nirodhaṃ maggaṃ,

* yadā ... aññāsi = 「〜と知った時」
  * aññāsi = 「知った」(ājānāti のアオリスト)
* te ... kallacitte = 「彼らが、心が(教えを受けるのに)適した状態にあると」
  * kalla = 「適した、堪えられる」
* muducitte = 「心が柔軟であると」
* vinīvaraṇacitte = 「心が蓋(妨げ)を離れていると」
  * nīvaraṇa = 「蓋、妨げ」
* udaggacitte = 「心が高揚していると」
* pasannacitte = 「心が浄信をもつと」
* yā buddhānaṃ sāmukkaṃsikā dhammadesanā = 「諸仏に固有の(自ら把握した)最勝の法話」(要確認)
  * sāmukkaṃsika = 「自ら高く掲げた、仏独自の」
* taṃ pakāsesi = 「それを明らかにした」
* dukkhaṃ samudayaṃ nirodhaṃ maggaṃ = 「苦・集・滅・道を」

→「世尊は、彼らの心が適し、柔軟になり、蓋を離れ、高揚し、浄信をもったと知った時、諸仏に固有の法話、すなわち苦・集・滅・道を明らかにした。」

20. seyyathāpi nāma suddhaṃ vatthaṃ apagatakāḷakaṃ sammadeva rajanaṃ paṭiggaṇheyya, evameva tesaṃ tasmiṃyeva āsane virajaṃ vītamalaṃ dhammacakkhuṃ udapādi ‘‘yaṃ kiñci samudayadhammaṃ, sabbaṃ taṃ nirodhadhamma’’nti.

* seyyathāpi nāma = 「あたかも〜のように」
* suddhaṃ vatthaṃ apagatakāḷakaṃ = 「黒い染みを離れた清浄な布が」
  * apagata-kāḷaka = 「黒い染み(kāḷaka)が去った」
* sammadeva rajanaṃ paṭiggaṇheyya = 「正しく染料を受け取るであろう」
  * rajana = 「染料」
  * paṭiggaṇhāti = 「受け取る」
* evameva = 「まさにそのように」
* tasmiṃyeva āsane = 「まさにその座で」
* virajaṃ vītamalaṃ = 「塵を離れ、垢を離れた」
* dhammacakkhuṃ udapādi = 「法眼が生じた」
  * udapādi = 「生じた」(uppajjati のアオリスト)
* yaṃ kiñci samudayadhammaṃ = 「およそ生じる性質のものは」
* sabbaṃ taṃ nirodhadhammaṃ = 「すべてそれは滅する性質のものである」

→「あたかも黒い染みを離れた清浄な布が正しく染料を受け取るように、まさにそのように、彼らにその座で「およそ生じる性質のものは、すべて滅する性質のものである」という、塵を離れ垢を離れた法眼が生じた。」

21. Te diṭṭhadhammā pattadhammā viditadhammā pariyogāḷhadhammā tiṇṇavicikicchā vigatakathaṃkathā vesārajjappattā aparappaccayā satthusāsane bhagavantaṃ etadavocuṃ – ‘‘labheyyāma mayaṃ, bhante, bhagavato santike pabbajjaṃ, labheyyāma upasampada’’nti.

* diṭṭhadhammā = 「法を見た者たち」
* pattadhammā = 「法に達した者たち」
* viditadhammā = 「法を知った者たち」
* pariyogāḷhadhammā = 「法に深く入った者たち」
  * pariyogāḷha = 「深く入った」(pariyogāhati の過去分詞)
* tiṇṇavicikicchā = 「疑いを渡り超えた者たち」
  * vicikicchā = 「疑い」
* vigatakathaṃkathā = 「ためらいを離れた者たち」
  * kathaṃkathā = 「ためらい、疑念」
* vesārajjappattā = 「自信を得た者たち」
  * vesārajja = 「自信、畏れなきこと」
* aparappaccayā satthusāsane = 「師の教えにおいて他に依存しない者たち」
  * apara-paccaya = 「他を縁としない」
* labheyyāma = 「得られますように」(labhati の願望法)
* bhagavato santike = 「世尊のもとで」
* pabbajjaṃ = 「出家を」
* upasampadaṃ = 「具足戒を」

→「彼らは法を見、法に達し、法を知り、法に深く入り、疑いを渡り超え、ためらいを離れ、自信を得て、師の教えにおいて他に依存しない者となり、世尊にこう言った――「尊師よ、私たちは世尊のもとで出家を得られますように、具足戒を得られますように」と。」

22. ‘‘Etha bhikkhavo’’ti bhagavā avoca – ‘‘svākkhāto dhammo, caratha brahmacariyaṃ sammā dukkhassa antakiriyāyā’’ti.

* etha bhikkhavo = 「来なさい、比丘たちよ」
  * etha = 「来なさい」(eti の命令法二人称複数)
* avoca = 「言った」(vacati のアオリスト)
* svākkhāto dhammo = 「法はよく説かれている」
  * su-akkhāta = 「よく説かれた」
* caratha brahmacariyaṃ = 「梵行を行じなさい」
* sammā dukkhassa antakiriyāya = 「正しく苦を終わらせるために」
  * antakiriyā = 「終わらせること」

→「「来なさい、比丘たちよ」と世尊は言った――「法はよく説かれている。正しく苦を終わらせるために梵行を行じなさい」と。」

23. Sāva tesaṃ āyasmantānaṃ upasampadā ahosi.

* sāva = 「まさにそれが」(sā eva)
* tesaṃ āyasmantānaṃ = 「それらの尊者たちの」
* upasampadā ahosi = 「具足戒となった」

→「まさにそれが、それらの尊者たちの具足戒となった。」

24. Bhaddavaggiyasahāyakānaṃ vatthu niṭṭhitaṃ.

* bhaddavaggiya-sahāyakānaṃ = 「バッダヴァッギヤの仲間たちの」
* vatthu niṭṭhitaṃ = 「話が終わった」
  * niṭṭhita = 「完結した」

→「バッダヴァッギヤの仲間たちの話、終わり。」

25. Dutiyabhāṇavāro.

* dutiya-bhāṇavāra = 「第二誦分」
  * bhāṇavāra = 「誦分(読誦の一区切り)」

→「第二誦分(終わり)。」
