# 7. Cūḷadhanuggahapaṇḍitavatthu

## 349-350

349.

‘‘Vitakkamathitassa jantuno,

Tibbarāgassa subhānupassino;

Bhiyyo taṇhā pavaḍḍhati,

Esa kho daḷhaṃ karoti bandhanaṃ.

350.

‘‘Vitakkūpasame ca yo rato,

Asubhaṃ bhāvayate sadā sato;

Esa kho byanti kāhiti,

Esa checchati mārabandhana’’nti.

Tattha vitakkamathitassāti kāmavitakkādīhi vitakkehi nimmathitassa. Tibbarāgassāti bahalarāgassa. Subhānupassinoti iṭṭhārammaṇe subhanimittagāhādivasena vissaṭṭhamānasatāya subhanti anupassantassa. Taṇhāti evarūpassa jhānādīsu ekampi na vaḍḍhati, atha kho chadvārikā taṇhāyeva bhiyyo vaḍḍhati. Esa khoti eso puggalo taṇhābandhanaṃ daḷhaṃ suthiraṃ karoti. Vitakkūpasameti micchāvitakkādīnaṃ vūpasamasaṅkhāte dasasu asubhesu paṭhamajjhāne. Sadā satoti yo ettha abhirato hutvā niccaṃ upaṭṭhitasatitāya sato taṃ asubhajhānaṃ bhāveti. Byanti kāhitīti esa bhikkhu tīsu bhavesu uppajjanakaṃ taṇhaṃ vigatantaṃ karissati. Mārabandhananti eso tebhūmakavaṭṭasaṅkhātaṃ mārabandhanampi chindissatīti attho.

  * paṇḍita = 「賢者」
  * vatthu = 「話、物語、事例」

→「小弓術師賢者の話」

2. 349. ‘‘Vitakkamathitassa jantuno, Tibbarāgassa subhānupassino; Bhiyyo taṇhā pavaḍḍhati, Esa kho daḷhaṃ karoti bandhanaṃ.

* vitakka-mathitassa = 「尋（思考）にかき乱された者の」
  * vitakka = 「尋、思考」
  * mathita = 「かき乱された、攪拌された（mathati の過去分詞）」
* jantuno = 「人の」（jantu の属格）
* tibba-rāgassa = 「激しい貪りをもつ者の」
  * tibba = 「激しい、強烈な」
  * rāga = 「貪り、貪欲」
* subhānupassino = 「（対象を）浄（美しい）と随観する者の」
  * subha = 「浄、美しいもの」
  * anupassin = 「随観する者」
* bhiyyo = 「さらに、いっそう」
* taṇhā = 「渇愛」
* pavaḍḍhati = 「増大する」
* esa kho = 「この者こそ」
* daḷhaṃ karoti = 「堅固にする」
* bandhanaṃ = 「束縛を」

→「尋にかき乱され、激しい貪りをもち、（対象を）浄と随観する人には、渇愛がいっそう増大する。この者こそ束縛を堅固にする。」

3. 350. ‘‘Vitakkūpasame ca yo rato, Asubhaṃ bhāvayate sadā sato; Esa kho byanti kāhiti, Esa checchati mārabandhana’’nti.

* vitakkūpasame = 「尋の静まりにおいて」（vitakka-upasama の処格）
  * upasama = 「静まり、鎮静」
* ca = 「しかし、また」
* yo rato = 「楽しむ者は」
  * rata = 「楽しむ、喜ぶ（ramati の過去分詞）」
* asubhaṃ bhāvayate = 「不浄を修習する」
  * asubha = 「不浄」
  * bhāvayate = 「修習する（bhāveti の中動態）」
* sadā sato = 「常に念をそなえて」
* esa kho = 「この者こそ」
* byanti kāhiti = 「終わらせるだろう」（byantiṃ karissati「終わりへともたらす」の意）
* esa checchati = 「この者は断つだろう」
  * checchati = 「断つだろう（chindati の未来形）」
* mārabandhanaṃ = 「悪魔の束縛を」
* ti = 引用の終わりを示す語

→「しかし尋の静まりを楽しみ、常に念をそなえて不浄を修習する者、この者こそ（渇愛を）終わらせるだろう。この者は悪魔の束縛を断つだろう。」

4. Tattha vitakkamathitassāti kāmavitakkādīhi vitakkehi nimmathitassa.

* tattha = 「そこで（この偈において）」
* vitakkamathitassā ti = 「『vitakkamathitassa』とは」
* kāma-vitakka-ādīhi vitakkehi = 「欲の尋などの尋によって」
  * kāmavitakka = 「欲の尋（感覚的欲望についての思考）」
* nimmathitassa = 「かき乱された者の」
  * nimmathita = 「かき乱された（nis + mathati の過去分詞）」

→「そこで『vitakkamathitassa（尋にかき乱された者の）』とは、欲の尋などの尋によってかき乱された者の、という意味である。」

5. Tibbarāgassāti bahalarāgassa.

* tibbarāgassā ti = 「『tibbarāgassa』とは」
* bahala-rāgassa = 「濃厚な貪りをもつ者の」
  * bahala = 「濃厚な、厚い」

→「『tibbarāgassa（激しい貪りをもつ者の）』とは、濃厚な貪りをもつ者の、という意味である。」

6. Subhānupassinoti iṭṭhārammaṇe subhanimittagāhādivasena vissaṭṭhamānasatāya subhanti anupassantassa.

* subhānupassino ti = 「『subhānupassino』とは」
* iṭṭha-ārammaṇe = 「好ましい所縁において」
  * iṭṭha = 「好ましい、望ましい」
* subha-nimitta-gāha-ādi-vasena = 「浄相の把握などによって」
  * subhanimitta = 「浄相（美しいという相）」
  * gāha = 「把握、とらえること」
* vissaṭṭha-mānasatāya = 「心を放っている（心が解き放たれている）ことのために」
  * vissaṭṭha = 「放たれた、解き放たれた」
  * mānasatā = 「心の状態」
* subhan ti anupassantassa = 「『浄である』と随観する者の」

→「『subhānupassino（浄と随観する者の）』とは、好ましい所縁に対して、浄相の把握などによって心を放っているために、『浄である』と随観する者の、という意味である。」

7. Taṇhāti evarūpassa jhānādīsu ekampi na vaḍḍhati, atha kho chadvārikā taṇhāyeva bhiyyo vaḍḍhati.

* taṇhā ti = 「『taṇhā』とは」
* evarūpassa = 「このような者には」
* jhāna-ādīsu ekam pi = 「禅などのうち一つも」
* na vaḍḍhati = 「増大しない」
* atha kho = 「むしろ、それどころか」
* cha-dvārikā = 「六門の（眼などの六つの門で働く）」
* taṇhā yeva = 「渇愛だけが」
* bhiyyo vaḍḍhati = 「いっそう増大する」

→「『taṇhā（渇愛）』とは、このような者には禅などのうち一つも増大せず、むしろ六門に関する渇愛だけがいっそう増大する（という意味である）。」

8. Esa khoti eso puggalo taṇhābandhanaṃ daḷhaṃ suthiraṃ karoti.

* esa kho ti = 「『esa kho』とは」
* eso puggalo = 「この人は」
* taṇhā-bandhanaṃ = 「渇愛の束縛を」
* daḷhaṃ suthiraṃ karoti = 「堅く、たいへん安定したものにする」
  * daḷha = 「堅固な」
  * suthira = 「たいへん安定した（su + thira）」

→「『esa kho（この者こそ）』とは、この人は渇愛の束縛を堅く、たいへん安定したものにする（という意味である）。」

9. Vitakkūpasameti micchāvitakkādīnaṃ vūpasamasaṅkhāte dasasu asubhesu paṭhamajjhāne.

* vitakkūpasame ti = 「『vitakkūpasame』とは」
* micchā-vitakka-ādīnaṃ = 「誤った尋などの」
* vūpasama-saṅkhāte = 「静まりと呼ばれる」
  * vūpasama = 「静まり、鎮静」
  * saṅkhāta = 「～と呼ばれる、～と称される」
* dasasu asubhesu = 「十不浄における」
  * dasa asubhā = 「十不浄（膨脹相などの十種の不浄の対象）」
* paṭhama-jjhāne = 「初禅において」

→「『vitakkūpasame（尋の静まりにおいて）』とは、誤った尋などの静まりと呼ばれる、十不浄における初禅において、という意味である。」

10. Sadā satoti yo ettha abhirato hutvā niccaṃ upaṭṭhitasatitāya sato taṃ asubhajhānaṃ bhāveti.

* sadā sato ti = 「『sadā sato』とは」
* yo ettha abhirato hutvā = 「ここ（初禅）に大いに楽しんで」
  * abhirata = 「大いに楽しむ、専心する」
* niccaṃ = 「常に」
* upaṭṭhita-satitāya = 「念が現前していることによって」
  * upaṭṭhita = 「現前した、確立した」
  * satitā = 「念があること」
* sato = 「念をそなえた者が」
* taṃ asubha-jhānaṃ bhāveti = 「その不浄禅を修習する」

→「『sadā sato（常に念をそなえて）』とは、ここに大いに楽しんで、常に念が現前していることによって念をそなえた者が、その不浄禅を修習する（という意味である）。」

11. Byanti kāhitīti esa bhikkhu tīsu bhavesu uppajjanakaṃ taṇhaṃ vigatantaṃ karissati.

* byanti kāhitī ti = 「『byanti kāhiti』とは」
* esa bhikkhu = 「この比丘は」
* tīsu bhavesu = 「三有において」
  * bhava = 「有、生存（欲有・色有・無色有）」
* uppajjanakaṃ taṇhaṃ = 「生じる渇愛を」
  * uppajjanaka = 「生じるもの、生起するもの」
* vigatantaṃ karissati = 「消滅したものにするだろう」
  * vigata-anta = 「終わりまで消え去った、跡形なく消滅した」(要確認)

→「『byanti kāhiti（終わらせるだろう）』とは、この比丘は三有において生じる渇愛を消滅させるだろう（という意味である）。」

12. Mārabandhananti eso tebhūmakavaṭṭasaṅkhātaṃ mārabandhanampi chindissatīti attho.

* mārabandhanan ti = 「『mārabandhanaṃ』とは」
* eso = 「この者は」
* tebhūmaka-vaṭṭa-saṅkhātaṃ = 「三地の輪転と呼ばれる」
  * tebhūmaka = 「三地の（欲界・色界・無色界に属する）」
  * vaṭṭa = 「輪転、輪廻の巡り」
* māra-bandhanam pi = 「悪魔の束縛をも」
* chindissatī ti = 「断つだろう、と」
* attho = 「という意味である」

→「『mārabandhanaṃ（悪魔の束縛を）』とは、この者は三地の輪転と呼ばれる悪魔の束縛をも断つだろう、という意味である。」
