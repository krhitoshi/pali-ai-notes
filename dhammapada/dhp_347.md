# 5. Khemātherīvatthu

## 347

347.

‘‘Ye rāgarattānupatanti sotaṃ,

Sayaṃ kataṃ makkaṭakova jālaṃ;

Etampi chetvāna vajanti dhīrā,

Anapekkhino sabbadukkhaṃ pahāyā’’ti.

Tattha makkaṭakova jālanti yathā nāma makkaṭako suttajālaṃ katvā majjhe ṭhāne nābhimaṇḍale nipanno pariyante patitaṃ paṭaṅgaṃ vā makkhikaṃ vā vegena gantvā vijjhitvā tassa rasaṃ pivitvā puna gantvā tasmiṃyeva ṭhāne nipajjati, evameva ye sattā rāgarattā dosapaduṭṭhā mohamūḷhā sayaṃkataṃ taṇhāsotaṃ anupatanti, te taṃ samatikkamituṃ na sakkonti, evaṃ duratikkamaṃ. Etampi chetvāna vajanti dhīrāti paṇḍitā etaṃ bandhanaṃ chetvā anapekkhino nirālayā hutvā arahattamaggena sabbadukkhaṃ pahāya vajanti, gacchantīti attho.

### 対訳

1. 347. ‘‘Ye rāgarattānupatanti sotaṃ, Sayaṃ kataṃ makkaṭakova jālaṃ; Etampi chetvāna vajanti dhīrā, Anapekkhino sabbadukkhaṃ pahāyā’’ti.

* ye = 「～する者たちは（関係代名詞・複数）」

* rāga-rattā = 「貪欲に染まった者たち」

  * rāga = 「貪欲」

  * ratta = 「染まった（rajjati の過去分詞）」

* anupatanti = 「落ち込む、随い落ちる（anu + patati）」

* sotaṃ = 「流れに」

* sayaṃ kataṃ = 「自ら作った」

* makkaṭako va = 「蜘蛛のように」

  * makkaṭaka = 「蜘蛛」

* jālaṃ = 「網に」

* etam pi chetvāna = 「これをも断ち切って」

  * chetvāna = 「断ち切って（chindati の連続体）」

* vajanti = 「進んで行く」

* dhīrā = 「賢者たちは」

* anapekkhino = 「期待のない者たちとして、顧みることのない者たちとして」

* sabbadukkhaṃ pahāya = 「一切の苦を捨てて」

→「貪欲に染まった者たちは流れに落ち込む。蜘蛛が自ら作った網に（落ち込む）ように。賢者たちはこれをも断ち切り、顧みることなく、一切の苦を捨てて進んで行く。」

2. Tattha makkaṭakova jālanti yathā nāma makkaṭako suttajālaṃ katvā majjhe ṭhāne nābhimaṇḍale nipanno pariyante patitaṃ paṭaṅgaṃ vā makkhikaṃ vā vegena gantvā vijjhitvā tassa rasaṃ pivitvā puna gantvā tasmiṃyeva ṭhāne nipajjati,

* tattha = 「そこで（その偈文の中で）」

* makkaṭako va jālan ti = 「"蜘蛛が網に（落ち込む）ように"とは」

* yathā nāma = 「ちょうど～ように」

* sutta-jālaṃ katvā = 「糸の網を作って」

  * sutta = 「糸」

* majjhe ṭhāne = 「真ん中の場所で」

* nābhi-maṇḍale = 「中心の円（網の中心部）で」

  * nābhi = 「へそ、中心、（車輪の）こしき」

  * maṇḍala = 「円、円形部分」

* nipanno = 「横たわって（nipajjati の過去分詞）」

* pariyante patitaṃ = 「（網の）端に落ちた」

* paṭaṅgaṃ vā makkhikaṃ vā = 「蛾やハエを」

  * paṭaṅga = 「蛾、バッタ」(要確認)

  * makkhikā = 「ハエ」

* vegena gantvā = 「素早く行って」

* vijjhitvā = 「刺して（vijjhati の連続体）」

* tassa rasaṃ pivitvā = 「その体液を飲んで」

* puna gantvā = 「再び行って」

* tasmiṃ yeva ṭhāne nipajjati = 「まさにその同じ場所に横たわる」

→「そこで"蜘蛛が網に（落ち込む）ように"とは、ちょうど蜘蛛が糸の網を作り、真ん中の場所、中心の円に横たわっていて、端に落ちた蛾やハエのところへ素早く行き、刺してその体液を飲み、再び（戻って）行ってまさにその同じ場所に横たわるように、」

3. evameva ye sattā rāgarattā dosapaduṭṭhā mohamūḷhā sayaṃkataṃ taṇhāsotaṃ anupatanti, te taṃ samatikkamituṃ na sakkonti, evaṃ duratikkamaṃ.

* evam eva = 「まさにそのように」

* ye sattā = 「～する衆生たちは」

* rāga-rattā = 「貪欲に染まり」

* dosa-paduṭṭhā = 「瞋恚に汚され」

  * dosa = 「瞋恚、怒り」

  * paduṭṭha = 「汚された（padussati の過去分詞）」

* moha-mūḷhā = 「愚痴に迷った」

  * moha = 「愚痴、迷妄」

  * mūḷha = 「迷った（muyhati の過去分詞）」

* sayaṃ-kataṃ = 「自ら作った」

* taṇhā-sotaṃ = 「渇愛の流れに」

* anupatanti = 「落ち込む」

* te = 「彼らは」

* taṃ samatikkamituṃ na sakkonti = 「それを超えることができない」

  * samatikkamituṃ = 「超えること（samatikkamati の不定詞）」

* evaṃ duratikkamaṃ = 「このように（それは）超え難いものである」

→「まさにそのように、貪欲に染まり、瞋恚に汚され、愚痴に迷った衆生たちは、自ら作った渇愛の流れに落ち込む。彼らはそれを超えることができない。このように（渇愛の流れは）超え難いものである。」

4. Etampi chetvāna vajanti dhīrāti paṇḍitā etaṃ bandhanaṃ chetvā anapekkhino nirālayā hutvā arahattamaggena sabbadukkhaṃ pahāya vajanti, gacchantīti attho.

* etam pi chetvāna vajanti dhīrā ti = 「"賢者たちはこれをも断ち切って進んで行く"とは」

* paṇḍitā = 「賢い人たちは」

* etaṃ bandhanaṃ chetvā = 「この束縛を断ち切って」

  * bandhana = 「束縛、縛るもの」

* anapekkhino = 「期待のない者たちとして」

* nirālayā hutvā = 「執着のない者たちとなって」

  * nirālaya = 「執着のない（nis + ālaya）」

  * ālaya = 「執着、住処」

* arahatta-maggena = 「阿羅漢道によって」

* sabbadukkhaṃ pahāya = 「一切の苦を捨てて」

* vajanti = 「進んで行く」

* gacchantī ti attho = 「（すなわち）行く、という意味である」

→「"賢者たちはこれをも断ち切って進んで行く"とは、賢い人たちはこの束縛を断ち切り、期待なく執着のない者たちとなって、阿羅漢道によって一切の苦を捨てて進んで行く、すなわち行く、という意味である。」
