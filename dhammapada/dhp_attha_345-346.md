
# 4. Bandhanāgāravatthu

## 345-346 (1)

Nataṃ daḷhanti imaṃ dhammadesanaṃ satthā jetavane viharanto bandhanāgāraṃ ārabbha kathesi.

Ekasmiṃ kira kāle bahū sandhicchedakapanthaghātakamanussaghātake core ānetvā kosalarañño dassayiṃsu. Te rājā andubandhanarajjubandhanasaṅkhalikabandhanehi bandhāpesi. Tiṃsamattāpi kho jānapadā bhikkhū satthāraṃ daṭṭhukāmā āgantvā disvā vanditvā punadivase sāvatthiṃ piṇḍāya carantā bandhanāgāraṃ gantvā te core disvā piṇḍapātapaṭikkantā sāyanhasamaye tathāgataṃ upasaṅkamitvā, ‘‘bhante, ajja amhehi piṇḍāya carantehi bandhanāgāre bahū corā andubandhanādīhi baddhā mahādukkhaṃ anubhavantā diṭṭhā, te tāni bandhanāni chinditvā palāyituṃ na sakkonti, atthi nu kho, bhante, tehi bandhanehi thirataraṃ aññaṃ bandhanaṃ nāmā’’ti pucchiṃsu. Satthā, ‘‘bhikkhave, kiṃ bandhanāni nāmetāni, yaṃ panetaṃ dhanadhaññaputtadārādīsu taṇhāsaṅkhātaṃ kilesabandhanaṃ, etaṃ etehi sataguṇena sahassaguṇena satasahassaguṇena thirataraṃ, evaṃ mahantampi panetaṃ ducchindaniyaṃ bandhanaṃ porāṇakapaṇḍitā chinditvā himavantaṃ pavisitvā pabbajiṃsū’’ti vatvā atītaṃ āhari –

Atīte bārāṇasiyaṃ brahmadatte rajjaṃ kārente bodhisatto ekasmiṃ duggatagahapatikule nibbatti. Tassa vayappattassa pitā kālamakāsi. So bhatiṃ katvā mātaraṃ posesi. Athassa mātā anicchamānasseva ekaṃ kuladhītaraṃ gehe katvā aparabhāge kālamakāsi. Bhariyāyapissa kucchiyaṃ gabbho patiṭṭhahi. So gabbhassa patiṭṭhitabhāvaṃ ajānantova, ‘‘bhadde, tvaṃ bhatiṃ katvā jīva, ahaṃ pabbajissāmī’’ti āha. ‘‘Sāmi, nanu gabbho me patiṭṭhito, mayi vijātāya dārakaṃ disvā pabbajissasī’’ti āha. So ‘‘sādhū’’ti sampaṭicchitvā tassā vijātakāle, ‘‘bhadde, tvaṃ sotthinā vijātā, idāni ahaṃ pabbajissāmī’’ti āpucchi. Atha naṃ sā ‘‘puttassa tāva thanapānato apagamanakālaṃ āgamehī’’ti vatvā puna gabbhaṃ gaṇhi. So cintesi – ‘‘imaṃ sampaṭicchāpetvā gantuṃ na sakkā, imissā anācikkhitvāva palāyitvā pabbajissāmī’’ti. So tassā anācikkhitvāva rattibhāge uṭṭhāya palāyi. Atha naṃ nagaraguttikā aggahesuṃ. So ‘‘ahaṃ, sāmi, mātuposako nāma, vissajjetha ma’’nti attānaṃ vissajjāpetvā ekasmiṃ ṭhāne vasitvā isipabbajjaṃ pabbajitvā abhiññāsamāpattiyo labhitvā jhānakīḷāya kīḷanto vihāsi. So tattha vasantoyeva ‘‘evarūpampi nāma me ducchindaniyaṃ puttadārabandhanaṃ kilesabandhanaṃ chinna’’nti imaṃ udānaṃ udānesi.

Satthā imaṃ atītaṃ āharitvā tena udānitaṃ udānaṃ pakāsento imā gāthā abhāsi –

1. 4. Bandhanāgāravatthu

* bandhana-āgāra-vatthu = 「牢獄の話」
  * bandhana = 「縛、束縛」
  * āgāra = 「家、建物」→ bandhanāgāra = 「牢獄」
  * vatthu = 「話、物語、事例」

→「牢獄の話」

2. Nataṃ daḷhanti imaṃ dhammadesanaṃ satthā jetavane viharanto bandhanāgāraṃ ārabbha kathesi.

* na taṃ daḷhaṃ = 「それは堅固(な縛)ではない」(Dhp 345 冒頭句)
  * na = 「～ではない」
  * taṃ = 「それは」
  * daḷhaṃ = 「堅固な、強固な」
* iti = 「～という」
* imaṃ dhammadesanaṃ = 「この法話を」
* satthā = 「師(仏陀)は」
* jetavane viharanto = 「祇園精舎に住んでいたとき」
* bandhanāgāraṃ ārabbha = 「牢獄に関して」
  * ārabbha = 「～に関して、～を機縁として」
* kathesi = 「語った(katheti の過去形)」

→「『na taṃ daḷhaṃ(それは堅固な縛ではない)』というこの法話を、師は祇園精舎に住んでいたとき、牢獄に関して語った。」

3. Ekasmiṃ kira kāle bahū sandhicchedakapanthaghātakamanussaghātake core ānetvā kosalarañño dassayiṃsu.

* ekasmiṃ kira kāle = 「あるとき、伝えられるところでは」
  * kira = 「伝聞を示す語」
* bahū ... core = 「多くの盗賊たちを」
* sandhicchedaka-panthaghātaka-manussaghātake = 「壁に穴を開けて押し入る者・追いはぎ・人殺しである(盗賊たちを)」
  * sandhicchedaka = 「壁の継ぎ目を破って侵入する盗人」
  * panthaghātaka = 「道で襲う追いはぎ」
  * manussaghātaka = 「人を殺す者」
* ānetvā = 「連行して」
* kosalarañño = 「コーサラ王に」
* dassayiṃsu = 「見せた、引き渡した(dasseti の過去形・複数)」

→「あるとき、(人々は)壁を破って押し入る者・追いはぎ・人殺しである多くの盗賊たちを連行して、コーサラ王に引き渡した。」

4. Te rājā andubandhanarajjubandhanasaṅkhalikabandhanehi bandhāpesi.

* te = 「彼らを」
* rājā = 「王は」
* andu-bandhana-rajju-bandhana-saṅkhalika-bandhanehi = 「足枷の縛・縄の縛・鎖の縛によって」
  * andu = 「足枷」
  * rajju = 「縄」
  * saṅkhalika = 「鎖」
* bandhāpesi = 「縛らせた(bandhati の使役・過去形)」

→「王は彼らを、足枷の縛・縄の縛・鎖の縛によって縛らせた。」

5. Tiṃsamattāpi kho jānapadā bhikkhū satthāraṃ daṭṭhukāmā āgantvā disvā vanditvā punadivase sāvatthiṃ piṇḍāya carantā bandhanāgāraṃ gantvā te core disvā piṇḍapātapaṭikkantā sāyanhasamaye tathāgataṃ upasaṅkamitvā, ‘‘bhante, ajja amhehi piṇḍāya carantehi bandhanāgāre bahū corā andubandhanādīhi baddhā mahādukkhaṃ anubhavantā diṭṭhā, te tāni bandhanāni chinditvā palāyituṃ na sakkonti, atthi nu kho, bhante, tehi bandhanehi thirataraṃ aññaṃ bandhanaṃ nāmā’’ti pucchiṃsu.

* tiṃsamattā pi kho = 「およそ三十人の」
  * tiṃsa-matta = 「三十ほどの」
* jānapadā bhikkhū = 「地方の比丘たちが」
* satthāraṃ daṭṭhukāmā = 「師に会いたいと望んで」
  * daṭṭhukāma = 「見たいと望む(daṭṭhu-kāma)」
* āgantvā disvā vanditvā = 「来て、(師に)会い、礼拝して」
* punadivase = 「翌日に」
* sāvatthiṃ piṇḍāya carantā = 「サーヴァッティーに托鉢のため歩いていて」
* bandhanāgāraṃ gantvā = 「牢獄に行き」
* te core disvā = 「あの盗賊たちを見て」
* piṇḍapātapaṭikkantā = 「托鉢から戻り」
* sāyanhasamaye = 「夕方の時に」
* tathāgataṃ upasaṅkamitvā = 「如来に近づいて」
* bhante = 「尊師よ」
* ajja amhehi piṇḍāya carantehi = 「今日、托鉢のため歩いていた私たちによって」
* bandhanāgāre bahū corā = 「牢獄で多くの盗賊たちが」
* andubandhanādīhi baddhā = 「足枷の縛などによって縛られ」
* mahādukkhaṃ anubhavantā diṭṭhā = 「大きな苦しみを受けているのが見られました」
* te tāni bandhanāni chinditvā palāyituṃ na sakkonti = 「彼らはそれらの縛を断ち切って逃げることができません」
* atthi nu kho ... aññaṃ bandhanaṃ nāma = 「いったい～という別の縛があるのでしょうか」
* tehi bandhanehi thirataraṃ = 「それらの縛よりも強固な」
  * thiratara = 「より強固な(thira の比較級)」
* ti pucchiṃsu = 「～と尋ねた」

→「およそ三十人の地方の比丘たちが、師に会いたいと望んで来て、(師に)会って礼拝し、翌日サーヴァッティーで托鉢に歩いていたとき牢獄に行き、あの盗賊たちを見て、托鉢から戻り、夕方の時に如来に近づいて、『尊師よ、今日、托鉢に歩いていた私たちは、牢獄で多くの盗賊たちが足枷の縛などによって縛られ、大きな苦しみを受けているのを見ました。彼らはそれらの縛を断ち切って逃げることができません。尊師よ、いったいそれらの縛よりも強固な別の縛というものはあるのでしょうか』と尋ねた。」

6. Satthā, ‘‘bhikkhave, kiṃ bandhanāni nāmetāni, yaṃ panetaṃ dhanadhaññaputtadārādīsu taṇhāsaṅkhātaṃ kilesabandhanaṃ, etaṃ etehi sataguṇena sahassaguṇena satasahassaguṇena thirataraṃ, evaṃ mahantampi panetaṃ ducchindaniyaṃ bandhanaṃ porāṇakapaṇḍitā chinditvā himavantaṃ pavisitvā pabbajiṃsū’’ti vatvā atītaṃ āhari –

* satthā = 「師は」
* bhikkhave = 「比丘たちよ」
* kiṃ bandhanāni nāma etāni = 「これらがどうして縛と言えようか」
* yaṃ pana etaṃ ... kilesabandhanaṃ = 「しかし、～という煩悩の縛は」
* dhana-dhañña-putta-dārādīsu = 「財産・穀物・息子・妻などに対する」
* taṇhāsaṅkhātaṃ = 「渇愛と呼ばれる」
  * saṅkhāta = 「～と呼ばれる、～と称される」
* etaṃ etehi ... thirataraṃ = 「これは、これら(の縛)よりも～強固である」
* sataguṇena sahassaguṇena satasahassaguṇena = 「百倍に、千倍に、十万倍に」
* evaṃ mahantam pi pana etaṃ = 「しかし、このように大きな、この」
* ducchindaniyaṃ bandhanaṃ = 「断ち切りがたい縛を」
  * du(r) + chindaniya = 「切断しがたい」
* porāṇakapaṇḍitā = 「昔の賢者たちは」
* chinditvā = 「断ち切って」
* himavantaṃ pavisitvā = 「ヒマラヤに入って」
* pabbajiṃsu = 「出家した」
* ti vatvā = 「～と言って」
* atītaṃ āhari = 「過去(の話)を持ち出した」
  * āhari = 「持ってきた(āharati の過去形)」

→「師は『比丘たちよ、これらがどうして縛と言えようか。財産・穀物・息子・妻などに対する渇愛と呼ばれる煩悩の縛こそは、これらよりも百倍、千倍、十万倍に強固である。しかし、このように大きな、この断ち切りがたい縛を、昔の賢者たちは断ち切って、ヒマラヤに入って出家したのである』と言って、過去の話を持ち出した。」

7. Atīte bārāṇasiyaṃ brahmadatte rajjaṃ kārente bodhisatto ekasmiṃ duggatagahapatikule nibbatti.

→「昔、バーラーナシーでブラフマダッタが統治していたとき、菩薩はある貧しい居士の家に生まれた。」

8. Tassa vayappattassa pitā kālamakāsi.

→「彼が成年に達したとき、父が死んだ。」

10. Athassa mātā anicchamānasseva ekaṃ kuladhītaraṃ gehe katvā aparabhāge kālamakāsi.

→「そして彼の母は、彼が望んでいないのに、ある良家の娘を家に迎えて(嫁とし)、後に死んだ。」

11. Bhariyāyapissa kucchiyaṃ gabbho patiṭṭhahi.

* bhariyāya pi assa = 「そして彼の妻の」

  * kucchi = 「腹、胎」

  * patiṭṭhahi = 「確立した、宿った(patiṭṭhahati の過去形)」

→「そして彼の妻の胎に子が宿った。」

12. So gabbhassa patiṭṭhitabhāvaṃ ajānantova, ‘‘bhadde, tvaṃ bhatiṃ katvā jīva, ahaṃ pabbajissāmī’’ti āha.

* so = 「彼は」
* gabbhassa patiṭṭhitabhāvaṃ = 「胎児が宿ったことを」

* ajānanto va = 「知らないままに」

→「彼は子が宿ったことを知らないままに、『妻よ、あなたは賃仕事をして生きなさい。私は出家しよう』と言った。」

13. ‘‘Sāmi, nanu gabbho me patiṭṭhito, mayi vijātāya dārakaṃ disvā pabbajissasī’’ti āha.

* sāmi = 「夫よ、主人よ」

* pabbajissasi = 「出家してください(未来形・二人称)」
* ti āha = 「～と言った」

→「(妻は)『夫よ、私には子が宿っているではありませんか。私が出産して、子供を見てから出家してください』と言った。」

14. So ‘‘sādhū’’ti sampaṭicchitvā tassā vijātakāle, ‘‘bhadde, tvaṃ sotthinā vijātā, idāni ahaṃ pabbajissāmī’’ti āpucchi.

* so = 「彼は」
* sādhū ti sampaṭicchitvā = 「『よろしい』と承諾して」
  * sampaṭicchati = 「受け入れる、承諾する」
* tassā vijātakāle = 「彼女が出産したとき」

→「彼は『よろしい』と承諾し、彼女が出産したとき、『妻よ、あなたは無事に出産した。今こそ私は出家しよう』と暇を告げた。」

15. Atha naṃ sā ‘‘puttassa tāva thanapānato apagamanakālaṃ āgamehī’’ti vatvā puna gabbhaṃ gaṇhi.

* atha naṃ sā = 「そこで彼女は彼に」
* puttassa tāva = 「まず息子が」
* thanapānato apagamanakālaṃ = 「乳を飲むことから離れる時(乳離れの時)を」

  * apagamana = 「離れること」

* ti vatvā = 「～と言って」

  * gabbhaṃ gaṇhāti = 「胎児を得る、妊娠する」

→「そこで彼女は彼に『まず息子が乳離れする時まで待ってください』と言って、再び妊娠した。」

16. So cintesi – ‘‘imaṃ sampaṭicchāpetvā gantuṃ na sakkā, imissā anācikkhitvāva palāyitvā pabbajissāmī’’ti.

* so cintesi = 「彼は考えた」

* ti = 「～と」

→「彼は考えた――『この女に承諾させてから行くことはできない。この女に告げないままに逃げ出して出家しよう』と。」

17. So tassā anācikkhitvāva rattibhāge uṭṭhāya palāyi.

* so = 「彼は」
* tassā anācikkhitvā va = 「彼女に告げないままに」

* palāyi = 「逃げた(palāyati の過去形)」

→「彼は彼女に告げないままに、夜のうちに起き上がって逃げた。」

18. Atha naṃ nagaraguttikā aggahesuṃ.

* atha naṃ = 「すると彼を」
* nagaraguttikā = 「都市の警備者たちが」

→「すると都市の警備者たちが彼を捕らえた。」

19. So ‘‘ahaṃ, sāmi, mātuposako nāma, vissajjetha ma’’nti attānaṃ vissajjāpetvā ekasmiṃ ṭhāne vasitvā isipabbajjaṃ pabbajitvā abhiññāsamāpattiyo labhitvā jhānakīḷāya kīḷanto vihāsi.

* so = 「彼は」
* ahaṃ, sāmi, mātuposako nāma = 「旦那がた、私は母を養う者です」
  * mātuposaka = 「母を養う者」
* vissajjetha maṃ = 「私を放してください」
  * vissajjeti = 「放つ、解放する」
* ti attānaṃ vissajjāpetvā = 「～と(言って)自分を解放させて」
* ekasmiṃ ṭhāne vasitvā = 「ある場所に住んで」
* isipabbajjaṃ pabbajitvā = 「仙人としての出家を遂げて」
  * isi-pabbajjā = 「仙人の出家」
* abhiññāsamāpattiyo labhitvā = 「神通と等至を得て」
  * abhiññā = 「神通」
  * samāpatti = 「等至(禅定の達成)」
* jhānakīḷāya kīḷanto = 「禅定の楽しみを楽しみながら」
