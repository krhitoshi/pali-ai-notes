# 4. Bandhanāgāravatthu

## 345-346

345.

‘‘Na taṃ daḷhaṃ bandhanamāhu dhīrā,

Yadāyasaṃ dārujapabbajañca;

Sārattarattā maṇikuṇḍalesu,

Puttesu dāresu ca yā apekkhā.

346.

‘‘Etaṃ daḷhaṃ bandhanamāhu dhīrā,

Ohārinaṃ sithilaṃ duppamuñcaṃ;

Etampi chetvāna paribbajanti,

Anapekkhino kāmasukhaṃ pahāyā’’ti.

Tattha dhīrāti buddhādayo paṇḍitapurisā yaṃ saṅkhalikasaṅkhātaṃ ayasā nibbattaṃ āyasaṃ, andubandhanasaṅkhātaṃ dārujaṃ, yañca pabbajatiṇehi vā aññehi vā vākādīhi rajjuṃ katvā kataṃ rajjubandhanaṃ, taṃ asiādīhi chindituṃ sakkuṇeyyabhāvena thiranti na vadantīti attho. Sārattarattāti sārattā hutvā rattā, bahalatararāgarattāti attho. Maṇikuṇḍalesūti maṇīsu ceva kuṇḍalesu ca, maṇivicittesu vā kuṇḍalesu. Etaṃ daḷhanti ye maṇikuṇḍalesu sārattarattā, tesaṃ so rāgo ca yā puttadāresu apekkhā taṇhā, etaṃ kilesamayaṃ bandhanañca paṇḍitapurisā daḷhanti vadanti. Ohārinanti ākaḍḍhitvā catūsu apāyesu pātanato avaharati heṭṭhā haratīti ohārinaṃ. Sithilanti bandhanaṭṭhāne chavicammamaṃsāni na chindati, lohitaṃ na nīharati, bandhanabhāvampi ajānāpetvā thalapathajalapathādīsu kammāni kātuṃ detīti sithilaṃ. Duppamuñcanti lobhavasena hi ekavārampi uppannaṃ kilesabandhanaṃ daṭṭhaṭṭhānato kacchapo viya dummociyaṃ hotīti duppamuñcaṃ. Etampi chetvānāti etaṃ daḷhampi kilesabandhanaṃ ñāṇakhaggena chinditvā anapekkhino hutvā kāmasukhaṃ pahāya paribbajanti, pakkamanti pabbajantīti attho.

### 対訳

1. 4. Bandhanāgāravatthu

* bandhana-āgāra-vatthu = 「牢獄の話」
  * bandhana = 「縛め、束縛」
  * āgāra = 「家」(bandhanāgāra で「牢獄」)
  * vatthu = 「話、物語、事例」

→「牢獄の話」

2. 345. ‘‘Na taṃ daḷhaṃ bandhanamāhu dhīrā, Yadāyasaṃ dārujapabbajañca; Sārattarattā maṇikuṇḍalesu, Puttesu dāresu ca yā apekkhā.

* na taṃ daḷhaṃ bandhanaṃ āhu = 「それを堅固な縛めとは言わなかった」
  * daḷha = 「堅固な、強固な」
  * āhu = 「言った(ah の完了形)」
* dhīrā = 「賢者たちは」
* yad āyasaṃ = 「鉄でできたもの」
  * āyasa = 「鉄製の(ayas「鉄」から)」
* dāruja-pabbajañ ca = 「木でできたもの、およびパッバジャ草(でできたもの)」
  * dāruja = 「木から生じた、木製の」
  * pabbaja = 「パッバジャ草(縄の材料となる草)」
* sāratta-rattā = 「強く貪着して染まった者たち」
* maṇi-kuṇḍalesu = 「宝珠と耳環に対して」
* puttesu dāresu ca = 「息子たちと妻たちに対して」
* yā apekkhā = 「(ある)期待、執着」

→「鉄製のもの、木製のもの、パッバジャ草のもの、それを賢者たちは堅固な縛めとは言わなかった。宝珠と耳環に強く貪着して染まること、息子たちと妻たちへの執着、」

3. 346. ‘‘Etaṃ daḷhaṃ bandhanamāhu dhīrā, Ohārinaṃ sithilaṃ duppamuñcaṃ; Etampi chetvāna paribbajanti, Anapekkhino kāmasukhaṃ pahāyā’’ti.

* etaṃ daḷhaṃ bandhanaṃ āhu dhīrā = 「これを賢者たちは堅固な縛めと言った」
* ohārinaṃ = 「下へ引きずるもの」
* sithilaṃ = 「ゆるいもの」
* duppamuñcaṃ = 「解き放ち難いもの」
  * du(r) + pamuñca = 「放すことが難しい」
* etam pi chetvāna = 「これをも断ち切って」
  * chetvāna = 「断ち切って(chindati の連続体)」
* paribbajanti = 「遊行する」
* anapekkhino = 「執着のない者たちとして」
* kāmasukhaṃ pahāya = 「欲楽を捨てて」

→「これを賢者たちは堅固な縛めと言った。下へ引きずり、ゆるく、解き放ち難いものであると。これをも断ち切って、執着のない者たちとして、欲楽を捨てて遊行する。」

4. Tattha dhīrāti buddhādayo paṇḍitapurisā yaṃ saṅkhalikasaṅkhātaṃ ayasā nibbattaṃ āyasaṃ, andubandhanasaṅkhātaṃ dārujaṃ, yañca pabbajatiṇehi vā aññehi vā vākādīhi rajjuṃ katvā kataṃ rajjubandhanaṃ, taṃ asiādīhi chindituṃ sakkuṇeyyabhāvena thiranti na vadantīti attho.

* tattha = 「そこ(その偈)において」
* dhīrā ti = 「『dhīrā(賢者たちは)』とは」
* buddhādayo paṇḍita-purisā = 「ブッダをはじめとする賢い人たちは」
* yaṃ saṅkhalika-saṅkhātaṃ ayasā nibbattaṃ āyasaṃ = 「鎖と呼ばれる、鉄から作られた鉄製のもの」
  * saṅkhalika = 「鎖」
  * saṅkhāta = 「～と呼ばれる」
  * nibbatta = 「生じた、作られた」
* andu-bandhana-saṅkhātaṃ dārujaṃ = 「足枷という縛めと呼ばれる木製のもの」
  * andu = 「足枷」
* yañ ca pabbaja-tiṇehi vā aññehi vā vākādīhi rajjuṃ katvā kataṃ rajju-bandhanaṃ = 「パッバジャ草で、あるいは他の樹皮などで縄を作って作られた縄の縛め」
  * tiṇa = 「草」
  * vāka = 「樹皮」
  * rajju = 「縄」
* taṃ asi-ādīhi chindituṃ sakkuṇeyya-bhāvena = 「それは剣などで断ち切ることができるものであることから」
  * sakkuṇeyya = 「可能である(sakkoti の可能法)」
* thiran ti na vadanti = 「『堅固である』とは言わない」
* ti attho = 「という意味である」

→「そこにおいて『dhīrā』とは、ブッダをはじめとする賢い人たちは、鎖と呼ばれる鉄から作られた鉄製のもの、足枷という縛めと呼ばれる木製のもの、そしてパッバジャ草あるいは他の樹皮などで縄を作って作られた縄の縛め、それを剣などで断ち切ることができることから『堅固である』とは言わない、という意味である。」

5. Sārattarattāti sārattā hutvā rattā, bahalatararāgarattāti attho.

* sāratta-rattā ti = 「『sārattarattā』とは」
* sārattā hutvā rattā = 「強く貪着した者となって染まった」
* bahalatara-rāga-rattā ti attho = 「より濃厚な貪りによって染まった、という意味である」
  * bahalatara = 「より濃厚な(bahala の比較級)」

→「『sārattarattā』とは、強く貪着した者となって染まった、すなわち、より濃厚な貪りによって染まった、という意味である。」

6. Maṇikuṇḍalesūti maṇīsu ceva kuṇḍalesu ca, maṇivicittesu vā kuṇḍalesu.

* maṇi-kuṇḍalesū ti = 「『maṇikuṇḍalesu』とは」
* maṇīsu c'eva kuṇḍalesu ca = 「宝珠に対しても耳環に対しても」
* maṇi-vicittesu vā kuṇḍalesu = 「あるいは宝珠で飾られた耳環に対して」
  * vicitta = 「飾られた、多彩な」

→「『maṇikuṇḍalesu』とは、宝珠に対しても耳環に対しても、あるいは宝珠で飾られた耳環に対して、である。」

7. Etaṃ daḷhanti ye maṇikuṇḍalesu sārattarattā, tesaṃ so rāgo ca yā puttadāresu apekkhā taṇhā, etaṃ kilesamayaṃ bandhanañca paṇḍitapurisā daḷhanti vadanti.

* etaṃ daḷhan ti = 「『etaṃ daḷhaṃ』とは」
* ye maṇi-kuṇḍalesu sāratta-rattā = 「宝珠と耳環に強く貪着して染まった者たち」
* tesaṃ so rāgo ca = 「彼らのその貪りと」
* yā putta-dāresu apekkhā taṇhā = 「息子たちと妻たちに対する執着すなわち渇愛」
* etaṃ kilesa-mayaṃ bandhanañ ca = 「この煩悩でできた縛めを」
  * maya = 「～でできた」
* paṇḍita-purisā daḷhan ti vadanti = 「賢い人たちは『堅固である』と言う」

→「『etaṃ daḷhaṃ』とは、宝珠と耳環に強く貪着して染まった者たちのその貪りと、息子たちと妻たちに対する執着すなわち渇愛、この煩悩でできた縛めを、賢い人たちは『堅固である』と言う(ということである)。」

8. Ohārinanti ākaḍḍhitvā catūsu apāyesu pātanato avaharati heṭṭhā haratīti ohārinaṃ.

* ohārinan ti = 「『ohārinaṃ』とは」
* ākaḍḍhitvā = 「引きずって」
* catūsu apāyesu pātanato = 「四つの悪処に落とすことから」
  * apāya = 「悪処(地獄・畜生・餓鬼・阿修羅)」
  * pātana = 「落とすこと」
* avaharati heṭṭhā haratī ti ohārinaṃ = 「下へ運ぶ、下方へ運ぶから ohārinaṃ(下へ引きずるもの)である」
  * heṭṭhā = 「下に、下方に」

→「『ohārinaṃ』とは、引きずって四つの悪処に落とすことから、下へ運ぶ、下方へ運ぶので ohārinaṃ である。」

9. Sithilanti bandhanaṭṭhāne chavicammamaṃsāni na chindati, lohitaṃ na nīharati, bandhanabhāvampi ajānāpetvā thalapathajalapathādīsu kammāni kātuṃ detīti sithilaṃ.

* sithilan ti = 「『sithilaṃ』とは」
* bandhana-ṭṭhāne = 「縛めの場所において」
* chavi-camma-maṃsāni na chindati = 「表皮・皮・肉を切らない」
  * chavi = 「表皮」
  * camma = 「皮」
  * maṃsa = 「肉」
* lohitaṃ na nīharati = 「血を流させない」
  * nīharati = 「取り出す、引き出す」
* bandhana-bhāvam pi ajānāpetvā = 「縛めであることを知らせもせずに」
  * ajānāpetvā = 「知らせないで(jānāpeti「知らせる」の否定連続体)」
* thala-patha-jala-pathādīsu kammāni kātuṃ detī ti sithilaṃ = 「陸路・水路などにおける仕事をすることを許すから sithilaṃ(ゆるいもの)である」
  * thala-patha = 「陸路」
  * jala-patha = 「水路」

→「『sithilaṃ』とは、縛めの場所において表皮・皮・肉を切らず、血を流させず、縛めであることを知らせもせずに、陸路・水路などにおける仕事をすることを許すので sithilaṃ である。」

10. Duppamuñcanti lobhavasena hi ekavārampi uppannaṃ kilesabandhanaṃ daṭṭhaṭṭhānato kacchapo viya dummociyaṃ hotīti duppamuñcaṃ.

* duppamuñcan ti = 「『duppamuñcaṃ』とは」
* lobha-vasena hi = 「実に貪欲の力によって」
* eka-vāram pi uppannaṃ kilesa-bandhanaṃ = 「一度でも生じた煩悩の縛めは」
* daṭṭha-ṭṭhānato kacchapo viya = 「噛みついた場所から(放さない)亀のように」
  * daṭṭha = 「噛まれた(ḍasati の過去分詞)」
  * kacchapa = 「亀」
* dummociyaṃ hotī ti duppamuñcaṃ = 「解き放し難いものであるから duppamuñcaṃ(解き放ち難いもの)である」

→「『duppamuñcaṃ』とは、実に貪欲の力によって一度でも生じた煩悩の縛めは、噛みついた場所から(放さない)亀のように解き放し難いものであるから、duppamuñcaṃ である。」

11. Etampi chetvānāti etaṃ daḷhampi kilesabandhanaṃ ñāṇakhaggena chinditvā anapekkhino hutvā kāmasukhaṃ pahāya paribbajanti, pakkamanti pabbajantīti attho.

* etam pi chetvānā ti = 「『etampi chetvāna』とは」
* etaṃ daḷham pi kilesa-bandhanaṃ = 「この堅固な煩悩の縛めさえも」
* ñāṇa-khaggena chinditvā = 「智慧の剣によって断ち切って」
  * khagga = 「剣」
* anapekkhino hutvā = 「執着のない者たちとなって」
* kāmasukhaṃ pahāya = 「欲楽を捨てて」
* paribbajanti, pakkamanti pabbajantī ti attho = 「遊行する、すなわち立ち去る、出家する、という意味である」
  * pakkamati = 「立ち去る、出発する」
  * pabbajati = 「出家する」

→「『etampi chetvāna』とは、この堅固な煩悩の縛めさえも智慧の剣によって断ち切り、執着のない者たちとなって、欲楽を捨てて遊行する、すなわち立ち去る、出家する、という意味である。」
