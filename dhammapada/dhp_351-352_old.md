
# 8. Māravatthu

## 351

351.

‘‘Niṭṭhaṅgato asantāsī, vītataṇho anaṅgaṇo;

Acchindi bhavasallāni, antimoyaṃ samussayo.

### 対訳

1. 8. Māravatthu

* māra-vatthu = 「マーラ(悪魔)の話」

  * māra = 「マーラ、悪魔」

  * vatthu = 「話、物語、事例」

→「マーラの話」

2. 351. ‘‘Niṭṭhaṅgato asantāsī, vītataṇho anaṅgaṇo; Acchindi bhavasallāni, antimoyaṃ samussayo.

* niṭṭhaṅgato = 「完成に達した者」（niṭṭhā-gata）

  * niṭṭhā = 「完成、終極、目的の成就」

  * gata = 「達した（gacchati の過去分詞）」

* asantāsī = 「恐れのない者、おののかない者」

  * a + santāsin（santāsa = 恐怖、おののき）

* vītataṇho = 「渇愛を離れた者」（vīta-taṇha）

  * vīta = 「離れた、去った」

  * taṇhā = 「渇愛」

* anaṅgaṇo = 「汚れのない者」

  * an + aṅgaṇa（aṅgaṇa = 汚れ、垢）

* acchindi = 「断ち切った（chindati のアオリスト）」

* bhavasallāni = 「生存の矢を」（bhava-salla の複数対格）

  * bhava = 「生存、有」

  * salla = 「矢、棘」

* antimo = 「最後の」

* ayaṃ = 「これは」

* samussayo = 「身体、積集した体」

→「完成に達し、恐れなく、渇愛を離れ、汚れのない者は、生存の矢を断ち切った。これが最後の身体である。」

## 352

352.

‘‘Vītataṇho anādāno, niruttipadakovido;

Akkharānaṃ sannipātaṃ, jaññā pubbāparāni ca;

Sa ve antimasārīro,

Mahāpañño mahāpurisoti vuccatī’’ti.

Tattha niṭṭhaṅgatoti imasmiṃ sāsane pabbajitānaṃ arahattaṃ niṭṭhaṃ nāma, taṃ gato pattoti attho. Asantāsīti abbhantare rāgasantāsādīnaṃ abhāvena asantasanako. Acchindi bhavasallānīti sabbānipi bhavagāmīni sallāni acchindi. Samussayoti ayaṃ etassa antimo deho.

Anādānoti khandhādīsu niggahaṇo. Niruttipadakovidoti niruttiyañca sesapadesu cāti catūsupi paṭisambhidāsu chekoti attho. Akkharānaṃ sannipātaṃ, jaññā pubbāparāni cāti akkharānaṃ sannipātasaṅkhātaṃ akkharapiṇḍañca jānāti, pubbakkharena aparakkharaṃ, aparakkharena pubbakkharañca jānāti. Pubbakkharena aparakkharaṃ jānāti nāma – ādimhi paññāyamāne majjhapariyosānesu apaññāyamānesupi ‘‘imesaṃ akkharānaṃ idaṃ majjhaṃ, idaṃ pariyosāna’’nti jānāti. Aparakkharena pubbakkharaṃ jānāti nāma – ante paññāyamāne ādimajjhesu apaññāyamānesu ‘‘imesaṃ akkharānaṃ idaṃ majjhaṃ, ayaṃ ādī’’ti jānāti. Majjhe paññāyamānepi ‘‘imesaṃ akkharānaṃ ayaṃ ādi, ayaṃ anto’’ti jānāti. Evaṃ mahāpañño. Sa ve antimasārīroti esa koṭiyaṃ ṭhitasarīro, mahantānaṃ atthadhammaniruttipaṭibhānānaṃ sīlakkhandhādīnañca pariggāhikāya paññāya samannāgatattā mahāpañño, ‘‘vimuttacittattā khvāhaṃ, sāriputta, mahāpurisoti vadāmī’’ti (saṃ. ni. 5.377) vacanato vimuttacittatāya ca mahāpurisoti vuccatīti attho.

### 対訳

1. 352. ‘‘Vītataṇho anādāno, niruttipadakovido;

* vītataṇho = 「渇愛を離れた者」（vīta-taṇha）

  * vīta = 「離れた、去った」

  * taṇhā = 「渇愛」

* anādāno = 「執着のない者」（an-ādāna）

  * ādāna = 「取ること、執着」

* niruttipadakovido = 「言語表現の句に巧みな者」（nirutti-pada-kovida）

  * nirutti = 「言語表現、語法」

  * pada = 「句、語」

  * kovida = 「巧みな、精通した」

→「渇愛を離れ、執着なく、言語表現の句に巧みで、」

2. Akkharānaṃ sannipātaṃ, jaññā pubbāparāni ca;

* akkharānaṃ = 「文字の（複数・属格）」

* sannipātaṃ = 「結合、集まり（を）」

* jaññā = 「知るであろう、知る（jānāti の願望法）」

* pubbāparāni ca = 「前と後（の文字）をも」

  * pubba = 「前の」、apara = 「後の」

→「文字の結合を知り、（文字の）前後をも知るであろう者、」

3. Sa ve antimasārīro, Mahāpañño mahāpurisoti vuccatī’’ti.

* sa ve = 「その者こそ」

* antimasārīro = 「最後の身体を持つ者」（antima-sārīra）

  * antima = 「最後の」

  * sārīra = 「身体を持つ」

* mahāpañño = 「大いなる智慧ある者」

* mahāpuriso ti vuccati = 「『偉大な人』と呼ばれる」

→「その者こそ最後の身体を持つ者であり、大いなる智慧ある者、『偉大な人』と呼ばれる。」

4. Tattha niṭṭhaṅgatoti imasmiṃ sāsane pabbajitānaṃ arahattaṃ niṭṭhaṃ nāma, taṃ gato pattoti attho.

* tattha = 「そこで（この偈において）」

  * 前偈（351）の語 niṭṭhaṅgata などから順に註釈される

* niṭṭhaṅgato ti = 「『完成に至った者』とは」

* imasmiṃ sāsane = 「この教えにおいて」

* pabbajitānaṃ = 「出家した者たちにとって」

* arahattaṃ niṭṭhaṃ nāma = 「阿羅漢果が『完成』と呼ばれる」

* taṃ gato patto ti attho = 「それに至った、到達したという意味である」

→「そこで『niṭṭhaṅgato（完成に至った者）』とは、この教えにおいて出家した者たちにとっては阿羅漢果が『完成』と呼ばれ、それに至った、到達したという意味である。」

5. Asantāsīti abbhantare rāgasantāsādīnaṃ abhāvena asantasanako.

* asantāsī ti = 「『恐れない者』とは」

* abbhantare = 「内に」

* rāga-santāsa-ādīnaṃ = 「貪りによる恐怖などの」

* abhāvena = 「ないことによって」

* asantasanako = 「恐れることのない者」

→「『asantāsī（恐れない者）』とは、内に貪りによる恐怖などがないことによって恐れることのない者である。」

6. Acchindi bhavasallānīti sabbānipi bhavagāmīni sallāni acchindi.

* acchindi = 「断ち切った（chindati のアオリスト）」

* bhavasallāni = 「存在（有）の矢を」（bhava-salla）

* sabbāni pi = 「すべての」

* bhavagāmīni sallāni = 「存在（有）へ導く矢を」

→「『acchindi bhavasallāni（存在の矢を断ち切った）』とは、存在へ導く矢をすべて断ち切ったのである。」

7. Samussayoti ayaṃ etassa antimo deho.

* samussayo ti = 「『身体』とは」

* ayaṃ = 「これは」

* etassa = 「この者の」

* antimo deho = 「最後の身体（である）」

→「『samussayo（身体）』とは、これがこの者の最後の身体である（という意味である）。」

8. Anādānoti khandhādīsu niggahaṇo.

* anādāno ti = 「『執着のない者』とは」

* khandha-ādīsu = 「（五）蘊などにおいて」

* niggahaṇo = 「取ることのない者」（nis-gahaṇa）

→「『anādāno（執着のない者）』とは、蘊などにおいて取ることのない者である。」

9. Niruttipadakovidoti niruttiyañca sesapadesu cāti catūsupi paṭisambhidāsu chekoti attho.

* niruttipadakovido ti = 「『言語表現の句に巧みな者』とは」

* niruttiyaṃ ca = 「言語表現においても」

* sesapadesu ca = 「残りの句においても」

  * 残りの句 = 義（attha）・法（dhamma）・弁説（paṭibhāna）を指す

* catūsu pi paṭisambhidāsu = 「四つの無礙解すべてにおいて」

* cheko ti attho = 「巧みな者という意味である」

→「『niruttipadakovido（言語表現の句に巧みな者）』とは、言語表現においても残りの句においても、すなわち四つの無礙解すべてにおいて巧みな者という意味である。」

10. Akkharānaṃ sannipātaṃ, jaññā pubbāparāni cāti akkharānaṃ sannipātasaṅkhātaṃ akkharapiṇḍañca jānāti, pubbakkharena aparakkharaṃ, aparakkharena pubbakkharañca jānāti.

* sannipātasaṅkhātaṃ = 「結合と呼ばれる」

* akkharapiṇḍaṃ ca jānāti = 「文字の集まりを知る」

* pubbakkharena aparakkharaṃ = 「前の文字によって後の文字を」

* aparakkharena pubbakkharaṃ ca jānāti = 「後の文字によって前の文字を知る」

→「『akkharānaṃ sannipātaṃ, jaññā pubbāparāni ca（文字の結合を知り、前後をも知る）』とは、文字の結合と呼ばれる文字の集まりを知り、前の文字によって後の文字を、後の文字によって前の文字を知るのである。」

11. Pubbakkharena aparakkharaṃ jānāti nāma – ādimhi paññāyamāne majjhapariyosānesu apaññāyamānesupi ‘‘imesaṃ akkharānaṃ idaṃ majjhaṃ, idaṃ pariyosāna’’nti jānāti.

* pubbakkharena aparakkharaṃ jānāti nāma = 「前の文字によって後の文字を知るとは、すなわち」

* ādimhi paññāyamāne = 「初めが知られているとき（処格絶対節）」

* majjha-pariyosānesu apaññāyamānesu pi = 「中間と終わりが知られていなくても」

* imesaṃ akkharānaṃ = 「これらの文字の」

* idaṃ majjhaṃ, idaṃ pariyosānaṃ ti jānāti = 「『これが中間、これが終わりである』と知る」

→「前の文字によって後の文字を知るとは、初めが知られていて中間と終わりが知られていなくても、『これらの文字のこれが中間であり、これが終わりである』と知ることである。」

12. Aparakkharena pubbakkharaṃ jānāti nāma – ante paññāyamāne ādimajjhesu apaññāyamānesu ‘‘imesaṃ akkharānaṃ idaṃ majjhaṃ, ayaṃ ādī’’ti jānāti.

* aparakkharena pubbakkharaṃ jānāti nāma = 「後の文字によって前の文字を知るとは、すなわち」

* ante paññāyamāne = 「終わりが知られているとき」

* ādi-majjhesu apaññāyamānesu = 「初めと中間が知られていなくても」

* idaṃ majjhaṃ, ayaṃ ādī ti jānāti = 「『これが中間、これが初めである』と知る」

→「後の文字によって前の文字を知るとは、終わりが知られていて初めと中間が知られていなくても、『これらの文字のこれが中間であり、これが初めである』と知ることである。」

13. Majjhe paññāyamānepi ‘‘imesaṃ akkharānaṃ ayaṃ ādi, ayaṃ anto’’ti jānāti.

* majjhe paññāyamāne pi = 「中間が知られている場合にも」

* ayaṃ ādi, ayaṃ anto ti jānāti = 「『これが初め、これが終わりである』と知る」

→「中間が知られている場合にも、『これらの文字のこれが初めであり、これが終わりである』と知る。」

14. Evaṃ mahāpañño.

* evaṃ = 「このように」

* mahāpañño = 「大いなる智慧ある者（である）」

→「このように大いなる智慧ある者なのである。」

15. Sa ve antimasārīroti esa koṭiyaṃ ṭhitasarīro, mahantānaṃ atthadhammaniruttipaṭibhānānaṃ sīlakkhandhādīnañca pariggāhikāya paññāya samannāgatattā mahāpañño, ‘‘vimuttacittattā khvāhaṃ, sāriputta, mahāpurisoti vadāmī’’ti (saṃ. ni. 5.377) vacanato vimuttacittatāya ca mahāpurisoti vuccatīti attho.

* sa ve antimasārīro ti = 「『その者こそ最後の身体を持つ者』とは」

* esa koṭiyaṃ ṭhitasarīro = 「この者は頂点（終極）に立つ身体を持つ者（である）」

  * koṭi = 「頂点、終極」

* mahantānaṃ attha-dhamma-nirutti-paṭibhānānaṃ = 「大いなる義・法・言語表現・弁説の」

* sīlakkhandha-ādīnaṃ ca = 「戒蘊などの」

* pariggāhikāya paññāya = 「把握する智慧を」

* samannāgatattā = 「備えていることから」

* mahāpañño = 「大いなる智慧ある者（であり）」

* vimuttacittattā kho ahaṃ, sāriputta, mahāpuriso ti vadāmī ti = 「『サーリプッタよ、私は心が解脱していることによって偉大な人と説く』と」

* (saṃ. ni. 5.377) vacanato = 「（相応部 5.377 の）言葉から」

* vimuttacittatāya ca = 「心が解脱していることによって」

* mahāpuriso ti vuccatī ti attho = 「『偉大な人』と呼ばれるという意味である」

→「『sa ve antimasārīro（その者こそ最後の身体を持つ者）』とは、この者は終極に立つ身体を持つ者であり、大いなる義・法・言語表現・弁説と戒蘊などを把握する智慧を備えていることから大いなる智慧ある者であり、『サーリプッタよ、私は心が解脱していることによって偉大な人と説く』（相応部 5.377）という言葉から、心が解脱していることによって『偉大な人』と呼ばれる、という意味である。」
