
# 6. Uggasenavatthu

## 348

348.

‘‘Muñca pure muñca pacchato,

Majjhe muñca bhavassa pāragū;

Sabbattha vimuttamānaso,

Na punaṃ jātijaraṃ upehisī’’ti.

Tattha muñca pureti atītesu khandhesu ālayaṃ nikantiṃ ajjhosānaṃ patthanaṃ pariyuṭṭhānaṃ gāhaṃ parāmāsaṃ taṇhaṃ muñca. Pacchatoti anāgatesupi khandhesu ālayādīni muñca. Majjheti paccuppannesupi tāni muñca. Bhavassa pāragūti evaṃ sante tividhassāpi bhavassa abhiññāpariññāpahānabhāvanāsacchikiriyavasena pāragū pāraṅgato hutvā khandhadhātuāyatanādibhede sabbasaṅkhate vimuttamānaso viharanto puna jātijarāmaraṇāni na upagacchatīti attho.

### 対訳

1. 6. Uggasenavatthu

* uggasena-vatthu = 「ウッガセーナの話」

  * vatthu = 「話、物語、事例」

→「ウッガセーナの話」

2. 348. ‘‘Muñca pure muñca pacchato, Majjhe muñca bhavassa pāragū; Sabbattha vimuttamānaso, Na punaṃ jātijaraṃ upehisī’’ti.

* muñca = 「捨てよ (muñcati の命令法二人称単数)」

* pure = 「前を(過去について)」

* pacchato = 「後ろを(未来について)」

* majjhe = 「中間を(現在について)」

* bhavassa pāragū = 「存在(有)の彼岸に至った者」

  * bhava = 「存在、有」

  * pāragū = 「彼岸に至った者」

* sabbattha = 「あらゆるところで」

* vimuttamānaso = 「心が解脱した者」(vimutta-mānasa)

* na punaṃ ... upehisi = 「再び～に近づかないであろう」

  * upehisi = 「近づくであろう (upeti の未来二人称単数)」

* jātijaraṃ = 「生と老い」

→「前を捨てよ、後ろを捨てよ、中間を捨てよ。存在の彼岸に至った者として、あらゆるところで心が解脱した者は、再び生と老いに近づかないであろう。」

3. Tattha muñca pureti atītesu khandhesu ālayaṃ nikantiṃ ajjhosānaṃ patthanaṃ pariyuṭṭhānaṃ gāhaṃ parāmāsaṃ taṇhaṃ muñca.

* tattha = 「そこで(その偈において)」

* atītesu khandhesu = 「過去の諸蘊について」

* ālayaṃ = 「執着」

* nikantiṃ = 「欲求」

* ajjhosānaṃ = 「固執」

* patthanaṃ = 「願い」

* pariyuṭṭhānaṃ = 「(心に)まとわりつくこと(纏)」

* gāhaṃ = 「とらえること(執取)」

* parāmāsaṃ = 「誤ったとらえ方(執着)」

* taṇhaṃ = 「渇愛」

* muñca = 「捨てよ」

→「そこで『muñca pure』とは、過去の諸蘊についての執着・欲求・固執・願い・纏・執取・誤ったとらえ方である渇愛を捨てよ(という意味である)。」

4. Pacchatoti anāgatesupi khandhesu ālayādīni muñca.

* anāgatesu pi khandhesu = 「未来の諸蘊についても」

* ālayādīni = 「執着などを」

* muñca = 「捨てよ」

→「『pacchato』とは、未来の諸蘊についても執着などを捨てよ(という意味である)。」

5. Majjheti paccuppannesupi tāni muñca.

* paccuppannesu pi = 「現在の(諸蘊)についても」

* tāni = 「それら(執着など)を」

* muñca = 「捨てよ」

→「『majjhe』とは、現在の(諸蘊)についてもそれらを捨てよ(という意味である)。」

6. Bhavassa pāragūti evaṃ sante tividhassāpi bhavassa abhiññāpariññāpahānabhāvanāsacchikiriyavasena pāragū pāraṅgato hutvā khandhadhātuāyatanādibhede sabbasaṅkhate vimuttamānaso viharanto puna jātijarāmaraṇāni na upagacchatīti attho.

* evaṃ sante = 「そのようであるとき」

* tividhassāpi bhavassa = 「三種の存在(欲有・色有・無色有)についても」

* abhiññā-pariññā-pahāna-bhāvanā-sacchikiriya-vasena = 「証知・遍知・捨断・修習・作証によって」

  * abhiññā = 「証知(すぐれた智で知ること)」

  * pariññā = 「遍知(あまねく知ること)」

  * pahāna = 「捨断」

  * bhāvanā = 「修習」

  * sacchikiriyā = 「作証(直接体験して実現すること)」

* pāragū pāraṅgato hutvā = 「彼岸に至った者、彼岸に達した者となって」

* khandha-dhātu-āyatana-ādi-bhede = 「蘊・界・処などに分類される」

* sabbasaṅkhate = 「すべての形成されたもの(有為)において」

* vimuttamānaso viharanto = 「心が解脱した者として住みつつ」

* puna jātijarāmaraṇāni na upagacchati = 「再び生・老・死に近づかない」

* ti attho = 「という意味である」

→「『bhavassa pāragū』とは、そのようであるとき、三種の存在についても証知・遍知・捨断・修習・作証によって彼岸に至った者、彼岸に達した者となって、蘊・界・処などに分類されるすべての形成されたものにおいて心が解脱した者として住みつつ、再び生・老・死に近づかない、という意味である。」
