
# 1. Pañcabhikkhuvatthu

## 360-361

360.

‘‘Cakkhunā saṃvaro sādhu, sādhu sotena saṃvaro;

Ghānena saṃvaro sādhu, sādhu jivhāya saṃvaro.

361.

‘‘Kāyena saṃvaro sādhu, sādhu vācāya saṃvaro;

Manasā saṃvaro sādhu, sādhu sabbattha saṃvaro;

Sabbattha saṃvuto bhikkhu, sabbadukkhā pamuccatī’’ti.

Tattha cakkhunāti yadā hi bhikkhuno cakkhudvāre rūpārammaṇaṃ āpāthamāgacchati, tadā iṭṭhārammaṇe arajjantassa aniṭṭhārammaṇe adussantassa asamapekkhanena mohaṃ anuppādentassa tasmiṃ dvāre saṃvaro thakanaṃ pidahanaṃ gutti katā nāma hoti. Tassa so evarūpo cakkhunā saṃvaro sādhu. Esa nayo sotadvārādīsupi. Cakkhudvārādīsuyeva pana saṃvaro vā asaṃvaro vā nuppajjati, parato pana javanavīthiyaṃ esa labbhati. Tadā hi asaṃvaro uppajjanto assaddhā akkhanti kosajjaṃ muṭṭhasaccaṃ aññāṇanti akusalavīthiyaṃ ayaṃ pañcavidho labbhati. Saṃvaro uppajjanto saddhā khanti vīriyaṃ sati ñāṇanti kusalavīthiyaṃ ayaṃ pañcavidho labbhati.

Kāyena saṃvaroti ettha pana pasādakāyopi copanakāyopi labbhati. Ubhayampi panetaṃ kāyadvārameva. Tattha pasādadvāre saṃvarāsaṃvaro kathitova. Copanadvārepi taṃvatthukā pāṇātipātaadinnādānakāmesumicchācārā. Tehi pana saddhiṃ akusalavīthiyaṃ uppajjantehi taṃ dvāraṃ asaṃvutaṃ hoti, kusalavīthiyaṃ uppajjantehi pāṇātipātāveramaṇiādīhi saṃvutaṃ. Sādhu vācāyāti etthāpi copanavācāpi vācā. Tāya saddhiṃ uppajjantehi musāvādādīhi taṃ dvāraṃ asaṃvutaṃ hoti, musāvādāveramaṇiādīhi saṃvutaṃ. Manasā saṃvaroti etthāpi javanamanato aññena manena saddhiṃ abhijjhādayo natthi. Manodvāre pana javanakkhaṇe uppajjamānehi abhijjhādīhi taṃ dvāraṃ asaṃvutaṃ hoti, anabhijjhādīhi saṃvutaṃ hoti. Sādhu sabbatthāti tesu cakkhudvārādīsu sabbesupi saṃvaro sādhu. Ettāvatā hi aṭṭha saṃvaradvārāni aṭṭha ca asaṃvaradvārāni kathitāni. Tesu aṭṭhasu asaṃvaradvāresu ṭhito bhikkhu sakalavaṭṭamūlakadukkhato na muccati, saṃvaradvāresu pana ṭhito sabbasmāpi vaṭṭamūlakadukkhā muccati. Tena vuttaṃ – ‘‘sabbattha saṃvuto bhikkhu, sabbadukkhā pamuccatī’’ti.

### 対訳

1. 1. Pañcabhikkhuvatthu

* pañca-bhikkhu-vatthu = 「五人の比丘の話」
  * pañca = 「五」
  * bhikkhu = 「比丘」
  * vatthu = 「話、物語、事例」

→「五人の比丘の話」

2. 360. ‘‘Cakkhunā saṃvaro sādhu, sādhu sotena saṃvaro; Ghānena saṃvaro sādhu, sādhu jivhāya saṃvaro.

* cakkhunā = 「眼によって、眼における」（cakkhu の具格）
* saṃvaro = 「防護、律儀」
* sādhu = 「善い、良いことである」
* sotena = 「耳における」（sota の具格）
* ghānena = 「鼻における」（ghāna の具格）
* jivhāya = 「舌における」（jivhā の具格）

→「眼における防護は善い。耳における防護は善い。鼻における防護は善い。舌における防護は善い。」

3. 361. ‘‘Kāyena saṃvaro sādhu, sādhu vācāya saṃvaro; Manasā saṃvaro sādhu, sādhu sabbattha saṃvaro; Sabbattha saṃvuto bhikkhu, sabbadukkhā pamuccatī’’ti.

* kāyena = 「身における」（kāya の具格）
* vācāya = 「語における」（vācā の具格）
* manasā = 「意における」（manas の具格）
* sabbattha = 「すべてのところにおいて」
* saṃvuto = 「防護された」（saṃvarati の過去分詞）
* bhikkhu = 「比丘は」
* sabbadukkhā = 「すべての苦から」（奪格）
* pamuccati = 「解放される」（pa + √muc の受動態）
* ti = 引用の終わりを示す

→「身における防護は善い。語における防護は善い。意における防護は善い。すべてのところにおける防護は善い。すべてのところで防護された比丘は、すべての苦から解放される。」

4. Tattha cakkhunāti yadā hi bhikkhuno cakkhudvāre rūpārammaṇaṃ āpāthamāgacchati, tadā iṭṭhārammaṇe arajjantassa aniṭṭhārammaṇe adussantassa asamapekkhanena mohaṃ anuppādentassa tasmiṃ dvāre saṃvaro thakanaṃ pidahanaṃ gutti katā nāma hoti.

* tattha = 「そこで（その偈の中で）」
* cakkhunā ti = 「『cakkhunā（眼における）』とは」
* yadā hi = 「実に～するとき」
* bhikkhuno = 「比丘にとって」（属格）
* cakkhudvāre = 「眼門において」
* rūpārammaṇaṃ = 「色の所縁が」（rūpa-ārammaṇa）
* āpāthamāgacchati = 「（認識の）領域にやって来る」（āpāthaṃ āgacchati）
  * āpātha = 「（感官の）領域、視野」
* tadā = 「そのとき」
* iṭṭhārammaṇe arajjantassa = 「好ましい所縁に対して貪らない者にとって」
  * iṭṭha = 「好ましい、望ましい」
  * arajjant = 「貪染しない」（rajjati の現在分詞の否定）
* aniṭṭhārammaṇe adussantassa = 「好ましくない所縁に対して怒らない者にとって」
  * adussant = 「瞋らない」（dussati の現在分詞の否定）
* asamapekkhanena = 「正しく観ないことによって」
  * a-samapekkhana = 「正しい観察の欠如」
* mohaṃ anuppādentassa = 「痴を生じさせない者にとって」
* tasmiṃ dvāre = 「その門において」
* saṃvaro = 「防護が」
* thakanaṃ pidahanaṃ gutti = 「閉じること、覆うこと、守護が」
* katā nāma hoti = 「なされたことになる」

→「そこで『cakkhunā（眼における）』とは（次の意味である）。実に、比丘の眼門に色の所縁が領域にやって来るとき、好ましい所縁に貪らず、好ましくない所縁に怒らず、正しく観ないことで痴を生じさせない者には、その門において防護が、すなわち閉じること、覆うこと、守護がなされたことになる。」

5. Tassa so evarūpo cakkhunā saṃvaro sādhu.

* tassa = 「その者にとって」
* so evarūpo = 「そのような」
  * evarūpa = 「このような形の」
* cakkhunā saṃvaro = 「眼における防護は」
* sādhu = 「善い」

→「その者にとって、そのような眼における防護は善い。」

6. Esa nayo sotadvārādīsupi.

* esa nayo = 「この方法（理趣）は」
* sotadvārādīsu pi = 「耳門などにおいても（同様である）」
  * sota-dvāra-ādi = 「耳門など」

→「この方法は耳門などにおいても同様である。」

7. Cakkhudvārādīsuyeva pana saṃvaro vā asaṃvaro vā nuppajjati, parato pana javanavīthiyaṃ esa labbhati.

* cakkhudvārādīsu yeva = 「眼門などそのものにおいては」
* pana = 「しかし」
* saṃvaro vā asaṃvaro vā = 「防護も不防護も」
* nuppajjati = 「生じない」（na uppajjati）
* parato = 「その後に」
* javanavīthiyaṃ = 「速行の路において」
  * javana = 「速行（認識過程で業を作る心）」
  * vīthi = 「路、認識過程」
* esa labbhati = 「これが得られる」

→「しかし、眼門などそのものにおいては防護も不防護も生じない。その後の速行の路において、これ（防護と不防護）が得られるのである。」

8. Tadā hi asaṃvaro uppajjanto assaddhā akkhanti kosajjaṃ muṭṭhasaccaṃ aññāṇanti akusalavīthiyaṃ ayaṃ pañcavidho labbhati.

* tadā hi = 「実にそのとき」
* asaṃvaro uppajjanto = 「不防護が生じるとき」
  * uppajjanta = 「生じつつある」（現在分詞）
* assaddhā = 「不信」
* akkhanti = 「不忍耐」
* kosajjaṃ = 「怠惰」
* muṭṭhasaccaṃ = 「失念（念の忘失）」
* aññāṇaṃ = 「無智」
* ti = 「～という（列挙の締め）」
* akusalavīthiyaṃ = 「不善の（速行の）路において」
* ayaṃ pañcavidho labbhati = 「この五種が得られる」

→「実にそのとき、不防護が生じるならば、不信・不忍耐・怠惰・失念・無智という、この五種が不善の路において得られる。」

9. Saṃvaro uppajjanto saddhā khanti vīriyaṃ sati ñāṇanti kusalavīthiyaṃ ayaṃ pañcavidho labbhati.

* saṃvaro uppajjanto = 「防護が生じるとき」
* saddhā = 「信」
* khanti = 「忍耐」
* vīriyaṃ = 「精進」
* sati = 「念」
* ñāṇaṃ = 「智」
* kusalavīthiyaṃ = 「善の（速行の）路において」
* ayaṃ pañcavidho labbhati = 「この五種が得られる」

→「防護が生じるならば、信・忍耐・精進・念・智という、この五種が善の路において得られる。」

10. Kāyena saṃvaroti ettha pana pasādakāyopi copanakāyopi labbhati.

* kāyena saṃvaro ti = 「『kāyena saṃvaro（身における防護）』とは」
* ettha pana = 「しかしここでは」
* pasādakāyo pi = 「浄（感受性）としての身も」
  * pasāda = 「浄色、感官の感受性」
* copanakāyo pi = 「動作としての身（身表としての身）も」
  * copana = 「動かすこと、動作（による意思の表示）」
* labbhati = 「得られる（該当する）」

→「『kāyena saṃvaro（身における防護）』とは、ここでは浄としての身も動作としての身も得られる（両方が該当する）。」

11. Ubhayampi panetaṃ kāyadvārameva.

* ubhayam pi = 「両者とも」
* pana etaṃ = 「しかしこれは」
* kāyadvāram eva = 「まさに身門である」

→「しかし、この両者とも、まさに身門である。」

12. Tattha pasādadvāre saṃvarāsaṃvaro kathitova.

* tattha = 「そのうち」
* pasādadvāre = 「浄の門については」
* saṃvarāsaṃvaro = 「防護と不防護は」（saṃvara-asaṃvara）
* kathito va = 「すでに説かれたとおりである」
  * kathita = 「説かれた」（katheti の過去分詞）

→「そのうち、浄の門における防護と不防護は、すでに説かれたとおりである。」

13. Copanadvārepi taṃvatthukā pāṇātipātaadinnādānakāmesumicchācārā.

* copanadvāre pi = 「動作の門においても」
* taṃvatthukā = 「それ（その門）を依りどころとする」
  * taṃ-vatthuka = 「それを基盤とするもの」
* pāṇātipāta-adinnādāna-kāmesumicchācārā = 「殺生・偸盗・欲における邪行（邪淫）が（ある）」
  * pāṇātipāta = 「殺生」
  * adinnādāna = 「与えられていないものを取ること、偸盗」
  * kāmesu micchācāra = 「諸欲における邪行、邪淫」

→「動作の門においても、それを依りどころとする殺生・偸盗・邪淫がある。」

14. Tehi pana saddhiṃ akusalavīthiyaṃ uppajjantehi taṃ dvāraṃ asaṃvutaṃ hoti, kusalavīthiyaṃ uppajjantehi pāṇātipātāveramaṇiādīhi saṃvutaṃ.

* tehi pana saddhiṃ = 「しかしそれら（殺生など）とともに」
* akusalavīthiyaṃ uppajjantehi = 「不善の路において生じるもの（心）によって」
* taṃ dvāraṃ = 「その門は」
* asaṃvutaṃ hoti = 「防護されていないものとなる」
* kusalavīthiyaṃ uppajjantehi = 「善の路において生じるものによって」
* pāṇātipātāveramaṇiādīhi = 「殺生からの離などによって」
  * veramaṇī = 「離れること、離」
  * ādi = 「など」
* saṃvutaṃ = 「防護されたものとなる」

→「しかし、それら（殺生など）とともに不善の路において生じるもの（心）によってその門は防護されないものとなり、善の路において生じる、殺生からの離などによって防護されたものとなる。」

15. Sādhu vācāyāti etthāpi copanavācāpi vācā.

* sādhu vācāyā ti = 「『sādhu vācāya（語における防護は善い）』とは」
* ettha pi = 「ここでも」
* copanavācā pi = 「動作としての語（語表としての語）も」
* vācā = 「語（に含まれる）」

→「『sādhu vācāya（語における防護は善い）』とは、ここでも動作としての語もまた語である。」

16. Tāya saddhiṃ uppajjantehi musāvādādīhi taṃ dvāraṃ asaṃvutaṃ hoti, musāvādāveramaṇiādīhi saṃvutaṃ.

* tāya saddhiṃ = 「それ（動作としての語）とともに」
* uppajjantehi musāvādādīhi = 「生じる妄語などによって」
  * musāvāda = 「妄語、嘘をつくこと」
* taṃ dvāraṃ asaṃvutaṃ hoti = 「その門は防護されないものとなる」
* musāvādāveramaṇiādīhi = 「妄語からの離などによって」
* saṃvutaṃ = 「防護されたものとなる」

→「それとともに生じる妄語などによってその門は防護されないものとなり、妄語からの離などによって防護されたものとなる。」

17. Manasā saṃvaroti etthāpi javanamanato aññena manena saddhiṃ abhijjhādayo natthi.

* manasā saṃvaro ti = 「『manasā saṃvaro（意における防護）』とは」
* ettha pi = 「ここでも」
* javanamanato aññena manena saddhiṃ = 「速行の意以外の意とともには」
  * javana-manas = 「速行の意」
  * añña = 「他の」
* abhijjhādayo = 「貪欲（abhijjhā）などは」
  * abhijjhā = 「貪欲、むさぼり」
* natthi = 「存在しない」

→「『manasā saṃvaro（意における防護）』とは、ここでも、速行の意以外の意とともには貪欲などは存在しない。」

18. Manodvāre pana javanakkhaṇe uppajjamānehi abhijjhādīhi taṃ dvāraṃ asaṃvutaṃ hoti, anabhijjhādīhi saṃvutaṃ hoti.

* manodvāre pana = 「しかし意門において」
* javanakkhaṇe = 「速行の瞬間に」
  * khaṇa = 「瞬間、刹那」
* uppajjamānehi abhijjhādīhi = 「生じつつある貪欲などによって」
* taṃ dvāraṃ asaṃvutaṃ hoti = 「その門は防護されないものとなる」
* anabhijjhādīhi = 「無貪欲などによって」
* saṃvutaṃ hoti = 「防護されたものとなる」

→「しかし意門においては、速行の瞬間に生じつつある貪欲などによってその門は防護されないものとなり、無貪欲などによって防護されたものとなる。」

19. Sādhu sabbatthāti tesu cakkhudvārādīsu sabbesupi saṃvaro sādhu.

* sādhu sabbatthā ti = 「『sādhu sabbattha（すべてのところにおける防護は善い）』とは」
* tesu cakkhudvārādīsu sabbesu pi = 「それら眼門などのすべてにおいても」
* saṃvaro sādhu = 「防護は善い（という意味である）」

→「『sādhu sabbattha』とは、それら眼門などのすべてにおいても防護は善い、という意味である。」

20. Ettāvatā hi aṭṭha saṃvaradvārāni aṭṭha ca asaṃvaradvārāni kathitāni.

* ettāvatā hi = 「実にこれだけで、以上によって」
* aṭṭha saṃvaradvārāni = 「八つの防護の門が」
* aṭṭha ca asaṃvaradvārāni = 「そして八つの不防護の門が」
* kathitāni = 「説かれた」

→「実に以上によって、八つの防護の門と八つの不防護の門が説かれた。」

21. Tesu aṭṭhasu asaṃvaradvāresu ṭhito bhikkhu sakalavaṭṭamūlakadukkhato na muccati, saṃvaradvāresu pana ṭhito sabbasmāpi vaṭṭamūlakadukkhā muccati.

* tesu aṭṭhasu asaṃvaradvāresu = 「それら八つの不防護の門に」
* ṭhito bhikkhu = 「立つ（とどまる）比丘は」
  * ṭhita = 「立った、確立した」（tiṭṭhati の過去分詞）
* sakalavaṭṭamūlakadukkhato = 「全体の、輪転を根とする苦から」
  * sakala = 「全体の」
  * vaṭṭa = 「輪転、輪廻」
  * mūlaka = 「～を根とする」
* na muccati = 「解放されない」
* saṃvaradvāresu pana ṭhito = 「しかし防護の門に立つ者は」
* sabbasmā pi vaṭṭamūlakadukkhā = 「すべての輪転を根とする苦から」
* muccati = 「解放される」

→「それら八つの不防護の門に立つ比丘は、輪転を根とする苦の全体から解放されない。しかし防護の門に立つ者は、輪転を根とするすべての苦からも解放される。」

22. Tena vuttaṃ – ‘‘sabbattha saṃvuto bhikkhu, sabbadukkhā pamuccatī’’ti.

* tena vuttaṃ = 「それゆえに説かれた」
* sabbattha saṃvuto bhikkhu = 「すべてのところで防護された比丘は」
* sabbadukkhā pamuccatī ti = 「すべての苦から解放される、と」

→「それゆえに『すべてのところで防護された比丘は、すべての苦から解放される』と説かれたのである。」
