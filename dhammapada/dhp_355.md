
# 11. Aputtakaseṭṭhivatthu

## 355

355.

‘‘Hananti bhogā dummedhaṃ, no ca pāragavesino;

Bhogataṇhāya dummedho, hanti aññeva attana’’nti.

Tattha no ca pāragavesinoti ye pana nibbānapāragavesino puggalā, na te bhogā hananti. Aññeva attananti bhoge nissāya uppannāya taṇhāya duppañño puggalo pare viya attānameva hanatīti attho.

### 対訳

1. 11. Aputtakaseṭṭhivatthu

* aputtaka-seṭṭhi-vatthu = 「子のない長者の話」
  * aputtaka = 「子のない、跡継ぎのない」
  * seṭṭhi = 「長者、富豪」
  * vatthu = 「話、物語、事例」

→「子のない長者の話」

2. 355. ‘‘Hananti bhogā dummedhaṃ, no ca pāragavesino; Bhogataṇhāya dummedho, hanti aññeva attana’’nti.

* hananti = 「殺す、害する（han の三人称複数現在）」
* bhogā = 「財産は（複数主格）」
* dummedhaṃ = 「愚かな者を（対格）」
  * dur + medhā（智慧）から、「智慧の乏しい者」
* no ca = 「しかし～ない」
* pāragavesino = 「彼岸を求める者たちを（対格複数）」
  * pāra-gavesin = 「彼岸（pāra）を探し求める（gavesin）者」
* bhoga-taṇhāya = 「財産への渇愛によって（具格）」
* dummedho = 「愚かな者は（主格）」
* hanti = 「殺す、害する（三人称単数現在）」
* aññe va = 「まるで他人を（害する）ように」
  * aññe = 「他の者たちを（対格複数）」
  * va = iva 「～のように」
* attanaṃ = 「自分自身を（対格）」
* ti = 「～と（引用の終わり）」

→「財産は愚かな者を害するが、彼岸を求める者たちを（害することは）ない。財産への渇愛によって、愚かな者は、まるで他人を（害する）かのように自分自身を害する。」

3. Tattha no ca pāragavesinoti ye pana nibbānapāragavesino puggalā, na te bhogā hananti.

* tattha = 「そこで（この偈の中で）」
* no ca pāragavesino ti = 「『no ca pāragavesino』とは」
* ye pana = 「しかし～である者たちは」
* nibbāna-pāra-gavesino puggalā = 「涅槃という彼岸を求める人々」
  * nibbāna = 「涅槃」
  * pāra = 「彼岸」
  * gavesin = 「探し求める者」
  * puggalā = 「人々（主格複数）」
* na te bhogā hananti = 「彼らを財産は害さない」
  * te = 「彼らを（対格複数）」
  * bhogā = 「財産は」
  * hananti = 「害する」

→「そこで『no ca pāragavesino』とは、涅槃という彼岸を求める人々を、財産は害さない（という意味である）。」

4. Aññeva attananti bhoge nissāya uppannāya taṇhāya duppañño puggalo pare viya attānameva hanatīti attho.

* aññe va attanan ti = 「『aññeva attanaṃ』とは」
* bhoge nissāya = 「財産に依って、財産を縁として」
  * nissāya = 「～に依って（nissayati の連続体）」
* uppannāya taṇhāya = 「生じた渇愛によって（具格）」
  * uppanna = 「生じた（uppajjati の過去分詞）」
* duppañño puggalo = 「智慧の劣った人は」
  * duppañña = 「智慧の劣った（du + paññā）」
* pare viya = 「他人たちを（害する）かのように」
  * pare = 「他の者たちを（対格複数）」
  * viya = 「～のように」
* attānam eva = 「まさに自分自身を」
* hanati = 「害する」
* ti attho = 「という意味である」

→「『aññeva attanaṃ』とは、財産を縁として生じた渇愛によって、智慧の劣った人は、他人たちを（害する）かのように、まさに自分自身を害する、という意味である。」
