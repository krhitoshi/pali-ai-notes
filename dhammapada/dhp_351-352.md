
# 8. Māravatthu

## 351-352

351.

‘‘Niṭṭhaṅgato asantāsī, vītataṇho anaṅgaṇo;

Acchindi bhavasallāni, antimoyaṃ samussayo.

352.

‘‘Vītataṇho anādāno, niruttipadakovido;

Akkharānaṃ sannipātaṃ, jaññā pubbāparāni ca;

Sa ve antimasārīro,

Mahāpañño mahāpurisoti vuccatī’’ti.

Tattha niṭṭhaṅgatoti imasmiṃ sāsane pabbajitānaṃ arahattaṃ niṭṭhaṃ nāma, taṃ gato pattoti attho. Asantāsīti abbhantare rāgasantāsādīnaṃ abhāvena asantasanako. Acchindi bhavasallānīti sabbānipi bhavagāmīni sallāni acchindi. Samussayoti ayaṃ etassa antimo deho.

Anādānoti khandhādīsu niggahaṇo. Niruttipadakovidoti niruttiyañca sesapadesu cāti catūsupi paṭisambhidāsu chekoti attho. Akkharānaṃ sannipātaṃ, jaññā pubbāparāni cāti akkharānaṃ sannipātasaṅkhātaṃ akkharapiṇḍañca jānāti, pubbakkharena aparakkharaṃ, aparakkharena pubbakkharañca jānāti. Pubbakkharena aparakkharaṃ jānāti nāma – ādimhi paññāyamāne majjhapariyosānesu apaññāyamānesupi ‘‘imesaṃ akkharānaṃ idaṃ majjhaṃ, idaṃ pariyosāna’’nti jānāti. Aparakkharena pubbakkharaṃ jānāti nāma – ante paññāyamāne ādimajjhesu apaññāyamānesu ‘‘imesaṃ akkharānaṃ idaṃ majjhaṃ, ayaṃ ādī’’ti jānāti. Majjhe paññāyamānepi ‘‘imesaṃ akkharānaṃ ayaṃ ādi, ayaṃ anto’’ti jānāti. Evaṃ mahāpañño. Sa ve antimasārīroti esa koṭiyaṃ ṭhitasarīro, mahantānaṃ atthadhammaniruttipaṭibhānānaṃ sīlakkhandhādīnañca pariggāhikāya paññāya samannāgatattā mahāpañño, ‘‘vimuttacittattā khvāhaṃ, sāriputta, mahāpurisoti vadāmī’’ti (saṃ. ni. 5.377) vacanato vimuttacittatāya ca mahāpurisoti vuccatīti attho.

### 対訳

1. 8. Māravatthu

* māra-vatthu = 「マーラ (悪魔) の話」
  * māra = 「マーラ、悪魔」
  * vatthu = 「話、物語、事例」

→「マーラの話」

2. 351. ‘‘Niṭṭhaṅgato asantāsī, vītataṇho anaṅgaṇo;

* niṭṭhaṅgato = 「目標に達した者」（niṭṭhā-gata）
  * niṭṭhā = 「目標、完成、究極」
  * gata = 「行った、達した（gacchati の過去分詞）」
* asantāsī = 「恐れおののかない者」
  * a + santāsin（santāsa = 「おののき、恐怖」）
* vītataṇho = 「渇愛を離れた者」
  * vīta = 「離れた、なくなった」
  * taṇhā = 「渇愛」
* anaṅgaṇo = 「汚れのない者」
  * aṅgaṇa = 「汚れ、けがれ」

→「目標に達し、恐れおののかず、渇愛を離れ、汚れのない者は、」

3. Acchindi bhavasallāni, antimoyaṃ samussayo.

* acchindi = 「断ち切った（chindati のアオリスト）」
* bhavasallāni = 「生存の矢を」
  * bhava = 「生存、有」
  * salla = 「矢」
* antimo ayaṃ samussayo = 「これが最後の身体である」
  * antima = 「最後の」
  * samussaya = 「身体、体躯」

→「生存の矢を断ち切った。これが最後の身体である。」

4. 352. ‘‘Vītataṇho anādāno, niruttipadakovido;

* vītataṇho = 「渇愛を離れた者」
* anādāno = 「執着のない者」
  * an + ādāna（ādāna = 「取ること、執着」）
* niruttipadakovido = 「言葉と語句に熟達した者」
  * nirutti = 「言葉、詞」
  * pada = 「語句」
  * kovida = 「熟達した、精通した」

→「渇愛を離れ、執着なく、言葉と語句に熟達し、」

5. Akkharānaṃ sannipātaṃ, jaññā pubbāparāni ca;

* akkharānaṃ = 「文字の」
* sannipātaṃ = 「結合、集まりを」
* jaññā = 「知るであろう（jānāti の願望法・三人称単数）」
* pubbāparāni ca = 「前後（の文字）をも」
  * pubba = 「前の」
  * apara = 「後の」

→「文字の結合と前後（の文字）を知るであろう。」

6. Sa ve antimasārīro, Mahāpañño mahāpurisoti vuccatī’’ti.

* sa ve = 「彼こそ」
* antimasārīro = 「最後の身体を持つ者」
  * antima = 「最後の」
  * sarīra = 「身体」
* mahāpañño = 「大いなる智慧ある者」
* mahāpuriso ti vuccati = 「『大人（偉大な人）』と言われる」

→「彼こそ最後の身体を持つ者であり、大いなる智慧ある者、『大人』と言われる。」

7. Tattha niṭṭhaṅgatoti imasmiṃ sāsane pabbajitānaṃ arahattaṃ niṭṭhaṃ nāma, taṃ gato pattoti attho.

* tattha = 「そのうち（その偈のうちで）」
* imasmiṃ sāsane = 「この教えにおいて」
* pabbajitānaṃ = 「出家した者たちにとって」
* arahattaṃ = 「阿羅漢果が」
* niṭṭhaṃ nāma = 「『目標』と呼ばれる」
* taṃ gato patto ti attho = 「それに至った、達した、という意味である」
  * patta = 「達した（pāpuṇāti の過去分詞）」

→「そのうち『niṭṭhaṅgato』とは、この教えにおいて出家した者たちにとって阿羅漢果が『目標』と呼ばれ、それに至った、達した、という意味である。」

8. Asantāsīti abbhantare rāgasantāsādīnaṃ abhāvena asantasanako.

* abbhantare = 「内に」
* rāga-santāsa-ādīnaṃ = 「貪りによるおののきなどの」
* abhāvena = 「存在しないことによって」
* asantasanako = 「おののかない者」

→「『asantāsī』とは、内に貪りによるおののきなどが存在しないことによって、おののかない者（という意味である）。」

9. Acchindi bhavasallānīti sabbānipi bhavagāmīni sallāni acchindi.

* sabbāni pi = 「すべての」
* bhavagāmīni = 「生存へ導く」
  * bhava-gāmin = 「有に趣く、生存へ向かわせる」
* sallāni = 「矢を」
* acchindi = 「断ち切った」

→「『acchindi bhavasallāni』とは、生存へ導くすべての矢を断ち切った（という意味である）。」

10. Samussayoti ayaṃ etassa antimo deho.

* ayaṃ = 「これは」
* etassa = 「この者の」
* antimo deho = 「最後の身体（である）」
  * deha = 「身体」

→「『samussayo』とは、これはこの者の最後の身体である（という意味である）。」

11. Anādānoti khandhādīsu niggahaṇo.

* khandha-ādīsu = 「蘊などにおいて」
* niggahaṇo = 「取ることのない者」
  * nis + gahaṇa（gahaṇa = 「取ること、把持」）

→「『anādāno』とは、蘊などにおいて取ることのない者（という意味である）。」

12. Niruttipadakovidoti niruttiyañca sesapadesu cāti catūsupi paṭisambhidāsu chekoti attho.

* niruttiyañ ca = 「詞（詞無礙解）においても」
* sesapadesu ca = 「残りの句（義・法・弁の無礙解）においても」
* ti = 「と（このように）」
* catūsu pi paṭisambhidāsu = 「四無礙解すべてにおいて」
* cheko ti attho = 「巧みな者、という意味である」
  * cheka = 「巧みな、熟練した」

→「『niruttipadakovido』とは、詞においても残りの句においても、と、四無礙解すべてにおいて巧みな者、という意味である。」

13. Akkharānaṃ sannipātaṃ, jaññā pubbāparāni cāti akkharānaṃ sannipātasaṅkhātaṃ akkharapiṇḍañca jānāti, pubbakkharena aparakkharaṃ, aparakkharena pubbakkharañca jānāti.

* akkharānaṃ sannipātasaṅkhātaṃ = 「文字の結合と呼ばれる」
  * saṅkhāta = 「～と呼ばれる、～と称される」
* akkharapiṇḍañ ca = 「文字のまとまりを」
  * piṇḍa = 「かたまり、集合」
* jānāti = 「知る」
* pubbakkharena aparakkharaṃ = 「前の文字によって後の文字を」
* aparakkharena pubbakkharañ ca jānāti = 「後の文字によって前の文字を知る」

→「『akkharānaṃ sannipātaṃ, jaññā pubbāparāni ca』とは、文字の結合と呼ばれる文字のまとまりを知り、前の文字によって後の文字を、後の文字によって前の文字を知る（という意味である）。」

14. Pubbakkharena aparakkharaṃ jānāti nāma – ādimhi paññāyamāne majjhapariyosānesu apaññāyamānesupi ‘‘imesaṃ akkharānaṃ idaṃ majjhaṃ, idaṃ pariyosāna’’nti jānāti.

* pubbakkharena aparakkharaṃ jānāti nāma = 「前の文字によって後の文字を知るとは」
* ādimhi paññāyamāne = 「はじめが明らかであるとき」
  * paññāyamāna = 「知られている、明らかな（paññāyati の現在分詞）」
* majjha-pariyosānesu apaññāyamānesu pi = 「中間と終わりが明らかでなくても」
  * pariyosāna = 「終わり、終結」
* "imesaṃ akkharānaṃ idaṃ majjhaṃ, idaṃ pariyosānaṃ" ti jānāti = 「"これらの文字の中間はこれ、終わりはこれ" と知る」

→「前の文字によって後の文字を知るとは、はじめが明らかで中間と終わりが明らかでなくても、"これらの文字の中間はこれ、終わりはこれ" と知ることである。」

15. Aparakkharena pubbakkharaṃ jānāti nāma – ante paññāyamāne ādimajjhesu apaññāyamānesu ‘‘imesaṃ akkharānaṃ idaṃ majjhaṃ, ayaṃ ādī’’ti jānāti.

* aparakkharena pubbakkharaṃ jānāti nāma = 「後の文字によって前の文字を知るとは」
* ante paññāyamāne = 「終わりが明らかであるとき」
* ādi-majjhesu apaññāyamānesu = 「はじめと中間が明らかでなくても」
* "imesaṃ akkharānaṃ idaṃ majjhaṃ, ayaṃ ādi" ti jānāti = 「"これらの文字の中間はこれ、はじめはこれ" と知る」

→「後の文字によって前の文字を知るとは、終わりが明らかではじめと中間が明らかでなくても、"これらの文字の中間はこれ、はじめはこれ" と知ることである。」

16. Majjhe paññāyamānepi ‘‘imesaṃ akkharānaṃ ayaṃ ādi, ayaṃ anto’’ti jānāti.

* majjhe paññāyamāne pi = 「中間が明らかであるときも」
* "imesaṃ akkharānaṃ ayaṃ ādi, ayaṃ anto" ti jānāti = 「"これらの文字のはじめはこれ、終わりはこれ" と知る」

→「中間が明らかであるときも、"これらの文字のはじめはこれ、終わりはこれ" と知る。」

17. Evaṃ mahāpañño.

* evaṃ = 「このように（知るのが）」
* mahāpañño = 「大いなる智慧ある者（である）」

→「このように（知るのが）大いなる智慧ある者である。」

18. Sa ve antimasārīroti esa koṭiyaṃ ṭhitasarīro, mahantānaṃ atthadhammaniruttipaṭibhānānaṃ sīlakkhandhādīnañca pariggāhikāya paññāya samannāgatattā mahāpañño, ‘‘vimuttacittattā khvāhaṃ, sāriputta, mahāpurisoti vadāmī’’ti (saṃ. ni. 5.377) vacanato vimuttacittatāya ca mahāpurisoti vuccatīti attho.

* esa = 「この者は」
* koṭiyaṃ ṭhitasarīro = 「終極に立つ身体を持つ者（である）」
  * koṭi = 「終極、際、はて」
* mahantānaṃ = 「大いなる」
* attha-dhamma-nirutti-paṭibhānānaṃ = 「義・法・詞・弁（の四無礙解）を」
* sīlakkhandha-ādīnañ ca = 「戒蘊などをも」
* pariggāhikāya paññāya = 「把握する智慧を」
  * pariggāhikā = 「把握する、とらえる（女性形）」
* samannāgatattā = 「具えていることから」
* mahāpañño = 「大いなる智慧ある者（であり）」
* "vimuttacittattā khvāhaṃ, sāriputta, mahāpurisoti vadāmi" ti vacanato = 「『サーリプッタよ、心が解脱していることから、私は「大人」と言う』という（相応部の）言葉から」
  * vimutta-cittattā = 「心が解脱していることから」
  * vacanato = 「言葉により、説かれていることから」
* vimuttacittatāya ca = 「そして心が解脱していることによって」
* mahāpuriso ti vuccatī ti attho = 「『大人』と言われる、という意味である」

→「『sa ve antimasārīro』とは、この者は終極に立つ身体を持つ者であり、大いなる義・法・詞・弁（の四無礙解）と戒蘊などを把握する智慧を具えていることから大いなる智慧ある者であり、『サーリプッタよ、心が解脱していることから、私は「大人」と言う』（相応部 5.377）という言葉から、心が解脱していることによって『大人』と言われる、という意味である。」
