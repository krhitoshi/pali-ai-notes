
# 9. Upakājīvakavatthu

## 353

353.

‘‘Sabbābhibhū sabbavidūhamasmi,

Sabbesu dhammesu anūpalitto;

Sabbañjaho taṇhakkhaye vimutto,

Sayaṃ abhiññāya kamuddiseyya’’nti.

Tattha sabbābhibhūti sabbesaṃ tebhūmakadhammānaṃ abhibhavanato sabbābhibhū. Sabbavidūti viditasabbacatubhūmakadhammo. Sabbesu dhammesūti sabbesupi tebhūmakadhammesu taṇhādiṭṭhīhi anūpalitto. Sabbañjahoti sabbe tebhūmakadhamme jahitvā ṭhito. Taṇhakkhaye vimuttoti taṇhakkhayante uppādite taṇhakkhayasaṅkhāte arahatte asekhāya vimuttiyā vimutto. Sayaṃ abhiññāyāti abhiññeyyādibhede dhamme sayameva jānitvā. Kamuddiseyyanti ‘‘ayaṃ me upajjhāyo vā ācariyo vā’’ti kaṃ nāma uddiseyyanti.

### 対訳

1. 9. Upakājīvakavatthu

* upaka-ājīvaka-vatthu = 「アージーヴィカのウパカの話」
  * upaka = 「ウパカ（人名。成道直後の仏に出会った遊行者）」
  * ājīvaka = 「アージーヴィカ、邪命外道（当時の遊行者の一派）」
  * vatthu = 「話、物語、事例」

→「アージーヴィカのウパカの話」

2. 353. ‘‘Sabbābhibhū sabbavidūhamasmi, Sabbesu dhammesu anūpalitto; Sabbañjaho taṇhakkhaye vimutto, Sayaṃ abhiññāya kamuddiseyya’’nti.

* sabbābhibhū = 「一切に打ち勝った者」（sabba-abhibhū）
* sabbavidū = 「一切を知った者」
* aham asmi = 「私は～である」（sabbavidūhamasmi = sabbavidū + aham + asmi の連声）
* sabbesu dhammesu = 「一切の法において」
* anūpalitto = 「汚されていない」（an-upalitta、upalimpati の過去分詞）
* sabbañjaho = 「一切を捨てた者」（sabbaṃ-jaha）
* taṇhakkhaye vimutto = 「渇愛の滅尽において解脱した者」
  * taṇhā-kkhaya = 「渇愛の滅尽」
* sayaṃ abhiññāya = 「自ら証知して」
* kam uddiseyyaṃ = 「誰を（師として）指し示そうか」
  * uddiseyyaṃ = 「指し示そうか（uddisati の願望法・一人称単数）」
* ti = 引用の terminator

→「私は一切に打ち勝った者、一切を知った者であり、一切の法において汚されていない。一切を捨て、渇愛の滅尽において解脱している。自ら証知したのに、誰を（師として）指し示そうか。」

3. Tattha sabbābhibhūti sabbesaṃ tebhūmakadhammānaṃ abhibhavanato sabbābhibhū.

* tattha = 「そこで（この偈において）」
* sabbesaṃ tebhūmaka-dhammānaṃ = 「三界に属する一切の法に」
  * tebhūmaka = 「三地の、三界（欲界・色界・無色界）に属する」
* abhibhavanato = 「打ち勝つことから」

→「そこで『sabbābhibhū』とは、三界に属する一切の法に打ち勝つことから『一切に打ち勝った者』である。」

4. Sabbavidūti viditasabbacatubhūmakadhammo.

* vidita-sabba-catubhūmaka-dhammo = 「四地に属する一切の法を知った者」
  * vidita = 「知られた（vindati / vid の過去分詞）」
  * catubhūmaka = 「四地の（三界に出世間を加えた四つの領域に属する）」

→「『sabbavidū』とは、四地に属する一切の法を知った者である。」

5. Sabbesu dhammesūti sabbesupi tebhūmakadhammesu taṇhādiṭṭhīhi anūpalitto.

* sabbesu pi tebhūmaka-dhammesu = 「三界に属する一切の法において」
* taṇhā-diṭṭhīhi = 「渇愛と見とによって」
* anūpalitto = 「汚されていない」

→「『sabbesu dhammesu』とは、三界に属する一切の法において、渇愛と見とによって汚されていない、ということである。」

6. Sabbañjahoti sabbe tebhūmakadhamme jahitvā ṭhito.

* sabbe tebhūmaka-dhamme = 「三界に属する一切の法を」
* jahitvā = 「捨てて（jahati の連続体）」
* ṭhito = 「立っている、とどまっている者」

→「『sabbañjaho』とは、三界に属する一切の法を捨てて立っている者である。」

7. Taṇhakkhaye vimuttoti taṇhakkhayante uppādite taṇhakkhayasaṅkhāte arahatte asekhāya vimuttiyā vimutto.

* taṇhakkhaya-ante uppādite = 「渇愛の滅尽の終極において生じた」
  * anta = 「終わり、終極」
  * uppādita = 「生じさせられた（uppādeti の過去分詞）」
* taṇhakkhaya-saṅkhāte arahatte = 「渇愛の滅尽と呼ばれる阿羅漢の位において」
  * saṅkhāta = 「～と呼ばれる、～と称される」
* asekhāya vimuttiyā = 「無学の解脱によって」
  * asekha = 「無学（もはや学ぶべきことのない阿羅漢の位）」
* vimutto = 「解脱した者」

→「『taṇhakkhaye vimutto』とは、渇愛の滅尽の終極において生じた、渇愛の滅尽と呼ばれる阿羅漢の位において、無学の解脱によって解脱した者である。」

8. Sayaṃ abhiññāyāti abhiññeyyādibhede dhamme sayameva jānitvā.

* abhiññeyya-ādi-bhede dhamme = 「証知されるべきものなどに分類される諸法を」
  * abhiññeyya = 「証知されるべき（もの）」
  * ādi-bheda = 「～などの区分をもつ」
* sayam eva = 「自らまさに」
* jānitvā = 「知って（jānāti の連続体）」

→「『sayaṃ abhiññāya』とは、証知されるべきものなどに分類される諸法を、自らまさに知って、ということである。」

9. Kamuddiseyyanti ‘‘ayaṃ me upajjhāyo vā ācariyo vā’’ti kaṃ nāma uddiseyyanti.

* ayaṃ me = 「この人が私の」
* upajjhāyo vā ācariyo vā = 「和尚あるいは阿闍梨」
  * upajjhāya = 「和尚（出家・受戒の際の師）」
* kaṃ nāma = 「いったい誰を」
* uddiseyyaṃ = 「指し示そうか」

→「『kamuddiseyyaṃ』とは、『この人が私の和尚である、あるいは阿闍梨である』と、いったい誰を指し示そうか、という意味である。」
