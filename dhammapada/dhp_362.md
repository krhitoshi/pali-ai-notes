
# 2. Haṃsaghātakabhikkhuvatthu

## 362

362.

‘‘Hatthasaṃyato pādasaṃyato,

Vācāsaṃyato saṃyatuttamo;

Ajjhattarato samāhito,

Eko santusito tamāhu bhikkhu’’nti.

Tattha hatthasaṃyatoti hatthakīḷāpanādīnaṃ vā hatthena paresaṃ paharaṇādīnaṃ vā abhāvena hatthasaṃyato. Dutiyapadepi eseva nayo. Vācāya pana musāvādādīnaṃ akaraṇato vācāya saṃyato. Saṃyatuttamoti saṃyatattabhāvo, kāyacalanasīsukkhipanabhamukavikārādīnaṃ akārakoti attho. Ajjhattaratoti gocarajjhattasaṅkhātāya kammaṭṭhānabhāvanāya rato. Samāhitoti suṭṭhu ṭhapito. Eko santusitoti ekavihārī hutvā suṭṭhu tusito vipassanācārato paṭṭhāya attano adhigamena tuṭṭhamānaso. Puthujjanakalyāṇakañhi ādiṃ katvā sabbepi sekhā attano adhigamena santussantīti santusitā, arahā pana ekantasantusitova. Taṃ sandhāyetaṃ vuttaṃ.

### 対訳

1. 2. Haṃsaghātakabhikkhuvatthu

* haṃsa-ghātaka-bhikkhu-vatthu = 「白鳥を殺した比丘の話」
  * haṃsa = 「白鳥、雁」
  * ghātaka = 「殺した者」
  * vatthu = 「話、物語、事例」

→「白鳥を殺した比丘の話」

2. 362. ‘‘Hatthasaṃyato pādasaṃyato, Vācāsaṃyato saṃyatuttamo; Ajjhattarato samāhito, Eko santusito tamāhu bhikkhu’’nti.

* hattha-saṃyato = 「手を制した者」
  * saṃyata = 「制した、抑制した（saṃ + yam の過去分詞）」
* pāda-saṃyato = 「足を制した者」
* vācā-saṃyato = 「言葉を制した者」
* saṃyatuttamo = 「最上のもの（身体全体）を制した者」（saṃyata-uttama）
* ajjhatta-rato = 「内に楽しむ者」
  * ajjhatta = 「内、内的なもの」
  * rata = 「楽しむ、喜ぶ（ram の過去分詞）」
* samāhito = 「心が統一された者、等持ある者」
* eko = 「独りの者」
* santusito = 「満足した者」
* taṃ āhu bhikkhuṃ = 「その者を比丘と呼ぶ」
  * āhu = 「（人々は）言った、呼ぶ」

→「手を制し、足を制し、言葉を制し、最上のもの（身体）を制し、内に楽しみ、心が統一され、独りで満足している者、その者を人々は比丘と呼ぶ。」

3. Tattha hatthasaṃyatoti hatthakīḷāpanādīnaṃ vā hatthena paresaṃ paharaṇādīnaṃ vā abhāvena hatthasaṃyato.

* tattha = 「そこ（その偈）において」
* hattha-kīḷāpanādīnaṃ = 「手でふざけることなどの」
  * kīḷāpana = 「遊ばせること、ふざけること」
  * ādi = 「～など」
* vā ... vā = 「あるいは～あるいは～」
* hatthena paresaṃ paharaṇādīnaṃ = 「手で他者を打つことなどの」
  * paresaṃ = 「他者たちを」
  * paharaṇa = 「打つこと、殴打」
* abhāvena = 「ないことによって」

→「そこにおいて『hatthasaṃyato（手を制した者）』とは、手でふざけることなど、あるいは手で他者を打つことなどがないことによって、手を制した者である。」

4. Dutiyapadepi eseva nayo.

* dutiya-pade pi = 「第二の句においても」
* esa eva nayo = 「これと同じ方法である」

→「第二の句（pādasaṃyato）においても、これと同じ方法である。」

5. Vācāya pana musāvādādīnaṃ akaraṇato vācāya saṃyato.

* vācāya = 「言葉によって、言葉に関して」
* pana = 「また、しかし」
* musāvādādīnaṃ = 「妄語などの」
  * musāvāda = 「妄語、嘘を言うこと」
* akaraṇato = 「なさないことから」

→「また、言葉によって妄語などをなさないことから、言葉を制した者である。」

6. Saṃyatuttamoti saṃyatattabhāvo, kāyacalanasīsukkhipanabhamukavikārādīnaṃ akārakoti attho.

* saṃyatattabhāvo = 「身体（自体）を制した者」（saṃyata-attabhāva）
  * attabhāva = 「自体、身体」
* kāya-calana-sīsukkhipana-bhamuka-vikārādīnaṃ = 「身体を揺らすこと、頭を振り上げること、眉を動かすことなどの」
  * kāya-calana = 「身体を揺らすこと」
  * sīsa-ukkhipana = 「頭を振り上げること」
  * bhamuka-vikāra = 「眉を動かすこと」
* akārako = 「なさない者」
* ti attho = 「という意味である」

→「『saṃyatuttamo』とは、身体を制した者であり、身体を揺らすこと、頭を振り上げること、眉を動かすことなどをなさない者、という意味である。」

7. Ajjhattaratoti gocarajjhattasaṅkhātāya kammaṭṭhānabhāvanāya rato.

* gocarajjhatta-saṅkhātāya = 「『行境としての内』と呼ばれる」
  * gocara = 「行境、（心の）行き場」
  * saṅkhāta = 「～と呼ばれる」
* kammaṭṭhāna-bhāvanāya = 「業処の修習において」
* rato = 「楽しむ者」

→「『ajjhattarato』とは、『行境としての内』と呼ばれる業処の修習を楽しむ者である。」

8. Samāhitoti suṭṭhu ṭhapito.

* suṭṭhu = 「よく」
* ṭhapito = 「（心が）据えられた者」

→「『samāhito』とは、（心が）よく据えられた者である。」

9. Eko santusitoti ekavihārī hutvā suṭṭhu tusito vipassanācārato paṭṭhāya attano adhigamena tuṭṭhamānaso.

* eka-vihārī hutvā = 「独りで住む者となって」
* suṭṭhu tusito = 「よく満足した者」
* vipassanā-cārato paṭṭhāya = 「観（ヴィパッサナー）の実践から始めて」
  * cāra = 「実践、行い」
  * paṭṭhāya = 「～から始めて、～以来」
* attano adhigamena = 「自らの証得によって」
  * adhigama = 「証得、到達」
* tuṭṭha-mānaso = 「心が満足した者」
  * mānasa = 「心、意」

→「『eko santusito』とは、独りで住む者となってよく満足した者であり、観の実践から始めて自らの証得によって心が満足した者である。」

10. Puthujjanakalyāṇakañhi ādiṃ katvā sabbepi sekhā attano adhigamena santussantīti santusitā, arahā pana ekantasantusitova.

* puthujjana-kalyāṇakaṃ hi ādiṃ katvā = 「実に、善き凡夫を初めとして」
  * puthujjana-kalyāṇaka = 「善き凡夫（善凡夫）」
  * ādiṃ katvā = 「～を初めとして」
* sabbe pi sekhā = 「すべての有学たちも」
  * sekha = 「有学（阿羅漢に至る前の聖者）」
* attano adhigamena santussanti = 「自らの証得によって満足する」
* ti santusitā = 「～から満足した者たちである」
* arahā pana = 「しかし阿羅漢は」
* ekanta-santusito va = 「まさに完全に満足した者である」
  * ekanta = 「完全に、ひとえに」

→「実に、善き凡夫を初めとして、すべての有学たちも自らの証得によって満足するから満足した者たちであるが、阿羅漢はまさに完全に満足した者である。」

11. Taṃ sandhāyetaṃ vuttaṃ.

* taṃ sandhāya = 「その者（阿羅漢）を指して」
  * sandhāya = 「～を指して、～に関して」
* etaṃ vuttaṃ = 「これが説かれた」

→「その者（阿羅漢）を指してこれが説かれたのである。」
