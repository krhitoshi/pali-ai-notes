# 12. Aṅkuravatthu

## 356-359

356.

‘‘Tiṇadosāni khettāni, rāgadosā ayaṃ pajā;

Tasmā hi vītarāgesu, dinnaṃ hoti mahapphalaṃ.

357.

‘‘Tiṇadosāni khettāni, dosadosā ayaṃ pajā;

Tasmā hi vītadosesu, dinnaṃ hoti mahapphalaṃ.

358.

‘‘Tiṇadosāni khettāni, mohadosā ayaṃ pajā;

Tasmā hi vītamohesu, dinnaṃ hoti mahapphalaṃ.

359.

‘‘Tiṇadosāni khettāni, icchādosā ayaṃ pajā;

Tasmā hi vigaticchesu, dinnaṃ hoti mahapphala’’nti.

Tattha tiṇadosānīti sāmākādīni tiṇāni uṭṭhahantāni pubbaṇṇāparaṇṇāni khettāni dūsenti, tena tāni na bahuphalāni honti. Evaṃ sattānampi anto rāgo uppajjanto satte dūseti, tena tesu dinnaṃ mahapphalaṃ na hoti . Khīṇāsavesu dinnaṃ pana mahapphalaṃ hoti. Tena vuttaṃ –

‘‘Tiṇadosāni khettāni, rāgadosā ayaṃ pajā;

Tasmā hi vītarāgesu, dinnaṃ hoti mahapphala’’nti. –

Sesagāthāsupi eseva nayo.

### 対訳

1. 12. Aṅkuravatthu

* aṅkura-vatthu = 「アンクラの話」
  * Aṅkura = 「アンクラ（人名。天界で施与の果報の差を知った天子の物語に登場する）」
  * vatthu = 「話、物語、事例」

→「アンクラの話」

2. 356. ‘‘Tiṇadosāni khettāni, rāgadosā ayaṃ pajā; Tasmā hi vītarāgesu, dinnaṃ hoti mahapphalaṃ.

* tiṇa-dosāni = 「雑草という欠陥をもつ」
  * tiṇa = 「草、雑草」
  * dosa = 「欠陥、汚点」
* khettāni = 「田畑は」
* rāga-dosā = 「貪りという欠陥をもつ」
  * rāga = 「貪り、貪欲」
* ayaṃ pajā = 「この人々は」
  * pajā = 「人々、生類」
* tasmā hi = 「それゆえに」
* vītarāgesu = 「貪りを離れた者たちに」
  * vīta = 「離れた、去った（vi + √i の過去分詞）」
* dinnaṃ = 「施されたものは」（dadāti の過去分詞）
* hoti mahapphalaṃ = 「大きな果報となる」
  * maha(t)-phala = 「大きな果報」

→「田畑は雑草という欠陥をもち、この人々は貪りという欠陥をもつ。それゆえに、貪りを離れた者たちに施されたものは大きな果報となる。」

3. 357. ‘‘Tiṇadosāni khettāni, dosadosā ayaṃ pajā; Tasmā hi vītadosesu, dinnaṃ hoti mahapphalaṃ.

* dosa-dosā = 「怒りという欠陥をもつ」
  * 前の dosa = 「怒り、瞋恚（Skt. dveṣa に相当）」
  * 後の dosa = 「欠陥、汚点（Skt. doṣa に相当）」
* vītadosesu = 「怒りを離れた者たちに」

→「田畑は雑草という欠陥をもち、この人々は怒りという欠陥をもつ。それゆえに、怒りを離れた者たちに施されたものは大きな果報となる。」

4. 358. ‘‘Tiṇadosāni khettāni, mohadosā ayaṃ pajā; Tasmā hi vītamohesu, dinnaṃ hoti mahapphalaṃ.

* moha-dosā = 「迷妄という欠陥をもつ」
  * moha = 「迷妄、愚かさ」
* vītamohesu = 「迷妄を離れた者たちに」

→「田畑は雑草という欠陥をもち、この人々は迷妄という欠陥をもつ。それゆえに、迷妄を離れた者たちに施されたものは大きな果報となる。」

5. 359. ‘‘Tiṇadosāni khettāni, icchādosā ayaṃ pajā; Tasmā hi vigaticchesu, dinnaṃ hoti mahapphala’’nti.

* icchā-dosā = 「欲求という欠陥をもつ」
  * icchā = 「欲求、望み」
* vigaticchesu = 「欲求を離れた者たちに」
  * vigata-icchā = 「欲求が去った」
* ti = 引用の終わりを示す語

→「田畑は雑草という欠陥をもち、この人々は欲求という欠陥をもつ。それゆえに、欲求を離れた者たちに施されたものは大きな果報となる。」

6. Tattha tiṇadosānīti sāmākādīni tiṇāni uṭṭhahantāni pubbaṇṇāparaṇṇāni khettāni dūsenti, tena tāni na bahuphalāni honti.

* tattha = 「そこで（その偈において）」
* tiṇadosānīti = 「『tiṇadosāni』とは」
* sāmākādīni tiṇāni = 「ヒエなどの雑草が」
  * sāmāka = 「ヒエ（穀物に混じって生える草の一種）」
  * ādi = 「〜など」
* uṭṭhahantāni = 「生え出て」（uṭṭhahati の現在分詞・中性複数）
* pubbaṇṇa-aparaṇṇāni khettāni = 「前穀と後穀の田畑を」
  * pubbaṇṇa = 「前穀（米・麦などの穀類）」
  * aparaṇṇa = 「後穀（豆類などの副穀）」
* dūsenti = 「損なう」（dūseti「損なう、汚す」の三人称複数）
* tena = 「それによって」
* tāni na bahuphalāni honti = 「それらは多くの実りをもたらさない」
  * bahu-phala = 「多くの実りのある」

→「そこで『tiṇadosāni（雑草という欠陥をもつ）』とは、ヒエなどの雑草が生え出て、前穀・後穀の田畑を損ない、それによってそれら（の田畑）は多くの実りをもたらさない（という意味である）。」

7. Evaṃ sattānampi anto rāgo uppajjanto satte dūseti, tena tesu dinnaṃ mahapphalaṃ na hoti.

* evaṃ = 「同様に」
* sattānam pi anto = 「衆生たちの内にも」
  * satta = 「衆生、有情」
  * anto = 「内に、内部で」
* rāgo uppajjanto = 「貪りが生じて」
  * uppajjanto = 「生じつつある」（uppajjati の現在分詞）
* satte dūseti = 「衆生たちを損なう」
* tena = 「それによって」
* tesu dinnaṃ = 「彼らに施されたものは」
* mahapphalaṃ na hoti = 「大きな果報とならない」

→「同様に、衆生たちの内にも貪りが生じて衆生たちを損ない、それによって彼らに施されたものは大きな果報とならない。」

8. Khīṇāsavesu dinnaṃ pana mahapphalaṃ hoti.

* khīṇāsavesu = 「漏尽者たちに」
  * khīṇa-āsava = 「漏（煩悩）の尽きた者、すなわち阿羅漢」
* dinnaṃ pana = 「しかし施されたものは」
* mahapphalaṃ hoti = 「大きな果報となる」

→「しかし、漏尽者たちに施されたものは大きな果報となる。」

9. Tena vuttaṃ –

* tena = 「それゆえに」
* vuttaṃ = 「説かれた」（vadati の過去分詞）

→「それゆえに（次のように）説かれた。」

11. Sesagāthāsupi eseva nayo.

* sesa-gāthāsu pi = 「残りの偈においても」
  * sesa = 「残りの」
  * gāthā = 「偈」
* esa eva nayo = 「まさにこれと同じ方法である」
  * naya = 「方法、理解の仕方」

→「残りの偈においても、これと同じ方法である。」
