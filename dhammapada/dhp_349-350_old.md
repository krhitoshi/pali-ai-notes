
# 7. Cūḷadhanuggahapaṇḍitavatthu

## 349

349.

‘‘Vitakkamathitassa jantuno,

Tibbarāgassa subhānupassino;

Bhiyyo taṇhā pavaḍḍhati,

Esa kho daḷhaṃ karoti bandhanaṃ.

### 対訳

1. 7. Cūḷadhanuggahapaṇḍitavatthu

* cūḷa-dhanuggaha-paṇḍita-vatthu = 「小弓術師賢者の話」

  * cūḷa = 「小さい」

  * dhanuggaha = 「弓術師、射手」（dhanu「弓」+ gaha「取る者」）

  * paṇḍita = 「賢者」

  * vatthu = 「話、物語、事例」

→「小弓術師賢者の話」

2. 349. ‘‘Vitakkamathitassa jantuno, Tibbarāgassa subhānupassino;

* vitakka-mathitassa = 「思考にかき乱された（者の）」

  * vitakka = 「思考、尋」

  * mathita = 「かき乱された、揺さぶられた（√math「かき混ぜる」の過去分詞）」

* jantuno = 「人にとって（jantu「人、生けるもの」の属格）」

* tibba-rāgassa = 「激しい貪りをもつ（者の）」

  * tibba = 「鋭い、激しい」

  * rāga = 「貪り、貪欲」

* subhānupassino = 「浄らかなもの（美しいもの）を随観する（者の）」

  * subha = 「浄らかなもの、美しいもの」

  * anupassin = 「随観する者、繰り返し観る者」

→「思考にかき乱され、激しい貪りをもち、浄らかなものと随観する人にとって」

3. Bhiyyo taṇhā pavaḍḍhati, Esa kho daḷhaṃ karoti bandhanaṃ.

* bhiyyo = 「ますます、さらに」

* taṇhā = 「渇愛」

* pavaḍḍhati = 「増大する」

* esa kho = 「まさにこの者は」

* daḷhaṃ karoti = 「堅固にする」

  * daḷha = 「堅固な、強固な」

* bandhanaṃ = 「束縛を」

→「渇愛はますます増大する。まさにこの者は束縛を堅固にする。」

## 350

350.

‘‘Vitakkūpasame ca yo rato,

Asubhaṃ bhāvayate sadā sato;

Esa kho byanti kāhiti,

Esa checchati mārabandhana’’nti.

Tattha vitakkamathitassāti kāmavitakkādīhi vitakkehi nimmathitassa. Tibbarāgassāti bahalarāgassa. Subhānupassinoti iṭṭhārammaṇe subhanimittagāhādivasena vissaṭṭhamānasatāya subhanti anupassantassa. Taṇhāti evarūpassa jhānādīsu ekampi na vaḍḍhati, atha kho chadvārikā taṇhāyeva bhiyyo vaḍḍhati. Esa khoti eso puggalo taṇhābandhanaṃ daḷhaṃ suthiraṃ karoti. Vitakkūpasameti micchāvitakkādīnaṃ vūpasamasaṅkhāte dasasu asubhesu paṭhamajjhāne. Sadā satoti yo ettha abhirato hutvā niccaṃ upaṭṭhitasatitāya sato taṃ asubhajhānaṃ bhāveti. Byanti kāhitīti esa bhikkhu tīsu bhavesu uppajjanakaṃ taṇhaṃ vigatantaṃ karissati. Mārabandhananti eso tebhūmakavaṭṭasaṅkhātaṃ mārabandhanampi chindissatīti attho.

### 対訳

1. 350.

→「350.(偈番号)」

2. ‘‘Vitakkūpasame ca yo rato, Asubhaṃ bhāvayate sadā sato; Esa kho byanti kāhiti, Esa checchati mārabandhana’’nti.

* vitakkūpasame = 「尋の静まりにおいて」(vitakka-upasama の処格)

  * vitakka = 「尋、思考」

  * upasama = 「静まり、寂止」

* ca = 「そして」

* yo rato = 「喜ぶ者は」

  * rata = 「喜んだ、楽しんだ(ramati の過去分詞)」

* asubhaṃ bhāvayate = 「不浄を修習する」

  * asubha = 「不浄(不浄観の対象)」

  * bhāvayate = 「修習する(bhāveti の中動態)」

* sadā sato = 「常に念をもって」

  * sadā = 「常に」

  * sata = 「念ある(sarati の過去分詞)」

* esa kho = 「その者こそ」

* byanti kāhiti = 「終わらせるだろう」

  * byanti = 「終滅、除去(vi + anta)」

  * kāhiti = 「なすだろう(karoti の未来形)」

* esa checchati = 「その者は断ち切るだろう」

  * checchati = 「断ち切るだろう(chindati の未来形)」

* mārabandhanaṃ = 「魔の束縛を」

  * māra = 「魔、悪魔」

  * bandhana = 「束縛」

→「尋の静まりを喜び、常に念をもって不浄を修習する者、その者こそ(渇愛を)終わらせるだろう。その者は魔の束縛を断ち切るだろう。」

3. Tattha vitakkamathitassāti kāmavitakkādīhi vitakkehi nimmathitassa.

* tattha = 「そこ(その偈)において」

* vitakkamathitassā ti = 「『vitakkamathitassa(尋にかき乱された者の)』とは」

* kāmavitakkādīhi vitakkehi = 「欲の尋などの尋によって」

  * kāma-vitakka = 「欲の尋、欲についての思考」

  * ādi = 「～など」

* nimmathitassa = 「かき乱された者の(という意味である)」

  * nimmathita = 「かき乱された、攪拌された(nimmatheti の過去分詞)」

→「そこにおいて『vitakkamathitassa』とは、欲の尋などの尋によってかき乱された者の(という意味である)。」

4. Tibbarāgassāti bahalarāgassa.

* tibbarāgassā ti = 「『tibbarāgassa(激しい貪りの者の)』とは」

  * tibba = 「激しい、鋭い」

  * rāga = 「貪り」

* bahalarāgassa = 「濃厚な貪りの者の(という意味である)」

  * bahala = 「濃厚な、厚い」

→「『tibbarāgassa』とは、濃厚な貪りの者の(という意味である)。」

5. Subhānupassinoti iṭṭhārammaṇe subhanimittagāhādivasena vissaṭṭhamānasatāya subhanti anupassantassa.

* subhānupassino ti = 「『subhānupassino(浄と随観する者の)』とは」

  * subha = 「浄、美しいもの」

  * anupassin = 「随観する者」

* iṭṭhārammaṇe = 「好ましい所縁において」

  * iṭṭha = 「好ましい、望ましい」

  * ārammaṇa = 「所縁、対象」

* subhanimittagāhādivasena = 「浄相の把握などによって」

  * subha-nimitta = 「浄相、美しいという相」

  * gāha = 「把握、執着」

* vissaṭṭhamānasatāya = 「心が放たれている(放縦になっている)ことによって」

  * vissaṭṭha = 「放たれた、放縦な」

  * mānasa = 「心」

* subhan ti anupassantassa = 「『浄である』と随観する者の(という意味である)」

→「『subhānupassino』とは、好ましい所縁において浄相の把握などによって心が放縦になっていることにより、『浄である』と随観する者の(という意味である)。」

6. Taṇhāti evarūpassa jhānādīsu ekampi na vaḍḍhati, atha kho chadvārikā taṇhāyeva bhiyyo vaḍḍhati.

* taṇhā ti = 「『taṇhā(渇愛)』とは」

* evarūpassa = 「このような者には」

* jhānādīsu ekam pi = 「禅などのうち一つも」

* na vaḍḍhati = 「増大しない」

* atha kho = 「むしろ、それどころか」

* chadvārikā taṇhā yeva = 「六門の渇愛だけが」

  * cha-dvārika = 「六門(眼・耳・鼻・舌・身・意の六門)に関わる」

* bhiyyo vaḍḍhati = 「ますます増大する」

→「『taṇhā』とは、このような者には禅などのうち一つも増大せず、むしろ六門の渇愛だけがますます増大する(という意味である)。」

7. Esa khoti eso puggalo taṇhābandhanaṃ daḷhaṃ suthiraṃ karoti.

* esa kho ti = 「『esa kho(その者こそ)』とは」

* eso puggalo = 「この人は」

* taṇhābandhanaṃ = 「渇愛の束縛を」

* daḷhaṃ suthiraṃ karoti = 「堅固に、とても堅くする(という意味である)」

  * daḷha = 「堅固な」

  * suthira = 「とても堅い(su + thira)」

→「『esa kho』とは、この人は渇愛の束縛を堅固に、とても堅くする(という意味である)。」

8. Vitakkūpasameti micchāvitakkādīnaṃ vūpasamasaṅkhāte dasasu asubhesu paṭhamajjhāne.

* vitakkūpasame ti = 「『vitakkūpasame(尋の静まりにおいて)』とは」

* micchāvitakkādīnaṃ = 「邪な尋などの」

  * micchā-vitakka = 「邪な尋、誤った思考」

* vūpasamasaṅkhāte = 「静まりと呼ばれる」

  * vūpasama = 「静まり、寂止」

  * saṅkhāta = 「～と呼ばれる」

* dasasu asubhesu = 「十不浄における」

  * dasa asubhā = 「十不浄(死体の十種の観察対象)」

* paṭhamajjhāne = 「初禅において(という意味である)」

→「『vitakkūpasame』とは、邪な尋などの静まりと呼ばれる、十不浄における初禅において(という意味である)。」

9. Sadā satoti yo ettha abhirato hutvā niccaṃ upaṭṭhitasatitāya sato taṃ asubhajhānaṃ bhāveti.

* sadā sato ti = 「『sadā sato(常に念をもって)』とは」

* yo ettha abhirato hutvā = 「ここ(初禅)において大いに喜ぶ者となって」

  * abhirata = 「大いに喜んだ」

* niccaṃ upaṭṭhitasatitāya sato = 「常に念が現前していることによって念ある者となり」

  * upaṭṭhita-sati = 「現前した念」

* taṃ asubhajhānaṃ bhāveti = 「その不浄の禅を修習する(という意味である)」

→「『sadā sato』とは、ここにおいて大いに喜ぶ者となり、常に念が現前していることによって念ある者となって、その不浄の禅を修習する(という意味である)。」

10. Byanti kāhitīti esa bhikkhu tīsu bhavesu uppajjanakaṃ taṇhaṃ vigatantaṃ karissati.

* byanti kāhitī ti = 「『byanti kāhiti(終わらせるだろう)』とは」

* esa bhikkhu = 「この比丘は」

* tīsu bhavesu = 「三有(欲有・色有・無色有)において」

* uppajjanakaṃ taṇhaṃ = 「生じる渇愛を」

  * uppajjanaka = 「生じるもの」

* vigatantaṃ karissati = 「終わりの去ったもの(消滅したもの)にするだろう(という意味である)」

  * vigata = 「去った、離れた」

  * anta = 「終わり」

→「『byanti kāhiti』とは、この比丘は三有において生じる渇愛を消滅したものにするだろう(という意味である)。」

11. Mārabandhananti eso tebhūmakavaṭṭasaṅkhātaṃ mārabandhanampi chindissatīti attho.

* mārabandhanan ti = 「『mārabandhanaṃ(魔の束縛を)』とは」

* eso = 「この者は」

* tebhūmakavaṭṭasaṅkhātaṃ = 「三地の輪転と呼ばれる」

  * tebhūmaka = 「三地の(欲界・色界・無色界の)」

  * vaṭṭa = 「輪転、輪廻」

  * saṅkhāta = 「～と呼ばれる」

* mārabandhanam pi = 「魔の束縛をも」

* chindissatī ti attho = 「断ち切るだろう、という意味である」

→「『mārabandhanaṃ』とは、この者は三地の輪転と呼ばれる魔の束縛をも断ち切るだろう、という意味である。」
