# [20] 10. Naḷapānajātakavaṇṇanā

## 20 (1)

Disvāpadamanuttiṇṇanti idaṃ satthā kosalesu cārikaṃ caramāno naḷakapānagāmaṃ patvā naḷakapānapokkharaṇiyaṃ ketakavane viharanto naḷadaṇḍake ārabbha kathesi. Tadā kira bhikkhū naḷakapānapokkharaṇiyaṃ nhatvā sūcigharatthāya sāmaṇerehi naḷadaṇḍake gāhāpetvā te sabbatthakameva chidde disvā satthāraṃ upasaṅkamitvā ‘‘bhante, mayaṃ sūcigharatthāya naḷadaṇḍake gaṇhāpema, te mūlato yāva aggā sabbatthakameva chiddā, kiṃ nu kho eta’’nti pucchiṃsu. Satthā ‘‘idaṃ, bhikkhave, mayhaṃ porāṇakaadhiṭṭhāna’’nti vatvā atītaṃ āhari.

## 20 (2)

Pubbe kira so vanasaṇḍo arañño ahosi. Tassāpi pokkharaṇiyā eko dakarakkhaso otiṇṇotiṇṇe khādati. Tadā bodhisatto rohitamigapotakappamāṇo kapirājā hutvā asītisahassamattavānaraparivuto yūthaṃ pariharanto tasmiṃ araññe vasati. So vānaragaṇassa ovādaṃ adāsi ‘‘tātā, imasmiṃ araññe visarukkhāpi amanussapariggahitapokkharaṇiyopi honti, tumhe akhāditapubbaṃ phalāphalaṃ khādantā vā apītapubbaṃ pānīyaṃ pivantā vā maṃ paṭipuccheyyāthā’’ti. Te ‘‘sādhū’’ti paṭissuṇitvā ekadivasaṃ agatapubbaṭṭhānaṃ gatā tattha bahudeva divasaṃ caritvā pānīyaṃ gavesamānā ekaṃ pokkharaṇiṃ disvā pānīyaṃ apivitvāva bodhisattassāgamanaṃ olokayamānā nisīdiṃsu. Bodhisatto āgantvā ‘‘kiṃ tātā, pānīyaṃ na pivathā’’ti āha. ‘‘Tumhākaṃ āgamanaṃ olokemā’’ti. ‘‘Suṭṭhu, tātā’’ti bodhisatto pokkharaṇiṃ āvijjhitvā padaṃ paricchindanto otiṇṇameva passi, na uttiṇṇaṃ. So ‘‘nissaṃsayaṃ esā amanussapariggahitā’’ti ñatvā ‘‘suṭṭhu vo kataṃ, tātā, pānīyaṃ apivantehi, amanussapariggahitā aya’’nti āha.

Dakarakkhasopi tesaṃ anotaraṇabhāvaṃ ñatvā nīlodaro paṇḍaramukho surattahatthapādo bībhacchadassano hutvā udakaṃ dvidhā katvā nikkhamitvā ‘‘kasmā nisinnāttha, otaritvā pānīyaṃ pivathā’’ti āha. Atha naṃ bodhisatto pucchi ‘‘tvaṃ idha nibbattadakarakkhasosī’’ti? ‘‘Āma, aha’’nti. ‘‘Tvaṃ pokkharaṇiṃ otiṇṇake labhasī’’ti? ‘‘Āma, labhāmi, ahaṃ idhotiṇṇaṃ antamaso sakuṇikaṃ upādāya na kiñci muñcāmi, tumhepi sabbe khādissāmī’’ti. ‘‘Na mayaṃ attānaṃ tuyhaṃ khādituṃ dassāmā’’ti. ‘‘Pānīyaṃ pana pivissathā’’ti. ‘‘Āma, pānīyaṃ pivissāma, na ca te vasaṃ gamissāmā’’ti. ‘‘Atha kathaṃ pānīyaṃ pivissathā’’ti? Kiṃ pana tvaṃ maññasi ‘‘otaritvā pivissantī’’ti. ‘‘Mayañhi anotaritvā asītisahassānipi ekamekaṃ naḷadaṇḍakaṃ gahetvā uppalanāḷena udakaṃ pivantā viya tava pokkharaṇiyā pānīyaṃ pivissāma, evaṃ no tvaṃ khādituṃ na sakkhissasī’’ti. Etamatthaṃ viditvā satthā abhisambuddho hutvā imissā gāthāya purimapadadvayaṃ abhāsi –

1. Pubbe kira so vanasaṇḍo arañño ahosi.

→「昔、その密林は（人里離れた）林野であったということである。」

* cattāri = 「四つ（とは）」

→「四つとは何か。」

9. Cande sasalakkhaṇaṃ sakalampi imaṃ kappaṃ ṭhassati, vaṭṭakajātake aggino nibbutaṭṭhānaṃ sakalampi imaṃ kappaṃ aggi na jhāyissati, ghaṭīkāranivesanaṭṭhānaṃ sakalampi imaṃ kappaṃ anovassakaṃ ṭhassati, imaṃ pokkharaṇiṃ parivāretvā uṭṭhitanaḷā sakalampi imaṃ kappaṃ ekacchiddā bhavissantīti imāni cattāri kappaṭṭhiyapāṭihāriyāni nāma.

* cande sasalakkhaṇaṃ = 「月にある兎の相は」
  * sasa-lakkhaṇa = 「兎の相、月面の兎の模様」
* sakalampi imaṃ kappaṃ ṭhassati = 「この劫の全期間にわたって存続するだろう」
  * ṭhassati = 「存続するだろう（tiṭṭhati の未来形）」
* vaṭṭakajātake aggino nibbutaṭṭhānaṃ = 「ウズラ本生（Vaṭṭakajātaka）において火が消えた場所は」
  * vaṭṭaka = 「ウズラ」
  * nibbuta-ṭṭhāna = 「消えた場所」
* sakalampi imaṃ kappaṃ aggi na jhāyissati = 「この劫の全期間、火が燃えないだろう」
  * jhāyissati = 「燃えるだろう（jhāyati の未来形）」
* ghaṭīkāranivesanaṭṭhānaṃ = 「（陶工）ガティーカーラの住居の場所は」
  * nivesana-ṭṭhāna = 「住居の場所」
* sakalampi imaṃ kappaṃ anovassakaṃ ṭhassati = 「この劫の全期間、雨に濡れないままであり続けるだろう」
  * anovassaka = 「雨のかからない（an + ovassaka）」
* imaṃ pokkharaṇiṃ parivāretvā uṭṭhitanaḷā = 「この蓮池を取り囲んで生え出た葦は」
* sakalampi imaṃ kappaṃ ekacchiddā bhavissantī ti = 「この劫の全期間、一本の空洞を持つものであるだろう、と」
* imāni cattāri kappaṭṭhiyapāṭihāriyāni nāma = 「これらが四つの、劫の間存続する奇跡と呼ばれるものである」

→「月にある兎の相はこの劫の全期間にわたって存続するだろう。ウズラ本生において火が消えた場所では、この劫の全期間、火が燃えないだろう。ガティーカーラの住居の場所は、この劫の全期間、雨に濡れないままであり続けるだろう。この蓮池を取り囲んで生え出た葦は、この劫の全期間、一本の空洞を持つものであるだろう。これらが、四つの、劫の間存続する奇跡と呼ばれるものである。」

10. Bodhisatto evaṃ adhiṭṭhahitvā ekaṃ naḷaṃ ādāya nisīdi.

* bodhisatto = 「菩薩は」
* evaṃ adhiṭṭhahitvā = 「このように決意して」
  * adhiṭṭhahitvā = 「決意して（adhiṭṭhāti の連続体）」
* ekaṃ naḷaṃ ādāya = 「一本の葦を取って」
  * ādāya = 「取って（ādāti の連続体）」
* nisīdi = 「坐った（nisīdati のアオリスト）」

→「菩薩はこのように決意し、一本の葦を取って坐った。」

11. Tepi asītisahassavānarā ekekaṃ ādāya pokkharaṇiṃ parivāretvā nisīdiṃsu.

* tepi = 「彼らも」
* asīti-sahassa-vānarā = 「八万の猿たちは」
* ekekaṃ ādāya = 「一本ずつ取って」
* pokkharaṇiṃ parivāretvā = 「蓮池を取り囲んで」
* nisīdiṃsu = 「坐った（複数アオリスト）」

→「その八万の猿たちも、一本ずつ（葦を）取り、蓮池を取り囲んで坐った。」

12. Tepi bodhisattassa naḷena ākaḍḍhitvā pānīyaṃ pivanakāle sabbe tīre nisinnāva piviṃsu.

* tepi = 「彼らも」
* bodhisattassa ... pivanakāle = 「菩薩が～飲む時に（属格絶対句的用法）」
  * pivana-kāla = 「飲む時」
* naḷena ākaḍḍhitvā = 「葦で吸い上げて」
  * ākaḍḍhitvā = 「引き寄せて、吸い上げて（ākaḍḍhati の連続体）」
* pānīyaṃ = 「飲み水を」
* sabbe = 「すべての者が」
* tīre nisinnā va = 「岸に坐ったままで」
  * nisinna = 「坐った（nisīdati の過去分詞）」
* piviṃsu = 「飲んだ（pivati の複数アオリスト）」

→「菩薩が葦で水を吸い上げて飲む時、彼らもみな岸に坐ったままで飲んだ。」

13. Evaṃ tehi pānīye pivite dakarakkhaso kiñci alabhitvā anattamano sakanivesanameva gato.

* evaṃ tehi pānīye pivite = 「このように彼らによって水が飲まれた時（処格絶対句）」
* dakarakkhaso = 「水の羅刹は」
  * daka-rakkhasa = 「水に住む羅刹、水魔」
* kiñci alabhitvā = 「何も得られず」
  * alabhitvā = 「得ないで（a + labhati の連続体）」
* anattamano = 「不機嫌になって」
  * an-attamana = 「心楽しまない、不満な」
* sakanivesanam eva gato = 「自分の住処へと去って行った」
  * saka-nivesana = 「自分の住居」

→「このように彼らが水を飲んだので、水の羅刹は何も得られず、不機嫌になって自分の住処へと去って行った。」

14. Bodhisattopi saparivāro araññameva pāvisi.

* bodhisatto pi = 「菩薩も」
* saparivāro = 「従者たちとともに」
  * sa-parivāra = 「取り巻きを伴った」
* araññam eva = 「森へと」
* pāvisi = 「入った（pavisati のアオリスト）」

→「菩薩も従者たちとともに森へと入って行った。」

15. Satthā pana ‘‘imesaṃ, bhikkhave, naḷānaṃ ekacchiddabhāvo nāma mayhamevetaṃ porāṇakaadhiṭṭhāna’’nti imaṃ dhammadesanaṃ āharitvā anusandhiṃ ghaṭetvā jātakaṃ samodhānesi –

* satthā pana = 「さて、師（ブッダ）は」
* imesaṃ, bhikkhave, naḷānaṃ ekacchiddabhāvo nāma = 「『比丘たちよ、これらの葦が一本の空洞を持つことは』」
  * ekacchidda-bhāva = 「一つの穴のある状態」
* mayham eva etaṃ porāṇaka-adhiṭṭhānaṃ ti = 「『それはほかならぬ私の昔の決意によるものである』と」
  * porāṇaka = 「昔の、古い」
* imaṃ dhammadesanaṃ āharitvā = 「この法話を説いて」
  * dhamma-desanā = 「法話、教えの説示」
* anusandhiṃ ghaṭetvā = 「（過去と現在の話の）つながりを結んで」
  * anusandhi = 「連結、話のつながり」
  * ghaṭetvā = 「結び合わせて（ghaṭeti の連続体）」
* jātakaṃ samodhānesi = 「本生（の登場人物）を結び合わせた」
  * samodhānesi = 「結合した、同定した（samodhāneti のアオリスト）」

→「さて、師は『比丘たちよ、これらの葦が一本の空洞を持つのは、ほかならぬ私の昔の決意によるものである』と、この法話を説き、（過去と現在の話の）つながりを結んで、本生（の登場人物）を次のように結び合わせた。」

16. ‘‘tadā dakarakkhaso devadatto ahosi, asītisahassavānarā buddhaparisā, upāyakusalo pana kapirājā ahameva ahosi’’nti.

* tadā = 「その時」
* dakarakkhaso devadatto ahosi = 「水の羅刹はデーヴァダッタであった」
* asītisahassavānarā buddhaparisā = 「八万の猿たちは仏の会衆であった」
  * buddha-parisā = 「仏の会衆、仏の弟子たち」
* upāyakusalo pana kapirājā = 「そして、方便に巧みな猿の王は」
  * upāya-kusala = 「方便に巧みな、手立てに熟練した」
  * kapi-rājā = 「猿の王」
* aham eva ahosin ti = 「ほかならぬ私であった、と」

→「『その時の水の羅刹はデーヴァダッタであり、八万の猿たちは仏の会衆であり、そして方便に巧みな猿の王はほかならぬ私であった』と。」

17. Naḷapānajātakavaṇṇanā dasamā.

* naḷapāna-jātaka-vaṇṇanā = 「葦飲本生の解説」
  * naḷa-pāna = 「葦で飲むこと」
  * vaṇṇanā = 「解説、註釈」
* dasamā = 「第十の」

→「葦飲本生の解説、第十が（終わった）。」
