# [316] 6. Sasapaṇḍitajātakavaṇṇanā

## 61-64 (1)

Sattame rohitā macchāti idaṃ satthā jetavane viharanto sabbaparikkhāradānaṃ ārabbha kathesi. Sāvatthiyaṃ kira eko kuṭumbiko buddhappamukhassa bhikkhusaṅghassa sabbaparikkhāradānaṃ sajjetvā gharadvāre maṇḍapaṃ kāretvā buddhappamukhaṃ bhikkhusaṅghaṃ nimantetvā susajjitamaṇḍape paññattavarāsane nisīdāpetvā nānaggarasaṃ paṇītadānaṃ datvā puna svātanāyāti sattāhaṃ nimantetvā sattame divase buddhappamukhānaṃ pañcannaṃ bhikkhusatānaṃ sabbaparikkhāre adāsi. Satthā bhattakiccāvasāne anumodanaṃ karonto ‘‘upāsaka, tayā pītisomanassaṃ kātuṃ vaṭṭati, idañhi dānaṃ nāma porāṇakapaṇḍitānaṃ vaṃso, porāṇakapaṇḍitā hi sampattayācakānaṃ jīvitaṃ pariccajitvā attano maṃsampi adaṃsū’’ti vatvā tena yācito atītaṃ āhari.

## 61-64 (3)

Punadivase tesu uddo pātova ‘‘gocaraṃ pariyesissāmī’’ti nikkhamitvā gaṅgātīraṃ gato. Atheko bālisiko satta rohitamacche uddharitvā valliyā āvuṇitvā netvā gaṅgātīre vālukaṃ viyūhitvā vālikāya paṭicchādetvā puna macche gaṇhanto adhogaṅgaṃ gacchi. Uddo macchagandhaṃ ghāyitvā vālukaṃ viyūhitvā macche disvā nīharitvā ‘‘atthi nu kho etesaṃ sāmiko’’ti tikkhattuṃ ghosetvā sāmikaṃ apassanto vallikoṭiṃ ḍaṃsitvā netvā attano vasanagumbe ṭhapetvā ‘‘velāyameva khādissāmī’’ti attano sīlaṃ āvajjento nipajji. Siṅgālopi vasanaṭṭhānato nikkhamitvā gocaraṃ pariyesanto ekassa khettagopakassa kuṭiyaṃ dve maṃsasūlāni ekaṃ godhaṃ ekañca dadhivārakaṃ disvā ‘‘atthi nu kho etesaṃ sāmiko’’ti tikkhattuṃ ghosetvā sāmikaṃ adisvā dadhivārakassa uggahaṇarajjukaṃ gīvāya pavesetvā dve maṃsasūle ca godhañca mukhena ḍaṃsitvā netvā attano vasanagumbe ṭhapetvā ‘‘velāyameva khādissāmī’’ti attano sīlaṃ āvajjento nipajji. Makkaṭopi vasanaṭṭhānato nikkhamitvā vanasaṇḍaṃ pavisitvā ambapiṇḍaṃ āharitvā attano vasanagumbe ṭhapetvā ‘‘velāyameva khādissāmī’’ti attano sīlaṃ āvajjento nipajji.

Bodhisatto pana ‘‘velāyameva vasanaṭṭhānato nikkhamitvā dabbatiṇāni khādissāmī’’ti attano vasanagumbeyeva nipanno cintesi ‘‘mama santikaṃ āgatānaṃ yācakānaṃ tiṇāni dātuṃ na sakkā, tilataṇḍulādayopi mayhaṃ natthi, sace me santikaṃ yācako āgacchissati, attano sarīramaṃsaṃ dassāmī’’ti. * attano ānubhāvena = 「自らの威力によって」
* ekaṃ aṅgārarāsiṃ = 「一つの炭火の山を」
  * aṅgāra-rāsi = 「炭火の集積、燃える炭の山」
* māpetvā = 「作り出して(māpeti の連続体)」
* bodhisattassa ārocesi = 「菩薩に告げた」

→「帝釈天は彼の言葉を聞いて、自らの威力によって一つの炭火の山を作り出し、菩薩に告げた。」

5. So dabbatiṇasayanato uṭṭhāya tattha gantvā ‘‘sace me lomantaresu pāṇakā atthi, te mā mariṃsū’’ti tikkhattuṃ sarīraṃ vidhunitvā sakalasarīraṃ dānamukhe ṭhapetvā laṅghitvā padumasare rājahaṃso viya pamuditacitto aṅgārarāsimhi pati.

* so = 「彼(菩薩である兎)は」
* dabbatiṇasayanato uṭṭhāya = 「ダッバ草の寝床から起き上がって」
  * dabba-tiṇa = 「ダッバ草(クシャ草の一種)」
* tattha gantvā = 「そこへ行って」
* sace me lomantaresu pāṇakā atthi = 「もし私の毛の間に小さな虫がいるなら」
  * loma-antara = 「毛の間」
  * pāṇaka = 「小さな生き物、虫」
* te mā mariṃsū ti = 「それらが死なないように、と」
  * mā mariṃsu = 「死んではならない」(mā + アオリスト、禁止)
* tikkhattuṃ = 「三度」
* sarīraṃ vidhunitvā = 「身体を振るって」
* sakalasarīraṃ dānamukhe ṭhapetvā = 「全身を布施のために捧げて」
  * dāna-mukha = 「布施という入り口、布施の用途」
* laṅghitvā = 「跳び上がって」
* padumasare rājahaṃso viya = 「蓮池に(舞い降りる)王鵞鳥のように」

* aṅgārarāsimhi pati = 「炭火の山に落ちた」

→「彼はダッバ草の寝床から起き上がってそこへ行き、『もし私の毛の間に小さな虫がいるなら、それらが死なないように』と三度身体を振るい、全身を布施のために捧げ、跳び上がって、蓮池に舞い降りる王鵞鳥のように喜びに満ちた心で炭火の山に落ちた。」

6. So pana aggi bodhisattassa sarīre lomakūpamattampi uṇhaṃ kātuṃ nāsakkhi, himagabbhaṃ paviṭṭho viya ahosi.

* so pana aggi = 「しかしその火は」
* bodhisattassa sarīre = 「菩薩の身体において」
* lomakūpamattampi = 「毛穴一つほども」
  * loma-kūpa = 「毛穴」
* uṇhaṃ kātuṃ nāsakkhi = 「熱くすることができなかった」
* himagabbhaṃ paviṭṭho viya ahosi = 「雪の中に入ったかのようであった」
  * hima-gabbha = 「雪の内部」

→「しかしその火は菩薩の身体を毛穴一つほども熱くすることができず、(菩薩は)雪の中に入ったかのようであった。」

7. Atha sakkaṃ āmantetvā ‘‘brāhmaṇa, tayā kato aggi atisītalo, mama sarīre lomakūpamattampi uṇhaṃ kātuṃ na sakkoti, kiṃ nāmeta’’nti āha.

* atha = 「そこで」
* sakkaṃ āmantetvā = 「帝釈天に呼びかけて」
* brāhmaṇa = 「バラモンよ」
* tayā kato aggi = 「あなたが起こした火は」
* atisītalo = 「とても冷たい」
* mama sarīre lomakūpamattampi uṇhaṃ kātuṃ na sakkoti = 「私の身体を毛穴一つほども熱くすることができない」
* kiṃ nāmetaṃ ti āha = 「これはいったいどうしたことか、と言った」
  * kiṃ nāma etaṃ = 「これはいったい何か」

→「そこで帝釈天に呼びかけて、『バラモンよ、あなたが起こした火はとても冷たく、私の身体を毛穴一つほども熱くすることができない。これはいったいどうしたことか』と言った。」

8. ‘‘Sasapaṇḍita, nāhaṃ brāhmaṇo, sakkohamasmi, tava vīmaṃsanatthāya āgatomhī’’ti.

* sasapaṇḍita = 「賢者の兎よ」
* nāhaṃ brāhmaṇo = 「私はバラモンではない」
* sakko aham asmi = 「私は帝釈天である」
* tava vīmaṃsanatthāya = 「あなたを試すために」
  * vīmaṃsana = 「試すこと、吟味」
* āgato amhi ti = 「私は来たのだ、と」

→「『賢者の兎よ、私はバラモンではない。私は帝釈天であり、あなたを試すために来たのだ』と。」

9. ‘‘Sakka, tvaṃ tāva tiṭṭha, sakalopi ce lokasannivāso maṃ dānena vīmaṃseyya, neva me adātukāmataṃ passeyyā’’ti bodhisatto sīhanādaṃ nadi.

* sakka = 「帝釈よ」
* tvaṃ tāva tiṭṭha = 「あなたはさておき」
  * tāva tiṭṭha = 直訳「まずは(そのままで)立っていなさい」→「あなただけでなく」の意
* sakalopi ce lokasannivāso = 「たとえ全世界の住人が」
  * loka-sannivāsa = 「世間に共住する者たち、世界の住人」
* maṃ dānena vīmaṃseyya = 「私を布施によって試みても」
* neva me adātukāmataṃ passeyya = 「私に与えたくない気持ちを決して見出さないだろう」
  * adātukāmatā = 「与えたくないこと」(a-dātu-kāmatā)
* ti bodhisatto sīhanādaṃ nadi = 「と菩薩は獅子吼した」

→「『帝釈よ、あなたはさておき、たとえ全世界の住人が私を布施によって試みても、私に与えたくない気持ちを決して見出さないだろう』と菩薩は獅子吼した。」

10. Atha naṃ sakko ‘‘sasapaṇḍita, tava guṇo sakalakappaṃ pākaṭo hotū’’ti pabbataṃ pīḷetvā pabbatarasaṃ ādāya candamaṇḍale sasalakkhaṇaṃ likhitvā bodhisattaṃ ānetvā tasmiṃ vanasaṇḍe tasmiṃyeva vanagumbe taruṇadabbatiṇapiṭṭhe nipajjāpetvā attano vasanaṭṭhānameva gato.

* atha naṃ sakko = 「そこで帝釈天は彼に(対して)」
* tava guṇo = 「あなたの徳が」
* sakalakappaṃ pākaṭo hotū ti = 「劫の全体にわたって知られるように、と」
  * pākaṭa = 「明らかな、よく知られた」
* pabbataṃ pīḷetvā = 「山を圧搾して」
* pabbatarasaṃ ādāya = 「山の液を取って」
  * pabbata-rasa = 「山のエキス、山を搾った液」
* candamaṇḍale sasalakkhaṇaṃ likhitvā = 「月輪に兎の相を描いて」
  * sasa-lakkhaṇa = 「兎の印、兎のしるし」
* bodhisattaṃ ānetvā = 「菩薩を連れて来て」
* tasmiṃ vanasaṇḍe = 「その森の茂みの」
* tasmiṃyeva vanagumbe = 「まさにその森の藪の」
* taruṇadabbatiṇapiṭṭhe = 「柔らかいダッバ草の上に」
  * taruṇa = 「若い、柔らかい」
  * piṭṭha = 「表面、上」
* nipajjāpetvā = 「横たわらせて(nipajjāpeti の連続体、使役)」
* attano vasanaṭṭhānameva gato = 「自らの住処へと帰って行った」

→「そこで帝釈天は、『賢者の兎よ、あなたの徳が劫の全体にわたって知られるように』と、山を圧搾して山の液を取り、月輪に兎の相を描き、菩薩を連れて来てその森の茂みの、まさにその森の藪の柔らかいダッバ草の上に横たわらせ、自らの住処へと帰って行った。」

11. Tepi cattāro paṇḍitā samaggā sammodamānā sīlaṃ pūretvā dānaṃ datvā uposathakammaṃ katvā yathākammaṃ gatā.

* tepi cattāro paṇḍitā = 「その四人の賢者たちも」
  * 兎・猿・ジャッカル・カワウソの四匹を指す
* samaggā = 「和合して」
* sammodamānā = 「喜び合いながら」
* sīlaṃ pūretvā = 「戒を満たし」
* dānaṃ datvā = 「布施をして」
* uposathakammaṃ katvā = 「布薩の行いをして」
* yathākammaṃ gatā = 「業に従って(それぞれの趣へ)去った」

→「その四人の賢者たちも和合して喜び合いながら、戒を満たし、布施をして、布薩の行いをして、業に従って(それぞれの趣へ)去った。」
